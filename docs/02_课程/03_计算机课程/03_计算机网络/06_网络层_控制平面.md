# 五、网络层：控制平面

## 5.1 路由选择算法

- 分类
    - 集中式：所有链路有完整拓扑和状态（链路状态）
    - 分布式：迭代式计算和邻居信息交换（距离向量）
    - 静态：路由随时间变化慢
    - 动态：路由随时间变化快

- 设计原则
    - 正确性、完整性
    - 简单性
    - 健壮性
    - 稳定性
    - 公平性
    - 最优性

### 链路状态(LS)算法

**Dijkstra 算法**

```
初始化：N' = {u}
for 所有节点 v:
    if v 与 u 相连:
        D(v) = c(u,v)
    else:
        D(v) = ∞

Loop:
    找到不在 N' 中的最小 D(w)
    将 w 加入 N'
    更新 w 的邻居 v:
        D(v) = min(D(v), D(w) + c(w,v))
until 所有节点在 N' 中
```

- 复杂度
    - 时间复杂度：O(n²)，堆实现 O(n log n)
    - 通信复杂度：每个路由器向其他路由器广播链路状态

**振荡问题：** 链路开销与链路容量有关，可能产生振荡

### 距离向量(DV)算法

**Bellman-Ford 方程：** $$D_x(y) = \min_v \{ C(x,v) + D_v(y) \}$$

- 特点
    - 每个节点定期发送距离向量到邻居
    - 接收 DV 时用 BF 更新
    - 好消息传播快，坏消息传播慢（无穷计数问题）
        - 无穷计数问题解决
            - **毒性逆转**：如果 z 经过 y 到达 x，则 z 告诉 y，z 到 x 的距离为 ∞
            - **定义最大度量**：用足够大数达至上限

### LS vs DV

|   对比项   |    LS    |    DV    |
| :--------: | :------: | :------: |
| 通信复杂度 |  O(n²)   | 邻居之间 |
|  收敛速度  |  O(n²)   |   较慢   |
|   健壮性   | 局部错误 | 错误扩散 |

## 5.2 自治系统(AS)

- 概念
    - **自治系统(AS)**：将路由器聚合成一个区域，每个 AS 有唯一的 AS 号
    - 同一 AS 内的路由器运行相同的路由选择协议
    - 不同 AS 之间通过网关路由器互联

- 网关路由器
    - 位于 AS 边缘，直接连接其他 AS
    - 负责 AS 之间的路由选择

### AS内部

- 自治系统内部路由选择
    - AS 内部
    - 常用协议
        - **RIP**：距离向量协议，最大跳数 15，30 秒更新一次
        - **EIGRP**：高级距离向量协议，快速收敛，支持负载均衡
        - **OSPF**：链路状态协议，开放最短路径优先

#### OSPF(开放最短路优先)

- 层次化 OSPF
    - **本地区域**：普通区域，内部路由器只知道区域内部拓扑
    - **骨干区域**：Area 0，所有区域间流量经过骨干区域转发
    - **区域边界路由器(ABR)**：连接本地区域和骨干区域，汇总并通告路由
    - **主干路由器**：在骨干区域内的路由器
    - **内部路由器**：完全在一个区域内的路由器

- 优点
    - 相对于 RIP：收敛更快、支持更大规模网络
    - 负载均衡：同一目的多条路径可分担流量
    - 分级结构：减少 LSDB 规模，加快收敛

### AS外部

#### BGP(边界网关协议)

**作用：** AS 之间路由选择，学习 AS 间的路由转发

- BGP 会话
    - **外部 BGP(eBGP)**：从相邻 AS 获得子网可达性信息
    - **内部 BGP(iBGP)**：将可达性信息传播给 AS 内部所有路由器

**路由：** `(前缀, AS-PATH, NEXT-HOP)`

- 路由选择规则
- 本地偏好值属性（策略决策）
- 最短 AS-PATH
- 最靠近 NEXT-HOP 路由器（热土豆路由选择）
- BGP 标识符

## 5.3 SDN 控制平面

- 逻辑集中控制器
    - **网络管理更加容易**
    - **基于流表的转发**：允许"可编程"的路由器
    - **控制平面的开放实现**

- SDN 组件
    - **数据平面交换机**：硬件实现通用转发
    - **SDN 控制器**：维护网络状态信息
    - **网络控制应用程序**：非绑定、可由第三方提供

## 5.4 ICMP(因特网控制报文协议)

- 功能
    - 差错报告
    - 路由器信令

**ICMP 报文类型**

| 类型 | 编码 | 描述           |
| :--: | :--: | :------------- |
|  0   |  0   | 回显回答(ping) |
|  3   | 0-15 | 目的不可达     |
|  8   |  0   | 回显请求(ping) |
|  11  |  0   | TTL 过期       |

## 5.5 网络管理

- 五大功能
    - **性能管理**：测量、报告、分析和控制性能
    - **故障管理**：记录、检测和响应故障
    - **配置管理**：跟踪设备配置
    - **账户管理**：定义、记录和控制用户访问
    - **安全管理**：定义安全策略

### SNMP(简单网络管理协议)

**报文类型：**
| 报文 | 功能 |
|:---|:---|
| GetRequest | 管理者到代理："给我数据" |
| SetRequest | 管理者到代理：设置 MIB 值 |
| Response | 代理到管理者：响应 |
| Trap | 代理到管理者：异常事件通知 |
