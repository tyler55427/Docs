# 六、IP 编址与子网划分

## 6.1 IP 地址

- **定义**：IP 地址与物理接口相关联
- **IPv4**：32 位，点分十进制 a.b.c.d（如 192.168.1.1）
  - **CIDR**：采用 a.b.c.d/x 格式表示网络前缀，其中 x 为掩码长度
- **IPv6**：128 位，冒号十六进制（如 2001:db8::1）
  - **格式**：冒号十六进制表示法（每 16 位一段，共 8 段）
  - **示例**：
    - 完整：2001:0db8:85a3:0000:0000:8a2e:0370:7334
    - 压缩：2001:db8:85a3::8a2e:370:7334（:: 压缩连续零段）
    - 前缀：2001:db8:85a3::/64（/64 为前缀长度）

## 6.2 子网

- **子网**：物理直连，中间不用经过路由器
- **子网划分**：将一个大的 IP 网络划分为多个较小的子网络
- **子网掩码**：用于确定 IP 地址中网络部分和主机部分
  - 形式同 IP 地址：255.255.255.0
  - 或前缀长度：/24

### IP 地址结构（IPv4）

以 **192.168.10.123/255.255.255.0** 为例：

| 部分   | 说明                   | 示例值         |
| :----- | :--------------------- | :------------- |
| 网络号 | 标识整个网络（或子网） | 192.168.10.0   |
| 子网号 | 在划分子网后，标识子网 | （上例无子网） |
| 主机号 | 标识子网内的具体主机   | 123            |

## 6.3 IP 地址分类（历史）

| 类别 | 范围                        | 用途     |
| :--- | :-------------------------- | :------- |
| A    | 0.0.0.0 - 126.255.255.255   | 大型网络 |
| B    | 128.0.0.0 - 191.255.255.255 | 中型网络 |
| C    | 192.0.0.0 - 223.255.255.255 | 小型网络 |
| D    | 224.0.0.0 - 239.255.255.255 | 多播     |
| E    | 240.0.0.0 - 255.255.255.255 | 保留     |

## 6.4 特殊 IP 地址

| 地址            | 用途                     |
| :-------------- | :----------------------- |
| 255.255.255.255 | 本地网络广播（受限广播） |
| 126.0.0.1       | 回环地址（loopback）     |
| 0.0.0.0         | 本网络（本主机）         |
| 网络号全 0      | 表示当前网络             |
| 主机号全 0      | 表示整个子网（网络地址） |
| 主机号全 1      | 子网广播                 |

**126.0.0.1 vs 0.0.0.0 区别**：
- 126.0.0.1 是本机进程间通信的环回地址，数据包不经过物理网卡；
- 0.0.0.0 在路由表中表示默认路由，在服务器中表示监听所有网络接口。
