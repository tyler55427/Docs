# 计算机网络缩写

| 缩写 | 全称 | 说明 |
| :--: | :-- | :-- |
| RFC | Request for Comments | 因特网工程任务组的标准文档 |
| HTTP | HyperText Transfer Protocol | 超文本传输协议 |
| TCP | Transmission Control Protocol | 传输控制协议 |
| UDP | User Datagram Protocol | 用户数据报协议 |
| IP | Internet Protocol | 网际协议 |
| ISP | Internet Service Provider | 因特网服务提供商 |
| DNS | Domain Name System | 域名系统 |
| DHCP | Dynamic Host Configuration Protocol | 动态主机配置协议 |
| NAT | Network Address Translation | 网络地址转换 |
| ARP | Address Resolution Protocol | 地址解析协议 |
| ICMP | Internet Control Message Protocol | 因特网控制报文协议 |
| OSPF | Open Shortest Path First | 开放最短路径优先 |
| BGP | Border Gateway Protocol | 边界网关协议 |
| LAN | Local Area Network | 局域网 |
| VLAN | Virtual LAN | 虚拟局域网 |
| MAC | Medium Access Control | 介质访问控制 |
| CRC | Cyclic Redundancy Check | 循环冗余检测 |
| CDN | Content Delivery Network | 内容分发网络 |
| P2P | Peer-to-Peer | 对等网络 |
| SDN | Software Defined Network | 软件定义网络 |
| MSS | Maximum Segment Size | 最大报文段长度 |
| RTT | Round-Trip Time | 往返时间 |
| AIMD | Additive Increase Multiplicative Decrease | 加性增乘性减 |
| GBN | Go-Back-N | 回退 N 步 |
| SR | Selective Repeat | 选择重传 |
| MTU | Maximum Transmission Unit | 最大传输单元 |
| SNMP | Simple Network Management Protocol | 简单网络管理协议 |
| MPLS | Multiprotocol Label Switching | 多协议标签交换 |
| WWW | World Wide Web | 万维网 |
| POP3 | Post Office Protocol v3 | 第三版邮局协议 |
| IMAP | Internet Message Access Protocol | 因特网邮件访问协议 |
| RDT | Reliable Data Transfer | 可靠数据传输协议 |
| DASH | Dynamic Adaptive Streaming over HTTP | 经 HTTP 的动态适应性流 |
| FSM | Finite State Machine | 有限状态机 |
| CIDR | Classless Inter-Domain Routing | 无类别域间路由选择 |
| EBC | Error Bits for detection and Correction | 差错检测和纠正比特 |
| PPP | Point-to-Point Protocol | 点对点协议 |
| FDMA | Frequency Division Multiple Access | 频分多址 |
| TDMA | Time Division Multiple Access | 时分多址 |
| CDMA | Code Division Multiple Access | 码分多址 |
| CSMA | Carrier Sense Multiple Access | 载波侦听多路访问 |
| CSMA/CD | CSMA with Collision Detection | 带碰撞检测的 CSMA |
