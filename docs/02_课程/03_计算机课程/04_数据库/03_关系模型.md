# 三、关系模型
## 3.1 ER 图转换为关系表

### 术语对应
- 关系 → 表 R(A₁, ..., Aₙ)
- 属性 → 列
- 元组 → 行
- 属性值
- 属性值域
- **外键**：指向其他关系的一条记录，为其他关系的主键，若指向任何实体的主键，可为空

### 转换规则

### ① 强实体
创建属性，选择主键

### ② 弱实体
创建属性，增加强实体的主键，共同构成主键

### ③ 二元关系
- **一对一**：选择二者之一的主键加入另一个作为外键
- **一对多**：将一的主键加入多的关系表中
- **多对多**：单独创建关系表，将两者的主键作为外键

### ④ 多元关系
转换为二元关系，单独创建关系表

### ⑤ 继承关系
- 方案一：为父类创建表，子类也创建（不重复父类属性）
- 方案二：为每个子类创建表，都包括父类的属性（查询方便，但可能有冗余）

## 3.2 关系代数

### 基本操作

| 操作 | 符号 | 说明 |
|:---:|:---:|:---|
| 投影 | πₗ(R) | 删除不必要的列 |
| 选择 | σc(R) | 选择满足条件的行 |
| 并集 | R₁ ∪ R₂ | 合并记录，去重 |
| 差集 | R₁ - R₂ | 去掉相同记录 |
| 笛卡尔乘积 | R₁ × R₂ | 两两组合 |
| 重命名 | ρ(R'(N₁→N'₁,...), R) | 改变名字 |

### 额外操作
- 交集
- 连接（θ-join、自然连接）
- 除法 A/B

### 连接类型
| 类型 | 说明 |
|:---:|:---|
| θ-join | 条件为任意逻辑表达式 |
| 等值连接 | 条件为等式 |
| 自然连接 | 相同属性有相同值的记录进行连接 |
| 外连接 | 保留没有匹配上的记录 |

### 外连接变体
- **左外连接** ⟕：保留左边不满足条件的记录
- **右外连接** ⟖：保留右边
- **全外连接** ⟗：保留两边

### 除法
A 有属性 x, y，B 有属性 y：
- A/B 的结果：对于 B 中的每个 y，A 中都有 y 的记录，返回 A 的 x
