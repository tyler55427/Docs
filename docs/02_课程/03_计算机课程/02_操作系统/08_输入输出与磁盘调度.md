# 八、输入输出与磁盘调度

## 8.1 I/O

### I/O 设备

- **I/O 设备分类**
  - 人可读：用户交互
  - 机器可读：电子设备
  - 通信：进程设备
- **I/O 设备组成**
  - 机械式：设备本身
  - 电子部分：设备控制器/适配器
- **I/O 控制方式**
  - 程序控制：CPU 循环等待 I/O 的标志位检查
  - 中断驱动：OS 将 I/O 命令写入控制器寄存器，I/O 完成时产生中断
  - DMA：DMA 模块控制内存与 I/O 设备之间的数据交换，CPU 只在传输完成时中断

### DMA

- **DMA 与中断对比**
  - 数据传输的控制者不同：DMA（DMA 控制器，不占用 CPU 时间）vs 中断（CPU 与 OS 控制）
  - DMA 为周期窃取技术，CPU 暂停一个总线周期，不退出，不保存上下文
- **DMA 配置方式**
  - 单总线，分离 DMA：所有 I/O 共享系统总线，一字节传输需要两个总线周期
  - 单总线，I/O 集成 DMA：DMA 接口多样
  - I/O 总线：DMA 与 I/O 脱离系统总线，接口单一，便于扩展

## 8.2 I/O 软件层次

|     层次     | 说明                           |
| :----------: | :----------------------------- |
|   用户进程   | I/O 调用，格式化 I/O，spooling |
| 设备无关软件 | 命名，保护，阻塞，缓冲，分配   |
| 设备驱动程序 | 建立设备寄存器，检查状态       |
| 中断处理程序 | I/O 结束时唤醒进程             |
|     硬件     | 执行 I/O 操作                  |

- **SPOOL（假脱机技术）**
  - 用程序处理设备 I/O
  - 程序 I/O 操作是和 SPOOL 交换数据，为"虚拟 I/O"
  - SPOOL 与外设交换，为"实际 I/O"
  - 优：高速虚拟 I/O；对独享设备的共享

## 8.3 I/O 缓冲

- **缓冲原因**
  - 进程必须要等待 I/O 操作完成才能继续
  - 执行 I/O 操作期间一些页面必须保存在主存
  - 限制：进程的 I/O 请求不能超过外设的处理能力
- **缓冲类型**
  - 单缓冲：OS 在内存为 I/O 请求分配一个缓冲区
  - 双缓冲：使用两个缓冲区
  - 环形缓冲：多个循环使用
  - 缓冲池：多队列（空闲缓冲区、输入缓冲区、输出缓冲区）

## 8.4 磁盘调度

- **磁盘组成**
  - 磁道、柱面、扇区
- **磁盘访问时间组成**
  - 寻道时间：移臂找到柱面（主要影响性能）
  - 旋转延迟：找到扇区
  - 传输时间：数据传输
- **调度算法**
  - FIFO：简单公平，效率不高
  - PRI：短作业/交互作业有较高优先级，长作业等待长
  - LIFO：有利于事务处理系统，局部性原理，可能饥饿
  - SSTF：优先选择离磁头最近的请求，可能饥饿
  - SCAN：磁头沿单一方向移动，过程中处理请求，偏爱内/外道服务
  - C-SCAN：从低柱面到高柱面，后返回低柱面，中间不处理请求
  - N步扫描：将请求分成长度为 N 的子队列，每个子队列用 SCAN 处理
  - Look 策略：判断该方向上是否还有访问请求，有则扫描，否则改变移动方向

## 8.5 RAID

| 级别  | 说明               | 特点                                 |
| :----: | :----------------- | :----------------------------------- |
| RAID 0 | 非冗余，条带化     | 高性能，无冗余                       |
| RAID 1 | 镜像               | 安全性最好，磁盘利用率 50%           |
| RAID 2 | 汉明码冗余         | 一位纠错，两位检错，所有磁盘磁头同步 |
| RAID 3 | 交错位奇偶校验     | 单冗余盘，并行 I/O                   |
| RAID 4 | 块级奇偶校验       | 独立访问，可并行处理 I/O             |
| RAID 5 | 块级分布式奇偶校验 | 校验数据分布各盘，避免瓶颈           |
| RAID 6 | 双重冗余           | 处理多个磁盘出错，写性能损耗         |

## 8.6 磁盘高速缓存

- 内存中的磁盘缓存区，是磁盘中某些扇区的副本
- **替换算法**
  - LRU：磁盘访问特征有密集性/集中性
  - LFU：基于频率的替换
  - 基于频率的替换：将 LRU 栈分为新区、老区
- **RAM 盘**：用部分内存模拟的磁盘，用于频繁读取磁盘的应用程序及文件
