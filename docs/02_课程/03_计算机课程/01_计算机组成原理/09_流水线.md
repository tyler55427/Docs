# 九、流水线

## 五级流水线

| 阶段 | 说明                                                |
| ---- | --------------------------------------------------- |
| IF   | 取指 (Instruction Fetch)                            |
| ID   | 译码和读寄存器 (Instruction Decode & Register Read) |
| EX   | 执行或计算地址 (Execute or Calculate Address)       |
| MEM  | 访问内存 (Memory Access)                            |
| WB   | 写回寄存器 (Write Back)                             |

## 流水线性能

$$
\text{流水线指令执行时间} = \frac{\text{非流水线指令执行时间}}{\text{流水线级数}}
$$

> 不减少单指令执行时间，提高**吞吐率**。

## 流水线冒险

| 类型               | 说明                                                     |
| ------------------ | -------------------------------------------------------- |
| **结构冒险** | 同一时钟周期不同指令使用同一硬件（指令内存 vs 数据内存） |
| **数据冒险** | 后续指令依赖前序指令结果，RAW（写后读）                  |
| **控制冒险** | 分支决策影响后续指令                                     |

### 结构冒险解决

通过**资源分离**解决：设置独立指令存储器（IF）和数据存储器（MEM），使不同指令可同时使用不同硬件。

### 数据冒险解决

| 方法                 | 说明                                        |
| -------------------- | ------------------------------------------- |
| **前递/旁路**  | ALU 结果直接作为后续指令输入，绕过寄存器堆  |
| **流水线停顿** | load-use 冲突时插入气泡（bubble），停顿一次 |

### 控制冒险解决

| 方法               | 说明                                     |
| ------------------ | ---------------------------------------- |
| **停顿**     | 分支结果确定前停顿（停顿 2 次）          |
| **静态预测** | 总预测不发生跳转，失败则清空流水线       |
| **动态预测** | 使用 BHT（分支历史表），根据历史信息预测 |
| **延迟决定** | 改变指令顺序，将有用指令放在分支后       |
