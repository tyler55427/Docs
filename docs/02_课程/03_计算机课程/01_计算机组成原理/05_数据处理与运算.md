# 五、数据处理与运算

## 整数

### 表示方法

- **原码**：符号位 + 绝对值，最高位为符号位（0 正 1 负）
- **反码**：符号位 + 绝对值，按位取反
- **补码**：符号位 + 绝对值，反码 + 1（计算机中负数常用表示）

范围：8 位 $[-128, 127]$；32 位 $[-2^{31}, 2^{31}-1]$

### 整数溢出

**判定规则：**

- **加法**：同符号数相加 → 可能溢出；不同符号数相加 → 不可能溢出
- **减法**：不同符号数相减 → 可能溢出；同符号数相减 → 不可能溢出

### 饱和处理

溢出时取最大值（最大正数/最小负数），用于音量和图像处理。

### 加法

- **半加器**：2 输入，产生和与进位
- **全加器**：3 输入（两个加数 + 进位）
- **进位保存加法器 (CSA)**：3 数相加变为 2 数相加

### 乘法

#### 普通乘法器结构

两个寄存器存放操作数：

- **被乘数寄存器**：每次循环左移 1 位
- **乘积/乘数寄存器**：初始存放乘数，每次循环右移 1 位

循环 $n$ 次（乘数位数），每步检测乘数最低位：

1. 若最低位 = 1：积 = 积 + 被乘数
2. 被乘数左移 1 位
3. 乘数右移 1 位

积的长度 = 被乘数长度 + 乘数长度，如 32 位 × 32 位 < 2^64。

#### 长乘法器优化（并行加速）

将普通乘法器的 3 个步骤合并为 1 个周期：每一步同时完成加法和移位。

原理：将部分积右移（而非被乘数左移），积和乘数共用 65 位寄存器（64 位积 + 1 位进位）。

#### 垂直加法堆栈

多个部分积并行计算，最后叠加：

```
    乘数31·被乘数30
    乘数30·被乘数31
    ...
    乘数1 ·被乘数0
    乘数0 ·被乘数1
```

每行结果垂直对齐后相加，减少循环次数。

#### 有符号乘法

符号位单独处理（异或），用无符号乘法计算。

> 可用 `mulh` 查看结果是否有溢出（高 64 位非零表示有溢出）。

#### 快速乘法原理

32 位 × 32 位乘法得到 64 位积，每个时钟周期完成一位乘法：

```
乘数[31]·被乘数 → 积[63:32]
乘数[30]·被乘数 → 积[62:31]
...
乘数[1] ·被乘数 → 积[1:0]
乘数[0] ·被乘数 → 积[0]
```

- 积的高位和低位分别由 `mulh` 和 `mul` 指令获取
- 可用 `mulh` 检测乘法是否溢出（高 64 位非零表示有溢出）
- 乘法本质是移位和相加，2 的幂可用移位直接得到（$n × 2^k = n \ll k$）
- 更多硬件并行可加速乘法

### 除法

#### 普通除法器结构

硬件结构：

- **被除数寄存器**：存放被除数
- **除数寄存器**：存放除数
- **商寄存器**：初始化为 0

步骤（重复 $n+1$ 次）：

1. 检测：若除数 ≤ 被除数余数，商左移 1；否则商左移 0
2. 余数寄存器 = 被除数 - 除数（若够减）
3. 除数右移

> 第一次循环必无效（因为初始商为 0）。

#### 长除法优化（无符号）

65 位寄存器结构，防止余数最高位消失：

- 左边部分初始化为 0，右边存放被除数
- 每步：余数左移、商左移
- 检测余数最高位：若为 0 则商左移 1，否则商左移 0 且余数 = 余数 + 除数
- 最后对结果取补码
- 有符号除法的舍入规则

被除数 = 商 × 除数 + 余数

| 表达式      | C 语言       | Python              |
| ----------- | ------------ | ------------------- |
| `7 / 2`   | 3，向零取整  | 3.5，整数除法取 3   |
| `-7 / 2`  | -3，向零取整 | -3.5，整数除法取 -4 |
| `7 / -2`  | -3，向零取整 | -3.5，整数除法取 -4 |
| `-7 / -2` | 3，向零取整  | 3.5，整数除法取 3   |

- **C 语言**：商向零取整，余数与被除数同号
- **Python**：商向下取整（向负无穷），余数与除数同号

> Python：`divmod(-7, 2) = (-4, 1)`，因为 `-4 × 2 + 1 = -7`

- RISC-V 除法指令

| 指令 | 说明                     |
| ---- | ------------------------ |
| div  | 有符号除法，商向零取整   |
| divu | 无符号除法               |
| rem  | 有符号余数，与被除数同号 |
| remu | 无符号余数               |

> 注意：除以 0 不报错；最小整数 ÷ (-1) 可能溢出。

### 减法

减法用补码实现：$a - b = a + (-b)$，对 b 取反 + 1。
