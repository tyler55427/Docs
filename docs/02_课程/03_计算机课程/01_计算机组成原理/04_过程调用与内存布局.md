# 四、过程调用与内存布局

## 过程调用步骤

1. **传参**：参数放入 x10-x17
2. **跳转链接**：`jal x1, Label`
3. **保护现场**：保存寄存器（如需要）
4. **执行过程**
5. **返回值**：结果放入 x10
6. **返回**：`jalr x0, 0(x1)`

### Caller 与 Callee

| 角色       | 说明                                      |
| ---------- | ----------------------------------------- |
| **Caller** | 调用者，保存返回地址 ra、参数寄存器 a0-a7 |
| **Callee** | 被调用者，保存帧指针 fp、栈指针 sp        |

### 寄存器约定

| 类别        | 寄存器                   | 说明         | 保存者 |
| ----------- | ------------------------ | ------------ | ------ |
| 恒 0        | x0                       | 始终为 0     | —      |
| 返回地址    | x1 (ra)                  | 下条指令地址 | Caller |
| 堆栈指针    | x2 (sp)                  | 指向栈顶     | Callee |
| 全局指针    | x3 (gp)                  | 访问静态数据 | —      |
| 线程指针    | x4 (tp)                  | 线程相关     | —      |
| 临时        | x5-x7, x28-x31 (t0-t7)   | 过程可能修改 | Caller |
| 保存寄存器  | x8, x9, x18-x27 (s0-s11) | 过程不修改   | Callee |
| 参数/返回值 | x10-x11 (a0-a1)          | 参数和返回值 | Caller |
| 参数        | x12-x17 (a2-a7)          | 参数         | Caller |

### 内存布局

- 栈帧（活动记录）
  - **活动记录**：过程保存的局部变量、寄存器的段（也叫栈帧）
  - **帧指针 FP** (x8)：指向栈帧底部，过程结束后释放
  - **栈指针 SP** (x2)：指向栈顶
  - 开辟：`addi sp, sp, -N`
  - 释放：`addi sp, sp, N`

> 栈向下增长，堆向上增长，两者相向增长。

- 进程内存布局

| 区域                     | 说明                               |
| ------------------------ | ---------------------------------- |
| **内核系统**             | 0xC0000000 以上，用户程序无法访问  |
| **命令行参数、环境变量** | argc、argv、envp                   |
| **栈**                   | 高地址向下增长，函数调用、局部变量 |
| **空闲内存**             | 堆与栈之间的未分配区域             |
| **堆**                   | malloc/free 动态分配，向上增长     |
| **数据段**               | 已初始化的全局/静态变量            |
| **代码段**               | 程序代码                           |
| **保留**                 | 保留                               |

### 递归示例：斐波那契

**C 代码：**

```c
int fib(int n) {
    if (n == 0) return 0;
    else if (n == 1) return 1;
    else return fib(n - 1) + fib(n - 2);
}
```

**RISC-V 汇编：**

```asm
fib:
    beq  x10, x0, done     # n == 0 则跳转 done
    addi x5, x0, 1
    beq  x10, x5, done     # n == 1 则跳转 done

    addi sp, sp, -16       # 开辟栈帧
    sd   x1, 0(sp)         # 保存 ra
    sd   x10, 8(sp)        # 保存参数 n

    addi x10, x10, -1       # n - 1 作为新参数
    jal  x1, fib            # 调用 fib(n-1)

    ld   x5, 8(sp)         # 恢复 n
    sd   x10, 8(sp)         # 保存 fib(n-1) 的结果

    addi x10, x5, -2        # n - 2 作为新参数
    jal  x1, fib            # 调用 fib(n-2)

    ld   x5, 8(sp)         # 恢复 fib(n-1) 的结果
    ld   x1, 0(sp)          # 恢复 ra
    addi sp, sp, 16         # 释放栈帧

    add  x10, x10, x5       # fib(n-1) + fib(n-2)
    jalr x0, 0(x1)          # 返回

done:
    jalr x0, 0(x1)          # n == 0 或 n == 1 时直接返回
```

递归调用时，每次都会在栈上保存 ra 和参数，形成嵌套的栈帧；返回时逐层弹出，恢复现场。

## 伪指令

伪指令不是真正的指令，是汇编器提供的语法糖，方便程序员编写。汇编器将其展开为一条或多条真实指令。

| 伪指令         | 展开                                            | 说明                 |
| -------------- | ----------------------------------------------- | -------------------- |
| `mv x10, x11`  | `addi x10, x11, 0`                              | 寄存器赋值           |
| `j Label`      | `jal x0, Label`                                 | 无条件跳转           |
| `la x5, Label` | `auipc x5, 0` + `addi x5, x5, offset`           | 加载标签地址到寄存器 |
| `li x5, imm`   | `lui x5, imm[31:12]` + `addi x5, x5, imm[11:0]` | 加载任意 32 位立即数 |

## 系统调用 (ecall)

系统调用是用户程序向操作系统请求服务（如 I/O、进程管理）的接口。

1. `li a7, N` — 将功能号放入 a7
2. 设置参数 a0-a5
3. `ecall` — 触发异常，进入内核态执行相应服务

| 功能号 | 说明        | 参数                           | 返回值          |
| ------ | ----------- | ------------------------------ | --------------- |
| 1      | PrintInt    | a0 = 要输出的整数              | —               |
| 2      | PrintString | a0 = 字符串地址                | —               |
| 3      | ReadInt     | —                              | a0 = 读取的整数 |
| 4      | ReadString  | a0 = 缓冲区地址, a1 = 最大长度 | —               |
| 5      | Exit        | —                              | 退出程序        |
