# 二、计算机性能与计量单位

## 性能指标

| 指标                     | 说明                                                                         | 适用场景 |
| ------------------------ | ---------------------------------------------------------------------------- | -------- |
| **响应时间**       | 任务执行时间（包括硬盘访问、内存访问、I/O 活动、操作系统开销、CPU 执行时间） | 手机等   |
| **吞吐率（带宽）** | 单位时间完成任务个数                                                         | 服务器   |

$$
性能 = \frac{1}{\text{执行时间}}, \quad \frac{\text{性能 X}}{\text{性能 Y}} = \frac{\text{执行时间 Y}}{\text{执行时间 X}}
$$

## 响应时间

响应时间 = CPU 时间 + I/O 时间

### CPU 时间

某线上 CPU 花费的时间，包括用户态时间（用户 CPU 时间）和内核态时间（系统 CPU 时间）。

$$
CPU\ Time = \text{程序指令数} \times \text{CPI} \times \text{时钟周期长度}
$$

CPU 时间的表示方式：

- **CPI（每指令周期数）**：$CPI = \frac{\text{周期数}}{\text{指令数}}$，$IPC = \frac{1}{CPI}$。目的：相同指令系统在不同实现下比较性能。
- **MIPS（每秒百万条指令）**：$\text{MIPS} = \frac{\text{时钟频率}}{CPI \times 10^6}$。不适合评估性能（代码行数、指令功能/时间不同）。
- **FLOPS（每秒浮点运算次数）**：$M(G,T,P,E,Z)FLOPS$。

> 时间是唯一可靠的指标（不适用于 MIPS、FLOPS 评估性能）

性能小结：

| 指标               | 影响因素              | 说明                                                                                                                               |
| ------------------ | --------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| **算法**     | 指令数、CPI           | 决定源程序语句数目，从而决定了 CPU 执行指令数目；通过使用较快或较慢的语句影响 CPI，如当算法使用更多的除法运算时，将会导致 CPI 增大 |
| **编程语言** | 指令数、CPI           | 编程语言的语句决定指令数；如 Java 中的数据抽象引起的间接调用，需使用 CPI 较高的指令                                                |
| **编译器**   | 指令数、CPI           | 编译器翻译源程序，其效率对指令数和 CPI 均有影响；编译器的角色可能十分复杂，并以多种方式影响 CPI                                    |
| **ISA**      | 指令数、CPI、时钟频率 | ISA 影响所有三个方面                                                                                                               |

### I/O 时间

硬盘访问、内存访问、I/O 活动、操作系统开销等。

## Amdahl 定律

$$
\text{总时间}_{\text{new}} = \frac{\text{改进部分的时间}}{\text{改进比率}} + \text{未改进部分的时间}
$$

加速比：

$$
S = \frac{T_{\text{old}}}{T_{\text{new}}} = \frac{1}{(1-a) + \frac{a}{k}}
$$

其中 $a$ 为提升的比例。$a \uparrow$ 时，$T_{\text{old}}$ 可提升性能。

## 存储系统访问时间

| 层次       | 访问时间 |
| ---------- | -------- |
| CPU 寄存器 | 1ns      |
| L1 Cache   | 10ns     |
| 内存 DRAM  | 50ns     |
| 固态硬盘   | 10 μs   |
| 磁盘       | 5~20 ms  |

## 功耗

降低功耗方法：

1. 先进半导体（闲时低功率）
2. 操作系统实现电源管理
3. 根据运行负载调整主频
