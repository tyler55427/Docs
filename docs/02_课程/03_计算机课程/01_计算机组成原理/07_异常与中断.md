# 七、异常与中断

## 定义

- **异常（Exception）**：不正当的处理器内部事件
- **中断（Interrupt）**：外部 I/O 设备请求

## 中断/异常分类

| 类型 | 说明 | 同步/异步 | 返回行为 |
|------|------|------------|----------|
| **中断** | I/O 设备信号 | 异步 | 返回下一条指令 |
| **陷阱** | 有意异常（系统调用） | 同步 | 返回下一条指令 |
| **故障** | 潜在可恢复错误 | 同步 | 可能返回当前指令 |
| **终止** | 不可恢复错误 | 同步 | 不可返回 |

## 外部中断

| 类型 | 说明 |
|------|------|
| 可屏蔽中断 INTR | 外设请求 |
| 不可屏蔽中断 NMI | 断电、内存读错等 |

## 内部中断

- **软中断**（软件发起）：系统调用
- **异常**（运行时错误）：除法错误、保护故障、缺页、机器检查

## 陷阱与系统调用

用户态 → 内核态（可执行所有指令）→ 返回用户态
