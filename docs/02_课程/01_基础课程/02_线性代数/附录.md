# 附录

## 三种等价关系对比

设 $A, B$ 为 $n$ 阶方阵，$P, Q$ 为可逆阵。

| 关系 | 定义 | 充要条件 | 不变量 |
|------|------|----------|--------|
| **等价** $A \cong B$ | 存在可逆 $P, Q$ 使 $PAQ = B$ | $r(A) = r(B)$（同型） | 秩 |
| **相似** $A \sim B$ | 存在可逆 $P$ 使 $P^{-1}AP = B$ | 同一线性变换不同基下的表示 | 迹、行列式、特征值、秩、特征多项式 |
| **合同** $A \simeq B$ | 存在可逆 $C$ 使 $C^TAC = B$ | 二次型经可逆替换互联 | 对称性、秩、正负惯性指数 |

**联系**：
- 正交相似必同时为合同：$Q^T A Q$（$Q$ 正交时 $Q^T = Q^{-1}$）
- 实对称阵的正交对角化：既是相似也是合同

## 常用秩的不等式

设 $A$ 为 $m \times n$，$B$ 为 $n \times s$：

- $r(AB) \le \min(r(A), r(B))$
- $r(A + B) \le r(A) + r(B)$
- $r(AB) \ge r(A) + r(B) - n$（西尔维斯特）
- 若 $AB = O$，则 $r(A) + r(B) \le n$
- 若 $A$ 列满秩：$r(AB) = r(B)$；若 $B$ 行满秩：$r(AB) = r(A)$
- $r\begin{pmatrix} A & O \\ O & B \end{pmatrix} = r(A) + r(B)$
- $r\begin{pmatrix} A & C \\ O & B \end{pmatrix} \ge r(A) + r(B)$

## 迹的常用公式

- $\mathrm{tr}(A) = \sum a_{ii} = \sum \lambda_i$（特征值之和）
- $\mathrm{tr}(AB) = \mathrm{tr}(BA)$
- $\mathrm{tr}(A + B) = \mathrm{tr}(A) + \mathrm{tr}(B)$
- $\mathrm{tr}(kA) = k\,\mathrm{tr}(A)$
- $\mathrm{tr}(A^T) = \mathrm{tr}(A)$

## 特殊矩阵性质速查

### 正交矩阵 $Q$（$Q^TQ = I$）

- 列向量组构成 $\mathbb{R}^n$ 标准正交基
- $Q^{-1} = Q^T$，$|Q| = \pm 1$
- 特征值模为 1（实特征值为 $\pm 1$）
- $Q_1, Q_2$ 正交 $\Rightarrow Q_1Q_2$ 正交

### 实对称矩阵 $A$（$A^T = A$）

- 特征值全为实
- 不同特征值对应特征向量正交
- 必可正交对角化：$\exists Q$ 正交，$Q^TAQ = \Lambda$
- $k$ 重特征值恰有 $k$ 个线性无关特征向量（几何 = 代数重数）

### 正定矩阵 $A$（$A^T = A$，$x^TAx > 0$）

- 特征值全为正
- 各阶顺序主子式全为正
- $a_{ii} > 0$（对角元为正）
- 正惯性指数 $p = n$
- 合同于 $I$：$A = C^TC$（$C$ 可逆）
- 存在唯一的 Cholesky 分解 $A = LL^T$（$L$ 下三角，对角元为正）

## 实对称阵与正交对角化要点

实对称阵 $A$ 正交对角化 $Q^TAQ = \Lambda$ 的要点：

1. 不同特征值的特征向量天然正交，**无需**跨特征值正交化
2. 重根内部需施密特正交化 + 单位化
3. $\Lambda$ 对角元即特征值，$Q$ 各列即对应单位特征向量
4. 同时实现相似（$Q^{-1}AQ$）与合同（$Q^TAQ$）

## 常见判别与解题线索

### 求解线性方程组 $Ax = b$

1. 唯一解：$r(A) = r(\bar{A}) = n$；$|A| \neq 0$（方阵）
2. 无穷多解：$r(A) = r(\bar{A}) < n$
3. 无解：$r(A) < r(\bar{A})$
4. 齐次 $Ax = 0$ 非零解：$r(A) < n$ 或 $|A| = 0$

### 矩阵可对角化判定

- 有 $n$ 个线性无关特征向量
- 各特征值几何重数 = 代数重数
- 实对称阵恒可对角化（可正交对角化）
- 有 $n$ 个互异特征值 $\Rightarrow$ 可对角化

### 二次型正定判定顺序

1. 优先用**顺序主子式**全为正
2. 或特征值全为正
3. 或正惯性指数 $p = n$
4. 或 $A$ 合同于 $I$（即 $A = C^TC$，$C$ 可逆）
