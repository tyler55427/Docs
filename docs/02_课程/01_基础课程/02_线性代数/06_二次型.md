# 六、二次型

## 二次型及其矩阵

### 定义

$n$ 个变量 $x_1, \cdots, x_n$ 的**二次齐次多项式**：

$$
f(x_1, \cdots, x_n) = \sum_{i,j} a_{ij} x_i x_j = \sum_{i=1}^{n} a_{ii} x_i^2 + 2\sum_{i < j} a_{ij} x_i x_j
$$

约定 $a_{ij} = a_{ji}$，则 $f = x^T A x$，其中 $A = (a_{ij})_{n \times n}$ 为**对称矩阵**，$x = (x_1, \cdots, x_n)^T$。

### 矩阵表示

$f(x) = x^T A x$，$A$ 为对称矩阵，称为二次型的**矩阵**；$r(A)$ 称为二次型的**秩**。

**一一对应**：$n$ 元二次型 $\leftrightarrow$ $n$ 阶对称矩阵。

**线性替换**：$x = Cy$，则 $f = x^T A x = y^T (C^T A C) y$，得到新二次型矩阵 $B = C^T A C$，仍对称。

### 矩阵合同

设 $A, B$ 为 $n$ 阶方阵，若存在可逆阵 $C$ 使 $C^T A C = B$，称 $A$ 与 $B$ **合同**。

**性质**：$r(A) = r(B)$；若 $A$ 对称，则 $B$ 对称；合同关系是等价关系。

二次型经可逆线性替换后，新旧矩阵合同。

## 二次型的标准形

### 标准形

只含平方项的二次型 $f = d_1 y_1^2 + d_2 y_2^2 + \cdots + d_n y_n^2$ 称为**标准形**。

**定理**：任一二次型经可逆线性替换可化为标准形（即任一对称阵合同于对角阵）。

### 配方法（拉格朗日法）

通过配方逐步消去交叉项：

1. 若有平方项 $a_{11} x_1^2$（$a_{11} \neq 0$），将含 $x_1$ 的项集中配方
2. 若无平方项（仅交叉项 $a_{12} x_1 x_2$），先作线性替换 $\begin{cases} x_1 = y_1 + y_2 \\ x_2 = y_1 - y_2 \end{cases}$ 产生平方项
3. 递归处理剩余变量

### 惯性定理

**定理**：二次型经可逆线性替换化为标准形后，正、负、零系数的个数是**不变量**，与所用替换无关。

- **正惯性指数** $p$：正系数个数
- **负惯性指数** $q$：负系数个数
- $p + q = r$（二次型的秩），$n - r$ 为零系数个数

**规范形**：系数为 $\pm 1$ 或 0 的标准形：

$$
f = y_1^2 + \cdots + y_p^2 - y_{p+1}^2 - \cdots - y_{p+q}^2
$$

由 $n, p, q$ 唯一决定。两二次型（对称阵）合同 $\Leftrightarrow$ 正、负惯性指数分别相等。

## 正交变换化标准形

### 实对称阵的性质

- 实对称阵的特征值全为**实数**
- 实对称阵不同特征值对应的特征向量**正交**
- 实对称阵必可正交对角化：存在正交阵 $Q$（$Q^T Q = I$）使 $Q^T A Q = \Lambda$（$\Lambda$ 对角）

### 正交对角化步骤

1. 求 $A$ 的特征值 $\lambda_1, \cdots, \lambda_n$
2. 对每个特征值求特征子空间的一组基
3. 将属于同一特征值的特征向量用**施密特正交化**化为正交基
4. 单位化得 $\eta_1, \cdots, \eta_n$
5. 令 $Q = (\eta_1, \cdots, \eta_n)$（正交阵，$Q^{-1} = Q^T$），则

$$
Q^T A Q = \Lambda = \mathrm{diag}(\lambda_1, \cdots, \lambda_n)
$$

### 正交变换保持几何性质

正交变换 $x = Qy$ 保持**长度**和**内积**不变，是几何中的旋转或反射，故正交变换化二次型标准形保持其几何形状。

## 正定二次型

### 定义

$f(x) = x^T A x$ 称为**正定**，若对任意 $x \neq 0$ 有 $f(x) > 0$，此时 $A$ 称正定矩阵。

类似定义：

- **负定**：$f(x) < 0\ (\forall x \neq 0)$
- **半正定**：$f(x) \ge 0$
- **半负定**：$f(x) \le 0$
- **不定**：既不正定也不负定

### 正定的充要条件

设 $A$ 为 $n$ 阶实对称阵，以下等价：

1. $A$ 正定
2. $A$ 的特征值全为正
3. $A$ 的正惯性指数 $p = n$
4. $A$ 合同于 $I_n$（即 $A = C^T C$，$C$ 可逆）
5. $A$ 的各阶**顺序主子式**全为正：

$$
\Delta_k = \begin{vmatrix} a_{11} & \cdots & a_{1k} \\ \vdots & & \vdots \\ a_{k1} & \cdots & a_{kk} \end{vmatrix} > 0, \quad k = 1, 2, \cdots, n
$$

**顺序主子式法**是判定正定最常用的方法。

### 负定的充要条件

$A$ 负定 $\Leftrightarrow$ 奇数阶顺序主子式 $< 0$，偶数阶顺序主子式 $> 0$，即 $(-1)^k \Delta_k > 0\ (k = 1, \cdots, n)$。

### 半正定的充要条件

$A$ 半正定 $\Leftrightarrow$ 所有特征值非负 $\Leftrightarrow$ 各主子式（注意是所有主子式，不仅是顺序）非负 $\Leftrightarrow A = C^T C$（$C$ 一般方阵，不必可逆）。

## 典型二次曲面

通过化简二次型可识别曲面的类型，标准形系数符号决定曲面类型：

| 标准形                                                      | 曲面类型           |
| ----------------------------------------------------------- | ------------------ |
| $\frac{x^2}{a^2} + \frac{y^2}{b^2} + \frac{z^2}{c^2} = 1$ | 椭球面             |
| $\frac{x^2}{a^2} + \frac{y^2}{b^2} - \frac{z^2}{c^2} = 1$ | 单叶双曲面         |
| $\frac{x^2}{a^2} - \frac{y^2}{b^2} - \frac{z^2}{c^2} = 1$ | 双叶双曲面         |
| $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 2z$                  | 椭圆抛物面         |
| $\frac{x^2}{a^2} - \frac{y^2}{b^2} = 2z$                  | 双曲抛物面（鞍面） |
| $\frac{x^2}{a^2} + \frac{y^2}{b^2} - \frac{z^2}{c^2} = 0$ | 二次锥面           |
