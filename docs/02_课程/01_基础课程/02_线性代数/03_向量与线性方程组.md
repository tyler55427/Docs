# 三、向量与线性方程组

## $n$ 维向量

### 向量的定义

**$n$ 维向量**：$n$ 个有序数组成的数组 $\alpha = (a_1, a_2, \cdots, a_n)^T$（列向量）或行向量。

**线性运算**：

- 加法：$\alpha + \beta = (a_1+b_1, \cdots, a_n+b_n)^T$
- 数乘：$k\alpha = (ka_1, \cdots, ka_n)^T$

满足与矩阵线性运算相同的八条运算律。

### 线性组合与线性表示

**线性组合**：$k_1\alpha_1 + k_2\alpha_2 + \cdots + k_s\alpha_s$。

**线性表示**：若 $\beta = k_1\alpha_1 + \cdots + k_s\alpha_s$，称 $\beta$ 可由 $\alpha_1, \cdots, \alpha_s$ 线性表示。

**判定**：$\beta$ 可由 $\alpha_1, \cdots, \alpha_s$ 线性表示 $\Leftrightarrow$ 非齐次方程组 $x_1\alpha_1 + \cdots + x_s\alpha_s = \beta$ 有解 $\Leftrightarrow r(\alpha_1, \cdots, \alpha_s) = r(\alpha_1, \cdots, \alpha_s, \beta)$。

## 线性相关性

### 定义

向量组 $\alpha_1, \cdots, \alpha_s$ 称为**线性相关**，若存在不全为零的数 $k_1, \cdots, k_s$ 使

$$
k_1\alpha_1 + k_2\alpha_2 + \cdots + k_s\alpha_s = 0
$$

否则称为**线性无关**（上式成立必推出 $k_1 = \cdots = k_s = 0$）。

### 重要结论

- 单个向量 $\alpha$ 线性相关 $\Leftrightarrow \alpha = 0$
- 两个向量线性相关 $\Leftrightarrow$ 成比例
- 含零向量的向量组必线性相关
- **部分相关 $\Rightarrow$ 整体相关**；整体无关 $\Rightarrow$ 部分无关
- $\alpha_1, \cdots, \alpha_s$ 线性相关 $\Leftrightarrow$ 其中某向量可由其余线性表示（$s \ge 2$）
- $s$ 个 $n$ 维向量，当 $s > n$ 时必线性相关

### 判定方法

设 $A = (\alpha_1, \cdots, \alpha_s)$（$\alpha_i$ 为列向量），则

$$
\alpha_1, \cdots, \alpha_s \text{ 线性相关} \Leftrightarrow r(A) < s \Leftrightarrow |A| = 0 \ (s = n \text{ 时})
$$

$$
\alpha_1, \cdots, \alpha_s \text{ 线性无关} \Leftrightarrow r(A) = s \Leftrightarrow |A| \neq 0 \ (s = n \text{ 时})
$$

## 向量组的秩

### 极大线性无关组

向量组（其部分组）$\alpha_{i_1}, \cdots, \alpha_{i_r}$ 称为原向量组的**极大线性无关组**，若它本身线性无关，且原组中任一向量都可由它线性表示。

**向量组的秩** $r(\alpha_1, \cdots, \alpha_s)$：极大线性无关组所含向量个数。

### 矩阵秩与向量组秩的关系

设 $A = (\alpha_1, \cdots, \alpha_s)$（列向量组），则

$$
r(A) = \text{列向量组的秩}
$$

同理行向量组的秩也等于 $r(A)$。

**求极大无关组**：把 $\alpha_1, \cdots, \alpha_s$ 排成矩阵 $A$，作初等行变换化为行阶梯形，主元所在列对应的原向量即构成一个极大无关组。

### 等价向量组

两向量组可互相线性表示称为**等价**。

- 等价的向量组秩相等
- 若向量组 I 可由 II 线性表示，则 $r(\text{I}) \le r(\text{II})$
- 若两向量组等价，则 $r(\text{I}) = r(\text{II})$

## 线性方程组解的结构

### 齐次方程组 $Ax = 0$

**解空间**：齐次方程组的全体解构成一个向量空间（称为**解空间**）。

**基础解系**：解空间的一个基，即一组线性无关的解 $\eta_1, \cdots, \eta_{n-r}$，使得任一解都可由它们线性表示。

- 若 $r(A) = r < n$，则基础解系含 $n - r$ 个解向量
- 若 $r(A) = n$，只有零解，无基础解系
- **通解**：$x = k_1\eta_1 + k_2\eta_2 + \cdots + k_{n-r}\eta_{n-r}$

### 非齐次方程组 $Ax = b$

设 $\eta^*$ 为 $Ax = b$ 的一个特解，$\eta_1, \cdots, \eta_{n-r}$ 为对应齐次方程组 $Ax = 0$ 的基础解系，则**通解**：

$$
x = \eta^* + k_1\eta_1 + k_2\eta_2 + \cdots + k_{n-r}\eta_{n-r}
$$

即"特解 + 导出组通解"。

**性质**：

- 若 $\eta_1, \eta_2$ 是 $Ax = b$ 的解，则 $\eta_1 - \eta_2$ 是 $Ax = 0$ 的解
- 若 $\eta^*$ 是 $Ax = b$ 的解，$\xi$ 是 $Ax = 0$ 的解，则 $\eta^* + \xi$ 是 $Ax = b$ 的解

### 解的结构与秩的关系

设 $A = (a_{ij})_{m \times n}$，$b \neq 0$：

| 条件                          | 解的结构                                     |
| ----------------------------- | -------------------------------------------- |
| $r(A) = r(\bar{A}) = n$     | 唯一解                                       |
| $r(A) = r(\bar{A}) = r < n$ | 通解 = 特解 +$\sum_{i=1}^{n-r} k_i \eta_i$ |
| $r(A) < r(\bar{A})$         | 无解                                         |

**$n - r(A)$** 称为解空间的维数（齐次情形），即自由未知量的个数。

### 解方程组的方法步骤

1. 写出增广矩阵 $\bar{A} = (A \mid b)$
2. 作初等行变换化为行阶梯形，判断是否有解（比较 $r(A)$ 与 $r(\bar{A})$）
3. 若有解，继续化为行最简形
4. 选取自由未知量，写出通解；齐次情形取自由变量依次取值得到基础解系
