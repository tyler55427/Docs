## 三角恒等式

### 基本恒等式

$$\sin^2 x + \cos^2 x = 1$$

$$\tan x = \frac{\sin x}{\cos x}$$

$$\sec^2 x - \tan^2 x = 1$$

$$\csc^2 x - \cot^2 x = 1$$

### 和差化积

$$\sin A + \sin B = 2\sin\frac{A+B}{2}\cos\frac{A-B}{2}$$

$$\sin A - \sin B = 2\cos\frac{A+B}{2}\sin\frac{A-B}{2}$$

$$\cos A + \cos B = 2\cos\frac{A+B}{2}\cos\frac{A-B}{2}$$

$$\cos A - \cos B = -2\sin\frac{A+B}{2}\sin\frac{A-B}{2}$$

### 积化和差

$$\sin A \cos B = \frac{1}{2}[\sin(A+B) + \sin(A-B)]$$

$$\cos A \cos B = \frac{1}{2}[\cos(A+B) + \cos(A-B)]$$

$$\sin A \sin B = \frac{1}{2}[\cos(A-B) - \cos(A+B)]$$

### 倍角公式

$$\sin 2x = 2\sin x \cos x$$

$$\cos 2x = \cos^2 x - \sin^2 x = 2\cos^2 x - 1 = 1 - 2\sin^2 x$$

### 半角公式

$$\sin\frac{x}{2} = \pm\sqrt{\frac{1-\cos x}{2}}$$

$$\cos\frac{x}{2} = \pm\sqrt{\frac{1+\cos x}{2}}$$

## 一元二次方程

$ax^2 + bx + c = 0$（$a \neq 0$）：

$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

**韦达定理**：

$$x_1 + x_2 = -\frac{b}{a}, \quad x_1 \cdot x_2 = \frac{c}{a}$$

## 行列式

**二阶**：

$$\begin{vmatrix} a & b \\ c & d \end{vmatrix} = ad - bc$$

**三阶（沙路法则）**：

$$\begin{vmatrix} a_1 & b_1 & c_1 \\ a_2 & b_2 & c_2 \\ a_3 & b_3 & c_3 \end{vmatrix} = a_1 b_2 c_3 + a_2 b_3 c_1 + a_3 b_1 c_2 - a_3 b_2 c_1 - a_2 b_1 c_3 - a_1 b_3 c_2$$

## 平面解析几何

**两点距离**：

$$d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}$$

**直线**：

- 点斜式：$y - y_0 = k(x - x_0)$
- 一般式：$Ax + By + C = 0$

**点到直线距离**：

$$d = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}$$

**圆**：

$$(x-a)^2 + (y-b)^2 = R^2$$

**椭圆**：

$$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 \quad (a > b \text{ 时焦点在 } x \text{ 轴})$$

**双曲线**：

$$\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1 \quad (a > 0, b > 0, \text{焦点在 } x \text{ 轴})$$

**抛物线**：

$$y^2 = 2px \quad (\text{焦点 } (p/2, 0) \text{，准线 } x = -p/2)$$
