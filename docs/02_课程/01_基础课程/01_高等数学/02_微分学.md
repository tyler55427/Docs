# 二、微分学

## 导数（微商）的概念

### 导数定义

$$
f'(x_0) = \lim_{h \to 0} \frac{f(x_0 + h) - f(x_0)}{h} = \lim_{\Delta x \to 0} \frac{f(x_0 + \Delta x) - f(x_0)}{\Delta x}
$$

记作 $y', \dfrac{dy}{dx}, \dfrac{df}{dx}$

**左导数**：$f'_-(x_0) = \lim_{h \to 0^-} \dfrac{f(x_0 + h) - f(x_0)}{h}$

**右导数**：$f'_+(x_0) = \lim_{h \to 0^+} \dfrac{f(x_0 + h) - f(x_0)}{h}$

**可导的充要条件**：左导数 = 右导数

### 可导与连续的关系

**可导 $\Rightarrow$ 连续**（几何意义：切线存在则曲线光滑）

**连续 $\not\Rightarrow$ 可导**：如 $y = |x|$ 在 $x=0$ 连续但不可导（尖点）

### 导数的几何意义

导数 $f'(x_0)$ 是曲线 $y = f(x)$ 在点 $(x_0, f(x_0))$ 处**切线的斜率**。

**切线方程**：$y - f(x_0) = f'(x_0)(x - x_0)$

**法线方程**：$y - f(x_0) = -\dfrac{1}{f'(x_0)}(x - x_0)$（$f'(x_0) \neq 0$）

### 导数的物理意义

位移对时间的导数 = 速度；速度对时间的导数 = 加速度。

## 链式法则与反函数求导

### 链式法则

若 $y = f(u)$，$u = g(x)$，则

$$
\frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx}
$$

多个中间变量以此类推。

### 反函数求导

若 $y = f(x)$ 可导且 $f'(x) \neq 0$，则 $x = f^{-1}(y)$ 可导，且

$$
\frac{dx}{dy} = \frac{1}{dy/dx} = \frac{1}{f'(x)}
$$

注意 $\dfrac{dx}{dy} \neq \dfrac{1}{dx/dy}$。

## 基本导数公式

| $f(x)$      | $f'(x)$                    |
| ------------- | ---------------------------- |
| $C$（常数） | $0$                        |
| $x^n$       | $nx^{n-1}$                 |
| $\sin x$    | $\cos x$                   |
| $\cos x$    | $-\sin x$                  |
| $\tan x$    | $\sec^2 x$                 |
| $\cot x$    | $-\csc^2 x$                |
| $\sec x$    | $\sec x \tan x$            |
| $\csc x$    | $-\csc x \cot x$           |
| $e^x$       | $e^x$                      |
| $a^x$       | $a^x \ln a$                |
| $\ln x$     | $\dfrac{1}{x}$             |
| $\log_a x$  | $\dfrac{1}{x \ln a}$       |
| $\arcsin x$ | $\dfrac{1}{\sqrt{1-x^2}}$  |
| $\arccos x$ | $-\dfrac{1}{\sqrt{1-x^2}}$ |
| $\arctan x$ | $\dfrac{1}{1+x^2}$         |
| $\sinh x$   | $\cosh x$                  |
| $\cosh x$   | $\sinh x$                  |

### 导数的四则运算

- $(u \pm v)' = u' \pm v'$
- $(u \cdot v)' = u'v + uv'$
- $(c \cdot f)' = c \cdot f'$（$c$ 为常数）
- $\left(\dfrac{u}{v}\right)' = \dfrac{u'v - uv'}{v^2}$（$v \neq 0$）

### 基本导数公式（I - V）

- **(I)** $(x^a)' = a x^{a-1}$（$x > 0$）
- **(II)** $(\sin x)' = \cos x$，$(\cos x)' = -\sin x$，$(\tan x)' = \sec^2 x$，$(\cot x)' = -\csc^2 x$
- **(III)** $(\arcsin x)' = \dfrac{1}{\sqrt{1-x^2}}$，$(\arccos x)' = -\dfrac{1}{\sqrt{1-x^2}}$，$(\arctan x)' = \dfrac{1}{1+x^2}$，$(\text{arccot}\, x)' = -\dfrac{1}{1+x^2}$（$|x| < 1$）
- **(IV)** $(a^x)' = a^x \ln a$，特别 $(e^x)' = e^x$
- **(V)** $(\ln|x|)' = \dfrac{1}{x}$（$x \neq 0$）

> 初等函数在定义域内可导时，导函数仍是初等函数。
> 互逆关系：$\arcsin x + \arccos x = \dfrac{\pi}{2}$（导数和为 $0$）。

## 无穷小量与微分

### 微分的定义

若 $\Delta y = f(x_0 + \Delta x) - f(x_0) = A\Delta x + o(\Delta x)$，则称 $f(x)$ 在 $x_0$ **可微**，$dy = A\Delta x$ 称为**微分**。

**可微的充要条件**：$f(x)$ 在 $x_0$ 可导，且 $dy = f'(x_0) dx$

因此 $f'(x) = \dfrac{dy}{dx}$，导数即微分之商。

### 一阶微分形式不变性

无论 $u$ 是自变量还是中间变量，$dy = f'(u) du$ 均成立。

此性质使微分运算比导数更灵活（尤其在积分中）。

### 近似计算

$$
f(x_0 + \Delta x) \approx f(x_0) + f'(x_0) \Delta x
$$

**常用近似公式**（$x \to 0$）：

| 近似公式                              | 名称       |
| ------------------------------------- | ---------- |
| $\sin x \approx x$                  | 正弦近似   |
| $\tan x \approx x$                  | 正切近似   |
| $e^x \approx 1 + x$                 | 指数近似   |
| $\ln(1+x) \approx x$                | 对数近似   |
| $(1+x)^\alpha \approx 1 + \alpha x$ | 二项式近似 |
| $\cos x \approx 1 - \dfrac{x^2}{2}$ | 余弦近似   |

## 高阶导数与高阶微分

### 高阶导数

$$
f^{(n)}(x) = (f^{(n-1)}(x))'
$$

**二阶导数**：$f''(x_0)$ 反映函数增减的快慢（切线斜率的变化率）

**物理意义**：$f''(x)$ 是速度对时间的导数 = 加速度

**三角函数高阶导数恒等式**：

$$
(\sin x)^{(n)} = \sin\left(x + \frac{n\pi}{2}\right)
$$

> 类似地 $(\cos x)^{(n)} = \cos\left(x + \frac{n\pi}{2}\right)$，可由 $\sin, \cos$ 周期性推出。

### 反双曲函数与对数恒等式

$$
\ln\left(y + \sqrt{y^2+1}\right) = x \quad\Longleftrightarrow\quad y = \sinh x = \frac{e^x - e^{-x}}{2}
$$

$$
\ln\left(y + \sqrt{y^2-1}\right) = x \quad\Longleftrightarrow\quad y = \cosh x = \frac{e^x + e^{-x}}{2}
$$

### 莱布尼茨公式

$$
(uv)^{(n)} = \sum_{k=0}^{n} C_n^k u^{(k)} v^{(n-k)}
$$

适用：两函数乘积的高阶导数。

### 高阶微分

$d^n y = f^{(n)}(x) (dx)^n$，$(dx)^n$ 是常数因子。

**二阶微分**：

$$
d^2 y = d(dy) = (f'(x)\,dx)'\,dx = f''(x)\,dx^2
$$

其中 $dx$ 视为常数。

**重要**：高阶微分**不具备**形式不变性。即当 $y$ 是中间变量时，$d^2 y \neq g''(y)\,dy^2$（因为 $dy$ 不再是常数）。

## 绝对值不等式（辅助）

$$
|x+y| \leqslant |x| + |y|
$$

$$
|a-c| \leqslant |a-b| + |b-c| \qquad \text{（三角不等式）}
$$

$$
\bigl||x|-|y|\bigr| \leqslant |x-y|
$$
