# 三、积分学

## 不定积分

### 原函数与不定积分

若 $F'(x) = f(x)$，则 $F(x)$ 是 $f(x)$ 的一个**原函数**。

**不定积分**：$\displaystyle \int f(x) dx = F(x) + C$，$C$ 为任意常数。

**原函数存在定理**：若 $f(x)$ 在区间 $I$ 连续，则原函数必存在。

### 基本积分公式

| $f(x)$                        | $\int f(x)dx$                     |
| ------------------------------- | ----------------------------------- |
| $x^n$（$n \neq -1$）        | $\dfrac{x^{n+1}}{n+1} + C$        |
| $\dfrac{1}{x}$                | $\ln|x| + C$                      |
| $e^x$                         | $e^x + C$                         |
| $a^x$                         | $\dfrac{a^x}{\ln a} + C$          |
| $\sin x$                      | $-\cos x + C$                     |
| $\cos x$                      | $\sin x + C$                      |
| $\sec^2 x$                    | $\tan x + C$                      |
| $\csc^2 x$                    | $-\cot x + C$                     |
| $\sec x \tan x$               | $\sec x + C$                      |
| $\csc x \cot x$               | $-\csc x + C$                     |
| $\dfrac{1}{\sqrt{1-x^2}}$     | $\arcsin x + C$                   |
| $\dfrac{1}{1+x^2}$            | $\arctan x + C$                   |
| $\dfrac{1}{\sqrt{x^2 \pm 1}}$ | $\ln|x \pm \sqrt{x^2 \pm 1}| + C$ |
| $\tan x$                      | $-\ln|\cos x| + C$                |
| $\cot x$                      | $\ln|\sin x| + C$                 |
| $\sec x$                      | $\ln|\sec x + \tan x| + C$        |
| $\csc x$                      | $-\ln|\csc x + \cot x| + C$       |

### 含 $a^2$ 的有理分式与根式积分

$$
\int \frac{1}{x^2-a^2}\,dx = \frac{1}{2a}\ln\left|\frac{x-a}{x+a}\right| + C
$$

$$
\int \frac{1}{x^2+a^2}\,dx = \frac{1}{a}\arctan\frac{x}{a} + C \quad (a>0)
$$

$$
\int \frac{1}{\sqrt{a^2-x^2}}\,dx = \arcsin\frac{x}{a} + C \quad (a>0)
$$

$$
\int \frac{1}{\sqrt{x^2\pm a^2}}\,dx = \ln\left|x + \sqrt{x^2\pm a^2}\right| + C
$$

$$
\int \sqrt{x^2\pm a^2}\,dx = \frac{x}{2}\sqrt{x^2\pm a^2} \pm \frac{a^2}{2}\ln\left|x+\sqrt{x^2\pm a^2}\right| + C
$$

$$
\int \sqrt{a^2-x^2}\,dx = \frac{a^2}{2}\arcsin\frac{x}{a} + \frac{x}{2}\sqrt{a^2-x^2} + C
$$

$$
\int \tan^2 x\,dx = \int \sin x\,d(\sec x) = \tan x - x + C
$$

### $\tan^n x$ 递推公式 $\;\; I_n = \displaystyle\int \tan^n x\,dx$

$$
I_{n+1} = \frac{2n-1}{2n}\,I_n + \frac{1}{n}\tan^{n-1} x, \qquad n \neq 1
$$

$$
I_1 = \frac{1}{4}\arctan\frac{1}{4}, \qquad I_2 = \frac{1}{2}\ln\left|\frac{x-1}{x+1}\right|
$$

> 备注：原笔记中 $I_1, I_2$ 的具体形式为特例记录，做题时需重新推导。

### $\sec^n x$ 递推公式

$$
\int \sec^n x\,dx = \int \sec^{n-2} x\,d(\tan x) = \sec^{n-2} x\tan x - (n-2)\int \sec^{n-2} x\sin x\tan x\,dx
$$

$$
= (n-1)\int \sec^{n-2} x(1-\cos^2 x)\,dx = (n-2)\int (\sec^n x - \sec^{n-2} x)\,dx
$$

$$
\boxed{\;\int \sec^n x\,dx = \frac{1}{n-1}\sec^{n-2} x\tan x + \frac{n-2}{n-1}\int \sec^{n-2} x\,dx\;}
$$

### 三角有理式积分

$$
\int \frac{dx}{a\cos x + b\sin x} = \frac{1}{\sqrt{a^2+b^2}}\arctan\frac{a\sin x - b\cos x}{\sqrt{a^2+b^2}\cos x} + C
$$

$$
\int \frac{dx}{a + b\cos x} = \frac{1}{\sqrt{a^2-b^2}}\arctan\frac{\sqrt{a-b}\tan\frac{x}{2}}{\sqrt{a+b}} + C \quad (a>|b|)
$$

### 指数 × 三角 积分

$$
\int x\sin nx\,dx = -\frac{x}{n}\cos nx + \frac{1}{n^2}\sin nx + C
$$

$$
\int x\cos nx\,dx = \frac{x}{n}\sin nx + \frac{1}{n^2}\cos nx + C
$$

$$
\int e^x \cos nx\,dx = \frac{e^x}{1+n^2}(\cos nx + n\sin nx) + C
$$

$$
\int e^x \sin nx\,dx = \frac{e^x}{1+n^2}(\sin nx - n\cos nx) + C
$$

### 积分的性质

- $\displaystyle \int [f(x) \pm g(x)] dx = \int f(x) dx \pm \int g(x) dx$
- $\displaystyle \int k f(x) dx = k \int f(x) dx$（$k$ 为常数）

## 定积分

### 定积分定义（黎曼积分）

$$
\int_a^b f(x) dx = \lim_{\lambda(T) \to 0} \sum_{i=1}^n f(\xi_i)\Delta x_i
$$

其中 $\lambda(T) = \max\{\Delta x_i\}$，$\xi_i \in [x_{i-1}, x_i]$。

**几何意义**：面积的代数和。

**约定**：

- 当 $b = a$ 时，$\displaystyle\int_a^b f(x)\,dx = 0$
- 当 $b < a$ 时，$\displaystyle\int_a^b f(x)\,dx = -\int_b^a f(x)\,dx$

**可积的充分条件**：闭区间 $[a,b]$ 上的连续函数，或单调有界函数，均可积。可积函数必有界。

### 定积分的性质

- **非负性**：$f(x) \geq 0 \Rightarrow \displaystyle\int_a^b f(x)\,dx \geq 0$
- **保号性**：$f(x) \geq g(x) \Rightarrow \displaystyle\int_a^b f(x)\,dx \geq \int_a^b g(x)\,dx$
- **常数因子**：$\displaystyle\int_a^b k f(x)\,dx = k\int_a^b f(x)\,dx$
- **区域可加性**：$\displaystyle\int_a^b f\,dx = \int_a^c f\,dx + \int_c^b f\,dx$，其中 $c$ 可不在 $[a,b]$ 内
- **等价积分**：$f$ 可积，$g$ 与 $f$ 仅在有限个点取值不同，则 $g$ 可积，且两者积分相等
- **绝对值不等式**：$\left|\displaystyle\int_a^b f(x)\,dx\right| \leq \int_a^b |f(x)|\,dx$

## 不定积分的还原法（换元法）

### 第一类换元法（凑微分）

将被积分式凑成 $f(\varphi(x)) \varphi'(x) dx = f(u) du$ 的形式。

**常用凑微分**：

- $2x\,dx = d(x^2)$
- $\dfrac{dx}{x} = d(\ln x)$
- $e^x\,dx = d(e^x)$
- $\cos x\,dx = d(\sin x)$
- $\sin x\,dx = -d(\cos x)$
- $\sec^2 x\,dx = d(\tan x)$
- $\dfrac{dx}{1+x^2} = d(\arctan x)$
- $\dfrac{dx}{\sqrt{1-x^2}} = d(\arcsin x)$

### 第二类换元法

令 $x = \varphi(t)$，将难积的 $\int f(x) dx$ 转化为易积的 $\int f(\varphi(t)) \varphi'(t) dt$。

**常用代换**：

- 根号下为一次式：$t = \sqrt[n]{ax+b}$，$x = \dfrac{t^n - b}{a}$
- $\sqrt{a^2 - x^2}$：$x = a\sin t$ 或 $x = a\cos t$
- $\sqrt{a^2 + x^2}$：$x = a\tan t$
- $\sqrt{x^2 - a^2}$：$x = a\sec t$

## 分部积分法

$$
\int u\,dv = uv - \int v\,du
$$

**选择 $u$ 的经验顺序**（"反、对、幂，三、指"）：

1. **反**三角函数（$\arctan x$，$\arcsin x$）
2. **对**数函数（$\ln x$，$\log_a x$）
3. **幂**函数（$x^n$）
4. **三**角函数（$\sin x$，$\cos x$）
5. **指**数函数（$e^x$，$a^x$）

**常见类型**：

- $\int x^n e^x dx$：$u = x^n$，$dv = e^x dx$
- $\int x^n \ln x dx$：$u = \ln x$，$dv = x^n dx$
- $\int e^x \sin x dx$：两次分部积分后出现原形式，联立求解

## 有理式的不定积分

### 有理函数

两个多项式之比 $R(x) = \dfrac{P(x)}{Q(x)}$，真分式（$\deg P < \deg Q$）才能部分分式分解。

### 部分分式分解

| 因式形式                      | 对应项                                               |
| ----------------------------- | ---------------------------------------------------- |
| $(x-a)$                     | $\dfrac{A}{x-a}$                                   |
| $(x-a)^n$                   | $\dfrac{A_1}{x-a} + \cdots + \dfrac{A_n}{(x-a)^n}$ |
| $x^2+px+q$（判别式 $<0$） | $\dfrac{Ax+B}{x^2+px+q}$                           |
| $(x^2+px+q)^n$              | $\dfrac{A_1 x+B_1}{x^2+px+q} + \cdots$             |

### 有理化方法

**三角有理式** $R(\sin x, \cos x)$：

- 万能代换（慎用）：$t = \tan \dfrac{x}{2}$，则 $\sin x = \dfrac{2t}{1+t^2}$，$\cos x = \dfrac{1-t^2}{1+t^2}$，$dx = \dfrac{2\,dt}{1+t^2}$

**无理函数**：

- $\sqrt[n]{\dfrac{ax+b}{cx+d}}$：令 $t = \sqrt[n]{\dfrac{ax+b}{cx+d}}$
- $\sqrt{ax^2+bx+c}$：配方法化为标准二次型，再用三角代换

## 定积分

### 定积分定义（黎曼积分）

$$
\int_a^b f(x) dx = \lim_{\lambda \to 0} \sum_{i=1}^{n} f(\xi_i) \Delta x_i
$$

其中 $\lambda = \max \Delta x_i$，$\xi_i \in [x_{i-1}, x_i]$

**几何意义**：$f \geq 0$ 时为曲边梯形面积

**可积的充分条件**：$f$ 在 $[a,b]$ 连续，或 $f$ 有界且只有有限个间断点。

### 定积分的性质

- **线性性**：$\displaystyle \int_a^b [kf + mg] = k\int_a^b f + m\int_a^b g$
- **区域可加性**：$\displaystyle \int_a^b f = \int_a^c f + \int_c^b f$
- **比较定理**：$f \leq g \Rightarrow \int_a^b f \leq \int_a^b g$
- **估值定理**：$m \leq f \leq M \Rightarrow m(b-a) \leq \int_a^b f \leq M(b-a)$
- **积分中值定理**：若 $f$ 连续，则 $\exists \xi \in [a,b]$ 使 $\int_a^b f = f(\xi)(b-a)$

## 定积分的计算

### 换元法

$$
\int_a^b f(x) dx = \int_\alpha^\beta f(\varphi(t)) \varphi'(t) dt
$$

其中 $\varphi(\alpha) = a$，$\varphi(\beta) = b$（或反向对应）

**注意**：换元必换限，上限对应上限，下限对应下限。

### 分部积分

$$
\int_a^b u\,dv = [uv]_a^b - \int_a^b v\,du
$$

### 华莱士公式（点火公式）

$$
\int_0^{\pi/2} \sin^n x\,dx = \int_0^{\pi/2} \cos^n x\,dx = \begin{cases} \dfrac{(n-1)!!}{n!!} \cdot \dfrac{\pi}{2} & n \text{ 为偶数} \\ \dfrac{(n-1)!!}{n!!} & n \text{ 为奇数} \end{cases}
$$

其中 $(n-1)!! = (n-1)(n-3)\cdots 3 \cdot 1$，$n!! = n(n-2)\cdots 4 \cdot 2$

**双阶乘展开形式**：

$$
\int_0^{\pi/2} \sin^{2k} x\,dx = \frac{\pi}{2}\cdot\frac{(2k-1)!!}{(2k)!!} = \frac{\pi}{2}\cdot\frac{(2k)!}{2^{2k}(k!)^2}
$$

$$
\int_0^{\pi/2} \sin^{2k+1} x\,dx = \frac{(2k)!!}{(2k+1)!!}
$$

### 重要积分公式（Wallis 型 / Gamma 型）

$$
\int_{-\infty}^{+\infty} e^{-x^2}\,dx = \sqrt{\pi} \qquad \text{（高斯积分）}
$$

$$
\int_{0}^{+\infty} \frac{\sin x}{x}\,dx = \frac{\pi}{2} \qquad \text{（Dirichlet 积分）}
$$

$$
\int_{0}^{+\infty} \frac{\sin ax}{x}\,dx =
\begin{cases}
\dfrac{\pi}{2}, & a > 0 \\[6pt]
0, & a = 0 \\[6pt]
-\dfrac{\pi}{2}, & a < 0
\end{cases}
$$

## 定积分的应用

### 平面图形面积

**直角坐标**：

$$
S = \int_a^b |f(x)| dx
$$

由 $y = f(x), y = g(x), x=a, x=b$ 围成：$S = \int_a^b |f(x) - g(x)| dx$

**极坐标**：$r = r(\theta)$，$\theta \in [\alpha,\beta]$

$$
S = \frac{1}{2} \int_\alpha^\beta r^2(\theta) d\theta
$$

### 旋转体体积

**绕 $x$ 轴**（$y = f(x)$，$x \in [a,b]$）：

$$
V_x = \pi \int_a^b f^2(x) dx
$$

**绕 $y$ 轴**（薄壳法）：

$$
V_y = 2\pi \int_a^b x |f(x)| dx
$$

**截面法**：截面面积 $S(x)$，$V = \int_a^b S(x) dx$

### 曲线弧长

**直角坐标** $y = f(x)$，$x \in [a,b]$：

$$
s = \int_a^b \sqrt{1 + [f'(x)]^2} dx
$$

**参数方程** $x = x(t),\ y = y(t)$，$t \in [\alpha,\beta]$：

$$
s = \int_\alpha^\beta \sqrt{[x'(t)]^2 + [y'(t)]^2} dt
$$

**极坐标** $r = r(\theta)$，$\theta \in [\alpha,\beta]$：

$$
s = \int_\alpha^\beta \sqrt{r^2 + [r'(\theta)]^2} d\theta
$$

### 旋转曲面面积

**绕 $x$ 轴**（$y = f(x) \geq 0$）：

$$
S = 2\pi \int_a^b f(x) \sqrt{1 + [f'(x)]^2} dx
$$

**参数方程** $x = x(t),\ y = y(t)$（$t \in [\alpha,\beta]$）：

$$
S = 2\pi \int_\alpha^\beta y(t)\sqrt{[x'(t)]^2 + [y'(t)]^2}\,dt
$$

**极坐标** $r = r(\theta)$（绕极轴）：

$$
S = 2\pi \int_\alpha^\beta r(\theta)\sin\theta\sqrt{r^2(\theta) + [r'(\theta)]^2}\,d\theta
$$

### 极坐标面积元素（扇形微元）

$$
dS = \frac{1}{2}r^2\,d\theta \quad (\text{扇形}), \qquad dS = \frac{1}{2}r\,d\theta \cdot r \quad (\text{圆环条})
$$

## 定积分的近似计算

**矩形公式**：

$$
S \approx \frac{b-a}{n} \sum_{i=1}^n f(x_i)
$$

**梯形公式**：

$$
S \approx \frac{b-a}{n} \left(\frac{y_0+y_n}{2} + \sum_{i=1}^{n-1} y_i\right)
$$

**辛普森公式**（需 $n$ 为偶数）：

$$
S \approx \frac{b-a}{3n}\left[y_0+y_n + 4(y_1+y_3+\cdots+y_{n-1}) + 2(y_2+y_4+\cdots+y_{n-2})\right]
$$

## 变上限积分与微积分基本定理

### 积分中值定理

若 $f(x)$ 在 $[a,b]$ 连续，则 $\exists c \in [a,b]$ 使

$$
\int_a^b f(x)\,dx = f(c)\cdot(b-a)
$$

### 变上限积分

若 $f$ 在 $[a,b]$ 连续，则 $F_0(x) = \int_a^x f(t)\,dt$ 在 $[a,b]$ 连续，在 $(a,b)$ 可导，且

$$
F_0'(x) = f(x), \quad \forall x \in (a,b)
$$

### 牛顿-莱布尼茨公式

设 $f$ 在 $[a,b]$ 连续，$F$ 是 $f$ 在 $(a,b)$ 的原函数（$F'(x) = f(x)$）且 $F$ 在 $[a,b]$ 连续，则

$$
\int_a^b f(x)\,dx = F(b) - F(a) = [F(x)]_a^b
$$

这是定积分计算的核心定理，将积分转化为求原函数。

## 偶函数、奇函数、周期函数的积分性质

**偶函数**：

$$
\int_{-a}^a f(x)\,dx = \begin{cases} 2\int_0^a f(x)\,dx, & f \text{ 为偶函数} \\ 0, & f \text{ 为奇函数} \end{cases}
$$

**周期函数**：

$$
\int_0^T f(x)\,dx = \int_a^{a+T} f(x)\,dx \quad \text{（任意 } T \text{ 长度积分值相等）}
$$

## 奇/偶/周期函数的定积分

**奇函数**：$a_n = 0$，只有正弦项（正弦级数）
**偶函数**：$b_n = 0$，只有余弦项（余弦级数）

## 初等函数的不可积情形

以下不定积分不能用初等函数表示：

$$
\int \frac{\sin x}{x}\,dx,\quad \int e^{-x^2}\,dx,\quad \int \sin x^2\,dx,\quad \int \frac{dx}{\sqrt{1 - k^2 \sin^2 x}}
$$

$$
\int \cos x^2\,dx,\quad \int \frac{\cos x}{x}\,dx,\quad \int \frac{1}{\ln x}\,dx,\quad \int \sqrt{1 - k^2 \sin^2 x}\,dx
$$

## 三角有理函数万能替换

设 $t = \tan\dfrac{x}{2}$，则

$$
\sin x = \frac{2t}{1+t^2}, \qquad \cos x = \frac{1-t^2}{1+t^2}, \qquad dx = \frac{2}{1+t^2}\,dt
$$

## 有理真分式的部分分式分解

设 $Q(x) = (x-a_1)^{n_1}\cdots(x-a_k)^{n_k}(x^2+p_1 x+q_1)^{m_1}\cdots$，其中 $p_i = -2\alpha_i$，$q_i = \alpha_i^2 + \beta_i^2$，$p_i^2 < 4q_i$，则

$$
\frac{P(x)}{Q(x)} = \sum_{j=1}^k \sum_{n=1}^{n_j} \frac{A_{nj}}{(x-a_j)^n} + \sum_{i=1}^l \sum_{m=1}^{m_i} \frac{B_{mi}x + C_{mi}}{(x^2 + p_i x + q_i)^m}
$$
