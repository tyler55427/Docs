# 三、热学

# 第9章 温度与气体动理论

## 9.1 平衡态

**热力学系统**（系统）：作为研究对象的一个物体或一组物体。系统以外的物体称为**外界**。

**平衡态**：一个系统的各种性质不随时间改变的状态。在微观上，平衡态是大量分子无规则运动的**动态平衡**。

**宏观描述**：用体积、压强等少数可直接测量的物理量（宏观状态参量）来描述系统。

**微观描述**：通过对分子运动状态的说明来描述系统的宏观状态，采用统计方法。

## 9.2 温度的概念

**定性定义**：共处于平衡态的物体，它们的温度相等。

**热力学第零定律**：如果物体 $A$ 和物体 $B$ 分别与物体 $C$ 的同一状态处于平衡态，那么当把 $A$ 和 $B$ 放到一起时，二者也必定处于平衡态。

## 9.3 理想气体温标

**理想气体**：在各种压强下都严格遵守玻意耳定律的气体，是实际气体在压强趋于零时的极限。

**玻意耳定律**：
$$pV = \text{常量} \quad (\text{温度不变}) \tag{9.1}$$

**理想气体温标**：
$$T = T_3 \frac{pV}{p_3V_3} = 273.16 \frac{pV}{p_3V_3} \tag{9.4}$$

其中 $T_3 = 273.16\text{ K}$ 为水的三相点温度。

**摄氏温度与热力学温度的关系**：
$$t = T - 273.15 \tag{9.6}$$

**热力学第三定律**：热力学零度（绝对零度）是不能达到的。

## 9.4 理想气体状态方程

$$pV = \nu RT \tag{9.10}$$

或
$$pV = \frac{m}{M}RT \tag{9.11}$$

其中 $R = 8.31\text{ J/(mol·K)}$ 为**普适气体常量**，$\nu$ 为摩尔数，$m$ 为质量，$M$ 为摩尔质量。

**玻耳兹曼常量**：
$$k = \frac{R}{N_{\text{A}}} = 1.38 \times 10^{-23} \text{ J/K} \tag{9.12}$$

其中 $N_{\text{A}} = 6.023 \times 10^{23}/\text{mol}$ 为阿伏伽德罗常量。

理想气体状态方程的另一形式：
$$pV = NkT \tag{9.13}$$
$$p = nkT \tag{9.14}$$

其中 $n = N/V$ 为分子数密度。

### 恒温气压公式

$$p = p_0 e^{-\frac{Mgh}{RT}} \tag{9.16}$$

## 9.5 气体分子的无规则运动

### 平均自由程

$$\bar{\lambda} = \frac{\bar{v}}{\bar{z}} \tag{9.17}$$

其中 $\bar{v}$ 为平均速率，$\bar{z}$ 为平均碰撞频率。

### 平均碰撞频率

$$\bar{z} = \sqrt{2}\pi d^2 \bar{v} n \tag{9.20}$$

其中 $d$ 为分子直径，$n$ 为分子数密度。

### 平均自由程公式

$$\bar{\lambda} = \frac{1}{\sqrt{2}\pi d^2 n} \tag{9.21}$$

或
$$\bar{\lambda} = \frac{kT}{\sqrt{2}\pi d^2 p} \tag{9.22}$$

## 9.6 理想气体的压强

### 理想气体分子模型的基本假设

**关于每个分子的力学性质**：
1. 分子本身的线度远小于分子间的平均距离
2. 除碰撞瞬间外，分子间无相互作用
3. 碰撞是完全弹性的
4. 分子运动遵从经典力学规律

**关于分子集体的统计性假设**：
1. 分子速度各不相同，通过碰撞不断变化
2. 平衡态时分子按位置分布均匀：$n = N/V$
3. 平衡态时分子速度按方向分布均匀：$\overline{v_x^2} = \overline{v_y^2} = \overline{v_z^2} = \frac{1}{3}\overline{v^2}$

### 压强公式

$$p = \frac{1}{3}nm\overline{v^2} = \frac{2}{3}n\bar{\epsilon}_t \tag{9.26}$$

其中 $\bar{\epsilon}_t = \frac{1}{2}m\overline{v^2}$ 为分子的平均平动动能。

## 9.7 温度的微观意义

$$\bar{\epsilon}_t = \frac{3}{2}kT \tag{9.28}$$

> 温度是分子平均平动动能的量度，反映了物体内部分子无规则运动的激烈程度。

### 方均根速率

$$v_{\text{rms}} = \sqrt{\overline{v^2}} = \sqrt{\frac{3kT}{m}} = \sqrt{\frac{3RT}{M}} \tag{9.29}$$

## 9.8 能量均分定理

### 自由度

| 分子种类 | 平动自由度 $t$ | 转动自由度 $r$ | 总自由度 $i$ |
| :--- | :---: | :---: | :---: |
| 单原子分子 | 3 | 0 | 3 |
| 刚性双原子分子 | 3 | 2 | 5 |
| 刚性多原子分子 | 3 | 3 | 6 |

### 能量均分定理

在温度为 $T$ 的平衡态下，气体分子每个自由度的平均能量都相等，且等于 $\frac{1}{2}kT$。

每个平动自由度的平均动能：
$$\frac{1}{2}m\overline{v_x^2} = \frac{1}{2}m\overline{v_y^2} = \frac{1}{2}m\overline{v_z^2} = \frac{1}{2}kT \tag{9.30}$$

分子的平均总动能：
$$\bar{\varepsilon}_k = \frac{i}{2}kT \tag{9.31}$$

### 理想气体的内能

$$E = N\bar{\varepsilon}_k = \frac{i}{2}\nu RT \tag{9.32}$$

- 单原子分子气体：$E = \frac{3}{2}\nu RT$
- 刚性双原子分子气体：$E = \frac{5}{2}\nu RT$
- 刚性多原子分子气体：$E = 3\nu RT$

## 9.9 麦克斯韦速率分布律

### 速率分布函数

$$f(v) = \frac{\mathrm{d}N_v}{N\mathrm{d}v} \tag{9.34}$$

**归一化条件**：
$$\int_{0}^{\infty} f(v)\mathrm{d}v = 1 \tag{9.35}$$

### 麦克斯韦速率分布函数

$$f(v) = 4\pi \left( \frac{m}{2\pi kT} \right)^{3/2} v^2 \mathrm{e}^{-mv^2/2kT} \tag{9.37}$$

### 最概然速率

$$v_p = \sqrt{\frac{2kT}{m}} = \sqrt{\frac{2RT}{M}} \approx 1.41 \sqrt{\frac{RT}{M}} \tag{9.38}$$

### 平均速率

$$\bar{v} = \sqrt{\frac{8kT}{\pi m}} = \sqrt{\frac{8RT}{\pi M}} \approx 1.60 \sqrt{\frac{RT}{M}} \tag{9.41}$$

### 方均根速率

$$v_{\text{rms}} = \sqrt{\frac{3kT}{m}} = \sqrt{\frac{3RT}{M}} \approx 1.73 \sqrt{\frac{RT}{M}} \tag{9.42}$$

> 三种速率的关系：$v_{\text{rms}} > \bar{v} > v_p$，都与 $\sqrt{T}$ 成正比，与 $\sqrt{m}$ 成反比。

### 麦克斯韦速度分布律

$$F(v) = \left(\frac{m}{2\pi kT}\right)^{3/2} \mathrm{e}^{-mv^2/2kT} \tag{9.48}$$

## 9.10 麦克斯韦速率分布律的实验验证

密勒-库什实验（1955年）精确验证了麦克斯韦速率分布律。

## 9.11 玻耳兹曼分布律

**玻耳兹曼分布律**：在温度为 $T$ 的平衡态下，气体分子在速度区间 $\mathrm{d}v_x \mathrm{d}v_y \mathrm{d}v_z$ 和位置区间 $\mathrm{d}x \mathrm{d}y \mathrm{d}z$ 内的分子数为：
$$\mathrm{d}N = n_0 \left(\frac{m}{2\pi kT}\right)^{3/2} \mathrm{e}^{-\varepsilon/kT} \mathrm{d}v_x \mathrm{d}v_y \mathrm{d}v_z \mathrm{d}x \mathrm{d}y \mathrm{d}z$$

其中 $\varepsilon$ 为分子的能量，$n_0$ 为势能零处的分子数密度。

### 重力场中的分子分布

$$n = n_0 e^{-\frac{mgh}{kT}} \tag{9.53}$$

## 9.12 实际气体等温线

实际气体等温线与理想气体等温线有明显偏差。在较低温度下，等温压缩气体时会出现**液化现象**。

- **临界温度**：能通过等温压缩使气体液化的最高温度
- **饱和蒸气压**：在一定温度下饱和蒸气的压强

## 9.13 范德瓦耳斯方程

考虑到分子本身的体积和分子间的相互作用力，范德瓦耳斯方程为：

$$\left(p + \frac{\nu^2 a}{V^2}\right)(V - \nu b) = \nu RT \tag{9.59}$$

其中：
- $a$ 为考虑分子间引力的修正量
- $b$ 为考虑分子本身体积的修正量

## *9.14 非平衡态 输运过程

### 内摩擦（黏性）

$$\mathrm{d}f = -\eta \frac{\mathrm{d}u}{\mathrm{d}z} \mathrm{d}S \tag{9.62}$$

其中 $\eta$ 为内摩擦系数（黏度）。

### 热传导

$$\mathrm{d}Q = -\kappa \frac{\mathrm{d}T}{\mathrm{d}z} \mathrm{d}S \mathrm{d}t \tag{9.63}$$

其中 $\kappa$ 为热导率。

### 扩散

$$\mathrm{d}M = -D \frac{\mathrm{d}\rho}{\mathrm{d}z} \mathrm{d}S \mathrm{d}t \tag{9.64}$$

其中 $D$ 为扩散系数。

# 第10章 热力学第一定律

## 10.1 功 热量 热力学第一定律

### 内能

**内能**是系统内所有分子的无规则运动动能和分子间势能的总和。理想气体的内能为：

$$E = \frac{i}{2}\nu RT$$

内能是**状态量**，只由系统的状态决定，与过程无关。

### 功与热量

外界对系统做功而交换能量有两种情形：
- **宏观功**：与系统边界的宏观位移相联系的功，表现为宏观机械能和内能的传递和转化
- **热量**：由于系统和外界温度不同，通过分子做微观功而进行的内能传递过程

### 热力学第一定律

$$Q = \Delta E + A \tag{10.2}$$

其中 $Q$ 为系统从外界吸收的热量，$A$ 为系统对外界做的功。

**微观意义**：能量守恒定律的"最初形式"，只涉及分子运动的能量。

## 10.2 准静态过程

**准静态过程**：过程中任意时刻，系统都无限地接近平衡态，任何时刻系统的状态都可以当作平衡态处理。

- 准静态过程可以用状态图（如 $p\text{-}V$ 图）上的曲线表示
- 非平衡态不能用状态参量描述，非准静态过程不能用状态图上的线表示

### 体积功

准静态过程中系统对外做的功：

$$\mathrm{d}A = p\,\mathrm{d}V \tag{10.3}$$

$$A = \int_{V_1}^{V_2} p\,\mathrm{d}V \tag{10.4}$$

**功是过程量**，其数值等于 $p\text{-}V$ 图上过程曲线下的面积。

## 10.3 热容

### 摩尔定压热容

$$C_{p,m} = \frac{1}{\nu}\left(\frac{\mathrm{d}Q}{\mathrm{d}T}\right)_p = \frac{i+2}{2}R \tag{10.9}$$

### 摩尔定体热容

$$C_{V,m} = \frac{1}{\nu}\left(\frac{\mathrm{d}Q}{\mathrm{d}T}\right)_V = \frac{i}{2}R \tag{10.12}$$

### 内能变化

$$\Delta E = E_2 - E_1 = \nu\int_{T_1}^{T_2} C_{V,m}\,\mathrm{d}T \tag{10.11}$$

### 迈耶公式

$$C_{p,m} - C_{V,m} = R \tag{10.13}$$

### 比热比

$$\gamma = \frac{C_{p,m}}{C_{V,m}} = \frac{i+2}{i} \tag{10.14}$$

| 气体种类 | $C_{V,m}$ | $C_{p,m}$ | $\gamma$ |
| :--- | :---: | :---: | :---: |
| 单原子分子 | $\frac{3}{2}R$ | $\frac{5}{2}R$ | $1.67$ |
| 刚性双原子分子 | $\frac{5}{2}R$ | $\frac{7}{2}R$ | $1.40$ |
| 刚性多原子分子 | $3R$ | $4R$ | $1.33$ |

## 10.4 绝热过程

系统在和外界无热量交换条件下进行的过程。$Q = 0$。

### 能量关系

$$\Delta E = -A$$

对于微小绝热过程：
$$\frac{i}{2}\nu R\,\mathrm{d}T + p\,\mathrm{d}V = 0 \tag{10.16}$$

### 绝热过程方程（泊松公式）

$$pV^\gamma = C_1 \tag{10.18}$$

$$TV^{\gamma-1} = C_2 \tag{10.19}$$

$$p^{\gamma-1}T^{-\gamma} = C_3 \tag{10.20}$$

### 绝热过程功

$$A = \frac{p_1V_1}{\gamma-1}\left[1 - \left(\frac{V_1}{V_2}\right)^{\gamma-1}\right] \tag{10.21}$$

或
$$A = -\nu C_{V,m}(T_2 - T_1) \tag{10.23}$$

## 10.5 循环过程

**循环过程**：系统经历一系列变化后又回到初始状态的整个过程。

### 正循环（热循环）

$$A = Q_1 - Q_2 \tag{10.24}$$

效率：
$$\eta = \frac{A}{Q_1} = 1 - \frac{Q_2}{Q_1} \tag{10.26}$$

### 空气标准奥托循环

四冲程内燃机的理想循环，效率：
$$\eta = 1 - \frac{1}{r^{\gamma-1}}$$

其中 $r = V_1/V_2$ 为压缩比。

## 10.6 卡诺循环

**卡诺循环**：系统只和两个恒温热库进行热交换的无损耗准静态循环过程。

### 卡诺循环的效率

$$\eta_C = 1 - \frac{T_2}{T_1} \tag{10.27}$$

### 卡诺循环的热量关系

$$\frac{Q_1}{Q_2} = \frac{T_1}{T_2} \tag{10.28}$$

### 有限时间循环

最大输出功率时的效率：
$$\eta_C' = 1 - \sqrt{\frac{T_2}{T_1}} \tag{10.29}$$

## 10.7 致冷循环

工质做逆循环，从低温热库吸热 $Q_2$，向高温热库放热 $Q_1$，外界对工质做功 $A$。

### 致冷系数

$$w = \frac{Q_2}{A} = \frac{Q_2}{Q_1 - Q_2} \tag{10.31}$$

### 卡诺致冷循环的致冷系数

$$w_C = \frac{T_2}{T_1 - T_2} \tag{10.32}$$

# 第11章 热力学第二定律

## 11.1 自然过程的方向

一切自然过程都是不可逆的，是按一定方向进行的。三个典型实例：

### 1. 功热转换

飞轮由于轴处摩擦而逐渐停下来，机械能转变为内能。相反的过程（热自动地全部转变为功）不可能发生。

> "热全部转变为功的过程"如理想气体等温膨胀可以实现，但会引起其他变化（体积增大）。

### 2. 热传导

热量总是自动地由高温物体传向低温物体。相反的过程（热量自动由低温物体传向高温物体）不可能发生。

> 致冷机可以实现热从低温传向高温，但需要外界做功。

### 3. 气体的绝热自由膨胀

气体自动地迅速膨胀充满整个容器。相反的过程（气体自动收缩回原来体积）不可能发生。

## 11.2 不可逆性的相互依存

各种自然宏观过程的不可逆性是相互联系、相互依存的。一种过程的不可逆性保证了另一种过程的不可逆性。

## 11.3 热力学第二定律及其微观意义

### 热力学第二定律的宏观表述

**克劳修斯表述**：热量不能自动地从低温物体传向高温物体。

**开尔文表述**：其唯一效果是热全部转变为功的过程是不可能的。

两种表述是**完全等效**的。

### 第二类永动机

有能量输入的单热源热机（把吸收的热量全部用来做功而不产生其他效果），违反热力学第二定律，不可能制成。

### 微观意义

一切自然过程总是沿着分子热运动的**无序性增大**的方向进行。这是不可逆性的微观本质，是热力学第二定律的微观意义。

热力学第二定律是**统计规律**，只适用于大量分子的集体。

## 11.4 热力学概率与自然过程的方向

### 热力学概率

任一宏观状态所对应的微观状态数目称为该宏观状态的**热力学概率**，用 $\Omega$ 表示。

### 基本统计假设

对于孤立系，各个微观状态出现的可能性（概率）是相同的。

### 自然过程的方向

- 对孤立系，平衡态对应于 $\Omega$ 为最大值的宏观状态
- 非平衡态将向 $\Omega$ 增大的方向过渡
- 自然过程总是沿着 $\Omega$ 增大的方向进行

### 微观状态数的二项式分布

$$\Omega(n) = \frac{N!}{n!(N-n)!}$$

对于均匀分布（左右相等）：
$$\Omega = \frac{N!}{\left[\left(\frac{N}{2}\right)!\right]^2}$$

### 斯特林公式

$$\ln M! \approx M\ln M - M$$

## 11.5 玻耳兹曼熵公式与熵增加原理

### 玻耳兹曼熵公式

$$S = k\ln\Omega \tag{11.1}$$

其中 $k$ 是玻耳兹曼常量。熵是系统状态的函数。

### 熵的可加性

$$S = S_1 + S_2 \tag{11.2}$$

### 熵增加原理

在孤立系统中所进行的自然过程总是沿着熵增大的方向进行，它是不可逆的。平衡态相应于熵最大的状态。

$$\Delta S > 0 \quad (\text{孤立系，自然过程}) \tag{11.3}$$

### 理想气体自由膨胀的熵变

$$\Delta S = \nu R\ln\frac{V_2}{V_1} \tag{11.5}$$

由于 $V_2 > V_1$，所以 $\Delta S > 0$，符合熵增加原理。

### 涨落

平衡态时系统的热力学概率或熵总是不停地进行着对于极大值的偏离。对于分子数少的系统，涨落容易观察到；对于大量分子的系统，涨落相对很小。

## 11.6 可逆过程

**可逆过程**：一个过程进行时，如果使外界条件改变一无穷小的量，这个过程就可以反向进行（其结果是系统和外界能同时回到初态）。

### 可逆过程的条件

- 无摩擦的准静态过程
- 有传热时，系统和外界的温差为无限小（"等温热传导"）

### 可逆过程的熵变

$$\Delta S = 0 \quad (\text{孤立系，可逆过程}) \tag{11.6}$$

### 卡诺定理

在相同的高温热库和相同的低温热库之间工作的一切可逆热机，其效率都相等，与工作物质种类无关，并且可逆热机的效率最高。

## 11.7 克劳修斯熵公式

### 克劳修斯熵公式

对于任意系统的可逆过程：

$$\mathrm{d}S = \frac{\mathrm{d}Q}{T} \tag{11.12}$$

$$S_2 - S_1 = \int_1^2 \frac{\mathrm{d}Q}{T} \tag{11.13}$$

### 克劳修斯不等式

对于不可逆过程：
$$\mathrm{d}S > \frac{\mathrm{d}Q}{T}$$

$$S_2 - S_1 > \int_1^2 \frac{\mathrm{d}Q}{T} \tag{11.13'}$$

### 热力学基本关系式

$$T\mathrm{d}S = \mathrm{d}E + \mathrm{d}A \tag{11.14}$$

### 可逆绝热过程

$\mathrm{d}Q = 0$，因此 $\Delta S = 0$，即可逆绝热过程是**等熵过程**。

## 11.8 用克劳修斯熵公式计算熵变

### 计算方法

1. 选择连接始、末两态的任一**可逆过程**
2. 利用公式 $\Delta S = \int_1^2 \frac{\mathrm{d}Q}{T}$ 积分求解
3. 熵是态函数，与过程无关

### 典型例子

**理想气体等温膨胀**：$\Delta S = \nu R\ln\frac{V_2}{V_1}$

**理想气体变温过程**：$\Delta S = C_{V,m}\ln\frac{T_2}{T_1} + R\ln\frac{V_2}{V_1}$

**有限温差热传导**：$\mathrm{d}S = |\mathrm{d}Q|\left(\frac{1}{T_B} - \frac{1}{T_A}\right) > 0$（$T_A > T_B$）

## *11.9 温熵图

系统在可逆过程中吸收的热量：

$$Q = \int T\,\mathrm{d}S \tag{11.19}$$

在 $T\text{-}S$ 图中，过程曲线下的面积表示吸收的热量。

卡诺循环的 $T\text{-}S$ 曲线为矩形，效率：
$$\eta_C = 1 - \frac{T_2}{T_1}$$

## *11.10 熵和能量退降

不可逆过程在能量利用上的后果是使一定的能量 $E_d$ 从能做功的形式变为不能做功的形式，即"退降的"能量：

$$E_d = T_0\,\mathrm{d}S \tag{11.20}$$

退降的能量与不可逆过程所引起的熵的增加成正比。熵的增加是能量退降的量度。
