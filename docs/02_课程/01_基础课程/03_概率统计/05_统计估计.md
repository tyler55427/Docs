# 五、统计估计

## 1、基本概念

- **总体**：研究对象的某项数量指标 $X$ 的全体（视为随机变量），其分布 $F(x)$ 称**总体分布**
- **个体**：总体中每个元素的指标
- **样本**：从总体中独立随机抽取 $n$ 个个体 $X_1, \cdots, X_n$。简单随机样本满足：(1) 独立；(2) 同分布（与总体同分布）
- **样本容量** $n$：样本中个体数
- **样本值（观测值）** $x_1, \cdots, x_n$：样本的具体取值

**统计量** $g(X_1, \cdots, X_n)$：不含未知参数的样本函数，仍是随机变量。

**常用统计量**：

- 样本均值 $\bar{X} = \dfrac{1}{n}\sum_{i=1}^n X_i$
- 样本方差 $S^2 = \dfrac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X})^2$（无偏版本，自由度 $n-1$）
- 样本二阶中心矩 $S_n^2 = \dfrac{1}{n}\sum(X_i - \bar{X})^2$
- 样本标准差 $S = \sqrt{S^2}$
- 样本 $k$ 阶原点矩 $A_k = \dfrac{1}{n}\sum X_i^k$，$k$ 阶中心矩 $B_k = \dfrac{1}{n}\sum(X_i - \bar{X})^k$

## 2、点估计

设总体分布 $F(x;\theta)$ 含未知参数 $\theta$（可向量），用样本构造统计量 $\hat{\theta} = \hat{\theta}(X_1,\cdots,X_n)$ 作为 $\theta$ 的估计，称为**点估计**。

**估计量 vs 估计值**

- **估计量** $\hat{\theta}(X_1,\cdots,X_n)$：是样本的函数（随机变量），用大写字母；评价其好坏要用期望、方差、依概率收敛等（如无偏性、有效性、相合性）
- **估计值** $\hat{\theta}(x_1,\cdots,x_n)$：样本观测值代入后的具体数值（一个数）；是估计量在一次抽样中的实现

> 简单记：估计量是"规则"，估计值是"结果"。

### 2.2 极大似然估计

设总体密度 $f(x;\theta)$（或分布律），样本似然函数

$$
L(\theta) = \prod_{i=1}^n f(x_i; \theta)
$$

取 $\hat{\theta}$ 使 $L(\hat{\theta}) = \max_\theta L(\theta)$，即**使样本出现概率最大**的参数值。

**步骤**：

1. 写似然函数 $L(\theta)$
2. 取对数 $\ln L(\theta)$（化积为和，不改变极值点）
3. 对各 $\theta_j$ 求偏导，令 $\dfrac{\partial \ln L}{\partial \theta_j} = 0$（似然方程）
4. 解出 $\hat{\theta}_{\text{MLE}}$

**性质**：

- 在较一般条件下 MLE 具有**相合性**（依概率收敛到真值）
- 具有不变性：若 $\hat{\theta}$ 是 $\theta$ 的 MLE，则 $g(\hat{\theta})$ 是 $g(\theta)$ 的 MLE
- 常渐近正态、渐近有效

### 2.3 矩估计法

用样本矩估计总体矩：令 $A_k = E(X^k)$ 用样本 $k$ 阶矩 $A_k = \dfrac{1}{n}\sum X_i^k$ 替换，解出参数。

**步骤**（设总体 $k$ 个未知参数 $\theta_1,\cdots,\theta_k$）：

1. 求总体前 $k$ 阶矩 $E(X^j) = g_j(\theta_1,\cdots,\theta_k)$
2. 令 $g_j(\theta) = A_j = \dfrac{1}{n}\sum X_i^j$（$j = 1,\cdots,k$）
3. 解方程组得 $\hat{\theta}_1,\cdots,\hat{\theta}_k$

**特点**：直观、无需知道总体分布形式；但效率较低（仅利用低阶矩信息）。

## 3、点估计的优良性

### 3.1 均方误差（MSE）

衡量估计量 $\hat{\theta}$ 的"误差大小"，用偏差平方的期望定义：

$$
\text{MSE}_\theta(\hat{\theta}) = E_\theta(\hat{\theta} - \theta)^2
$$

**比较**：若对所有 $\theta$ 都有 $\text{MSE}_\theta(\hat{\theta}_1) \le \text{MSE}_\theta(\hat{\theta}_2)$，且至少存在一个 $\theta_0$ 使严格成立，则称 $\hat{\theta}_1$ 比 $\hat{\theta}_2$ **更有效**。

> MSE 是**偏差 + 方差**的综合度量：$\text{MSE} = \text{Bias}^2 + D(\hat{\theta})$。

### 3.2 无偏性

$\hat{\theta}$ 是 $\theta$ 的**无偏估计**：$E(\hat{\theta}) = \theta$。

- $\bar{X}$ 是 $\mu$ 的无偏估计：$E(\bar{X}) = \mu$
- $S^2 = \dfrac{1}{n-1}\sum(X_i - \bar{X})^2$ 是 $\sigma^2$ 的无偏估计（故分母为 $n-1$）；$S_n^2 = \dfrac{1}{n}\sum(X_i-\bar{X})^2$ 是**有偏**的，$E(S_n^2) = \dfrac{n-1}{n}\sigma^2$

**最小方差无偏估计（MVUE）**：若 $\hat{\theta}$ 是无偏估计，且对 $\theta$ 的任意无偏估计 $\tilde{\theta}$ 都有 $D_\theta(\tilde{\theta}) \le D_\theta(\hat{\theta})$，则 $\hat{\theta}$ 称为 $\theta$ 的**一致最小方差无偏估计**（即在所有无偏估计中方差最小）。

### 3.3 相合性（一致性）

$\hat{\theta}_n \xrightarrow{P} \theta$（$n \to \infty$），称 $\hat{\theta}_n$ 为 $\theta$ 的**相合估计**（又称一致估计）。

- 矩估计一般相合
- MLE 在正则条件下相合
- $\bar{X} \xrightarrow{P} \mu$（由大数定律）
- $m_2, S^2$ 都是 $DX$ 的相合估计

**三个指标的联系**：三个标准对应三个通常的要求——**有较小的误差**（MSE）、**没有系统的偏差**（无偏性）、**样本量增大时估计量逼近真值**（相合性）。无偏估计未必 MSE 最小，MSE 小未必无偏；相合性是大样本意义下的"极限正确"。

## 4、期望的置信区间

### 4.0 预备：抽样分布定理

区间估计的**枢轴量**依赖如下抽样分布定理，先统一列出。

**$\chi^2$ 分布定义（5.4.1）**：称 $X$ 服从自由度为 $n$ 的 $\chi^2$ 分布，记 $X \sim \chi^2_n$，若其密度为

$$
p(x) = \frac{1}{2^{n/2}\Gamma(n/2)} x^{n/2 - 1} e^{-x/2} I_{(0,+\infty)}(x)
$$

**三个基本性质**：

- $\chi^2_m$ 与 $\chi^2_n$ 独立 ⇒ 和 $\sim \chi^2_{m+n}$（可加性，5.4.1）
- 标准正态的平方和 $\sim \chi^2_n$：若 $X_i \overset{iid}{\sim} N(0,1)$，则 $\sum X_i^2 \sim \chi^2_n$（5.4.2）
- 若 $Z \sim N(0,1)$ 与 $W \sim \chi^2_n$ 独立，则 $T = Z/\sqrt{W/n} \sim t_n$（5.4.3，$t$ 分布的构造）

**引理**：设 $X_1,\cdots,X_n \overset{iid}{\sim} N(0,1)$，则

1. $\bar{X} = \dfrac{1}{n}\sum X_i \sim N\!\left(0,\ \dfrac{1}{n}\right)$
2. $\sum (X_i-\bar{X})^2 \sim \chi^2_{n-1}$
3. $\bar{X}$ 与 $\sum (X_i-\bar{X})^2$ **相互独立**（关键！）

**推论**（一般正态 $N(\mu,\sigma^2)$）：把 $X_i = \mu + \sigma Y_i$（$Y_i \sim N(0,1)$）代入引理 5.4.1，标准化得

1. $\bar{X} \sim N\!\left(\mu,\ \dfrac{\sigma^2}{n}\right)$
2. $\dfrac{1}{\sigma^2}\sum(X_i-\bar{X})^2 \sim \chi^2_{n-1}$
3. $\bar{X}$ 与 $\sum(X_i-\bar{X})^2$ 相互独立

**定理**（正态总体三大抽样分布）：设总体 $X \sim N(\mu,\sigma^2)$，$X_1,\cdots,X_n$ 为样本，则

1. $Z = \dfrac{\bar{X}-\mu}{\sqrt{\sigma^2/n}} \sim N(0,1)$
2. $T = \dfrac{\bar{X}-\mu}{\sqrt{S^2/n}} = \dfrac{\bar{X}-\mu}{\sqrt{\dfrac{1}{n(n-1)}\sum(X_i-\bar{X})^2}} \sim t_{n-1}$
3. $\eta = \dfrac{(n-1)S^2}{\sigma^2} = \dfrac{1}{\sigma^2}\sum(X_i-\bar{X})^2 \sim \chi^2_{n-1}$

> 这三个分布（$Z, T, \chi^2$）就是构造**枢轴量**的工具，所有正态总体的区间估计都基于它们。

### 4.1 区间估计的思想

构造统计量 $[\underline{\theta}, \overline{\theta}]$（依赖样本）使 $P(\underline{\theta} \le \theta \le \overline{\theta}) = 1 - \alpha$，称 $1-\alpha$ 为**置信度**，$[\underline{\theta}, \overline{\theta}]$ 为**置信区间**，$\underline{\theta}, \overline{\theta}$ 为置信下、上限。

**枢轴量法**：构造仅含待估参数（不含其他未知量）且分布已知的函数（枢轴量），由分位数反解出区间。

### 4.2 单正态总体均值 $\mu$ 的区间估计（$X \sim N(\mu, \sigma^2)$）

| 条件              | 枢轴量                                                     | $1-\alpha$ 置信区间                                |
| ----------------- | ---------------------------------------------------------- | ---------------------------------------------------- |
| $\sigma^2$ 已知 | $Z = \dfrac{\bar{X} - \mu}{\sigma/\sqrt{n}} \sim N(0,1)$ | $\bar{X} \pm z_{\alpha/2}\dfrac{\sigma}{\sqrt{n}}$ |
| $\sigma^2$ 未知 | $T = \dfrac{\bar{X}-\mu}{S/\sqrt{n}} \sim t(n-1)$        | $\bar{X} \pm t_{\alpha/2}(n-1)\dfrac{S}{\sqrt{n}}$ |

## 5、方差的置信区间

### 5.1 区间估计的思想（$\sigma^2$）

构造仅含 $\sigma^2$ 且分布已知的枢轴量，由分位数反解区间。

**注意**：$\chi^2$ 分布**不对称**，左右各取 $\alpha/2$ 概率时上下分位数都要写，不能像 $Z/T$ 那样只用一个 $z_{\alpha/2}$。

### 5.2 单正态总体 $\sigma^2$ 的区间估计（$X \sim N(\mu, \sigma^2)$，$\mu$ 未知）

| 条件         | 枢轴量                                                                      | 分布            | $1-\alpha$ 置信区间                                                                                  |
| ------------ | --------------------------------------------------------------------------- | --------------- | ------------------------------------------------------------------------------------------------------ |
| $\mu$ 未知 | $W = \dfrac{(n-1)S^2}{\sigma^2} = \dfrac{1}{\sigma^2}\sum(X_i-\bar{X})^2$ | $\chi^2(n-1)$ | $\left[\dfrac{(n-1)S^2}{\chi^2_{\alpha/2}(n-1)},\ \dfrac{(n-1)S^2}{\chi^2_{1-\alpha/2}(n-1)}\right]$ |

**推导要点**（课件 §5.5）：

- 选 $\lambda_1,\lambda_2$ 使 $P(W \le \lambda_1) = \alpha/2$、$P(W \ge \lambda_2) = \alpha/2$，即 $P(\lambda_1 < W < \lambda_2) = 1-\alpha$
- 由 $\lambda_1 < \dfrac{(n-1)S^2}{\sigma^2} < \lambda_2$ 反解 $\sigma^2$：

$$
\frac{(n-1)S^2}{\lambda_2} < \sigma^2 < \frac{(n-1)S^2}{\lambda_1}
$$

- $\lambda_1 = \chi^2_{1-\alpha/2}(n-1)$，$\lambda_2 = \chi^2_{\alpha/2}(n-1)$（左尾取小、右尾取大，分数上下端对调）

**对称情形**：若 $\mu$ 已知，则枢轴量 $\dfrac{1}{\sigma^2}\sum(X_i-\mu)^2 \sim \chi^2(n)$，自由度 $n$，置信区间类推。

## 6、经验分布函数与直方图

### 6.1 经验分布函数

设样本值按小到大排为 $x_{(1)} \le x_{(2)} \le \cdots \le x_{(n)}$（次序统计量），**经验分布函数**

$$
F_n(x) = \frac{1}{n}\#\{i: x_i \le x\} = \begin{cases} 0, & x < x_{(1)} \\ \dfrac{k}{n}, & x_{(k)} \le x < x_{(k+1)} \\ 1, & x \ge x_{(n)} \end{cases}
$$

**格里文科定理**：$n \to \infty$ 时

$$
P\left(\lim_{n\to\infty}\sup_x |F_n(x) - F(x)| = 0\right) = 1
$$

即经验分布函数**几乎处处一致收敛**于总体分布函数，是非参数统计的理论基础。

### 6.2 直方图

将数据分组到互不重叠的区间（箱），以各区间内数据频率/组距为高作矩形：

**频率密度直方图**：第 $i$ 组矩形高 $= \dfrac{f_i}{\Delta_i} = \dfrac{n_i/(n\,\Delta_i)}{1}$，其中 $n_i$ 为该组频数，$\Delta_i$ 为组距。

- 各矩形面积 $= \dfrac{n_i}{n} = $ 组内频率，总面积 $= 1$
- $n$ 大、组距小时直方图顶部近似总体密度 $f(x)$

**频数直方图**：高直接用频数 $n_i$，仅用于展示分布形态。
