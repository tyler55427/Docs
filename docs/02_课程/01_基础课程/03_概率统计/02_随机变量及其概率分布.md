# 二、随机变量及其概率分布

## 1、随机变量及其分布函数

### 1.1 随机变量

设 $\Omega$ 为样本空间，**随机变量** $X$ 是定义在 $\Omega$ 上的实值函数 $X: \Omega \to \mathbb{R}$，使对任意 $x \in \mathbb{R}$，$\{\omega: X(\omega) \le x\}$ 都是事件。

将样本点映射到人的主观取值

### 1.2 分布函数

$$
F(x) = P(X \le x), \quad x \in \mathbb{R}
$$

称为 $X$ 的**分布函数**（累积分布函数）。

**性质**：

1. **单调不减**：$x_1 < x_2 \Rightarrow F(x_1) \le F(x_2)$
2. **边界**：$F(-\infty) = 0$，$F(+\infty) = 1$
3. **右连续**：$F(x+0) = F(x)$
4. $P(a < X \le b) = F(b) - F(a)$
5. **左极限**：$F(a-) = \lim_{x \to a^-} F(x) = P(X < a)$
6. $P(X = a) = F(a) - F(a-)$，特别地，$P(X = a) = 0 \Leftrightarrow a$ 是 $F(x)$ 的连续点

任意满足上述四条的函数都可作为某随机变量的分布函数。

## 2、离散型随机变量

### 2.1 概率分布律

$X$ 取有限或可列个值 $x_1, x_2, \cdots$，记

$$
P(X = x_i) = p_i, \quad i = 1, 2, \cdots
$$

满足 $p_i \ge 0$ 且 $\sum p_i = 1$。分布函数 $F(x) = \sum_{x_i \le x} p_i$（阶梯函数）。

### 2.2 常见离散分布

| 分布                            | 记号                              | 分布律$P(X=k)$                                                                                                                         | 性质                     |
| ------------------------------- | --------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- | ------------------------ |
| 两点分布（0-1分布、伯努利分布） | $B(1,p)$                        | $p^k(1-p)^{1-k},\ k=0,1$                                                                                                               | 独立同分布相加为二项分布 |
| 二项分布                        | $B(n,p)$                        | $\binom{n}{k}p^k(1-p)^{n-k},\ k=0,\cdots,n$          | **可加性：**$B(n_1,p)+B(n_2,p)\sim B(n_1+n_2,p)$                        |                          |
| 泊松分布                        | $\pi(\lambda)$ / $P(\lambda)$ | $\dfrac{\lambda^k}{k!}e^{-\lambda},\ k=0,1,\cdots$   | **可加性：**$\pi(\lambda_1)+\pi(\lambda_2)\sim\pi(\lambda_1+\lambda_2)$ |                          |
| 几何分布                        | $\mathrm{Geo}(p)$               | $(1-p)^{k-1}p,\ k=1,2,\cdots$                        | **无记忆性：**$P(X>s+t\mid X>s)=P(X>t)$                                 |                          |
| 超几何分布                      | $H(N,M,n)$                      | $\dfrac{\binom{M}{k}\binom{N-M}{n-k}}{\binom{N}{n}}$                                                                                   | 不放回抽样               |

**泊松定理（二项→泊松）**

设 $n \to \infty, p \to 0$，$np = \lambda > 0$ 保持常数，则

$$
\binom{n}{k}p^k(1-p)^{n-k} \to \frac{\lambda^k}{k!}e^{-\lambda}
$$

即**稀有事件**（$p$ 小、$n$ 大）可用泊松近似二项分布。

## 3、连续型随机变量

### 3.1 概率密度函数

若存在非负可积函数 $f(x)$ 使 $F(x) = \int_{-\infty}^x f(t)\,dt$，称 $X$ 为**连续型随机变量**，$f(x)$ 为其**概率密度**。

**性质**：

1. $f(x) \ge 0$
2. $\int_{-\infty}^{+\infty} f(x)\,dx = 1$
3. $P(a < X \le b) = \int_a^b f(x)\,dx$
4. $P(X = x_0) = 0$**（单点概率为零）**
5. $F'(x) = f(x)$（连续点）

**注意**：连续型 $P(a < X < b) = P(a \le X \le b) = P(a < X \le b) = F(b) - F(a)$。

### 3.2 常见连续分布

| 分布     | 记号                      | 密度函数 / 分布函数                                                                                                                                                                                                                                    | 性质                                                                                                                                |  |  |
| -------- | ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------- | - | - |
| 均匀分布 | $U(a,b)$                | $f(x) = \begin{cases}\dfrac{1}{b-a}, & a<x<b \\ 0, & \text{其他}\end{cases}$                                                                                                                                                                         | $E(X)=\dfrac{a+b}{2}$，$D(X)=\dfrac{(b-a)^2}{12}$                                                                               |  |  |
| 指数分布 | $\mathrm{Exp}(\lambda)$ | $f(x) = \begin{cases}\lambda e^{-\lambda x}, & x>0 \\ 0, & x\le 0\end{cases}$，$F(x) = \begin{cases}1-e^{-\lambda x}, & x>0 \\ 0, & x\le 0\end{cases}$ | **无记忆性**：$P(X>s+t\mid X>s)=P(X>t)$；$E(X)=1/\lambda$，$D(X)=1/\lambda^2$ |                                                                                                                                     |  |  |
| 正态分布 | $N(\mu,\sigma^2)$       | $f(x) = \dfrac{1}{\sqrt{2\pi}\,\sigma}e^{-\frac{(x-\mu)^2}{2\sigma^2}}$                                                                                                                                                                              | $E(X)=\mu$，$D(X)=\sigma^2$；**标准化**：$Z=\dfrac{X-\mu}{\sigma}\sim N(0,1)$；**对称性**：$\Phi(-x)=1-\Phi(x)$ |  |  |

## 4、随机向量及其分布

### 4.1 联合分布函数

$(X, Y)$ 的**联合分布函数**：

$$
F(x, y) = P(X \le x,\ Y \le y)
$$

**性质**：关于 $x, y$ 单调不减、右连续、$F(-\infty, y) = F(x, -\infty) = 0$、$F(+\infty, +\infty) = 1$。

### 4.2 离散型随机向量

$(X, Y)$ 取值 $(x_i, y_j)$，**联合分布律** $p_{ij} = P(X = x_i, Y = y_j)$，$\sum_{i,j} p_{ij} = 1$。

### 4.3 连续型随机向量

**联合密度** $f(x,y)$：$F(x,y) = \int_{-\infty}^x \int_{-\infty}^y f(u,v)\,dv\,du$，$\iint f = 1$，$P((X,Y) \in D) = \iint_D f\,dx\,dy$。

### 4.4 边缘分布

由联合分布求单独一个变量的分布：

- 离散：$p_{i\cdot} = \sum_j p_{ij}$（$X$ 的边缘），$p_{\cdot j} = \sum_i p_{ij}$（$Y$ 的边缘）
- 连续：$f_X(x) = \int_{-\infty}^{+\infty} f(x,y)\,dy$，$f_Y(y) = \int_{-\infty}^{+\infty} f(x,y)\,dx$

### 4.5 二维正态分布

$(X, Y) \sim N(\mu_1, \mu_2, \sigma_1^2, \sigma_2^2, \rho)$，密度含参数 $\rho$（相关系数）。

边缘分布 $X \sim N(\mu_1, \sigma_1^2)$，$Y \sim N(\mu_2, \sigma_2^2)$（边缘与 $\rho$ 无关）。

## 5、随机变量的独立性

### 5.1 定义

$X, Y$ **独立** $\Leftrightarrow$ 联合 = 边缘之积：

- 离散：$p_{ij} = p_{i\cdot} \cdot p_{\cdot j}$
- 连续：$f(x,y) = f_X(x)\,f_Y(y)$
- 一般：$F(x,y) = F_X(x)\,F_Y(y)$

**推广**：$n$ 个变量相互独立 $\Leftrightarrow$ 联合分布等于各边缘分布之积。

**二维正态**：$X, Y$ 独立 $\Leftrightarrow \rho = 0$。

## 6、随机变量函数的分布

### 6.1 两个随机变量之和、差、积、商

设 $(X, Y)$ 联合密度为 $f(x,y)$，$X, Y$ 独立时 $f(x,y) = f_X(x)\,f_Y(y)$：

**和 $Z = X + Y$（卷积公式）**：

$$
f_Z(z) = \int_{-\infty}^{+\infty} f(x, z-x)\,dx = \int_{-\infty}^{+\infty} f(z-y, y)\,dy
$$

**差 $Z = X - Y$**：

$$
f_Z(z) = \int_{-\infty}^{+\infty} f(x, x-z)\,dx = \int_{-\infty}^{+\infty} f(z+y, y)\,dy
$$

**积 $Z = XY$**：

$$
f_Z(z) = \int_{-\infty}^{+\infty} f(x, z/x)\,\frac{dx}{|x|} = \int_{-\infty}^{+\infty} f(z/y, y)\,\frac{dy}{|y|}
$$

**商 $Z = X/Y$**：

$$
f_Z(z) = \int_{-\infty}^{+\infty} f(yz, y)\,|y|\,dy
$$

**可加性**（独立、同分布情形）：

- 二项分布：$B(n_1, p) + B(n_2, p) \sim B(n_1+n_2, p)$
- 泊松分布：$\pi(\lambda_1) + \pi(\lambda_2) \sim \pi(\lambda_1+\lambda_2)$
- 正态分布：$N(\mu_1,\sigma_1^2) + N(\mu_2,\sigma_2^2) \sim N(\mu_1+\mu_2,\ \sigma_1^2+\sigma_2^2)$

### 6.2 $\max$ 与 $\min$ 的分布

$X_1, \cdots, X_n$ 独立同分布，$F(x)$：

**$\max$ 的分布**：

- $F_Y(y) = P(Y \le y) = P(\max(X_1,\cdots,X_n) \le y) = P(X_1 \le y, \cdots, X_n \le y) = P(X_1 \le y)\cdots P(X_n \le y) = [F(y)]^n$

**$\min$ 的分布**：

- $F_Y(y) = P(Y \le y) = 1 - P(Y > y) = 1 - P(\min(X_1,\cdots,X_n) > y) = 1 - P(X_1 > y, \cdots, X_n > y) = 1 - [1 - F(y)]^n$

### 6.3 随机变量函数的变换公式

**定理（单调变换公式）**：设连续型随机变量 $X$ 有密度 $f_X(x)$，$P(X \in V) = 1$，$f(x)$ 在 $V$ 上严格单调且有连续导数，则 $Y = f(X)$ 的密度为

$$f_Y(y) = f_X(h(y))\,|h'(y)|,\quad y \in G$$

其中 $h(y)$ 为 $f(x)$ 的反函数，$G = \{y = f(x) : x \in V\}$。当 $y \notin G$ 时 $f_Y(y) = 0$。

**定理（二维变换公式）**：设 $(X_1, X_2)$ 有联合密度 $f(x_1, x_2)$，变换

$$\begin{cases} y_1 = y_1(x_1, x_2) \\ y_2 = y_2(x_1, x_2) \end{cases}$$

在 $D$ 上为一一变换，有连续偏导数且 $\dfrac{\partial(y_1, y_2)}{\partial(x_1, x_2)} \neq 0$，则 $(Y_1, Y_2)$ 的联合密度为

$$f_{Y_1,Y_2}(y_1, y_2) = f_X(x_1(y_1, y_2), x_2(y_1, y_2)) \left|\frac{\partial(x_1, x_2)}{\partial(y_1, y_2)}\right|,\quad (y_1, y_2) \in G$$

其中 $(x_1, x_2)$ 是变换的逆，$G$ 为值域。
