# 四、贝叶斯推理方法：准确数学分析
## 共轭先验

**共轭先验**：先验和似然得到的后验与先验形式上相同。

Beta 分布是伯努利 似然的共轭先验；正态分布是高斯似然的共轭先验。

## Beta-Bernoulli 模型

**伯努利似然（似然函数）**：

$$P(D|\theta) = p(z|N,\theta) = \binom{N}{z} \theta^z (1-\theta)^{N-z}$$

其中 $z = \sum y_i$（正面次数），$N$ 为总试验次数。

**Beta 先验**：

$$p(\theta|a,b) = \frac{\theta^{a-1}(1-\theta)^{b-1}}{B(a,b)}, \quad \theta \in [0,1], \quad a>0, \ b>0$$

其中归一化常数 $B(a,b) = \int_0^1 \theta^{a-1}(1-\theta)^{b-1} d\theta$。

**Beta 分布性质**：

| 量 | 公式 |
|----|------|
| 均值 | $\mu = \frac{a}{a+b}$ |
| 众数（$a>1, b>1$） | $w = \frac{a-1}{a+b-2}$ |
| 精度（集中度） | $k = a+b$ |

参数影响：$a \uparrow$ 偏向右；$b \uparrow$ 偏向左；$a \uparrow, b \uparrow$ 变窄更集中。

由均值/众数和精度确定参数：
$$a = w(k-2) + 1, \quad b = (1-w)(k-2) + 1$$

**后验**：

$$P(\theta|D) \propto \theta^{z+a-1}(1-\theta)^{N-z+b-1} = \text{Beta}(\theta | z+a, \ N-z+b)$$

后验均值：
$$\frac{z+a}{N+a+b} = \frac{z}{N} \cdot \frac{N}{N+a+b} + \frac{a}{a+b} \cdot \frac{a+b}{N+a+b}$$

> 含义：后验是先验与似然的**加权平均**

**特殊情况**：

- $N > a+b$：数据决定
- $N < a+b$：先验决定
- **不确定先验**：Beta$(\theta|1,1)$ 退化为均匀分布，后验 = 似然

## 高斯参数的贝叶斯估计

设数据 $D \sim N(\mu, \sigma^2)$，似然：$p(D|\mu, \sigma^2) = N(D|\mu, \sigma^2)$

### 估计 $\mu$（假设 $\sigma^2$ 已知）

设先验 $\mu \sim N(\mu_0, \sigma_0^2)$。

后验：
$$\hat{\sigma}^2 = \frac{1}{\frac{1}{\sigma^2} + \frac{1}{\sigma_0^2}}$$
$$\hat{\mu} = \left( \frac{\mu_0}{\sigma_0^2} + \frac{N\bar{x}}{\sigma^2} \right) / \left( \frac{N}{\sigma^2} + \frac{1}{\sigma_0^2} \right)$$

后验分布：$p(\mu|D) \sim N(\hat{\mu}, \hat{\sigma}^2)$

**MAP 估计**：
$$\hat{\mu}_{\text{MAP}} = \frac{\sigma^2}{\sigma^2 + N\sigma_0^2} \mu_0 + \frac{N\sigma_0^2}{\sigma^2 + N\sigma_0^2} \bar{x}$$

**MLE 估计**：$\hat{\mu}_{\text{MLE}} = \bar{x}$

### 估计 $\sigma^2$（假设 $\mu$ 已知）

形式 $(\sigma^2)^{-a} e^{-\frac{b}{\sigma^2}}$ → **逆 Gamma 分布**：

$$\text{IG}(\gamma|a,b) = \frac{b^a}{\Gamma(a)} \gamma^{-(a+1)} e^{-\frac{b}{\gamma}}, \quad \gamma > 0, \ a > 0, \ b > 0$$

众数：$\text{mode} = \frac{b}{a+1}$

先验：$p(\sigma^2) = \text{IG}(\sigma^2|a_0, b_0)$

后验：
$$\hat{a} = \frac{N}{2} + a_0, \quad \hat{b} = b_0 + \frac{1}{2}\sum_{i=1}^N (x_i - \mu)^2$$

### 先验设计原则

1. 先验形式与似然一致，从而使后验形式也一致，便于推导
2. 先验使 $p(D)$ 方便求解
3. 先验有足够表达能力来表达先验知识

### 精度 $\lambda$

$$\lambda = \frac{1}{\sigma^2}$$

共轭先验变为 **Gamma 分布**（不考）

## MLE 与 MAP 对比

- **MLE**：$\hat{\theta} = \arg\max_\theta p(D|\theta)$
- **MAP**：$\hat{\theta} = \arg\max_\theta p(D|\theta)p(\theta)$（多了先验约束）
