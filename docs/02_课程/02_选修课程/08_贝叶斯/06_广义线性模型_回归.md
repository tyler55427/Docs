# 六、广义线性模型：回归
## 基本概念

**术语对比**：

| 统计/机器学习 | 含义 |
|---------------|------|
| 自变量/特征 | Predictor / Independent Variable |
| 因变量/预测 | Predicted / Dependent Variable |

**因变量类型**：

| 类型 | 说明 |
|------|------|
| 度量值（metric） | 连续 → 回归 |
| 类别值（nominal） | 离散 → 分类 |

**自变量**：度量值或类别值（可分箱）

## 广义线性模型框架

自变量 $\xrightarrow{\text{集中趋势}}$ 因变量 $\xrightarrow{\text{噪声建模}}$ 含噪声的数据

步骤：
1. **线性组合**：$\mu = f(\ln(x)) = \beta_0 + \sum_k \beta_k x_k$
2. **连接函数**：$f$ 映射到合适值域
   - 回归：恒等函数 $f(\ln(x)) = \ln(x)$
   - 分类：逻辑函数 $f(\ln(x)) = \frac{1}{1+e^{-\ln(x)}}$
3. **概率分布建模噪声**：$y \sim \text{pdf}(\mu, \text{其他参数})$

## 简单线性回归

**模型（似然）**：$\mu = \beta_1 x + \beta_0$，$y \sim \text{normal}(\mu, \sigma)$

**先验**（相互独立）：

$$p(\beta_0) = \text{normal}(\mu_0, \sigma_0), \quad p(\beta_1) = \text{normal}(\mu_1, \sigma_1), \quad p(\sigma) = \text{uniform}(0|a_0, b_0)$$

## 数据标准化

当数据集中区域远离原点时，$\beta_1$ 与 $\beta_0$ 相关性高，导致采样困难。

**标准化方法**：

$$z_x = \frac{x - \mu_x}{\sigma_x}, \quad z_y = \frac{y - \mu_y}{\sigma_y}$$

变换后：$z_y = \beta_1 z_x + \beta_0$，$z_y \sim \text{normal}(\beta_1 z_x + \beta_0, \frac{\sigma_y}{\sigma_x})$

## Robust 线性回归

对异常值不敏感。普通线性回归中平方项使异常值影响大。

**学生 $t$ 分布**：

$$p(x|\mu, \sigma, \nu) = \frac{\Gamma(\frac{\nu+1}{2})}{\Gamma(\frac{\nu}{2})} \frac{1}{\sqrt{\pi\nu}\sigma} \left[1 + \frac{(x-\mu)^2}{\nu\sigma^2}\right]^{-\frac{\nu+1}{2}}$$

性质：
- $\nu \to \infty$：趋于正态分布
- $\nu \downarrow$：薄尾概率，异常值更不敏感
- 一般 $\nu = 30$

**先验**：
$$p(\beta_0) = \text{normal}(m_0, s_0), \quad p(\beta_1) = \text{normal}(m_1, s_1)$$
$$p(\sigma) = \text{uniform}(a_\sigma, b_\sigma), \quad p(\nu) = \text{inverse-gamma}(\alpha_\nu, \beta_\nu)$$

## 多重线性回归

自变量 $> 1$：$\hat{y} = \sum_k \beta_k x_k + \beta_0$

模型：$y \sim \text{student\_t}(\hat{y}, \sigma, \nu)$

### 冗余自变量

高度相关的自变量会导致系数相互影响。

**判断**：相关系数 $|r| > 0.7$ 为强相关。

**处理**：
- 去掉其中一个
- 加权平均代替
- 主成分分析 (PCA)

## MLE 与 MAP

**MLE 线性回归**：
$$\hat{\beta} = (X^T X)^{-1} X^T y, \quad \text{复杂度 } O(K^3)$$

**负对数似然 (NLL)**：
$$-\log p(y|x,\beta,\sigma) = \frac{1}{2\sigma^2}\sum_i (y^{(i)} - \hat{y}^{(i)})^2 + \text{常数}$$

**MAP**：
$$\theta = \arg\min_\theta -\sum_i \log p(D|\theta) - \log p(\theta)$$
