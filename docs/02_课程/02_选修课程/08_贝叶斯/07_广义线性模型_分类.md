# 七、广义线性模型：分类
## 分类问题

因变量是类别值。

## 逻辑回归（二分类）

**模型**：$\mu = \text{logistic}(\beta_0 + \sum_k \beta_k x_k)$

$$y \sim \text{Bernoulli}(\mu)$$

**Sigmoid（逻辑）函数**：

$$\text{logistic}(x; \beta_0, \beta_1) = \frac{1}{1 + e^{-(\beta_0 + \beta_1 x)}}$$

- $\beta_1$（即 $\gamma$）：控制斜率陡度
- $\beta_0$（即 $-\theta$）：控制 $y=0.5$ 的 $x$ 位置

**Logit 函数**（sigmoid 的反函数）：

$$\text{logit}(x) = \log\frac{x}{1-x}, \quad 0 < x < 1$$

因此 $\text{logit}(\mu) = \beta_0 + \beta_1 x$

## 对数几率 (Log-Odds)

$$\text{logit}(\mu) = \log\frac{P(y=1)}{P(y=0)}$$

- $x_2$ 增加 1，$\text{logit}(\mu)$ 增加 $\beta_2$
- $\beta_2 > 0$：$y=1$ 概率变大
- $\beta_2 < 0$：$y=0$ 概率变大

## 回归系数解释

$$\text{logit}(\mu) = \beta_2 x_2 + \beta_1 x_1 + \beta_0$$

直线 $\beta_2 x_2 + \beta_1 x_1 + \beta_0 = 0$ 表示概率变化最快的方向。

## 数据不平衡处理

| 方法 | 说明 |
|------|------|
| 收集阶段控制 | 控制采样比例 |
| 过采样 | 重复数量少的样本 |
| 欠采样 | 采样数量多的样本 |

## Softmax 回归（多分类）

**模型**：$\lambda_i = \sum_j \beta_{i,j} x_j + \beta_{0,i}$

$$\phi_k = \text{softmax}(\{\lambda_k\})_k = \frac{e^{\lambda_k}}{\sum_i e^{\lambda_i}}$$

$k$ 个类别，$\phi_k$ 为第 $k$ 个类别的概率。

**归一化方法对比**：

| 方法 | 特点 |
|------|------|
| max | 最大值置 1，其他置 0 |
| 求和 | 归一化但保留所有概率 |
| softmax | 扩大最大项与其他项的概率差距 |

## 类别分布（多项分布）

伯努利分布的扩展：$p(y=k|\bar{\theta}) = \theta_k$，满足 $\sum_k \theta_k = 1$

**softmax 与 logistic 的关系**：当只有二分类时，softmax 退化为 logistic 函数。

## 系数不确定性

由于所有 $\lambda_k$ 加上相同常数概率结果不变，需要限制一个参考类别 $\lambda_k = 0$（常设第一类）。

softmax 只有二分类时变为 logistic 函数。

## 类别自变量编码

类别值不能用 $\{1, 2, 3\}$（含义不合理），应使用**独热编码**（对应位置为 1，其他为 0）。

线性组合：$y = \beta_0 + \beta^T x$，$\beta_{[j]}$ 表示从无类别到类别 $j$ 的改变量。

通常设 $\sum_{j=1}^M \beta_{[j]} = 0$ 或将 $\beta_0$ 作为基准使 $\beta_{[0]} = 0$（减少一个类别）。

## Robust 逻辑回归

异常值使阈值偏移，曲线不陡峭。

**解决方法**：$\mu = \alpha \cdot \frac{1}{2} + (1-\alpha) \text{logistic}(\beta_0 + \beta_1 x_1 + \cdots)$（非 0.5 概率的插值组合）
