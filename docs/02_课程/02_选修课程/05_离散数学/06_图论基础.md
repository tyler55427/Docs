# 六、图论基础

## 图的基本概念

### 定义

**图** G = (V, E)：

- V：顶点集（非空有限集合）
- E：边集（V × V 的子集）

**无向图**：边无方向，(u, v) = (v, u)。
**有向图**：边有方向，<u, v> ≠ <v, u>（有向边从尾到头）。

**多重图**：两顶点间有多于一条边（含平行边）。
**简单图**：无平行边、无自环（通常简称"图"）。

**邻接**：u, v 相邻 ⇔ (u, v) ∈ E（无向）或 <u, v> ∈ E（有向）。

## 度

**无向图**：顶点 v 的度 d(v) = v 的关联边数（自环算 2）。

**握手定理**：Σ d(v) = 2|E|（所有顶点度之和 = 2 × 边数）。

**有向图**：

- 出度 d⁺(v)：从 v 出发的边数
- 入度 d⁻(v)：指向 v 的边数
- d(v) = d⁺(v) + d⁻(v)
- Σ d⁺(v) = Σ d⁻(v) = |E|

**定理**：奇度顶点个数为偶数（握手定理的直接推论）。

## 完全图

- **无向完全图** Kₙ：n 个顶点、两两相邻，|E| = C(n, 2) = n(n-1)/2。
- **有向完全图**：两顶点间有一对方向相反的边。

## 二分图

**定义**：V = X ∪ Y，X ∩ Y = ∅，每条边一端在 X、一端在 Y。

**完全二分图** K_{m,n}：X 有 m 个、Y 有 n 个顶点，|E| = m·n。

## 子图

### 基本概念

**子图**：G' = (V', E')，V' ⊆ V，E' ⊆ E 且 E' 的边端点都在 V' 中。
**生成子图 / 生成子图**：V' = V 的子图（保留所有顶点）。
**导出子图**：V' ⊆ V，由 V' 及其在原图中端点都在 V' 的边构成。

**补图**：G 的补图 G̅：同顶点集，V̅ = V，(u, v) ∈ E̅ ⇔ u ≠ v 且 (u, v) ∉ E。

## 图同构

**同构**：G ≅ H 当且仅当存在双射 f: V_G → V_H，使 (u, v) ∈ E_G ⇔ (f(u), f(v)) ∈ E_H。

**不变量**：同构必保持的性质 —— 顶点数、边数、度序列、连通性、环/三角形数。

**判断同构**：通常通过不变量排除 + 构造映射。完全分类（如所有 5 顶点的简单图）可用 adjacency matrix / canonization 判断。

## 通路与连通

### 基本概念

**通路（路径）**：顶点序列 v₀e₁v₁e₂...eₙvₙ，边不重复（简单路径）或顶点不重复（基本通路）。

**回路**：起点终点相同 (v₀ = vₙ) 的路径。
**圈**：除起点终点外顶点不重复的回路（n-圈记 Cₙ）。

## 连通性

**无向图**：

- 连通：任意两顶点间存在路径
- 连通分支（连通分量）：极大连通子图
- 弱连通：有向图忽略方向后连通
- 强连通：任意两顶点间存在有向路径

**有向图**：

- 强连通分量（SCC）：极大强连通子图
- 单向连通：任意两顶点间至少一个方向可达

## 连通图的性质

- 连通无向图 |E| ≥ |V| - 1（树是 |E| = |V| - 1 的极小连通图）
- 连通图 |E| ≥ |V| - 1

## 点割与边割

**点割**：删除某些顶点（及关联边）后图不连通。
**边割**：删除某些边后图不连通。
**连通度** κ(G)：最小点割集的大小。
**边连通度** λ(G)：最小边割集的大小。

**Whitney 定理**：对任意图 G，κ(G) ≤ λ(G) ≤ δ(G)（δ 为最小度）。

## Euler 图与 Hamilton 图

### Euler 图（Euler 路径 / 回路）

**定义**：

- **Euler 回路**：经过每条边恰好一次的**回路**（所有顶点度为偶数）
- **Euler 路径**：经过每条边恰好一次的**路径**（恰好 0 或 2 个顶点度为奇数）

**判定**：

- 无向图有 Euler 回路 ⇔ 连通（忽略孤立点）+ 所有顶点度为偶数
- 无向图有 Euler 路径 ⇔ 连通 + 奇度顶点数为 0 或 2

**Fleury 算法**：逐步走边，每次走非桥边（除非别无选择）。
**Hierholzer 算法**：O(|V|+|E|) 找 Euler 回路。

## Hamilton 图

**定义**：

- **Hamilton 回路**：经过每个顶点恰好一次的回路（Cₙ）
- **Hamilton 路径**：经过每个顶点恰好一次的路径

**判定**（充分条件）：

- **Dirac 定理**：n ≥ 3 的简单图，若 δ(G) ≥ n/2，则 H(G) 成立（必有 Hamilton 回路）
- **Ore 定理**：n ≥ 3，若对每对不相邻 u, v，有 d(u)+d(v) ≥ n，则 H(G) 成立

**困难**：Hamilton 判定是 **NP 完全**问题（与旅行商问题 TSP 直接相关）。

## 平面图

### 定义

**平面图**：能嵌入平面且边只在顶点相交的图（可平面化画法）。

## Euler 公式

**Euler 公式**：连通平面图 V - E + F = 2（顶点数 - 边数 + 面数 = 2）。

**推论**：

- 平面图 E ≤ 3V - 6（V ≥ 3）
- 平面图必有度 ≤ 5 的顶点（平均度 < 6）
- K₅、K₃,₃ 是**非平面图**的判定标准（Kuratowski 定理）

## 平面图判定

- K₅（5 阶完全图）：10 条边
- K₃,₃（完全二分图）：3+3 个顶点，9 条边
- **Kuratowski 定理**：图 G 是平面图 ⇔ G 不包含 K₅ 或 K₃,₃ 的细分（可平面图 = 无 K₅/K₃,₃ 细分子图）

## 对偶图

平面图 G 的对偶图 G*：每个面对应 G* 的一个顶点，共享边对应 G* 的边。

## 树

**树**：无环连通无向图。

**等价定义**（以下任一条件均可定义树）：

1. 连通且无回路
2. 无回路且有 n-1 条边
3. 连通且删去任一边就不连通
4. 无回路且添加任一边就产生回路

**生成树**：生成子图且是树。任意连通图必有生成树。

**性质**：

- 树有 n 个顶点、n-1 条边
- 树中任意两顶点间有**唯一**路径
- 树中悬挂点（度为 1）的数量 ≥ 2（除非 n=1）

## 应用

- **计算机网络**：路由协议（RIP 基于跳数最短路；OSPF 基于 SPF/Dijkstra）、生成树协议（STP）
- **电路设计**：平面电路布线
- **地图染色**：四色定理（平面图点染色 ≤ 4）
- **编译器**：AST（抽象语法树）、控制流图
- **数据结构**：二叉树、B树、B+树
- **任务调度**：拓扑排序（偏序 → 线性序）

## 例题

**例 1**：n 阶完全图 Kₙ 中有多少个割边？

割边 = 删除后图不连通。在完全图中：

- K₂ 的 1 条边是割边
- Kₙ (n≥3) 中，删除任何一条边后图仍连通（因为还有 n-2 个顶点可走），所以没有割边？

实际上 Kₙ (n≥3) 中**没有割边**，因为任何两个顶点间至少有两条独立路径（n≥3 时）。
