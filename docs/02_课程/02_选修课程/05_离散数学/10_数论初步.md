# 十、数论初步

## 整除

### 定义

**整除**：b ≠ 0，a = b·q（q 为整数）⇔ b | a（b 整除 a）。

- b 是 a 的约数（因子），a 是 b 的倍数
- 若 b ∤ a，记 b ∤ a

**真因子**：非平凡因子，即 1 < d < n。

## 性质

- a | a（自反）
- a | b, b | c ⇒ a | c（传递）
- a | b, a | c ⇒ a | (b ± c)（线性组合）
- a | b ⇔ (-a) | b ⇔ a | (-b)（符号无关）
- 若 a | b 且 |b| < |a|，则 b = 0

## 素数与合数

**素数**（质数）：p > 1 且仅有 ±1, ±p 约数。
**合数**：n > 1 且非素数（必有非平凡因子）。

**基本定理**：

- **算术基本定理**（唯一分解定理）：任意 n > 1 可唯一分解为 n = p₁^{a₁}·p₂^{a₂}·...·p_k^{a_k}（素因子幂次唯一）。
- 素数有无穷多个（Euclid 证明）。
- **Eratosthenes 筛法**：求素数的算法。

## 最大公约数与最小公倍数

**gcd(a, b)**：最大公因子。
**lcm(a, b)**：最小公倍数。

**性质**：

- gcd(a, b) · lcm(a, b) = |a·b|（a, b 同号或考虑绝对值）
- gcd(a, b, c) = gcd(gcd(a, b), c)
- lcm(a, b, c) = lcm(lcm(a, b), c)

**互素**：gcd(a, b) = 1。

**Bezout 定理**：∃ x, y ∈ ℤ 使 ax + by = gcd(a, b)。

**推论**：gcd(a, b) = 1 ⇔ ∃ x, y 使 ax + by = 1（整数线性组合表示 1）。

## 欧几里得算法

### 辗转相除法

gcd(a, b) = gcd(b, a mod b)，反复迭代直到余数为 0。

```
gcd(1071, 1029):
1071 = 1029 + 42
1029 = 42 × 24 + 21
42 = 21 × 2 + 0
∴ gcd = 21
```

**时间复杂度**：O(log min(a, b))。

## 扩展欧几里得算法

求 x, y 使 ax + by = gcd(a, b)。

**递推**：

```
gcd(a, b) = gcd(b, a mod b)
gcd(a, b) = b·x₁ + (a mod b)·y₁
         = b·x₁ + (a - ⌊a/b⌋·b)·y₁
         = a·y₁ + b·(x₁ - ⌊a/b⌋·y₁)
```

反向回代求出 x, y。

## 一次同余方程

ax ≡ b (mod m) 有解 ⇔ gcd(a, m) | b。

**解的个数**：若有解，则模 m 下恰有 gcd(a, m) 个不同解。

**特例**：gcd(a, m) = 1 ⇔ a 在模 m 下有乘法逆元 a⁻¹。

## 同余

### 定义

a ≡ b (mod m) ⇔ m | (a - b)。

**等价表述**：

- a = b + km（k ∈ ℤ）
- a mod m = b mod m
- m | (a - b)

## 同余的性质

- **自反**：a ≡ a (mod m)
- **对称**：a ≡ b ⇒ b ≡ a (mod m)
- **传递**：a ≡ b, b ≡ c ⇒ a ≡ c (mod m)
- **加减**：a ≡ b, c ≡ d ⇒ a±c ≡ b±d (mod m)
- **乘法**：a ≡ b, c ≡ d ⇒ ac ≡ bd (mod m)
- **幂**：a ≡ b ⇒ aⁿ ≡ bⁿ (mod m)
- **约简**（需与模互素）：ac ≡ bc (mod m), gcd(c, m) = 1 ⇒ a ≡ b (mod m)

> **同余是等价关系**：在模 m 下，整数集被划分为 m 个**剩余类**（同余类）。

## 剩余类环

**剩余类**：模 m 下 a 的等价类，记 [a]_m。
**剩余类环**：ℤ/mℤ = {[0]_m, [1]_m, ..., [m-1]_m}，带模 m 加法和乘法。

**零因子**：若 [a]_m · [b]_m = [0]_m 但 [a]_m ≠ [0], [b]_m ≠ [0]，则 [a]_m, [b]_m 为零因子。

- ℤ/mℤ 无零因子 ⇔ m 是素数 ⇔ ℤ/mℤ 是域

**简化剩余系**（既约剩余系）：模 m 下与 m 互素的剩余类的集合。
**Euler φ 函数**：φ(m) = |{1 ≤ a ≤ m | gcd(a, m) = 1}| = 与 m 互素的剩余类个数。

**φ 函数的性质**：

- 若 p 是素数，φ(p) = p-1
- φ(p^k) = p^k - p^{k-1} = p^{k-1}(p-1)
- 若 gcd(m, n) = 1，φ(mn) = φ(m)·φ(n)（积性函数）

## 中国剩余定理（CRT）

### 定理内容

若 gcd(mᵢ, mⱼ) = 1（i ≠ j），则同余方程组：

$$
\begin{cases}
x \equiv a_1 \pmod{m_1} \\
x \equiv a_2 \pmod{m_2} \\
\vdots \\
x \equiv a_k \pmod{m_k}
\end{cases}
$$

有唯一解（模 M = m₁·m₂·...·mₖ）。

## 构造解

设 Mᵢ = M/mᵢ。由于 gcd(Mᵢ, mᵢ) = 1，存在逆元 yᵢ 使 Mᵢ·yᵢ ≡ 1 (mod mᵢ)。

解：$x = \sum_{i=1}^{k} a_i \cdot M_i \cdot y_i \pmod{M}$

**理解**：x ≡ aᵢ (mod mᵢ) 因为当 j ≠ i 时 Mⱼ ≡ 0 (mod mᵢ)，而 Mᵢ·yᵢ ≡ 1 (mod mᵢ)。

## 简化形式

若 m₁, m₂ 互素，x ≡ a₁m₂t₁ + a₂m₁t₂ (mod m₁m₂)，其中 t₁m₂ + t₂m₁ ≡ 1 (mod m₁m₂)。

## 应用

- **大整数分解**：CRT 用于合并模运算
- **RSA**：CRT 可加速解密（x = M_e^d mod N 可用 CRT 加速）
- **MIPS/ARM 伪指令**：`MUL` 溢出检测用 multLo/multHi 寄存器
- **昆虫学家 / 鬼畜问题**："今有物不知其数，3 件一数余..."

## 费马小定理（Fermat）

### 定理

若 p 是素数，p ∤ a，则 a^{p-1} ≡ 1 (mod p)。

**另一种形式**：a^p ≡ a (mod p)（对所有整数 a 成立）。

**证明**：考虑集合 {a, 2a, ..., (p-1)a} mod p。因 p ∤ a，这些数两两不同余且不等于 0。故 {a, 2a, ..., (p-1)a} ≡ {1, 2, ..., p-1} (mod p)。两边乘积相等：a^{p-1}·(p-1)! ≡ (p-1)! (mod p)。消去 (p-1)! 得 a^{p-1} ≡ 1 (mod p)。

## 伪素数

**伪素数**：合数 n 满足 a^{n-1} ≡ 1 (mod n) 对某个 a（1 < a < n）成立。

**Carmichael 数**：对所有与 n 互素的 a 都有 a^{n-1} ≡ 1 (mod n) 的合数 n（如 561, 1105, 1729）。

**Miller-Rabin 素性测试**：用随机 a 检验；若 n 是合数，至少 3/4 的 a 会失败（概率算法）。

## Euler 定理

### 定理

若 gcd(a, m) = 1，则 a^{φ(m)} ≡ 1 (mod m)。

**是 Fermat 小定理的推广**：当 m = p 素数，φ(p) = p-1。

## 证明

考虑简化剩余系 {r₁, ..., r_φ(m)}（与 m 互素的模 m 剩余类）。
乘以 a 后 {a·r₁, ..., a·r_φ(m)} 仍是简化剩余系（乘 a 不改变互素性，且为双射）。
两集合乘积同余：a^{φ(m)}·∏rᵢ ≡ ∏rᵢ (mod m)。
消去 ∏rᵢ（与 m 互素）得 a^{φ(m)} ≡ 1 (mod m)。

## RSA 密码体制

### 数学基础

1. **大整数分解困难**：给定 N = p·q（p, q 大素数），难以求出 p, q。
2. **Euler 定理**：a^{φ(N)} ≡ 1 (mod N)（gcd(a, N) = 1）。

## RSA 算法

**密钥生成**：

- 选两个大素数 p, q
- N = p·q，φ(N) = (p-1)(q-1)
- 选 e 使 gcd(e, φ(N)) = 1（公钥指数，通常取 65537）
- 求 d 使 e·d ≡ 1 (mod φ(N))（私钥指数，用扩展欧几里得）

**加密**：c = m^e mod N
**解密**：m = c^d mod N

**正确性**：
由 e·d ≡ 1 (mod φ(N)) ⇒ e·d = 1 + k·φ(N)
若 gcd(m, N) = 1，c^d = m^{1+kφ(N)} ≡ m·(m^{φ(N)})^k ≡ m (mod N)

**为何 RSA 安全**：已知 N, e 求 d 需要 φ(N)，而求 φ(N) 需要分解 N（大数分解问题）。

## RSA 的注意事项

- 需要 padding（如 OAEP）防止选择密文攻击
- 小指数攻击（如 e=3 的广播攻击）需加随机 padding
- 共模攻击：相同 N 不同 e 不能共用
- 实际中 RSA 用于密钥交换（加密对称密钥），数据加密用 AES

## 数论函数

### 积性函数

**积性函数**：f(mn) = f(m)·f(n)（当 gcd(m, n) = 1）。

常见积性函数：

- φ(n)：Euler 函数
- d(n)（τ(n)）：约数个数
- σ(n)：约数和
- μ(n)：Mobius 函数

## Mobius 函数

$$
\mu(n) = \begin{cases} 1 & n=1 \\ (-1)^k & n = p_1 p_2 \cdots p_k \text{（无平方因子）} \\ 0 & \text{其他} \end{cases}
$$

**Mobius 反演**：若 g(n) = Σ_{d|n} f(d)，则 f(n) = Σ_{d|n} μ(d)·g(n/d)。

## 二次剩余

**二次剩余**：a 是模 p 的二次剩余 ⇔ ∃x 使 x² ≡ a (mod p)。

**Euler 判别法**：a^{(p-1)/2} ≡ 1 (mod p) ⇔ a 是二次剩余；≡ -1 ⇔ 非二次剩余。

**Legendre 符号**：(a/p) = 1（剩余）、-1（非剩余）、0（p|a）。

## 应用与联系

- **密码学**：RSA、椭圆曲线密码（ECC）、Diffie-Hellman 密钥交换、ElGamal
- **Hash 函数**：MD5（已破）、SHA-1（已破）、SHA-256
- **数字签名**：RSA 签名、DSA
- **随机数生成**：线性同余生成器（LCG）
- **计算机安全**：整数溢出检测（模运算）
- **编码理论**：有限域上的运算
- **算法**：Miller-Rabin 素性测试 Pollard Rho 大数分解

## 例题

**例 1**：求 gcd(12345, 67890)

```
67890 = 12345 × 5 + 6165
12345 = 6165 × 2 + 15
6165 = 15 × 411 + 0
∴ gcd = 15
```

**例 2**：解同余方程 3x ≡ 6 (mod 9)

gcd(3, 9) = 3，且 3 | 6 ⇒ 有解。
方程化简为 x ≡ 2 (mod 3)。
模 9 下有 3 个解：x ≡ 2, 5, 8 (mod 9)。

**例 3**：求 φ(12)

12 = 2² × 3
φ(12) = 12·(1-1/2)·(1-1/3) = 12·0.5·0.667 = 4

**例 4**：解 CRT 系统：
x ≡ 2 (mod 3)，x ≡ 3 (mod 5)，x ≡ 2 (mod 7)

M = 3·5·7 = 105
M₁ = 35, y₁ = 35⁻¹ mod 3 = 2（因为 35 ≡ 2 mod 3, 2⁻¹ = 2）
M₂ = 21, y₂ = 21⁻¹ mod 5 = 1（21 ≡ 1 mod 5）
M₃ = 15, y₃ = 15⁻¹ mod 7 = 1（15 ≡ 1 mod 7）
x = 2·35·2 + 3·21·1 + 2·15·1 = 140 + 63 + 30 = 233
x ≡ 233 mod 105 = 23
