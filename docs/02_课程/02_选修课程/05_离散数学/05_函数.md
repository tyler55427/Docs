# 五、函数

## 函数的基本概念

### 定义

**函数**（映射）：f: A → B 是 A × B 的子集，满足**唯一性**：∀a ∈ A，∃! b ∈ B 使 (a, b) ∈ f。记 f(a) = b。

- A：定义域（domain）
- B：陪域（codomain）
- f(A) = {f(a) | a ∈ A}：值域（range），是 B 的子集
- f⁻¹(B') = {a ∈ A | f(a) ∈ B'}：原像（preimage）

> 函数 = 特殊的关系（每个定义域元素恰好对应一个值域元素）。

## 函数相等的条件

f: A → B 和 g: C → D 相等当且仅当 A = C、B = D 且 ∀a, f(a) = g(a)。

## 常用记号

- 单射：f: A ↣ B
- 满射：f: A ↠ B
- 双射：f: A ⇔ B（A ↔ B）

## 特殊函数

### 单射（ injective / one-to-one）

∀a₁, a₂ ∈ A，a₁ ≠ a₂ ⇒ f(a₁) ≠ f(a₂)。

等价条件：f(a₁) = f(a₂) ⇒ a₁ = a₂。

## 满射（surjective / onto）

∀b ∈ B，∃a ∈ A 使 f(a) = b。即 f(A) = B。

## 双射（bijective / one-to-one onto）

既是单射又是满射。

**双射的等价条件**：∀b ∈ B，∃! a ∈ A 使 f(a) = b。

## 函数的运算

### 复合

(g ○ f)(a) = g(f(a))

**复合运算的性质**：

- **结合律**：(h ○ g) ○ f = h ○ (g ○ f)
- 单射 + 单射 ⇒ 单射（g ○ f）
- 满射 + 满射 ⇒ 满射（g ○ f）
- **反之不成立**（复合可能单但组成元素不单；反例：常函数）

## 逆函数

若 f: A → B 是双射，则存在唯一的逆函数 f⁻¹: B → A，使得 f⁻¹(f(a)) = a 且 f(f⁻¹(b)) = b。

**双射 ⇔ 存在逆函数**。

**性质**：

- (f⁻¹)⁻¹ = f
- (g ○ f)⁻¹ = f⁻¹ ○ g⁻¹
- 单射 ⇔ 左逆存在；满射 ⇔ 右逆存在

## 特殊函数

### 常函数

f(a) = c（固定 c ∈ B）。

## 恒等函数

id_A(a) = a。

## 特征函数

对于子集 A ⊆ E，χ_A(e) = 1 当 e ∈ A，χ_A(e) = 0 当 e ∉ A。

## 投影函数

π₁(a, b) = a，π₂(a, b) = b。

## 置换（双射 A → A）

有限集合上的双射。n 元集合有 n! 个置换。

## 集合的基数

### 定义

|A| = |B|（等势）：存在双射 f: A → B。
|A| ≤ |B|：存在单射 g: A → B。
|A| < |B|：|A| ≤ |B| 且 |A| ≠ |B|。

## 可数集

**可数集**：与自然数集 ℕ 等势的集合。包含无限可数（ℕ, ℤ, ℚ）和有限集。

**定理**：ℚ 是可数的（对角线枚举）。
**定理**：ℝ 是不可数的（康托尔对角论证）。
**推论**：超越数存在且"几乎所有"实数都是超越数。

## 连续统

|ℝ| = 2^(|ℕ|)，记作 ℵ₁（Cantor）。

## Cantor-Bernstein 定理

若 |A| ≤ |B| 且 |B| ≤ |A|，则 |A| = |B|。

## 基数比较

- |ℕ| = ℵ₀（可数无限）
- |ℝ| = ℵ₁ = 2^ℵ₀
- |P(ℕ)| = |ℝ|
- |ℕ|^|ℕ| = |ℝ|
- ℵ₀ < ℵ₁ < ℵ₂ < ...（Cantor 序列）

> **Cantor 定理**：|A| < |P(A)|（任何集合的幂集都比原集合"更大"）。

## 鸽巢原理（抽屉原理）

### 基本形式

把 n+1 个物体放入 n 个盒子，则至少有一个盒子中有 ≥ 2 个物体。

形式化：若 f: A → B，|A| > n|B|，则 ∃b ∈ B 使 |f⁻¹(b)| ≥ 2。

## 广义鸽巢原理

把 n 个物体放入 k 个盒子，则至少有一个盒子中有 ≥ ⌈n/k⌉ 个物体。

## 加强形式

若 n₁, ..., n_k 是正整数，且 Σ n_i > (k-1)·r，则将 n_i 个物体放入 k 个盒子时，必有一个盒子的物体数 ≥ r+1。

## 应用

- 任何 5 个人中必有 2 个人认识相同数量的人（或不认识相同数量的人）
- 任意 13 个人中至少有 2 个同月同日生（鸽巢：12 个月）
- 任何长度为 n 的序列必有长度为 ⌈log₂ n⌉+1 的单调子序列
- Dirichlet（抽屉）原理：实数逼近定理

## Ramsey 定理（鸽巢原理的推广）

任意 6 人中，要么有 3 人彼此认识，要么有 3 人彼此不认识（R(3,3) = 6）。

**R(m, n)**：使"必有 m 个人两两认识或 n 个人两两不认识"成立的最小人数。

> 鸽巢原理的深度扩展：组合数学中 Ramsey 理论的开端。

## 例题

**例 1**：证明 ℤ × ℤ 与 ℕ 等势（可数）。

构造双射 f(m, n) → 2^{m+1} · 3^{n+1}（质因数编码）。但质因数唯一分解 ⇒ 双射 ⇒ |ℤ × ℤ| = |ℕ|。

**例 2**：用鸽巢原理证明：1~10 中任选 6 个数，必有两个数一个是另一个的倍数。

将 1~10 分成 5 组：{1, 2, 4, 8}（2 的幂次）、{3, 6}（3 的倍数）、{5, 10}（5 的倍数）、{7}、{9}。选 6 > 5 组 ⇒ 必有两数同组，同组中必有一个是另一个的倍数。

**例 3**：证明 f: ℕ → ℝ 不是双射。

反证：设 f(1), f(2), f(3), ... 为 ℝ 的可数子列。构造实数 x：第 i 位小数与 f(i) 的第 i 位不同（加 1 绕开进位）。x 不在数列中 ⇒ f 不是满射。

## 应用与联系

- **算法**：哈希函数（单射设计）、映射归约（MapReduce 的 map/shuffle 阶段）
- **密码学**：双射（加密是双射置换）、伪随机函数（PRF）
- **数据库**：函数依赖 A → B（规范化理论）
- **范畴论**：函数是范畴 Set 的态射；单射/满射/双射是特殊态射
- **可数性**：算法可处理的输入必须是可数集（有限字符串），这与停机问题有深刻联系
