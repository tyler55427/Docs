# 一、命题逻辑

## 命题与联结词

### 命题

**命题**：有**唯一真值**（真 T 或假 F）的陈述句。命题须同时满足：是陈述句 + 真值唯一。

- 例："北京是中国的首都"（T）、"1+1=3"（F）、"x>0"（**不是**命题，因真值依赖 x）
- 反例：疑问句、祈使句、感叹句、悖论（如"这句话是假的"）

**原子命题**：不能再分解的命题（如 p, q, r 表示）。
**复合命题**：由原子命题经联结词组合而成。

### 五个基本联结词

| 联结词 | 符号   | 含义         | 真值表                                   |
| ------ | ------ | ------------ | ---------------------------------------- |
| 否定   | ¬p    | 非 p         | T↔F, F↔T                               |
| 合取   | p ∧ q | p 且 q       | 仅当 p,q 都 T 时为 T                     |
| 析取   | p ∨ q | p 或 q       | 仅当 p,q 都 F 时为 F（**相容或**） |
| 蕴含   | p → q | 若 p 则 q    | 仅当 p=T,q=F 时为 F                      |
| 等价   | p ↔ q | p 当且仅当 q | p,q 同真值时为 T                         |

> **蕴含 p → q 的含义**：
>
> - p 是 q 的**充分条件**，q 是 p 的**必要条件**
> - 等价于 ¬p ∨ q
> - 仅当 p=T, q=F 时为假；其他三种情形（FF, FT, TT）都为真
> - 这是数学证明的基础：证 p → q 即证"假设 p 成立，推出 q 成立"

## 其他常用联结词

- **异或**：p ⊕ q ≡ (p ∧ ¬q) ∨ (¬p ∧ q)（p,q 不同为真）
- **与非**：p ↑ q ≡ ¬(p ∧ q)（Sheffer 竖线）
- **或非**：p ↓ q ≡ ¬(p ∨ q)（Webb 竖线）

> **最小联结词组**：{¬, ∧, ∨}、{¬, ∧}、{¬, →} 都能表达所有联结词（功能完备）。单个联结词中，**NOR（↓）**和**NAND（↑）**各自功能完备。

## 命题公式

### 命题公式的递归定义

- 命题常项/命题变元是命题公式
- 若 A 是命题公式，则 (¬A) 是命题公式
- 若 A, B 是命题公式，则 (A ∧ B), (A ∨ B), (A → B), (A ↔ B) 是命题公式
- 仅由以上有限次应用得到的才是命题公式

## 优先级

¬ > ∧ > ∨ > → > ↔（可用括号改变）

## 真值表

将命题变元的每种赋值组合列出，求出公式的真值。

例：`(p → q) ∧ ¬q → ¬p`（实质蕴含换位律）

| p | q | p→q | ¬q | (p→q)∧¬q | ¬p | ((p→q)∧¬q)→¬p |
| - | - | ---- | --- | ----------- | --- | ------------------ |
| T | T | T    | F   | F           | F   | T                  |
| T | F | F    | T   | F           | F   | T                  |
| F | T | T    | F   | F           | T   | T                  |
| F | F | T    | T   | T           | T   | T                  |

永真式（重言式/Tautology）：所有赋值下真值均为 T。

## 等价与蕴含

### 公式等价

**定义**：A ≡ B 当且仅当对任意赋值，A, B 真值相同（真值表相同）。

## 基本等价公式

**幂等律**：

- A ∨ A ≡ A
- A ∧ A ≡ A

**交换律**：

- A ∨ B ≡ B ∨ A
- A ∧ B ≡ B ∧ A

**结合律**：

- (A ∨ B) ∨ C ≡ A ∨ (B ∨ C)
- (A ∧ B) ∧ C ≡ A ∧ (B ∧ C)

**分配律**：

- A ∧ (B ∨ C) ≡ (A ∧ B) ∨ (A ∧ C)
- A ∨ (B ∧ C) ≡ (A ∨ B) ∧ (A ∨ C)

**德摩根律（De Morgan）**：

- ¬(A ∨ B) ≡ ¬A ∧ ¬B
- ¬(A ∧ B) ≡ ¬A ∨ ¬B

**吸收律**：

- A ∨ (A ∧ B) ≡ A
- A ∧ (A ∨ B) ≡ A

**零律 / 同一律**：

- A ∨ 0 ≡ A，A ∧ 1 ≡ A
- A ∨ 1 ≡ 1，A ∧ 0 ≡ 0

**双重否定**：

- ¬¬A ≡ A

**补律**（设 B = ¬A）：

- A ∨ ¬A ≡ 1（排中律）
- A ∧ ¬A ≡ 0（矛盾律）

**蕴含-析取转换**：

- A → B ≡ ¬A ∨ B
- A ↔ B ≡ (A → B) ∧ (B → A) ≡ (¬A ∨ B) ∧ (¬B ∨ A)

**假言易位 / 换位**：

- A → B ≡ ¬B → ¬A

**逆否**：

- A → B ≡ ¬A ∨ B（直接）

**等价否定**：

- ¬(A → B) ≡ A ∧ ¬B
- ¬(A ↔ B) ≡ A ⊕ B

## 对偶原理

**定义**：公式 A 的对偶 A* 是将 A 中 ∧ ↔ ∨、T ↔ F、其他保持不变。

**对偶原理**：A ≡ B 当且仅当 A* ≡ B*。永真式的对偶仍是永真式（但真值表的 0/1 互换）。

## 蕴含（永真蕴含）

**定义**：A ⇒ B（永真蕴含）当且仅当 A → B 是永真式，即 A 为 T 时 B 必为 T。

**常用推理规则**：

- **假言推理**（Modus Ponens）：A ∧ (A → B) ⇒ B
- **拒取式**（Modus Tollens）：¬B ∧ (A → B) ⇒ ¬A
- **假言三段论**（HS）：(A → B) ∧ (B → C) ⇒ A → C
- **析取三段论**（DS）：¬A ∧ (A ∨ B) ⇒ B
- **附加律**：A ⇒ A ∨ B
- **化简律**：A ∧ B ⇒ A
- **假言易位**：A → B ⇒ ¬B → ¬A

## 反证法（CP 规则）

要证 A → B，等价于证 A ∧ ¬B ⇒ F。

逻辑上：A → B ≡ ¬(A ∧ ¬B)

## 范式

### 文字与简单析取式

- **文字**：命题变元或其否定（L 或 ¬L）
- **简单析取式（子句）**：若干文字的析取（k 个文字为 k-子句）
- **简单合取式**：若干文字的合取

## 合取范式（CNF）

**形如**：A₁ ∧ A₂ ∧ ... ∧ Aₙ，其中 Aᵢ 是简单析取式（子句）。

例：(¬p ∨ q) ∧ (p ∨ ¬r)

> 任意命题公式都等价于一个合取范式（用分配律、蕴含-析取转换、德摩根律展开）。

## 析取范式（DNF）

**形如**：A₁ ∨ A₂ ∨ ... ∨ Aₙ，其中 Aᵢ 是简单合取式（蕴含项）。

例：(p ∧ q) ∨ (¬p ∧ r)

## 主范式（标准范式）

- **主合取范式**：CNF 中每个简单析取式**包含所有变元**（或其否定）
- **主析取范式**：DNF 中每个简单合取式**包含所有变元**（或其否定）

主合取范式是若干**极大项**（含 n 个文字、对应一种使公式为假的赋值）的合取；主析取范式是若干**极小项**（含 n 个文字、对应一种使公式为真的赋值）的析取。

**求主析取范式**（极小项之和）：

1. 化为 DNF（用分配律展开）
2. 用吸收律等化简
3. 缺少变元的合取项：用 P ∨ ¬P ≡ 1 补全

或更系统的方法：**真值表法** —— 把真值为 T 的所有赋值对应的极小项析取。

**n 个变元有 2ⁿ 个极小项 / 极大项**。

例：求 ¬(p → q) 的主析取范式
¬(p → q) ≡ ¬(¬p ∨ q) ≡ p ∧ ¬q （缺变元 r）

只有 p=T, q=F 时为 T。n=2 时主析取范式就是 (p ∧ ¬q)。

例：求 ¬(p → q) 的主合取范式
n=2，有 4 个极大项，其余 3 种赋值 (T,T),(F,T),(F,F) 都使公式为 F，对应 3 个极大项的合取：
M_{TT} ∧ M_{FT} ∧ M_{FF} = (¬p ∨ ¬q) ∧ (p ∨ ¬q) ∧ (p ∨ q)

**性质**：

- 主析取范式 / 主合取范式**唯一**（除去变元顺序和项顺序）
- 永真式 ⇔ 主合取范式为空（0 个极大项）
- 永假式 ⇔ 主析取范式为空（0 个极小项）

## 推理理论

### 自然推理系统

基本推理规则：

- 前提引入（P）：可随时引入前提
- 结论引入（T）：可随时引入已证的结论
- **假言推理**（MP / 分离规则）：A, A → B ⊢ B
- **拒取式**（MT）：¬B, A → B ⊢ ¬A
- 假言三段论（HS）：A → B, B → C ⊢ A → C
- 附加（∨I）：A ⊢ A ∨ B
- 化简（∧E）：A ∧ B ⊢ A
- 合取引入（∧I）：A, B ⊢ A ∧ B
- 析取三段论（DS）：A ∨ B, ¬A ⊢ B
- **CP 规则**：要证 A → B，可在前提中加 A，再证 B
- 反证法（¬¬E / RAA）：¬A → F ⊢ A（双否消去）

## 永真蕴含的证明

**方法 1**：真值表法（机械但繁琐）。
**方法 2**：推理规则链（前提 → 结论的演绎证明）。
**方法 3**：等价变换（用等价公式）。

## 反证法（CP / RAA）

要证前提 Γ ⊢ A：

- 假设 ¬A，加入前提
- 推出矛盾（如推出 F）
- 由矛盾律反证得 A

这是数学中**反证法**的形式化。

## 应用与联系

### 逻辑门电路

| 命题运算 | 逻辑门  |
| -------- | ------- |
| ¬p      | NOT     |
| p ∧ q   | AND     |
| p ∨ q   | OR      |
| p → q   | IMPLIES |
| p ⊕ q   | XOR     |

## 程序断言

在程序验证中，三元断言 `{P} S {Q}` 表示"若执行 S 前 P 成立，则执行后 Q 成立"。证明 `{P} S {Q}` 的核心就是验证 p → q 形式的逻辑蕴含。

## SAT 问题

判断命题公式是否可满足（是否存在赋值使其为 T）—— **SAT** 是第一个被证明的 NP 完全问题（Cook 定理，1971）。实际 SAT 求解器使用 CNF + DPLL / CDCL 算法，与合取范式紧密相关。

## 例题

**例 1**：化 (p ∧ ¬q) ∨ (¬p ∧ q) ∨ (p ∧ q) 为主析取范式。

```
(p ∧ ¬q) ∨ (¬p ∧ q) ∨ (p ∧ q)
= (p ∧ ¬q ∧ (r ∨ ¬r)) ∨ (¬p ∧ q ∧ (r ∨ ¬r)) ∨ (p ∧ q ∧ (r ∨ ¬r))   [3 个变元 p,q,r]
= m_{100} ∨ m_{010} ∨ m_{110} ∨ m_{011} ∨ m_{111}（展开后）
```

**例 2**：证明 (p → q) ∧ (q → r) ⇒ (p → r)（假言三段论）。

```
p → q        (前提 1)
q → r        (前提 2)
p            (附加前提，CP)
q            (由 MP)
r            (由 MP)
∴ p → r      (CP)
```
