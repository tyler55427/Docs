# 三、集合论

## 集合的基本概念

### 集合与元素

**集合**：由确定的、彼此可区分的对象组成的无序整体。

- 元素（成员）：集合中的对象
- 记号：x ∈ A（x 属于 A），x ∉ A（x 不属于 A）

**集合的确定性**：任意对象 x，"x ∈ A" 是有唯一真值的命题。
**集合的互异性**：同一集合中元素不重复。
**集合的无序性**：{a, b} = {b, a}。

**表示方法**：

- **列举法**：A = {1, 2, 3}, B = {a, b, c}
- **描述法（刻画法）**：A = {x | P(x)} —— 满足谓词 P 的所有 x

## 常用特殊集合

| 集合     | 记号     | 说明                          |
| -------- | -------- | ----------------------------- |
| 空集     | ∅ 或 {} | 没有任何元素                  |
| 全集     | E 或 U   | 讨论范围内所有对象            |
| 自然数集 | ℕ 或 N  | {0, 1, 2, ...} 或 {1, 2, ...} |
| 整数集   | ℤ 或 Z  | {..., -2, -1, 0, 1, 2, ...}   |
| 有理数集 | ℚ 或 Q  | p/q (q≠0)                    |
| 实数集   | ℝ 或 R  | 全部实数                      |
| 复数集   | ℂ 或 C  | a+bi                          |

> 空集是任何集合的子集：∀A, ∅ ⊆ A。

## 集合的表示方式

**Roster 法**：列出所有元素（A = {1, 2, 3}）。
**Set-Builder 法**：用条件刻画（A = {x ∈ ℕ | x 是偶数}）。

## 集合的关系

### 子集

**定义**：A ⊆ B（**真子集**记 A ⊂ B 或 A ⊊ B）当且仅当 ∀x (x ∈ A → x ∈ B)。

**性质**：

- A ⊆ A（自反）
- A ⊆ B, B ⊆ A ⇒ A = B（反对称）
- A ⊆ B, B ⊆ C ⇒ A ⊆ C（传递）
- ∅ ⊆ A（对任意 A）

## 集合相等

**定义**：A = B 当且仅当 A ⊆ B 且 B ⊆ A（即 ∀x (x ∈ A ↔ x ∈ B)）。

## 真子集

A ⊊ B 当且仅当 A ⊆ B 且 A ≠ B。

## 幂集

**定义**：A 的幂集 P(A) = {X | X ⊆ A} —— A 的所有子集的集合。

| |A| | |P(A)| |
|-----|-------|
| 0 | 1（只有 ∅）|
| n | 2ⁿ |

> 命题：**不存在以自身为元素的集合**（避免罗素悖论：R = {X | X ∉ X}）。

## 集合运算

### 基本运算

**并集**：A ∪ B = {x | x ∈ A ∨ x ∈ B}
**交集**：A ∩ B = {x | x ∈ A ∧ x ∈ B}
**差集**：A - B = {x | x ∈ A ∧ x ∉ B}（也称 B 在 A 中的余集）
**补集**（关于 E）：~A = E - A = {x | x ∈ E ∧ x ∉ A}
**对称差**：A ⊕ B = (A - B) ∪ (B - A) = (A ∪ B) - (A ∩ B)

## 文氏图

用平面区域直观表示集合及其运算：

- 矩形 = 全集 E
- 圆 = 集合 A, B
- 重叠 = 交集
- 外部 = 补集

## 集合恒等式

**幂等律**：

- A ∪ A = A
- A ∩ A = A

**交换律 / 结合律**：

- A ∪ B = B ∪ A
- A ∩ B = B ∩ A
- (A ∪ B) ∪ C = A ∪ (B ∪ C)
- (A ∩ B) ∩ C = A ∩ (B ∩ C)

**分配律**：

- A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
- A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)

**德摩根律**：

- ~(A ∪ B) = ~A ∩ ~B
- ~(A ∩ B) = ~A ∪ ~B

**吸收律**：

- A ∪ (A ∩ B) = A
- A ∩ (A ∪ B) = A

**同一律 / 零律**：

- A ∪ ∅ = A，A ∩ E = A
- A ∪ E = E，A ∩ ∅ = ∅

**补律**：

- A ∪ ~A = E
- A ∩ ~A = ∅
- ~(~A) = A（双重否定）

**差集公式**：

- A - B = A ∩ ~B
- A - (B ∪ C) = (A - B) ∩ (A - C)
- A - (B ∩ C) = (A - B) ∪ (A - C)
- (A ∪ B) - C = (A - C) ∪ (B - C)
- (A ∩ B) - C = (A - C) ∩ (B - C)

**对称差性质**：

- A ⊕ B = (A ∪ B) - (A ∩ B)
- A ⊕ B = (A - B) ∪ (B - A)
- A ⊕ ∅ = A，A ⊕ A = ∅
- A ⊕ B = B ⊕ A（交换）
- (A ⊕ B) ⊕ C = A ⊕ (B ⊕ C)（结合）
- A ∩ (B ⊕ C) = (A ∩ B) ⊕ (A ∩ C)（分配）

## 笛卡尔积

### 定义

**有序 n 元组**：(a₁, a₂, ..., aₙ)：顺序固定。

- (a, b) ≠ (b, a)（a≠b 时）
- (a, b) = (c, d) ⇔ a = c 且 b = d

**笛卡尔积**（直积）：

- A × B = {(a, b) | a ∈ A, b ∈ B}
- A₁ × A₂ × ... × Aₙ = {(a₁, a₂, ..., aₙ) | aᵢ ∈ Aᵢ}

## 性质

- A × ∅ = ∅（任何集合与空集的笛卡尔积为空）
- |A × B| = |A| · |B|（有限集）
- A × (B ∪ C) = (A × B) ∪ (A × C)（分配）
- A × (B ∩ C) = (A × B) ∩ (A × C)
- 笛卡尔积**不满足交换律**：A × B ≠ B × A（A, B 非空时）
- 不满足结合律：(A × B) × C ≠ A × (B × C)

## 容斥原理

### 两集合

|A ∪ B| = |A| + |B| - |A ∩ B|

## 三集合

|A ∪ B ∪ C| = |A| + |B| + |C|
              - |A ∩ B| - |A ∩ C| - |B ∩ C|
              + |A ∩ B ∩ C|

## 一般形式

$$
\left|\bigcup_{i=1}^{n} A_i\right| = \sum_{i=1}^{n} |A_i| - \sum_{1 \le i < j \le n} |A_i \cap A_j| + \sum_{1 \le i < j < k \le n} |A_i \cap A_j \cap A_k| - \cdots + (-1)^{n+1}|A_1 \cap \cdots \cap A_n|
$$

**核心思想**：加所有单集 → 减去两两交集（加多了） → 加回三重交集（减多了） → ...

## 应用

- 错排问题：D(n) = n! · Σ(-1)ᵏ/k!（k=0..n）
- Euler φ 函数：φ(n) = n · Π(1 - 1/p)（p 过 n 的素因子）
- 哈密顿路径 / 路径计数（去重）
- 棋盘上的非攻击放置问题（去重）

## 集合族与广义运算

### 集合族

**集合族**：以集合为元素的集合。

- 例：F = {{1, 2}, {2, 3}, {1, 3}} 是集合族
- 指标族：F = {Aᵢ | i ∈ I}，I 是索引集

## 广义并 / 交

**广义并**：

$$
\bigcup_{i=1}^{n} A_i = \{x \mid \exists i, x \in A_i\}
$$

**广义交**：

$$
\bigcap_{i=1}^{n} A_i = \{x \mid \forall i, x \in A_i\}
$$

**广义分配律**：

$$
\bigcap_{i \in I} A_i \cup B = \bigcup_{i \in I} (A_i \cup B)
$$

$$
\bigcup_{i \in I} A_i \cap B = \bigcap_{i \in I} (A_i \cap B)
$$

## 公理化集合论（ZFC）

朴素集合论存在罗素悖论（"由所有不包含自身的集合组成的集合 R = {X | X ∉ X}，则 R ∈ R ⇔ R ∉ R"）。

**ZFC 公理系统**（最常用的集合论公理化）：

- 外延公理、分离公理模式、配对公理、并公理、幂集公理
- 无穷公理、替换公理模式、正则公理、选择公理（AC）

> 类比：ZFC 是现代数学的"基础"——大多数数学对象都能在 ZFC 内构造。

## 例题

**例 1**：证明 A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)

```
∀x [x ∈ A ∪ (B ∩ C) ⇔ x ∈ A ∨ (x ∈ B ∧ x ∈ C)]
        ⇔ (x ∈ A ∨ x ∈ B) ∧ (x ∈ A ∨ x ∈ C)  [分配律]
        ⇔ x ∈ (A ∪ B) ∧ x ∈ (A ∪ C)
        ⇔ x ∈ (A ∪ B) ∩ (A ∪ C)
∴ A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)
```

**例 2**：1~100 中能被 2 或 3 整除的数有几个？

A = 2 的倍数：|A| = 50
B = 3 的倍数：|B| = 33
A ∩ B = 6 的倍数：|A ∩ B| = 16

|A ∪ B| = 50 + 33 - 16 = 67

**例 3**：求 26 个英文字母的全排列中，"QWERTY" 始终按原顺序出现的排列数。

将 QWERTY 视为 1 个"超级字母"，则共有 21 个字符（20 个其他字母 + 1 个 QWERTY），但其中其他 20 个字母可重复（因为位置间还有空隙）。

实际上是"在 26 个位置中选 6 个位置给 QWERTY 占据（顺序固定），剩下 20 个位置填其他字母"：
C(26, 6) · 20!（如果字母不重复）

如果字母可重复，则更复杂（容斥）。

## 应用与联系

- **数据库理论**：关系（表）= 笛卡尔积的子集；SELECT = 投影 + 选择；JOIN = 集合运算 + 笛卡尔积。
- **算法**：集合表示（位图、哈希集）、并查集、集合覆盖问题。
- **概率论**：概率空间 = 集合论框架（事件 = 集合，概率 = 测度）。
- **类型论**：类型可视为集合（值集合）。
