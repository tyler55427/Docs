# 二、谓词逻辑

## 谓词与量词

### 谓词

**谓词**：描述对象性质或对象之间关系的符号。含 n 个个体变元的谓词称为 **n 元谓词**，记 P(x₁, ..., xₙ)。

- 一元谓词：P(x) 表示"x 是素数"
- 二元谓词：Q(x, y) 表示"x < y"
- 三元谓词：R(x, y, z) 表示"x + y = z"

**命题函数（谓词填式）**：将谓词中的某些变元用**个体常项**或**函数**替换后得到的式子。

> 一元谓词 + 一个个体 = 命题（带真值的陈述句）

## 个体域（论域）

谓词中变元的取值范围。所有变元都需指明个体域，**默认非空**。

## 量词

**全称量词** ∀x P(x)：对个体域中**每个** x，P(x) 都成立。
**存在量词** ∃x P(x)：个体域中**至少有一个** x 使 P(x) 成立。

| 量词     | 自然语言            | 真假判定                       |
| -------- | ------------------- | ------------------------------ |
| ∀x P(x) | 对所有 x, P(x) 成立 | 找不到反例 → T；找到反例 → F |
| ∃x P(x) | 存在 x 使 P(x) 成立 | 找到实例 → T；没有实例 → F   |

## 量词作用域：量词后到第一个逻辑联结词

例：∀x P(x) → Q(x) 中，∀ 作用域是 P(x)（不包括 Q(x)）；而 ∀x (P(x) → Q(x)) 中，∀ 作用域是整个蕴含。

## 谓词公式

### 项与公式

**项**（递归定义）：

- 个体常项、个体变元是项
- 若 f 是 n 元函数符号，t₁, ..., tₙ 是项，则 f(t₁, ..., tₙ) 是项

**原子公式**：

- 若 P 是 n 元谓词符号，t₁, ..., tₙ 是项，则 P(t₁, ..., tₙ) 是原子公式

**谓词公式**（递归定义）：

- 原子公式是公式
- 若 A 是公式，则 (¬A) 是公式
- 若 A, B 是公式，则 (A ∧ B), (A ∨ B), (A → B), (A ↔ B) 是公式
- 若 A 是公式，x 是个体变元，则 (∀x A), (∃x A) 是公式

## 约束变元与自由变元

- **约束变元**：被量词约束的变元（出现位置在量词作用域内）
- **自由变元**：未被约束的变元

例：∀x (P(x) → Q(x, y)) 中 x 是约束变元，y 是自由变元。
因为 y 不受 ∀x 约束（在量词作用域内但形式上是"被 ∀ 关联"的只有 x）。

> 注：括号嵌套时，要看是否真的在 ∀ 的作用域内。

## 闭式（语句）

不含**自由变元**的公式。闭式是一个真值确定的命题。

## 改名规则

**约束变元换名**（dummy renaming）：可对约束变元做统一换名（如 ∀x P(x) → ∀y P(y)），自由变元不能改名。

## 量词等价与蕴含

### 量词否定（量词对偶）

- ¬∀x P(x) ≡ ∃x ¬P(x)
- ¬∃x P(x) ≡ ∀x ¬P(x)

> "并非所有 x 都满足 P" ⇔ "存在 x 使 P 不成立"

## 量词辖域扩张/收缩

**扩张**（前提：x 不在 Q 中自由出现）：

- ∀x (P(x) ∧ Q) ≡ (∀x P(x)) ∧ Q
- ∀x (P(x) ∨ Q) ≡ (∀x P(x)) ∨ Q
- ∃x (P(x) ∧ Q) ≡ (∃x P(x)) ∧ Q
- ∃x (P(x) ∨ Q) ≡ (∃x P(x)) ∨ Q

**分配律**：

- ∀x (P(x) ∧ Q(x)) ≡ (∀x P(x)) ∧ (∀x Q(x))
- ∃x (P(x) ∨ Q(x)) ≡ (∃x P(x)) ∨ (∃x Q(x))
- ∀x (P(x) → Q(x)) ≡ (∀x P(x)) → (∃x Q(x)) 不成立！，需单独分析
- ∀x P(x) → ∀y Q(y) ≡ ∀x ∀y (P(x) → Q(y))（x,y 无关时）
- ∃x P(x) → ∀y Q(y) ≡ ∀y (∃x P(x) → Q(y))（∃ 在 → 后、∀ 在前时）

## 量词交换

- ∀x ∀y P(x, y) ≡ ∀y ∀x P(x, y)
- ∃x ∃y P(x, y) ≡ ∃y ∃x P(x, y)
- ¬(∀x ∃y P(x, y) ≡ ∃x ∀y P(x, y))（**两者不等价**！）

## 量词的蕴含关系

- ∀x P(x) ⇒ ∃x P(x)（前提：个体域非空）

**其他**：

- ∀x P(x) ⇒ P(c)（c 是任意个体，UI 规则）
- P(c) ⇒ ∃x P(x)（EG 规则）
- ∀x P(x) ⇒ ∀y P(y)（换名规则）

## 前束范式（Prenex Normal Form）

**定义**：形如 (Q₁x₁)(Q₂x₂)...(Qₖxₖ) M 的公式，其中 Qᵢ ∈ {∀, ∃}，M 是无量词的合取范式（或析取范式）—— 即**量词全部在前、矩阵 M 在后**的形式。

**化为前束范式的步骤**：

1. 消去蕴含、等价：用 A → B ≡ ¬A ∨ B，A ↔ B ≡ (A → B) ∧ (B → A)
2. 减少否定符号：用德摩根律和量词否定至原子
3. 改名：使每个量词的约束变元不同名（避免冲突）
4. 提取量词到公式最前面：利用量词辖域扩张/收缩律

**例**：化 (∀x P(x) → ∃y Q(y)) 为前束范式

```
¬(∀x P(x)) ∨ ∃y Q(y)                       [消去 →]
∃x ¬P(x) ∨ ∃y Q(y)                         [量词否定]
∃x ∃y (¬P(x) ∨ Q(y))                       [提取量词]
```

> 注：Skolem 范式（消去 ∃ 后）用于自动定理证明。

## 自然推理系统（谓词逻辑）

### 基本规则

**全称量词消去**（UI / ∀E）：∀x P(x) ⊢ P(c)（c 是任意项）
**全称量词引入**（UG / ∀I）：若在任意 c 下都有 P(c) ⊢ Q(c)，则 ⊢ ∀x Q(x)
**存在量词消去**（EI / ∃E）：∃x P(x) ⊢ P(c)，其中 c 是新引入的常项（不能在其他假设中出现）
**存在量词引入**（EG / ∃I）：P(c) ⊢ ∃x P(x)

> **EI 的限制**：引入的 c 必须"新"，不能与已有个体冲突（否则会导致 ∃ 失去存在性意义）。

## 推理示例

**例 1**：证明 ∀x (P(x) → Q(x)), ∃x P(x) ⊢ ∃x Q(x)

```
1. ∀x (P(x) → Q(x))           前提
2. ∃x P(x)                      前提
3. P(c)                         ∃E (2)，c 新
4. P(c) → Q(c)                  ∀E (1)
5. Q(c)                         MP (3, 4)
6. ∃x Q(x)                      ∃I (5)
```

**例 2**：证明 ∀x (P(x) → Q(x)), ¬∃x Q(x) ⊢ ∀x ¬P(x)

```
1. ∀x (P(x) → Q(x))            前提
2. ¬∃x Q(x)                     前提
3. ∀x ¬Q(x)                     量词否定 (2)
4. ¬Q(c)                        ∀E (3)
5. P(c) → Q(c)                  ∀E (1)
6. ¬P(c)                        MT (4, 5)
7. ∀x ¬P(x)                     ∀I (6)
```

## 一阶逻辑的局限

**哥德尔不完备定理**（1931）：

- **第一定理**：任何包含初等数论的一致（一阶）形式系统中，都存在一个真但不可证明的命题。
- **第二定理**：这样的系统不能证明自身的无矛盾性。

**含义**：不存在一个"通用、一致、可判定"的形式系统能完全刻画自然数算术。这对"是否能机械化所有数学推理"给出根本性否定。

> 类比：[算法可计算性](../04_计算机课程/) 中停机问题的不可判定性，与哥德尔不完备性有深刻联系（两者都是递归可枚举集的真子集）。

## 应用与联系

### 数据库查询（关系演算）

元组关系演算、域关系表达式 —— 谓词 + 量词 → SQL 的 WHERE / EXISTS / FOR ALL。

## 程序验证

Hoare 逻辑 `{P} S {Q}` 中，循环不变量 P 通常用 ∀ 表达（"对所有循环变量 i，P 成立"）。

## 自动定理证明

定理证明器（Isabelle、Coq、Lean）建立在谓词逻辑 + 高阶逻辑 + 类型论基础上。

## 形式语义

指称语义、操作语义用谓词逻辑定义程序的等价性。

> 类比：[计算机理论](../04_计算机课程/) 中，可计算性理论、形式语言、自动机都建立在一阶逻辑之上。
