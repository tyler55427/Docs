# 四、关系

## 二元关系

### 定义

**笛卡尔积的子集**：A × B 的子集 R 称为 A 到 B 的**二元关系**。记 aRb 表示 (a, b) ∈ R。

**关系矩阵**：若 A = {a₁,...,aₘ}，B = {b₁,...,bₙ}，则 R 对应一个 m×n 的 0-1 矩阵 M_R，其中 M_R[i][j] = 1 当且仅当 aᵢ R bⱼ。

**关系图**：有向图 G = (V, E)，V 是顶点（A ∪ B），E 是有向边 (a, b) ∈ R。

## 特殊关系

- **空关系**：∅（无任何对应）
- **全域关系**：A × B（所有可能对应）
- **恒等关系**：I_A = {(a, a) | a ∈ A}
- **对角关系**：{(a, a) | a ∈ A}（集合 A 上的恒等关系）

## 关系的性质

设 R 是 A 上的二元关系（定义域和值域都是 A）：

| 性质             | 定义                  | 关系矩阵特征             | 关系图特征               |
| ---------------- | --------------------- | ------------------------ | ------------------------ |
| **自反**   | ∀a ∈ A, aRa         | 对角线全 1               | 每个顶点有自环           |
| **反自反** | ∀a ∈ A, (a, a) ∉ R | 对角线全 0               | 每个顶点无自环           |
| **对称**   | aRb → bRa            | M = Mᵀ                  | 无单向边对               |
| **反对称** | aRb ∧ bRa → a = b   | M[i][j] = M[j][i] ⇒ i=j | 同一对顶点最多一条单向边 |
| **传递**   | aRb ∧ bRc → aRc     | M³ ⊆ M                 | 路径存在则直接边存在     |

> 对称与反对称不互斥：A = ∅ 时既对称又反对称。
> 自反与反自反：若 A 非空，则不可能同时满足。

**常见判定**：

- 自反：I_A ⊆ R
- 对称：R = R⁻¹
- 反对称：R ∩ R⁻¹ ⊆ I_A
- 传递：R ○ R ⊆ R

## 闭包

对 A 上的关系 R，找到包含 R 的最小关系 S，使其满足特定性质：

- **自反闭包** r(R)：添加最少对使自反（加 I_A）
- **对称闭包** s(R)：添加最少对使对称（加 R⁻¹）
- **传递闭包** t(R)：添加最少对使传递（添加路径两端点的直接对应）

**传递闭包**的等价定义：R 的传递闭包 t(R) = R ∪ R² ∪ R³ ∪ ...（有限次停止）。

**Warshall 算法**：在 O(n³) 时间内求传递闭包的关系矩阵。

## 关系的运算

### 基本运算

- **并** R ∪ S
- **交** R ∩ S
- **补** ~R = (A × A) - R
- **复合** R ○ S：a(R ○ S)c ⇔ ∃b (aRb ∧ bSc)
- **逆** R⁻¹：bR⁻¹a ⇔ aRb

## 复合的性质

- (R ○ S) ○ T = R ○ (S ○ T)（结合律）
- (R ○ S)⁻¹ = S⁻¹ ○ R⁻¹
- R ○ (S ∪ T) = (R ○ S) ∪ (R ○ T)
- Rⁿ = R ○ R ○ ... ○ R（n 次复合）

**性质传递**：

- R, S 自反 ⇒ R ○ S 自反
- R, S 对称 ⇒ R ○ S 对称（不成立！反例：R = {(1,2)}，S = {(2,1)} 都对称但复合不对称）
- R, S 传递 ⇒ R ○ S 传递（不成立！反例：R = {(1,2)}，S = {(2,3)} 都传递但复合为空）

## 等价关系

### 定义

R 是 A 上的**等价关系**当且仅当 R 是**自反、对称、传递**的。

**等价类**：[a]_R = {x ∈ A | xRa} —— 与 a 等价的全体元素。

**商集**：A/R = {[a]_R | a ∈ A} —— 所有等价类的集合。

## 等价关系与划分

**划分**：将集合 A 分成若干互不相交的非空子集，这些子集的并为 A。

**定理**：A 上的等价关系 R ⇔ A 的一个划分（每个等价类是一个块）。

**自然映射**：π: A → A/R，a ↦ [a]_R。

## 典型等价关系

- **模 n 同余**：a ≡ b (mod n) —— 余数相同
- **同余类环**：ℤ/nℤ
- **多面体全等/相似**：几何中的等价类
- **整数加法群模 n**：ℤ_n

**例**：ℤ 上模 3 同余关系 ≡₃：

- 等价类：[0] = {..., -6, -3, 0, 3, 6, ...}
- [1] = {..., -5, -2, 1, 4, 7, ...}
- [2] = {..., -4, -1, 2, 5, 8, ...}
- 商集 ℤ/≡₃ = {[0], [1], [2]}

## 偏序关系

### 定义

R 是 A 上的**偏序关系**当且仅当 R 是**自反、反对称、传递**的。

记 a ≼ b 表示 a ≤ b（偏序中）。
**(a, b) ∈ R 记作 a ≤ b**。

**可比**：若 ∀a, b ∈ A，要么 a ≤ b 要么 b ≤ a，则 a, b **可比**。
**全序 / 线序**：所有元素两两可比。
**严格偏序**：< 是反自反、传递的（去掉自环的偏序）。

## 哈斯图（Hasse Diagram）

表示偏序的简化关系图：

- 省去自环
- 省去可传递推出的边（上尖方向）
- 若 a ≤ b 且 a ≠ b，则 a 在 b 下方

## 特殊元素

**极小 / 极元**：没有元素严格小于 / 大于它的元素。
**最小 / 最大元**：小于 / 大于等于所有其他元素的元素。

```
极小元：{a | ¬∃x (x < a)}      最大元：{a | ¬∃x (a < x)}
最小元：{a | ∀x (a ≤ x)}      最大元：{a | ∀x (x ≤ a)}
```

**上界 / 下界**：偏序子集 S 的上界是"≥ S 中所有元素"的所有元素。
**最小上界（上确界）**：所有上界中的最小元。
**最大下界（下确界）**：所有下界中的最大元。

## 典型偏序

- **集合包含**：⊆（非空集合族）
- **整数除法**：a | b（a 整除 b）
- **程序模块依赖**：偏序

## 相容关系

**相容关系**：A 上的自反、对称关系（非传递要求）。

**相容类**：C 是极大相容类 —— C 是相容的且加入任何元素就不相容了。

用于**词类分析**（如词组搭配限制）和**状态机**。

## 合成与数据库

**复合关系** R ○ S 在数据库中对应"JOIN + SELECT"：

- A → B 的关系 R 和 B → C 的关系 S
- R ○ S 是 A → C 的合成关系（经由 B 的两跳路径）

**关系代数**是关系数据库的理论基础：选择(σ)、投影(π)、并(∪)、差(-)、笛卡尔积(×)、连接(⋈)、除(÷)。

> 类比：关系代数 ↔ SQL；偏序/等价 ↔ 层次数据/XML/JSON 树结构。
