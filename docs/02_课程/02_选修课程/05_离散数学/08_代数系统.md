# 八、代数系统

## 代数运算

### 定义

设 A 为非空集合，**n 元运算** f: Aⁿ → A（A 的 n 元素映射到 A）。
**二元运算**：* : A × A → A。

**封闭**：运算结果仍在 A 中。

## 运算的性质

| 性质             | 定义                                     |
| ---------------- | ---------------------------------------- |
| **结合律** | (a * b) * c = a * (b * c)                |
| **交换律** | a * b = b * a                            |
| **幂等律** | a * a = a                                |
| **分配律** | a · (b + c) = a·b + a·c（对 · 和 +） |
| **吸收律** | a ⋆ (a ⋀ b) = a（对 · 和 +）          |
| **单位元** | ∃e, e * a = a * e = a                   |
| **零元**   | ∃θ, θ * a = a * θ = θ               |
| **逆元**   | ∀a, ∃a⁻¹, a * a⁻¹ = a⁻¹ * a = e  |

> **左/右单位元**：e*a=a（左单位元）/ a*e=a（右单位元）。若左右单位元都存在则相等。

## 同态与同构

**同态**：设 * : A → A'，若 ∀a,b, f(a * b) = f(a) *' f(b)，则 f 为同态。

- 单同态（单射）、满同态（满射）
- **同构**：双射同态（f: A → A' 为双射）

**同余关系**：保持运算的等价关系。

## 半群与独异点

### 半群

满足**结合律**的二元运算的代数系统 (A, *)。

## 独异点（含单位元的半群）

满足结合律 + 存在**单位元** e。

**例**：

- (ℕ, +) 是独异点（单位元 0）
- (ℕ, ·) 是独异点（单位元 1）
- (ℤ, +) 是独异点（单位元 0）
- (ℤ, ·) 是独异点（单位元 1）

## 群

### 定义

**群** (G, *)：半群 + 存在单位元 + 每个元素有逆元。

** Abel 群（交换群）**：还满足交换律。

## 群的性质

- **唯一单位元**：若 e, e' 都是单位元，则 e = e'
- **唯一逆元**：若 b, c 都是 a 的逆元，则 b = c
- **可约律**：a * b = a * c ⇒ b = c（左可约）；b * a = c * a ⇒ b = c（右可约）
- **方程求解**：∀a,b ∈ G，x * a = b 有唯一解 x = b * a⁻¹

## 有限群

**有限群**：|G| = n < ∞。

**循环群**：∃a ∈ G 使 G = ⟨a⟩ = {aⁿ | n ∈ ℤ}，a 称为**生成元**。

**Cayley 定理**：任意有限群同构于某个对称群 Sₙ 的子群（|G| = n）。

## Lagrange 定理

若 G 是有限群，H 是 G 的子群，则 |H| 整除 |G|。

**推论**：

- |G| = n，a ∈ G，则 a 的阶 |⟨a⟩| 整除 n
- **素数阶群** ⇔ 必为循环群

## 陪集

**左陪集**：aH = {a * h | h ∈ H}
**右陪集**：Ha = {h * a | h ∈ H}

**性质**：

- |aH| = |H|
- aH = bH ⇔ a⁻¹b ∈ H ⇔ b ∈ aH
- H 的左右陪集数相等（指数 |G:H| = |G|/|H|）

## 正规子群与商群

**正规子群**：∀a ∈ G，aH = Ha（H 是 G 的正规子群 ⇔ H 的所有左陪集 = 右陪集）

**商群**：G/H = {aH | a ∈ G}，运算 (aH)(bH) = (ab)H。

- |G/H| = |G|/|H|
- G/H 是群

## 群的同态基本定理

- **同态核**：ker f = {a ∈ G | f(a) = e'} 是 G 的正规子群
- **像**：Im f 是 G' 的子群
- **同构**：G/ker f ≅ Im f ⊆ G'

> **第一同构定理**：G/H ≅ Im f

## 环与域

### 环

**(R, +, ·)**：加法构成 Abel 群 + 乘法构成半群 + 乘法对加法分配。

**例**：ℤ（整数环）、ℚ、ℝ、ℂ（数环）；多项式环 ℝ[x]。

## 特殊环

| 类型             | 额外条件                                      |
| ---------------- | --------------------------------------------- |
| **含幺环** | 乘法有单位元 1 ≠ 0                           |
| **交换环** | 乘法满足交换律                                |
| **整环**   | 含幺交换环 + 无零因子（a·b=0 ⇒ a=0 ∨ b=0） |
| **除环**   | 每个非零元有乘法逆（域）                      |
| **域**     | 除环 + 交换（ℚ, ℝ, ℂ）                     |

**性质**：

- 整环 / 除环 / 域中消去律成立：a·b = a·c, a≠0 ⇒ b = c
- ℤₙ 是域 ⇔ n 是素数（素域）
- ℤₙ 是整环 ⇔ n 是素数

## 域的基本性质

- 域有且只有两个平凡理想 {0} 和域本身（**单环**）
- 有限域的阶必为素数幂 pⁿ（F₁₀₄₃ = 2¹⁰⁴³ - 1 不合法！2^{10}×...）

## 格

### 定义

**(L, ≤)** 是**偏序集**，且任意 a, b ∈ L，**上确界** sup{a, b} 和**下确界** inf{a, b} 存在。

记 sup{a, b} = a ∨ b（**并 / join**），inf{a, b} = a ∧ b（**交 / meet**）。

**分配格**：∧ 对 ∨ 分配、∨ 对 ∧ 分配。

**有界格**：有全上界（1）和全下界（0）。

## 格的性质

**对偶原理**：把格中 ∨ 换成 ∧、∧ 换成 ∨、≤ 换成 ≥，命题仍成立。

**蕴含**：格中恒有 a ≤ b ⇔ a ∨ b = b ⇔ a ∧ b = a。

## 模格

满足**模律**：(x ≤ b) ⇒ (x ∨ (a ∧ b) = (x ∨ a) ∧ b) 的格。

**Dedekind 模格**：专门指某个特殊结构。

## 布尔代数

### 定义

**布尔代数**：(B, ∧, ∨, ¬, 0, 1)：

- (B, ∧, ∨) 是分配格
- 有界（0, 1 存在）
- 有补（每个元素有补元 ¬a）

**布尔代数基本定律**（对偶）：

- 幂等：a ∨ a = a，a ∧ a = a
- 交换、结合、分配
- 同一：a ∨ 0 = a，a ∧ 1 = a
- 补元：a ∨ ¬a = 1，a ∧ ¬a = 0
- 德摩根：¬(a ∨ b) = ¬a ∧ ¬b

## 布尔表达式

在布尔代数中用 ∧, ∨, ¬ 构造的表达式。

**对偶式**：将 ∨ 和 ∧、0 和 1 互换。

**标准形式**：

- **主合取范式（积之和）**：极小项之积
- **主析取范式（和之积）**：极大项之和（用于布尔代数）

## 原子命题逻辑 vs 布尔代数

布尔代数 ↔ 命题逻辑（去掉了 →, ↔）：

- ∧ = 合取，∨ = 析取，¬ = 否定
- 布尔代数是命题逻辑的形式化抽象

## 布尔函数

**布尔函数**：f: Bⁿ → B（B = {0,1}）。

**小项编号**：n 变元的小项（极小项）编号为二进制对应的十进制。

**函数化简**：用卡诺图（Karnaugh Map）或 Quine-McCluskey 法化简布尔函数。

## 格的特殊类型总结

```
偏序集
  └─ 格（sup/inf 存在）
       ├─ 分配格（满足分配律）
       │    └─ 布尔代数（有界 + 补格）
       │         └─ 布尔环
       └─ 模格（满足模律）
```

## 应用与联系

- **电路设计**：布尔代数 → 逻辑门电路 → 组合逻辑 / 时序逻辑
- **计算机体系结构**：ALU、指令译码、内存寻址
- **密码学**：有限域 ℤ/pℤ（素域）、GF(2ⁿ)（AES 的域运算）
- **编码理论**：有限域上的多项式运算
- **数据库**：布尔查询（AND/OR/NOT）
- **形式语言**：Monoid（半群）在正则表达式中的应用

## 例题

**例 1**：证明 ℤ₆ 不是整环。

ℤ₆ 中，2·3 = 6 ≡ 0 (mod 6)，但 2 ≠ 0, 3 ≠ 0。存在非零零因子 ⇒ 不是整环 ⇒ 更不是域。

**例 2**：证明有限整环是域。

设 D 是有限整环，a ≠ 0 ∈ D。考虑映射 f: D → D，f(x) = a·x。
整环 ⇒ f 是单射（a·x₁ = a·x₂ ⇒ x₁ = x₂）。
有限集合上单射 ⇒ 双射 ⇒ ∃b 使 a·b = 1。
故每个非零元有逆 ⇒ D 是域。

**例 3**：化简布尔表达式 F = (a ∧ b) ∨ (¬a ∧ c) ∨ (b ∧ c)

```
F = (a ∧ b) ∨ (¬a ∧ c) ∨ (b ∧ c)
  = (a ∧ b) ∨ (¬a ∧ c)            [吸收律：b∧c 被 a∧b ∨ ... 吸收]
```

验证：(b ∧ c) ∨ (a ∧ b ∧ ¬a) = (b ∧ c) ∨ 0 = b ∧ c ⊆ F，所以被吸收。
