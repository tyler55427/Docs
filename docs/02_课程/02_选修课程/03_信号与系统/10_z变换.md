# 十、z 变换

## z 变换的定义

### 双边 z 变换

$$
X(z) = \mathcal{Z}\{x[n]\} = \sum_{n=-\infty}^{+\infty} x[n]\,z^{-n}
$$

令 $z = re^{j\omega}$，则 $z^{-n} = r^{-n}e^{-j\omega n}$，z 变换即 $r^{-n}x[n]$ 的 DTFT。与 $s$ 平面关系 $z = e^{sT}$（$s$ 平面虚轴映射为 $z$ 平面单位圆）。

### 单边 z 变换

$$
X(z) = \sum_{n=0}^{+\infty} x[n]\,z^{-n}
$$

用于因果序列与差分方程初值求解。

## 收敛域（ROC）

### ROC 的形式

使级数收敛的所有 $z$ 值集合：

| 信号类型           | ROC                             |
| ------------------ | ------------------------------- |
| 右边序列（因果）   | $|z| > r_0$（圆外）           |
| 左边序列（反因果） | $|z| < r_0$（圆内）           |
| 双边序列           | $r_1 < \|z\| < r_2$（环状）   |
| 有限长序列         | 全平面（除$0$ 或 $\infty$） |

**与拉氏变换一致**：$X(z)$ 与 ROC 共同确定序列；不同序列可有相同 $X(z)$ 不同 ROC。

### 极点与 ROC

- 右边序列：ROC 在最外极点所在圆外
- 左边序列：ROC 在最内极点所在圆内
- 双边：ROC 在相邻极点之间的环带

## z 变换的性质

设 $x[n] \leftrightarrow X(z)$，ROC $R$：

| 性质             | 时域              | z 域                       | ROC                          |
| ---------------- | ----------------- | -------------------------- | ---------------------------- |
| 线性             | $a x_1 + b x_2$ | $a X_1 + b X_2$          | $\supseteq R_1\cap R_2$    |
| 时移             | $x[n-n_0]$      | $z^{-n_0}X(z)$           | $R$（可能差 $0,\infty$） |
| z 域平移         | $a^n x[n]$      | $X(z/a)$                 | $|a|R$                     |
| z 域微分         | $n\,x[n]$       | $-z\dfrac{dX}{dz}$       | $R$                        |
| 时域反转         | $x[-n]$         | $X(1/z)$                 | $1/R$                      |
| 共轭             | $x^*[n]$        | $X^*(z^*)$               | $R$                        |
| 卷积定理         | $x_1*x_2$       | $X_1 X_2$                | $\supseteq R_1\cap R_2$    |
| 初值定理（因果） | $x[0]$          | $\lim_{z\to\infty}X(z)$  | —                           |
| 终值定理         | $x[\infty]$     | $\lim_{z\to 1}(z-1)X(z)$ | $z=1$ 在 ROC 内            |

### 卷积定理

$$
x_1[n] * x_2[n] \;\longleftrightarrow\; X_1(z)\,X_2(z)
$$

LTI 离散系统 $Y(z) = X(z)H(z)$，$H(z)$ 为**系统函数**。

### 常用 z 变换对

| 时域$x[n]$             | z 域$X(z)$                                        | ROC             |
| ------------------------ | --------------------------------------------------- | --------------- |
| $\delta[n]$            | $1$                                               | 全$z$         |
| $u[n]$                 | $\dfrac{1}{1-z^{-1}} = \dfrac{z}{z-1}$            | $\|z\|>1$     |
| $-u[-n-1]$             | $\dfrac{z}{z-1}$                                  | $\|z\|<1$     |
| $a^n u[n]$             | $\dfrac{1}{1-az^{-1}} = \dfrac{z}{z-a}$           | $\|z\|>\|a\|$ |
| $-a^n u[-n-1]$         | $\dfrac{z}{z-a}$                                  | $\|z\|<\|a\|$ |
| $n a^n u[n]$           | $\dfrac{az}{(z-a)^2}$                             | $\|z\|>\|a\|$ |
| $\cos(\omega_0 n)u[n]$ | $\dfrac{z^2-z\cos\omega_0}{z^2-2z\cos\omega_0+1}$ | $\|z\|>1$     |
| $\sin(\omega_0 n)u[n]$ | $\dfrac{z\sin\omega_0}{z^2-2z\cos\omega_0+1}$     | $\|z\|>1$     |

注意：$a^n u[n]$ 与 $-a^n u[-n-1]$ 有相同 $X(z)$，仅 ROC 不同，是"ROC 决定序列"的典型例子。

### 系统函数与稳定性

#### 离散 LTI 系统函数

$$
H(z) = \frac{Y(z)}{X(z)} = \frac{\sum_{k=0}^M b_k z^{-k}}{\sum_{k=0}^N a_k z^{-k}}
$$

由系统差分方程 $\sum a_k y[n-k] = \sum b_k x[n-k]$ 推出，由零、极点决定。

#### 稳定性判据

LTI 离散系统 BIBO 稳定 $\Leftrightarrow$ $H(z)$ 的 ROC 包含**单位圆** $|z|=1$。

**因果系统**：稳定 $\Leftrightarrow$ 所有极点在**单位圆内**（$|p_k|<1$）。

#### s 平面与 z 平面映射

由 $z = e^{sT}$：

| $s$ 平面                   | $z$ 平面          |
| ---------------------------- | ------------------- |
| 虚轴$s=j\omega$            | 单位圆$\|z\|=1$   |
| 左半平面$\mathrm{Re}(s)<0$ | 单位圆内$\|z\|<1$ |
| 右半平面                     | 单位圆外            |
| 平行虚轴直线                 | 圆                  |
| 平行实轴直线                 | 射线                |

### 用 z 变换解差分方程

#### 步骤

1. 对差分方程两边取单边 z 变换（自动纳入初始条件 $y[-1],\cdots$）
2. 解代数方程得 $Y(z)$
3. 部分分式分解
4. 反变换得 $y[n]$

#### 反变换方法

**部分分式法**（最常用）：化 $Y(z)/z$ 为简单分式，查表。

$$
\frac{Y(z)}{z} = \frac{A}{z-p} + \cdots \Rightarrow Y(z) = \frac{Az}{z-p} + \cdots \Rightarrow A\,p^n u[n]
$$

**长除法**（幂级数展开）：适合求初值项，按 $z$ 的降幂（因果）或升幂（反因果）除，得 $x[n]$ 逐项系数。

**留数法**：$x[n] = \sum \mathrm{Res}[X(z)z^{n-1}, p_k]$（对因果序列在 ROC 内极点取留数）。
