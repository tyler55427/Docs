# 五、离散时间傅里叶变换（DTFT）

## 基本概念

### DTFT 的定义

非周期离散信号 $x[n]$ 的**离散时间傅里叶变换**：

$$
X(e^{j\omega}) = \sum_{n=-\infty}^{+\infty} x[n]\,e^{-j\omega n}
$$

**反变换**（IDTFT）：

$$
x[n] = \frac{1}{2\pi}\int_{2\pi} X(e^{j\omega})\,e^{j\omega n}\,d\omega
$$

积分取任意 $2\pi$ 区间（因 $X(e^{j\omega})$ 周期 $2\pi$）。

### DTFT 的关键性质

- $X(e^{j\omega})$ 是 $\omega$ 的**连续**函数（自变量 $\omega$ 连续）
- $X(e^{j\omega})$ 是 $\omega$ 的**周期 $2\pi$** 函数（与连续 CTFT 本质区别）
- 实信号：$X(e^{-j\omega}) = X^*(e^{j\omega})$（共轭对称）

### 收敛条件

$x[n]$ 绝对可和 $\sum_n |x[n]| < \infty$ $\Rightarrow$ DTFT 存在。能量信号满足。

### 与 CTFT 的关系

若 $x(t) \leftrightarrow X(j\omega)$，对其理想采样 $x[n]=x(nT)$：

$$
X(e^{j\omega}) = \frac{1}{T}\sum_{k=-\infty}^{+\infty} X\!\left(j\frac{\omega - 2\pi k}{T}\right)
$$

即离散时间频谱是连续频谱的**周期延拓**（周期 $\omega_s = 2\pi/T$ 再归一化到 $2\pi$），是采样定理的频域体现。

## 性质

设 $x[n] \leftrightarrow X(e^{j\omega})$：

| 性质     | 时域                        | 频域                                                                                  |
| -------- | --------------------------- | ------------------------------------------------------------------------------------- |
| 线性     | $a x_1 + b x_2$           | $a X_1 + b X_2$                                                                     |
| 时移     | $x[n-n_0]$                | $e^{-j\omega n_0}X(e^{j\omega})$                                                    |
| 频移     | $e^{j\omega_0 n}x[n]$     | $X(e^{j(\omega-\omega_0)})$                                                         |
| 共轭对称 | $x^*[n]$                  | $X^*(e^{-j\omega})$                                                                 |
| 实信号   | $x\in\mathbb{R}$          | $X(e^{-j\omega})=X^*(e^{j\omega})$                                                  |
| 时域反转 | $x[-n]$                   | $X(e^{-j\omega})$                                                                   |
| 时域差分 | $x[n]-x[n-1]$             | $(1-e^{-j\omega})X(e^{j\omega})$                                                    |
| 累加     | $\sum_{k=-\infty}^n x[k]$ | $\dfrac{X(e^{j\omega})}{1-e^{-j\omega}} + \pi X(e^{j0})\sum_k\delta(\omega-2\pi k)$ |
| 频域微分 | $n\,x[n]$                 | $j\dfrac{dX}{d\omega}$                                                              |
| 卷积定理 | $x_1[n]*x_2[n]$           | $X_1(e^{j\omega})\,X_2(e^{j\omega})$                                                |
| 相乘     | $x_1[n]\,x_2[n]$          | $\dfrac{1}{2\pi}\int_{2\pi}X_1 X_2\,d\theta$（周期卷积）                            |
| 帕塞瓦尔 | $\sum_n\|x[n]\|^2$        | $\dfrac{1}{2\pi}\int_{2\pi}\|X(e^{j\omega})\|^2 d\omega$                            |

### 帕塞瓦尔定理

$$
\sum_{n=-\infty}^{+\infty}|x[n]|^2 = \frac{1}{2\pi}\int_{2\pi}|X(e^{j\omega})|^2\,d\omega
$$

离散信号能量 = 一个周期内频谱能量。

## 基本变换对

| 时域$x[n]$                | 频域$X(e^{j\omega})$                                                       |
| --------------------------- | ---------------------------------------------------------------------------- |
| $\delta[n]$               | $1$                                                                        |
| $1$（所有 $n$）         | $2\pi\sum_k\delta(\omega-2\pi k)$                                          |
| $e^{j\omega_0 n}$         | $2\pi\sum_k\delta(\omega-\omega_0-2\pi k)$                                 |
| $\cos\omega_0 n$          | $\pi\sum_k[\delta(\omega-\omega_0-2\pi k)+\delta(\omega+\omega_0-2\pi k)]$ |
| $a^n u[n]\ (\|a\|<1)$     | $\dfrac{1}{1-ae^{-j\omega}}$                                               |
| $-a^n u[-n-1]\ (\|a\|>1)$ | $\dfrac{1}{1-ae^{-j\omega}}$                                               |
| $a^{\|n\|}\ (\|a\|<1)$    | $\dfrac{1-a^2}{1-2a\cos\omega+a^2}$                                        |
| 矩形窗$R_N[n]$            | $\dfrac{\sin(\omega N/2)}{\sin(\omega/2)}\,e^{-j\omega(N-1)/2}$            |

### 周期性与混叠

由于 $X(e^{j\omega})$ 周期 $2\pi$，离散频率只需考察 $[-\pi, \pi]$（或 $[0, 2\pi]$）。不同 $\omega$ 相差 $2\pi$ 的整数倍对应同一离散频率，这是采样引入的**频谱混叠**根源。
