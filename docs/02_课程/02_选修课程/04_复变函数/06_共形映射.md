# 六、共形映射

从几何角度理解解析函数的性质和应用。共形映射能将复杂区域问题转到比较简单的区域讨论。

## 第一节 共形映射的概念

### 1. 曲线与切线

$z$ 平面一条有向连续曲线 $C$ 可用 $z=z(t), \alpha \le t \le \beta$ 表示，正向取 $t$ 增大的 $z$ 移动的方向，$z(t)$ 为连续函数。

若 $z'(t_0) \neq 0 (\alpha < t_0 < \beta)$，那么 $z'(t_0)$ 的向量（起点 $z_0$）与 $C$ 相切于点 $z_0 = z(t_0)$。

**切线与 $x$ 轴正向的夹角：** $\text{Arg } z'(t_0)$ 是 $C$ 上点 $z_0$ 的切线与 $x$ 轴正向之间的夹角。

**两曲线的夹角：** 相交于一点的两条曲线 $C_1, C_2$ 正向之间的夹角是 $C_1$ 与 $C_2$ 交点处两条切线正向之间的夹角：

$$
\text{Arg } z'_1(t_0) - \text{Arg } z'_2(t_0)
$$

### 2. 解析函数导数的几何意义

$w = f(z)$ 在区域 $D$ 内解析，$z_0$ 为 $D$ 内一点，且 $f'(z_0) \neq 0$。设 $C$ 为 $z$ 平面经过 $z_0$ 的一条有向光滑曲线，$z = z(t)$，正向对应 $t$ 增大，且 $z_0 = z(t_0)$，$z'(t_0) \neq 0$，则 $w = f(z)$ 将 $C$ 映射到 $w$ 平面中过点 $w_0 = f(z_0)$ 的有向光滑曲线 $\Gamma$。

复合函数求导，有 $w'(t_0) = f'(z_0) z'(t_0) \neq 0$，在 $\Gamma$ 上点 $z_0$ 有切线存在。

$$
\text{Arg } w'(t_0) = \text{Arg } f'(z_0) + \text{Arg } z'(t_0)
$$

即 $\text{Arg } f'(z_0) = \text{Arg } w'(t_0) - \text{Arg } z'(t_0)$

#### 辐角的意义

**结论一：** 导数 $f'(z_0)$ 的辐角 $\text{Arg } f'(z_0)$ 是 $C$ 经 $w=f(z)$ 映射在 $z_0$ 的转动角。

**结论二：** 映射的**转动角的不变性**：转动角的大小与方向与 $C$ 的形状和方向无关。

**保角性：** 相交于 $z_0$ 的任两条曲线 $C_1, C_2$ 之间的夹角，其大小、方向在 $w=f(z)$ 映射后保持不变。

#### 模的意义

**伸缩率：** $|f'(z_0)| = \lim_{\Delta s \to 0} \frac{\Delta \sigma}{\Delta s}$，与 $C$ 形状、方向无关。

**伸缩率的不变性：** $|f'(z_0)|$ 是经 $w=f(z)$ 映射后过 $z_0$ 的任何曲线 $C$ 在 $z_0$ 的伸缩率。

### 3. 共形映射的概念

**定义：** $w=f(z)$ 在 $z_0$ 的邻域内是一一的，在 $z_0$ 有保角性和伸缩率的不变性，那么称 $w=f(z)$ 在 $z_0$ 是共形的 / 是共形映射。若在 $D$ 内每一点都是共形的，称 $w$ 是区域 $D$ 内的共形映射。

$$
\begin{cases}
\text{第一类共形映射：夹角大小和方向不变} \\
\text{第二类共形映射：夹角大小不变，方向相反} \quad (\text{例：} w = \bar{z})
\end{cases}
$$

**定理：** $w=f(z)$ 在 $z_0$ 解析，且 $f'(z_0)\neq 0$，则 $w=f(z)$ 在 $z_0$ 是共形的。

- $\text{Arg } f'(z_0)$ 表示该映射的旋转角
- $|f'(z_0)|$ 表示伸缩率

**扩展：** $w=f(z)$ 在 $D$ 内处处有 $f'(z)\neq 0$，则 $w=f(z)$ 是 $D$ 内的共形映射。

**几何意义：** $w=z$ 扇形 $\rightarrow$ 小曲边三角形，两者近似相似；小圆 $\rightarrow$ 近似的圆。

## 第二节 分式线性映射

**定义：** $w = \dfrac{az+b}{cz+d}$（$ad-bc \neq 0$）

$$
\frac{dw}{dz} = \frac{ad-bc}{(cz+d)^2}
$$

当 $\dfrac{dw}{dz}=0$，$w=\infty$ 常数，映射到一点。

又称**双线性映射（默比乌斯映射）**：固定 $w$ 关于 $z$ 是线性的；固定 $z$ 关于 $w$ 是线性的。

**逆映射：** $z = \dfrac{-dw+b}{cw-a}$（$(-a)(-d)-bc \neq 0$，也是分式线性映射）

**复合映射：** 两个分式线性映射的复合仍是分式线性映射。

一般可由三种特殊形式复合：

1. $w = z+b$，**平移映射**
2. $w = az, a \neq 0$，**旋转与伸缩映射**
3. $w = \dfrac{1}{z}$，**反演变换**

### 1. 反演变换 $w = \dfrac{1}{z}$

分解为 $w_1 = \dfrac{1}{z}$，$w = w_1$：$z \to \bar{z} \to w_1 \to w$（为了使用对称点）。

**圆周的对称点：** $C$ 为以原点为中心，$r$ 为半径的圆周。在以原点为起点的射线上，有 $P$、$P'$，满足 $OP \cdot OP' = r^2$。

$z=re^{i\theta}$，$w_1=\dfrac{1}{z}=\dfrac{1}{r}e^{i\theta}$，$|w_1||z|=1$，且幅角相等，是 $|z|=1$ 的对称点。

**性质：**

- $w=\dfrac{1}{z}$，在扩充复平面是一一对应的。

  i) 在除去 $z=0, \infty$ 时，$w'(z)$ 存在且 $\neq 0$，$\therefore$ 是共形的。

  ii) 对 $z=0, \infty$ 时，规定：两条曲线在 $\infty$ 的夹角 $=$ 映射 $f=\dfrac{1}{z}$ 在 $z=0$ 两条曲线的夹角。

  $$
  \begin{cases}
  w=\dfrac{1}{z}=\xi \text{ 在 } \xi=0 \text{ 解析，} w'(0)=1 \text{，}\therefore \text{在 } z=\infty \text{ 共形} \\
  \text{由 } z=\dfrac{1}{w} \text{，知 } w=0 \text{ 与 } z=\infty \text{ 共形，即 } z=0 \text{ 共形}
  \end{cases}
  $$

  $\therefore$ $w=\dfrac{1}{z}$ 在扩充复平面是处处共形的，为共形映射。

- $w=az+b$ ($a \neq 0$)，在扩充复平面是一一对应的。

  i) $z \neq \infty$ 时，$w'=a \neq 0$，共形的。

  ii) $z=\infty$ 时，$\xi=\dfrac{1}{z}$，$\eta=\dfrac{1}{w}$，$\eta=\dfrac{\xi}{a+b\xi}$，解析且 $\eta'(0)=\dfrac{1}{a} \neq 0$，共形的。

  $\therefore$ $w=az+b$ 在扩充复平面是处处共形的，为共形映射。

**定理：** 分式线性映射在扩充复平面是一一对应的，且有保角性。

### 2. 保圆性

**辨析：** 扩充的圆周（扩充平面上）

**保圆性：** $z$ 平面内的一个圆周/直线经 $w = az + b (a \neq 0)$ 映射后仍为一个圆周/直线。

$w = \dfrac{1}{z}$：一个圆周/直线 $a(x^2 + y^2) + bx + cy + d = 0$，映射到 $d(u^2 + v^2) + bu - cv + d = 0$。

$$
\begin{cases}
a \neq 0, d \neq 0 : \text{圆周} \rightarrow \text{圆周} \\
a \neq 0, d = 0 : \text{圆周} \rightarrow \text{直线} \\
a = 0, d \neq 0 : \text{直线} \rightarrow \text{圆周} \\
a = 0, d = 0 : \text{直线} \rightarrow \text{直线}
\end{cases}
$$

**定理：** 分式线性映射将扩充 $z$ 平面上的圆周映射为扩充 $w$ 平面上的圆周，即**保圆性**。

**推论：** 分式线性映射下，给定圆周/直线没有点映射到无穷远点，则映射为半径有限的圆周。若有点映射到无穷远点，则映射为直线。

### 3. 保对称性

**保持对称点不变的性质：**

$z_1, z_2$ 是关于圆周 $C: |z - z_0| = R$ 的对称点 $\Leftrightarrow$ 经过 $z_1, z_2$ 的任何圆周 $\Gamma$ 与 $C$ 正交。

**情形一：** 过 $z_1$ 作 $\Gamma$ 的切线，交 $C$ 于 $z', z''$，则 $z_1, z_2$ 为 $\Gamma$ 的割线/切线交点，由初中几何：

$$
|z' - z_0|^2 = |z_1 - z_0| |z_2 - z_0| \quad (\text{初等几何})
$$

而 $z_1, z_2$ 又是 $C$ 的对称点，则 $z'$ 在 $C$ 上，$|z' - z_0|$ 为 $C$ 的半径，则 $\Gamma$ 与 $C$ 正交。

**情形二：** $\Gamma$ 是过 $z_1, z_2$ 且与 $C$ 正交的圆周。$z_1, z_2$ 作为 $\Gamma$ 的 $l = \infty$ 的特殊线，也与 $C$ 正交，且经过 $z_0$，$\therefore z_0 z_2$ 是 $\Gamma$ 的切线。

$\therefore$ 直线 $|z_1 - z_0| |z_2 - z_0| = R^2$ 是对称点。

**定理：** $z_1, z_2$ 是圆周 $C$ 的对称点，在分式线性映射 $f$ 下，象点 $w_1, w_2$ 也是关于 $C$ 的象 $C'$ 的对称点。

$$
\begin{cases}
\text{圆} \to \text{圆} \\
\text{正交的解析映射是正交的}
\end{cases}
$$

## 第三节 几个常用的共形映射

### 1. 幂函数 $w = z^n$（$n \in \mathbb{N}^+$）

- 将角域 $\{0 < \arg z < \alpha\}$ 映射为 $\{0 < \arg w < n\alpha\}$（$n$ 倍角）
- 将上半平面 $\{0 < \arg z < \pi\}$ 映射为整个复平面除去正实轴 $\{0 < \arg w < n\pi\}$

### 2. 指数函数 $w = e^z$

- 将水平带域 $\{0 < \Im z < \alpha\}$ 映射为角域 $\{0 < \arg w < \alpha\}$
- 将 $\{-\infty < \Re z < +\infty, 0 < \Im z < 2\pi\}$ 映射为 $\mathbb{C} \setminus \{0\}$

### 3. 对数函数 $w = \ln z$

- 将复平面去掉原点和负实轴的区域映射为水平带域
- 是指数函数的反函数

### 4. 分式线性映射 $w = \dfrac{az + b}{cz + d}$（$ad - bc \neq 0$）

- 将圆（直线）映射为圆（直线）
- 保角，保交比
- **Riemann 映射定理：** 单连通域（边界多于一点）上存在单叶解析函数将其一一映射到单位圆

### 5. 反演映射 $w = \dfrac{1}{z}$

- 将圆映射为圆（直线视为半径无穷大的圆）
- 关于单位圆对称：若 $|z| = 1$，则 $z$ 与 $1/\bar{z}$ 互为对称点
