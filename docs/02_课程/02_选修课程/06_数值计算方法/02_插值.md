# 二、插值

## 概述

- 求 $f(x)$ 的若干函数值近似构造 $p(x)$，$p(x)$ 称为 $f(x)$ 的插值函数。
- 路径：拉格朗日插值 → 牛顿插值 → Hermite 插值 → 分段低次插值 → 三次样条插值。
- 背景：$\begin{cases} \text{数据规律 } f \text{ 未知} \\ f \text{ 复杂，要近似} \end{cases} \Rightarrow \begin{cases} \text{插值} \\ \text{拟合} \end{cases}$
- 应用：$\begin{cases} \text{积分} \\ \text{CAD、3D 动画制作} \\ \text{对数、三角函数求值} \\ \text{数值积分、微分} \end{cases}$

### 定义（一元）

- $f(x)$ 在 $[a,b]$ 定义，$a \le x_0 < \cdots < x_n \le b$，已知 $f(x_i)=y_i$；若在某函数类 $\exists\, P(x)$，使 $P(x_i)=y_i$，称 $P(x)$ 为 $f(x)$ 的**插值函数**。
- $x_i$ 称**插值节点**，$(x_i,y_i)$ 称**插值点**，$f(x)$ 称**被插函数**。仅考虑一元插值，$x_0=a$，$x_n=b$。
- 常见函数类：$\begin{cases} \text{多项式函数 } P(x)=\sum a_i x^i \\ \text{三角函数} \end{cases}$
- 逼近定理：闭区间上的连续函数可用多项式一致逼近。

### 插值多项式问题

- **存在唯一性**：系数行列式 $D\ne 0 \Rightarrow$ $P_n(x)$ 存在且唯一（$n+1$ 个互异 $x_i$，存在唯一的 $P_n(x)$）。
- 计算方法：如何计算
- 误差分析

## 朗格朗日插值

$n+1$ 个点用 $n$ 次多项式插值。

**线性插值：**

$$
P(x)=y_0+\frac{y_1-y_0}{x_1-x_0}(x-x_0)=\frac{x_1-x}{x_1-x_0}y_0+\frac{x-x_0}{x_1-x_0}y_1=l_0(x)y_0+l_1(x)y_1
$$

$l_i(x)$ 称**线性插值基函数**，$\begin{cases} l_0(x_0)=1,\ l_0(x_1)=0 \\ l_1(x_0)=0,\ l_1(x_1)=1 \end{cases}$

**推广到 $n$ 维：**

过 $n+1$ 个插值节点，$L_n(x)=\displaystyle\sum_{i=0}^{n} l_i(x)y_i$，$l_i$ 为 $n$ 次拉格朗日插值基函数。

$l_i(x_i)=\delta_{ij}$，唯一确定一个 $n$ 次多项式，设 $l_i(x)=A\displaystyle\prod_{j\ne i}(x-x_j)$，代入 $(x_i,y_i)$ 解得：

$$
l_i(x)=\frac{(x-x_0)\cdots(x-x_{i-1})(x-x_{i+1})\cdots(x-x_n)}{(x_i-x_0)\cdots(x_i-x_{i-1})(x_i-x_{i+1})\cdots(x_i-x_n)}
$$

令 $W_{n+1}(x)=\displaystyle\prod_{i=0}^{n}(x-x_i)$，则

$$
l_i(x)=\frac{W_{n+1}(x)}{(x-x_i)W_{n+1}'(x_i)},\qquad \sum_{i=0}^{n}l_i(x)=1
$$

**定理（插值余项 / 截断误差）：**

$f^{(n)}(x)$ 在 $[a,b]$ 连续，$f^{(n+1)}(x)$ 在 $(a,b)$ 存在，$L_n(x)$ 为插值多项式，$\forall x\in[a,b]$，插值余项

$$
R_n(x)=f(x)-L_n(x)=\frac{f^{(n+1)}(\xi)}{(n+1)!}W_{n+1}(x),\quad \xi\in(a,b)\text{ 且依赖于 }x
$$

- 误差界与 $f^{(n+1)}$ 相关、与 $x_i$ 相关。
- 优：$O(n)$，秦九韶 $O(n)$。
- 劣：增减节点基函数需全部重算（不能承袭，牛顿解决）。

**拉格朗日插值算法（伪码）：**

```
step1  输入：插值节点 n，插值点序列 {(x_i, y_i), i=0,1,...,n}，计算点 x。
step2  for i = 0 to n
       {  tmp := 1;                        ! l_i(x)
          for j = 0 to i-1   tmp *= (x-x_j)/(x_i-x_j);
          for j = i+1 to n   tmp *= (x-x_j)/(x_i-x_j);
          fx += tmp * y_i  }                ! L_n(x) = Σ l_i(x) y_i
step3  输出 fx
```

- 内插（计算点在节点区间内）/ 外插。

## 牛顿插值

$$
N_n(x)=\sum_{i=0}^{n} a_i\prod_{j=0}^{i-1}(x-x_j),\quad a_i \text{ 由 } P(x_i)=y_i \text{ 确定}
$$

**差商：**

$$
f[x_i]=f(x_i)\quad(0\text{阶})
$$

$$
f[x_i,x_{i+1}]=\frac{f(x_{i+1})-f(x_i)}{x_{i+1}-x_i}\quad(1\text{阶})
$$

$$
f[x_i,\cdots,x_{i+k}]=\frac{f[x_{i+1},\cdots,x_{i+k}]-f[x_i,\cdots,x_{i+k-1}]}{x_{i+k}-x_i}\quad(k\text{阶})
$$

**性质：**

- $f[x_0,\cdots,x_k]=\displaystyle\sum_{j=0}^{k}\frac{f(x_j)}{\prod_{m\ne j}(x_j-x_m)}$（$f(x_j)$ 的线性组合）。
- 任意排列的差商相同，仅与节点有关，与节点顺序无关（对称性）。
- $f(x)$ 为 $m$ 次多项式，则 $f[x_0,\cdots,x_{k-1},x]$ 为 $m-k$ 次多项式。

**差商表（表 1.2）：**

| $i$      | $x_i$ | $f(x_i)$ | 一阶差商           | 二阶差商                  | 三阶差商                  | $\cdots$ | $n$ 阶差商          |
| ---------- | ------- | ---------- | ------------------ | ------------------------- | ------------------------- | ---------- | --------------------- |
| 0          | $x_0$ | $f(x_0)$ |                    |                           |                           |            |                       |
| 1          | $x_1$ | $f(x_1)$ | $f[x_0,x_1]$     |                           |                           |            |                       |
| 2          | $x_2$ | $f(x_2)$ | $f[x_1,x_2]$     | $f[x_0,x_1,x_2]$        |                           |            |                       |
| 3          | $x_3$ | $f(x_3)$ | $f[x_2,x_3]$     | $f[x_1,x_2,x_3]$        | $f[x_0,x_1,x_2,x_3]$    |            |                       |
| $\vdots$ |         |            |                    |                           |                           |            | $\vdots$            |
| $n$      | $x_n$ | $f(x_n)$ | $f[x_{n-1},x_n]$ | $f[x_{n-2},\cdots,x_n]$ | $f[x_{n-3},\cdots,x_n]$ | $\cdots$ | $f[x_0,\cdots,x_n]$ |

> 增加一点，增加一行；$k$ 阶差商可由任意两个 $k-1$ 阶差商计算。

**牛顿插值公式：**

由插值唯一性，与拉格朗日相同、表达形式不同：

$$
N_n(x)=\sum_{i=0}^{n} f[x_0,\cdots,x_i]\prod_{j=0}^{i-1}(x-x_j)=N_{n-1}(x)+a_n\prod_{j=0}^{n-1}(x-x_j)
$$

推导：每项为差商定义逐级代入，$a_i=f[x_0,\cdots,x_i]$。

**误差：**

$$
R_n(x)=f(x)-N_n(x)=f[x,x_0,\cdots,x_n]\prod_{i=0}^{n}(x-x_i)=\frac{f^{(n+1)}(\xi)}{(n+1)!}\prod_{i=0}^{n}(x-x_i)
$$

> 差商与导数关系：$f[x_0,\cdots,x_n]=\dfrac{f^{(n)}(\xi)}{n!}$（差商中值定理，$\xi$ 是 $x$ 的函数）。$n$ 阶差商 $\approx n$ 阶导。

**龙格现象（Runge）（不收敛）：**

- 插值点变多效果不一定好（高次插值、等距插值的缺陷）。
- $f(x)=\dfrac{1}{1+25x^2}$，等距插值点 $x_i=-1+\dfrac{2i}{n}$，$\lim\limits_{n\to\infty}\max\limits_{x\in[-1,1]}|f(x)-P_n(x)|=+\infty$。

**Weierstrass 定理：**

$f(x)\in C[a,b]$，$\forall\varepsilon>0$，$\exists\, P(x)$ 使 $\|P(x)-f(x)\|<\varepsilon$ 一致成立；但需合适的构造节点。

## Hermite 插值

给定 $n+1$ 插值点和对应节点的导数，确定 $2n+1$ 次多项式 $H_{2n+1}(x)$。 引入差商的推广定义。

**借拉格朗日：**

$$
H_{2n+1}(x)=\sum_{i=0}^{n}\left[\alpha_i(x)f_i+\beta_i(x)m_i\right],\quad \alpha_i,\beta_i\text{ 为 }2n+1\text{ 次多项式}
$$

$$
\begin{cases}\alpha_i(x_k)=\delta_{ik},\ \alpha_i'(x_k)=0 \\ \beta_i(x_k)=0,\ \beta_i'(x_k)=\delta_{ik}\end{cases}
$$

$$
\alpha_i(x)=\left(1-2(x-x_i)\sum_{k\ne i}\frac{1}{x_i-x_k}\right)l_i^2(x),\qquad \beta_i(x)=(x-x_i)l_i^2(x)
$$

插值余项：$f\in C^{2n+2}[a,b]$ 时，$R(x)=\dfrac{f^{(2n+2)}(\xi)}{(2n+2)!}\displaystyle\prod_{i=0}^{n}(x-x_i)^2$。

**借牛顿：**

推广差商：$f[x_0,x_0]=\lim\limits_{x_1\to x_0}f[x_0,x_1]=f'(x_0)$（重节点对应导数，$z_{2n}=z_{2n+1}=x_n$）。

$$
H_{2n+1}(x)=f[z_0]+\sum_{k=1}^{2n+1}f[z_0,\cdots,z_k]\prod_{i=0}^{k-1}(x-z_i)
$$

## 分段插值

为解决龙格现象（插值多项式在区间剧烈振荡）

**分段线性插值：**

$a=x_0<\cdots<x_n=b$，$h_i=x_{i+1}-x_i$，$h=\max h_i$，折线 $I_h(x)$ 满足

$$
\begin{cases}I_h(x)\in C[a,b] \\ I_h(x_i)=f_i \\ I_h(x)\text{ 在每个区间为不高于一次的多项式}\end{cases}
$$

误差估计：$|R(x)|\le \dfrac{M h^2}{8}$，$M=\max|f''(x)|$。

- 算法简单、计算量小；
- 区间多小误差多小；
- 修改一个节点仅影响两个相邻区间；
- 插值点不光滑。

**三次样条插值：**

弹性样条固定样点，自动形成光滑曲线，解决分段插值在节点处导数不连续问题。$m$ 次样条由 $m$ 次多项式拼接、连续、$m-1$ 次可导且连续。

$\begin{cases}S(x_i)=f_i \\ S(x)\in C^2[a,b] \\ S(x)\text{ 在每个 }[x_i,x_{i+1}]\text{ 为三次多项式}\end{cases}$

误差（与 $x$ 无关，$[a,b]$ 上一致收敛）：

$$
\|f^{(k)}(x)-S^{(k)}(x)\|_\infty\le C_k\|f^{(4)}\|_\infty h^{4-k},\quad k=0,1,2;\quad C_0=\tfrac{5}{384},\ C_1=\tfrac{1}{24},\ C_2=\tfrac{1}{8}
$$

$n+1$ 个节点、$n$ 个区间，确定 $S(x)$ 需 $4n$ 个系数。条件计数：

- $S(x_i)=f(x_i)$：$n+1$ 个
- $S,S',S''$ 在内节点连续：各 $n-1$ 个（共 $3n-3$）
- 边界条件：$\begin{cases}S'(x_0)=f_0',\ S'(x_n)=f_n' & (m\text{ 条件}) \\ S''(x_0)=f_0'',\ S''(x_n)=f_n''\text{ 或 }0 & (M\text{ 条件， 自然边界}) \\ \text{周期条件} \end{cases}$

**$M$ 关系式（三弯矩方程）：**

记 $M_i=S''(x_i)$，$h_i=x_{i+1}-x_i$。$S''(x)$ 线性 → 积分两次得 $S(x)$ → 求导由 $S_{i-1}'(x_i)=S_i'(x_i)$ 得：

$$
\mu_i M_{i-1}+2M_i+\lambda_i M_{i+1}=d_i
$$

$$
\lambda_i=\frac{h_i}{h_{i-1}+h_i},\quad \mu_i=1-\lambda_i=\frac{h_{i-1}}{h_{i-1}+h_i},\quad d_i=6f[x_{i-1},x_i,x_{i+1}]
$$

边界情况：$M_0,M_n$ 已知（$M_0=M_n=0$ 自然边界）；$S'(x_0)=m_0,S'(x_n)=m_n$；周期 $f(x_0)=f(x_n)$。

> 三者均为对角占优的三对角带状矩阵，可用**追赶法**求解。

**$m$ 关系式（三转角方程）：**

记 $m_i=S'(x_i)$。在 $[x_i,x_{i+1}]$ 上用 Hermite 插值构造 $S(x)$，由 $S''(x_{i+0})=S''(x_{i-0})$ 得：

$$
\lambda_i m_{i-1}+2m_i+\mu_i m_{i+1}=c_i,\quad c_i=3\left[\lambda_i f[x_{i-1},x_i]+\mu_i f[x_i,x_{i+1}]\right]
$$

加两个边界条件即可解 $m_i$，分类同上。
