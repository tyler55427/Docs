### 计算机小知识

计算机中的半导体存储器由大量的独立存储单元组成。每个存储单元都保存一个 $1$ 或者者 $0$。存储器的一种类型是静态随机访问存储器 (SRAM)，其中每个单元都使用触发器，因此只要加上直流电源，触发器就能不确定地保持两个状态之一，由此得到“静态”这个概念。这种类型的存储器被归类为易失性存储器，因为当电源断开时，存储的所有数据都会丢失。另一种类型的存储器为动态随机访问存储器 (DRAM)，它使用电容而不是触发器作为基本存储元件，并且必须周期性地刷新以保留存储的数据。

#### 7.2.4 异步预置位和清零输入

*   $\diamond$ 有效的预置位输入使得 $Q$ 输出为高电平（置位）。

对于刚才讨论的触发器，D 触发器和 J-K 触发器的输入被称为同步输入，因为只有在时钟脉冲的边沿，触发器的输入才能传送到输出；也就是数据的传送和时钟同步。

### 实践技巧

CMOS 器件相比于双极型器件的一个优点是，它可以运行在一个较宽范围的直流电源电压内（一般为 $2 \sim 6\text{ V}$），所以可以使用没有精确调整的、不太昂贵的电源。同样，可以使用电池作为 CMOS 电路的辅助电源或主要电源。此外，较低的电压就意味着 IC 具有较小的功率损耗。CMOS 器件的缺陷是它的性能在电源电压较低时会差一些。例如，CMOS 触发器允许的最大时钟频率在 $V_{\text{CC}} = 2\text{ V}$ 时要比 $V_{\text{CC}} = 6\text{ V}$ 时低很多。

### 7.4.2 分频

触发器的另一个应用是对周期波形的频率进行分（减少）频。当脉冲波形加在一个 D 触发器或 J-K 触发器的时钟输入时（$D = \overline{Q}$ 或 $J = K = 1$），这时 $Q$ 输出就是一个频率为时钟频率一半的方波。因此，单个触发器可以用作除以 2 芯片，如图 7.36 的 D 触发器或 J-K 触发器所示。如图 7.36(c) 所示，触发器在每一个时钟脉冲的触发边沿（在这个例子中是上升沿触发）改变状态。这就产生了一个输出，它的频率变为时钟频率的一半。

时钟频率的进一步分频可以通过将触发器的输出用作第二个触发器的时钟输入来实现，如图 7.37 所示。$Q_A$ 输出的频率由触发器 $Q_B$ 二分频。所以 $Q_B$ 输出的频率就是原先时钟频率的 1/4。传输延迟时间没有在时序图中指出。

以这种方式连接触发器，就可以实现 $2^n$ 分频，其中 $n$ 是触发器的个数。例如，3 个触发器把时钟频率除以 $2^3 = 8$，4 个触发器把时钟频率除以 $2^4 = 16$，以此类推。

#### 正文论述

初始时，当电源打开后，电容 ($C_1$) 并没有充电，因此触发电压 (引脚 2) 是 $0\text{V}$。这导致了比较器 B 的输出为高电平，比较器 A 的输出为低电平，迫使锁存器的输出，也就是 $Q_1$ 的基极为低电平，并保持晶体管截止。这时，$C_1$ 开始通过 $R_1$ 和 $R_2$ 充电，如图 7.57 所示。当电容电压达到 $1/3 V_{\text{CC}}$ 时，比较器 B 就变为它的低电平输出状态；而当电容电压达到 $2/3 V_{\text{CC}}$ 时，比较器 A 就变为它的高电平输出状态。这就使锁存器复位，使得 $Q_1$ 的基极为高电平，并使晶体管导通。这一连串变化为电容建立了一个从 $R_2$ 到晶体管的放电回路，如图所示。电容现在开始放电，使得比较器 A 的输出变为低电平。当电容放电到 $1/3 V_{\text{CC}}$ 时，比较器 B 就变为高电平；这使得锁存器置位，并使得 $Q_1$ 的基极为低电平，并且晶体管截止。然后开始另一个充电循环，重复整个过程。结果就是一个矩形波输出，它的占空比取决于电阻 $R_1$ 和 $R_2$ 的数值。振荡的频率由下面的公式给出，或者可以在图 7.58 中找到。

$$f = \frac{1.44}{(R_1 + 2R_2)C_1} \tag{7.4}$$

通过选择 $R_1$ 和 $R_2$，可以调节输出的占空比。由于 $C_1$ 通过 $R_1+R_2$ 充电，仅通过 $R_2$ 放电，如果 $R_2 \gg R_1$，就可以达到最接近 50% 的占空比，从而使得充电和放电时间大致相等。

占空比的表达式如下所示。输出为高电平的时间 ($t_{\text{H}}$) 是 $C_1$ 从 $1/3V_{\text{CC}}$ 充电到 $2/3V_{\text{CC}}$ 所需要的时间。它可以表示为
$$t_{\text{H}} = 0.7(R_1 + R_2)C_1 \quad\quad\quad\quad\quad\quad\quad (7.5)$$

输出为低电平的时间 ($t_{\text{L}}$) 是 $C_1$ 从 $1/3V_{\text{CC}}$ 放电到 $2/3V_{\text{CC}}$ 所需要的时间。它可以表示为
$$t_{\text{L}} = 0.7R_2C_1 \quad\quad\quad\quad\quad\quad\quad (7.6)$$

输出波形的周期 $T$ 是 $t_{\text{H}}$ 和 $t_{\text{L}}$ 的和。这就是式(7.4)中 $f$ 的倒数。
$$T = t_{\text{H}} + t_{\text{L}} = 0.7(R_1 + 2R_2)C_1$$

最后，占空比为
$$\text{占空比} = \frac{t_{\text{H}}}{T} = \frac{t_{\text{H}}}{t_{\text{H}} + t_{\text{L}}}$$
$$\text{占空比} = \left(\frac{R_1 + R_2}{R_1 + 2R_2}\right)100\% \quad\quad\quad\quad\quad\quad\quad (7.7)$$

为了实现小于 50% 的占空比，可以对图 7.56 的电路进行修改，使得 $C_1$ 通过 $R_1$ 充电，并通过 $R_2$ 放电。这由一个二极管 $D_1$ 来实现，如图 7.59 所示。令 $R_1$ 小于 $R_2$ 就可以实现占空比小于 50%。在这种情况下，占空比的表达式为
$$\text{占空比} = \left(\frac{R_1}{R_1 + R_2}\right)100\% \quad\quad\quad\quad\quad\quad\quad (7.8)$$

### 8.1 移位寄存器的功能

* 寄存器可以由一个或者多个用以存储和移位数据的触发器组成。

寄存器是一个具有两种基本功能——数据存储和数据移动的数字电路。寄存器的存储能力使得它成为一种重要的存储元件。图 8.1 解释了在 D 触发器中存储 1 或者 0 的这种存储概念。如图所示，一个 1 加在数据输入上，同时加一个时钟脉冲使触发器置位，这样就能存储这个 1。当输入上的 1 被移走之后，触发器还是保持在置位状态，因此存储了 1。应用相似的过程，通过复位触发器来存储 0，如图 8.1 所示。

##### 图 8.1 触发器作为存储元件
* **左图（存储 1）：**
  当 $D$ 上出现 1 时，在时钟 (CLK) 的触发边沿到来时 $Q$ 变为 1，如果已经在置位状态，则保持为 1。
* **右图（存储 0）：**
  当 $D$ 上出现 0 时，在时钟 (CLK) 的触发边沿到来时 $Q$ 变为 0，如果已经在复位状态，则保持为 0。

寄存器的存储容量是它可以包含的数字数据 (1 和 0) 的总位数。移位寄存器中的每一级（触发器）都表示存储容量中的一位。所以，寄存器中的级数决定了它的存储容量。

寄存器的移位功能允许在寄存器内从级到级移动数据，或者根据所加的时钟脉冲，使得数据进入或者离开寄存器。图 8.2 解释了移位寄存器中数据移动的类型，框图表示任意的 4 位寄存器，箭头表示数据移动的方向。

##### 图 8.2 移位寄存器中基本的数据移动（用 4 位来解释，箭头指示数据移动的方向）
* **(a) 串行输入/右移/串行输出**
  数据从左端串行输入，经内部逐级向右移动，由右端串行输出。
* **(b) 串行输入/左移/串行输出**
  数据从右端串行输入，经内部逐级向左移动，由左端串行输出。
* **(c) 并行输入/串行输出**
  数据通过 4 条并行线同时输入，在时钟作用下向右逐级移动，最后由右端串行输出。
