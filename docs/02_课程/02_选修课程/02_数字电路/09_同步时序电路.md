### 9.5 同步计数器的设计

#### 9.5.1 步骤 1：状态图

设计计数器的第一步是创建一个状态图。状态图给出了计数器在时钟的作用下状态行进的历程。作为一个例子，图 9.26 给出了基本的 3 位格雷码计数器的状态图。这个特殊电路除时钟外没有输入，除计数器中每个触发器所具有的输出外也没有其他输出。这时，可以复习一下第 2 章有关格雷码的内容。

（图 9.26：3 位格雷码计数器的状态图，展示了状态 $000 \to 001 \to 011 \to 010 \to 110 \to 111 \to 101 \to 100 \to 000$ 的循环转换过程。）

#### 9.5.2 步骤 2：次态表

一旦由状态图定义了时序电路，第二步就是推导出次态表，列出计数器的每一个状态（当前状态）和相应的下一个状态（次态）。次态就是计数器在时钟脉冲的作用下从当前状态转换过来的状态。次态表由状态图导出，如表 9.8 的 3 位格雷码计数器的次态表所示，$Q_0$ 是最低有效位。

#### 9.5.3 步骤 3：触发器转换表

表 9.9 是 J-K 触发器转换表。通过给出触发器从当前状态到次态的 $Q$ 输出，表中列出了所有可能的输出转换。$Q_N$ 是触发器的当前状态（在时钟脉冲之前），而 $Q_{N+1}$ 是次态（在时钟脉冲之后）。对于每个输出转换，列出了使转换得以发生的输入 $J$ 和 $K$。$X$ 表示“无关”项（输入可以为 1 或者 0）。

为了设计此计数器，基于次态表（见表 9.8）的转换应应用于计数器中的每一个触发器。例如，对于当前状态 $000$，$Q_0$ 从当前状态 0 变化到次态 1。为了使这种情况得以发生，$J_0$ 必须为 1，不要考虑 $K_0$ 是什么 $\angle (J_0 = 1, K_0 = X)$，正如在转换表（见表 9.9）中看到的那样。接下来，$Q_1$ 的当前状态为 0，并且在下一个状态保持为 0。对于这个转换，$J_1 = 0, K_1 = X$。最后，$Q_2$ 的当前状态为 0，而在下一个状态保持为 0。所以，$J_2 = 0$ 和 $K_2 = X$。对于表 9.8 中的每一个当前状态，重复这样的分析。

### 9.5.5 步骤 5：触发器输入的逻辑表达式

从图 9.28 的卡诺图中，得到如下所示的每个触发器的 $J$ 和 $K$ 输入的表达式：
$$
\begin{aligned}

\end{aligned}

设计 3 位格雷码计数器所需步骤的总结如下所示。一般情况下，这些步骤可以应用于任意的状态机。

1. 确定计数器序列并绘制状态图。
2. 从状态图推导出次态表。
3. 开发转换表，给出每个转换所需要的触发器输入。转换表对于触发器的给定类型总是相同的。
4. 把 $J$ 和 $K$ 状态从转换表转移到卡诺图上。每个触发器的每个输入都有一个卡诺图。
5. 对卡诺图小方格进行分组，从而产生并导出每个触发器输入的逻辑表达式。
6. 使用组合逻辑实现表达式，并且连接触发器以创建计数器。

    使用并行数据输入把计数器初始预置为 $0$（这里没有给出）。每辆进入车库的汽车都会切断一条光束，从而使得传感器产生一个正向电子脉冲。这个正脉冲的上升沿把 S-R 锁存器置位。锁存器 $\bar{Q}$ 输出上的低电平使得计数器进入加模式。同样，此传感器脉冲经过或非门，并在其后沿的低电平到高电平的转换时使计数器加 $1$。每次汽车进入车库时，计数器就增加 $1$（递增）。当第 $100$ 辆汽车进入车库时，计数器就到达它的最后一个状态 $(100_{10})$。$\text{MAX/MIN}$ 输出变为高电平，并使得接口电路工作（没有细节），点亮停满标志并降下起落杆以阻止汽车继续进入。

*   **计数器递减**：就是将它的计数值减去 $1$。
    当汽车离开时，光电传感器产生一个正向电子脉冲，把 S-R 锁存器复位，使得计数器进入减模式。在时钟下降沿使得计数器减 $1$。如果车库停满并且汽车离开，那么计数器的 $\text{MAX/MIN}$ 输出就会变为低电平，使得停满标志关闭，同时抬起起落杆。

#### 10.1.5 RAM 和 ROM

两类主要的半导体存储器是 RAM 和 ROM。RAM（随机访问存储器）是在等量时间内可以访问所有地址的一类存储器，并且可以按照任意顺序来选择这些地址以执行读操作或者写操作。所有的 RAM 都具有读和写的能力。因为 RAM 在电源关闭时会丢失所存储的数据，所以它是易失性存储器。

ROM（只读存储器）是可以永久或者半永久地保存数据的一类存储器。数据可以从 ROM 中读出，但是和 RAM 不同，ROM 没有写操作。ROM 和 RAM 类似，也是随机访问存储器，但是术语 RAM 的传统意思是随机读/写存储器。本章将会介绍几种类型的 RAM 和 ROM。因为 ROM 在电源关闭后仍然保存着数据，所以它是非易失性存储器。

### 10.2.5 高速缓冲存储器

SRAM 的一个主要应用即用于计算机的高速缓冲存储器中。高速缓冲存储器（简称缓存）是一种体积相对较小且可高速访问的存储器，用来存储最近使用的指令或者来自体积较大且访问速度较慢的主存储器的数据。高速缓冲存储器还可以使用动态 RAM (DRAM) 实现，随后将会介绍。典型情况下，SRAM 的操作速度要比 DRAM 快很多。总之，如果只使用高容量 DRAM，高速缓冲存储器可以使得存储信息更快地进入微处理器。高速缓冲存储器基本上是改进系统性能的一个经济实惠的方法，而且没有加快所有存储器的处理速度所付出的代价。

### 10.2.6 动态 RAM (DRAM) 存储单元

动态存储 (dynamic memory) 单元在一个很小的电容里而不是在锁存器里存储一个数据位。这种类型的存储单元的优点是非常简单，因此允许将很大的存储阵列构建在一个芯片上，并且每位的成本很低。缺点是存储电容不能长时间保持它的电荷，并且会丢失它所保存的数据位，除非对它的电荷进行定期刷新。为了刷新电荷就需要附加的存储电路，这使得 DRAM 的操作复杂化。图 10.17 给出了一个典型的 DRAM 单元，由单个 MOS 晶体管 (MOSFET) 和一个电容组成。

在这种类型的单元中，晶体管作为开关来使用。基本的简化操作如图 10.18 所示。$R/\overline{W}$ 线 (WRITE 模式) 上的低电平使能三态输入缓冲器并且禁止输出缓冲器。对于即将写入单元中的一个 1 来说，$D_{\text{IN}}$ (数据输入) 线必须为高电平，必须由行线上的高电平使晶体管导通。晶体管相当于一个闭合开关，将电容连接到位线上。这个连接允许电容充电到一个正电压，如图 10.18(a) 所示。当存储 0 时，低电平就加在 $D_{\text{IN}}$ 线上。如果电容正在存储 0，它就保持非充电状态；如果它正在存储 1，电容就会放电，如图 10.18(b) 所示。当行线返回低电平时，晶体管截止，电容和位线断开，从而在电容中“俘获”电荷 (1 或者 0)。

10.2.7 DRAM 的组成结构

DRAM 主要用于计算机的主存储器中。DRAM 和 SRAM 之间的区别是存储单元的类型不同。正如所看到的那样，DRAM 的存储单元由一个晶体管和一个电容组成，这要比 SRAM 单元简单得多。这种组成结构允许 DRAM 中的存储密度更大，因而在给定的芯片面积里有更大的位容量，但是存取时间慢了许多。

因为电容中存储的电荷会泄漏，DRAM 单元需要经常地进行刷新操作来保持存储的数据位。这个需求就导致了比 SRAM 中更加复杂的电路。下面使用一般的 1M×1 位 DRAM 为例来讨论大多数 DRAM 常见的几个特征。
