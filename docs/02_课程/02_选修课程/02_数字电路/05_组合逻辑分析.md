#### 5.1.4 同或逻辑

异或函数的反码就是同或函数，其推导过程如下所示：
$$X = \overline{A\bar{B} + \bar{A}B} = \overline{(A\bar{B})} \cdot \overline{(\bar{A}B)} = (\bar{A} + B)(A + \bar{B}) = \bar{A}A + \bar{A}\bar{B} + BA + B\bar{B} = \bar{A}\bar{B} + AB$$

注意，只有当输入 $A$ 和 $B$ 处于相同的电平时，输出 $X$ 才是高电平。

同或逻辑可以通过简单地将异或逻辑的输出反相来实现，如图 5.6(a) 所示，或者直接由表达式 $\bar{A}\bar{B} + AB$ 来实现，如图 5.6(b) 所示。

##### 图 5.6 实现同或逻辑的两种等价方法 (打开文件 F05-06 可验证该操作)

*   **(a) $X = \overline{A\bar{B} + \bar{A}B}$**：
    输入 $A$ 和 $B$ 经过异或门（XOR）后，再通过一个非门（反相器）输出 $X$。
*   **(b) $X = \bar{A}\bar{B} + AB$**：
    输入 $A$ 和 $B$ 分别经非门产生 $\bar{A}$ 和 $\bar{B}$。

    下支路：$A$ 和 $B$ 输入与门，输出 $AB$。
    两路输出通过或门相加，得到 $X$。

## 5.2 组合逻辑电路的实现

### 5.2.1 从布尔表达到逻辑电路

◇ 每一个布尔表达式都有一个对应的逻辑电路，每一个逻辑电路也都有一个对应的布尔表达式。

考虑下面这个布尔表达式：
$$X = AB + CDE$$

简单观察该表达式，就会发现这个表达式由两个项 $AB$ 和 $CDE$ 组成，并且有一个 5 变量的域。第一项由 $A$ 和 $B$ 相与组成，而第二项由 $C$、$D$ 和 $E$ 相与组成，这两项再进行或运算，从而形成输出 $X$。这些运算结构由如下相关的表达式所指示：

$$
\begin{aligned}
& \searrow \ \ \ \searrow \ \ \ \ \text{与} \\
& \ \ X = AB + CDE \\
& \nearrow \\
& \text{或}
\end{aligned}
$$
（图示指示：$AB$ 与 $CDE$ 分别进行“与”运算，再将结果进行“或”运算得到 $X$）

**全加器 4：**
$$C_{\text{in4}} = C_{\text{out3}}$$

$$\quad\quad = C_{g4} + C_{p4}C_{g3} + C_{p4}C_{p3}C_{g2} + C_{p4}C_{p3}C_{p2}C_{g1} + C_{p4}C_{p3}C_{p2}C_{p1}C_{\text{in1}}$$

注意，对于这些表达式，每一级全加器的输出进位仅由最初的输入进位($C_{\text{in1}}$)及那一级的 $C_g$ 和 $C_p$ 函数和前一级的 $C_g$ 和 $C_p$ 函数确定。因为每一级的 $C_g$ 和 $C_p$ 函数可以由这一级全加器的输入位 $A$ 和 $B$ 来表示，所以所有的输入进位可以立即获得(除了门的延迟)，不需要等到进位异步传输通过每一级后才得到最后结果。因此，超前进位技术加快了加法运算的速度。

#### 6.3.3 超前进位与异步进位加法器的组合

如同多数的集成电路加法器，6.2 节介绍的 4 位并行加法器 74HC283 是一个超前进位加法器。当这些加法器级联起来，把处理二进制数的能力扩展到 4 位以上时，一个加法器的进位输出将连接到下一个加法器的进位输入。当两个以上的 74HC283 级联时，就在 4 位加法器中间产生了异步进位。最终的加法器实际上是一个超前进位和异步进位的组合。每个中规模集成(MSI)电路加法器的内部使用超前进位机制，当进位从一个加法器传输到下一个加法器时，异步进位就起作用了。

在计算机中，高速缓冲存储器(cache)是介于中央处理器(CPU)和低速主存储器之间的高速存储器。CPU通过发送数据在存储器中的地址(唯一的地址)来获取数据。地址的一部分称为标识符(tag)。标识符地址比较器将CPU中的标识符与高速缓冲存储器目录中的标识符进行比较。如果二者是一致的，那么这个地址数据已经在高速缓冲存储器中，可以很快地获取。如果这两个标识符不一致，那么数据则必须从主存储器中以慢得多的速度获取。

#### 计算机小知识
指令告知计算机应该进行什么样的运算。指令以机器码 (1 和 0) 的形式存在，为了使计算机执行指令，需要对指令进行译码。指令译码是指令流水线中的一步，过程如下：从存储器读取指令（取指令），指令被译码，从存储器读取操作数（取操作数），执行指令，结果写回存储器。通常，在当前的指令完成后，流水线才允许执行下一条指令。
