# 五、函数

## 5.1 函数

**定义：**

设 $A, B$ 是非空集合，从 $A$ 到 $B$ 的**函数** $f: A \to B$ 是 $A$ 到 $B$ 的一个关系，使得对 $\text{Dom}(f)$ 中每个 $a$，$f(a)$ 恰好包含 $B$ 中一个元素。记 $f(a) = b$。

函数也称作**映射**或**变换**。$a$ 称**自变量**，$f(a)$ 称**函数值**或 $a$ 在 $f$ 下的**像**。

- 若 $f$ 处处有定义（$\text{Dom}(f) = A$），称 $f$ 处处有定义
- $f: A \to B$ 且处处有定义、满射时，称为 $A$ 与 $B$ 之间的**一一对应**

### 特殊函数类

- **单射（injection）**：$\forall a_1, a_2 \in A$，$a_1 \ne a_2 \Rightarrow f(a_1) \ne f(a_2)$。等价地 $f(a_1) = f(a_2) \Rightarrow a_1 = a_2$。
- **满射（surjection）**：$\forall b \in B, \exists a \in A, f(a) = b$，即 $\text{Ran}(f) = B$。
- **双射（bijection）**：单射的函数 $f$（即 $\text{Dom}(f)$ 与 $\text{Ran}(f)$ 之间一一对应）。若 $f$ 还处处有定义且满射，则称 $A$ 与 $B$ 之间**一一对应**。

> 注意本教材的术语：单射函数 $f$ 使 $\text{Dom}(f)$ 与 $\text{Ran}(f)$ 一一对应，即"双射"；而处处有定义且满射的双射才称为 $A, B$ 之间的"一一对应"。

### 复合与逆

**复合** $g \circ f$：$(g \circ f)(a) = g(f(a))$，是 $f$ 跟随 $g$ 的复合（$f$ 先作用）。

**性质**：

- $(g \circ f)^{-1} = f^{-1} \circ g^{-1}$
- 若 $f, g$ 单射则 $g \circ f$ 单射
- 若 $f, g$ 满射则 $g \circ f$ 满射
- $f$ 是 $A, B$ 间一一对应 $\Leftrightarrow$ $f^{-1}$ 是 $B, A$ 间一一对应，且 $f \circ f^{-1} = I_B$，$f^{-1} \circ f = I_A$

**定理**：若 $f: A \to B$ 处处有定义，则 $f$ 可逆当且仅当 $f$ 是单射。

## 5.2 计算机科学中的函数

### 散列函数

为在计算机中存储记录，构造从**密钥**集合到表号集合的**散列函数**，常使用模 $n$ 函数。

- **冲突**：不同密钥被分配到同一表号
- 解决方法：连接表（链表）挂在该表号下
- 模数宜选素数

散列函数也用于密码学（数字指纹、消息验证）。

### 模糊集

**模糊集**：全集 $U$ 上取值于 $[0, 1]$ 的函数 $f$，是特征函数的推广。$f(x)$ 称**隶属度**。

- $f(x) = 0$：$x$ 不在模糊集中；$f(x) = 1$：$x$ 完全属于
- $0 < f(x) < 1$：$x$ 在某种程度上属于
- 普通集合是模糊集的特例（隶属度只取 0 或 1）

**模糊集运算**（推广特征函数定理）：

- 交：$(f \cap g)(x) = \min(f(x), g(x))$
- 并：$(f \cup g)(x) = \max(f(x), g(x))$
- 补：$\bar{f}(x) = 1 - f(x)$

### 模糊逻辑

模糊逻辑推广二值逻辑，命题真值取 $[0, 1]$ 中任意值，应用于模糊控制、人工智能等。

## 5.3 函数的增长

### 增长记号

计算机科学中常用 $\Theta$-类（Theta 类）描述函数增长阶：

$$
f = \Theta(g) \text{ 当且仅当 } f \text{ 与 } g \text{ 有相同的增长阶}
$$

形式化：$f = \Theta(g)$ 当且仅当存在正整数 $C_1, C_2, n_0$，使 $|f(n)| \le C_1 |g(n)|$ 且 $|g(n)| \le C_2 |f(n)|$（$n \ge n_0$）。

大 $O$ 记号是其一部分：$f = O(g)$ 当且仅当 $|f(n)| \le C |g(n)|$（$n \ge n_0$）。

### 确定函数 $\Theta$-类的法则

- 若 $f(n) = p(n)$ 为 $d$ 次多项式，则 $f = \Theta(n^d)$
- $n^d = \Theta(n^d)$，$\log n = \Theta(\log n)$
- $1 < a < b \Rightarrow a^n = O(b^n)$，$a^n \ne \Theta(b^n)$
- $n^d = O(b^n)$，$b^n \ne O(n^d)$（$b > 1$）
- $\log_b n = \Theta(\log_a n)$（任意 $a, b > 1$）

### 常见 $\Theta$-类（由低到高）

$$
1 \prec \log n \prec n \prec n \log n \prec n^2 \prec n^3 \prec 2^n \prec n! \prec n^n
$$

## 5.4 置换函数

### 置换

集合 $A$ 到自身的**双射（一一对应）**称为 $A$ 上的**置换**。有限集合 $A$（$|A| = n$）上的置换共 $n!$ 个，构成**对称群** $S_n$。

### 置换的复合

两个置换的复合仍是置换。置换的逆也是置换。

### 偶置换与奇置换

一个置换可表示为若干个**对换**（二元交换）的复合。对换个数的奇偶性是置换的不变量：

- **偶置换**：可表示为偶数个对换的复合
- **奇置换**：可表示为奇数个对换的复合

**定理**：任意置换要么偶要么奇，不能兼是。
