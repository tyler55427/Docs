# 六、偏序集

## 6.1 偏序集

**定义：**

集合 $A$ 上的关系 $R$ 如果是**自反的、反对称的和传递的**，那么称 $R$ 是一个**偏序**。集合 $A$ 与偏序 $R$ 一起称作**偏序集**，记 $(A, R)$。

- 常用符号 $\le$ 表示偏序（约定 $(A, \ge)$ 表示其对偶偏序集，$\ge$ 为 $\le^{-1}$）
- 若 $a \le b$ 或 $b \le a$，称 $a, b$ **可比的**
- 若偏序集中每对元素都可比，称 $A$ 为**全序集**，偏序称为**全序**，$A$ 也称**链**

**典型偏序**：

- 集合族上的包含关系 $\subseteq$
- 正整数集上的 $\le$（全序）或 $\ge$
- 正整数集上的整除关系 $\mid$（非全序，如 $2 \nmid 7$ 且 $7 \nmid 2$）

### 哈塞图

偏序集的有向图可简化为**哈塞图**：

1. 去掉所有自环（自反性）
2. 去掉由传递性可推出的边（若 $a \le b \le c$，去掉 $a$ 到 $c$ 的边）
3. 约定所有边朝上，省略箭头
4. 用点（而非圆圈）表示顶点

哈塞图完全描述了偏序，比有向图简单。对偶偏序集 $(A, \ge)$ 的哈塞图就是把 $(A, \le)$ 的哈塞图颠倒过来。

### 字典序

$A = \mathbb{R}^2 = \mathbb{R} \times \mathbb{R}$ 上的字典序：每条竖直线上按通常序，靠左竖线上的点比靠右的小。它是全序。

## 6.2 偏序集的极值元

### 极大元与极小元

- **极大元** $a$：$A$ 中不存在 $c$ 使 $a < c$（即没有元素严格大于 $a$）
- **极小元** $b$：$A$ 中不存在 $c$ 使 $c < b$

> 极大元/极小元不一定唯一。
> $(A, \ge)$ 的极大元就是 $(A, \le)$ 的极小元。

**定理**：有限非空偏序集至少有一个极大元和一个极小元。

### 最大元与最小元

- **最大元** $a$：$\forall b \in A, b \le a$（大于等于所有元素）
- **最小元** $b$：$\forall b \in A, a \le b$

最大元/最小元若存在则唯一。

最大元又称**单位元 $I$**，最小元又称**零元 $0$**。

### 上界与下界

设 $A'$ 是偏序集 $A$ 的子集：

- **上界**：$a \in A$ 使 $\forall b \in A', b \le a$
- **下界**：$a \in A$ 使 $\forall b \in A', a \le b$
- **最小上界（LUB）**：所有上界中的最小元，记 $\text{LUB}(A')$
- **最大下界（GLB）**：所有下界中的最大元，记 $\text{GLB}(A')$

### 拓扑排序

有限偏序集可产生一个**线性序**（全序），使若 $a \le b$ 则 $a$ 排在 $b$ 前。

算法：反复选取一个极小元放入序列，从剩余集中删除。

## 6.3 格

### 格的定义

偏序集 $(L, \le)$ 称为**格**，若 $L$ 中任意 $a, b$，**最小上界**和**最大下界**都存在。

- $a \vee b = \text{LUB}(a, b)$（**并 / join**）
- $a \wedge b = \text{GLB}(a, b)$（**交 / meet**）

**例**：$(P(S), \subseteq)$ 是格，$A \vee B = A \cup B$，$A \wedge B = A \cap B$。

### 格的性质

**对偶原理**：把格命题中 $\vee \leftrightarrow \wedge$、$\le \leftrightarrow \ge$，命题仍成立。

**定理**：$a \le b \Leftrightarrow a \vee b = b \Leftrightarrow a \wedge b = a$。

### 格的类型

| 类型             | 额外条件                                                           |
| ---------------- | ------------------------------------------------------------------ |
| **分配格** | $a \wedge (b \vee c) = (a \wedge b) \vee (a \wedge c)$ 及对偶    |
| 模格（习题涉及） | $a \le c \Rightarrow a \vee (b \wedge c) = (a \vee b) \wedge c$  |
| **有界格** | 有最大元$I$ 和最小元 $0$                                       |
| **补格**   | 有界格中每个元素有补元$a'$（$a \vee a' = I, a \wedge a' = 0$） |

分配格必满足模律（习题中的模格条件）；全序集（链）是分配格。

## 6.4 有限布尔代数

### 布尔代数的定义

**布尔代数**是有界、分配、补格，即 $(B, \wedge, \vee, ', 0, I)$：

- $(B, \wedge, \vee)$ 是分配格
- 有界（最大元 $I$、最小元 $0$）
- 有补（每个 $a$ 有补元 $a'$，$a \vee a' = I, a \wedge a' = 0$）

**布尔代数基本定律**：

- 幂等：$a \vee a = a$，$a \wedge a = a$
- 交换、结合、分配
- 同一：$a \vee 0 = a$，$a \wedge I = a$
- 补：$a \vee a' = I$，$a \wedge a' = 0$
- 双重否定：$(a')' = a$
- 德·摩根：$(a \vee b)' = a' \wedge b'$，$(a \wedge b)' = a' \vee b'$
- 对偶原理：$\vee \leftrightarrow \wedge$、$0 \leftrightarrow I$ 命题仍成立

### 有限布尔代数的结构

**$B_n$**：$n$ 元集合 $S$ 的幂集 $P(S)$ 在 $\subseteq$ 下构成的布尔代数，$|B_n| = 2^n$。

**定理**：一个有限格是布尔代数当且仅当它与某个 $B_n$ 同构。因此每个有限布尔代数的元素个数为 $2^n$。

**$D_n$**（$n$ 的所有正因子在整除关系下的格）：

- $D_n$ 是布尔代数当且仅当 $n$ 是互异素数之积 $n = p_1 p_2 \cdots p_k$（$|D_n| = 2^k$）

## 6.5 布尔代数上的函数

### 布尔函数

$f: B_n \to B$ 的函数。$B = \{0, 1\}$ 是有两个元素的布尔代数。

### 小项

$n$ 个变量 $x_1, \cdots, x_n$ 的**小项**：每个变量取原变量或其补的合取，形如 $x_1^{a_1} \wedge x_2^{a_2} \wedge \cdots \wedge x_n^{a_n}$（$x_i^{a_i}$ 为 $x_i$ 或 $x_i'$）。$n$ 个变量共 $2^n$ 个小项。

**定理**：每个布尔函数可唯一表示为小项的并（析取）。

### 卡诺图

将函数 $f: B_n \to B$ 的 1-值用方格图表示（$n = 2, 3, 4$ 时常用），通过将相邻的 1 合并成最大矩形来化简布尔表达式。

- 每个基本矩形对应一个简单布尔表达式
- 用最大可能的矩形合并 1-值
- 顶行与底行、左列与右列可"卷起来"相邻

**例**：$f(x, y) = x' \vee y'$ 可由两个矩形合并得到。
