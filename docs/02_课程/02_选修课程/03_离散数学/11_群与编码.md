# 十一、群与编码

## 11.1 二元信息码与检错码

### 报文与字

- **报文**：有限字母表中字符的有限序列
- **字**：信息基本单位，是 $m$ 个 0 和 1 的序列。取字母表 $B = \{0, 1\}$

### 群 $B^m$

把 $B$ 看作群 $\mathbb{Z}_2$（模 2 加法）。由 9.5 节定理 1，$B^m = B \times B \times \cdots \times B$（$m$ 个因子）在运算 $\oplus$ 下是群：

$$
(x_1, \cdots, x_m) \oplus (y_1, \cdots, y_m) = (x_1 + y_1, \cdots, x_m + y_m)
$$

- 单位元 $\vec{0} = (0, \cdots, 0)$
- 每个元素是它自身的逆
- $|B^m| = 2^m$

### 传输模型

发送字 $x \in B^m$ $\xrightarrow{\text{传输通道（有噪声）}}$ 接收字 $x_t \in B^m$。若 $x \ne x_t$ 即传输出错。

### $(m, n)$ 编码函数

选取整数 $n > m$ 和**单射函数** $e: B^m \to B^n$，称 $e$ 为 **$(m, n)$ 编码函数**。$e(b)$ 称表示 $b$ 的**代码字**，代码字集合 $\text{Ran}(e) \subseteq B^n$。

### 检测错误

若 $x = e(b)$ 有 $k$ 个或更少位置与 $x_t$ 不同，称有 $k$ 个或更少错误传送。若此时 $x_t$ 不是代码字，称 $e$ **检测** $k$ 个或更少错误。

### 权

$x \in B^n$ 中 1 的个数称 $x$ 的**权**，记 $|x|$。

### Hamming 距离

$\delta(x, y) = |x \oplus y|$，即 $x, y$ 不同位置的个数。

**定理 1**（距离函数性质）：(a) $\delta(x, y) = \delta(y, x)$；(b) $\delta(x, y) \ge 0$；(c) $\delta(x, y) = 0 \Leftrightarrow x = y$；(d) $\delta(x, y) \le \delta(x, z) + \delta(z, y)$（三角不等式）。

### 最短距离与检错

**最短距离**：所有不同代码字对之间距离的最小值。

**定理 2**：$(m, n)$ 编码函数 $e$ 能检测 $k$ 个或更少错误 $\Leftrightarrow$ 最短距离至少为 $k + 1$。

### 群码

**群码**：$e(B^m) = \text{Ran}(e)$ 是 $B^n$ 的子群。因 $B^n$ 是阿贝尔群，每个子群是正规子群。

**定理 3**：群码的最短距离 = 非零代码字的最小权。

### 奇偶校验矩阵与群码构造

设 $H$ 为 $n \times r$ 布尔矩阵（$r = n - m$），最后 $r$ 行构成 $r \times r$ 单位矩阵。定义 $f_H: B^n \to B^r$，$f_H(x) = x * H$（模 2 布尔积）。

- **定理 5**：$f_H$ 是群 $B^n$ 到 $B^r$ 的同态
- **推论 1**：$N = \{x \in B^n \mid x * H = \vec{0}\}$ 是 $B^n$ 的正规子群（同态核）
- **编码函数** $e_H$：$e_H(b) = b_1 \cdots b_m x_1 \cdots x_r$，$x_i = b_1 h_{1i} + \cdots + b_m h_{mi}$
- **定理 6**：$x * H = \vec{0} \Leftrightarrow x = e_H(b)$（某 $b$）
- **推论 2**：$e_H(B^m)$ 是子群，$e_H$ 是群码

## 11.2 译码与纠错

### $(n, m)$ 译码函数

**满射** $d: B^n \to B^m$，使无噪声时 $d \circ e = I_{B^m}$，称与 $e$ 相关的 **$(n, m)$ 译码函数**。

### 纠正错误

若 $x = e(b)$ 有 $k$ 个或更少错误传送并接收 $x_t$ 时都有 $d(x_t) = b$，称 $(e, d)$ **校正** $k$ 个或更少错误。

### 最大似然译码

收到 $x_t$ 后，计算 $x_t$ 与所有代码字的距离，选**第一个**最接近的代码字 $x^{(s)}$；若 $x^{(s)} = e(b)$，定义 $d(x_t) = b$。

### 定理（纠错能力）

$(e, d)$（最大似然译码）能纠正 $k$ 个或更少错误 $\Leftrightarrow$ $e$ 的最短距离至少为 $2k + 1$。

### 群码的陪集译码

$N = e(B^m)$ 是 $B^n$ 的子群。$x_t$ 的左陪集 $x_t \oplus N = \{\varepsilon_1, \cdots, \varepsilon_{2^m}\}$，$\varepsilon_j = x_t \oplus x^{(j)}$。$x_t$ 到代码字 $x^{(j)}$ 的距离 $= |\varepsilon_j|$。

**陪集头部**（陪集首部）：陪集中权最小的字（不一定唯一）。

**定理**：有限子群的每个左陪集与子群元素个数相同。

### 译码步骤

1. 确定 $B^n$ 中 $N$ 的所有左陪集（共 $2^r$ 个）
2. 每个陪集求头部（最小权的字）
3. 收到 $x_t$，确定其所在陪集，取头部 $\varepsilon$
4. 计算 $x = x_t \oplus \varepsilon = e(b)$，则 $d(x_t) = b$

### 用校验子简化

**校验子**：$f_H(x) = x * H$。

**定理**：$x, y$ 属于 $N$ 的同一左陪集 $\Leftrightarrow f_H(x) = f_H(y)$（校验子相同）。

简化：只需保存各陪集头部及校验子，收到 $x_t$ 后计算 $f_H(x_t)$，查表得头部 $\varepsilon$，则 $x = x_t \oplus \varepsilon$。

## 11.3 公钥密码学

### RSA 公钥密码系统

1978 年 Rivest、Shamir、Adelman 提出的 RSA 系统，基于费马小定理的推广。

### 定理（RSA 理论基础）

设 $p, q$ 是不同素数，$k$ 是任意整数：

- (a) 若 $\text{GCD}(a, pq) = 1$，则 $a^{k(p-1)(q-1)} \equiv 1 \pmod{pq}$
- (b) 对任意整数 $a$，$a^{k(p-1)(q-1)+1} \equiv a \pmod{pq}$

### 加密

1. 信息转整数：字母 $A, B, \cdots, Z$ 表示 $0, 1, \cdots, 25$；一对字母 $\alpha\beta$ 表示 $(26\alpha) + \beta$（$0 \sim 675$）
2. 选素数 $p, q$，令 $m = pq$，$n = (p-1)(q-1)$
3. 选与 $n$ 互素的 $s$，公开 $m, s$（**公钥**）
4. 发送方：$y \equiv x^s \pmod{m}$（$m$ 至少为 675）

### 解密

$s$ 模 $n$ 有乘法逆 $t$（$st \equiv 1 \pmod n$，用欧几里得算法求）。

$$
y^t \equiv x^{st} \equiv x^{1 + k(p-1)(q-1)} \equiv x \pmod{m}
$$

因 $x < m$，恢复原整数 $x$。

**例**：$p = 19, q = 37$，$m = 703$，$n = 648$，$s = 25$。加密 GO（$x = 170$）得 $y = 664$。$t = 337$，解密 $664^{337} \equiv 170 \pmod{703}$。

### 安全性

解密需知 $t$，进而需知 $n$，即需分解 $m = pq$。实际中 $p, q$ 取 $10^{100}$ 量级，$m$ 为 $10^{200}$ 量级，分解困难。近似素数定理：$\le m$ 的素数约 $\frac{m}{\ln m}$ 个，试除需天文数字时间。

> 若额外知道 $n = (p-1)(q-1)$，则由 $p + q = m - n + 1$ 和 $pq = m$ 可解出 $p, q$，故 $n$ 必须保密。

> **说明**：本教材第 11 章不含中国剩余定理、欧拉定理（通用形式 $a^{\varphi(m)} \equiv 1$）、欧拉 $\varphi$ 函数、Miller-Rabin 素性测试、Mobius 反演、二次剩余等内容。RSA 的理论基础是费马小定理的扩展（定理 1）。
