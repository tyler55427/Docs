# 九、半群与群

## 9.1 再论二元运算

### 二元运算

集合 $S$ 上的**二元运算** $*$：$*: S \times S \to S$，将每对元素映射到 $S$ 中的元素（满足**封闭性**）。

**运算表（Cayley 表）**：用表格表示有限集上的二元运算。

### 性质

- **可交换**：$a * b = b * a$
- **可结合**：$(a * b) * c = a * (b * c)$
- **幂等**：$a * a = a$

> 第 1.6 节已介绍数学结构、封闭性、单位元、逆元等概念。

## 9.2 半群

### 半群与幺半群

- **半群**：$(S, *)$ 是具有**可结合**二元运算的数学结构
- **幺半群**（monoid）：有**单位元** $e$（$a * e = e * a = a$）的半群

**例**：$(\mathbb{Z}, +)$ 是幺半群（单位元 0）；$(\mathbb{Z}, \cdot)$ 是幺半群（单位元 1）；$(S^*, \cdot)$（字符串连接）是幺半群（单位元 $\wedge$）。

### 子半群

$S$ 的子集 $T$ 若对运算封闭，则 $(T, *)$ 是 $(S, *)$ 的**子半群**。若还含单位元则是**子幺半群**。

### 幂

幺半群 $(S, *)$ 中，$a^0 = e$，$a^n = a * a^{n-1}$（$n \ge 1$）。$a^n * a^m = a^{n+m}$，$(a^n)^m = a^{nm}$。

**定理**：若 $a * b = b * a$，则 $(a * b)^n = a^n * b^n$。

## 9.3 半群的积与商

### 直积

$(S_1, *_1)$ 与 $(S_2, *_2)$ 的**直积** $(S_1 \times S_2, *)$：$(a_1, a_2) * (b_1, b_2) = (a_1 *_1 b_1, a_2 *_2 b_2)$，仍是半群/幺半群。

### 同余关系

$S$ 上的等价关系 $R$ 若满足：$a R b \wedge c R d \Rightarrow (a * c) R (b * d)$，称 $R$ 为**同余关系**。

### 商半群

若 $R$ 是半群 $(S, *)$ 上的同余关系，则商集 $S/R$ 上可定义运算 $[a] * [b] = [a * b]$，$(S/R, *)$ 是半群，称**商半群**。

**定理**：自然映射 $f: S \to S/R$，$f(a) = [a]$，是满同态。

## 9.4 群

### 群的定义

**群** $(G, *)$：满足

1. $*$ 可结合
2. 存在**单位元** $e$（$a * e = e * a = a$）
3. 每个元素 $a$ 有**逆元** $a^{-1}$（$a * a^{-1} = a^{-1} * a = e$）

**阿贝尔群（交换群）**：还满足交换律的群。

### 群的性质

- **消去律**：$a * b = a * c \Rightarrow b = c$（左消去）；$b * a = c * a \Rightarrow b = c$（右消去）
- 单位元唯一、逆元唯一
- $(a^{-1})^{-1} = a$，$(a * b)^{-1} = b^{-1} * a^{-1}$
- 方程 $a * x = b$ 有唯一解 $x = a^{-1} * b$；$y * a = b$ 有唯一解 $y = b * a^{-1}$

### 有限群

**有限群**：$|G|$ 有限，$|G|$ 称为群的**阶**。阶为 1、2、3、4 的非同构群可枚举。

- **循环群**：$\exists a \in G$，$G = \{a^n \mid n \in \mathbb{Z}\}$，$a$ 称**生成元**
- **Klein 四元群** $V$、$\mathbb{Z}_4$ 是阶 4 的两个非同构群

### $\mathbb{Z}_n$ 作为群

$\mathbb{Z}_n = \{[0], [1], \cdots, [n-1]\}$ 在模 $n$ 加法下是群（也是循环群）。

## 9.5 群的积与商

### 陪集

设 $H$ 是群 $G$ 的子群，$a \in G$：

- **左陪集** $aH = \{a * h \mid h \in H\}$
- **右陪集** $Ha = \{h * a \mid h \in H\}$

**性质**：

- $|aH| = |H|$
- $aH = bH \Leftrightarrow a^{-1} b \in H$
- $G$ 的所有左陪集构成 $G$ 的划分

### 正规子群

$H$ 是 $G$ 的**正规子群**：$\forall a \in G, aH = Ha$（左右陪集相同）。

- 阿贝尔群的所有子群都是正规子群
- $G$ 的任意子群 $H$，若 $[G : H] = 2$（两个陪集），则 $H$ 是正规子群

### 商群

若 $N$ 是 $G$ 的正规子群，$G/N = \{aH \mid a \in G\}$（所有陪集的集合）在运算 $(aH)(bH) = (ab)H$ 下构成群，称**商群**。

### 同态与同构

**同态** $f: G \to G'$：$\forall a, b \in G, f(ab) = f(a) f'(b)$。满同态、单同态、同构（双射同态）。

**同态核** $\ker(f) = \{a \in G \mid f(a) = e'\}$，是 $G$ 的正规子群。

### 定理（同态基本定理）

设 $f: S \to T$ 是半群 $(S, *)$ 到半群 $(T, *')$ 的同态，$R$ 定义为 $aRb \Leftrightarrow f(a) = f(b)$，则

- (a) $R$ 是 $S$ 上的同余关系
- (b) 商半群 $S/R$ 与 $f(S)$ 同构

对群的情形（推论 1）：设 $f: G \to G'$ 是满同态，则

- (a) $\ker(f)$ 是 $G$ 的正规子群
- (b) 商群 $G/\ker(f)$ 与 $G'$ 同构

即 $G/\ker(f) \cong \text{Im}(f)$。

## 9.6 其他数学结构

### 环

**环** $(S, +, *)$：$(S, +)$ 是阿贝尔群，$*$ 可结合且对 $+$ 满足分配律。

- **交换环**：$*$ 可交换
- **含幺环**：$*$ 有单位元 $1$（$+$ 的单位元记 $0$）
- **零因子**：$a \ne 0, b \ne 0$ 但 $a * b = 0$，则 $a, b$ 为零因子

**定理**：设 $R$ 是可交换含幺环，则

- (a) $0 * x = x * 0 = 0$（零元吸收）
- (b) $(-a) * b = a * (-b) = -(a * b)$
- (c) $(-a) * (-b) = a * b$
- (d) $a * c = a * d \wedge a \ne 0 \wedge$ 无零因子 $\Rightarrow c = d$（消去律）

### 域

**域**：可交换含幺环 $F$ 中每个非零元有乘法逆（即 $F^*$ 在乘法下是阿贝尔群）。

**域的性质**：域中无零因子，消去律成立。

**定理**：当 $n$ 是素数时，环 $\mathbb{Z}_n$ 是域。

**定理**：

- (a) 若 $G = \{g_1, \cdots, g_n\}$ 是有限阿贝尔群，单位元 $e$，则对任意 $a \in G$，$a^n = e$
- (b) **费马小定理**：若 $p$ 是素数且 $\text{GCD}(a, p) = 1$，则 $a^{p-1} \equiv 1 \pmod{p}$
- (c) 若 $p$ 是素数、$a$ 是任意整数，则 $a^p \equiv a \pmod{p}$

### $\mathbb{Z}_n$ 的性质

- 若 $\text{GCD}(a, n) = 1$，则 $\bar{a}$ 在 $\mathbb{Z}_n$ 中有乘法逆（由 1.4 节定理 4(a)，存在 $k, s$ 使 $ak + ns = 1$）
- $\mathbb{Z}_n$ 无零因子 $\Leftrightarrow$ $n$ 是素数
- $\mathbb{Z}_n$ 是域 $\Leftrightarrow$ $n$ 是素数

> **说明**：本教材第 9 章不含 Lagrange 定理（子群阶整除群阶）、Cayley 定理（有限群同构于对称群子群）、整环/除环的概念、群的同态基本定理以外的同构定理（第二、第三同构定理）等内容。
