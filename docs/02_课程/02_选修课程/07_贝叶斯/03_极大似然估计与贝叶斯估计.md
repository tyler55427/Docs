# 三、极大似然估计与贝叶斯估计
## 极大似然估计（频率学派）

**似然函数**：$L(\theta) = p(D|\theta)$，不是概率分布，但可当作概率模型

- 独立同分布 (IID) 采样时，似然可展开为连乘：
$$p(D|\theta) = p(\{y_i\}|\theta) = \prod_i p(y_i|\theta)$$

**极大似然估计 (MLE)**：
$$\hat{\theta} = \arg\max_\theta p(D|\theta)$$

**实用技巧**：
- 极大化似然 → 极小化负对数似然（防止精度问题、连乘变连加）
- $\log p(D|\theta)$ 记为 $LL(\theta)$
- $\arg\min_\theta -\sum_i \log p(x^{(i)}|\theta)$
- 求极值：梯度下降或求导（二阶导 < 0 验证极大值）

> 例：硬币的似然 $\theta = \frac{\sum y_i}{N}$

## 贝叶斯估计

**贝叶斯规则转换**：
$$p(\theta|D) = \frac{p(D|\theta) p(\theta)}{p(D)}$$

| 组成部分 | 含义 |
|----------|------|
| 似然 $p(D|\theta)$ | 模型（已知） |
| 先验 $p(\theta)$ | 对参数的不确定性 |
| 证据 $p(D)$ | $\int p(D|\theta) p(\theta) d\theta$（难计算） |
| 后验 $p(\theta\|D)$ | 目标（参数的分布） |

## 贝叶斯 vs 频率学派

| | 贝叶斯 | 频率学派 |
|--|--------|----------|
| 估计结果 | 参数的概率分布 | 一个点的估计值 |
| MLE | 是"点估计" | 贝叶斯给出的是分布 |
| 特点 | 包含不确定性 | 不确定性通过抽样分布表达 |

## 计算 $p(D)$ 的四种方法

| 方法 | 说明 |
|------|------|
| 1. **网格近似** | $\theta$ 离散近似，用求和近似积分 |
| 2. **准确数学分析** | 构造合适的 $p(\theta)$ 使后验形式一致（共轭先验） |
| 3. **MCMC 近似** | 从后验采样更多 $\theta$ |
| 4. **变分近似** | 用 $q(\theta)$ 近似 $p(\theta\|D)$，转为优化问题 |

## 后验预测分布

**MLE 直接代入**：$p(y'|D) \approx p(y'|\hat{\theta})$

**贝叶斯方法**（边缘化）：
$$p(y'|D) = \int p(y'|\theta) p(\theta|D) d\theta$$

对于伯努利分布：$p(y'=1|D) = E(\theta) = \frac{a+b}{N+a+b}$

## 极大后验估计 (MAP)

$$\hat{\theta} = \arg\max_\theta P(\theta|D) = \arg\max_\theta p(D|\theta) p(\theta)$$

等价于（忽略常数 $p(D)$）：
$$= \arg\max_\theta \log p(D|\theta) + \log p(\theta)$$

> 在极大似然基础上 $+\log p(\theta)$（正则项，约束 $\theta$ 的取值）

## 先验与后验的关系

- 样本数量少时，后验偏向先验
- 样本数量多时，后验偏向似然
- 后验是**先验和似然的折中**

## 网格近似

步骤：假设先验 → 计算 $L(\theta)$ → 计算后验

$$p(\theta_i) = \frac{P(\theta_i)}{\sum_j P(\theta_j)} \quad \text{（离散）}$$

归一化：起初不用保证概率和为 1，最后归一化。

> 网格近似将低概率值设 1，然后归一化，而不是置零
