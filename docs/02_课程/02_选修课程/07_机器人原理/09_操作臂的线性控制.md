# 九、操作臂的线性控制
### 基本概念

可用线性微分方程建模的系统

关节处：驱动器、位置传感器、速度传感器

### 开环与闭环控制

| 类型 | 说明 |
|------|------|
| **开环** | 确定操作后无需调整 |
| **闭环** | 反馈的控制系统（控制系统有环路） |

控制信号与关节数量一致

### 二阶线性系统

运动方程：
$$m\ddot{x} + b\dot{x} + kx = 0$$

特征根：
$$s = -\frac{b}{2m} \pm \frac{\sqrt{b^2 - 4mk}}{2m}$$

| 情况 | 特征根 | 运动形式 |
|------|--------|----------|
| $b^2 > 4mk$ | 不相等实根 | 过阻尼（无振荡） |
| $b^2 = 4mk$ | 相等实根 | 临界阻尼 |
| $b^2 < 4mk$ | 复根 | 欠阻尼（振荡） |

稳定的系统：$m, b, k > 0$

### 阻尼比与固有频率

$$s^2 + 2\zeta\omega_n s + \omega_n^2 = 0$$

$$\zeta = \frac{b}{2\sqrt{km}}, \quad \omega_n = \sqrt{\frac{k}{m}}$$

| $\zeta$ 值 | 系统特性 |
|------------|----------|
| $\zeta < 0$ | 负阻尼（不稳定） |
| $0 < \zeta < 1$ | 欠阻尼（振荡） |
| $\zeta = 1$ | 临界阻尼 |

> 欠阻尼：$x(t) = c_1 e^{\lambda t} \cos(\mu t) + c_2 e^{\lambda t} \sin(\mu t)$，其中 $\lambda = -\zeta\omega_n$，$\mu = \omega_n\sqrt{1-\zeta^2}$
>
> 临界阻尼：$x(t) = (C_1 + C_2 t) e^{-\frac{b}{2m}t}$

### 位置调节系统

使质量块保持在固定位置，而不考虑受到的干扰力

假设 $f = -k_p x - k_v \dot{x}$，代入得：

$$m\ddot{x} + (b + k_v)\dot{x} + (k + k_p)x = 0 \to m\ddot{x} + b'\dot{x} + k'x = 0$$

- $k' = k + k_p$：**闭环刚度**
- $b' = b + k_v$：阻尼，$b' = 2\sqrt{m k'}$（临界阻尼配方）

当 $b'/k'$ 为负数时，控制系统不稳定，误差趋向增大。

### 控制规律分解

把控制器分为**基于模型控制部分**和**前馈控制部分**

令 $f = \alpha f' + \beta$：

$$m\ddot{x} + b\dot{x} + kx = \alpha f' + \beta$$

取 $\alpha = m$（化为单位质量运动方程），$\beta = b\dot{x} + kx$，$f' = \ddot{x}$（被控系统内部动力学方程）

再令 $f' = -k_p x - k_v \dot{x} = \ddot{x}$：

$$\ddot{x} + k_v \dot{x} + k_p x = 0$$

$$k_v = 2\sqrt{k_p}$$

### 轨迹跟踪

不要求质量块在期望位置，还希望能跟踪一条轨迹

$$f' = \ddot{x}_d + k_v \dot{e} + k_p e$$

其中 $e, \dot{e}$ 为伺服误差：$e = \theta_d - \theta$，$\dot{e} = \dot{\theta}_d - \dot{\theta}$

代入得：

$$\ddot{e} + k_v \dot{e} + k_p e = 0$$

称为**误差空间方程**

### 抑制干扰

存在外部干扰/噪声也能保持良好性能

$$\ddot{e} + k_v \dot{e} + k_p e = f_{\text{dist}}$$

若 $\max_t f_{\text{dist}}(t) < a$，则误差有界。

### 稳态误差

$f_{\text{dist}}$ 为常数时：
$$k_p e = \frac{f_{\text{dist}}}{m}, \quad e = \frac{f_{\text{dist}}}{k_p m}$$

想要较小的 $e$，则 $k_p$ 应尽量大。

### PID 控制

增加积分项消除稳态误差：

$$f = \ddot{x}_d + k_v \dot{e} + k_p e + k_i \int e \, dt$$

$$\ddot{e} + k_v \dot{e} + k_p e + k_i \int e \, dt = \frac{f_{\text{dist}}}{m}$$

稳态时：$k_i e = 0$，因此 $e = 0$。

### 连续控制与离散时间控制

- 实际计算需要一定时间，输出的力指令是一个离散的阶梯函数
- 若系统更新计算速率比受控系统固有频率快得多，可近似为连续系统
- 结构共振：机构的刚度有限，必须采样频率至少为固有频率的两倍

### 单关节机器人的建模

#### 电机方程

$$F = qV \times B, \quad \tau_m = k_m i_d$$

反电动势：$v = k_e \dot{\theta}_m$

电枢方程：$L_a i_a + R_a i_a = v_a - k_e \dot{\theta}_m$

通过上述假设可建模为二阶线性系统

#### 减速比影响

$$\tau = \eta \tau_m, \quad \dot{\theta} = \frac{\dot{\theta}_m}{\eta}$$

**电机轴平衡方程**：
$$\tau_m = (J_m + \frac{J}{\eta^2}) \ddot{\theta}_m + (b_m + \frac{b}{\eta^2}) \dot{\theta}_m$$

**负载端平衡方程**：
$$\tau = (J + \eta^2 J_m) \ddot{\theta} + (b + \eta^2 b_m) \dot{\theta}$$

| 参数 | 表达式 |
|------|--------|
| 有效惯量 | $I + \eta^2 I_m$ |
| 有效阻尼 | $b + \eta^2 b_m$ |

> 在 $\eta \gg 1$ 时，$I_m$ 是有效惯量的主要部分；为防止负阻尼，$I$ 通常取最大值 $I_{\max}$

#### 单关节控制参数设定

假设：忽略电机电感；大传动比，有效质量为常数 $J_{\max} + \eta^2 J_m$；结构柔性可忽略

控制器分解：

$$\alpha = J_{\max} + \eta^2 J_m, \quad \beta = (b + \eta^2 b_m)\dot{\theta}, \quad \tau' = \ddot{\theta}_d + k_v \dot{e} + k_p e$$

闭环动力学方程：
$$\ddot{e} + k_v \dot{e} + k_p e = \tau_{dist}$$

参数设定：

$$k_p = \omega_n^2 = \frac{1}{4} \omega_{res}^2, \quad k_v = 2\sqrt{k_p} = \omega_{res}$$

其中 $\omega_{res}$ 为结构共振频率：
$$\omega_{res} = \sqrt{\frac{k}{m}}$$

- $k$：柔性结构刚度
- $m$：负载惯量

### 共振频率估计

弹簧系统近似：$\omega_n = \sqrt{\frac{k}{m}}$

估计最低共振频率采用集中质量估计：
- 立杆末端取 $0.23m$
- 旋转轴末端取 $0.33I$

### 三种共振频率

| 类型 | 说明 |
|------|------|
| **开环固有频率** | $\omega_n$ |
| **闭环固有频率** | $\omega_n = \sqrt{k_p} \le \frac{1}{\lambda} \omega_{res}$ |
| **结构共振频率** | $\omega_{res} = \sqrt{\frac{k}{m}}$（使负载惯量求） |
