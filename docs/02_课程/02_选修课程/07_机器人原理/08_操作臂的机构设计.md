# 八、操作臂的机构设计
## 设计原则

- 让机构本身承担力，而非让关节承担
- 基于任务需求的设计（完成特定任务）

### 主要考虑因素

| 因素 | 说明 |
|------|------|
| **自由度** | 工具可以更改、弥补操作臂的自由度不足（可利用工具自带的旋转轴而非关节旋转） |
| **工作空间** | 工作需求与工作空间匹配（工作体积/包络） |
| **负载能力** | 结构与传动系统 |
| **速度** | 一般越快越好 |
| **重复精度与精度** | — |

### 运动学构型（机械臂类型）

| 类型 | 特点 |
|------|------|
| **直角坐标型** | 不用 IK、FK，但体积占用大 |
| **铰接型（关节型/肘型）** | 只用旋转，占用空间小 |
| **SCARA 型** | 负载能力强（前两个转轴竖直，最后一个关节承重） |
| **极坐标型** | — |
| **圆柱坐标型** | — |

### 手腕设计

手腕的第一个关节通常是操作臂的第四关节

1. 三个正交轴才有解析解（微调但不垂直）
2. 三个回转关节，倾斜的旋转轴：能达到一些姿态
3. 没有相交轴但 2、3、4 关节平行：也有封闭解

### 效率指标

**结构长度系数**：
$$Q_L = \frac{\sum_{i=1}^{N} (a_{i+1} + d_i)}{\sqrt{V}}$$

可达空间体积，越小越好（直角坐标比关节型消耗更多材料）

**操作度**：
$$w = \sqrt{|J(\theta) J^T(\theta)|}$$

衡量灵巧性，$|J(\theta)| = 0$ 时存在奇异位形

**惯性椭球**：表示运动能力

### 冗余结构与闭链结构

- **冗余结构**：6 自由度但有限制，逆向运动学复杂，正向运动学困难。冗余可避免碰撞
- **闭链结构**：机械臂末端固定在一起

### 驱动方案

#### 驱动器的选择原则

- 直观类：靠近关节，负载大
- 靠近不动的位置：防止上一个驱动器承担下一个驱动器的重量（使用传动）

#### 减速系统

传动：

| 类型 | 特点 |
|------|------|
| **齿轮** | 转速与扭矩；齿轮之间的间隙导致精度误差（传动比：齿轮减速，扭矩增加） |
| **皮带/链条** | 灵活；但弹性导致精度问题，非钢体共振 |
| **丝杠** | 旋转 → 直线（钢珠轴承） |

#### 驱动器类型

| 类型 | 特点 |
|------|------|
| **液压** | 力量大；但器件多 |
| **气缸** | 力量小，精度差 |
| **电机** | — |

操作臂结构与驱动系统的总体刚度是设计重点考虑问题

### 刚度与变形

- 刚度 ↑ → 精度 ↑，共振 ↓
- 传动刚度影响系统刚度
- 连杆刚度

### 位置检测

- **光学编码器**：误差来自于圆心与转轴的不重合
- **力传感器**

伺服控制：根据误差传递扭矩的命令
