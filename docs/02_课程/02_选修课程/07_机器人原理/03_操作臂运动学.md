# 三、操作臂运动学
## 基本概念

**运动学**：研究位置、速度、加速度、位置变量对时间/其他变量的高阶微分

$$vdv = ads$$

**正向运动学（Forward Kinematics）**：给定关节角，计算末端执行器的位姿（关节空间 → 笛卡尔空间）

**DH 矩阵**：所有关节的 4 个参数汇总的矩阵

## 连杆参数

| 参数 | 含义 |
|------|------|
| $a_{i-1}$（连杆长度） | 两关节轴 $i-1$ 与 $i$ 之间公垂线的长度（沿 $x_{i-1}$ 方向） |
| $\alpha_{i-1}$（连杆扭转角） | 绕 $x_{i-1}$ 轴，从 $z_{i-1}$ 旋转到 $z_i$ 的角度 |
| $d_i$（连杆偏距） | 沿 $z_i$ 轴，从 $x_{i-1}$ 移动到 $x_i$ 的距离 |
| $\theta_i$（关节角） | 绕 $z_i$ 轴，从 $x_{i-1}$ 旋转到 $x_i$ 的角度 |

## 建立连杆坐标系的步骤

1. 找出各关节轴，并标出这些轴线的延长线
2. 找出关节轴 $i$ 和 $i+1$ 之间的公垂线或交点，以其作为连杆坐标系 $\{i\}$ 的原点
3. 规定 $z_i$ 轴沿关节轴 $i$ 的指向
4. 规定 $x_i$ 轴沿公垂线的指向；若关节轴 $i$ 和 $i+1$ 相交，则规定 $x_i$ 轴垂直于两轴所在的平面
5. 按照右手定则确定 $y_i$ 轴
6. 当第一个关节变量为 0 时，规定坐标系 $\{0\}$ 和 $\{1\}$ 重合；对于 $\{N\}$，原点可任意选取，通常使参数为 0

> **特殊情况**：$z_{i+1}$ 与 $z_i$ 相交时 $a_{i-1}=0$；共线时 $x_i$ 可任意选

## DH 变换矩阵

$$_{i}^{i-1}T = T_{x_{i-1}}(a_{i-1}) \cdot T_{x_{i-1}}(\alpha_{i-1}) \cdot T_{z_i}(\theta_i) \cdot T_{z_i}(d_i)$$

展开形式：
$$_{i}^{i-1}T = \begin{bmatrix}
c\theta_i & -s\theta_i & 0 & a_{i-1} \\
s\theta_i c\alpha_{i-1} & c\theta_i c\alpha_{i-1} & -s\alpha_{i-1} & -s\alpha_{i-1} d_i \\
s\theta_i s\alpha_{i-1} & c\theta_i s\alpha_{i-1} & c\alpha_{i-1} & c\alpha_{i-1} d_i \\
0 & 0 & 0 & 1
\end{bmatrix}$$

> 变换过程：绕 $x$ 轴旋转 $\alpha_{i-1}$ 使 $z$ 轴平行 → 沿 $x$ 移动 $a_{i-1}$ → 绕 $z$ 旋转 $\theta_i$ → 沿 $z$ 移动 $d_i$

## 标准 DH 参数（改进 DH）

$$_{i}^{i-1}T = T_{Z_{i-1}}(\theta_i) \cdot T_{Z_R}(d_i) \cdot T_{X_Q}(a_i) \cdot T_{X_P}(\alpha_i)$$

顺序与标准 DH 相反

| 参数 | 含义 |
|------|------|
| $\theta_i$ | 以 $\hat{Z}_{i-1}$ 方向看，$\hat{X}_{i-1}$ 和 $\hat{X}_i$ 间的夹角 |
| $d_i$ | 沿 $\hat{Z}_{i-1}$ 方向，$\hat{X}_{i-1}$ 和 $\hat{X}_i$ 间的距离 |
| $a_i$ | 沿 $\hat{X}_i$ 方向，$\hat{Z}_{i-1}$ 和 $\hat{Z}_i$ 间的距离（$a_i > 0$） |
| $\alpha_i$ | 以 $\hat{X}_i$ 方向看，$\hat{Z}_{i-1}$ 和 $\hat{Z}_i$ 间的夹角 |

## 坐标系标准命名

| 符号 | 含义 |
|------|------|
| $\{B\}$ / link0 / {0} | 机械臂基座 |
| $\{W\}$ / $\{N\}$ | 手腕（最后关节），$^0_N T$ |
| $\{T\}$ | 工具（机器人指尖） |
| $\{S\}$ | 固定坐标系（任务/世界坐标系） |
| $\{G\}$ | 目标（运动结束时与 $\{T\}$ 重合） |

工具位置定位函数：
$$^S_T T = ^S_B T^{-1} \, ^B_W T \, ^W_T T$$

## 计算技巧

- 使用定点数表示变化范围小的易确定数
- 公式分解可增加局部变量，减少乘法次数
- 超越函数（sin, cos）可用级数展开近似，节省内存
- 只计算旋转矩阵的两列，用叉乘确定第三列
