# 一、信号与系统

## 信号的基本概念

### 信号与系统

- **信号**：随时间变化的物理量，是信息的载体。数学上表示为函数 $x(t)$（连续）或 $x[n]$（离散）
- **系统**：对输入信号进行变换产生输出信号，记 $y(t) = T\{x(t)\}$ 或 $y[n] = T\{x[n]\}$
- **连续时间系统 vs 离散时间系统**：自变量 $t$ 连续 / $n$ 取整数

### 信号的分类

| 分类维度 | 类型                                                              |
| -------- | ----------------------------------------------------------------- |
| 时间     | 连续时间信号$x(t)$ / 离散时间信号 $x[n]$                      |
| 周期     | 周期信号$x(t+T)=x(t)$ / 非周期信号                              |
| 能量功率 | 能量信号（$E<\infty, P=0$）/ 功率信号（$P<\infty, E=\infty$） |
| 确定性   | 确定信号 / 随机信号                                               |
| 因果性   | 因果信号（$t<0$ 时 $x(t)=0$）/ 非因果信号                     |

### 基本连续时间信号

**指数信号**：

$$
x(t) = C e^{at}
$$

**正弦信号**：

$$
x(t) = A \cos(\omega t + \theta)
$$

**复指数信号**（核心，频域分析基础）：

$$
x(t) = e^{st} = e^{(\sigma + j\omega)t} = e^{\sigma t}(\cos\omega t + j\sin\omega t)
$$

- $\sigma = 0$：等幅正弦；$\sigma < 0$：衰减正弦；$\sigma > 0$：增长正弦
- 欧拉公式：$e^{j\theta} = \cos\theta + j\sin\theta$，$\cos\theta = \dfrac{e^{j\theta}+e^{-j\theta}}{2}$，$\sin\theta = \dfrac{e^{j\theta}-e^{-j\theta}}{2j}$

### 基本离散时间信号

**离散指数信号**：

$$
x[n] = C\alpha^n
$$

**离散复指数**：

$$
x[n] = e^{j\omega n} = \cos\omega n + j\sin\omega n
$$

**关键区别**：离散时间中 $e^{j\omega n}$ 的周期性——$x[n]$ 周期为 $N$ 当且仅当 $\omega/(2\pi)$ 是有理数 $k/N$，即 $\omega = 2\pi k/N$。否则 $e^{j\omega n}$ 不周期，与连续情形本质不同。

**单位冲激**：$\delta[n] = \begin{cases}1, & n=0 \\ 0, & n\ne 0\end{cases}$

**单位阶跃**：$u[n] = \begin{cases}1, & n\ge 0 \\ 0, & n<0\end{cases}$

## 复指数信号

### 复指数的核心地位

复指数信号 $e^{st}$（$s=\sigma+j\omega$）是 LTI 系统分析的基本"积木块"，因为：

1. 它是 LTI 系统的**特征函数**：输入 $e^{st}$ → 输出 $H(s)e^{st}$
2. 任意信号可分解为复指数的线性组合（傅里叶级数 / 变换、拉氏变换）
3. 复指数的线性组合仍是复指数

### 连续复指数

$$
e^{st} = e^{(\sigma+j\omega)t},\quad s=\sigma+j\omega \in \mathbb{C}
$$

### 离散复指数

$$
z^n = r^n e^{j\omega n} = r^n(\cos\omega n + j\sin\omega n),\quad z = re^{j\omega} \in \mathbb{C}
$$

## 连续离散时间系统

### 系统的描述

- **连续系统**：$y(t) = T\{x(t)\}$，常用微分方程描述
- **离散系统**：$y[n] = T\{x[n]\}$，常用差分方程描述

### 系统间的互联

- **级联**（串联）：$y(t) = T_2\{T_1\{x(t)\}\}$
- **并联**：$y(t) = T_1\{x(t)\} + T_2\{x(t)\}$
- **反馈互联**：输出经系统反馈回输入端

## 基本系统性质

### 线性性

**线性系统**满足叠加性与齐次性：

$$
T\{a x_1(t) + b x_2(t)\} = a\,T\{x_1(t)\} + b\,T\{x_2(t)\}
$$

即输入线性组合 → 输出同一线性组合。

### 时不变性

**时不变系统**：输入延迟 → 输出同延迟：

$$
x(t) \to y(t) \Rightarrow x(t-t_0) \to y(t-t_0)
$$

### 线性时不变（LTI）系统

同时满足线性与时不变性的系统，是本课程核心研究对象。LTI 系统完全由其**冲激响应** $h(t)$（或 $h[n]$）刻画。

### 因果性

**因果系统**：输出只取决于当前与过去输入，不依赖未来：

$$
x(t) = 0\ (t < t_0) \Rightarrow y(t) = 0\ (t < t_0)
$$

LTI 系统因果 $\Leftrightarrow$ $h(t) = 0\ (t < 0)$（冲激响应因果）。

### 稳定性

**BIBO 稳定**（有界输入 → 有界输出）：$|x(t)| \le M_x \Rightarrow |y(t)| \le M_y$。

LTI 系统稳定 $\Leftrightarrow$ $\int_{-\infty}^{+\infty}|h(\tau)|\,d\tau < \infty$（连续），$\sum_n |h[n]| < \infty$（离散）。

### 记忆性

**无记忆系统**：输出只与当前输入有关（如 $y(t) = kx(t)$）。

**记忆系统**：输出依赖过去输入（含储能元件）。

### 可逆性

**可逆系统**：存在逆系统使 $x(t) = T^{-1}\{T\{x(t)\}\}$。可逆 $\Leftrightarrowarrow$ 不同输入产生不同输出。
