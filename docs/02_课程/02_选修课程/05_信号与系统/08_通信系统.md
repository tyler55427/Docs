# 八、通信系统

## 调制与解调

### 复指数载波调制

$$
y(t) = x(t)\,\cos\omega_c t \quad \Longleftrightarrow \quad Y(j\omega) = \frac{1}{2}\big[X(j(\omega-\omega_c)) + X(j(\omega+\omega_c))\big]
$$

调制 = 信号与载波相乘，频域上把基带频谱 $X(j\omega)$ 搬移到 $\pm\omega_c$ 处，带宽翻倍。

### 正弦载波调制的类型

| 调制方式      | 表达式                                    |
| ------------- | ----------------------------------------- |
| 常规调幅 AM   | $y(t) = [A + x(t)]\cos\omega_c t$       |
| 双边带 DSB-SC | $y(t) = x(t)\cos\omega_c t$（抑制载波） |
| 单边带 SSB    | 只传输一个边带（上或下）                  |

### 幅度调制（AM）

#### 常规调幅

$$
s(t) = [A_c + m(t)]\cos\omega_c t
$$

- $A_c$ 为载波振幅，$m(t)$ 为调制信号
- 调幅系数 $\mu = \max|m(t)|/A_c$；$\mu < 1$ 不过调制
- 频谱：载波 + 两个边带，载波分量不携带信息（功率浪费）

**包络检波**：$A_c > |m(t)|$ 时包络 $= A_c + m(t)$，用简单二极管电路即可解调（非相干）。

### 双边带抑制载波（DSB-SC）

$$
s(t) = m(t)\cos\omega_c t
$$

无载波分量，效率高但需**相干解调**（同步检波）：

$$
r(t) = s(t)\cos\omega_c t = \frac{1}{2}m(t) + \frac{1}{2}m(t)\cos 2\omega_c t
$$

低通滤波后得 $\dfrac{1}{2}m(t)$。要求本地载波与发射端同频同相。

### 单边带调制（SSB）

用滤波法只保留一个边带，节省一半带宽。可用希尔伯特变换实现相移法：

$$
s_{\text{USB}}(t) = \tfrac{1}{2}m(t)\cos\omega_c t - \tfrac{1}{2}\hat{m}(t)\sin\omega_c t
$$

其中 $\hat{m}(t)$ 为 $m(t)$ 的希尔伯特变换（$-90°$ 相移）。

### 角度调制

#### 频率调制（FM）与相位调制（PM）

**瞬时相位**：$\phi(t) = \omega_c t + \theta(t)$，瞬时频率 $f_i(t) = \dfrac{1}{2\pi}\dfrac{d\phi}{dt}$。

| 调制 | 瞬时相位                                          | 瞬时频率偏移   |
| ---- | ------------------------------------------------- | -------------- |
| PM   | $\omega_c t + k_p m(t)$                         | $k_p\,m'(t)$ |
| FM   | $\omega_c t + k_f\int_{-\infty}^t m(\tau)d\tau$ | $k_f\,m(t)$  |

二者可互转（积分/微分），频谱为无限宽，但主要能量集中在卡森带宽内。

### 卡森法则

FM 信号带宽：

$$
B_T = 2(\beta_f + 1)W = 2(\Delta f + W)
$$

其中 $\beta_f = \Delta f / W$ 为调频指数，$W$ 为调制信号带宽，$\Delta f$ 为最大频偏。

### 频分复用（FDM）

#### 原理

将多个信号调制到不同载波频率上，共享同一信道传输：

$$
s(t) = \sum_i m_i(t)\cos(\omega_{ci} t + \theta_i)
$$

各载波频率间隔 $\ge$ 信号带宽的两倍（防边带重叠），接收端用带通滤波器分离各路信号再解调。

### 与时分复用（TDM）对比

| 复用 | 划分维度 | 适用           |
| ---- | -------- | -------------- |
| FDM  | 频率     | 模拟、连续传输 |
| TDM  | 时间     | 数字、突发传输 |

### 超外差接收机

#### 结构

天线 → 射频放大 → **混频**（与本地振荡相乘）→ **中频（IF）滤波放大** → 解调 → 音频放大

### 混频原理

$$
r(t)\cos\omega_{\text{LO}} t \Rightarrow 频谱搬移到 \omega_{\text{RF}} \pm \omega_{\text{LO}}
$$

固定中频（如 $455$ kHz 或 $10.7$ MHz）的好处：中频滤波器特性固定且易优化，仅需调本地振荡即可选台。
