# 四、连续时间傅里叶变换

## 傅里叶变换的定义

### 从级数到变换

将非周期信号视为周期 $T\to\infty$ 的周期信号极限，得连续时间傅里叶变换（CTFT）：

**正变换**：

$$
X(j\omega) = \mathcal{F}\{x(t)\} = \int_{-\infty}^{+\infty} x(t)\,e^{-j\omega t}\,dt
$$

**反变换**：

$$
x(t) = \mathcal{F}^{-1}\{X(j\omega)\} = \frac{1}{2\pi}\int_{-\infty}^{+\infty} X(j\omega)\,e^{j\omega t}\,d\omega
$$

**物理意义**：$X(j\omega)$ 是 $x(t)$ 在频率 $\omega$ 处的**频谱密度**，$|X(j\omega)|$ 为幅度谱，$\arg X(j\omega)$ 为相位谱。非周期信号的频谱为连续谱。

### 收敛条件

充分条件（狄利克雷）：$x(t)$ 绝对可积 $\int_{-\infty}^{+\infty}|x(t)|dt < \infty$，且分段光滑。

能量信号满足该条件；功率信号（如常数、正弦）需用冲激处理频谱。

## 傅里叶变换的性质

设 $x(t) \leftrightarrow X(j\omega)$，$x_1(t) \leftrightarrow X_1(j\omega)$：

| 性质     | 时域                                   | 频域                                                       |
| -------- | -------------------------------------- | ---------------------------------------------------------- |
| 线性     | $a x_1 + b x_2$                      | $a X_1 + b X_2$                                          |
| 时移     | $x(t-t_0)$                           | $X(j\omega)\,e^{-j\omega t_0}$                           |
| 频移     | $x(t)\,e^{j\omega_0 t}$              | $X(j(\omega-\omega_0))$                                  |
| 共轭对称 | $x^*(t)$                             | $X^*(-j\omega)$                                          |
| 实信号   | $x\in\mathbb{R}$                     | $X(-j\omega)=X^*(j\omega)$（幅度偶、相位奇）             |
| 时域反转 | $x(-t)$                              | $X(-j\omega)$                                            |
| 时域微分 | $\dfrac{d^n x}{dt^n}$                | $(j\omega)^n X(j\omega)$                                 |
| 时域积分 | $\int_{-\infty}^t x(\tau)d\tau$      | $\dfrac{X(j\omega)}{j\omega} + \pi X(0)\delta(\omega)$   |
| 频域微分 | $t^n\,x(t)$                          | $j^n\dfrac{d^n X}{d\omega^n}$                            |
| 卷积定理 | $x_1(t)*x_2(t)$                      | $X_1(j\omega)\,X_2(j\omega)$                             |
| 相乘定理 | $x_1(t)\,x_2(t)$                     | $\dfrac{1}{2\pi}X_1*X_2$（频域卷积）                     |
| 对偶性   | $X(t)$                               | $2\pi x(-\omega)$                                        |
| 帕塞瓦尔 | $\int_{-\infty}^{+\infty}\|x\|^2 dt$ | $\dfrac{1}{2\pi}\int_{-\infty}^{+\infty}\|X\|^2 d\omega$ |

### 卷积定理（核心）

$$
x_1(t) * x_2(t) \;\longleftrightarrow\; X_1(j\omega)\,X_2(j\omega)
$$

**意义**：时域卷积 = 频域相乘。LTI 系统 $y=x*h$ 的频域关系 $Y(j\omega)=X(j\omega)H(j\omega)$，$H(j\omega)$ 为**频率响应**。

### 帕塞瓦尔定理（能量定理）

$$
\int_{-\infty}^{+\infty}|x(t)|^2\,dt = \frac{1}{2\pi}\int_{-\infty}^{+\infty}|X(j\omega)|^2\,d\omega
$$

$|X(j\omega)|^2$ 为**能量谱密度**。

## 基本变换对

| 时域$x(t)$            | 频域$X(j\omega)$                                                 |
| ----------------------- | ------------------------------------------------------------------ |
| $\delta(t)$           | $1$                                                              |
| $1$                   | $2\pi\delta(\omega)$                                             |
| $e^{j\omega_0 t}$     | $2\pi\delta(\omega-\omega_0)$                                    |
| $\cos\omega_0 t$      | $\pi[\delta(\omega-\omega_0)+\delta(\omega+\omega_0)]$           |
| $\sin\omega_0 t$      | $-j\pi[\delta(\omega-\omega_0)-\delta(\omega+\omega_0)]$         |
| $u(t)$                | $\pi\delta(\omega)+\dfrac{1}{j\omega}$                           |
| $e^{-at}u(t)\ (a>0)$  | $\dfrac{1}{j\omega+a}$                                           |
| $e^{-a\|t\|}\ (a>0)$  | $\dfrac{2a}{\omega^2+a^2}$                                       |
| $\mathrm{rect}(t/T)$  | $T\,\mathrm{sinc}(\omega T/2)$                                   |
| $\mathrm{sinc}(Wt)$   | $\dfrac{\pi}{W}\,\mathrm{rect}\!\left(\dfrac{\omega}{2W}\right)$ |
| $\sum_n \delta(t-nT)$ | $\omega_s\sum_k\delta(\omega-k\omega_s)$，$\omega_s=2\pi/T$    |

### 矩形脉冲与 sinc 函数对偶

时域矩形 $\leftrightarrow$ 频域 sinc，时域 sinc $\leftrightarrow$ 频域矩形。**时间受限 → 频谱无限延伸**，反之亦然，是信号的基本测不准关系。

## 周期信号的傅里叶变换

周期信号 $x(t) = \sum_k a_k e^{jk\omega_0 t}$ 的傅里叶变换为冲激串：

$$
X(j\omega) = 2\pi\sum_{k=-\infty}^{+\infty} a_k\,\delta(\omega - k\omega_0)
$$

统一了周期（离散谱线）与非周期（连续谱）的频域表示。
