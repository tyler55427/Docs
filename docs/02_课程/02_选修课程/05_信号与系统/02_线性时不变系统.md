# 二、线性时不变系统

## LTI 系统与冲激响应

### 离散时间 LTI 系统

**卷积和**：离散 LTI 系统的输出由输入与冲激响应卷积给出。

利用冲激 $\delta[n]$ 的筛选性质 $x[n] = \sum_{k=-\infty}^{+\infty} x[k]\,\delta[n-k]$，由线性与时不变性：

$$
y[n] = \sum_{k=-\infty}^{+\infty} x[k]\,h[n-k] = x[n] * h[n]
$$

其中 $h[n] = T\{\delta[n]\}$ 为**单位冲激响应**。

**卷积和计算**：翻转 $h$、平移 $n$、与 $x$ 对应相乘求和。

### 连续时间 LTI 系统

**卷积积分**：

$$
y(t) = \int_{-\infty}^{+\infty} x(\tau)\,h(t-\tau)\,d\tau = x(t) * h(t)
$$

由 $x(t) = \int_{-\infty}^{+\infty} x(\tau)\,\delta(t-\tau)\,d\tau$ 与 LTI 性质推出。

### 卷积的图解法

1. **换元**：$h(\tau) \to h(t-\tau)$（翻转 + 平移）
2. **相乘**：$x(\tau)\,h(t-\tau)$
3. **积分/求和**：对 $\tau$ 积分得 $y(t)$

$t$ 扫过时间轴时观察两信号重叠区域的变化。

## 卷积计算

### 离散卷积

$$
y[n] = (x*h)[n] = \sum_{k=-\infty}^{+\infty} x[k]\,h[n-k]
$$

**有限长序列**：若 $x$ 长 $L_1$、$h$ 长 $L_2$，则 $y$ 长 $L_1+L_2-1$。

**典型例**：$u[n]*u[n] = (n+1)u[n]$（离散斜坡）。

### 连续卷积

$$
y(t) = (x*h)(t) = \int_{-\infty}^{+\infty} x(\tau)\,h(t-\tau)\,d\tau
$$

**典型例**：

- $u(t) * u(t) = t\,u(t)$（连续斜坡）
- $e^{-at}u(t) * e^{-at}u(t) = t\,e^{-at}u(t)$
- $x(t) * \delta(t-t_0) = x(t-t_0)$（与冲激卷积 = 延迟）
- $x(t) * \delta(t) = x(t)$

### 卷积的性质

设 $a, b$ 为常数：

- **交换律**：$x*h = h*x$
- **结合律**：$(x*h_1)*h_2 = x*(h_1*h_2)$
- **分配律**：$x*(h_1+h_2) = x*h_1 + x*h_2$（并联系统）
- **平移性**：$x(t-t_0)*h(t-t_1) = y(t-t_0-t_1)$
- **与冲激**：$x*\delta = x$，$x*\delta(t-t_0) = x(t-t_0)$
- **微分**：$\dfrac{d}{dt}(x*h) = x'*h = x*h'$
- **积分**：$\int_{-\infty}^t (x*h)(\tau)\,d\tau = \left(\int_{-\infty}^t x\right)*h = x*\left(\int_{-\infty}^t h\right)$

## LTI 系统的性质

### 用冲激响应判定系统性质

| 性质      | 连续充要条件                                    | 离散充要条件                  |
| --------- | ----------------------------------------------- | ----------------------------- |
| 因果      | $h(t)=0\ (t<0)$                               | $h[n]=0\ (n<0)$             |
| BIBO 稳定 | $\int_{-\infty}^{+\infty}\|h\|\,d\tau<\infty$ | $\sum_n \|h[n]\|<\infty$    |
| 无记忆    | $h(t)=K\delta(t)$                             | $h[n]=K\delta[n]$           |
| 可逆      | $\exists h_1: h*h_1=\delta$                   | $\exists h_1: h*h_1=\delta$ |

### LTI 系统的特征函数性质

对 LTI 系统，复指数输入产生同频率复指数输出（仅幅度、相位改变）：

$$
x(t) = e^{st} \Rightarrow y(t) = H(s)\,e^{st}
$$

其中 $H(s) = \int_{-\infty}^{+\infty} h(\tau)\,e^{-s\tau}\,d\tau$（连续），是系统的**系统函数**。这是频域分析的基石。

### 阶跃响应与冲激响应

**阶跃响应** $s(t) = T\{u(t)\}$，与冲激响应关系：

$$
h(t) = \frac{d}{dt}s(t), \quad s(t) = \int_{-\infty}^t h(\tau)\,d\tau
$$

离散：$h[n] = s[n] - s[n-1]$，$s[n] = \sum_{k=-\infty}^n h[k]$。

### 用卷积分析系统的步骤

1. 求系统冲激响应 $h$（由微分/差分方程或电路）
2. 输入 $x$ 与 $h$ 卷积：$y = x*h$
3. 用卷积性质（交换、平移、与冲激卷积）简化计算
