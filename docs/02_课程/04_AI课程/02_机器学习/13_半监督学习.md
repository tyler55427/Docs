# 十三、半监督学习

## 1. 未标记样本

令 $D_l = \{(x_i, y_i)\}$ 为"有标记"样本，$D_u = \{x_i\}$ 为"未标记"样本，$l \ll u$。

想利用 $D_u$ 信息，增强泛化能力。

> **"主动学习"**：用 $D_l$ 训练模型，从 $D_u$ 抽样，利用专家知识获得标记，重新训练模型（不是半监督学习！）

$D_u$ 采样独立同分布采样，关于数据分布的信息有利于建立模型。

**半监督学习**：学习器不依赖外界交互，自动利用未标记样本来提升学习性能。

为利用 $D_u$，需对 $D_u$ 所揭示的数据分布信息与类别标记相联系的假设：

- **聚类假设**：数据存在簇结构，同一簇是同一类别
- **流形假设**：数据分布在一个流形结构上，邻近样本有相似的输出
  - "邻近"程度用"相似"刻画，流形是聚类的推广，范围更广
  - **本质**：相似样本相似输出

$$\text{半监督学习} \begin{cases} \text{纯半监督学习：模型能适用于整个样本} \\ \text{直推学习：预测是预测未标记样本的类别} \end{cases}$$

## 2. 生成式方法

基于生成式模型的方法，即假设数据由一个潜在的模型生成。

- 潜在模型的参数将未标记数据与学习目标联系，未标记数据的标记作为模型参数的隐变量
- 基于 EM 算法进行极大似然估计求解

不同模型假设产生不同方法/推导。

> 关键：模型假设准确

## 3. 半监督 SVM (S3VM)

- **SVM**：找最大间隔划分超平面
- **S3VM**：找分开有标记样本，且穿过数据低密度区域的划分超平面
  - **基本假设**：低密度分隔，聚类考虑超平面的推行

S3VM 中的代表是 TSVM（直推），针对二分类，对未标记样本指派标记，找间隔最大的划分超平面。

$$\min_{w, b, \xi, \hat{\xi}} \frac{1}{2} \|w\|^2 + C_l \sum_{i=1}^l \xi_i + C_u \sum_{i=l+1}^m \hat{\xi}_i \quad \text{s.t.} \quad y_i(w^T x_i + b) \ge 1 - \xi_i, \ i=1,\dots,l$$

$$\hat{y}_i(w^T x_i + b) \ge 1 - \hat{\xi}_i, \ i=l+1,\dots,m, \ \hat{\xi}_i \ge 0$$

穷举只能在未标记样本少时进行，高效方法：采用局部搜索进化找近似解。

具体：

- 利用有标记样本训练一个 SVM
- 利用这个 SVM 对未标记样本指派
- 求解新的划分超平面和松弛变量
- 设置 $C_u$ 比 $C_l$ 小，找两个标记指派为异类，且可能发生错误的未标记样本交换标记
- 重复上述操作，并逐渐增大 $C_u$ 直至 $C_u = C_l$

**TSVM 算法**

输入：有标记样本集 $D_l = \{(x_1, y_1), (x_2, y_2), \dots, (x_l, y_l)\}$；未标记样本集 $D_u = \{x_{l+1}, x_{l+2}, \dots, x_{l+u}\}$；折中参数 $C_l, C_u$。

过程：

1.  用 $D_l$ 训练一个 $\text{SVM}_l$；
2.  用 $\text{SVM}_l$ 对 $D_u$ 中样本进行预测，得到 $\hat{y} = (\hat{y}_{l+1}, \hat{y}_{l+2}, \dots, \hat{y}_{l+u})$；
3.  初始化 $C_u \leftarrow C_l$；
4.  while $C_u < C_l$ do:
5.      基于 $D_l, D_u, \hat{y}, C_l, C_u$ 求解式(13.9)，得到 $(w, b, \xi, \hat{\xi})$；
6.      while $\exists i, j \ [ (\hat{y}_i \hat{y}_j < 0) \land (\xi_i > 0) \land (\xi_j > 0) \land (\xi_i + \xi_j > 2) ]$ do：
7.          $\hat{y}_i = -\hat{y}_i$;
8.          $\hat{y}_j = -\hat{y}_j$;
9.          基于 $D_l, D_u, \hat{y}, C_l, C_u$ 重新求解式(13.9)，得到 $(w, b, \xi, \hat{\xi})$;
10.     end while
11.     $C_u = \min\{2C_u, C_l\}$
12. end while

输出：未标记样本的预测结果：$\hat{y} = (\hat{y}_{l+1}, \hat{y}_{l+2}, \dots, \hat{y}_{l+u})$

> 若不平衡，可折 $C_u$ 为 $C_l$、$C_u$

## 4. 图半监督学习

将数据集映射为图，样本对应结点，样本相似度用一条边连接，边的强度正比于相似度。

有标记样本染红色，未标记样本未染色，则可视作颜色扩散。

基于 $D_l \cup D_u$ 构建图 $G = (V, E)$，$V$ 为结点集，$E$ 为边集，表示相似矩阵 $(W)_{ij} = \begin{cases} e^{-\frac{\|x_i - x_j\|^2}{\sigma^2}}, & i \neq j \\ 0, & i = j \end{cases}$（常基于高斯函数定义）。

假设从 $G$ 中学到 $f: V \to \mathbb{R}$，$y_i = \operatorname{sign}(f(x_i))$。

相似样本相似标记，可定义 $f$ 的能量函数：

$$E(f) = \frac{1}{2} \sum_{i,j=1}^{l+u} (W)_{ij} (f(x_i) - f(x_j))^2 = f^T (D - W) f$$

其中：

$$f = (f_l; f_u)^T,\quad f_l = (f(x_1); \cdots; f(x_l)),\quad f_u = (f(x_{l+1}); \cdots; f(x_{l+u}))$$

$$D = \operatorname{diag}(d_1, \cdots, d_{l+u}),\quad d_i = \sum_{j=1}^{l+u} (W)_{ij}$$

则最小能量的 $f$ 满足：有标记样本，在未标记样本满足 $\Delta f = 0$，$\Delta = D - W$ 为拉普拉斯矩阵。

二分类的标记传播可推广至多分类

优、缺点分析：

- **优：** 易通过矩阵运算分析性质
- **劣：** 在稀疏图下效果较差；新样本预测困难

## 5. 基于分歧的方法

利用多学习器的"分歧"。

"协同训练"，用于"多视角"数据 $(\langle x_1, x_2, y \rangle)$，每个属性集构成一个视角。

假设不同视图有"相容性"：输出空间相同。

协同训练利用多视图的"相互互补性"，

假设数据集有两个充分且条件独立视图：

- **充分**：视图包含产生最优学习器的信息
- **条件独立**：给定类别标记，视图独立

**步骤：**

- 每个视图训练一个分类器
- 对未标记样本"最有把握"的标记提供给另一个分类器训练
- 直至两个分类器不变 / 达到预设迭代次数

> 未标记样本的分类置信度产生大量计算开销

> 能提升弱分类器的泛化能力

> 单视图也可多分支大的弱学习器

## 6. 半监督聚类

聚类无监督，但实际能获得一些信息：

- **约束：**
  - "必连"：样本一定是一个簇
  - "勿连"：样本一定不是一个簇
- 少量有标记样本

1. 约束信息：有约束 $k$ 均值算法，在 $k$ 均值增加约束判断。

2. 少量有标记样本：有约束种子 $k$ 均值算法，初始有信息的 $k$ 个聚类中心。
