# 七、贝叶斯方法

## 1. 贝叶斯决策论

根据概率决策，在相关概率已知，基于这些概率和误判损失来选择最优的类别标记。

定义：$\lambda_{ij}$ 是将标记为 $c_i$ 的样本分类为 $c_j$ 的损失。

基于后验概率 $P(c_i|\boldsymbol{x})$ 可获得将 $\boldsymbol{x}$ 分类为 $c_i$ 所产生的期望损失。

即 $\boldsymbol{x}$ 上的"条件风险"：

$$R(c_i|\boldsymbol{x}) = \sum_{j=1}^n \lambda_{ji} P(c_j|\boldsymbol{x})$$

目标：最小化总体风险：$R(h) = E_{\boldsymbol{x}} [ R(h(\boldsymbol{x})|\boldsymbol{x}) ]$

显然，只要最小化每个样本的条件风险 $R(h(\boldsymbol{x})|\boldsymbol{x})$ 即可。

即 $h^*(\boldsymbol{x}) = \arg\min_{c \in \mathcal{Y}} R(c|\boldsymbol{x})$

$$\begin{cases} h^* \text{ 称为贝叶斯最优分类器} \\ R(h^*) \text{ 称为贝叶斯风险} \\ 1 - R(h^*) \text{ 反映分类器能达到的最好性能，即模型精度的理论上限} \end{cases}$$

若损失是最小化分类错误率（0-1 损失），则 $\lambda_{ij} = \begin{cases} 0, & i=j \\ 1, & i \neq j \end{cases}$

此时 $R(c|\boldsymbol{x}) = 1 - P(c_i|\boldsymbol{x})$

$h^*(\boldsymbol{x}) = \arg\max_{c \in \mathcal{Y}} P(c|\boldsymbol{x})$，即每个样本后验概率最大的类别标记。

则要基于样本 $D$ 可能准确估计后验概率，一般思路：

$$\begin{cases} \text{"判别式模型"：直接建模 } P(c|\boldsymbol{x}) \text{ 来预测 } c \\ \text{"生成式模型"：先建模 } P(\boldsymbol{x}, c) \text{，再计算 } P(c|\boldsymbol{x}) \quad , \quad P(c|\boldsymbol{x}) = \frac{P(c, \boldsymbol{x})}{P(\boldsymbol{x})} \end{cases}$$

## 2. 极大似然估计 (MLE)

假定数据具有某种确定的概率分布，基于训练样本估计参数，记 $P(\boldsymbol{x}|c)$ 为 $P(\boldsymbol{x}|\theta_c)$。

$$\text{概率模型训练即参数估计} \begin{cases} \text{频率学派：参数虽未知，但为客观存在的固定值，优化似然函数} \\ \text{贝叶斯学派：参数是随机变量，本身有分布} \end{cases}$$

$$\text{似然：} P(D_c|\hat{\theta}_c) = \prod_{\boldsymbol{x} \in D_c} P(\boldsymbol{x}|\hat{\theta}_c)$$

$$\text{MLE：找 } \hat{\theta}_c \text{，最大化似然}$$

$$\text{对数似然：} LL(\theta_c) = \sum_{\boldsymbol{x} \in D_c} \log P(\boldsymbol{x}|\theta_c)$$

$$\theta_c = \arg\max_{\theta_c} LL(\theta_c)$$

> 估计简单，但结果准确性依赖于假设分布形式与真实分布是否符合。

## 3. 朴素贝叶斯分类器

**"属性条件独立性"假设**：对所有类别，所有属性相互独立。

$$P(c|\boldsymbol{x}) = \frac{P(c)P(\boldsymbol{x}|c)}{P(\boldsymbol{x})} = \frac{P(c)}{P(\boldsymbol{x})} \prod_{i=1}^d P(x_i|c)$$

$$h_{nb}(\boldsymbol{x}) = \arg\max_{c \in \mathcal{Y}} P(c) \prod_{i=1}^d P(x_i|c)$$

$$\begin{cases} \text{离散：} P(c) = \frac{|D_c|}{|D|}, \quad P(x_i|c) = \frac{|D_{c, x_i}|}{|D_c|} \\ \text{连续：假定概率密度函数，用样本特征分布参数} \end{cases}$$

为避免出现样本导致错误，进行"拉普拉斯修正"平滑，

$$\begin{cases} \hat{p}(c) = \frac{|D_c| + 1}{|D| + N} \xrightarrow{\quad} \text{初始类别数} \\ \hat{p}(x_i|c) = \frac{|D_{c,x_i}| + 1}{|D_c| + N_i} \xrightarrow{\quad} \text{属性取值数} \end{cases}$$

本质：假设属性值与类别均匀分布，引入额外的先验。

要求：

$$\begin{cases} \text{预测速度：查表} \\ \text{数据更频繁："懒惰学习"：要预测时才估计} \\ \text{数据不断增加：增量学习：修正已估计数据} \end{cases}$$

## 4. 半朴素贝叶斯分类器

条件独立性假设不一定成立，对该假设进行一定程度的放松。

基本思想：部分属性相互依赖（不完全联合，也不忽略强依赖）。

**"独依赖估计"（ODE）**：每个属性除类别外最多依赖一个其他属性。

$$P(c|\vec{x}) \propto P(c) \prod_{i=1}^{d} P(x_i | c, \text{pa}_i)$$

$\text{pa}_i$ 为 $x_i$ 依赖的属性，称为 $x_i$ 的父属性。

### 4.1 确定每个属性的父属性

**SPODE**：所有属性依赖同一个属性，称为"超父"（SP），通过交叉验证来确定，形成 SPODE。

**TAN**：最大带权生成树算法，将属性依赖关系简化为树形结构。

$$\begin{cases} \text{计算两属性的条件互信息：} I(x_i, x_j | y) = \sum_{x_i, x_j; c \in \mathcal{Y}} P(x_i, x_j | c) \log \frac{P(x_i, x_j | c)}{P(x_i | c) P(x_j | c)} \\ \text{构建属性为结点的完全图，边权为 } I(x_i, x_j | y) \\ \text{构建完全图的最大带权生成树，选择根变量，边变为有向（仅保留强相关）} \\ \text{加入类别结点 $y$，增加 $y$ 到每个属性的有向边} \end{cases}$$

**AODE**：基于集成学习机制的 ODE。

将每个属性作为 SP 构建 SPODE，然后将有足够多训练数据支撑的 SPODE 集成为最终结果。

$$P(c|\vec{x}) \propto \sum_{|D_{x_i}| \ge 2m} P(c, x_i) \prod_{j=1}^{d} P(x_j | c, x_i) \quad (\text{$m$ 为阈值常数})$$

## 5. 贝叶斯网（信念网）

有向无环图（DAG）刻画属性的依赖关系，用条件概率表（CPT）描述属性的联合概率分布。

一个贝叶斯网 $B$ = 结构 $G$ + 参数 $\theta$，$B = \langle G, \theta \rangle$

$$\begin{cases} G \text{ 是一个 DAG，每个结点有属性，若两个属性有直接依赖，用一条边连接} \\ \theta \text{ 描述依赖关系，记在 } G \text{ 中父结点为 } \pi_x, \theta \text{ 包含 } \theta_{x|\pi_x} = P_B(x|\pi_x) \end{cases}$$

### 5.1 结构

贝叶斯网络有效地表达了属性间的条件独立性。

给定父结点集，贝叶斯网络假设属性与它的非后裔属性独立。

$$P_B(x_1, \cdots, x_d) = \prod_{i=1}^d P_B(x_i|\pi_{x_i}) = \prod_{i=1}^d \theta_{x_i|\pi_{x_i}}$$

三种依赖：

$$\begin{cases} A \leftarrow B \rightarrow C \text{（链式）} : \text{给定 } B, A \perp C \text{ 独立} \\ A \rightarrow B \leftarrow C \text{（V型）} : \text{不给定 } B, A \perp C \text{ 独立} \\ A \rightarrow B \rightarrow C \text{（顺式）} : \text{给定 } B, A \perp C \text{ 独立} \end{cases}$$

判断有向图中变量的条件独立性，使用"有向分离"（d-separation）。

将有向图转为无向图（道德图）：

$$\begin{cases} \text{在所有 V 型结构的父结点之间加无向边（道德化）} \\ \text{将有向边改为无向边} \end{cases}$$

则对 $x, y$ 给定集合 $z$，若从道德图中去掉 $z$，$x, y$ 属于两个连通分支。

则 $x, y$ 被 $z$ 有向分离，$x \perp y \mid z$ 成立。

### 5.2 学习

若网络结构（依赖关系）已知，学习就是对训练样本计数，估计 CPT。

但往往不知道网络结构，需要用训练集找到网络。

"评分函数"求解，评估贝叶斯网络与训练集的契合程度。

常用评分函数基于信息论，学习者压缩，目标找一个最短编码长度描述数据的模型。

编码不包括描述模型自身和使用该模型描述数据的字节长度。

选择综合编码长度最短的，"最小描述长度"(MDL)

给定 $D$, $B=\langle \mathcal{G}, \theta \rangle$ 在 $D$ 上的评分函数：

$$S(B|D) = f(\theta)|B| - LL(B|D)$$

$|B|$ 为参数个数，$f(\theta)$ 为每个 $\theta$ 所需的字节数

$$\begin{cases} f(\theta)=1 & , \text{AIC}(B|D) = |B| - LL(B|D) \\ f(\theta)=\frac{1}{2}\log n & , \text{BIC}(B|D) = \frac{\log n}{2}|B| - LL(B|D) \\ f(\theta)=0 & , \text{NLL}(B|D) \end{cases}$$

若网络固定，$f(\theta)$ 为常数，在 $D$ 上经典估计量为 $\text{NLL}(B|D)$，对网络结构进行搜索。

但从所有可能的网络结构空间搜索最优结构是 NP难。

近似：

$$\begin{cases} \text{贪心：初始化一个网络，每次调整一条边（增、删、改方向），直至评分函数不再降低} \\ \text{对网络结构施加约束，减少搜索空间} \end{cases}$$

### 5.3 推断

通过已知变量推测查询变量

通过定义"精确推断"是 NP难值的

"近似推断"：吉布斯采样：初始化样本与 $E$ 一致，首次对 $Q$ 迭代改变取值，采样证据为马尔可夫覆盖。

统计样本，近似计算后验证 $P(Q=q|E=e) \approx \frac{n_q}{n}$

$$\begin{cases} \text{随机漫步} & t \to \infty \text{，收敛到平衡分布，但可能不存在平衡分布} \\ \text{马尔可夫链} \end{cases}$$

## 6. EM 算法

实际上，训练样本可能不完整，有些属性值未知。

未观测变量 称为"隐变量"，记为 $z$，已观测记为 $X$。

最大化 $LL(\theta|X, z) = \ln P(x, z|\theta)$

可以计算 $z$ 的期望，最大化已观测的"边际似然"：$LL(\theta|X) = \ln \sum_z P(x, z|\theta)$

EM算法用于估计参数隐变量，迭代的方法。

初始化 $\theta^0$ 为起点，迭代至收敛：

$$\begin{cases} \text{E：基于 } \theta^t \text{ 推断 } z \text{ 的期望} \\ \text{M：基于 } X, z^t \text{，对 } \theta \text{ 极大似然估计，得 } \theta^{t+1} \end{cases}$$

若不取 $z$ 的期望，而是 $P(z|x, \theta^t)$：

$$\begin{cases} \text{E：用 } \theta^t \text{ 推断 } P(z|x, \theta^t)\text{，计算 } LL(\theta|x, z) \text{ 关于 } z \text{ 的期望，} Q(\theta|\theta^t) = E_{z|x,\theta^t} LL(\theta|x, z) \\ \text{M：} \theta^{t+1} = \arg\max_\theta Q(\theta|\theta^t) \end{cases}$$

也可以用梯度下降，但复杂度随 $z$ 的增加指数上升；EM可视为非梯度优化方法。
