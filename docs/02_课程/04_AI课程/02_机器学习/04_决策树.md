# 四、决策树

## 1. 基本流程

基于树结构对属性的测试：

- **叶结点**：决策结果
- **其他内部结点**：属性测试
- **每个结点的样本集**：根据属性测试结果划分到子结点
- **根结点**：包含样本全集

**学习目的**：泛化能力强，处理规则能力强的决策树。

分而治之的递归，递归终止：

1. 当前结点包含的样本全属于同一类，无需划分
2. 当前属性集为空 / 所有样本在所有属性上取值相同，无法划分
3. 当前结点包含的样本集合为空，不能划分

### 1.1 决策树学习基本算法

```text
输入: 训练集 D = {(x1,y1), (x2,y2), ..., (xm,ym)};
      属性集 A = {a1, a2, ..., ad}.
过程: 函数 TreeGenerate(D, A)
1: 生成结点 node;
2: IF D 中样本全属于同一类别 C then
3:     将 node 标记为 C 类叶结点; return
4: end if
5: IF A = Ø OR D 中样本在 A 上取值相同 then
6:     将 node 标记为叶结点, 其类别标记为 D 中样本数量最多的类; return
7: end if
8: 从 A 中选择最优划分属性 a*;
9: for a* 的每一个值 a_v* do
10:    为 node 生成一个分支; 令 D_v 表示 D 中在 a* 上取值为 a_v* 的样本子集;
11:    IF D_v 为空 then
12:        将分支结点标记为叶结点, 其类别标记为 D 中样本最多的类; return
13:    else
14:        以 TreeGenerate(D_v, A \ {a_v*}) 为分支结点
15:    end if
16: end for
输出: 以 node 为根结点的一棵决策树
```

## 2. 划分选择

**关键**：算法第 8 行，希望分支结点包含的样本尽可能属于同一类（纯度↑）。

### 2.1 信息增益

信息熵：$Ent(D) = -\sum_{k=1}^{|\mathcal{Y}|} p_k \log_2 p_k$

$Ent(D)\downarrow$，$D$ 的纯度 $\uparrow$，确定性 $\uparrow$

信息增益：属性 $a$ 有 $V$ 个取值，用 $a$ 对样本划分为 $V$ 个分支结点 $D^v$，权重为 $\frac{|D^v|}{|D|}$

$$
Gain(D,a) = Ent(D) - \sum_{v=1}^{V} \frac{|D^v|}{|D|} Ent(D^v)
$$

$Gain(D,a)\uparrow$，属性 $a$ 带来的纯度提升 $\uparrow$

> ID3 算法使用信息增益选择划分属性。

### 2.2 增益率

当属性取值数多（如"编号"），信息增益偏好多取值属性，导致不能泛化、无法预测新样本。

增益率：$Gain\_ratio(D,a) = \frac{Gain(D,a)}{IV(a)}$

$$
IV(a) = -\sum_{v=1}^{V} \frac{|D^v|}{|D|} \log_2 \frac{|D^v|}{|D|} \quad \text{（属性 } a \text{ 的固有值，取值数越多 } IV(a) \text{ 越大）}
$$

> C4.5 算法：先从信息增益高于平均水平的属性中，再挑增益率最大的。

### 2.3 基尼指数

基尼值：

$$
Gini(D) = \sum_{k=1}^{|\mathcal{Y}|} \sum_{k'\neq k} p_k p_{k'} = 1 - \sum_{k=1}^{|\mathcal{Y}|} p_k^2
$$

反映从 $D$ 中抽取两个样本类别不一致的概率。$Gini(D)\downarrow$，$D$ 的纯度 $\uparrow$

属性 $a$ 的基尼指数：$Gini\_index(D,a) = \sum_{v=1}^{V} \frac{|D^v|}{|D|} Gini(D^v)$

> CART 算法在划分时选择基尼指数最小的属性。

## 3. 剪枝处理

防止决策树学习算法过拟合。

- **预剪枝**：生成过程中，对每个结点划分前评估；若划分不能提升泛化性能则停止，标记为叶结点。
- **后剪枝**：生成完整树后，自底向上考察非叶结点；若子树替换为叶结点能提升泛化性能则替换。

泛化性能用验证集精度判断。

### 3.1 预剪枝

对结点：

- **划分前**：$D$ 中最多类别，验证集精度
- **划分后**：按属性 $A$ 划分，各子结点最多类别的加权精度

> 降低过拟合和训练开销，但贪心可能导致欠拟合。

### 3.2 后剪枝

将子树重新变回叶结点

> 缓解预剪枝贪心导致的欠拟合，但训练后还要自底向上考察，计算开销增大。

## 4. 连续值与缺失值

### 4.1 连续值处理

二分法：连续属性 $a$ 有 $n$ 个不同取值，排序后基于划分点 $t$ 划分为 $D_t^-$、$D_t^+$

候选划分点集合（$n-1$ 个）：$T_a = \left\{ \frac{a^{(i)} + a^{(i+1)}}{2} \;\middle|\; 1 \le i \le n-1 \right\}$

$$
Gain(D, a, t) = Ent(D) - \sum_{r \in \{-, +\}} \frac{|D_t^r|}{|D|} Ent(D_t^r)
$$

从 $T_a$ 中选使 $Gain(D, a, t)$ 最大的 $t$ 作为划分点。

> 与离散属性不同，连续属性可作为后继结点的划分属性（可重复使用）。

### 4.2 缺失值处理

需解决两个问题：

$$
\begin{cases} \text{(1) 属性值缺失时，如何进行划分属性选择} \\ \text{(2) 给定划分属性，样本在该属性缺失时如何被划分} \end{cases}
$$

令 $\tilde{D}$ 为 $D$ 在属性 $a$ 上无缺失值的样本子集，$\tilde{D}^v$ 为 $\tilde{D}$ 中 $a$ 取值 $a^v$ 的子集，$\tilde{D}_k$ 为 $\tilde{D}$ 中第 $k$ 类子集。假定每个样本有权重 $w_x$：

$$
\rho = \frac{\sum_{x \in \tilde{D}} w_x}{\sum_{x \in D} w_x} \quad (\text{无缺失值样本占比}), \quad
\tilde{p}_k = \frac{\sum_{x \in \tilde{D}_k} w_x}{\sum_{x \in \tilde{D}} w_x} \quad (\text{无缺失值中第 } k \text{ 类占比}), \quad
\tilde{r}_v = \frac{\sum_{x \in \tilde{D}^v} w_x}{\sum_{x \in \tilde{D}} w_x} \quad (\text{无缺失值中 } a^v \text{ 占比})
$$

对于 (1)：基于 $\tilde{D}$ 计算信息增益，$Gain(D, a) = \rho \times Gain(\tilde{D}, a)$

对于 (2)：

$$
\begin{cases} \text{若 } x \text{ 在 } a \text{ 上取值已知，划入对应子结点，权重 } w_x \text{ 不变} \\ \text{若 } x \text{ 在 } a \text{ 上取值未知，以 } \tilde{r}_v \text{ 为权重划入所有子结点} \end{cases}
$$

## 5. 多变量决策树

将每个属性作为坐标空间的一个轴，样本即 $d$ 维空间中的点。

单变量决策树的分类边界由与坐标轴平行的线段分段组成（可解释性好，但边界近似曲折、模型复杂）。

多变量决策树：非叶结点测试属性的**线性组合** $\sum w_i a_i \le t$，分类边界可为斜线，$w_i$、$t$ 可学习。
