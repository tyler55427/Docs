# 十一、特征选择与稀疏学习

## 1. 子集搜索与评价

属性称为"特征"，与当前学习任务有关的"相关特征"，否则"无关特征"。

从特征中选择相关特征叫"特征选择"。

特征选择是重要的"数据预处理"：

- 维数灾难
- 降低学习难度

特征选择确保不丢失重要特征。

"冗余特征"，可以从其他特征推出，有时能作为"中间概念"降低学习任务难度。

无先验知识，只能遍历。或初始"候选子集"，评价好坏，基于结果产生下一个候选子集。

### 1.1 子集搜索

- **前向**：每个特征作子集，评价选最好，增加一个特征，评价选最好，且优于上一个子集
- **后向**：减少
- **双向**：
- 贪心的，非最优的

### 1.2 子集评价

$D$ 中第 $k$ 类样本占比 $p_k$。属性子集 $A$ 将 $D$ 划分为 $\{D^1, \cdots, D^v\}$，$D^v$ 在 $A$ 上取值相同（$v = |A|$）。

计算 $A$ 的信息增益：

$$\text{Gain}(A) = \text{Ent}(D) - \sum_{v=1}^{|A|} \frac{|D^v|}{|D|} \text{Ent}(D^v)$$

其中：

$$\text{Ent}(D) = -\sum_{k=1}^{|y|} p_k \log_2 p_k$$

> 类似决策树，决策树可用于特征选择。

特征选择分三类：过滤式、包裹式、嵌入式。

## 2. 过滤式

对数据集进行特征选择，然后再训练学习器。特征选择与学习器无关。

### 2.1 Relief

Relief 设计了一个"相关统计量"度量特征的重要性。一向量，每个分量对应一个特征，有样本随特征子集的重要性由每个特征的相关统计量之和决定。设计阈值 $\tau$ 选择。

确定相关统计量，对 $x_i$，在同类样本中找最近邻 $x_{i,nh}$ 称为"猜对近邻"，异类样本中找最近邻 $x_{i,nm}$ 称为"猜错近邻"。

对应属性的分量 $\delta^i = \sum_{-} \text{diff}(x_i, x_{i,nh})^2 + \text{diff}(x_i, x_{i,nm})^2$

$x_i$ 表示不在 $j$ 的取值：

- 若离散，反当 $x_i^j = x_{ij}$，$\text{diff}(x_i^j, x_{ij}) = 0$，否则为 $1$
- 若连续，$\text{diff}(x_i^j, x_{ij}) = |x_i^j - x_{ij}|$，$x_i$ 规范化到 $[0,1]$

> 越大，分类能力越强。

$\tau$ 需在数据集上采样平均的样本，不一定整体计算，时间是采样次数、原始特征数目的线性关系。

### 2.2 Relief-F

Relief 为二分类，Relief-F 扩展为多分类，$x_i$ 为第 $k$ 类，$p_k$ 为类别 $D$ 中比例：

$$\delta^i = \sum_{-} \text{diff}(x_i, x_{i,nh})^2 + \sum_{L \neq k} (p_k \times \text{diff}(x_i^j, x_{i,L,nm})^2)$$

## 3. 包裹式选择

将学习器的性能作为特征子集的评价准则，看上去好，但多次训练学习器，计算开销大。

### 3.1 LVW (Las Vegas Wrapper)

LVW 基于拉斯维加斯（Las Vegas）的随机策略进行搜索，以交叉验证误差作为评价准则。

**输入：**

- 数据集 $D$；
- 特征集 $A$；
- 学习算法 $\xi$；
- 停止条件控制参数 $T$。

**过程：**

1. $E = \infty$;
2. $d = |A|$;
3. $A^* = A$;
4. $t = 0$;
5. while $t < T$ do
6. 随机产生特征子集 $A'$;
7. $\delta' = |A'|$;
8. $E' = \text{CrossValidation}(\xi(D_{A'}))$;
9. if $E' < E \lor (E' = E \land d > \delta')$ then
10. $E = E'$;
11. $d = \delta'$;
12. $A^* = A'$;
13. else
14. end if
15. $t = t + 1$;
16. end while
17. end while

**输出：** 特征子集 $A^*$

> 交叉验证学习器误差

> 不一定能在有限时间得到训练结果/解

## 4. 嵌入式选择与 $L_1$ 正则化

特征选择与训练过程在一起，在同一优化中完成，即训练中自动进行特征选择。

在原始目标加正则化：

$$\begin{cases} \text{LASSO}, & + \lambda \|w\|_1 \\ \text{"岭回归"}, & + \lambda \|w\|_2^2 \end{cases}$$

- 降低过拟合，$L_1$ 比 $L_2$ 更容易获得稀疏解
- 几何解释：等值线与约束域相切

反应对应变量非零的特征有效。

### 4.1 近端梯度下降 (PGD)

$L_1$ 求解可用近端梯度下降

推导：利用泰勒展开、二阶近似。

选择：

$$x_{k+1} = \arg\min_x \frac{1}{2} \| x - (x_k - \frac{1}{2} \nabla f(x_k)) \|_2^2 + \lambda \|x\|_1$$

对 $x$ 的每个分量互不影响，$x_{k+1}^i$ 的解为：

$$x_{k+1}^i = \begin{cases} z^i - \lambda, & \lambda < z^i \quad (x_{k+1}^i > 0) \\ 0, & |z^i| \le \lambda \quad (\text{最小值在零点，范围内单调}) \\ z^i + \lambda, & z^i < -\lambda \quad (x_{k+1}^i < 0) \end{cases}$$

> 有分量的闭式解（软阈值算子 / Soft Thresholding）

PGD 快速求解 $L_1$ 相关。

## 5. 稀疏表示与字典学习

将 $D$ 视作矩阵，每一个样本对应一个特征。特征选择是删除列。

- **稀疏性**：$D$ 对应有许多元素，使高维冗余可分，同时有方法让稀疏表示已降维且不占用太多空间
- 普通非稀疏数据可转化为"稀疏表示"。例如：文档常用字是"给定稀疏"，在字典是"过度稀疏"

### 5.1 字典学习 (Dictionary Learning)

学习一个"字典"，将普通稠密样本转化为合适的稀疏表示，称"字典学习"/"稀疏编码"。

字典学习最简单形式：

$$\min_{B, \alpha_i} \sum_{i} \| x_i - B\alpha_i \|_2^2 + \lambda \sum_{i} \|\alpha_i\|_1$$

$B \in \mathbb{R}^{d \times k}$ 为字典矩阵，$k$ 为字典的词汇量，$\alpha_i \in \mathbb{R}^k$ 为 $x_i \in \mathbb{R}^d$ 的稀疏表示。

变量交替优化求解：

1. 固定 $B$，按分量展开，给定 $d_i^j$、$d_i^p$ 已知项，求 $\alpha_i$，使 $\min_{\alpha_i} \|x_i - B\alpha_i\|_2^2 + \lambda \|\alpha_i\|_1$

2. 固定 $\alpha_i$，更新 $B$，$\min_B \|X - BA\|_F^2$，$X \in \mathbb{R}^{d \times n}$，$A \in \mathbb{R}^{k \times n}$

逐列更新策略的 K-SVD：$b_i$ 为 $B$ 的第 $i$ 列，$\alpha^i$ 为 $A$ 的第 $i$ 行。

$$\begin{aligned} \min_B \|X - BA\|_F^2 &= \min_{b_i} \|X - \sum_{j=1}^k b_j \alpha^j\|_F^2 \\ &= \min_{b_i} \|(X - \sum_{j \neq i} b_j \alpha^j) - b_i \alpha^i\|_F^2 \\ &= \min_{b_i} \|E_i - b_i \alpha^i\|_F^2 \end{aligned}$$

原则上，对 $E_i$ 做 SVD 取最大奇异值对应左、右奇异向量，但修改 $b_i \alpha^i$ 时，为保持 $A$ 的稀疏性：

K-SVD 处理时，$\alpha^i$ 反保留非零元素，$E_i$ 只保留 $b_i \alpha^i$ 的非零乘积项。

重复以上两步，求得 $B$ 和 $\alpha_i$。

> 可通过 $k$ 控制字典规模，影响稀疏程度。

## 6. 压缩感知

希望根据部分信息恢复全部信息。

长度为 $m$ 的离散信号 $x$，采样得到长度为 $n$ 的 $y$，$n \ll m$，$y = \Phi x$，$\Phi \in \mathbb{R}^{n \times m}$ 为 $x$ 的测量矩阵。

仅通过 $y$ 已知不能还原 $x$，因为是一个不定方程。

假若得 $\psi \in \mathbb{R}^{m \times n}$，$x = \psi s$，$y = \Phi \psi s = As$，若能根据 $y$ 恢复 $s$，则能由 $x = \psi s$ 恢复 $x$。

虽然是不定，但若 $s$ 有稀疏性，则可以求解。中称稀疏正则，$A$ 称作字典。

很多应用可获得具有稀疏性的 $s$（如时域或频域）。

压缩感知关注利用信号本身稀疏性，从部分观测样本中恢复信号。

$$\begin{cases} \text{感知测量：处理原始信号获得稀疏样本表示（如傅里叶变换、字典学习）} \\ \text{重构恢复：基于稀疏性从少量观测中恢复原信号} \end{cases}$$

### 6.1 限定等距性质 (RIP)

"限定等距性质" RIP：若 $A \in \mathbb{R}^{n \times m} (n \ll m)$，若 $\exists \delta_k \in (0, 1)$，对任向量 $s$ 的 $k$ 稀疏矩阵 $A_k \in \mathbb{R}^{n \times k}$ 有

$$(1 - \delta_k) \|s\|_2^2 \le \|A_k s\|_2^2 \le (1 + \delta_k) \|s\|_2^2$$

则称 $A$ 满足 $k$ 限定等距性质 ($k$-RIP)。

此时可通过优化算法从 $y$ 恢复稀疏信号 $s$，进而恢复 $x$：

$$\min_s \|s\|_0, \quad \text{s.t. } y = As$$

但 $L_0$ 范数最小化是 NP 难问题，在一定条件下，$L_1$ 最小化与 $L_0$ 最小化等价，即

$$\min_s \|s\|_1, \quad \text{s.t. } y = As$$

### 6.2 矩阵补全

压缩感知能够恢复采样的前提是：一、信号有稀疏表示。

矩阵补全：$\min_x \operatorname{rank}(X)$，$\text{s.t. } (X)_{ij} = (A)_{ij}, (i, j) \in \Omega$（有样本用样本，无则优先）

但也是 NP 难问题。注意到 $\operatorname{rank}(X)$ 在 $\{X \in \mathbb{R}^{m \times n} : \|X\|_F^2 \le 1\}$ 上的凸包是 $X$ 的"核范数"：

$$\|X\|_* = \sum_{i=1}^{\min\{m, n\}} \sigma_i(X), \quad \sigma_i(X) \text{ 为 } X \text{ 的奇异值}$$

即矩阵的核范数为矩阵的奇异值之和。

最优化矩阵核范数近似求解：

$$\min_X \|X\|_*, \quad \text{s.t. } (X)_{ij} = (A)_{ij}, \quad (i, j) \in \Omega$$

> 凸优化问题可用半正定规划 (SDP) 求解。
