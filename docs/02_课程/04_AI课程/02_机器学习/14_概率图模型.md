# 十四、概率图模型

## 1. 概述

概率图模型 (Probabilistic Graphical Models, PGM) 是一种用图结构描述变量之间依赖关系的概率模型。

- **有向图**：贝叶斯网络 (Bayesian Networks)
- **无向图**：马尔可夫随机场 (Markov Random Fields)

关键概念：

- **联合概率分布**：$P(X_1, X_2, \cdots, X_n)$
- **条件独立性**：给定 $Z$，$X$ 与 $Y$ 独立，$P(X|Z, Y) = P(X|Z)$
- **分解性质**：联合概率可分解为因子的乘积

## 2. 贝叶斯网络

### 2.1 定义

贝叶斯网络是用有向无环图 (DAG) 表示的联合概率分布分解：

$$P(X_1, X_2, \cdots, X_n) = \prod_{i=1}^n P(X_i | \text{Pa}(X_i))$$

其中 $\text{Pa}(X_i)$ 是 $X_i$ 的父结点集合。

### 2.2 独立性

**全局马尔可夫性质**：给定父结点集，每个变量与它的非后代结点条件独立。

**局部马尔可夫性质**：给定父结点集，每个变量与它的子结点条件独立。

**道德图**：将贝叶斯网络转换为无向图的方法：

1. 在同一子结点的两个父结点之间加边
2. 将所有有向边替换为无向边

### 2.3 推断

**精确推断**：

- 枚举：$P(A|B) = \frac{P(A, B)}{P(B)}$，变量消元
- 信念传播（消息传递）

**近似推断**：

- 吉布斯采样：基于马尔可夫链的随机采样
- 变分推断：用简单分布逼近复杂后验

## 3. 马尔可夫随机场 (MRF)

### 3.1 定义

马尔可夫随机场是用无向图表示的联合概率分布：

$$P(X_1, X_2, \cdots, X_n) = \frac{1}{Z} \prod_{C \in \mathcal{C}} \psi_C(X_C)$$

其中：

- $\mathcal{C}$ 是团 (clique) 的集合
- $\psi_C$ 是势函数 (potential function)，$\psi_C > 0$
- $Z$ 是配分函数 (partition function)，$Z = \sum_X \prod_{C \in \mathcal{C}} \psi_C(X_C)$

### 3.2 独立性

**全局马尔可夫性质**：若 $A, B$ 被 $C$ 分离，则给定 $C$ 时 $A$ 与 $B$ 条件独立。

**局部马尔可夫性质**：给定邻居结点，每个变量与其他变量条件独立。

**成对马尔可夫性质**：若 $X_i$ 与 $X_j$ 不相邻，则给定其他所有变量，两者条件独立。

### 3.3 团与分离集

**团 (clique)**：无向图中两两相连的结点子集。

**最大团**：不能再加入任何结点形成更大团的团。

**分离集 (separator)**：移除后将图分离为两个部分的结点集合。

### 3.4 势函数

常用势函数形式：

$$\psi_C(X_C) = \exp(-E(X_C))$$

其中 $E(X_C)$ 是能量函数。

典型的势函数：

- 对数线性模型：$\psi_C(X_C) = \exp(\sum_k w_k f_k(X_C))$
- Ising 模型：$\psi(X_i, X_j) = \exp(J_{ij} X_i X_j)$，$J_{ij}$ 为耦合常数

## 4. 条件随机场 (CRF)

### 4.1 定义

条件随机场是判别式无向图模型，给定输入序列 $X$，输出序列 $Y$ 的条件概率：

$$P(Y|X) = \frac{1}{Z(X)} \exp\left(\sum_k w_k f_k(Y, X)\right)$$

线性链 CRF 的图结构：

$$P(Y|X) = \frac{1}{Z(X)} \prod_{i=1}^n \psi_i(y_{i-1}, y_i, X)$$

### 4.2 参数估计

**训练**：给定 $(X^{(i)}, Y^{(i)})$，最大化条件对数似然：

$$\max_{\mathbf{w}} \sum_i \log P(Y^{(i)} | X^{(i)})$$

对数似然是凹函数，可用梯度下降求解：

$$\frac{\partial L}{\partial w_k} = \sum_i \left[ f_k(Y^{(i)}, X^{(i)}) - \mathbb{E}_{P(Y|X^{(i)})}[f_k(Y, X^{(i)})] \right]$$

### 4.3 推断

**最优序列预测**：Viterbi 算法（动态规划）

给定 $X$，求 $Y^* = \arg\max_Y P(Y|X)$：

$$Y^* = \arg\max_{y_1, \cdots, y_n} \sum_{i=1}^n \log \psi_i(y_{i-1}, y_i, X)$$

Viterbi 算法复杂度 $O(n \cdot |\mathcal{Y}|^2)$，$\mathcal{Y}$ 为状态集合。

## 5. 隐马尔可夫模型 (HMM)

### 5.1 定义

HMM 是序列数据生成模型，包含：

- **隐状态序列** $Z = (z_1, \cdots, z_n)$
- **观测序列** $X = (x_1, \cdots, x_n)$
- **转移概率** $A$：$a_{ij} = P(z_t = j | z_{t-1} = i)$
- **发射概率** $B$：$b_j(x) = P(x_t = x | z_t = j)$
- **初始概率** $\pi$：$\pi_i = P(z_1 = i)$

联合概率分解：

$$P(X, Z) = \pi_{z_1} \prod_{t=1}^{n-1} a_{z_t, z_{t+1}} \prod_{t=1}^n b_{z_t}(x_t)$$

### 5.2 三个基本问题

**评估问题**：给定 $\lambda = (A, B, \pi)$，求 $P(X|\lambda)$

- 前向算法：$O(n |\mathcal{Z}|^2)$
- 后向算法：$O(n |\mathcal{Z}|^2)$

**解码问题**：给定 $X$ 和 $\lambda$，求最优状态序列 $Z^*$

- Viterbi 算法：$O(n |\mathcal{Z}|^2)$

**学习问题**：给定训练集，估计 $\lambda$

- Baum-Welch 算法（EM 算法）：
  - E 步：计算前向-后向概率 $\gamma_t(i) = P(z_t = i | X, \lambda)$
  - M 步：更新参数

### 5.3 Baum-Welch 算法

$$\gamma_t(i) = \frac{\alpha_t(i) \beta_t(i)}{\sum_{j=1}^{|\mathcal{Z}|} \alpha_t(j) \beta_t(j)}$$

$$\xi_t(i, j) = \frac{\alpha_t(i) a_{ij} b_j(x_{t+1}) \beta_{t+1}(j)}{\sum_{i,j} \alpha_t(i) a_{ij} b_j(x_{t+1}) \beta_{t+1}(j)}$$

更新参数：

$$\pi_i = \gamma_1(i)$$

$$a_{ij} = \frac{\sum_{t=1}^{n-1} \xi_t(i, j)}{\sum_{t=1}^{n-1} \gamma_t(i)}$$

$$b_j(k) = \frac{\sum_{t=1, x_t=k}^n \gamma_t(j)}{\sum_{t=1}^n \gamma_t(j)}$$

## 6. HMM 与 CRF 的比较

| 特性 | HMM | CRF |
| :--- | :--- | :--- |
| 模型类型 | 生成式 | 判别式 |
| 概率分解 | $P(X, Z)$ | $P(Y|X)$ |
| 假设 | 状态转移独立性 | 无条件独立性假设 |
| 特征 | 只能使用转移和发射特征 | 可使用任意特征 |
| 训练 | Baum-Welch (EM) | 梯度下降/拟牛顿 |
| 推断 | Viterbi | Viterbi |

## 7. 模型推断方法

### 7.1 精确推断

**变量消元**：利用分解性质逐步计算

$$P(x_1) = \sum_{x_2, \cdots, x_n} P(x_1, x_2, \cdots, x_n) = \sum_{x_2} \cdots \sum_{x_n} \prod_{i} \psi_i(x_i, \text{Pa}(x_i))$$

**信念传播**：在树结构图上精确推断

$$m_{i \to j}(x_j) = \sum_{x_i} \psi(x_i, x_j) \psi(x_i) \prod_{k \in N(i) \setminus j} m_{k \to i}(x_i)$$

### 7.2 近似推断

**蒙特卡罗采样**：

- 拒绝采样
- 重要性采样
- 马尔可夫链蒙特卡罗 (MCMC)：吉布斯采样、Metropolis-Hastings

**变分推断**：

$$\text{ELBO} = \mathbb{E}_{q}[\log P(X, Z)] - \mathbb{E}_{q}[\log q(Z)]$$

$$\log P(X) = \text{ELBO} + \text{KL}(q(Z) \| P(Z|X))$$

KL 散度非负，ELBO 是 $\log P(X)$ 的下界。

## 8. 贝叶斯学习

基于贝叶斯定理更新假设：

$$P(H|D) = \frac{P(D|H) P(H)}{P(D)}$$

- $P(H)$：先验概率
- $P(D|H)$：似然
- $P(H|D)$：后验概率
- $P(D)$：证据

**贝叶斯定理**：后验 $\propto$ 似然 $\times$ 先验

**贝叶斯最优分类**：

$$h^* = \arg\max_h P(h|D) = \arg\max_h P(D|h) P(h)$$

**预测**：

$$P(x|D) = \sum_h P(x|h) P(h|D)$$

## 9. 贝叶斯网络学习

### 9.1 参数学习

给定网络结构，学习 CPT（条件概率表）：

- 完整数据：MLE / 贝叶斯估计
- 不完整数据：EM 算法

### 9.2 结构学习

- **基于评分搜索**：评分函数（BIC/AIC）+ 搜索算法（贪心/模拟退火）
- **基于约束**：利用条件独立性测试构建网络

**Chow-Liu 算法**：构建最大权生成树

1. 计算所有变量对的互信息
2. 构建完全图，边权为互信息
3. 求最大权生成树
4. 确定根结点和边方向

## 10. 总结

概率图模型的核心思想：

- **分解**：利用图结构分解联合概率
- **独立性**：利用条件独立性简化计算
- **推断**：从观测推断隐变量或预测
- **学习**：从数据学习模型参数和结构
