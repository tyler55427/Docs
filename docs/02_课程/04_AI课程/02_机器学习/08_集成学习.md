# 八、集成学习

## 1. 个体与集成

集成学习通过构建多个学习器来完成学习任务（多分类器系统、基于委员会的学习）

一般结构：一组"个体学习器"，用某种策略将它们结合（例："少数服从多数"的投票）

"个体学习器"由已知算法从训练数据产生

- **同质**：只包含同种类型的个体学习器。相应算法称"基学习算法"，个体学习器称"基学习器"
- **异质**：包含不同类型的个体学习器。个体学习器称"组件学习器"

结合常比单一效果好，"弱学习器"（比猜测略高）尤为明显

因此集成学习针对弱学习器，基学习器有时称弱学习器

以分类为例，假设错误率 $\epsilon$ 且相互独立，投票为超过半数相同，则集成错误率随 $T$ 下降，指数下降至 0

但 $\epsilon$ 独立不成立，使"准确性"和"多样性"权衡，即集成学习的核心："好而不同"的建模

分两类：

- 个体学习器之间存在强依赖，必须串行生成的序列化方法（**Boosting**）
- 个体学习器之间不存在强依赖，可同时生成的并行化方法（**Bagging** 和**随机森林**）

## 2. Boosting

一族可将弱学习器变为强学习器的算法

工作机制：

- 从训练集中训练一个基学习器（权重）
- 根据基学习器的表现调整训练集的分布，使错误样本得到更多关注
- 直到学习器数量达到 $T$，将 $T$ 个基学习器加权求和

### 2.1 AdaBoost 算法

代表算法：AdaBoost

"弱模型"基学习器的线性组合：$H(x) = \sum_{t=1}^T \alpha_t h_t(x)$

来最小化指数损失函数 $l_{\exp}(H|D) = E_{x \sim D} \left[ e^{-f(x)H(x)} \right]$，$f$ 是真实函数。

**AdaBoost 算法**

输入：训练集 $D = \{(x_1, y_1), (x_2, y_2), \dots, (x_m, y_m)\}$；基学习算法 $\mathcal{L}$；训练轮数 $T$。

过程：

1. $D_1(x) = 1/m$
2. for $t = 1, 2, \dots, T$ do
3. $\quad h_t = \mathcal{L}(D_t);$
4. $\quad \epsilon_t = P_{x \sim D_t}(h_t(x) \neq f(x));$
5. $\quad$ if $\epsilon_t > 0.5$ then break
6. $\quad \alpha_t = \frac{1}{2} \ln \left( \frac{1-\epsilon_t}{\epsilon_t} \right);$
7. $\quad D_{t+1}(x) = \frac{D_t(x)}{Z_t} \times \begin{cases} \exp(-\alpha_t), & \text{if } h_t(x) = f(x) \\ \exp(\alpha_t), & \text{if } h_t(x) \neq f(x) \end{cases}$
8. end for

输出：$H(x) = \text{sign} \left( \sum_{t=1}^T \alpha_t h_t(x) \right)$

### 2.2 导数推导与贝叶斯最优

$$\frac{\partial l_{\exp}(H|D)}{\partial H(x)} = -e^{-H(x)} P(f(x)=1|x) + e^{H(x)} P(f(x)=-1|x)$$

令导数为 $0$，解得最优 $H(x)$：

$$H(x) = \frac{1}{2} \ln \frac{P(f(x)=1|x)}{P(f(x)=-1|x)}$$

从而：

$$\begin{aligned} \text{sign}(H(x)) &= \text{sign} \left( \frac{1}{2} \ln \frac{P(f(x)=1|x)}{P(f(x)=-1|x)} \right) \\ &= \underset{y \in \{-1, 1\}}{\arg\max} P(f(x)=y|x) \end{aligned}$$

达到了贝叶斯最优分类误差率。

即：若指数损失最小化，则分类错误率最小化，是 $0/1$ 损失函数的一致替代损失函数。

### 2.3 对每一轮迭代的 $\alpha_t h_t$ 的分析

$$\begin{aligned} l_{\exp}(\alpha_t h_t | D_t) &= E_{x \sim D_t} \left[ e^{-f(x)\alpha_t h_t(x)} \right] \\ &= e^{-\alpha_t} (1 - \epsilon_t) + e^{\alpha_t} \epsilon_t \end{aligned}$$

对 $\alpha_t$ 求偏导：

$$\frac{\partial l_{\exp}(\alpha_t h_t | D_t)}{\partial \alpha_t} = -e^{-\alpha_t} (1 - \epsilon_t) + e^{\alpha_t} \epsilon_t$$

置 $D_t$, $d_t = \frac{1}{2} \ln\left(\frac{1-\epsilon_t}{\epsilon_t}\right)$，即权重更新公式

获得 $H_{t-1}$ (而非 $h_{t-1}$) 后对样本分布调整，使 $h_t$ 能纠正 $H_{t-1}$ 的错误

$$h_t(x) = \arg\max_h E_{x \sim D_t} [f(x) h(x)]$$

由于 $f(x)h(x) = 1 - 2\mathbb{I}(f(x) \neq h(x))$，故 $h_t(x) = \arg\min_h E_{x \sim D_t} [\mathbb{I}(f(x) \neq h(x))]$

因此，基于 $D_t$ 训练，且分类误差小于 0.5

Boosting 要求学习算法能对特定数据分布学习：

- 对样本"重见权重"
- 若无法接受带权样本，则"重采样"

训练的每一轮要求基学习器比随机猜测要好，否则应停止学习

重采样比重见权可以用不同样本"重启动力"，防止过早停止

> Boosting 主要关注降低偏差

## 3. Bagging 与随机森林

想泛化强，每个体学习器应尽量独立，但实际不行，考虑较大差异，从训练集中采样

用采样集训练，但可能无法有效学习

考虑相互交叠的采样子集

### 3.1 Bagging

并行式集成学习的代表

自助采样：有放回抽样 (bootstrap sampling)

采样 $m$ 个含 $m$ 个训练样本的采样集，训练 $m$ 个基学习器

$$\text{预测 } \begin{cases} \text{分类：简单投票} \\ \text{回归：简单平均} \end{cases}$$

与基学习器复杂度无关，且能直接用于多分类、回归

自采样的一个采样集约包含 $63.2\%$ 的样本，剩下的 $36.8\%$ 的样本可作验证集，称为"包外估计"

$$\text{包外样本作用 } \begin{cases} \text{决策树剪枝 / 估计零训练样本} \\ \text{辅助神经网络早期停止} \end{cases}$$

> Bagging 主要关注降低方差

### 3.2 随机森林 (RF)

Bagging 的扩展变体

RF 以决策树为基学习器构建 Bagging 上，在决策树的训练过程引入随机属性选择

具体对属性集先选择包含 $k$ 个的子集，再选择最优属性（一般 $k = \log_2 d$）

简单、易实现，开销小，性能强

"多样性" 不仅来自样本扰动，还来自属性扰动，提升泛化性能

开始性能差，随学习器的数量 $m$ 增加，收敛到更低的泛化误差，且计算效率高

## 4. 结合策略

学习器结合的好处：

- **统计**：假设空间大，多个假设在训练集上达到同等性能，结合能泛化
- **计算**：降低局部最小的可能性
- **表示**：多学习器将假设空间扩大，更好近似

$T$ 个学习器 $h_i$，几种常见的结合策略

### 4.1 平均法（回归）

$$\begin{cases} \text{简单平均}，& H(x) = \frac{1}{T} \sum_{i=1}^T h_i(x) \\ \text{加权平均}，& H(x) = \sum_{i=1}^T w_i h_i(x)，\quad w_i \geq 0，\sum_{i=1}^T w_i = 1 \end{cases}$$

> 由于存在噪声，$w_i$ 的训练不一定可靠，且当权重多时，容易过拟合。一般只有学习器性能相差较大时才用加权平均。

### 4.2 投票法（分类）

$h_i$ 在样本 $x$ 上输出一个 $N$ 维向量 $(h_i^1(x), \cdots, h_i^N(x))$，$h_i^j(x)$ 表示 $h_i$ 在类别 $C_j$ 上的输出。

$$\begin{cases} \text{绝对多数投票法}：& H(x) = \begin{cases} C_j，& \frac{1}{T} \sum_{i=1}^T h_i^j(x) \geq 0.5 \sum_{k=1}^N \sum_{i=1}^T h_i^k(x) \\ \text{拒绝}，& \text{其他} \end{cases} \\ \text{相对多数投票法}：& H(x) = C_j，\quad j = \arg\max_{j} \sum_{i=1}^T h_i^j(x) \\ \text{加权投票法}：& H(x) = C_j，\quad j = \arg\max_{j} \sum_{i=1}^T w_i h_i^j(x) \end{cases}$$

输出类型不同：

- **类标记（硬投票）**：$C_j$ 取值为 1，其他为 0
- **类概率（软投票）**：对后验概率 $P(C_j|x)$ 的估计

不同类型的 $h_i^j(x)$ 可混用，可将类标记的置信度归一化为类概率，效果还不错。

但对基学习器的类型不同的类概率，需转化为类标记（异质不行！）

### 4.3 学习法

通过一个学习器来结合，代表为 Stacking。

个体学习器称初级学习器，结合学习器称次级/元学习器。

Stacking 先从训练集产生初级学习器，再生成一个新数据集用于训练次级学习器。

将训练集划分为 $k$ 个大小相似的 $D_i$，$\bar{D}_i = D - D_i$ 为验证集、训练集。$h_i(x)$ 在 $\bar{D}_i$ 上训练。

将 $k$ 个学习器在 $x$ 的输出形成向量，与标记 $y$ 组成 $D'$，用于训练次级学习器。

次级学习器的输入属性对泛化性能有很大影响。

若为类概率，用多响应线性回归 (MLR) 学习法效果好。

贝叶斯模型平均 (BMA) 基于后验概率为不同模型赋予权重。

但只有生成模型在考虑的模型中，且噪声少，BMA 逊于 Stacking。

且对模型近似误差敏感。

## 5. 多样性

### 5.1 误差—分歧分解

$x$ 在 $h_i$ 的分歧：$A(h_i|x) = (h_i(x) - H(x))^2$

集成的分歧：$\bar{A}(h|x) = \sum_{i=1}^T w_i A(h_i|x)$，一定程度上反映多样性。

个体学习器 $h_i$ 和集成 $H$ 的平方误差：

$$E(h_i|x) = (h_i(x) - f(x))^2$$

$$E(H|x) = (H(x) - f(x))^2$$

$$\bar{E}(h|x) = \sum_{i=1}^T w_i E(h_i|x)$$

则 $\bar{A}(h|x) = \bar{E}(h|x) - E(H|x)$

令 $\bar{E} = \sum w_i E_i$，$\bar{A} = \sum w_i A_i$，$E = \bar{E} - \bar{A}$。个体学习器准确、多样，集成越好。

但实际很难对 $\bar{E} - \bar{A}$ 直接优化，且上面用到回归性假设。

### 5.2 多样性度量

考虑个体分类器的两两相似性/相异性。

**列联表**

| | $h_i = +1$ | $h_i = -1$ |
| :--- | :---: | :---: |
| $h_j = +1$ | $a$ | $c$ |
| $h_j = -1$ | $b$ | $d$ |

$m = a + b + c + d$

$$\begin{cases} \text{不相似度量} : \text{dis}_{ij} = \frac{b+c}{m} \quad \text{，值}\uparrow\text{，多样}\uparrow \\ \text{相关系数} : P_{ij} = \frac{ad-bc}{\sqrt{(a+b)(a+c)(c+d)(b+d)}} \quad , \quad c \in [-1, 1] \\ \text{Q-统计量} : Q_{ij} = \frac{ad-bc}{ad+bc} \quad , \quad \text{与 } P_{ij} \text{ 同符号} \quad , \quad |Q_{ij}| \le |P_{ij}| \\ \text{k-统计量} : k = \frac{P_1 - P_2}{1 - P_2} \quad , \quad P_1 \text{ 是 } h_i \text{ 与 } h_j \text{ 一致的概率} \quad \frac{a+d}{m} \\ \quad \quad \quad \quad \quad \quad P_2 \text{ 是 } h_i \text{ 与 } h_j \text{ 偶然达到一致的概率} \quad \frac{(a+b)(a+c) + (c+d)(b+d)}{m^2} \end{cases}$$

$$\begin{cases} k = 1 \text{，完全一致} \quad ; \quad k = 0 \text{，偶然一致} \\ \text{通常非负，反 } P_1, P_2 \text{ 时取负} \end{cases}$$

**"成对型"度量**：绘制二维图

### 5.3 多样性增强

#### 引入随机性

1. **数据样本扰动**：数据集基于采样，分成不同数据子集。（原始采样、自助采样）
   - 对不稳定基学习器（决策树、神经网络）有效
   - 对稳定基学习器（线性学习器、支持向量机、朴素贝叶斯、k近邻学习器）效果有限

2. **输入属性扰动**：一般在冗余属性，使用"子空间"（高维 $\rightarrow$ 低维，属性选择）

3. **输出表示扰动**：对标签进行改动

4. **算法参数扰动**：对模型设置不同的参数
