# 一、数学基础与绪论

## 1. 矩阵基础

### 1.1 Frobenius 范数

$\|A\|_F = \left( \sum_{i=1}^m \sum_{j=1}^n A_{ij}^2 \right)^{\frac{1}{2}}$

矩阵内积 $\langle A, B \rangle = \mathrm{tr}(A^T B) = \sum_{ij} A_{ij} B_{ij}$，即拉平后的内积。

### 1.2 导数

#### 1.2.1 导数 = 最佳线性逼近

导数的本质不是"一个数"，而是**线性映射**：描述"输入微小变化(输入空间) → 输出微小变化(输出空间)"

$$
f(x + dx) \approx f(x) + Df(x)[dx]
$$

| 输入 \ 输出 | 标量     | 向量      | 矩阵   |
| :------ | :----- | :------ | :--- |
| **标量**  | 数      | 向量（切向量） | 矩阵   |
| **向量**  | 向量（梯度） | 矩阵（雅可比） | 三阶张量 |
| **矩阵**  | 矩阵（梯度） | 三阶张量    | 四阶张量 |

#### 1.2.2 各情形的导数

- **标量→标量**
    - $f: \mathbb{R} \to \mathbb{R}$：$f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$
    - 逼近 $f(x+h) \approx f(x) + f'(x)h$
- **标量→向量**
    - $f: \mathbb{R} \to \mathbb{R}^n$：逐分量求导，得切向量 $\frac{df}{dt} = (\frac{df_1}{dt}, \cdots, \frac{df_n}{dt})$
- **向量→标量**
    - $f: \mathbb{R}^n \to \mathbb{R}$：梯度 $\nabla f(x) = (\frac{\partial f}{\partial x_1}, \cdots, \frac{\partial f}{\partial x_n})^T$
    - 逼近 $f(x+dx) \approx f(x) + \nabla f(x)^T dx$（$\nabla f$ 为列向量，与 $dx$ 内积得标量）
    - $\mathbb{R}^n \to \mathbb{R}$ 的线性映射即"与某向量做内积"，该向量就是梯度，指向增长最快方向
- **向量→向量** 
	- $f: \mathbb{R}^n \to \mathbb{R}^m$：雅可比矩阵 $J \in \mathbb{R}^{m \times n}$，$J_{ij} = \frac{\partial f_i}{\partial x_j}$，逼近 $f(x+dx) \approx f(x) + J dx$
    - 行对应输出分量，列对应输入分量
- **矩阵→标量**
	- $f: \mathbb{R}^{m \times n} \to \mathbb{R}$：梯度与输入同形状，$(\nabla_X f)_{ij} = \frac{\partial f}{\partial X_{ij}}$
    - 逼近 $f(X+dX) \approx f(X) + \langle \nabla_X f, dX \rangle = f(X) + \mathrm{tr}\left( (\nabla_X f)^T dX \right)$
- **矩阵→向量/矩阵**：
	- 一般得高阶张量，$T_{kij} = \frac{\partial f_k}{\partial X_{ij}}$。实际计算中**拉平成雅可比**再 reshape 回去

#### 1.2.3 两种布局约定

导数形状约定不一致会导致链式法则转置错乱，全篇必须统一：

| 约定                 | 导数形状          | 说明                                    |
| :----------------- | :------------ | :------------------------------------ |
| **分子布局**<br>（数学分析） | 输出$\times$ 输入 | 上文所用；<br />梯度为列向量                     |
| **分母布局**<br>（计算机）  | 输入$\times$ 输出 | 雅可比的转置；<br />梯度为行向量，矩阵 cookbook 默认此约定 |

#### 1.2.4 链式法则

链式法则永远是**线性映射的复合**，与维度无关：

$$
D(g \circ f)(x) = Dg(f(x)) \circ Df(x)
$$

- 标量：$(g \circ f)' = g'(f(x)) f'(x)$，数相乘
- 向量：雅可比相乘 $J_{g \circ f} = J_g J_f$
- 矩阵/张量：线性映射复合，表现为张量缩并

> 矩阵求导中乘法顺序重要，因为它是线性映射复合的顺序，不可随意交换

### 1.3 奇异值分解 (SVD)

> $AA^T$ 的单位特征向量 $\qquad\qquad\qquad A^TA$ 的单位特征向量

任意实矩阵 $A \in \mathbb{R}^{m \times n}$ 可分解为：

$$
A = U \Sigma V^T \ , \quad U \in \mathbb{R}^{m \times m} \ , \quad \Sigma \in \mathbb{R}^{m \times n} \ , \quad V \in \mathbb{R}^{n \times n}
$$

| 符号                       | 说明                                                     |     |
| :------------------------- | :------------------------------------------------------- | --- | --- |
| $U, V$                     | 满足$U^T U = I$，$V^T V = I$ 的 $m$、$n$ 阶正交矩阵      |     |     |
| $(\Sigma)_{ii} = \sigma_i$ | 其他为$0$，可令 $\sigma_1 \ge \sigma_2 \ge \cdots \ge 0$ |     |     |
| $u_i, v_i$                 | 左/右奇异向量                                            |     |
| $\sigma_i$                 | 奇异值，与$A$ 的秩相同（$A$ 为对称正定，则特征分解相同） |     |     |

**用途**：低秩矩阵近似，将 $r-k$ 个最小的奇异值置 $0$，同时删除其对应的奇异向量。

### 1.3 叉乘

$$
\vec{a} = a_x \vec{i} + a_y \vec{j} + a_z \vec{k} = (a_x, a_y, a_z) \ , \quad \vec{b} = b_x \vec{i} + b_y \vec{j} + b_z \vec{k} = (b_x, b_y, b_z)
$$

$$
\vec{a} \times \vec{b} = \begin{vmatrix} \vec{i} & \vec{j} & \vec{k} \\ a_x & a_y & a_z \\ b_x & b_y & b_z \end{vmatrix}
$$

$$
\vec{a} \cdot (\vec{b} \times \vec{c}) = \vec{b} \cdot (\vec{c} \times \vec{a}) = \vec{c} \cdot (\vec{a} \times \vec{b}) \qquad \text{循环不变等，叉乘有优先级}
$$

### 1.4 特征分解

$$
Av = \lambda v,\quad (\lambda I - A)v = 0,\quad |\lambda I - A| = 0
$$

解得 $\lambda$ 代入 $(\lambda I - A)$，找到特征向量系数之间的关系，任意取具体值得到特征向量

$$
V = (v_1, \cdots, v_n),\quad AV = V \operatorname{diag}(\lambda),\quad A = V \operatorname{diag}(\lambda) V^{-1}
$$

## 2. 优化理论

### 2.1 拉格朗日乘子法

将 $n$ 个变量、$k$ 个约束的最优化转为 $n+k$ 个变量的无约束优化

#### 2.1.1 等式约束

$g(x) = 0$

由 $g(x) = 0$ 确定 $n-1$ 维曲面上 $f(x)$ 最小

$$
\begin{cases} \text{约束曲面上 } x, \nabla g(x) \text{ 正交于约束曲面} \\ \text{最优点 } x^*, \nabla f(x^*) \text{ 正交于约束曲面} \end{cases}
$$

$$
\nabla f(x^*) + \lambda \nabla g(x^*) = 0
$$

定义 $L(\lambda, x) = f(x) + \lambda g(x)$（$\lambda$ 正负可负）

#### 2.1.2 不等式约束

$g(x) \le 0$

$$
\begin{cases} g(x) < 0, \text{ 直接 } \nabla f(x) = 0, \text{ 等价于 } \lambda = 0 \\ g(x) = 0, \nabla f(x^*) + \lambda \nabla g(x^*) = 0 \quad (\lambda > 0) \end{cases} \quad \Longrightarrow \quad \lambda g(x) = 0
$$

得到 KKT 条件：

$$
\begin{cases} g(x) \le 0 \\ \lambda \ge 0 \\ \nabla g(x) = 0 \end{cases}
$$

#### 2.1.3 多约束

$h_i(x) = 0, g_j(x) \le 0$

$$
L(x, \lambda, \mu) = f(x) + \sum_{i=1}^m \lambda_i h_i(x) + \sum_{j=1}^p \mu_j g_j(x)
$$

KKT 条件：

$$
\begin{cases} g_j(x) \le 0 \\ \mu_j \ge 0 \\ \mu_j g_j(x) = 0 \end{cases}
$$

## 3. 概率分布

### 3.1 KL 散度

KL 散度（相对熵/信息散度），度量概率分布的差异

$$
\begin{aligned} KL(P||Q) &= \int_{-\infty}^{\infty} p(x) \log \frac{p(x)}{q(x)} \, dx \\ &= \int_{-\infty}^{\infty} p(x) \log p(x) dx - \int_{-\infty}^{\infty} p(x) \log q(x) \, dx \\ &= -H(P) + H(P, Q) \end{aligned}
$$

$$
\begin{cases} H(P) \text{ 为熵} \\ H(P, Q) \text{ 为交叉熵，用 } Q \text{ 来编码 } P \end{cases}
$$

> 非负性，无对称性
