# 六、概率推理

## 1、不确定性的量化

用逻辑处理问题的困难原因：个脆性（列出完整集合，概率的逻辑）；未知（没有完整的理论认知）。结合概率论 + 效用论 -> 决策论（理性的 agent）。最大化期望效用：$a^* = \arg\max_a \sum_s P(s|a) U(s)$。

**不确定性**：一无所知情况 —— 没有足够的知识以描述当前情况/估计将来结果。观察变量（证据）：世界状态的某些事情；未观察变量：要推理的其他方面；本模型：已知变量与未知变量的关系。基本概率模型（省略）。解：De Finetti 定理（逆反定律下注契约）。

$P(w|T)$ 对 $T$ 的每个取值满足概率分布，具体每个 $t$ 的概率和为 1（归一化分布）。

**归一化操作**：

- 条件 -> 联合：乘法原理：$P(a, b) = P(a|b) P(b)$
- 联合 -> 条件：链式法则：$P(x_1, \dots, x_n) = \prod_{i=1}^n P(x_i | x_1, \dots, x_{i-1})$

$P(w|T=t_i) \propto P(w, T=t_i)$（找到与证据匹配原因）。

**概率推理**：已观察的证据计算查询变量的后验概率。信念度（先验概率），随新证据加入变化。

1 **通过枚举进行推理**：证据变量 $E_1, \dots, E_k = e_1, \dots, e_k$；查询变量 $Q$；隐蔽变量 $H_1, \dots, H_r$。

## 2、联合概率与贝叶斯规则

联合 $P(x_1, \cdots, x_n)$ 已知，求 $P(q | e_1, \cdots, e_k)$。步骤 1：选择与证据一致的条目（$e_i$ 对应取值）。2：从模型求叫得到 $q$ 与 $E_i$ 的联合分布（消去隐藏变量 $H_i$）。3：归一化。

$$P(q | e_1, \cdots, e_k) = \alpha P(q, e_1, \cdots, e_k)$$

问题：定义域大小为 $d$ 的变量，时空复杂度 $O(d^n)$。

2 **贝叶斯规则推理**：

$$P(B|E) = P(B) \times \frac{P(E|B)}{P(E)}$$

逆向构建条件；先验到后验更新。$E$：证据/特征，$B$：信息/类别。基于贝叶斯规则，建立贝叶斯网络进行推理。

**独立性**：$X, Y$ 独立，$P(x, y) = P(x)P(y)$ / $P(x|y) = P(x)$。减少问题域或表示的规模，并减小推理复杂度，但现实完全独立少。

**条件独立**：$P(x|y, z) = P(x|z) \implies P(x, y|z) = P(x|z)P(y|z)$，记 $x \perp y | z$（常用）。新 $P(Y|X, Z) = P(Y|Z)$。

例如：$P(T|R, U) = P(T|R)$（交通 隔离 指挥），$P(F|S, A) = P(F|S)$（着陆 侧风 暴报）。

## 3、朴素贝叶斯

**抓鬼敢死队**：变量定义 $X$ 或：$G$ 鬼位置（$q_t$），$C_{x,y}$ 颜色（$4t$）。世界：均匀先验 $P(G)$。传感器模型 $P(c_{x,y} | G)$，仅取决于到 $G$ 的距离（有条件独立给定 $G$）。

**贝叶斯分解联合概率模型**（链式法则）：

$$P(G, C_{1,1}, \cdots, C_{3,3}) = P(G) P(C_{1,1} \mid G) P(C_{1,2} \mid G, C_{1,1}) \cdots P(C_{3,3} \mid G, C_{1,1}, \cdots, C_{3,2})$$

条件独立化简：

$$P(G, C_{1,1}, \cdots, C_{3,3}) = P(G) P(C_{1,1} \mid G) P(C_{1,2} \mid G) \cdots P(C_{3,3} \mid G)$$

将模型参数数量从指数级简化为线性级。即 **朴素贝叶斯**：一个离散查询变量（通常为类别），所有其他变量是证据变量；给定查询变量，证据变量是条件独立的（每个证据独立地对查询变量影响）。

**朴素贝叶斯分类器**：分类任务：$N$ 种类别标记 $y = \{c_1, \cdots, c_N\}$，把样本 $\vec{x}$ 分类为其中一个；获得后验 $P(c \mid \vec{x})$：机器学习基于有限样本尽可能估计后验。

- **判别式模型**：直接建模 $P(c \mid \vec{x})$；神经网络（类别的特征）
- **生成式模型**：先对 $P(\vec{x}, c)$ 建模，再获得 $P(c \mid \vec{x})$

$\vec{x}$ 中的 $x_i$ 属性独立性假设：

$$P(c \mid \vec{x}) = \frac{P(c) P(\vec{x} \mid c)}{P(\vec{x})} = \frac{P(c)}{P(\vec{x})} \prod_{i=1}^{d} P(x_i \mid c)$$

$P(c)$、$P(x_i \mid c)$ 由训练集 $D$ 估计：

$$P(c) = \frac{|D_c|}{|D|}, \quad P(x_i \mid c) = \frac{|D_{c, x_i}|}{|D_c|}$$

## 4、平滑与朴素贝叶斯评估

若 $Q$ 中出现 $D$ 中没有的 $x$，「平滑」处理：

$$\hat{P}(c) = \frac{|D_c| + 1}{|D| + N} \rightarrow \text{类别数量}, \quad \hat{P}(x_i | c) = \frac{|D_{c, x_i}| + 1}{|D_c| + N_i} \rightarrow \text{取值数量}$$

不用管 $P(x)$，相对归一化操作。应用：实时预测、多类别预测、文本分类、推荐系统（速度快）。

- 优：大数据集容易实现，效果好；计算效率高；多类别预测，文本分类
- 劣：特征独立性假设不成立；数据集精度下降；当预测概率而非类别，有偏见

## 5、贝叶斯网络

贝叶斯网络：简单条件分布（条件独立）来描述复杂联合概率模型。

$$P(x_1, \cdots, x_n) \stackrel{\text{def}}{=} \prod_{i=1}^{n} p(x_i | \text{parents}(x_i))$$

（$\text{parents}(x_i)$ 表示结点 $x_i$ 的父结点）

**图模型**：局部图关系/条件独立性 —— DAG：有向无环图：属性之间依赖关系；CPT：条件概率表：描述属性的联合分布。结点：变量（可以赋值（observed）/ 未赋值）；有向边：条件独立的影响。

自由参数数量：父变量取值范围 $d_1, \cdots, d_k$，变量取值范围 $d$，$(d-1) \prod d_i$。

稀疏的贝叶斯网络：$n$ 个变量；变量范围最大为 $d$；父变量最大个数 $k$。完整联合概率的规模：$O(d^n)$；贝叶斯网络：$O(n \cdot d^k)$。

1 **全局语义**：$P(X_1, \cdots, X_n) = \prod_{i} P(X_i \mid \text{Parent}(X_i))$，可以使用拓扑排序做到；与链式法则对比：链式一般性假设 $\text{Parent}(X_i) \subseteq \{X_1, \cdots, X_{i-1}\}$ 使类似；条件独立时，则 $P(X_i \mid X_{i-1}, \cdots, X_1) = P(X_i \mid \text{Parent}(X_i))$。

2 **条件独立语义**：给定父节点，一个结点条件独立于其他祖先节点；更一般地，给定父变量，每个变量条件独立于其非后代（祖先 + 后代的父节点）。

3 **马尔可夫覆盖**：一个结点包括父节点、子结点、子结点的父节点；给定一个变量的马尔可夫覆盖，则该节点独立于其他所有变量。

## 6、贝叶斯网络推理

1 **枚举**：$P(Q|e) = \alpha \sum_{h} P(Q, h, e)$ 对联合分布的求和 $= \alpha \sum_{h} P(X_i | \text{Parent}(X_i))$ 再用贝叶斯网络展开。指数级多的乘积求和。

2 **变量消元法**：因式分解。使用 factors（因子）：$\sum_{h} P(h) \sum_{u} P(u) P(X_i | \text{Parent}(X_i))$，以多值变量为索引的下拉矩阵。大写代表变量（维数量），小写代表具体取值。实现值重叠 = 表格维数。1 逐点相乘（非矩阵相乘）（形成更大因子）；新因子变量集是原始因子变量集的并集；每个项目是原始因子中相应项目的乘积（一个元素一个元素的乘，在证据相同下）。2 求和消元（$P(A) = \sum_{b} P(A, b) = \sum_{b} P(A|b) P(b)$）；针对因子中的变量求和，把因子缩小到一个更小因子；将变量依次固定为一个取值，然后子矩阵相加。实践同时进行。过程：初始因子（CPT），遇到隐藏变量 $H_i$，进行1、2消去，逐点相乘归一化。消元过程中一个因子中含有的最大变量数目；最大因子的规模（消去一个变量时涉及到的因子数量）（网络 $n$ 个节点，最大因子规模 $2^n$）。变量消元：不同消元顺序影响时空复杂度，获得不最优。

## 7、精确推理与 D-Separation

贝叶斯网络精确推理：依赖网络结构。拓展：多形树：两结点只有一条无向路径的图（变量消元，线性规模，时空复杂度）；多连通网络，指数级，时空复杂度；聚类（联合树）优化。

**D-Separation**：判断条件独立。给定条件变量集合 Z，若两结点 X、Y 之间所有路径（无向）都被阻断（X、Y 之间的无向路径都被阻断（给定）），则 $X \perp\!\!\!\perp Y \mid Z$。

1 Tail-to-Tail（c 在箭头的尾）2 head-to-tail 3 head-to-head。网络类型（$X=a, Y=b, Z$）| $Z$ 是 $c$ 或 $c$ 的后代 | $Z$ 既不是 $c$ 也不是 $c$ 的后代：1 阻塞 / 不阻塞；2 阻塞 / 不阻塞；3 不阻塞 / 阻塞。看路径上所有结构，每相邻三个节点，若给定中间节点 $c$ 或 $c$ 的后代中的一个，用表判断；若路径上存在一处阻塞，则阻塞；直接相邻的不独立。

## 8、近似推理：采样

采样 = 从待采样的概率分布中采样 N 个样本，计算一个近似的后验，用频率逼近真实概率 P。优：快、通用简单、内存小、适用于大型模型。

1 **直接采样**：根据贝叶斯网络联合概率生成样本，分类统计。Prior: random()，$P_A \approx \frac{N(A)}{N}$，N 小则精确。

```text
for t = 1, ..., n (拓扑序，使父节点先确定，规则注采样(CPT)):
    Sample X_i from P(X_i | parents(X_i))
Return (x_1, ..., x_n) 具体样本
```

生成一个待定事件 $S_{P_S}(x_1, \cdots, x_n) = \prod_i P(x_i \mid \text{parents}(x_i)) = P(x_1, \cdots, x_n)$。大样本极限：$\lim_{N \to \infty} Q_N(x_1, \cdots, x_n) = P(x_1, \cdots, x_n)$。

2 **拒绝采样**：根据贝叶斯网络联合概率生成样本，把符合条件的样本分类统计。Rejection：伪代码需增加对与证据不符的判断（跳入证据），不符则退出本轮。问题：概率低时，效率低，没有利用已知的证据。

3 **似然采样 Likelihood**：按贝叶斯网络联合概率生成满足证据的样本，把样本分配上样本权重再统计。

- Input: evidence $e_1, ..., e_k$；$w = 1.0$
- for $i = 1, 2, ..., n$：if $X_i$ is an evidence variable -> $x_i$ = observed value, for $X_i$；Set $w = w * P(x_i \mid parents(X_i))$；else -> Sample $x_i$ from $P(X_i \mid parents(X_i))$
- return $(x_1, x_2, ..., x_n), w$

问题：样本分布不一样，用给定父节点的证据变量概率加权。思路：固定证据变量，对剩余变量采样。非证据变量（隐藏变量）记为 $z$，证据变量的值固定为 $e$。采样的分布为 $S_{ws}(z, e) = \prod_j P(z_j \mid parents(z_j))$。每个样本有权重值：$w(z, e) = \prod_k P(e_k \mid parents(E_k))$。似然加权采样是一致的：$S_{ws}(z, e) \cdot w(z, e) = P(z, e)$。重要性采样的一种：根据 $P$ 的样本估计一些数量，用 $\frac{P(x)}{Q(x)}$ 对每个样本加权。

- 优势：所有样本都适用；非证据变量的采样值会受到祖先节点中证据的影响（隐藏变量出现在下游）
- 劣势：上游非证据变量的采样值不会受到下游的证据的影响（无证据指导生成样本）；证据样本数量增加，样本权重指数级减小

4 **吉布斯采样**：改变当前样本的一个非证据变量，生成新的样本。Gibbs：MCMC 是一系列随机算法，在非常大的状态空间中逼近一些值。马尔科夫链：一系列随机选择的状态，每个状态根据前面一个状态选择。特殊的 MCMC：状态是对所有变量的完整赋值；只改变非证据变量，证据变量固定；生成下一个状态时，选择一个变量并根据所有其他变量对其采样一个值。贝叶斯网络：$P(x_i|x_{-i}) = P(x_i | \text{马尔可夫覆盖}(x_i))$。

why：样本很快反映网络的所有证据，因为是从真正的后验中采样的。how：$P(x_i|x_{-i}) = P(x_i | \text{马尔可夫覆盖}(x_i)) = \alpha P(x_i | \text{parents}(x_i)) \prod_j P(y_j | \text{parents}(y_j))$（$y_j$ 是 $x_i$ 的子结点（后代））。

大型贝叶斯网络常用：BUGS、JAGS、STAN、Infer.net。编译运行快（只用采样和乘积）、并行异步运行（每个变量一个处理器）、收敛速度慢。稳态：$\pi_{t+1}(x') = \sum_x (x'|x)\pi_t(x)$。

## 9、时间上的概率推理：马尔可夫模型

时间与不确定性、马尔科夫模型、隐马尔科夫模型。

- $X$ 在给定时间的值称为状态 state
- **转移模型** $P(X_t | X_{t-1})$ 状态的演变 -> 已知
- 稳态过程假设：转移概率在所有时间是相同的
- **马尔科夫假设**：当前状态只依赖于前一个状态，而与更早的状态递（依赖多少称为 $n$ 阶）

$$P(X_0, \cdots, X_T) = P(X_0) \prod_{t=1}^T P(X_t | X_{t-1})$$

与贝叶斯网络对比：均为 DAG，因果/时间关系，联系=事件独立；但马尔科夫链有那么多变量，转移模型的重复性不是贝叶斯网络的语法。表示同一概率表的两种方法：$X_t$ 作为单结点；$X_t$ 的 $n$ 作为单结点。

$$P(X_t) = \sum_{X_{t-1}} P(X_t | X_{t-1}) = \sum_{X_{t-1}} \prod_{i=1}^t P(X_i | X_{i-1}) \cdot P(X_0)$$

**前向算法**：由初始和转移模型，写成递归 $F_t = g(F_{t-1}) = g(g(\cdots g(T_0)))$。使用矩阵相乘，$\vec{T}^T \cdot \vec{X}_{t-1}$。稳态分布：$\vec{P}_{\infty} = \vec{P}_{\infty-1} = T^T \vec{P}_{\infty}$。到达稳态有条件，有些稳态不一定能达到；也不一定只有一个（多解时）。

## 10、隐马尔可夫模型（HMM）

真实状态不能直接观察。

- 状态 $X$ 的马尔科夫链是隐藏的
- 每个时间步能观察到证据 $E$
- $X_t$ 是单值离散变量；$E_t$ 是连续包含多个变量

$$\left(x_0 \rightarrow x_1 \rightarrow x_2 \rightarrow \cdots\right), \quad \left(E_1 \quad E_2\right)$$

- **初始状态分布**：$P(X_0)$
- **转移模型**：$P(X_t | X_{t-1})$
- **传感器模型（likelihood）**：$P(E_t | X_t)$

联合分布：$P(X_0, \cdots, X_t, E_{1:t}) = P(X_0) \prod_{i=1}^{t} P(X_i | X_{i-1}) P(E_i | X_i)$。马尔科夫（假设）；传感器马尔科夫（假设）：证据变量只依赖于当前的状态变量。应用：语音识别、机器翻译（HMM）、机器人跟踪、分子测序。

**推理任务**：滤波 $P(X_t | e_{1:t})$、预测 $P(X_{t+1} | e_{1:t})$、平滑 $P(X_k | e_{1:t}), k < t$、最可能解释（即解码）。

1 **滤波**：给定目前所有证据，计算当前状态的后验概率分布。推理算法：向前算法。假设 $f_0$ 为均匀分布。滤波算法：设计一个递归过滤算法：$P(X_{t+1} | e_{1:t+1}) = g(e_{t+1}, P(X_t | e_{1:t}))$。

$$P(X_{t+1} | e_{1:t+1}) = \alpha P(e_{t+1} | X_{t+1}, e_{1:t}) P(X_{t+1} | e_{1:t})$$

## 11、更新与预测

$$
\begin{aligned}
& \text{更新} \quad \text{预测} \\
& = \alpha P(e_{t+1} \mid x_{t+1}) P(x_{t+1} \mid e_{1:t}) \\
& = \alpha P(e_{t+1} \mid x_{t+1}) \sum_{x_t} P(a_t \mid e_{1:t}) P(x_{t+1} \mid x_t, e_{1:t}) \\
& = \alpha P(e_{t+1} \mid x_{t+1}) \sum_{x_t} P(a_t \mid e_{1:t}) P(x_{t+1} \mid x_t)
\end{aligned}
$$

$f_{1:t+1} = \text{Forward}(f_{1:t}, e_{t+1})$。结果有 $|X|$ 个相对概率，每个概率需要前一个结果的计算；每个时间步的复杂度为 $O(|X|)$，时空复杂度是常数，独立于 $t$，总共 $O(t|X|)$。预测部分准确率随时间积累降低。

变为矩阵：转移矩阵 $T_{ij} = P(x_{t+1}=j \mid x_t=i)$，观察矩阵 $O_t$ 取具体值只乘一列，转为对角阵，累计对角阵 $P(e_t \mid x_t=i)$。

$$f_{1:t+1} = \alpha O_{t+1} T^T f_{1:t}$$

## 12、平滑（前向向后算法）

2 **平滑**：$P(x_k \mid e_{1:t}) \quad f_{01}, \quad 0 \le k < t$。给定目前所有证据，计算过去某一状态的后验。推理算法：前向向后算法。

网格流图：节点为 $H_i$ 的取值 $h_{ij}$，边权重 $\underbrace{p(h_i \mid h_{i-1}) P(e_i \mid h_i)}_{\text{权重}}$。记路径权重为路径上的边的权重乘积，记作 $w(h_{i-1}, h_i)$。

前向：$F_i(h_i) = \sum_{h_{i-1}} F_{i-1}(h_{i-1}) w(h_{i-1}, h_i)$，从 start 到该点所有路径权重的和。后向：$B_i(h_i) = \sum_{h_{i+1}} B_{i+1}(h_{i+1}) w(h_i, h_{i+1})$，从 end 到该点所有路径权重的和。

定义 $S_i(h_i) = F_i(h_i) B(h_i)$，从 start 到 end 经过该点的所有路径权重的和。$P(H_i=h_i | E=e) \propto S_i(h_i)$，$O(n K^2)$，$n$ 个状态，每个状态 $K$ 个取值。

前向的算法：计算 $F_1, \cdots, F_n$；计算 $B_n, \cdots, B_1$；计算 $S_i$ for each $i$，并归一化。

合理性：$P(X_k | e_{1:t}, e_{k+1:t}) = \alpha P(X_k | e_{1:k}) P(e_{k+1:t} | X_k, e_{1:k})$（贝叶斯公式）$= \alpha P(X_k | e_{1:k}) P(e_{k+1:t} | X_k)$（条件独立）$= \alpha f_{1:k} \times b_{k+1:t}$。

```text
function Forward-Backward(ev, prior) returns 一个概率分布的向量
    inputs: ev, 时间步 1, ..., t 的证据值的向量
    prior, 初始状态的先验分布 P(X_0)
    local variables: fv, 时间步 0, ..., t 的前向消息的向量
    b, 后向消息的表示，初始化全为 1
    sv, 时间步 0, ..., t 的平滑估计的向量

    fv[0] := prior
    for i = 1 to t do
        fv[i] := Forward(fv[i-1], ev[i])
    for i = t down to 1 do
        sv[i] := Normalize(fv[i] × b)
        b := Backward(b, ev[i])
    return sv
```

## 13、维特比算法（最可能解释）

3 **最可能解释**：$\text{argmax}_{x_{1:t}} P(x_{1:t} | e_{1:t})$。给定观察序列，找出最可能生成这些观察结果的状态序列。推理任务：维特比算法。

$$\text{argmax}_{x_{1:t}} P(x_{1:t} | e_{1:t}) = \text{argmax}_{x_{1:t}} P(x_0) \prod_{t=1:T} P(x_t | x_{t-1}) P(e_t | x_t)$$

状态网络：状态和转移随时间变化的图。每条边代表一个转移 $x_{t-1} \rightarrow x_t$；每条边权重 $P(x_t | x_{t-1}) P(e_t | x_t)$；路径上的权重的乘积与该状态序列的概率成正比。不能用滤波（最后最大），平滑（中间最大）。

$$m_{t+1} = \text{Viterbi}(m_t, e_{t+1}) = P(e_{t+1} | X_{t+1}) \max_{x_t} P(X_{t+1} | x_t) m_t$$

对 $X_{t+1}$ 的 $x_{t+1}$ 中取 $x_t$ 的最大的边，时间 $O(|S|^2 T)$、空间 $(|S|T)$、路径 $O(|S|T)$。数值太大/太小，取 $\log$，将乘积变为和。

**维特比算法伪代码**：

```text
Result: Most likely sequence of hidden states x_{1:N}^*
/* forward pass
for t = 1 to N do
    for x_t ∈ X do
        if t = 1 then
            m_t(x_t) = P(x_t) P(o_t|x_t)
        else
            m_t(x_t) = P(o_t|x_t) max_{x_{t-1}} P(x_t|x_{t-1}) m_{t-1}(x_{t-1})
            a_t(x_t) = argmax_{x_{t-1}} P(x_t|x_{t-1}) m_{t-1}(x_{t-1})
/* Find the most likely path's ending point
x_N^* = argmax_{x_N} m_N(x_N);
/* Work backwards through our most likely path and find the hidden states
for t = N down to 2 do
    x_{t-1}^* = a_t(x_t^*)
```

## 14、动态贝叶斯网络与粒子滤波

**动态贝叶斯网络（DBNs）**：每个时间步有任意数量状态变量、证据变量；用动态贝叶斯网络（DBNs）表示居跟踪新变量；每次重复一个固定的贝叶斯网络结构。VS：每个隐马尔科夫模型可以表示为每个状态量、证据变量的 DBNs；每个离散变量的 DBNs 可以表示为一个隐马尔科夫模型（多合成一个）。

DBNs 的推理任务：1 精确推理：变量消元法。离线：展开所有 $t$，变量消元法，问题：最大因子包含当前时间步的所有变量，复杂度仍是变量个数的指数级。在线：消 $t$ 的所有元，只存储当前时间步的因子。

2 **近似推理：粒子滤波（重点）**。任何一个状态变量的祖先结点都不包含任何证据变量 —— 实际生成的样本集合完全不依赖于证据；与真实状态序列接近的样本比例随 t 呈指数级下降；维持一定的精度水平所需的样本数随 t 指数级增加。问题：似然加权忽略证据，都在叶子节点。解决：根据 e，舍弃低权重样本，生成更多高权重样本，即：重采样 / SOF（适者生存）。

**粒子滤波**：目标：用一组样本表示信念状态 $P(x_t | e_{1:T})$，这组样本称为粒子（较短表示信息）；每时间步的计算时间与样本数量成正比（但传统似然加权要 $|X|$ 才能）；想用 $N \ll |X|$ 个样本来表示 $P(x)$；用取值为 $x$ 的粒子数近似 $P(x)$；更少的粒子近似推理；通常求一个后维边缘分布。

每一步：根据粒子当前位置和转移模型，采样下一个时间步的位置；观察到新的证据后，对每一个粒子进行似然加权，并归一化似然权重；加上重采样的思想（舍弃低权重），根据归一化的似然权重，重新采样粒子数量个的新粒子。

```text
function PARTICLE-FILTERING(e, N, dbn) returns a set of samples for the next time step
    inputs: e, the new incoming evidence
            N, the number of samples to be maintained
            dbn, a DBN with prior P(X_0), transition model P(X_1 | X_0), sensor model P(E_1 | X_1)
    persistent: S, a vector of samples of size N, initially generated from P(X_0)
    local variables: W, a vector of weights of size N

    for i = 1 to N do
        S[i] <- sample from P(X_1 | X_0 = S[i])   /* step 1 */
        W[i] <- P(e | X_1 = S[i])                /* step 2 */
    S <- WEIGHTED-SAMPLE-WITH-REPLACEMENT(N, S, W) /* step 3 */
    return S
```
