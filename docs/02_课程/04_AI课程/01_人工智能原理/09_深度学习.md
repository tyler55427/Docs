# 九、深度学习

## 1、前馈网络与 MLP

**前馈网络**：在一个方向上有连接的网络，有向无环，指定输入和输出。

**网络的单元**：计算前驱节点的输入的加权和，并使用非线性函数产生该节点的输出 $a_j = g_j(\sum_i w_{ij} a_i)$。

**MLP：多层线性感知器**。神经元/感知器：（偏置）；每个输入有一个权重 $w_{ixj}$（还有一个固定输入 $a_0$，对应权重 $w_{0,j}$）；输出：激活函数 $g(\vec{a}_i w_{ixj})$（$g$ 增加非线性关系）（对每个元素操作）。

**激活函数选项**：

- 1 threshold
- 2 sigmoid $\frac{1}{1+e^{-x}}$
- 3 $\frac{e^x - e^{-x}}{e^x + e^{-x}} = \text{tanh}$
- 4 $\text{ReLU} = \max(0, x)$；$x \cdot \text{sigmoid}(x)$ 近似 ReLU，但可导

## 2、逻辑回归分类与神经网络

$$\max_w l(w) = \max_w \sum \log P(y^{(i)} | x^{(i)}, w) = \max_w \sum \log \frac{e^{w_{y^{(i)}} \cdot f(x^{(i)})}}{\sum_y e^{w_y \cdot f(x^{(i)})}}$$

$$P(y_2 | x; w) = \frac{e^{z_3}}{e^{z_1} + e^{z_2} + e^{z_3}}, \quad \frac{e^z}{\sum e^z}$$

人工设计特征/机器学习（特征?）-> 使用前面的神经网络学习特征：$h = \phi(x \times W_{\text{layer1}})$，$y = \phi(h \times W_{\text{layer2}})$。

输入 $(1, \dim(x))$，输出 $(1, \dim(y))$，矩阵为 $(\dim(x), \dim(y))$；使用 $(\text{batch size}, \dim(x))$ 并行计算；权重乘法和非线性函数应用于每一行（一个批次中的同一组数据）；高维矩阵乘法，前面维度相同不变，最后两个维度进行矩阵乘块。

**函数逼近**：隐藏足够大，即使两层也能学习逼近任何精度。实际考虑：前面用于学习特征；太多神经元能过拟合；优化难度大。

**训练**：

1. $y = \phi(\phi(x W_1) \times W_2)$
2. 损失函数（希望更低）：零一损失（错误接受数量）、对数损失（$-\sum y_i \log P_i$，$y_i$ 为真实类别，$P_i$ 是预测概率）、误差平方和。注：右侧小字标注为「训练 $P_i$ 变，$y_i$ 不变」
3. 数值方法（如梯度下降）最小化优化损失 $\text{loss}$：$w \leftarrow w - \alpha \nabla \log \text{loss}(w)$

**反向传播**：链式法则；通过计算图，每个节点都视为变量，计算导数（反向传播）。

## 3、激活函数、输出层与经典架构

激活函数：隐藏层使用相同的激活函数；输出层使用与隐藏层不同的激活函数，与预测类别有关：回归值域（回归问题）；分类：sigmoid / softmax。

著名的神经网络的架构：残差、注意力机制、Transformer。

**支持向量**：距离决策平面的距离和最大（两个类的和）（SVG）。convex optimization（凸优化）；计算得 $\min \frac{1}{2} \|w\|^2$，$\text{st } y_i(w \cdot x_i + b) \ge 1$（预测正确）。

回归：没有激活函数；分类：二分（sigmoid）、多分（softmax）。

**朴素贝叶斯分类**：$$P(c, w_1, \cdots, w_n) = P(c) \prod_{i=1}^n P(w_i | c) \quad (\text{防止未出现情况，拉普拉斯平滑})$$初始化时加上小常数 $1$。多形树（DAG），且无向也不含环：$$P(c | w_1, \cdots, w_n) = \alpha P(c) \prod_{i=1}^n P(w_i | c)$$需要估计的参数：先验 $P(c) = [\theta_c, 1 - \theta_c]$；似然 $P(w_i | c)$。
