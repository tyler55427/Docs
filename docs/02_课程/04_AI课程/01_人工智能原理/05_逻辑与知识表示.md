# 五、逻辑与知识表示

## 1、逻辑简介

**逻辑推理**：应用一系列推理规则得到结果。

### Search Problems

基于状态的模型，考虑：状态、行动代价。question：最小代价的路径？感知器，根据数据给定（估计）的行动代价。流程：`data` -> `Learning` -> `model` -> `Inference` -> `answer`。推理算法：DFS、UCS 或 $A^*$。

### CSP

基于变量的模型，考虑：变量和限制。question：最高得分的赋值？例如地图着色问题的建模。流程：`data` -> `Learning` -> `model` -> `Inference` -> `answer`。推理算法：回溯搜索。

### 逻辑

基于逻辑的模型，考虑：逻辑公式和值理逻辑。优势：表达能力强；应用：定理证明、验证、推理。

## 3、陈述性构建 Agent

陈述性构建 Agent：告诉它要东西（让其学习到知识）；它可以询问它的环境应该采取什么行动。Agents 处于知识层，只需描述它知识，不关心具体的实现。

**逻辑**：

- **语法**：为所有合法语句给出规范（规定合法语句）
- **语义**：每个语句在每个可能世界的真值，对命题符号则试值（定义每条语句在每个世界真值）

**不同类型**：命题逻辑、一阶逻辑。

**逻辑连接词**：

- 否定（不）：$\neg$、N（前缀）、$\sim$
- 合取（与）：$\wedge$、K（前缀）、&、$\cdot$
- 析取（或）：$\vee$、A（前缀）
- 实质蕴含（如果...那么）：$\rightarrow$、C（前缀）、$\Rightarrow$、$\supset$
- 双条件的（当且仅当）：$\leftrightarrow$、E（前缀）、$\equiv$、$=$

**命题逻辑**：推理：蕴含 entail：$\alpha \vdash \beta$ 即等价于 $\alpha \Rightarrow \beta$ 为 true，当 world $\alpha$ is true，$\beta$ is also true（$[\text{models}(\alpha) \subseteq \text{models}(\beta)]$）。

证明 $\alpha$ 与 $\beta$ 的蕴含关系（$\text{KB} \models \text{query}$ 的正确性）：

- **可靠的 Sound**：算法可以推导出这条蕴含句；不包含错的结果，所有输出是正确的
- **完备的 Complete**：算法可以生成任何一条蕴含句；包含所有对的结果，输出所有正确的输出

## 4、模型检验与定理证明

$\text{KB} \vdash \alpha$：推断算法从 KB 推导出 $\alpha$。仅推导蕴含语句的推断算法是可靠的：前提是真则结论为真（得出的推论是正确的）。完整性：推断算法能推导所有蕴含语句：蕴含推出所有的 $\alpha$。

证明蕴含两种方法：

- 1 **模型检验**：枚举所有可能世界的取值
- 2 **定理证明**：使用推理规则从 $\alpha$ 推导到 $\beta$

**命题逻辑语法**：$X_i$ 为命题逻辑的原子语句，组成复合句。**命题逻辑语义**：模型 $m$ 给 $\{X_1, \cdots, X_n\}$ 判真值，$\alpha$ 语句的真值 $s$ 由 $m$ 赋予。

### 1、 模型检验（暴力枚举搜索）

```text
function TT-ENTAILS?(KB, α) returns true or false
    inputs: KB, the knowledge base, a sentence in propositional logic
    α, the query, a sentence in propositional logic
    symbols := a list of the proposition symbols in KB and α
    return TT-CHECK-ALL(KB, α, symbols, {})

function TT-CHECK-ALL(KB, α, symbols, model) returns true or false
    if EMPTY?(symbols) then
        if PL-TRUE?(KB, model) then return PL-TRUE?(α, model)
        else return true
    else return true when KB is false, always return true
    else
        P := FIRST(symbols)
        rest := REST(symbols)
        return (TT-CHECK-ALL(KB, α, rest, model ∪ {P = true}) and TT-CHECK-ALL(KB, α, rest, model ∪ {P = false}))
```

问题：时间复杂度为指数级的（深度优先搜索）。KB 为真时 —— $\alpha$ 皆为真，能推出 $\alpha$；$\alpha$ 全为假，能推出 $\neg\alpha$。

## 5、前向链接、归结与反证法

**前向链接**：将新事实加到 KB 中，要求 KB 包含有限句（只包含正文字的析取式，单语句）。

```text
function PL-FC-ENTAILS?(KB, q) returns true or false
    count := a table, where count[c] is the number of symbols in c's premise
    inferred := a table, where inferred[s] is initially false for all s
    agenda := a queue of symbols, initially symbols known to be true in KB
    while agenda is not empty do
        p := Pop(agenda) //准备处理项表中的一个符号p
        if p = q then return true
        if inferred[p] = false then //这个符号p是否已经被推导出来了，如是，则无需再次添加到Agenda中
            inferred[p] := true
            for each clause c in KB where p is in c.premise do
                decrement count[c] //对每个前提中出现p的蕴含式而言，它相应的计数值减去1
                if count[c] = 0 then add c.conclusion to agenda //蕴含式的所有前提都已知，将它的结论添加到Agenda中
    return false
```

性质：限定子句的 KB —— 可靠的（假设推理是可靠的）；完备的（算法 + 定义，穷举为真的前提）。

3 **归结（归纳作结论）**：将 CNF 转化为一个新的 CNF。归结算法：基于归结对 KB ∧ α 转为 CNF 使用归结推断；转为 CNF：替换（<-, ->），∧ 对 ∨ 分配。归结规则；与完备搜索策略结合得到完备的推断算法。

3 **反证法**：$\text{KB} \models \alpha$，证 $\text{KB} \land \neg\alpha$ 在所有世界都不是真（不可满足的）。把含有互斥文字。可满足的：一个语句在某些模型是真的。SAT 求解器：求使语句为真的模型。逻辑等价；有效性/重言式；单调性、逻辑伴随信息加入增长（违反：改变想法）。

## 6、合取范式与 DPLL

即反证法/消解法（方便转 CNF）。

**合取范式 CNF**：每个语句可以写成句的合取；每个子句都是非合取的析取式；每个析取式是一个命题词/非命题词。

有效的 SAT：DPLL，利用合取范式的性质。本质上 DFS 树掌，加以下改进：

- 启发式：提前终止 —— A 出现在所有句且为真则真；一个子句为假
- **纯符号启发式**：赋值一个符号减少子句数量（都是 A / $\neg$A）
- **单元句启发式**：句只有一个文字，直接赋值使句为 true

```python
function DPLL(clauses, symbols, model) returns true or false
    if every clause in clauses is true in model then return true  # 如果 CNF 中每个子句都为真
    if some clause in clauses is false in model then return false  # 提前终止
    P, value <- FIND-PURE-SYMBOL(symbols, clauses, model)  # 纯符号启发式 缩小求解空间了
    if P is non-null then return DPLL(clauses, symbols-P, model ∪ {P=value})
    P, value <- FIND-UNIT-CLAUSE(clauses, model)  # 单元子句启发式 缩小求解空间了
    if P is non-null then return DPLL(clauses, symbols-P, model ∪ {P=value})
    P <- First(symbols); rest <- Rest(symbols)  # 正常对第一个符号进行赋值
    return or(DPLL(clauses, rest, model ∪ {P=true}),
               DPLL(clauses, rest, model ∪ {P=false}))
```

**命题逻辑的智能体**：基于知识的 Agent。

```python
function KB-AGENT(percept) returns an action
    persistent: KB, a knowledge base
    t, an integer, initially 0
    TELL(KB, MAKE-PERCEPT-SENTENCE(percept, t))  # 告知知识库它感知到的内容
    action <- ASK(KB, MAKE-ACTION-QUERY(t))  # 询问知识库应该执行什么行动
    TELL(KB, MAKE-ACTION-SENTENCE(action, t))  # 告知知识库它所选择的行动
    t <- t+1
    return action
```

## 7、知识库 Agent 的应用与 SAT 规划

- `tell(KB, α)`：添加知识库断言（$\text{KB} \land \alpha$）；`ask(KB, α)`：$\text{KB} \models \alpha$
- 推理任务：地图定位（给定初始知识库和一系列感知和行动，求位置）；地图建模（给定初始知识库和一系列感知和行动，求地图）；同步的定位和地图建模
- 路径规划：初始位置加入 KB；进行 T 个时间点的 KB 初始化；每一个位置，每一个动作，每个时间点的转移模型；推理机器人能在目标位置。都用到同样的知识库和算法
- 通过命题推理制定规划（高效的 SAT 求解器）；完全可观察的、确定的场景，规划问题可解 iff 存在可满足的模型 —— 模型中表示行动的变量值为 true 的变量

**SAT/PLAN 算法**（用 SAT 规划）：

```text
function SATPLAN(init, transition, goal, T_max) returns solution or failure
    inputs: init, transition, goal, constitute a description of the problem
    T_max is an upper limit for plan length  # 规划步骤上限
    for t = 0 to T_max do
        cnf := TRANSLATE-TO-SAT(init, transition, goal, t)  # 把语句转化为 cnf 形式输入求解器
        model := SAT-SOLVER(cnf)
        if model is not null then
            return EXTRACT-SOLUTION(model)
    return failure
```

小结：命题逻辑中的推理 —— 推理算法 推断 $\alpha \models \beta$（用于构建规则构建目标语句的）；前瞻推理 对限定句 是可靠的、完备的 和线性时间可解的；DPLL 通过递归 dfs 枚举所有可能的模型。

## 8、一阶逻辑

### 命题逻辑的局限性

- 缺少对象和谓词，缺少量词和变量
- 命题内部结构；不想列举所有

### 一阶逻辑的可能世界

- 至少一个对象
- **关系**：相互关联的对象集合，或一个对象的关系
- **函数映射**：对象与对象的关联

### 语法和语义

**项（Term）**：对象的逻辑表达式 —— 常量符号（表示对象）、谓词符号（关系）、函数符号（函数）；函数表示函数，可能世界中给定常量作函数变量，函数的值确定；变量。

**原子语句**：由谓词符号（即关系）以及括号的列表项组成。**复合语句**：由逻辑连接词构成 —— 带有全称量词 $\wedge$ / 存在量词 $\vee$ 的语句；$\neg \forall x P(x) \equiv \exists x \neg P(x)$；$\forall x \exists y P(x)$ 与 $\exists y \forall x P(x)$ 不同。

### 一阶逻辑的模型

用关系图表示：只有一元和二元函数，可用有向图表示。结点代表对象（常量），有向边代表二元谓词，一元谓词作额外的结点标记。

1 **命题化**：一阶逻辑替换为命题逻辑，用基项置换变量，把原子语句换成符号。半可判定的：算法能证明蕴含成立的语句，不能否定蕴含不成立的语句。

$$
\left\{
\begin{aligned}
\forall x\ P(x) &\iff (x_1 \Rightarrow P(x_1)) \wedge (x_2 \Rightarrow P(x_2)) \wedge \cdots \\
\exists x\ P(x) &\iff (x_1 \Rightarrow P(x_1)) \vee (x_2 \Rightarrow P(x_2)) \vee \cdots
\end{aligned}
\right.
$$

顺序重要，可以通过否定词转化。
