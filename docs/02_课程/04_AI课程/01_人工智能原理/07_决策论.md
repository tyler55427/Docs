# 七、决策论

## 1、决策论基础

不仅需要概率分布，还要知道行动的效用，来作出合理的决策。理性的决策：结合概率论+效用论 -> 决策。

对当前状态的不确定性、对动作结果的不确定性、变量（条件）（关注：动作 a，到达结果 s 的概率分布）。到达 $s'$：$P(\text{result}(a)=s') = \sum_s P(s) P(s'|s, a)$。

**动作期望效用**：$\text{EU}(a) = \sum_{s'} P(\text{result}(a)=s') V(s')$。需要世界模型、科学家/规划 -> 对世界状态的预测。

$$a^* = \arg\max_a \sum_s P(s|a) V(s)$$

最大期望效用 $a^* = \arg\max_a \text{EU}(a)$。理性的决策：理性的 agent 在给定知识库下，选择最大化其期望效用的行为。

minmax 终止状态下的数字无关紧要，只希望更好的状态有更高的评价（正向排序）；最有决策在单调变换下是不变的；expectimax 需要有幅度的状态值才有意义（存在较大差异）。

**效用**：效用是把结果（世界状态）对应到 agent 的偏好的实数的函数。定理：任何理性的偏好都可以概括为效用函数（效用函数总结了 agent 的目标）。效用：定义了效用，agent 的理性行动随之决定（偏好 A 优于 B：$A > B$；偏好：一个 agent 有一些偏好，表示偏好相同：$A \sim B$）。理性的偏好：对偏好增加限制，如传递性公理 $(A > B) \land (B > C) \Rightarrow (A > C)$。具有不可传递偏好，可能会输掉。不让 agent 自己定义效用，产生不一致的目标；不预先定义行动力，环境是复杂的。

## 2、理性偏好的约束

**彩票**：每动作的结果集合，每个动作是一张彩票。对彩票 $L = [p_1, s_1; \cdots; p_n, s_n]$（每个结果可以是原子状态，也可以是另一张彩票）。

**理性偏好的约束**：（有序性、传递性、连续性、可替换性、单调性、可分解性）

- **有序性**：$A \succ B$、$B \succ A$、$A \sim B$ 有且仅有一个成立
- **传递性**：$(A \succ B) \land (B \succ C) \Rightarrow (A \succ C)$
- **连续性**：$A \succ B \succ C \Rightarrow \exists p [p, A; 1-p, C] \sim B$，有概率 $p$ 使偏好相同
- **可替换性**：$A \sim B \Rightarrow [p, A; 1-p, C] \sim [p, B; 1-p, C]$
- **单调性**：$A \succ B \Rightarrow (p > q \Leftrightarrow [p, A; 1-p, B] \succ [q, A; 1-q, B])$。将复合化为简单（「无赌博悖论」，将两个连续化为一个等价）：$$[p, A; 1-p, [q, B; 1-q, C]] \sim [p, A; (1-p)q, B; (1-p)(1-q), C]$$
- **可分解性**：见上式

**定理**：理性的偏好的行动决策可以用期望效用最大化来描述。上述效用理论的公理，无论违反哪一条，都有非理性的偏好。

偏好导致效用的数值差异（不唯一）。给定满足这些约束的任何偏好，存在一个实值函数 $U$ 使得：$U(A) \ge U(B) \Leftrightarrow A \succ B$。

**彩票的期望效用**：$$U([p_1, s_1; \cdots; p_n, s_n]) = p_1 U(s_1) + \cdots + p_n U(s_n)$$

- 对状态进行偏好排序其数值不重要，称为**价值函数/序数效用函数**
- 效用函数的正仿射变换，agent 的最优行为不会改变：$U'(s) = a U(s) + b \quad (a > 0)$，即状态对应的效用。（期待效用最大化即理性）
- 遵守上述公理是效用函数的全部内容

## 3、金钱的效用

金钱不表现为一个效用函数（不同人对相同钱看法不同）（一般为对数函数）。对 $L = [p, X; 1-p, Y]$：

期望货币价值 $\text{EMV}(L) = pX + (1-p)Y$（以钱的价值作为效用）（将彩票期望视为确定的 $(\text{EMV}(X) = X)$）。

其他效用：$$U(L) = pU(X) + (1-p)U(Y)，\text{通常 } U(L) < U(\text{EMV}(L)) \quad \text{（风险厌恶）}$$

- 风险厌恶：曲线呈凹形（$\cap$）
- 风险追求：曲线呈凸形（$\cup$）
- 风险中性：接近线性

确定性等价：$\text{CE}(L) \sim L$（不以彩票的期望购买彩票）。保险费：$\text{EMV}(L) - \text{CE}(L) > 0$（宁愿损失的钱）（风险厌恶意味着保险费是正的）。

后决策失望：无法知道精确的效用，只能估计，倾向乐观估计，使结果未达到乐观估计。几种效应：确定性效应（更喜欢确定性的收益）；表达效应（框架效应）（喜欢乐观的表述）；锚效应（使用相对效用评价，不使用决定的评价）。

## 4、决策网络（影响图）

关于 agent 当前状态信息、可能动作、agent 动作后的状态、状态的效用。

- **机会节点（圆形）**：随机变量，关联相应事件树
- **决策节点（矩形）**：可选择动作的点（没有父节点，有算法给定的固定值）（目前考虑单个决策节点）
- **效用节点（菱形）**：agent 的效用函数（依赖于动作、机会节点）（给定变量值，效用节点的值完全确定）

与 $S'$：当前节点到下一节点；与 $a$：效用节点直接连接当前状态节点和决策节点（简化）（Q-Learning）。

简化形式：省去动作的结果状态的机制节点，效用节点与每个动作相关联的期望效用，而非输出状态的效用。是否仍成立？前提是结果状态，现在有结果不确定应与一动作效用函数（Q 函数）相连；因为结果状态永远不会设置为证据变量，所以可作上述简化。

**评估决策网络（影响图）**：对决策节点的各种可能设置动作，行为应与作为证据变量的机会节点一致。算法：(1) 为当前状态设置证据变量 e；(2) 对决策节点的每个可能值 $\alpha$ —— 将决策节点设为该值 $\alpha$，用概率推断算法计算效用节点的父节点的后验概率 $P(w|e,\alpha)$，计算动作的结果效用 $\sum_w P(w|e,\alpha) U(\alpha,w) = EU(\alpha|e)$；(3) 返回最高效用的动作。（用贝叶斯网络计算 $P(\text{result}(\alpha)=w|e)$）

## 5、信息价值（VPI）

上述是在智能体决策前给定证据（信息），但实践中不可能。有了信息，动作将会改变。一个特定信息的价值定义为：获得信息前后，最佳动作的期望之差。

计算待取值的信息的价值：可直接从决策网络中计算。

**完美信息**：$EU(\alpha_e|e_j) = \max_{\alpha} \sum_{s'} P(\text{result}(\alpha)=s'|e_j)U(s')$（获得精确的 $E_i=e_j$）。

$$VPI(E_j) = (\sum_{e_j} P(E_j=e_j) EU(\alpha_e|E_j=e_j)) - EU(\alpha)$$

$$VPS(E'|e) = [\sum_{e'} P(e'|e) \max_{\alpha} EU(a|e, e')] - \max_{\alpha} EU(a|e)$$

已有证据 $E=e$，$\text{MEU}(e) = \max_{\alpha} \sum_{s} P(s|e)U(s, a)$。新加证据 $E'=e'$，$\text{MEU}(e, e') = \max_{\alpha} \sum_{s} P(s|e, e')U(s, a)$。但不知道 $e'$，则可预测：$\text{MEU}(e, E') = \sum_{e'} P(e'|e) \text{MEU}(e, e')$。信息的价值：只有 $E'$ 行动，跟原来比，$\text{MEU}$ 上升多少：$VPS(E'|e) = \text{MEU}(e, E') - \text{MEU}(e)$。

### 完美信息的性质

$$
\begin{cases}
\text{信息的期望价值是正的, } \forall j \ \text{VPI}(E_j) \ge 0 & (\text{若为负, 可以放弃信息}) \\
\text{是不可累加的: } \text{VPI}(E_i, E_j | e) \neq \text{VPI}(E_i | e) + \text{VPI}(E_j | e) & (\text{证据之间相互约束}) \\
\text{独立于次序的: } \text{VPI}(E_i, E_j | e) = \text{VPI}(E_i | e) + \text{VPI}(E_j | E_i, e) & (\text{VPI}(A, B) - \text{VPI}(B) = \text{VPI}(A | B)) \\
\quad = \text{VPI}(E_j | e) + \text{VPI}(E_i | E_j, e) & (\text{与先后顺序无关}) \\
(\text{给定的 } e \text{ 相同, 可为空})
\end{cases}
$$

### 不完美信息

信息不一定是真的。信息价值不等式：$P(\text{parents}(U) | z) = P(\text{parents}(U))$（根据节点与效用节点的独立性）。

1. 如果 $z$ 独立于 $\text{parents}(U)$ 给定 $e_i$，$\text{VPI}(z | e_i) = 0$
2. $\text{VPI}(A, S) > \text{VPI}(A) + \text{VPI}(S) \Leftrightarrow \text{VPI}(S | A) > \text{VPI}(S) \Leftrightarrow \text{VPI}(A | S) > \text{VPI}(A)$
3. $\text{VPI}(A | S) \ge \text{VPI}(A)$（除非 $S$ 是 $\text{parents}(U)$，只要有等号成立）—— 知道 $S$ 获得 $A$ 不应该比 $A$ 差
4. 直接知道 $\text{parents}(U)$ 的 $\text{VPI}$ 最大（$R = \text{parents}(U)$）：$\text{VPI}(R | Q) \le \text{VPI}(R) \Leftrightarrow \text{VPI}(Q | R) \le \text{VPI}(Q)$，两者相等
