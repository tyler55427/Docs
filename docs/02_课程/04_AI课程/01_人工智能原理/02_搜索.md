# 二、搜索

## 1、搜索问题形式化

- **状态空间**：$S$
- **初始状态**：$s_0$
- **动作空间**：$A(s)$
- **转移模型**：$\text{Result}(s, a)$
- **目标状态**：$G(s)$
- **代价函数**：$c(s, a, s')$
- **解**：初始状态到目标状态的一组动作序列
- **最优解**：解的路径代价的最小值
- 开环不找到解忽略环境感知；闭环环境不确定，与环境感知
- 问题形式化为一个模型
- **边界**：所有扩展的但未到达的节点集（队列里的）
- **已达状态**：已经生成过节点的状态

## 2、最佳优先搜索

使评价函数 $f(n)$ 最小。

```text
function BEST-FIRST-SEARCH(problem, f) returns 一个解节点或 failure
    node := NODE(State=problem.INITIAL)
    frontier := 一个以 f 排序的优先队列，其中一个元素为 node -> 初始化
    reached := 一个查找表，其中一个条目的键为 problem.INITIAL，值为 node
    while not IS-EMPTY(frontier) do
        node := Pop(frontier)
        if problem.IS-GOAL(node.STATE) then return node -> 先目标检测 (后期目标检测)(扩展节点)
        for each child in EXPAND(problem, node) do
            s := child.STATE
            if s 不在 reached 中 或 child.PATH-COST < reached[s].PATH-COST then
                reached[s] := child
                将 child 添加到 frontier 中 -> 边界地 reached 表中 (生成节点)
    return failure

function EXPAND(problem, node) yields 节点
    s := node.STATE
    for each action in problem.ACTIONS(s) do
        s' := problem.RESULT(s, action)
        cost := node.PATH-COST + problem.ACTION-COST(s, action, s')
        yield NODE(State=s', PARENT=node, ACTION=action, PATH-COST=cost)
```

## 3、搜索数据结构与树/图搜索

- 元组：$(s, a, s', r)$
- **搜索树**：节点状态、父节点、父节点动作、初始状态到此节点的路径代价
- **边界结构**：FIFO 队列、LIFO 队列
- **已访问状态**：查找表（哈希表）

带策略树搜索：

```text
function TREE-SEARCH(problem, strategy) returns a solution, or failure
    initialize the search tree using the initial state of problem
    loop do
        if there are no candidates for expansion then return failure
        choose a leaf node for expansion according to strategy
        if the node contains a goal state then return the corresponding solution
        else expand the node and add the resulting nodes to the search tree
    end
```

- 选择策略、应对重复、数据结构
- 定义结构，为了总结路径、动作、路径代价，以选择未来最优动作

**状态空间图与搜索树**：

- **状态空间图**：节点是世界的状态、箭头代表状态转移、目标测试是目标节点集（图搜索）
- **搜索树**：计划及其结果、起始状态为根、子节点对应后继状态（树搜索）
- 状态空间图中每个状态只出现一次，而搜索树可重复出现（每个节点是状态到一条路径）
- 环导致搜索树是无穷的（重复历史）
- 图搜索是树搜索 + 节点是否被拓展过的标记集（设置最大深度），不让同一状态多次访问

**搜索算法的性质（问题评价）**：

- **完备性**：找到解，证明无解。到达每个状态
- **最优性**：最优
- **时空复杂性**
- 完备：系统的、能达到与初始状态相关的所有状态

**树搜索与图搜索**：

- **树搜索**：允许访问重复节点，节省存储空间
- **图搜索**：不允许访问重复节点，不会陷入死循环
- 粗斜体：应对重复状态的操作
- **frontier（边缘）**：所有待扩展的节点
- 下-状态选择：重复状态、数据结构。总路径、动作、代价，选择最优

```text
function TREE-SEARCH(problem) returns a solution, or failure
    initialize the frontier using the initial state of problem
    loop do
        if the frontier is empty then return failure
        choose a leaf node and remove it from the frontier
        if the node contains a goal state then return the corresponding solution
        expand the chosen node, adding the resulting nodes to the frontier

function GRAPH-SEARCH(problem) returns a solution, or failure
    initialize the explored set to be empty
    initialize the frontier using the initial state of problem
    loop do
        if the frontier is empty then return failure
        choose a leaf node and remove it from the frontier
        if the node contains a goal state then return the corresponding solution
        add the node to the explored set
        for each resulting child node do
            only if not in the frontier or explored set
```

## 4、无信息搜索策略

记法：$m$ 路径最大长度（或最大深度），$d$ 目标节点（最浅）深度，$b$ 分支因子，$C^*$ 最优解代价，$\varepsilon$ 每个动作最少代价。

### 1、 BFS（宽度优先搜索）

- **时间**：$b^d$
- **空间**：$b^d$
- **完备**：存在即有完备性
- **最优**：代价相同（双向搜索：$2b^{d/2}$）
- **特点**：打开深度最浅节点、代时间最短、内存占用大、找行动次数最少

```text
function BREADTH-FIRST-SEARCH(problem) returns a solution, or failure
    node := a node with STATE = problem.INITIAL-STATE, PATH-COST = 0
    if problem.GOAL-TEST(node.STATE) then return SOLUTION(node)       # 目标测试
    frontier := a FIFO queue with node as the only element             # 边缘节点集，队列
    explored := an empty set
    loop do
        if EMPTY?(frontier) then return failure
        node := POP(frontier)    /* chooses the shallowest node in frontier */  # 先进先出
        add node.STATE to explored
        for each action in problem.ACTIONS(node.STATE) do
            child := CHILD-NODE(problem, node, action)                      # 子节点
            if child.STATE is not in explored or frontier then             # 是否已经被扩展
                if problem.GOAL-TEST(child.STATE) then return SOLUTION(child)  # 目标测试
                frontier := INSERT(child, frontier)                         # 更新边缘节点集（下一层的节点了，放队列最后）
```

- 多指针：可以早期目标检测，在出界时就进行目标检测

### 2、 DFS（深度优先搜索）

- **时间**：$b^m$（$m$ 有限时）
- **空间**：$bm$（变量回溯栈，$O(m)$）
- **特点**：打开边缘节点中最深的；有限、无完备，非最优；但可能多次经过同一状态

### 3、 迭代加深 IDS

- $b^l$，$bd$ 有限、无环完备，最优（基于深度受限）
- 1、2的结合，虽重复搜索，但影响大的在底层，使最终不大（可以超过）
- 限定深度下的 DFS；空间是搜索问题更重要的（实际问题规模大），时间可并行加速，时间都是指数级的

### 4、 一致代价 UCS

- $b^{\frac{C^*}{\epsilon}}$，非负则完备，最优
- 打擦边球中前进的；1的变体，搜索过程类似等值线，但各方向探索，无目标信息，引出 $A^*$
- 问题：搜索类似递增的代价等值线，在每个方向做了太多的探索

```text
function UNIFORM-COST-SEARCH(problem) returns a solution, or failure
    node := a node with STATE = problem.INITIAL-STATE, PATH-COST = 0
    frontier := a priority queue ordered by PATH-COST, with node as the element  # 以路径代价排序的优先级队列
    explored := an empty set  # 已探索节点集
    loop do
        if EMPTY?(frontier) then return failure
        node := POP(frontier) /* chooses the lowest-cost node in frontier */ # 取代价最低的子节点
        if problem.GOAL-TEST(node.STATE) then return SOLUTION(node)  # 目标测试
        add node.STATE to explored
        for each action in problem.ACTIONS(node.STATE) do
            child := CHILD-NODE(problem, node, action)
            if child.STATE is not in explored or frontier then  # 是否已经被扩展或已在边缘节点集
                frontier := INSERT(child, frontier)  # 不是，则把子节点加入到优先级队列中
            else if child.STATE is in frontier with higher PATH-COST then  # 是，则要检查该子节点的代价是否比已在优先级队列中的同一子节点的代价更低
                replace that frontier node with child
```

## 5、搜索算法比较

| 指标       | 广度优先                                                                                    | 一致代价                     | 深度优先   | 深度受限   | 迭代加深   | 双向（如适用） |
| :--------- | :------------------------------------------------------------------------------------------ | :--------------------------- | :--------- | :--------- | :--------- | :------------- |
| 完备性     | 是$^1$   | 是$^2$                     | 否       | 否       | 是$^1$   | 是$^{1,4}$ |                              |            |            |            |                |
| 代价最优   | 是$^3$   | 是                         | 否       | 否       | 是$^3$   | 是$^4$       |                              |            |            |            |                |
| 时间复杂性 | $O(b^l)$                                                                                  | $O(b^{l(1+C^*/\epsilon)})$ | $O(b^m)$ | $O(b^l)$ | $O(b^l)$ | $O(b^{d/2})$ |
| 空间复杂性 | $O(b^l)$                                                                                  | $O(b^{l(1+C^*/\epsilon)})$ | $O(bm)$  | $O(bl)$  | $O(bl)$  | $O(b^{d/2})$ |

注：$^1$ 如果 $b$ 是有限的且状态空间要么有解要么有限，则算法是完备的。$^2$ 如果所有动作的代价都 $\ge \epsilon > 0$，算法是完备的。$^3$ 如果动作代价都相同，算法是代价最优的。$^4$ 如果两个方向均使用广度优先搜索或一致代价搜索。

## 6、有信息（启发式）搜索策略

使用 UCS 在各方向「均匀」探索，复杂度大；使用问题本身的定义之外的特定知识。一般算法称为最佳优先搜索：使 $f(n)$ 值最小。

- $g(n)$：初始到 $n$ 的代价
- **评价函数** $f(n) = g(n) + h(n)$（经过节点 $n$ 的路径代价函数）（无信息 $f(n) = g(n)$）
- 后续节点中 $f(n)$ 最小的扩展（经验结论/辅助信息）
- **启发函数** $h(n)$ 为到目标的估计代价

### 1、 贪心算法

$f(n) = h(n)$，只利用启发函数，使用距离函数的处理方式，完备（有限图搜索），非最优。

### 2、 $A^*$ 搜索

$f(n) = g(n) + h(n)$（最小代价解的估计代价）。完备的，$h(n)$ 估计不好，非最优。

- close（$g(n)$ 确定、已拓展）、open（$g(n)$ 待定、未拓展）
- 已拓展（队列栈）、边界（队列栈）

## 7、可容许与一致性启发式

1. **可容许/采纳的（admissible）**：$0 \le h(n) \le h^*(n)$，$h^*(n)$ 为最小真实代价。

- 推论：最优解及其祖先都比次优解先扩展（$f(n) < c^*$：必然扩展节点）
- $A^*$ 的关键是：找到可采纳启发式 $h(n)$
- **松驰问题**：在宽松的条件下计算 $h(n)$
- 移除约束好处：封闭形式的解、更方便的搜索、独立的子问题；若子独立，可取 $\max(h_1(n), h_2(n))$
- **占优**：$\forall n$，$h_1(n) \ge h_2(n)$ 且均为可采纳的，比 $h$ 选择更好（$h$ 更接近真实代价）

2. **一致性**：$n$ 通过行动到 $n'$ 的启发之差，不能大于 $n$ 到 $n'$ 的单步代价（为图搜索）。

- 节点 $n$ 到节点 $n'$：$h(n) \le h(n') + \text{cost}(n, n')$ 即 $h(n) - h(n') \le \text{cost}(n, n')$
- 推论：沿任何路径的 $f(n)$ 是非递减的
- $A^*$ 扩展到 $n$ 时，找到 $n$ 的最优路径（可以期望目标检测）
- 一致 $\Rightarrow$ 可容许（一般，大多数可采纳的启发式是一致的，特别是来自松马尔问题的启发式）

实现：树搜索 + 扩展过的节点集（closed set）。扩展每个节点前，检查是否扩展过：有则已见过，无则加入 closed set。

## 8、$A^*$ 总结与变体

- 树搜索，$h(n)$ 可容许的，最优：不检查冗余路径
- 图搜索，$h(n)$ 一致的，最优的：检查冗余路径 -> 记忆历史状态有序，不用担心父指针，减少循环（不搜索冗余路径）
- UCS 是 $h(n)=0$ 特例
- 设计启发式：关键建：松弛条件（去除一些限制）
- 都是模拟搜索，没有在真实环境行动；$A^*$ 高效，因为剪枝（pruning），排除无帮助节点，完备、代价最优、效率最优
- **满意搜索**：不可采纳 / 加权 $A^*$，权重大拓展节点少，次优节省时间空间的解
- **有界代价搜索**：代价 $= w \cdot C^*$；有界代价搜索：代价 $< C$；无界代价搜索：快速
- **内存受限搜索**：IDA*、RBFS、SMA*
- 搜索在世界模型上运行：并没有尝试所有计划；规划是「模拟」的（执行闭环？）；效果取决于模型

## 9、局部搜索与最优化

要找的状态是离散状态，使用启发式评估。

- **优化问题**：不关心路径，只关注最终的目标（不记录路径、已访状态，不是系统的）（内存少，无限空间）
- **状态空间**：完整配置布局集合
- **目标**：找到满足限制的配置布局 / 找到最优的配置
- 「迭代提升」思想：以现在状态为基准，尝试提升它。从单个节点出发，移动到邻近状态，不保留搜索路径，使用很少内存。在系统化算法不适用的很大 / 连续空间中找到合理解

### 1、 爬山法

任何节点开始，重复移动到最佳邻接节点，直到没有（贪心局部搜索）。

```text
function HILL-CLIMBING(problem) returns a state
    current := make-node(problem.initial-state)
    loop do # 重复
        neighbor := a highest-valued successor of current # 找当前节点最佳邻接
        if neighbor.value ≤ current.value then
            # 如该邻接点还比不上当前节点，退出
            return current.state
        current := neighbor # 如该邻接点更好，用该点替换当前节点
```

- $f(n) = -h(n)$（因为最大化）
- n-皇后：目标：n 个皇后无冲突，状态：n 皇后有值一列，$h(n)$：相互攻击的皇后对数量
- 全局极大值—爬山，全局极小值—梯度下降；状态空间；地形图；山峰：一寻到局部极大值；平台区：平坦的区域

**简单优化**：

- **横向移动**：平台行进（有限次数防止死循环）
- **随机爬山**：随变好未排序的概率选择
- **随机重启（完备）**：随机初始状态，进行一系列爬山
- n-皇后：禁止横向移动；成功概率 $0.14$，平均移动 $4$，平均 $3$ 次重启次数；随机重启预升：$\frac{1}{p} (4p + 3(1-p))$
- 变体：随机爬山法（上坡依梯度概率选择）、首选爬山法（第一个比当前好的解）

### 2、 模拟退火

结合爬山和随机游走，允许概率选「不好」；允许晃动（摇出局部极点）、某种策略降温。概率随评价函数指数下降，随温度降低而减小。结论：温度指数级地慢地下降，以概率逼近找到全局最优解（初始温度高，对数降温，每温度迭代 $w$）。

```text
function SIMULATED-ANNEALING(problem, schedule) returns a state
    current <- problem.initial-state
    for t = 1 to ∞ do
        T <- schedule(t)  # 根据一个时间函数设定「温度」
        if T = 0 then return current
        next <- a randomly selected successor of current  # 随机选取一个邻接节点
        ΔE <- next.value - current.value  # 计算梯度
        if ΔE > 0 then current <- next  # 如梯度上升（情况改善），接受该移动
        else current <- next only with probability e^(ΔE/T)  # 否则，也一定概率接受该移动
```

### 3、 局部束搜索

当前 $k$ 个状态的最佳 $k$ 个后继；初始化 $k$ 个随机状态；与并行 $k$ 随机重启算法区别：不是独立的。

### 4、 遗传算法

根据适应度函数评估值，取样 $k$ 个个体（可以相同）；随机配对杂交，小概率变异。混合数 $p$，形成后代参与的亲本的数量，通常为 2；从适应度函数归一化概率以选择，以随机杂交点重组；或直接选择 top 的 $p$ 个。

**局部搜索解题思想**：描述问题 -> 成本函数 -> 优化算法；转化成寻找解 $(x_1, x_2, x_3)$ 的问题，并确定变量取值的定义域，定义成本函数 costf，考查问题中影响成本的、可度量的变量。

## 10、连续空间中的局部搜索

上述算法是离散的问题。方法：1 空间离散化；2 随机后退，随机长度随机后退，模拟退火；3 梯度下降、凸函数梯度重点。解是局部的，如果凸函数，全局的。
