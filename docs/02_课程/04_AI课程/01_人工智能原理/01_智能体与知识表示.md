# 一、智能体与知识表示

## 1、知识表示

- **原子表示**：世界每个状态没有内部结构
- **因子化表示**：每个状态拆分为固定的变量/属性
- **结构化表示**

## 2、理性智能体

- 本课程目标：设计理性智能体
- **理性智能体**：选择最大化（预期）效用的行动
- **智能体**：传感器感知环境，并通过执行器作用于环境
- **感知序列**：感知到的历史
- **智能体函数**：感知序列映射到动作
- **良好行为**：给定感知序列提供的证据和智能体所有的先验知识，理性智能体应选择一个期望最大化性能度量的动作
- **性能度量**：评估环境状态的给定序列，定义成功的标准

## 3、任务环境的四要素（PEAS）

- **性能度量**
- **先验知识**
- **执行器**
- **传感器**

## 4、环境属性与智能体设计维度

| 属性 | 说明 |
| :--- | :--- |
| 完全/部分可观测 | 每个时间点访问环境的完整状态（记法模糊） |
| 单/多智能体 | 随机行为 |
| （非）确定性 | 下一步状态完全由当前状态和动作决定（准备意外） |
| 回合式/序贯 | 回合式的下一回不依赖之前的动作 |
| 静态/动态 | 正在发生改变（快速决策） |
| 离散/连续 | 控制 |
| 已知/未知 | 行动的结果/概率是确定的（探索） |

## 5、智能体分类

- **简单反射型**：当前感知选择动作
- **基于模型的反射型**：依赖感知历史的内部状态
- **基于目标的**：考虑未来的环境
- **基于效用的**：考虑未来的收益

## 6、三维分类图（智能体设计空间）

- **红轴（垂直向上）**：未知的 unknown
- **绿轴（水平向右）**：已知的 known -> 确定的 deterministic -> 随机的 stochastic
- **蓝轴（向左下方延伸）**：原子 atomic -> 要素化 factored -> 结构化 structured

节点/方法分布：

- **Supervised Learning & Reinforcement Learning**：位于上方，连接确定的、随机的、未知的区域
- **SEARCH**：位于「原子 atomic」与「确定的 deterministic」交界处
- **MDPs**：位于「原子 atomic」与「随机的 stochastic」交界处
- **LOGIC**：位于「要素化 factored」与「确定的 deterministic」交界处
- **Bayes nets**：位于「要素化 factored」与「随机的 stochastic」交界处
- **First-order logic**：位于「结构化 structured」区域，用虚线圈起
