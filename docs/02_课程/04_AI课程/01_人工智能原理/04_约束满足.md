# 四、约束满足

## 1、定义约束满足问题（建模）

**CSP 处理变量赋值问题。**

- 一致/合法赋值：不违反任何约束
- 完整赋值：每个变量都被赋值
- 部分赋值：某些变量未被赋值
- 部分解：一致的部分赋值

**CSP（因子化）**：搜索问题的特殊子集；状态由变量 $X_i$ 定义，值来自于 $D_i$；目标测试是一组约束，指定变量子集的值的允许组合 $C(\langle scope, rel \rangle)$。允许使用比标准搜索算法更强大的有用的通用算法（搜索问题有帮助，慢）。NP 完全问题，所以启发式没有改变时间复杂度。

### Binary CSP：每个约束（至多）涉及两个变量

- **二元约束图**：节点为变量，圆弧表示约束（可以非相邻、可以非所有）；右侧注释：引入尽可能多的辅助变量，可转化为二元约束
- **全局约束**：含任意数变量的约束（AllDiff，涉及变量有不同的值）

### 偏好约束

首选但其他也有效，叫约束优化问题。形式化为 CSP：变量集合 $X_i$；值域集合 $D_i$；变量赋值的约束 $C$：$C_i = \langle scope, rel \rangle$。

问题的解：变量的赋值，使 C 得到满足。为每种赋值方法 $x$ 有一个得分（weight），$f_i(x) = 1 \equiv C_i$ 得到满足，$\text{weight}(x) = \prod f_i(x)$，目标 $\operatorname{argmax} \text{ weight}(x)$（这里只有 1）。

原子搜索只能拓展节点，CSP 可以选择变量赋值，也可以执行约束传播。

## 2、约束传播与弧一致性

**约束传播的核心思想**：局部一致性。

- **节点一致性**：单变量满足一元约束，$x_i$ 相对于 $x_i$ 弧一致
- **弧一致性**：单变量的所有值满足二元约束（对 $(X_i, X_j)$，$D_j$ 中所有值有 $D_i$ 中一个满足）
- **AC-3 算法**：维护弧队列，每个二元约束有两条弧（两个方向）

初始化所有二元约束的两条弧到队列：若 $(X_i, X_j)$ 满足弧一致，则处理下一条弧；若 $D_j$ 改变，会影响向 $D_k$ 增加的所有 $(D_k, D_i)$ 到队列。

```text
function AC-3(csp) returns false (如果发现不一致) 或 true (其他情况)
    queue := 一个弧的队列，初始化时包含 csp 中的所有弧
    while queue 不空 do
        (X_i, X_j) := Pop(queue)
        if Revise(csp, X_i, X_j) then
            if D_i 的规模 = 0 then return false
            for each X_k in X_i.NEIGHBORS - {X_j} do
                将 (X_k, X_i) 添加到 queue 中
    return true

function Revise(csp, X_i, X_j) returns true 当且仅当我们修改 X_i 的域
    revised := false
    for each x in D_i do
        if D_j 中不存在使 (x, y) 满足 (X_i, X_j) 约束的值 then
            将 x 从 D_i 中删除
            revised := true
    return revised
```

叶变量，新变量 $d$ 次，$cf$ 约束，新变量 $d$ 次，弧一致性检查 $O(cd)$，最多（值域最坏化 $d$ 次）$\therefore O(cd^3)$。

## 3、CSP 回溯搜索（朴素）

搜索树规模：$n! \cdot d^n$ 个叶节点，即只有 $d^n$ 个完整赋值。利用不同变量之间赋值顺序不影响性（可交换性），则只有 $d^n$ 叶节点。

**解决 CSP 的基本的无信息算法**：即 DFS + 可按任意顺序（可优化）一次赋值一个变量，边走边检查约束。其中：变量赋值顺序值可交换顺序（每次只对单个变量赋值，可交换性）；只考虑不冲突的值；否则回溯到前一变量重新赋值；可能要计算检查约束（「增量目标测试」）。

优化点：

- **选择变量顺序 1**
- **选择值顺序 2**
- **尽早发现失败 3**
- **更好利用问题的结构 4**

## 4、启发式优化

1 **取变量顺序**：最少剩余值（MRV）启发式（「最受约束变量」/「失败优先」），minimum remaining value，选择「合法」取值最少的变量（开始用度启发式）

2 **赋值顺序**：最少约束值（LCV），least constraining value（「失败延后」），选择使邻居变量留下更多的选择的值（可能要一定的计算）（成功优先）

3 **推断**：前向检验（失败优先）；为某个变量赋值时，有机会检查邻居变量的值域空间；过程：跟踪未分配变量的域并删除其不满足约束的值；前向检验：对每个通过约束与 X 相关的未赋值 Y，删除 Y 中与 X 不相容的值 (Y, X)；AC-3 在变量前减少变量的域

- 约束传播：从约束到约束的推理（维护弧相容）
- MAC：弧相容：CSP 中某变量的所有取值满足该变量的二元约束；带弧相容的前向检验：前向检验至满足弧相容（MAC: make AC）；如果改变 X 的值域，需将与 X 相邻的 Y 重新检查弧相容；当有 X 为空时，检测到失败，回溯；比简单的前向检验更早检测到失败；在赋值前/后运行

## 5、AC-3 与问题结构

- 直接跑这个 AC-3 就可以求解了？没有，弧相容不能保证每个变量都有一个赋值了
- 边数 $c$，选项 $d$，$cd^2$ 移除 $d^2$，$O(cd^3)$；AC-3：repeatedly enforce arc consistency on all variables
- 使每个变量都是弧相容的；运行了这个算法后，要么每个变量都是弧相容的，要么有变量的值域为空（该 CSP 无解）
- **局限**：弧相容后 —— 唯一解 / 多解 / 无解；弧相容检查仍需在回溯搜索中运行
- 拓展：k-一致性：k 个节点满足一致性（k=2，弧一致性）
- **智能回溯**：时序回溯（重新访问时间最近的决策点）；更好：基于失败的根源回溯（退回到可能解决这个问题的变量）；要跟踪与改变了的某些赋值冲突的一组赋值
- 4 **问题的结构**：快速找到解；独立的子问题：减少总的工作量；独立性定义：集合 A、B 之间没有边，$A \perp B$（通常分量独立性）

## 6、树状结构 CSP

树状结构约束图：任两个变量之间最多一条路径连通（$O(nd^d)$ 求解）。转成拓扑排序，$O(n)$ 步把图改成 DAC，沿树结构前进（无需回溯）。

**定向弧一致性（DAC）**：变量顺序 $X_1, \cdots, X_n$ 为 DAC，iff $j < i$，$X_j$ 对 $X_i$ 是弧一致的。

```text
function TREE-CSP-Solver(csp) 返回一个解或 failure
    inputs: csp, 共有 X, D, C
    assign := ∅ 一个空的赋值
    root := 任意一个变量
    X := TREE-ORDERING-SORT(root)
    for i = n downto 1 do
        MAKE-ARC-CONSISTENT(Parent(X_i), X_i)
        if 不能取得一致 then return failure
    for i = 1 to n do
        assign[X_i] := D_i 中任意一个数的值
        if 没有一个值 then return failure
    return assign
```

- 1 部分变量赋值，剩下变量成树（删除节点）；实例化一个变量，修剪其邻居的域（精炼）；cutset（割集）：实例化一组变量，使剩余是树
- 2 约束图的树分解（合并节点）；原问题每个变量至少在一个子问题中出现；两变量在原问题有约束相连，需同时出现在同一子问题中；一个变量出现在两个子问题，它必须出现在连接这两个子问题路径的所有子问题里

## 7、CSP 的局部搜索

每个状态为所有变量赋值，搜索一次改变一个变量的值。

```text
function MIN-CONFLICTS(csp, max_steps) returns 一个解或 failure
    inputs: csp, 约束满足问题
            max_steps, 放弃前允许的步数
    current := csp 的一个初始完整赋值
    for i = 1 to max_steps do
        if current 是 csp 的一个解 then return current
        var := 从 csp.VARIABLES 中随机选取的冲突变量
        value := 对于 var 使 CONFLICTS(csp, var, v, current) 取得最小值的 v 值
        在 current 中设置 var = value
    return failure
```
