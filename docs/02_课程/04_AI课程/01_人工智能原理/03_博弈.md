# 三、博弈

## 1、博弈论

- 确定的、完整信息的、2Agent、回合制的、零和游戏（效用函数相反，一个最大化，另一个最小化）
- 找到策略：根据每个可能行动推测应采取的行动
- 非零和博弈：个人理性导致集体的非理性（关税、补课、价格战）
- 多次博弈：以牙还牙；利益共同体：集体利益

**游戏形式化（其中一种）**：

- **状态**：$s$
- **玩家**：$\text{Player}(s)$ 此时该谁行动
- **行动**：$\text{Actions}(s)$ 该状态下的合法移动集合
- **转移模型**：$\text{Result}(s, a)$，$S \times A \rightarrow S$
- **目标/终止测试**：$\text{Terminal-Test}(s)$，$S \rightarrow \{\text{true}, \text{false}\}$
- **效用函数**：$\text{Utility}(s, p)$ 游戏者 $p$ 在状态 $s$ 下的数值

- 一个玩家的解为一个策略（policy）：$S \rightarrow A$

对抗搜索树，每层之间交替最大化/最小化效用函数（极大极小搜索）（与或搜索的推广）。

对状态值 $V(s)$：

$$
\begin{cases}
\text{agent: } V(s) = \max_{s' \in \text{successors}(s)} V(s') \\
\text{故 } V(s') = \min_{s' \in \text{successors}(s)} V(s')
\end{cases}
$$

（终止状态值已知）

```python
def value[state]:
    if the state is a terminal state: return the state's utility
    if the next agent is MAX: return max-value(state)
    if the next agent is MIN: return min-value(state

def max-value[state]:
    initialize v = $-\infty$
    for each successor of state:
        v = max(v, value(successor))
    return v

def min-value[state]:
    initialize v = $+\infty$
    for each successor of state:
        v = min(v, value(successor))
    return v
```

- 最大深度 $m$，分支因子 $b$，时间 $O(b^m)$，空间 $O(bm)$，本质是 DFS

## 2、α-β 剪枝

- $\alpha$：路径上的自己回合的极大值（实时更新）
- $\beta$：路径上的对手回合的极小值

剪枝思路：考虑某对手 MIN 结点 $n$，本来我们得计算其 $\text{MIN-VALUE}$；考虑到如果对手在 $n$ 的上层的任何选择点有更好的选择 $m$，那么在实际的博弈中一个理性的对手就永远不会到达 $n$。在检查 $n$ 的后代的过程中，如果发现 $n$ 目前的极小值（还没检查完所有后代）已经比 $\alpha$ 还要小了，则没必要再继续检查 $n$ 的其它后代了。

- $\alpha$：$\text{MAX's best option on path to root}$
- $\beta$：$\text{MIN's best option on path to root}$

```python
def max-value(state, alpha, beta):
    initialize v = -infinity
    for each successor of state:
        v = max(v, value(successor, alpha, beta))
        if v >= beta:
            return v  # 提前退出 (剪枝)
        # 如果当前子结点的状态值比 alpha 大，更新 alpha
        alpha = max(alpha, v)
    return v

def min-value(state, alpha, beta):
    initialize v = +infinity
    for each successor of state:
        v = min(v, value(successor, alpha, beta))
        if v <= alpha:
            return v
        # 如果当前子结点的状态值比 beta 小，更新 beta
        beta = min(beta, v)
    return v
```

- $[\alpha, \beta]$；剪枝不影响最终结果
- 剪枝量取决于树展开顺序（与评估函数的协同作用）；剪枝效率依赖检查后续的顺序（IDA* 有帮助）
- 「完美排序」，时间 $O(b^{\frac{m}{2}})$

## 4、随机博弈

**Expectimax 搜索**：计算机会结点的期望效用。极大值结点、极小值结点一样，机会结点像极大值结点，但结果不确定，计算机会结点的期望效用。

```python
def value(state):
    if the state is a terminal state: return the state's utility
    if the next agent is MAX: return max-value(state)
    if the next agent is EXP: return exp-value(state)

def max-value(state):
    initialize v = -∞
    for each successor of state:
        v = max(v, value(successor))
    return v

def exp-value(state):
    initialize v = 0
    for each successor of state:
        p = probability(successor)
        v += p * value(successor)
    return v
```

- 当取值范围有限，期望不会更大，可以 $\alpha-\beta$ 剪枝
- **Expectimax 剪枝**：上下界估计；取值范围有上下界，动态维护部分和及剩余节点的概率；剪枝条件：机会节点的期望上界低于父节点的 $\alpha$ 下界；高敏节点的 $\beta$

**引申到 Expectiminimax**：

```python
function decision(s) returns an action
    return the action a in Actions(s) with the highest value(Result(s,a))

function value(s) returns a value
    if Terminal-Test(s) then return Utility(s)
    if Player(s) = MAX then return max_{a in Actions(s)} value(Result(s,a))
    if Player(s) = MIN then return min_{a in Actions(s)} value(Result(s,a))
    if Player(s) = CHANCE then return sum_{a in Actions(s)} Pr(a) * value(Result(s,a))
```

- 深度受限的 Expectimax，估计的真实期望的最大值

## 5、蒙特卡洛树搜索（MCTS）

重要思想：

- **rollouts**：试运行进行评估：从状态 $S$ 玩多次游戏（简单快速策略），到终止状态，统计赢次数
- **选择性搜索**：集中关注有希望赢的结点，不管深度

平均效用为获胜百分比，要选择好的模拟策略、选择策略。rollouts 策略：分配给更有希望节点（rollouts 相近）；分配给更不确定节点（胜利的赌注相近）—— trade-off 权衡子。

$$UCB1 = \frac{U(n)}{N(n)} + c \times \sqrt{\frac{\log N(\text{Parent}(n))}{N(n)}} \quad (\text{权衡的启发式})$$

其中：$n$ 赢次数：$\frac{U(n)}{N(n)}$；$n$ 的次数：$N(n)$。

**UCT**：UCB 在 Tree 上搜索。选择策略：重复至超时 —— 选择移动：用 UCB 向下到达叶节点 $n$ 的路径；扩展和模拟：添加一个新子节点 $c$ 到 $n$，从 $c$ 运行一个 rollout（玩到结束？）；反向传播：更新 $c$ 回到根节点。选择指向 $N$ 最高的子结点的动作（因为启发式，所以 $N$ 越大就胜利越多）。

```text
function Monte-Carlo-Tree-Search(state) returns 一个动作
    tree := Node(state)
    while Is-Time-Remaining() do
        leaf := Select(tree)
        child := Expand(leaf)
        result := Simulate(child)
        Back-Propagate(result, child)
    return Actions(state) 中指向模拟次数最多的节点的移动
```
