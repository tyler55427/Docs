# 十、序贯决策与强化学习

**上半部分：马尔可夫决策过程（MDP）**

## 1、MDP 建模

序列式决策问题（暂时完全可观察的）：效用值依赖一个决策序列（一系列状态和动作 / 一个环境历史）（相同环境的随机性导致不同历史，环境的随机性导致不同历史）。

**马尔可夫决策过程 MDP**：

- 特点：不可观察，不取决于历史
- 组成要素：状态 $S$、行动 $A(S)$、转移模型 $T(s,a,s') / P(s'|s,a)$、回报函数 $R(s,a,s')$ 对每一步；初始状态、终止状态（不一定有）、效用函数

MDPs 是完全可观察的概率规划搜索问题：$\langle s_0 \rangle \rightarrow \langle s_1 \rangle \rightarrow \langle s_2 \rangle \rightarrow \cdots$（伴随动作 $A_0, A_1$，即时回报 $R_0, R_1$ 的状态转移图示）。

**MDPs 的解**：一个策略：为每个状态提供一个动作，$\pi: S \rightarrow A$。**最优策略 $\pi^*$**：$S \rightarrow A$，反映的最大化期望效用。

$$\max_{a \in A(s)} \sum_{s'} P(s'|s,a) [R(s,a,s') + \gamma U(s')]$$

注：$\gamma$ 为贴现率（下一状态上一个时间步的 $U(s')$ 值）。

风险和奖励之间的平衡：取决于非终止状态之间的 $R(s,a,s')$ —— 动作确定：不冒风险；动作不确定：厌恶风险。关于终止状态的回报设定：$R(s,a,s') > 0$ 终止状态；$R(s,a,s') < 0$，$\gamma \uparrow$ 选择近出口；$\gamma$ 大，远出口的奖励 > 近出口的奖励，选择远出口。不确定性使更接近真实世界。

## 2、MDP 要素与效用

不确定性的引入使 MDP 比确定性问题更接近真实世界。MDP 要素包括（迭代求解）：动态规划，递归分解问题。

$$V(s) = \max_{a \in A} T(s,a,s') [R + \gamma V(s')], \quad Q(s,a) = \sum_{s'} T(s,a,s') [R + V(s')], \quad \max_{a'} Q(s,a')$$

相同动作却观察到不同的 $s$（同一策略导致不同的路径的原因）。

考虑时间上的效用。环境历史是：有限期（对某个时间点后不再关注，最优动作取决于剩余时间，非平稳的）；无限期（无时间限制，最优动作取决于当前状态，但可能进入终止状态导致不是无限）。

计算状态序列的效用，采用加权累积奖励，定义效用历史 $U_h([s_i, a_i]) = \sum_{i=0}^{\infty} \gamma^i R(s_i, a_i, s_{i+1})$。$\gamma$ 接近 0，未来奖励无关。折扣因子 $\gamma \in [0,1]$，$\gamma$ 接近 1，愿意长期奖励（$\gamma=1$，纯 0 性奖励）。合理：重视近期；金钱早获得用于投资；对奖励的不确定性；对历史偏好的自然偏好；消除 $\infty$。

比较 $+\infty$ 的状态序列：1 $\gamma$ 有限；2 终止状态能保证达到（安全策略）；3 每时间步的平均奖励。

## 3、贝尔曼方程

**静态度的偏好**：同一状态、不同时间行为相同 -> 使 $V^\pi(s_0)$ 与 $V^\pi(s)$ 相同。则效用：累加回报 $U = \sum r_i$；折扣回报 $U = \sum \gamma^i r_i$（折扣因子 $\gamma \in [0,1]$，看重近期奖励）。给定上下限 $\pm R_{\text{max}}$，则 $\sum \gamma^i r_i$ 的上下限为 $\pm \frac{R_{\text{max}}}{1-\gamma}$。

**定义 MDP**：状态集合 $S$、初始状态 $s_0$、行动集合 $A$、转移模型 $P(s'|s,a) / T(s,a,s')$、回报 $R(s,a,s')$（以及折扣因子 $\gamma$）。策略：每个状态下采取的行动；效用：折扣回报的和。定义了状态效用后，就能得到状态效用与它的相邻状态的效用之间的直接关系（贝尔曼方程）：

$$U(s) = \max_{a \in A(s)} \sum_{s'} P(s'|s,a) [R(s,a,s') + \gamma U(s')]$$

状态效用函数 / Q 函数：给定状态下采取给定动作的期望效用：$U(s) = \max_{a} Q(s,a)$；最优策略 $\pi^*(s) = \arg\max_{a} Q(s,a)$。得到 Q 函数的贝尔曼方程：

$$Q(s,a) = \sum_{s'} P(s'|s,a) [R(s,a,s') + \gamma \max_{a' \in A(s')} Q(s',a')]$$

## 4、奖励规则与求解方法

**奖励规则**：效用的规模任意：仿射变换使最大化决策保持不变。奖励变换类型：$R'(s, a, s') = m R(s, a, s') + b$。加性奖励分解：$R'(s, a, s') = R(s, a, s') + \gamma \phi(s) - \phi(s)$。

**求解 MDP**：四种方法：离线：价值迭代、策略迭代、线性规划；在线近似：蒙特卡洛规划。

累积奖赏：遵循策略 $\pi$ 产生的随机路径的回报总和（由 $s_t$ 决定的状态序列的概率分布）。状态值：期望效用 $E \left[ \sum_{t=0}^{\infty} \gamma^t R(s_t, \pi(s_t), s_{t+1}) \right]$（从 $s$ 执行 $\pi$ 的期望效用）。效用后的状态值：$V^\pi(s_0)$ 的期望效用 $V^\pi(s_0) = E \left[ \sum_{t=0}^{\infty} \gamma^t R(s_t, \pi(s_t), s_{t+1}) \right]$（所有随机路径的期望）。最优策略：$\pi^*_t = \text{argmax}_\pi U^\pi(s)$。无限期的折扣效用的结论：最优策略与初始状态无关，$\therefore \pi^*_t$ 可写成 $\pi^*$。

状态 $s$ 的期望效用：$V^*(s) = V^{\pi^*}(s)$（最优策略）-> 想求解的（简记为 $V(s)$）。$q$-state $(s, a)$ 的期望效用：$Q^*(s, a)$，状态 $s$ 下采取 $a$ 后采取最优策略的期望效用。

## 5、价值迭代

直接 Monte Carlo，迭代求解。贝尔曼方程：一个状态的效用值 = 该状态下的立即回报 + 下一个状态的期望折扣效用值。根据走到不同状态的递归定义：$V(s) = \max_{a \in A(s)} \sum_{s'} T(s, a, s') \left[ R(s, a, s') + \gamma V(s') \right]$（最大值节点）。

Q 函数的贝尔曼方程：$Q(s,a) = \sum_{s'} T(s, a, s') \left[ R(s, a, s') + \gamma V(s') \right]$（机会/期望节点）$= \sum_{s'} T(s, a, s') \left[ R(s, a, s') + \gamma \max Q(s', a) \right]$。正是 expectimax 的计算过程。问题：状态重复（每个相同状态用同一参数存储，在搜索树对不同层次进行迭代更新）；树对无限扩展，更新较小时终止。

1 **价值迭代**：每个节点的值，自底向上搜索（终止状态）。从搜索树：限定深度（因为有 $\gamma$）；从方程：每个节点的更新小于终止参数 $\epsilon$（时间 $O(SA)$）。

定理：收敛到唯一的最优值（状态值不收敛，但是策略收敛）。

```text
function VALUE-ITERATION(mdp, c) returns a utility function
    inputs: mdp, an MDP with states S, actions A(s), transition model P(s' | s, a), rewards R(s), discount γ
           c, the maximum error allowed in the utility of any state
    local variables: U, U', vectors of utilities for states in S, initially zero
           δ, the maximum change in the utility of any state in an iteration

    repeat
        U := U'; δ := 0
        for each state s in S do  # 对每个状态做一个贝尔曼更新
            U'[s] := R(s) + γ max_a Σ_{s'} P(s' | s, a) U[s']
            if |U'[s] - U[s]| > δ then δ := |U'[s] - U[s]|
    until δ < c(1 - γ)/γ  # 直到收敛，即所有更新小于 c
    return U
```

从 $U(s) = 0$ 和一些终止参数 $\epsilon$ 开始。收缩：$d(F_x, F_y) \le c d(x, y), c < 1$，用于证明压缩映射（压缩有唯一的不动点，$F(z) = z$）。从 $V(G)$ 中提取策略：策略提取 $\pi_v(s) = \arg\max_a \sum_{s'} P(s' \mid s, a) [R(s, a, s') + \gamma V(s')]$。$Q^*(s, a) = \sum_{s'} T(s, a, s') [R(s, a, s') + \gamma V^*(s')]$，$\pi^*(s) = \arg\max_a Q^*(s, a)$。

问题：1. 每次迭代慢，$O(S^2 A)$；2. 最优行动很少改变；3. 策略在状态值前收敛。

## 6、策略迭代

2 **策略迭代**。初始策略 $\pi_0$。重复直到策略没有变化：策略评估（评估当前 $\pi_k$ 的 $V^{\pi_k}$）；策略改进（从 $V^{\pi_k}$ 中提取新的 $\pi_{k+1}$）。

$$\pi_{i+1}(s) = \arg\max_a \sum_{s'} T(s,a,s') [R(s,a,s') + \gamma V^{\pi_i}(s')]$$

价值迭代：迭代求 $V^*(s)$，提取 $\pi^*(s)$；策略迭代：迭代求 $\pi^*(s) = \arg\max_{a \in A(s)} \sum_{s'} P(s'|s,a) V^*(s')$。

```text
function POLICY-ITERATION(mdp) returns a policy
    inputs: mdp, an MDP with states S, actions A(s), transition model P(s' | s, a)
    local variables: U, a vector of utilities for states in S, initially zero
               π, a policy vector indexed by state, initially random

    repeat
        U := POLICY-EVALUATION(π, U, mdp)
        unchanged? := true
        for each state s in S do
            a* := argmax_{a ∈ A(s)} Q-VALUE(mdp, s, a, U)
            if Q-VALUE(mdp, s, a*, U) > Q-VALUE(mdp, s, π[s], U) then
                π[s] := a*; unchanged? := false
    until unchanged?
    return π
```

Step 1：策略评估 —— 计算当前策略 $\pi_k$ 的值 $V^{\pi_k}$。Step 2：策略改进 —— 从 $V^{\pi_k}$ 中提取新的隐含策略 $\pi_{k+1}$。

优化：将 $a \in A(s)$ 改为 $\pi(s)$（类似求解线性方程，更简单）。

**贝尔曼方程的简化**：$$V^\pi(s) = \sum_{s'} T(s, \pi(s), s') [R(s, \pi(s), s') + \gamma V^\pi(s')] \quad (\text{时间 } O(S^2))$$

策略评估：精确求解（$\pi$ 固定，$s'$ 个常数，线性方程组 $O(S^3)$，该状态值 = 一步到该状态值）；近似求法：$V_{k+1}^\pi(s) = \sum_{s'} T(s, \pi(s), s') [R(s, \pi(s), s') + \gamma V_k^\pi(s')]$（没 max，因为策略是固定的），初值 $V_0^\pi(s) = 0$，迭代至收敛（修正策略迭代）。

价值迭代与策略迭代在计算相同的东西，都收敛到最优解，都是 MDP 的动态规划。计算最优值：价值迭代、策略迭代；计算特定策略的值：策略评估；值转为策略：策略提取。例题：$A: 25 \quad B: \frac{25}{8}$。假设 $R(s, a, s') = 0, T(s, a, s') = 1, \gamma = \frac{1}{2}$。确定最优解（确定最优准则）；$6$ 次最优解（第一次要迭代出口）（出口也算一个动作，不是一定执行）。不会改变策略的 reward 函数 —— 线性变换 $R' = aR + b \quad (a > 0)$ 确定 $b$ 的值；无限迭代（倍数，加上常数）；降幂器：$\gamma b = \frac{1}{1-\gamma} < \text{出口最小收益}$；最少迭代。

**下半部分：强化学习**

## 7、强化学习概述

向智能体提供奖励比标签容易。

- **被动强化学习**：model-based（自适应动态规划）、model-free（直接效用估计、时序差分学习）
- **主动强化学习**：Q-Learning

策略固定目标是学习状态的效用。探索策略。

**基本思想**：

- **探索**：尝试未知行动获得信息
- **利用（信息）**：使用已知信息（利用奖励信息，学习非终止状态 $s$ 的 $U'(s)$）
- **采样**：重复多次才能有良好的估计
- **泛化**：一个状态学习到的东西适用于其他状态

Agent <- 环境（action；state, reward）。从环境接收反馈；Agent 的效用由回报函数定义；最终学会采取行动最大化期望；学习基于采样的样本。

MDPs：完全可观察，离线（拥有环境的完整模型，知道回报）模拟。RL：没有两者的先验知识，在线。与 MDPs 相比，不知道 $T(s, a, s')$ 与 $R(s, a, s')$（目标定义一致）；需要尝试去学习（传感器感知）。

## 8、被动强化学习（离线）

给定固定的 $\pi(s)$，不知道 $T$ 或 $R$。目标：学习状态值，评估策略的好坏 $U(\pi)$（即策略评估）。

**D model-based**：玩一次游戏（一个序列）得到一个采样（重复更新）。思路：1 根据经历学习近似的模型 —— 计算每个 $s, a$ 的结果 $s'$（传感器）（频率统计），归一化估计 $\hat{T}(s, a, s')$，经历 $(s, a, s')$ 时发现一个 $\hat{R}(s, a, s')$（均值）。2 求解学习到的 MDP，对策略进行评估。

- 利：有效地利用了经历（简单）
- 弊：无法扩展到大型空间 —— 一次学习一个状态-动作对模型；无法解决状态非常大的 MDP

例：model-based：$\hat{p}(a) = \frac{\text{num}(a)}{N}$，$E[A] \approx \sum_{a} \hat{p}(a) \cdot a$；model-free：$E[A] \approx \frac{1}{N} \sum_{i} a_i$（样本会以正确概率被采样）。

## 9、无模型被动学习

2) model-free：

1 **直接（效用）估计**：目标：计算每个有效状态的（效用）值。状态序列的效用：$\frac{1}{t_0} \sum_{t=0} \gamma^t R_t(s, a, s')$。思路：平均化观察到的样本值（一个状态的效用定义为从该状态出发的期望总奖励）（期望奖励）—— 按工作动（不同状态出发模拟）；每访问一个状态，累加回报的总和（有个样本出现对应状态和 $t$）；取这些样本的回报平均值。

- 利：容易理解；不用下 R 知识；使用样本中的转换关系
- 弊：一次经历（时间长）才能学习；浪费状态与状态之间的信息；状态必须分解学习；效率低；忽略了根正率

2 **时序差分学习（TD）**：类似策略迭代。$V^\pi(s) = 0$；$V^\pi(s) \leftarrow \sum_{s'} T(s, \pi(s), s') [R(s, \pi(s), s') + \gamma V^\pi(s')]$。利用了状态之间的关系，但是需要下 R。关键：知道下 R 下对 V 进行更新。

想计算平均值来改进对 $V$ 的估计：1 对结果 $s'$ 进行采样（执行动作）并取平均值（蒙特卡洛）：$\text{sample}_i = R(s, \pi(s), s') + \gamma V_k^\pi(s')$（均从 $s$ 出发），$V_{k+1}^\pi(s) \leftarrow \frac{1}{n} \sum_{i=1}^n \text{sample}_i$。问题：不一定能退回 $s$。2 因为不一定能在 $s$ 采样，通过一次序列来采样。3 更新值：通过维护一个移动平均 —— 直接平均没有递推的思想；保持 $M_n$：$M_n = ((n-1)M_{n-1} + X_n) / n = \frac{n-1}{n} M_{n-1} + \frac{1}{n} X_n$（加权平均）；近似求解：$M_n = (1-\alpha)M_{n-1} + \alpha X_n$，展开发现对早期的数据权重越小（类似 $\gamma$，指数遗忘）。

$$\text{sample} = R(s, \pi(s), s') + \gamma V^\pi(s') \quad (\text{固定动作}), \quad V^\pi(s) \leftarrow (1-\alpha)V^\pi(s) + \alpha \, \text{sample}$$

## 10、TD 学习算法

**TD 时序差分（机器学习）**：$$V^\pi(s) \leftarrow V^\pi(s) + \alpha [\text{sample} - V^\pi(s)] \text{ (时序差分学习)(更新一点点)}$$学习率 $\searrow$ TD error。样本多 $\alpha \downarrow$，样本少 $\alpha \uparrow$。从每次状态转移中学习；越有可能出现的 $s$ 频繁更新（相当于转移模型）。

```text
Temporal Difference Learning 时序差分学习
function PASSIVE-TD-LEARNER(percept) returns an action
    inputs: percept, 指示当前状态 s' 与奖励信号 r 的某个感知
    persistent: π, 一个确定性策略
      s, 之前的状态, 初始化为空
      U, 关于状态效用的表, 初始化为空
      N_s, 关于状态出现频率的表, 初始化为零

    if s' 是一个新的状态 then U[s'] := 0
    if s 非空 then
        增加 N_s[s]
        U[s] := U[s] + α(N_s[s]) × (r + γ U[s'] - U[s])
        s := s'
    return π[s']
```

$\alpha \downarrow$，序列多长，收敛到最优解。问题：只能得到某个策略各的效用值；由于 TR 未知，不能得到新策略。

## 11、主动强化学习与 Q-Learning

二、**主动强化学习**：agent 自己决定采取什么行动，需要学习 $P(s'|s,a)$。Q 学习：学习 Q-values 而非效用值，得到更好的 $\pi(s)$。

**Q-Learning：基于采样的 Q 值迭代**。$Q_0(s,a) = 0$（双变量的多值初始化）（前 $A$ 个 Q 值）。

$$\text{sample}(s,a,s') = R(s,a,s') + \gamma \max_{a'} Q(s',a')$$

差算法：$Q(s,a) \leftarrow (1-\alpha)Q(s,a) + \alpha\ \text{sample}$，$\leftarrow Q(s,a) + \alpha(\text{sample} - Q(s,a))$。

更新后选最大的行动；开始随机行动，学习到一定程度使用启发式行动（turnoff）。完整的强化学习求最优策略：不知道 $T, R$，自己选择行动，目标：学习最优策略/状态值。

根据已学到的 Q 来 sample（即使不精确，但能收敛到最优）。脱离策略的学习：足够的探索；最终要足够小的学习率，但不要太快减小它。

**探索方案**：

- 1 $\epsilon$-greedy 策略：以 $\epsilon$ 的概率随机选择动作，否则 $\max_a Q(s,a)$（利用以往的 $Q$ 最大）。为防止收敛后仍探索，使用降低策略的随时间降低 $\epsilon$
- 2 探索函数：探索那些「不好」还没有建立的区域。输入：价值估计 $\mu$、访问次数 $n$，返回效用 $V$，得 $f(\mu, n) = \mu + \text{something}$。$$Q(s,a) \leftarrow \alpha R(s,a,s') + \gamma \max_{d'} f(Q(s,a'), N(s,a')) \quad \text{（改变）}$$（$N(s,a)$ 为 $Q(s,a)$ 的访问次数）。优点：收敛快；缺点：策略/Q值不一定好

regret 衡量总错误成本：（期望）回报与最佳（期望）回报之间的差异。要求「最优地学到最优」，$\epsilon$-greedy 有较高的 regret。

## 12、近似 Q-Learning

例：$\pi(s)$ 的 sample 能够使 $V(s)$ 收敛，$\pi(s)$ 是最优策略（被动）。2 Q 学习，同步学习策略，sample 包含所有 $(s,a)$ 则 $Q(s,a)$ 收敛（主动）。

**近似 Q-Learning（重点）**：$Q(s,a)$ 的太多状态无法在训练中全部访问（sample 次数大）；占用内存大。概括：从经历中学习一些少量的训练状态；泛化到新的类似的情况。解决：使用特征向量描述状态。特征：从状态到实数的函数（深度神经网络）。

例：$V(s) = w_i f_i(s)$，$Q(s,a) = w_i f_i(s,a)$（深度强化学习）。

Q-Learning：$\text{transition} = (s, a, r, s')$；$\text{difference} = [r + \gamma \max_{a'} Q(s', a')] - Q(s,a)$。
