# 八、机器学习

## 1、机器学习概述

监督学习：决策树、线性回归和分类；深度学习；极大似然参数学习（贝叶斯参数学习）。

人工智能 -> 机器学习 -> 深度学习。构建小孩去学习，而非构建成年人。

依据输入的反馈分类：

- **监督学习**：有标注样例
- **强化学习**：有回报序列
- **无监督学习**：无标注样例
- **自监督学习**：利用数据本身的结构信息进行监督学习

监督学习：学习一个目标函数 $f$；输入：训练集 $(x_i, y_i)$，$y_i = f(x_i)$；输出：假设 $h$ 逼近真实函数 $f$（准确预测新样例）—— 一般性假设 $h(x)$ 与 $y_i$，最小化损失函数。假设空间 $H$（$h \in H$）：线性模型、逻辑回归、神经网络、决策树。

- **分类**：学习输出为离散型 $f$
- **回归**：学习输出为连续型 $f$

## 2、假设选择原则

从样本学习一个函数 $g$。问题：给定假设空间 $\mathcal{H}$，给定训练样本，找到 $h(x) \sim g$。

原则：

- **一致性**：偏差（真实值的差）、方差（不同训练集下）；(f 与 ground truth 一致) 更喜欢确切拟合数据
- **简单性**：与数据一致的最简单假说

$$h^* = \arg\max_{h \in H} P(h|data) = \arg\max_{h \in H} P(data|h) P(h)$$

方法：缩小假设空间（更多假设更少，更好的特征）；结构限制（决策树、树）；正则化：显式惩罚复杂假说。

$$\text{cost}(h) = \text{EmpLoss}(h) + \lambda \cdot \text{Complexity}(h)$$

- **偏差**：所有可能数据集训练出来的所有模型的输出的平均值与真实模型输出的差异；算法期望预测与真实结果的偏离程度，算法本身的拟合能力，$\text{bias}^2(x) = (\bar{f}(x) - y)^2$
- **方差**：不同训练集训练出的模型输出值之间的差异；同样大小的训练集的变动导致学习性能的变化，数据扰动的影响，$\text{var}(x) = E_D[(f(x;D) - \bar{f}(x))^2]$

问题：选择假设空间，衡量拟合度，权衡拟合度与复杂度。

## 3、分类与决策树

1 分类：$x(\text{input}) \xrightarrow{\text{提取特征}} f(x) \xrightarrow{\text{机器学习}} y$ 预测输出。

分类模型：决策树（决策树模型、构造决策树、衡量学习表现）（重点）。属性值向量映射到单体输出值；对输入空间分区，为每个分区分派一个标签（相当于真值表）。布尔分类：输入为离散的，输出为标值。

**表达能力**：离散决策树可以表达任何布尔逻辑（$n$ 个属性有 $2^n$ 个结果，共 $2^{2^n}$ 个函数）；$\text{Output} \Leftrightarrow \text{path}_i$（$\text{path}_i$ 为 $\text{true}$ 的路径）。

从样例中学习决策树：在庞大空间设计算法，学习决策树。目标：给定属性和标签列表的训练数据；假设家族 $\mathcal{H}$：决策树；找到适合训练数据的最小决策树；选择下一个要拆分属性的迭代过程。启发式：先测试重要的属性，递归地解决测试结果产生的更小的子问题。

## 4、信息熵与信息收益

**信息收益**：衡量属性对增加样本子集「纯度」的贡献。找最有区分能力的特征，提供有关分类的信息。

- 1 剩余样例全为正/负，达成目标
- 2 剩余样例有正有负，继续选择最好的属性对样例分割
- 3 没有剩余样例，则没有观测值，返回构造该节点的父节点的样例集中最常见的值
- 4 没有其他的属性剩余，但有有正有负，则相同属性不同取值（噪声导致），返回剩余样例集中最常见的值。对未出现样例会出现错

**信息熵**：$1 \text{ bit} = \text{在等概率下，一个二进制位(bit)}$。衡量不确定性（越大，越高），信息越多，越小。若 $v$ 的取值为 $v_k$ 的概率为 $P(v_k)$，则熵 $H(v) = -\sum_{k} P(v_k) \log_2 P(v_k)$。

对于二值：$H(\langle p, 1-p \rangle) = -p \log p - (1-p) \log(1-p) = B(p)$（$p = \frac{1}{2}$，熵最大 $= 1$）。$H(\langle p_1, p_2, \dots, p_n \rangle) = -\sum_{i} p_i \log p_i$。

**拆分收益**：样例 $E$ 有 $p$ 个正例和 $n$ 个负例，对应 $B(\frac{p}{p+n})$ 比特。一个属性将样例 $E$ 分成子集 $E_k$（$p_k$ 个正例，$n_k$ 个负例），每个用更少的信息。一个样例进入 $E_k$ 的概率 $\frac{p_k+n_k}{p+n}$（权重），对应拆分后的期望 $\sum_k \frac{p_k+n_k}{p+n} B(\frac{p_k}{p_k+n_k})$。

$\text{Gain}$ 信息收益 $= B(\frac{p}{p+n}) - \sum_k \frac{p_k+n_k}{p+n} B(\frac{p_k}{p_k+n_k})$（ID3 决策树算法）。希望收益越大越好，使用附加信息减少熵的值（拆分后更确定）。最大的信息收益作为树的根。学习决策树：贪心选择信息收益最高的属性拆分。

**决策树学习算法**：

```text
function Decision-Tree-Learning(examples, attributes, parent_examples) returns a tree
    if examples is empty then return Plurality-Value(parent_examples)
    else if all examples have the same classification then return the classification
    else if attributes is empty then return Plurality-Value(examples)
    else A := argmax_{a ∈ attributes} Importance(a, examples)
    tree := a new decision tree with root test A
    for each value v of A do
        exs := the subset of examples with value v for attribute A
        subtree := Decision-Tree-Learning(exs, attributes - A, examples)
        add a branch to tree with label (A = v) and subtree subtree
    return tree
```

优点：易理解；处理有缺失属性的样本；处理不相关特征；运行速度快。

## 5、决策树的改进

缺点：容易忽略数据集中属性的关联；容易过拟合（正则化，权重衰减以服从简单性原则）。

改进：（前剪枝）若当前结点不能带来泛化性能的提升，则停止划分；（后剪枝）生成完整决策树后，自底向上对非叶结点考查，若将该结点对应的子树替换为叶结点能提升决策树泛化性能，则替换。

改进：随机森林（拓展）。使用不同数据子集。集成学习算法：放回抽样，多数表决（分类）/ 平均（回归）；减方差；多个独立的弱分类器（基学习器）。随机森林：随机选择样本、随机选择特征、构建决策树、随机森林投票。优：处理高维的数据；并行。缺：噪声大，易过拟合。

XGBoost（拓展）。集成学习方法：训练基学习器，对其中错误的样本更多关注（减少偏差）。$\hat{y}_i^{(t)} = \sum_{k=1}^{t} f_k(x_i) = \hat{y}_i^{(t-1)} + f_t(x_i)$ -> 第 $t$ 棵树的模型（需训练的）。

训练和测试。经验风险最小化：在实际训练集上造最好的模型（优化）。减少过拟合：增加训练数据（抽样方差减小）；限制假设的复杂性（正则化/缩小假设空间）。数据：训练集、验证集、测试集（验证集调超参数）。结果中：漏检不放，单类多，强确定性。评估：accuracy、recall、precision、F1。过拟合和欠拟合：overfit（过拟合）、underfit（欠拟合）。

2 **回归** regression = 学习输出为数值型的 f。线性回归 = 拟合一条直线/一个超平面；最小二乘法（最小化方差）。定义损失函数；目标：找到最优参数 $w^*$ 以最小化损失函数；对预测值 $y_i$ 的噪声服从正态分布时，$\text{Loss}(w) = \sum_{i=1}^{N} (y_i - (w x_i + w_0))^2$。精确解：$w^* = (X^T X)^{-1} X^T y$（$X$ 为特征向量）；梯度下降：$w_i \leftarrow w_i - \alpha \frac{\partial \text{Loss}}{\partial w_i}$。

## 7、线性分类与感知器

(3) 线性回归通过激活函数达到线性分类（通过阈值到 $\{0, 1\}$）（阈值）（决策边界）= 二元决策规则，方程 $\vec{w} \cdot \vec{x} = 0$ 定义了一个超平面，两侧对应 $y=1/0$。学习特征向量 $(\vec{w})$；输入是特征值，每个特征正有一个权重，加权求和后激活：$\text{activation}_w(x) = \vec{w} \cdot \vec{f}(x)$（点积是相似度）（$f(x)$ 是特征，从 $x$ 中提取的）；比较输入特征和权重向量；学会之后，即为信息。损失：平方损失。

**感知学习规则**（权重更新）：真实出错 $y \neq h_w(x)$，调整权重。学习规则：$\vec{w} \leftarrow \vec{w} + \lambda (y - h_w(x)) x$（学习率 $\lambda$）；$w \leftarrow w - \eta \nabla_w L$；$L = (y - h(x))^2, \quad \nabla_w L = 2(y - h(x))(-x) \leftarrow w + \alpha (y - h(x)) x$。

**感知收敛定理**：若学习问题是线性可分的（存在超平面将正样例与负样例分开）—— 训练数据：可分离的 => 收敛到完美的分离器；不可分离的 => 收敛到极小误差解（误差逐渐减小）。

问题：不能学异动。

- 对噪声敏感：权重不可分离，权重震荡
- 泛化能力不多：接近边界（只能得到完全确定的 1/0 预测）
- 过度训练：过拟合导致准确率下降

解决：确定性决定 -> 概率化的决定。硬约束 $u(x)$ 变为软约束 $\text{sigmoid}(x) = \frac{1}{1 + e^{-x}}$ 变为概率。

## 8、Logistic 回归与多分类

**概率化的决定**：(logistic 回归)。感知器的输出 (logits)（没激活前）。$\text{sigmoid}$（值域 $(0,1)$，概率和为 $1$，$\phi' = \phi(1-\phi)$，取 $z$ 对数值稳定）。

极大似然估计：$$L = P(D|w) = \prod_{i} P(D_i|w) = \prod_{i} P(y^{(i)} | x^{(i)}; w)$$

正例：$p = \frac{1}{1 + e^{-w^T x}}$，负例：$1 - p$。是逻辑回归问题：二分类、sigmoid 激活 $(p, 1-p)$。$w$ 也不能找到很好的超平面，但有概率。简单：$L_2$ 正则化，使 $w$ 的值小：$$w_i \leftarrow w_i + \alpha (y - h(x)) \cdot h(x) \cdot (1 - h(x)) \cdot x_i$$

**二分类到多分类**：

- **感知机**：每一类有一个权重向量 $\vec{w}_y$，类 $y$ 的得分（激活）：$\vec{w}_y \cdot \vec{F}(x)$，选得分高的
- **softmax**（不同类别不同决策平面）：$\text{minimize } -\ell(w)$；softmax 在二分类时：$+1$ 的权重为 $w$，$-1$ 的权重为 $0$，变为 sigmoid（$p = \sigma(p)$，不用 $w_1, w_2$ 都训）

爬山法：$w \leftarrow w + \alpha \nabla_w g(w)$。$\alpha$ 足够小，能够保证收敛到全局的唯一极小值；二阶导数调整学习率；小批量随机梯度下降。

**结构化假设空间 $H$：概率模型** —— 拟合度：似然；权衡拟合度与复杂度：正则化或先验；好的 $h$：泛化精度上升。
