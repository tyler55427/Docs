# PowerToys：

- 高级粘贴
  - Win+Shift+V：打开粘贴面板，支持选择粘贴历史

- 前端显示
  - Ctrl+Alt+T

- 速览
  - Ctrl+Space

# Everything：

文件搜索

# Notepad++：

记事本

- 功能
  - 垂直同步/水平同步滚动
  - 结构图：左侧菜单，右侧总览

- 快捷键：
  - Ctrl+T：交换上下两行

# ZoomIt：

放大镜

[download](https://download.sysinternals.com/files/ZoomIt.zip)

- 快捷键：
  - Ctrl+1：禁止页面缩放
  - Ctrl+4：动态页面缩放
  - Ctrl+8：滚动截屏
