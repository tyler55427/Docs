# 文本模型

## 训练

### 预训练

利用大规模语料进行自监督学习，学习语言的统计规律和语义表示。

一句文本，通过因果注意力（masked self-attention）并行训练，监督目标就是下一个token的预测。

### 指令微调

利用人工标注的指令数据集对预训练模型进行微调，使其能够更好地理解和执行自然语言指令。

问答对训练，拼接成一句话训练，但是只计算答案的损失。

## 推理

### 分类

- 自回归生成（主流）
- 并行生成
    - 双向注意力掩码（BERT）
    - 迭代式解码
    - 扩散语言模型

### 流程

- 计算当前确定的token中的最后一个token的QKV
- 用这个Q，与之前所有的K和V进行注意力计算，得到下一个token的输出
- 将输出通过解码头解码成词表的概率分布，得到下一个token

#### KV Cache

- 每个token的Q只计算一次，跟之前的所有KV计算
- 但是每个token的KV都需要跟之后新生成的token进行计算，所以可以存储起来

> **注意**：transformer的每一层的KV都需要进行缓存，不是只缓存最后一层的KV
