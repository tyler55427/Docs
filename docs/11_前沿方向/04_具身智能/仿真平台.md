## 仿真平台

| 平台                      | 主要定位                                 | 适合任务                                     |
| ------------------------- | ---------------------------------------- | -------------------------------------------- |
| **MuJoCo**               | 轻量、高效、控制友好                     | 控制、机械臂、模仿学习、小闭环实验           |
| Robosuite + **LIBERO**   | MuJoCo 系操作与 VLA 研究组合             | manipulation、VLA、终身学习 benchmark        |
| **Isaac Sim**            | 高保真渲染与复杂机器人仿真               | 合成数据、ROS2、Sim2Real、复杂场景           |
| Isaac Lab                 | Isaac 生态下的 RL/IL 主线                | RL、IL、策略训练、任务构建                   |
| Habitat-Sim / Habitat-Lab | 室内导航与 VLN 平台                      | PointNav、ObjectNav、VLN                     |
| ManiSkill                 | GPU 并行操作与 RL 平台                   | manipulation、PPO、数据采集、任务构建        |
| GenieSim / GenieSim3      | 高写真操作仿真与 benchmark               | Pi0、策略评测、高保真操作任务                |
| OmniGibson / BEHAVIOR     | 长程家庭任务与复杂交互                   | household、mobile manipulation、长程任务     |
| Genesis                   | 新兴高速物理仿真平台                     | 高速仿真、多物理场、研究探索                 |
| Gazebo                    | ROS/ROS2 系统工程验证                    | 传感器仿真、移动机器人系统集成               |
| AirSim                    | 无人机历史常用平台                       | 无人机、视觉导航 demo                        |
| DISCOVERSE                | MuJoCo + 3DGS 高保真渲染 + Real2Sim2Real | 高保真渲染、真实场景重建、Real2Sim2Real 研究 |
| SIM1                      | 双臂柔体操作与数据生成                   | 布料操作、遥操作、replay、扩散轨迹生成       |
