# 评估

## 指标

- 成功率

## 测评方面

- **泛化（Generalization）**：正确处理不是ID（分布内）的数据
- **OOD（Out-of-Distribution）**：
    - 也属于泛化，但是比泛化要求更加严格，类似极端特殊环境
    - 泛化指数据不是训练数据，但跟训练数据分布类似，但是OOD分布不同，例如：真实图像（训练）->卡通图像（推理）
- **长程任务：**
- **跨本体（Cross-Embodiment）**：
    - 与世界交互的物理实体
    - 包含多种类别：
        - 异构机器人：不同结构，不同自由度
        - 同构机器人：相同结构和自由度，但是传感器不同、传感器位置不同
