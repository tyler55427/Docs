# 数据集

## MetaWorld（2019.10）

- 环境：仿真（MuJoCo）
- 范围：Bench
  - 50 个多样化操作任务（抓取、搬运、开门、抽屉操作等）
- 指标：成功率

## RoboMimic（2021.8）

- 环境：仿真（MuJoCo）+真实
- 范围：训练+bench
- 指标：成功率

## CALVIN（2021.12）

- 环境：仿真（PyBullet）
- 范围：训练 + Bench
  - 34 项预定义基础技能，24k 人类遥操作演示
- 指标：成功率 + 平均成功序列长度（Avg. Len，取值 0–5）

## Push-T（2023.3）

- 环境：仿真（MuJoCo）
- 范围：训练+bench
- 指标：IoU

## LIBERO（2023.6）

- 环境：仿真（MuJoCo / RoboSuite）
- 范围：训练 + Bench
  - 人类遥操作演示数据集
  - 130 个任务（分属 Spatial、Object、Goal、100 等套件），专为终身学习与知识迁移设计
- 指标：成功率

## Open X-Embodiment（OXE）（2023.10）

- 环境：真实
- 范围：训练
  - 汇集全球 34 家机构、22 种机器人形态的真实机器人轨迹数据
  - 作为大规模**预训练**数据集，用于训练**通用**机器人策略（如 RT-X 系列）
- 指标：无

## Robottwin 2.0（2025.6）

- 环境：仿真（MuJoCo）
- 范围：训练 + Bench
  - 50 个双臂任务基准，覆盖 5 种机器人形态
- 指标：成功率

## RoboDojo（2026.7）

- 环境：仿真 + 真实
- 范围：Bench
  - 42 个仿真任务 + 18 个真实机器人任务
  - 覆盖泛化、记忆、精细操作、长程、开放语义五大维度
- 指标：成功率
