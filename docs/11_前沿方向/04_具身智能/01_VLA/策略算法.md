# 策略算法

## 模仿学习（重头训练？）

### 行为克隆（BC）

机器人数据监督学习

### ACT (Action Chunking Transformer)

一种基于模仿学习的机器人操作算法，通过预测未来多步动作块（action chunks）而非单步动作，显著提升了抓取、放置等任务的稳定性与精度。

### DP (Diffusion Policy)

利用扩散模型进行去噪式动作生成的视觉运动策略，是机器人操控领域的代表性方法，在大量操作任务上取得了先进效果。

## 机器人技能接口

## 微调模型

### DP3 (3D Diffusion Policy)

DP 的三维扩展版本，使用点云等 3D 表示输入进行策略学习，被广泛用作抓取、双臂操作等各类机器人操作任务的基准与基础策略。

### RDT (Robotics Diffusion Transformer)

专为双臂操作设计的扩散基础模型，在大规模双臂数据集上预训练，可直接面向复杂的机器人操控场景进行微调与部署。

### VLA（视觉语言动作）

一个视觉-语言-动作（VLA）基础模型，其动作输出直接用于机器人闭环控制，并在叠衣服、清理桌面、装袋等真实家庭操作任务上进行了评估与演示。
