## PaLM-E（2023.3）

- 开源范围：论文、项目主页
- backbone：预训练 PaLM 大语言模型 + ViT-22B 视觉编码
- 动作生成：输出low-level文本指令，额外使用其他策略训练机器人学会执行low-level的指令
- 运行频率：约1~2Hz（规划级）
- 训练的数据集

  - 真实性：真机+仿真
  - 数据范围：机器人数据 + 大规模通用视觉语言数据 + 语言数据 + VQA

    - 机器人数据：Task and Motion Planning（TAMP）、Language Table、Mobile Manipulation 等任务数据
    - 通用视觉语言数据：WebLI、VQAv2、OK-VQA、COCO 等
    - 语言数据：Wikipedia 等文本数据
  - 跨本体：有
- 评估的数据集

  - 范围：具身推理为主
  - 场景：

    - TAMP：仿真桌面物体抓取、堆叠与任务规划
    - Language Table：桌面推物体任务，包含真机实验
    - Mobile Manipulation：移动机器人导航与操作，包含真机实验
    - 通用视觉语言：OK-VQA、VQAv2、COCO 等
  - 任务类型：

    - 机器人任务规划：根据指令进行多步骤物体操作
    - 桌面操作：根据语言指令推动目标物体
    - 移动操作：寻找物体、打开抽屉、取出物品并响应环境变化
    - 视觉问答、图像描述等通用视觉语言任务
  - 指标：

    - 机器人任务成功率
    - 视觉语言任务使用相应的问答准确率
    - 图像描述指标
- 训练方式

  - 训练方法：端到端自回归训练
  - 训练范围：
    - 使用预训练的 PaLM 与 ViT-22B
    - 对输入编码器与语言模型进行端到端训练/微调

## ACT（2023.4）

- 开源范围：论文、代码
- backbone：transformer+图像模态输入
- 动作生成：LLM的**动作分块**输出，窗口权重衰减
- 运行频率：50Hz（ALOHA本体控制；一次前向预测约100步动作块）
- 训练的数据集

  - 真实性：真机+仿真
  - 数据范围：机器人数据
  - 跨本体：无
- 评估的数据集

  - 范围：自行收集
  - 场景：桌面平台
  - 任务类型：
    - 打开半透明调料杯
    - 插入电池
    - 滑动密封袋
    - 穿扎带
    - 准备胶带
    - 穿鞋
  - 指标：任务成功率
- 训练方式

  - 训练方法：VAE重构和KL散度损失训练（VAE_Encoder+VAE_Decoder(transformer_encoder+transformer_decoder))）
  - 训练范围：从0训练

- 动作生成：动作token输出（动作离散化分桶，7-DoF）
- 运行频率：RT-1-X约3~5Hz（本地推理）；RT-2-X约1Hz（云端推理）
- 训练的数据集

  - 真实性：真机

  - 跨本体：有（22种本体）
- 评估的数据集

  - 范围：多家整合（多个研究机构、多台真机）
  - 场景：各实验室真机场景
  - 任务类型：抓取、放置等操作任务，含跨本体迁移与组合泛化
  - 指标：成功率（衡量相比单本体数据训练的提升）
- 训练方式

  - 训练方法：模仿学习（行为克隆）
  - 训练范围：
    - RT-1和RT-2上使用新数据训练

- 运行频率：约6Hz（自回归单步推理）
- 训练的数据集

  - 真实性：真机
  - 数据范围：机器人数据（Open X-Embodiment，约970k episodes，27个数据集）
  - 跨本体：有
- 评估的数据集

  - 范围：直接使用多家现成bench，共29个任务
    - WidowX + BridgeData V2：真机，7个任务（抓取、放置等）
    - Google Robot：真机，12个任务（沿用RT-1/RT-2评测协议，含分布内与分布外泛化）
    - LIBERO：仿真，10个任务（覆盖Spatial、Object、Goal、Long四个套件）
  - 场景：看具体bench（真机为WidowX、Google Robot；仿真为LIBERO）
  - 任务类型：看具体bench
  - 指标：任务成功率
- 训练方式

  - 训练方法：在预训练VLM上微调（自回归）
  - 训练范围：
    - 使用预训练VLM
    - 大规模全量微调预训练
    - 特定任务后训练（全量微调/LoRA微调）

## GR00T N1.7（2026.4）

- 说明：GR00T 系列是 NVIDIA 面向人形机器人的跨本体 VLA 基础模型，采用**双系统架构（System 2 视觉语言 + System 1 动作头）**，而非单一端到端网络
- 开源范围：代码、预训练权重（3B）、微调与推理代码、仿真 bench 复现脚本，Apache 2.0 可商用

  - 版本演进：N1（2025.3，首批开源）→ N1.5（2025.6）→ N1.6（2025.12）→ N1.7（2026.4 GA）
- backbone
  - 视觉语言模块（System 2）：N1 用 Eagle VLM；N1.5 冻结、简化适配层、增强 grounding；N1.6 改用内部 Cosmos-2B VLM；N1.7 换为 **Cosmos-Reason2-2B（基于 Qwen3-VL）**，支持原始宽高比不 padding 的灵活分辨率
  - 动作模块（System 1）：flow matching 的扩散 transformer（DiT）动作头；N1.6 用 32 层 DiT，N1.7 改回 16 层
  - 两模块紧耦合、端到端联合训练
- 动作生成：连续动作块（flow matching 去噪），N1.7 引入**相对末端 EEF 动作空间**（相对当前位姿的增量），人体数据与机器人数据共用同一动作表示，动作维度 132（N1.6 为 29），action horizon 40
- 运行频率：模型推理约 36Hz（H100 + TensorRT，4 步去噪）、AGX Thor 约 12Hz；机器人动作执行约 30FPS

  - 注意推理频率 ≠ 执行频率：一次推理输出多步动作块，靠 action chunking + 异步推理达到 30FPS 执行
- 训练的数据集

  - 真实性：真机 + 仿真 + 人体视频
  - 数据范围：异构混合数据，N1.6 预训练额外加入了双臂 YAM、AgiBot Genie-1、Galaxea R1 Pro（仿真 BEHAVIOR）、Unitree G1 全身移动操作共数千小时遥操作数据；N1.7 再加 20K 小时 EgoScale 人体视频
  - 跨本体：有（人形、半人形、双臂机械臂多种本体）

- 评估的数据集

  - 范围：仿真 bench（LIBERO、SimplerEnv（Fractal/Bridge）、RoboCasa、RoboCasa-GR1 桌面任务）+ 真机评估
  - 场景：桌面操控、双臂操控、全身移动操作
  - 任务类型：抓取放置、长程推理、灵巧操作、多任务，以及语言跟随和分布外泛化
  - 指标：任务成功率；也做 open-loop（MSE）评估
- 训练方式

  - 训练方法：流匹配动作训练 + 联合训练目标（N1.5 起加入 FLARE 未来隐表示对齐损失，便于利用人体视频）
  - 训练范围
    - 大规模预训练（N1.6 为 300K 步、global batch 16384）
    - 特定本体/任务后训练（10K~30K 步，batch 1K 以下），配套 DAgger、RTC 等实机纠偏手段
