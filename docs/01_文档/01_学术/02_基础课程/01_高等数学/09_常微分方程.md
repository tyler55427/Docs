# 常微分方程

## 基本概念

**$n$ 阶常微分方程**：联系自变量 $x$、未知函数 $y = y(x)$ 及其导数 $y^{(j)}(x)$（$0 < j \leq n$）的方程

$$F(x, y, y', \cdots, y^{(n)}) = 0$$

**阶数**：最高阶导数的阶数。

**解**：代入方程使其成为恒等式的函数。

**通解**：含 $n$ 个独立任意常数的解 $y = \varphi(x; C_1, \cdots, C_n)$。

**独立性条件**：$\dfrac{D(\varphi, \varphi', \cdots, \varphi^{(n-1)})}{D(C_1, \cdots, C_n)} \neq 0$

**通积分**：隐函数形式的通解 $\phi(x, y; C_1, \cdots, C_n) = 0$

**特解**：由初始条件 $y(x_0) = y_0,\ y'(x_0) = y_1, \ldots$ 确定的解。

**初值问题**：求 $F(x, y, \ldots) = 0$ 满足 $\begin{cases} y(x_0) = y_0 \\ \cdots \\ y^{(n-1)}(x_0) = y_{n-1} \end{cases}$ 的解。

**积分曲线**：解对应的曲线。

## 初等积分法

### 可分离变量方程

$$\frac{dy}{dx} = f(x) \cdot g(y)$$

**解法**：分离变量 $\dfrac{dy}{g(y)} = f(x)\,dx$，两边积分。

### 可化为变量分离的方程

**① $\dfrac{dy}{dx} = f(ax + by + c)$**

令 $z = ax + by + c$，则 $\dfrac{dz}{dx} = a + b\,\dfrac{dy}{dx} = a + b\,f(z)$

**② 齐次方程 $\dfrac{dy}{dx} = f\left(\dfrac{y}{x}\right)$**

令 $u = \dfrac{y}{x}$，则 $y = ux,\ y' = u'x + u$，代入化为可分离变量方程：$f(u) = \dfrac{du}{dx}x + u$

**③ $\dfrac{dy}{dx} = f\left(\dfrac{a_1 x + b_1 y + c_1}{a_2 x + b_2 y + c_2}\right)$**

- 若 $c_1 = c_2 = 0$，化为 ②
- 若 $\begin{vmatrix} a_1 & b_1 \\ a_2 & b_2 \end{vmatrix} \neq 0$，方程组 $a_i x + b_i y + c_i = 0$ 有唯一解 $(x_0, y_0)$，令 $X = x - x_0,\ Y = y - y_0$，化为 ②
- 若 $(a_2, b_2) = k(a_1, b_1)$，令 $z = a_1 x + b_1 y$，化为可分离变量方程

### 一阶线性微分方程

$$\frac{dy}{dx} + P(x)y = Q(x)$$

**① 齐次情形**（$Q(x) \equiv 0$）：

$$y = Ce^{-\int_{x_0}^x P(t)\,dt} \quad \text{（通解包含一切解）}$$

**② 非齐次情形**：

**通解公式**：

$$y = e^{-\int P(x)\,dx} \left(\int Q(x)\,e^{\int P(x)\,dx}\,dx + C\right)$$

**常数变易法**：先解齐次方程得 $y = Ce^{-\int P\,dx}$，将 $C$ 换为 $u(x)$ 代入原方程求特解。

**解的结构**：通解 = 一个特解 + 对应齐次方程的通解。

**伯努利方程**：

$$y' + P(x)y = Q(x) y^\alpha \quad (\alpha \neq 0, 1)$$

令 $z = y^{1-\alpha}$，得 $\dfrac{1}{1-\alpha}\dfrac{dz}{dx} + P(x)z = Q(x)$（化为线性方程）。

### 全微分方程与积分因子

#### 全微分方程

$$du(x,y) = P(x,y)\,dx + Q(x,y)\,dy = 0$$

**判定条件**：

$$\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}$$

通积分 $u(x,y) = C$（包含一切解）。

#### 积分因子

设方程 $M(x,y)\,dx + N(x,y)\,dy = 0$ 不是恰当方程。若存在 $\mu(x,y) \neq 0$ 使 $\mu M\,dx + \mu N\,dy = 0$ 是恰当方程，则 $\mu$ 为积分因子。

积分因子需满足：

$$N\frac{\partial\mu}{\partial x} - M\frac{\partial\mu}{\partial y} = \mu\left(\frac{\partial M}{\partial y} - \frac{\partial N}{\partial x}\right)$$

**命题 1**：若 $\dfrac{\partial M/\partial y - \partial N/\partial x}{N}$ 仅依赖于 $x$（记 $F(x)$），则

$$\mu(x) = e^{\int F(x)\,dx}$$

是积分因子。

**命题 2**：若 $\dfrac{\partial N/\partial x - \partial M/\partial y}{M}$ 仅依赖于 $y$（记 $G(y)$），则

$$\mu(y) = e^{\int G(y)\,dy}$$

是积分因子。

### 可降阶的二阶微分方程

**(1) 不含 $y$**：$F(x, y', y'') = 0$，令 $z = y'$（变为 $z$ 关于 $x$ 的一阶方程）。

**(2) 不含 $x$**：$F(y, y', y'') = 0$，令 $p = y'$，则 $y'' = p\,\dfrac{dp}{dy}$（变为 $p$ 关于 $y$ 的一阶方程）。

## 微分方程解的存在唯一性定理

**李普希茨条件**：$|f(x, y_1) - f(x, y_2)| \leq L|y_1 - y_2|$

**定理** 设初值问题中 $f(x,y)$ 在闭矩形域

$$R = \{(x,y) \mid |x-x_0| \leq a,\ |y-y_0| \leq b\}$$

上连续，且对 $y$ 满足李氏条件，则在区间 $[x_0 - h, x_0 + h]$ 上有且只有一个解，其中

$$h = \min(a, b/M), \quad M = \max\{|f(x,y)| \mid (x,y) \in R\}$$

## 高阶线性微分方程

### 二阶线性方程解的存在唯一性

设 $p(x), q(x), f(x)$ 在 $[a,b]$ 连续，则初值问题

$$\begin{cases} y'' + p(x)y' + q(x)y = f(x) \\ y(x_0) = y_0,\ y'(x_0) = y_1 \end{cases}$$

在 $[a,b]$ 内存在唯一的解 $y(x)$。

### 线性相关与线性无关

$m$ 个函数 $\varphi_1(x), \ldots, \varphi_m(x)$ 在 $[a,b]$ **线性相关** $\Leftrightarrow$ 存在不全为零的 $k_1, \ldots, k_m$ 使

$$k_1\varphi_1(x) + \cdots + k_m\varphi_m(x) \equiv 0$$

否则线性无关。

### 齐次方程通解结构

**定理 2**：若 $y_1(x), y_2(x)$ 是齐次方程的两个解，则 $C_1 y_1 + C_2 y_2$ 也是解。

**朗斯基行列式**：

$$W(x) = \begin{vmatrix} \varphi_1(x) & \varphi_2(x) \\ \varphi_1'(x) & \varphi_2'(x) \end{vmatrix}$$

$y_1, y_2$ 线性相关 $\Leftrightarrow$ $W(x) \equiv 0$；线性无关 $\Leftrightarrow$ $W(x) \not\equiv 0$。

**定理 3**：若 $\varphi_1, \varphi_2$ 是齐次方程的两个线性无关解，则

$$C_1\varphi_1(x) + C_2\varphi_2(x) \quad (C_1, C_2 \text{ 为任意常数})$$

是通解（包含一切解）。

**推广（$n$ 阶）**：$n$ 阶齐次线性方程的 $n$ 个线性无关解的线性组合构成通解。

### 非齐次方程通解结构

**定理 5**：$y^*(x)$ 是非齐次方程的一个特解，$C_1\varphi_1 + C_2\varphi_2$ 是对应齐次方程的通解，则

$$y(x) = C_1\varphi_1(x) + C_2\varphi_2(x) + y^*(x)$$

是非齐次方程的通解（包含一切解）。

**定理 6**（叠加原理）：若 $y_1, y_2$ 分别是非齐次方程 $y'' + py' + qy = f_1$ 和 $f_2$ 的解，则 $y_1 + y_2$ 是 $f_1 + f_2$ 的解。

## 二阶线性常系数微分方程

### 齐次方程 $y'' + py' + qy = 0$

**特征方程**：$\lambda^2 + p\lambda + q = 0$

| 特征根 | 对应的线性无关特解 |
|--------|---------|
| 两不等实根 $\lambda_1 \neq \lambda_2$ | $e^{\lambda_1 x}, e^{\lambda_2 x}$ |
| 两相等实根 $\lambda$ | $e^{\lambda x}, xe^{\lambda x}$ |
| 共轭复根 $\lambda = \alpha \pm \beta i$ | $e^{\alpha x}\cos\beta x,\ e^{\alpha x}\sin\beta x$ |
| $k$ 重实根 $\lambda$ | $e^{\lambda x}, xe^{\lambda x}, \ldots, x^{k-1}e^{\lambda x}$ |
| $m$ 重共轭复根 $\alpha \pm \beta i$ | $e^{\alpha x}\cos\beta x,\ e^{\alpha x}\sin\beta x,\ xe^{\alpha x}\cos\beta x,\ xe^{\alpha x}\sin\beta x,\ \ldots$ |

通解形式：
- 不等实根：$y = C_1 e^{\lambda_1 x} + C_2 e^{\lambda_2 x}$
- 等实根：$y = (C_1 + C_2 x) e^{\lambda x}$
- 共轭复根：$y = e^{\alpha x}(C_1\cos\beta x + C_2\sin\beta x)$

### 非齐次特解的待定系数法（$y'' + py' + qy = f(x)$）

**类型 1**：$f(x) = P_n(x)$（$n$ 次多项式）

| 条件 | 特解形式 |
|------|---------|
| $q \neq 0$（0 不是特征根） | $Q_n(x)$ |
| $q = 0,\ p \neq 0$（0 是单根） | $xQ_n(x)$ |
| $q = 0,\ p = 0$（0 是重根） | $x^2 Q_n(x)$ |

**类型 2**：$f(x) = ae^{ax}$

| 条件 | 特解形式 |
|------|---------|
| $a$ 不是特征根（$a^2 + pa + q \neq 0$） | $Ae^{ax}$ |
| $a$ 是单根（$2a + p \neq 0$） | $Axe^{ax}$ |
| $a$ 是重根（$2a + p = 0$） | $Ax^2 e^{ax}$ |

**类型 3**：$f(x) = a\cos\beta x + b\sin\beta x$

| 条件 | 特解形式 |
|------|---------|
| $\pm i\beta$ 不是特征根 | $A\cos\beta x + B\sin\beta x$ |
| $\pm i\beta$ 是特征根 | $x(A\cos\beta x + B\sin\beta x)$ |

**复合类型**：$f(x) = P_n(x) e^{ax}$ 或 $f(x) = P_n(x) e^{ax}(a\cos\beta x + b\sin\beta x)$ 等，特解中对应乘以 $x^k$（$k$ 为对应根的重数）。

### 常数变易法

设齐次通解 $y = C_1 y_1 + C_2 y_2$，令 $C_1 = u(x)$，$C_2 = v(x)$，解方程组：

$$\begin{cases} u' y_1 + v' y_2 = 0 \\ u' y_1' + v' y_2' = f(x) \end{cases}$$

得 $u' = -\dfrac{y_2 f}{W}$，$v' = \dfrac{y_1 f}{W}$，其中 $W = y_1 y_2' - y_1' y_2$（朗斯基行列式，$\neq 0$）。

### 欧拉方程

形如 $x^2 y'' + pxy' + qy = f(x)$ 的方程，通过变量替换 $x = e^t$ 化为常系数线性方程。

## 常系数线性微分方程组

令 $y_1 = x,\ y_2 = x',\ \ldots$ 将高阶方程降为一阶方程组，用特征根法求解。
