# 五、假设检验

## 1、基本概念

### 1.1 假设与原假设

- **原/零假设** $H_0$：被检验的、通常希望保护的假设（如 $\theta = \theta_0$）
- **备/对立假设** $H_1$（或 $H_a$）：与 $H_0$ 对立的假设

### 1.2 检验的思路（小概率原理）

小概率事件在一次试验中几乎不发生。

先假定 $H_0$ 成立，构造与 $H_0$ 有关的检验统计量；

- 若统计量取值落入小概率（拒绝域），则与 $H_0$ 矛盾，**拒绝 $H_0$**；
- 否则**不拒绝 $H_0$**（"接受"是谨慎表述）。

### 1.3 两类错误

| 决策 \ 真实 | $H_0$ 真                              | $H_1$ 真                             |
| ----------- | --------------------------------------- | -------------------------------------- |
| 接受$H_0$ | 正确                                    | **第二类错误** $\beta$（取伪） |
| 拒绝$H_0$ | **第一类错误** $\alpha$（弃真） | 正确                                   |

- **显著性水平** $\alpha$ = 犯第一类错误概率的上限（控制弃真），一般取 $0.1, 0.05, 0.01$
- $\beta$ = 犯第二类错误概率；**功效** $= 1 - \beta$
- 样本固定时 $\alpha \downarrow \Rightarrow \beta \uparrow$（二者此消彼长）；同时减小需增大样本量

### 1.4 检验的一般步骤

1. 提出原假设 $H_0$ 与备择 $H_1$
2. 选定显著性水平 $\alpha$
3. 构造检验统计量（在 $H_0$ 下分布已知，含样本但不含其他未知参数）
4. 由 $H_1$ 的方向确定**拒绝域**（单侧/双侧），用分位数定界
5. 由样本计算统计量值，落入拒绝域则拒绝 $H_0$，否则不拒绝

## 2、正态分布的参数假设检验

设总体 $X \sim N(\mu, \sigma^2)$，样本 $X_1, \cdots, X_n$，显著性水平 $\alpha$。

### 2.1 单样本均值 $\mu$ 的检验

设总体 $X \sim N(\mu, \sigma^2)$，样本 $X_1,\cdots,X_n$，显著性水平 $\alpha$。

| 条件 | $H_0 \leftrightarrow H_1$ | 检验统计量 | 拒绝域 |
| --- | --- | --- | --- |
| $\sigma^2 = \sigma_0^2$ 已知 | $\mu = \mu_0 \leftrightarrow \mu \ne \mu_0$（双侧） | $Z = \dfrac{\bar{X}-\mu_0}{\sqrt{\sigma_0^2/n}} \sim N(0,1)$ | $\|Z\| \ge z_{\alpha/2}$ |
| 同上 | $\mu \le \mu_0 \leftrightarrow \mu > \mu_0$（右侧） | 同上 | $Z \ge z_\alpha$ |
| 同上 | $\mu \ge \mu_0 \leftrightarrow \mu < \mu_0$（左侧） | 同上 | $Z \le -z_\alpha$ |
| $\sigma^2$ 未知 | $\mu = \mu_0 \leftrightarrow \mu \ne \mu_0$（双侧） | $T = \dfrac{\bar{X}-\mu_0}{\sqrt{S^2/n}} \sim t(n-1)$ | $\|T\| \ge t_{\alpha/2}(n-1)$ |
| 同上 | $\mu \le \mu_0 \leftrightarrow \mu > \mu_0$（右侧） | 同上 | $T \ge t_\alpha(n-1)$ |
| 同上 | $\mu \ge \mu_0 \leftrightarrow \mu < \mu_0$（左侧） | 同上 | $T \le -t_\alpha(n-1)$ |

> **单侧检验的构造要点**：令 $Z^* = \dfrac{\bar{X}-\mu}{\sigma_0/\sqrt{n}}$（或 $T^*$ 用 $S^2$），
> 则 $Z^* \sim N(0,1)$，$T^* \sim t(n-1)$，与用 $\mu_0$ 替换的 $Z$ 比较：
> $H_0: \mu \le \mu_0$ 时 $Z \le Z^*$，$H_0: \mu \ge \mu_0$ 时 $Z \ge Z^*$。
> 由 $P(Z^* \ge z_\alpha) = \alpha$ 推出 $P(Z \ge z_\alpha) \le \alpha$（右侧检验），左侧检验类似。

### 2.2 单样本方差 $\sigma^2$ 的检验（$\chi^2$ 检验）

$\mu$ 未知，检验统计量

$$
W = \frac{1}{\sigma_0^2}\sum(X_i - \bar{X})^2 = \frac{(n-1)S^2}{\sigma_0^2} \sim \chi^2(n-1)
$$

| $H_0 \leftrightarrow H_1$ | 拒绝域 |
| --- | --- |
| $\sigma^2 = \sigma_0^2 \leftrightarrow \sigma^2 \ne \sigma_0^2$（双侧） | $W \le \chi^2_{1-\alpha/2}(n-1)$ 或 $W \ge \chi^2_{\alpha/2}(n-1)$ |
| $\sigma^2 \le \sigma_0^2 \leftrightarrow \sigma^2 > \sigma_0^2$（右侧） | $W \ge \chi^2_\alpha(n-1)$ |
| $\sigma^2 \ge \sigma_0^2 \leftrightarrow \sigma^2 < \sigma_0^2$（左侧） | $W \le \chi^2_{1-\alpha}(n-1)$ |

> **构造要点**：令 $W^* = \dfrac{1}{\sigma^2}\sum(X_i-\bar{X})^2 \sim \chi^2(n-1)$，
> $W \le W^*$（$H_0: \sigma^2 \le \sigma_0^2$），故 $P(W \ge \lambda) \le P(W^* \ge \lambda) = \alpha$。

## 3、两个正态总体的参数假设检验

设 $X \sim N(\mu_1, \sigma_1^2)$，$Y \sim N(\mu_2, \sigma_2^2)$，样本量分别为 $n_1, n_2$。

### 3.1 均值差 $\mu_1 - \mu_2$ 的检验

| 条件                                         | 检验统计量                                                                              | 分布             |
| -------------------------------------------- | --------------------------------------------------------------------------------------- | ---------------- |
| $\sigma_1^2, \sigma_2^2$ 已知（$Z$）     | $Z = \dfrac{(\bar{X}-\bar{Y})-(\mu_1-\mu_2)}{\sqrt{\sigma_1^2/n_1 + \sigma_2^2/n_2}}$ | $N(0,1)$       |
| $\sigma_1^2=\sigma_2^2$ 未知（合并 $t$） | $T = \dfrac{(\bar{X}-\bar{Y})-(\mu_1-\mu_2)}{S_w\sqrt{1/n_1+1/n_2}}$                  | $t(n_1+n_2-2)$ |

$H_0: \mu_1 = \mu_2$ vs $H_1: \mu_1 \ne \mu_2$（双侧），拒绝域 $\|T\| \ge t_{\alpha/2}(\nu)$。

合并方差 $S_w^2 = \dfrac{(n_1-1)S_1^2 + (n_2-1)S_2^2}{n_1+n_2-2}$。

### 3.1.5 预备：$F$ 分布

方差比检验的统计量依赖 $F$ 分布，先给出定义和性质。

**$F$ 分布定义**：称 $X$ 服从**第一自由度 $m$、第二自由度 $n$** 的 $F$ 分布，记 $X \sim F_{m,n}$，若其密度为

$$
p(x) = \frac{\Gamma\!\left(\dfrac{m+n}{2}\right)\,m^{m/2}\,n^{n/2}}{\Gamma(m/2)\,\Gamma(n/2)} \cdot \frac{x^{m/2-1}}{(n+mx)^{(m+n)/2}}\, I_{(0,+\infty)}(x)
$$

**定理**：设 $m+n$ 个相互独立且都服从 $N(\mu,\sigma^2)$ 的随机变量 $X_1,\cdots,X_m, Y_1,\cdots,Y_n$，令

$$
U = \frac{1}{m-1}\sum_{i=1}^{m}(X_i-\bar{X})^2,\quad V = \frac{1}{n-1}\sum_{j=1}^{n}(Y_j-\bar{Y})^2
$$

则

$$
F = \frac{U}{V} \sim F_{m-1,\ n-1}
$$

即两独立样本方差之比（用无偏样本方差 $U, V$）服从 $F$ 分布。

**$F$ 分布的对称性**：

1. $\xi \sim F_{n,m} \Leftrightarrow 1/\xi \sim F_{m,n}$
2. $F_{n,m}(1-\alpha)\cdot F_{m,n}(\alpha) = 1$

> 性质 1 告诉我们求 $F_{1-\alpha}(n-1,n-2)$ 时，可先求 $F_\alpha(n-2,n-1)$ 再取倒数。

### 3.2 方差比 $\sigma_1^2/\sigma_2^2$ 的检验（$F$ 检验）

$H_0: \sigma_1^2 = \sigma_2^2$（方差齐性检验），统计量

$$
F = \frac{S_1^2}{S_2^2} \sim F(n_1-1,\ n_2-1)
$$

| $H_1$                       | 拒绝域                                                                         |
| ----------------------------- | ------------------------------------------------------------------------------ |
| $\sigma_1^2 \ne \sigma_2^2$ | $F \le F_{1-\alpha/2}(n_1-1, n_2-1)$ 或 $F \ge F_{\alpha/2}(n_1-1, n_2-1)$ |
| $\sigma_1^2 > \sigma_2^2$   | $F \ge F_\alpha(n_1-1, n_2-1)$                                               |

实际计算时常将样本方差大的放分子，使 $F \ge 1$，再用 $F_{\alpha/2}$ 判断以简化（只查上侧分位）。

### 3.3 常见检验方法对照

| 检验对象                 | 统计量                                                               | 条件                                | 检验名称        |
| ------------------------ | -------------------------------------------------------------------- | ----------------------------------- | --------------- |
| 单样本均值（方差已知）   | $Z = \dfrac{\bar{X}-\mu_0}{\sigma/\sqrt{n}}$                       | $\sigma^2$ 已知                   | $Z$ 检验      |
| 单样本均值（方差未知）   | $T = \dfrac{\bar{X}-\mu_0}{S/\sqrt{n}}$         | 小样本$t(n-1)$ | $t$ 检验                          |                 |
| 单样本方差               | $\chi^2 = \dfrac{(n-1)S^2}{\sigma_0^2}$                            | $\mu$ 未知                        | $\chi^2$ 检验 |
| 两均值差（方差相等未知） | $T = \dfrac{\bar{X}-\bar{Y}}{S_w\sqrt{\cdots}}$                    | $t(n_1+n_2-2)$   | 合并$t$ 检验 |                 |
| 两方差齐性               | $F = S_1^2/S_2^2$                                                  | $F(n_1-1,n_2-1)$                  | $F$ 检验      |

**惯例**：检验方差齐性一般作为均值检验（选合并 $t$ 还是近似 $t$）的前置步骤——先 $F$ 检验判断方差是否相等，再据此选择均值差检验形式。
