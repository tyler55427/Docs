# 特征值与特征向量

## 特征值与特征向量

### 定义

设 $A$ 为 $n$ 阶方阵，若存在数 $\lambda$ 和非零向量 $x$ 使

$$Ax = \lambda x$$

则称 $\lambda$ 为 $A$ 的**特征值**，$x$ 为对应的**特征向量**。

### 特征多项式

$$|A - \lambda I| = 0$$

称为 $A$ 的**特征方程**，左端为**特征多项式** $f(\lambda) = |A - \lambda I|$，是 $\lambda$ 的 $n$ 次多项式。

- 特征值是特征方程的根，$n$ 阶方阵在复数范围内有 $n$ 个特征值（计重数）
- **代数重数**：特征值作为特征多项式根的重数

### 求特征值、特征向量的步骤

1. 求特征多项式 $f(\lambda) = |A - \lambda I|$（或 $|\lambda I - A|$，二者至多差符号）
2. 解 $f(\lambda) = 0$ 得全部特征值 $\lambda_1, \cdots, \lambda_n$
3. 对每个 $\lambda_i$，解齐次方程组 $(A - \lambda_i I)x = 0$，其基础解系即为属于 $\lambda_i$ 的线性无关特征向量

### 特征向量的几何意义

$Ax = \lambda x$ 表示 $x$ 经线性变换 $A$ 作用后**方向不变**（$\lambda > 0$）或**反向**（$\lambda < 0$），仅长度伸缩 $|\lambda|$ 倍；$\lambda = 0$ 时 $x$ 被压缩为零向量。

## 性质

### 特征值的重要性质

设 $A$ 的特征值为 $\lambda_1, \cdots, \lambda_n$：

- **迹**：$\mathrm{tr}(A) = \sum_{i} \lambda_i = \sum_i a_{ii}$
- **行列式**：$|A| = \prod_{i} \lambda_i$（故 $A$ 可逆 $\Leftrightarrow$ 特征值均非零）
- $A^T$ 与 $A$ 有相同特征值（特征多项式相同）
- $A^k$ 的特征值为 $\lambda_i^k$
- $kA$ 的特征值为 $k\lambda_i$
- $A + kI$ 的特征值为 $\lambda_i + k$
- $f(A)$ 的特征值为 $f(\lambda_i)$（$f$ 为多项式）
- 若 $A$ 可逆：$A^{-1}$ 特征值为 $1/\lambda_i$；$A^*$ 特征值为 $|A|/\lambda_i$

### 特征向量的性质

- 一个特征向量只属于一个特征值
- 属于同一特征值的特征向量的非零线性组合仍是该特征值的特征向量
- 属于不同特征值的特征向量**线性无关**
- **几何重数**（$\lambda_i$ 对应特征子空间维数 $n - r(A - \lambda_i I)$）$\le$ 代数重数

## 相似矩阵

### 定义

设 $A, B$ 为 $n$ 阶方阵，若存在可逆阵 $P$ 使 $P^{-1}AP = B$，称 $A$ 与 $B$ **相似**，记 $A \sim B$。

**线性变换视角**：相似矩阵是同一线性变换在不同基下的表示。

### 相似的性质

若 $A \sim B$，则：
- $|A| = |B|$，$\mathrm{tr}(A) = \mathrm{tr}(B)$
- $r(A) = r(B)$
- $A, B$ 有相同特征多项式与特征值（代数重数相同）
- $A^k \sim B^k$，$f(A) \sim f(B)$
- $A$ 可逆 $\Leftrightarrow B$ 可逆，且 $A^{-1} \sim B^{-1}$

相似是等价关系（自反、对称、传递），但相似比等价（秩相同）更强。

## 矩阵的对角化

### 可对角化条件

$A$ 可对角化（$\exists P$ 可逆使 $P^{-1}AP = \Lambda$ 对角）$\Leftrightarrow$ $A$ 有 $n$ 个线性无关的特征向量。

**充分条件**：$A$ 有 $n$ 个互异特征值 $\Rightarrow$ 可对角化。

**充要条件**：每个特征值的**几何重数 = 代数重数**，即 $n - r(A - \lambda_i I) = $ $\lambda_i$ 作为根的重数。

**实对称阵**必可对角化（进一步可正交对角化，见二次型）。

### 对角化方法

1. 求特征值 $\lambda_1, \cdots, \lambda_n$（计重数）
2. 对每个特征值求特征子空间的一组基，合并得特征向量组 $p_1, \cdots, p_n$（需线性无关）
3. 令 $P = (p_1, \cdots, p_n)$，则

$$P^{-1}AP = \mathrm{diag}(\lambda_1, \cdots, \lambda_n) = \Lambda$$

$P$ 的列次序与 $\Lambda$ 对角元次序一致。

### 对角化的应用

**求 $A^k$**：若 $A = P\Lambda P^{-1}$，则

$$A^k = P \Lambda^k P^{-1} = P\, \mathrm{diag}(\lambda_1^k, \cdots, \lambda_n^k)\, P^{-1}$$

**求矩阵多项式**：$f(A) = P\, \mathrm{diag}(f(\lambda_1), \cdots, f(\lambda_n))\, P^{-1}$

### 几何重数判定不可对角化的典型例子

$A = \begin{pmatrix} 1 & 1 \\ 0 & 1 \end{pmatrix}$：特征值 $\lambda = 1$（二重），$r(A - I) = 1$，几何重数 $= 1 < 2$，不可对角化（**若尔当块**）。

## 哈密顿—凯莱定理

### 定理

任意方阵 $A$ 满足其自身的特征多项式：

$$f(A) = 0$$

其中 $f(\lambda) = |A - \lambda I|$（或 $|\lambda I - A|$）。

### 应用

用于降次计算矩阵多项式：把高次多项式 $g(A)$ 用特征多项式 $f(\lambda)$ 除得 $g(\lambda) = q(\lambda)f(\lambda) + r(\lambda)$，则 $g(A) = q(A) f(A) + r(A) = r(A)$（因 $f(A) = 0$），只需算余式 $r(A)$。

**例**：$A^{-1}$ 可由特征多项式表示：若 $f(\lambda) = \lambda^n + c_{n-1}\lambda^{n-1} + \cdots + c_1 \lambda + c_0$，$A$ 可逆（$c_0 = (-1)^n |A| \neq 0$），则

$$A^{-1} = -\frac{1}{c_0}(A^{n-1} + c_{n-1}A^{n-2} + \cdots + c_1 I)$$
