## 6.2 文件组织

### 记录组织方式

### 固定长度记录
- 顺序存放
- 删除：后面前移 或 将最后移到空 或 维护 free list

### 可变长度记录
- 标记法：插入、删除困难
- 指针方法：锚定块 + 溢出块

### 文件组织类型

| 类型 | 说明 |
|:---:|:---|
| 堆文件(Heap) | 有空间就放 |
| 顺序文件 | 按搜索键值顺序 |
| 哈希文件 | hash 到桶 |

## 6.3 索引

### 顺序索引

| 类型 | 说明 |
|:---:|:---|
| 主索引/聚合索引 | 文件按搜索键排序 |
| 辅助索引/非聚合索引 | 文件不是按搜索键排序 |

| 类型 | 说明 |
|:---:|:---|
| 稀疏索引 | 仅包含某些搜索键建的索引 |
| 稠密索引 | 包含所有搜索键建的索引 |

### 多级索引
- 内部索引：主索引
- 外部索引：主索引的稀疏索引

## 6.4 B+ 树

### 性质
- 从根到叶子的所有路径都具有相同的长度
- 每个节点都有 ⌈n/2⌉ 到 n 个指针
- 每个叶节点存储 ⌊(n-1)/2⌋ 到 n-1 个数据值
- 根至少有两个子节点

### 操作
- **查找**：从根开始，找最后一个 kᵢ₋₁ ≤ a < kᵢ 的指针
- **插入**：有空位直接插入，否则分裂
- **删除**：超过半数从兄弟节点借，否则合并

## 6.5 动态哈希

### 特点
- 使用指向桶的指针目录
- 桶拆分时重新索引
- local depth vs global depth

### 操作
- **插入**：满了增加 local depth
- **删除**：桶变空与镜像合并

## 6.6 其他索引

### 位图索引
- 对每个 key 建一个位图
- 查找用 AND/OR/NOT

### 网格索引
- 维度对应搜索键个数
- 轴对应搜索键取值个数
