# 八、事务与恢复
## 8.1 事务

### ACID 属性

| 属性 | 说明 |
|:---:|:---|
| Atomicity | 原子性：要么全部完成，要么全部不执行 |
| Consistency | 一致性：从一个一致性状态变到另一个 |
| Isolation | 隔离性：事务执行不受其他事务干扰 |
| Durability | 持久性：已提交事务的改变不被丢失 |

### 事务状态
- **Active**：活动状态
- **Partially Committed**：最后一条语句执行后
- **Failed**：不能正常执行
- **Aborted**：回滚，恢复到执行前状态
- **Committed**：提交成功

## 8.2 并发问题

### 三类数据不一致性
1. **丢失修改**：同时读数据，覆盖另一个的修改
2. **不可重复读**：T₁ 两次读取数据不同
3. **读脏数据**：读取了被撤销的数据

## 8.3 可串行性

### 冲突
两个事务访问同一数据项，至少有一个是 write：
- <r,w>, <w,r>, <w,w>

### 优先图
若两个事务冲突且 Tᵢ 较早处理，画 Tᵢ → Tⱼ 的边

**图存在环 → 不可串行化**

## 8.4 并发控制协议

### 锁

| 类型 | 说明 |
|:---:|:---|
| 独占锁(X) | 可读可写 |
| 共享锁(S) | 只读 |

### 两阶段锁协议(2PL)
- **生长阶段**：可以申请新锁，但不能释放任何锁
- **收缩阶段**：可以释放锁，但不能申请新锁

**变体**：严格 2PL、强严格 2PL

### 时间戳协议
- W-timestamp(Q)：最后执行 write 的时间戳
- R-timestamp(Q)：最后执行 read 的时间戳

## 8.5 恢复

### 故障类型
| 类型 | 说明 |
|:---:|:---|
| 事务故障 | 内部逻辑错误 |
| 系统故障 | 硬件故障 |
| 磁盘故障 | 磁头划伤 |

### 日志
记录数据库修改的序列信息：
- `<Tᵢ, start>`
- `<Tᵢ, X, V₁, V₂>`：写前值和新值
- `<Tᵢ, commit>`

### 恢复操作
- **撤销(Undo)**：恢复旧值
- **重做(Redo)**：更新为新值

### 检查点
定期将事务副本/缓存写入磁盘，记录检查点

### 影子页面
维护当前页表和影子页表，修改时在拷贝页进行，恢复时使用影子页表
