# 二、进程描述与控制

## 2.1 进程的基本概念

- 顺序执行（单道单线程）

  - 顺序性
  - 封闭性：独占资源
  - 可再现性：与执行速度无关
- 并发执行（多道单线程、单道多线程）

  - 间断性：共享资源→相互制约→执行-暂停-执行
  - 失去封闭性
  - 不可再现性（即使实现互斥和同步）

### 进程的各种定义

- 进程是程序的一次执行
- 进程是正在运行的一个程序实例
- 进程是分配给处理器并由处理器执行的实体
- 进程是可以和别的计算并发执行的计算
- 进程是一个数据结构及能在其上进行操作的一个程序
- 进程是一个程序及其数据在处理机上顺序执行时所发生的活动
- 进程是程序在一个数据集上的运行过程，是系统进行资源分配和调度的一个独立单位

### 进程的特征

- **动态性**：一定的生命周期
- **并发性**：一段时间同时运行存在内存中的多个实体
- **独立性**：进程实体是一个独立运行的基本单位
- **异步性**：独立的、不可预知的速度运行
- **结构特征**：由程序段、数据段、进程控制块（PCB）组成

## 2.2 进程控制块（PCB）

- PCB 描述进程、管理和调度进程，包含信息：

  - 状态符
  - 状态
  - 优先级
  - 程序计数器
  - 内存指针
  - 上下文数据
  - I/O 状态信息
  - 记账信息
- PCB 的组织

  - **链表**：同状态进程的 PCB 成一个链表
  - **虚存**：将物理内存映射到大的连续的空间，方便进程内存使用逻辑
  - **作用**：进程调度、资源分配、中断处理、性能监控和分析

### 进程映像（Process Image）

- 用户数据、用户程序（位置由 OS 决定）
- 系统栈
- 进程控制块

## 2.3 进程状态

### 状态模型

- 两状态模型

  - 运行态、未运行态
- 三状态模型（三个基本）

  - 运行态（Running）
  - 就绪态（Ready）
  - 阻塞态/等待态（Blocked）
- 五状态模型

  - 运行态（Running）
  - 就绪态（Ready）
  - 阻塞态/等待态（Blocked）
  - 挂起就绪态（Suspended Ready）
  - 挂起阻塞态（Suspended Blocked）

### 进程的挂起状态

- **交换 (Swapping)**：进程映像整体/部分从主存转移到辅存（换出）
- **挂起 (Suspended)**：未处于就绪态的进程
- **激活 (Active)**：处于就绪态的进程

**引入原因：**

- 物理内存不足
- CPU 时间浪费
- 调度策略需要

## 2.4 进程的创建与终止

### 创建原语的主要操作

1. 给新进程分配一个唯一的进程标识号
2. 给进程分配空间
3. 初始化进程控制块
4. 设置正确的链接
5. 创建或扩充其他数据结构（如审计文件）

### 进程的撤销

1. 撤销该进程的所有子进程
2. 收回进程所占用的资源
3. 撤销该进程的 PCB

## 2.5 进程控制

### 执行模式

- 特权指令
- 非特权指令

### 内核（Kernel）

OS 中重要系统功能，驻留在主存，特权态，响应系统功能调用/服务的中断。

**功能：**

- 进程管理
- 存储管理
- I/O 管理

**支持功能：** 中断处理、审计、监视

### 程序状态字（PSW）

模式切换：

$$
\begin{cases} \text{用户} \rightarrow \text{系统}：\text{中断} \\ \text{系统} \rightarrow \text{用户}：\text{修改 PSW} \end{cases}
$$

### 进程切换时机

**外部中断/硬中断：**

- 时钟中断：时间片到
- I/O 中断：I/O 完成，高优先级进程就绪
- 内存失效：调页时阻塞

**内部中断/软中断：**

- 陷阱：系统调用
- 异常：指令出错

### 进程切换步骤

1. 保存当前正在执行的程序的上下文环境
2. 更新当前进程的 PCB，如改变进程状态为阻塞态
3. 将进程控制块移到相应的队列
4. 选择另一个就绪进程
5. 更新所选进程的 PCB，如改变进程状态为运行态
6. 更新内存转换机构的数据
7. 恢复所选进程的 CPU 上下文环境

## 2.6 OS 的控制结构

### 操作系统控制表的通用结构

- **内存表**：内存位置
- **I/O 表**：设备状态
- **文件表**：文件信息
- **进程表**：主进程表

### 进程属性

- **进程标识信息：** 进程 ID、父进程 ID、用户 ID
- **处理器状态信息：** 寄存器、栈指针
- **控制信息：**
  - 调度和状态信息
  - 数据结构
  - 进程间通信
  - 进程特权
  - 存储管理
  - 资源所有权和使用情况
