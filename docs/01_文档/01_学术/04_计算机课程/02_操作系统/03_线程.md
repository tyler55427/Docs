# 三、线程

## 3.1 线程的概念

**多线程：** 操作系统支持在一个进程中执行多个线程的能力

**进程含多线程：**

- 进程管理资源
- 线程负责指令的执行

**使用线程原理：**

- 进程切换开销大：保存/恢复进程的全部信息
- 进程占用资源多：同类进程占用多份资源，一个进程多线程共享一份资源

## 3.2 多线程环境下的进程和线程

### 进程/任务

资源分配和保护单位

- 拥有用于保存进程映像的虚拟地址空间
- 受保护地访问处理器、其他进程、文件和 I/O 资源

### 线程

分派的执行单位

- 执行状态（运行、就绪等）
- 线程上下文（非运行时）
- 一个执行线
- 存储局部变量的动态存储空间
- 对进程的内存和其他资源的访问（同进程其他线程共享）

## 3.3 线程优点

- 创建/终止快（在进程内）
- 切换时间少（保存/恢复少）
- 通信效率高（同一进程内，无需内核，利用共享的存储空间）

## 3.4 线程分类

|      类型      | 说明                                          | 优点                                           | 缺点                                         |
| :-------------: | :-------------------------------------------- | :--------------------------------------------- | :------------------------------------------- |
| 用户级线程(ULT) | 线程库管理，内核不知道线程存在                | 无模式切换；<br />调度算法自由；<br />无需内核 | 线程阻塞导致进程阻塞；<br />不能利用多处理器 |
| 内核级线程(KLT) | 调度基于线程进行，内核完成管理                | 线程阻塞不导致进程阻塞；<br />利用多核和多处理 | 线程切换要模式切换                           |
|    组合方法    | 线程创建在用户空间完成，n个 KLT 支持 m 个 ULT | 结合两者优点                                   | 实现复杂                                     |

### 线程与进程的关系模型

| 关系 | 描述                           | 示例系统                                  |
| :--: | :----------------------------- | :---------------------------------------- |
| 1:1 | 每个进程有唯一线程             | DOS、传统 Unix                            |
| M:1 | 一个进程可拥有多个线程         | Windows NT、Solaris、Linux、Mac OS X、iOS |
| 1:M | 一个线程可在多个进程环境中迁移 | RS(Clouds)、Emerald                       |
| M:N | M:1+1:M                        | Trix                                      |

## 3.5 多核与多线程

### 对称多处理（SMP）

- 多个处理器执行相同的功能，内核可运行在任一处理器
- 处理器从进程和线程池完成的调度工作

### 计算机分类

- SISD（单处理器）
- SIMD（向量机）
- MISD（GPU）
- MIMD（多核/SMP/机群）

### 多线程环境下的同步

- 线程状态：就绪、执行、阻塞
- 线程阻塞不会阻塞整个进程
- 同进程的多线程共享同一地址空间和其他资源

### 操作

- 派生（spawn）：线程可派生新线程
- 阻塞（block）
- 唤醒（unblock）
- 调度（schedule）：OS 将就绪线程调度到处理器执行
- 结束（finish）：释放寄存器上下文和栈
