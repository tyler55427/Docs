# 七、链路层和局域网

## 7.1 链路层概述

**功能：** 将帧从一个节点通过一条链路传递到另一个物理上连接的邻近节点

- 链路层服务
    - 成帧与链路接入：将数据报封装在帧中，通过MAC地址标识源和目的节点
    - 流量控制：协调相邻节点的发送速率，使收发双方速度匹配
    - 差错检测：接收方检测比特差错，通知发送方重传或直接丢弃出错帧
    - 差错纠正：接收方检测并直接修复比特错误，无需重传
    - 半双工/全双工：半双工为交替双向通信，全双工为同时双向通信

**实现：** 在每个节点均实现链路层，在网络适配器(NIC)中实现

## 7.2 差错检测和纠正

### 三种技术

- 奇偶校验
    - **一维奇偶校验**
        - 添加 1 个奇偶位，使整个数据中 1 的个数为偶（偶校验）或奇（奇校验）
        - 只能检测单个比特差错

    - **二维奇偶校验**
        - 将数据划分为行列，添加行列奇偶位
        - 可以检测并纠正单个比特错误
        - 可以检测交织比特错误

- 检验和
    - 将数据划分为 16 位字，相加取反得到检验和
    - 接收方将数据与检验和相加，结果全 1 表示无差错
    - 常用于网络层和传输层（如 IP、TCP、UDP）

- 循环冗余检测(CRC)
    - **G**：生成多项式，r+1 比特
    - **D**：待发送数据，附加 r 位 CRC 比特 R
    - 关系：`D * 2^r XOR R` 能被 G 整除
    - 特点
        - 可检测所有小于 r+1 比特的突发差错
        - 可检测所有奇数个比特差错
        - 常用 CRC：CRC-8、CRC-16、CRC-32

**示例：** D = 110111，G = 1001（r=3）

```
1. D * 2^3 = 110111000
2. 110111000 / 1001 = 111001 ... 011（余数）
3. 发送：D * 2^3 + R = 110111011
```

接收方用相同 G 去除，能整除则无错

## 7.3 多路访问协议

- 两种链路类型
    - 点对点链路：单发单收，无需调度
    - 广播链路：多发多收，需要协调

- 理想协议要求
    - 单个全速
    - 多个公平
    - 完全分散控制
    - 简单

### 三种类型

- **信道划分：** 将信道划分为多个独立子信道
    - TDMA：时分多址，按时间划分
    - FDMA：频分多址，按频率划分
    - CDMA：码分多址，按编码划分

- **随机接入：** 节点随机发送，可能发生碰撞
    - **ALOHA**
        - 纯 ALOHA：帧到达时立刻传输，碰撞概率高，效率 18%
        - 时隙 ALOHA：时间划分为等长时隙，只在时隙起点开始传输，最大效率 37%
    - **CSMA/CD（碰撞检测）**
        - 步骤：
            - 侦听信道（空闲则传输）
            - 传输中检测碰撞
            - 检测到碰撞后中止传输
            - **二进制指数后退等待**：碰撞后随机选择等待时间，k = min(碰撞次数, 10)，等待 {0, 1, ..., 2^k - 1} \* 512 bit times
        - 效率：
            $$
            \text{efficiency} = \frac{1}{1 + 5t_{prop}/t_{trans}}
            $$

- **轮流：** 结合信道划分和随机接入的优点，避免碰撞、提高效率
    - **轮询**
        - 主节点轮流邀请其他节点发送
        - 问题：轮询开销、等待时延、单点故障
    - **令牌传递**
        - 控制令牌从节点传递，令牌持有者才能发送
        - 问题：令牌开销、等待时延、单点故障

## 7.4 局域网

### 链路层寻址

- **MAC 地址**
    - 48 位 MAC 地址
    - 固化在网卡的 ROM
    - 扁平结构，可移植
    - 与 IP 层次结构不同

- **ARP（地址解析协议）**
    - 将 IP 地址转换为 MAC 地址
    - **ARP 表**：每台主机维护，存储 IP 地址到 MAC 地址的映射，格式为 (IP 地址, MAC 地址, TTL)
    - **同一 LAN 内工作流程：**
        - A 广播 ARP 查询请求分组（包含目标 IP 地址）
            - 目的IP
            - 目的MAC：广播地址（FF:FF:FF:FF:FF:FF）
        - 目标主机 B 接收后，发送 ARP 响应（包含自己的 MAC 地址）
        - A 收到响应后，将映射添加到 ARP 表
    - **跨 LAN 工作流程：**
        - **A 主机准备工作**：A 知道 B 的 IP（目标 IP），并且知道下一跳路由器 R 的 IP 和 MAC 地址（网关）（通过DHCP）
        - **下一跳 R**：提取帧，转发上层，确定转发端口和MAC地址
        - **路由器 R 处理**：
            - IP不变
            - R的出MAC
            - B的MAC
        - **B 主机接收**

### 以太网

- **特点**
    - 最流行的 LAN
    - 无连接、无可靠交付
    - 使用 CSMA/CD

**以太网帧结构**

```
前同步码 | 目的地址 | 源地址 | 类型 | 数据 | CRC
8B       | 6B       | 6B     | 2B  |      | 4B
```

### 交换机

- 特性
    - **透明**：主机无法感知
    - **即插即用、自学习**
    - **多路同时进行**

- 交换机表
    - 表项：(MAC 地址, 接口, 时间戳)
    - 自学习：收到帧时记录

**帧过滤/转发**

1. 记录源 MAC 与输入链路
2. 利用目的 MAC 检索
3. 匹配且在同一网段 -> 丢弃
4. 匹配且在不同网段 -> 转发
5. 不匹配 -> 泛洪

**交换机 vs 路由器**
| 对比 | 交换机 | 路由器 |
| :----------: | :------: | :-----: |
| 层次 | 链路层 | 网络层 |
| 转发表依据 | MAC 地址 | IP 地址 |
| 即插即用 | 是 | 否 |
| 广播风暴防护 | 无 | 有 |

### 虚拟局域网(VLAN)

- 问题
    - 缺乏流量隔离
    - 交换机低效使用
    - 管理用户困难

**基于端口的 VLAN：** 单个交换机划分多个 VLAN，每个成为独立广播域

**802.1Q 帧格式**

```
前同步码 | DA | SA | VLAN标签 | 类型 | 数据 | CRC
```

## 7.5 数据中心网络

- 组成
    - **边界路由器**：与公共 Internet 相连
    - **第一层交换机**
    - **第二层交换机**
    - **机架顶部(TOR)交换机**
    - **服务器机架**

- 目标
    - 减少成本，提高性能
    - 多路径增加吞吐量和可靠性
