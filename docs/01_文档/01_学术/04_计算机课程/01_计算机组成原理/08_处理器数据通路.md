# 九、处理器数据通路

## 指令执行过程

1. **取指 (IF)**：从指令存储器取指令
2. **译码 (ID)**：读寄存器，生成控制信号
3. **执行 (EXE)**：ALU 运算或计算地址
4. **访存 (MEM)**：访问数据存储器
5. **写回 (WB)**：结果写入寄存器

- **指令周期**：CPU 执行一条指令的完整过程（取指→译码→执行→访存→写回）
- **数据通路单元**：CPU 内部完成数据运算和传输的硬件组件，含 IR、寄存器堆、ALU、存储器、加法器、多路选择器等

## ALU 控制信号（4 位）

| 控制信号 | 功能           |
| -------- | -------------- |
| 0000     | 与             |
| 0001     | 或             |
| 0010     | 加             |
| 0110     | 减             |
| 0111     | 小于比较 (slt) |
| 1100     | 或非           |

## 控制信号

**4 个控制信号：**

| 信号           | 说明         |
| -------------- | ------------ |
| RegWrite       | 寄存器堆写入 |
| ALU操作（4位） | ALU控制信号  |
| MemRead        | 内存读       |
| MemWrite       | 内存写       |

**3 个选择信号：**

| 信号     | 说明                                  |
| -------- | ------------------------------------- |
| ALUSrc   | ALU 第二输入：0=寄存器，1=立即数      |
| PCSrc    | 下条指令：0=PC+4，1=分支目标          |
| MemtoReg | 写入寄存器数据：0=ALU结果，1=内存数据 |
