# 一、绪论
## 课程概述

**考核方式**：平时 40%（考勤 10%、作业 30%），期末 60%

**重点内容**：空间的描述和变换、正运动学、逆运动学、轨迹生成和运动规划

**掌握内容**：雅克比矩阵、动力学、机构设计、线性控制和力控制

**了解内容**：编程

**题型**：选择、判断、填空、计算、分析

## 相关概念

| 概念 | 说明 |
|------|------|
| **位姿** | 位置 + 姿态，描述物体在空间中的完整状态 |
| **自由度** | 独立位置变量的数目 |
| **末端执行器** | 操作臂运动链的自由端 |
| **转动关节** | 关节角 |
| **滑动关节** | 关节偏移量 |

## 运动学与动力学概览

位姿 — 正运动学 — 逆运动学 — 动力学 — 轨迹生成 — 线性位置控制

- **正运动学**：给定关节角，计算工具坐标系相对基坐标系的位置（关节空间 → 笛卡尔空间）
- **逆运动学**：给定末端执行器的位姿，计算关节角（笛卡尔空间 → 关节空间）
- **雅可比矩阵**：进行机构的速度分析（关节空间速度 ↔ 笛卡尔空间速度）
- **奇点**：映射不可逆（自由度减少）

## 机械臂构型与工作空间

| 类型 | 特点 |
|------|------|
| 直角坐标型 | 体积占用大，不需要 IK/FK |
| 圆柱坐标型 | — |
| 球坐标型 | — |
| 关节坐标型（铰接型/肘型） | 只用旋转，占用空间小 |
| SCARA 型 | 负载能力强（前两个转轴竖直，最后一个关节承重） |
