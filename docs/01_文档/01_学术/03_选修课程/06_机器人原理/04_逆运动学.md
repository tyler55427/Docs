# 四、逆运动学
## 定义

- **正向运动学（FK）**：给 $\theta_i$，求 $\{H\}$ 或 $^W P$
- **逆向运动学（IK）**：给 $\{H\}$ 或 $^W P$，求 $\theta_i$

$^W T$ 有 12 个参数，消去旋转矩阵的 3 个约束后剩 9 个有效方程，6 个未知数。

## 工作空间

| 类型 | 定义 |
|------|------|
| **工作空间** | 末端执行器能达到的范围（执行器末端点的位置） |
| **可达空间** | 用一种以上姿态能达到的位置（坐标系不在里面，直接无死角） |
| **灵巧空间** | 可以从各个方向到达（无穷多解），如两连杆 $l_1=l_2$ 时的原点 |

> 工作空间是子空间的一部分；$n < 6$ 时子空间为关节 $T$ 所能达到的活动范围

## 解的个数

6R 机械臂（$2 \le n \le 6$）：

| 条件 | 解的上限 |
|------|----------|
| $a_1 = a_3 = a_5 = 0$ | $\le 4$ 组 |
| $a_3 = a_4 = 0$，$a_2 = 0$ | $\le 8$ 组 |
| $\forall a_i \neq 0$ | $\le 16$ 组 |

**PUMA**：8 组解（前三轴 4 种姿态 × 每种姿态 2 组手腕）

$$\theta_4' = \theta_4 + 180^\circ, \quad \theta_5' = -\theta_5, \quad \theta_6' = \theta_6 + 180^\circ$$

### 解法

#### ① 解析法（代数/几何）

- **几何法**：找固定的三角形求解（余弦定理），相邻三轴相交一点时存在封闭解

- **代数法**：位姿矩阵与本杆传递的矩阵相同（$^0_3T^3P_4$ 等，在 $\{3\}$ 下描述 $\{W\}$ 坐标）

**PUMA 560 求解步骤**（6R，后三轴交于一点）：

1. **位移**：由 $_6^0ORG = \, _4^0ORG$ 求 $\theta_1, \theta_2, \theta_3$

   $$V = x^2 + y^2 + z^2 = q_1^2 + q_2^2 + q_3^2$$

   平方将 $\theta_1$ 变量消去，化简后对比求得

2. **姿态**：用 $Z$-$Y$-$Z$ 欧拉角求解 $\theta_4, \theta_5, \theta_6$

   $$\begin{cases}
   \theta_4 = \alpha + \epsilon \\
   \theta_5 = \beta \\
   \theta_6 = \gamma + \pi
   \end{cases}$$

   通常有 2 个解，总个数是前 3 个关节解数量的 2 倍

#### ② 数值法

迭代逼近

### 三角方程求解技巧

求 $a\cos\theta + b\sin\theta = c$ 时，用半角公式 $u = \tan\frac{\theta}{2}$ 化简：

$$\cos\theta = \frac{1-u^2}{1+u^2}, \quad \sin\theta = \frac{2u}{1+u^2}$$

$$u = \frac{-b \pm \sqrt{b^2 + a^2 - c^2}}{a+c}$$

- $b^2 + a^2 - c^2 < 0$：无解
- $a + c = 0$：$\theta = 180^\circ$
- 否则：$\theta = 2\tan^{-1}u$

> 4 次多项式有封闭形式的解

### 解的选择原则

- 当前状态最近（快速、节能）
- 避开障碍物等

### 示教点与计算点

| 类型 | 说明 |
|------|------|
| **示教点** | 直接将机械臂拉到目标点，关节位置传感器读取关节角并存储 |
| **计算点** | 不示教，用逆运动学计算关节角 |
| **重复精度** | 重复到相同位置的精度（较好），操作臂精度不会超过重复精度 |
| **操作臂精度** | 同型号不同机械臂的精度不同（较差） |
