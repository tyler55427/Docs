# 常微分方程数值解

## 基本概念

- **微分方程**：包含自变量、未知函数及其导数/微分的方程
- **自变量个数**：
  - 一个 → 常微分方程；
  - 多个 → 偏微分方程
- **阶数**：最高阶导数的阶数
- **线性**：未知函数及其导数/微分均为一次的

## 初值问题（ICV）

$$
\begin{cases} y' = f(x, y) \\ y(x_0) = y_0 \end{cases} \quad \text{在 } [a,b] \text{ 上的数值解}
$$

若 $f$ 在 $x \in [a,b]$、$y \in (-\infty, +\infty)$ 上连续，且满足**李普希兹条件**（$\exists L$ 使 $|f(x,y_1) - f(x,y_2)| \leq L|y_1 - y_2|$ 对 $\forall y_1, y_2$ 成立），则**解存在且唯一**。

问题分类：初值问题 / 边界问题

### 数值方法的基本思想

- **基本定义**：根据先验 $x_i$ 得到对应的 $y_i$，相邻为步长 $h_i$，可不相同
- **基本思想**（）："步进式"，顺点排序顺序，用 $y_0, \cdots, y_i$ 得到 $y_{i+1}$，考虑定长 $h_i = h$
- **基本方法**：用数值积分、数值微分、泰勒展开等离散化方法，对导数 $y'$ 用不同的离散化处理

**递推公式分类**：

- **单步法**：计算 $y_{i+1}$ 只用 $x_i, x_{i+1}, y_i$ —— 代表：龙格-库塔法
- **多步法**：计算 $y_{i+1}$ 还用 $x_{i-p}, y_{i-p}$ —— 代表：亚当姆斯法

## 欧拉法（折线法）

欧拉法得到初值问题的解，代表通过 $(x_0, y_0)$ 的一条称为微分方程的**积分曲线**。积分曲线上每一点的切线斜率等于函数在该点的值。

$$
y_{n+1} = y_n + f(x_n, y_n)(x_{n+1} - x_n), \quad \text{近似 } y(x) \text{ 的折线}
$$

### 不同方式推导欧拉

数值积分出发点：$\displaystyle\int_{x_i}^{x_{i+1}} y'\,dx = \int_{x_i}^{x_{i+1}} f(x, y)\,dx$

- **用左矩形积分**（向前欧拉公式）：$= (x_{i+1} - x_i)f(x_i, y(x_i))$，矩形法精度低使欧拉法精度低（显式）
- **用右矩形积分**（向后欧拉公式）：$= (x_{i+1} - x_i)f(x_{i+1}, y(x_{i+1}))$，用非线性方程隐解，（隐式）
- **用梯形公式**：$= \dfrac{x_{i+1}-x_i}{2}\left(f(x_i, y(x_i)) + f(x_{i+1}, y(x_{i+1}))\right)$，比欧拉法高一阶

  - 是左矩形和右矩形的平均
- **两步欧拉**：改用 $x_{i-1}, x_{i+1}$，得 $y_{i+1} - y_{i-1} = (x_{i+1} - x_{i-1})f(x_i, y(x_i))$（中点矩形公式），比欧拉法高一阶；需用其他方法得 $y_1$，称为**起步计算**
- 衡量标准：

  - 局部截断误差
  - 阶数

> 整体截断误差低一阶

**定义** 在 $y_i$ 准确（即 $y_i = y(x_i)$）的前提下，用数值方法计算 $y_{i+1}$ 的误差

$$
R_i = y(x_{i+1}) - y_{i+1}
$$

称为该数值方法计算时 $y_{i+1}$ 的**局部截断误差**。对欧拉法：$y(x_{i+1}) - y_{i+1} = \dfrac{h^2}{2!}y''(\xi)$。

**定义** 数值方法的局部截断误差为 $O(h^{P+1})$，则称这种数值方法的**阶数是 $P$**。

步长（$h<1$）越小、$P$ 越高，则精度越高。

**各公式来源归类**：

- 向前欧拉：向前差分 / 左矩形积分 → 预估校正
- 向后欧拉：向后差分 / 右矩形积分 → 校正前后平均
- 梯形欧拉：梯形积分 → 改进的欧拉 / 平均格式 / 二阶龙格-库塔法之一
- 多步格式 / 两步欧拉 / 中间矩形公式：中心差分

### 改进的欧拉公式

 用向前预报 $\overline{y_{i+1}}$，用梯形公式迭代一次校正得 $y_{i+1}$：

$$
\begin{cases} \text{预测：} & \overline{y_{i+1}} = y_i + h\,f(x_i, y_i) \\ \text{校正：} & y_{i+1} = y_i + \dfrac{h}{2}\left(f(x_i, y_i) + f(x_{i+1}, \overline{y_{i+1}})\right) \end{cases}
$$

> 求解 → 迭代； 显式的二阶精度； 
> 整理为数列，极限成为精确解

- **嵌入形式**：

$$
y_{i+1} = y_i + \frac{h}{2}\left[f(x_i, y_i) + f\left(x_{i+1},\, y_i + h\,f(x_i, y_i)\right)\right]
$$

- **平均化形式**（二阶龙格-库塔法的一种）：

$$
\begin{cases} y_P = y_i + h\,f(x_i, y_i) & \text{预测（向前欧拉）} \\ y_C = y_i + h\,f(x_{i+1}, y_P) & \text{校正（向后欧拉）} \\ y_{i+1} = \dfrac{1}{2}(y_P + y_C) \end{cases}
$$

## 龙格-库塔法

$y(x+h)$ 泰勒展开：

$$
y(x_{i+1}) = y(x_i) + h\,y'(x_i) + \frac{h^2}{2!}y''(x_i) + \cdots + \frac{h^P}{P!}y^{(P)}(x_i) + T_{P+1} \;\Rightarrow\; O(h^{P+1})
$$

其中 $y'(x_i) = f(x_i, y(x_i))$，$y''(x_i) = f_x(x_i, y(x_i)) + f_y(x_i, y(x_i)) \cdot y'(x_i)$，… [?] 二元泰勒展开对比系数。

有任意阶的精度，但偏导难算，故用 $f(x_i, y(x_i))$、$f(x_{i+1}, y(x_{i+1}))$ 和内部点的线性组合代替。

> **基本思想**：一步内预测多个点的斜率，用加权平均作为平均斜率

将欧拉公式中 $f(x_i, y_i)$ 记为 $K_1$，$f(x_{i+1}, y_i + hK_1)$ 记为 $K_2$，则欧拉（改进）公式为：

$$
\begin{cases} y_{i+1} = y_i + \dfrac{h}{2}(K_1 + K_2) \\ K_1 = f(x_i, y_i),\quad K_2 = f(x_{i+1}, y_i + hK_1) \end{cases}
$$

### 二阶龙格-库塔法

在 $[x_i, x_{i+1}]$ 上取 $x_i$、$x_{i+p} = x_i + ph$ 两点处的斜率 $K_1, K_2$ 加权平均 $K = \lambda_1 K_1 + \lambda_2 K_2$，即 $y(x_{i+1}) = y(x_i) + h \cdot K$，其中 $K_2 = f(x_i + ph,\, y_i + phK_1)$。对比系数，只要

$$
\begin{cases} \lambda_1 + \lambda_2 = 1 \\ \lambda_2 \cdot p = \dfrac{1}{2} \end{cases}
$$

截断误差为 $O(h^3)$，二阶精度，有无穷多解，统称**二阶龙格-库塔格式**。

1. $p = 1$ 时为改进的欧拉法 （常用）
2. $\lambda_1 = 0$ 时为变形的二阶龙格-库塔法，也称**中点公式**

### 三阶龙格-库塔法

额外增加 $x_{i+q} = x_i + qh$（$0 \leq q \leq 1$），用 $x_i, x_{i+p}, x_{i+q}$ 的斜率 $K_1, K_2, K_3$ 加权平均得 $K$，用 $K_1, K_2$ 得到 $K_3$，有 $O(h^4)$，三阶精度。其中一种为**库塔公式**：

$$
\begin{cases} k_1 = f(x_i, y_i) \\ k_2 = f\left(x_i+\dfrac{h}{2},\, y_i + \dfrac{h}{2}k_1\right) \\ k_3 = f(x_{i+1},\, y_i + h(-k_1 + 2k_2)) \\ y_{i+1} = y_i + \dfrac{h}{6}(k_1 + 4k_2 + k_3) \end{cases}
$$

### 四阶龙格-库塔法（经典 RKF4）

$$
\begin{cases} k_1 = f(x_i, y_i) \\ k_2 = f\left(x_i+\dfrac{h}{2},\, y_i + \dfrac{h}{2}k_1\right) \\ k_3 = f\left(x_i+\dfrac{h}{2},\, y_i + \dfrac{h}{2}k_2\right) \\ k_4 = f(x_{i+1},\, y_i + h k_3) \\ y_{i+1} = y_i + \dfrac{h}{6}(k_1 + 2k_2 + 2k_3 + k_4) \end{cases}
$$

> $k_2, k_3$ 两点均为中点

### 四阶龙格-库塔算法流程

```
开始
  ↓
输入 x0, y0, h, N
  ↓
1 → n
  ↓
┌─────────────────────────────────────────┐
│ x0 + h → x1                              │
│ f(x0, y0) → k1                           │
│ f(x0+h/2, y0+hk1/2) → k2                │
│ f(x0+h/2, y0+hk2/2) → k3                │
│ f(x1, y0+hk3) → k4                       │
│ y0 + h(k1+2k2+2k3+k4)/6 → y1            │
└─────────────────────────────────────────┘
  ↓
输出 x1, y1
  ↓
n = N ?
  ↓ y            ↓ n
结束      ┌──────────────┐
          │ n+1 → n      │
          │ x1 → x0      │───┐
          │ y1 → y0      │   │
          └──────────────┘   │
                            ←┘ (回到计算块)
```

> 龙格-库塔法基于泰勒展开，要求解有光滑性，否则可能不如改进的欧拉法

### 变步长的龙格-库塔法

- 步长大 → 误差大；步长小 → 计算量大，且舍入误差大。也有选择步长问题
- 将步长折半，连跨两步从而求得 $x_{i+1}$，得近似值
- 用 $\Delta = |y_{i+1}^{(h)} - y_{i+1}^{(h/2)}|$ 判断误差

当要求的数值精度为 $\varepsilon$ 时：

1. 若 $\Delta > \varepsilon$，反复将步长折半计算，直至 $\Delta < \varepsilon$ 为止，取最后一次步长的结果作为 $y_{i+1}$
2. 若 $\Delta < \varepsilon$，反复将步长加倍，直到 $\Delta > \varepsilon$ 为止，取上一次步长的结果作为 $y_{i+1}$

## 多步法（亚当姆斯法）

对 $\dfrac{dy}{dx}=f(x,y)$ 在 $[x_{n-p},x_{n+1}]$ 上积分：

$$
y(x_{n+1})-y(x_{n-p})=\int_{x_{n-p}}^{x_{n+1}}f(x,y)\,dx
$$

- $p$ 控制积分区间（$p=0$ 时为 Adams 公式）；$q$ 控制插值节点个数（共 $q+1$ 个）。

$$
\begin{cases}\text{显式：}y_{n+1}-y_{n-p}=\sum_{j=0}^{q}\beta_j f(x_{n-j},y_{n-j}) & \text{节点 }x_n\cdots x_{n-q} \\[4pt] \text{隐式：}y_{n+1}-y_{n-p}=\sum_{j=-1}^{q-1}\beta_j f(x_{n-j},y_{n-j}) & \text{节点 }x_{n+1}\cdots x_{n-q+1}\end{cases}
$$

一般 $k+1$ 步线性多步格式：$y_{n+1}=\sum_{i=0}^{k}\alpha_i y_{n-i}+\sum_{j=-1}^{k}\beta_j f(x_{n-j},y_{n-j})$，$\beta_{-1}=0$ 显式、$\ne 0$ 隐式。

给定 $p,q$ 用拉格朗日插值确定 $\beta_j$。

### 亚当姆斯法（$p=0$ 特例）

龙格-库塔法要先预报几个点、计算量大，用之前的已知值减少计算量。用泰勒展开确定 $\lambda$ 使有二阶精度，$\lambda=-\dfrac12$：

- **显式（外推）**：
  - 二阶：$y_{i+1}=y_i+\dfrac{h}{2}(3y_i'-y_{i-1}')$
  - 三阶：$y_{i+1}=y_i+\dfrac{h}{12}(23y_i'-16y_{i-1}'+5y_{i-2}')$
  - 四阶：$y_{i+1}=y_i+\dfrac{h}{24}(55y_i'-59y_{i-1}'+37y_{i-2}'-9y_{i-3}')$
- **隐式（内插）**：加入 $y_{i+1}'$
  - 二阶：$y_{i+1}=y_i+\dfrac{h}{2}(y_{i+1}'+y_i')$
  - 三阶：$y_{i+1}=y_i+\dfrac{h}{12}(5y_{i+1}'-8y_i'-y_{i-1}')$
  - 四阶：$y_{i+1}=y_i+\dfrac{h}{24}(9y_{i+1}'+19y_i'-5y_{i-1}'+y_{i-2}')$

> 预报用显式外推、校正用隐式内插（预估-校正）。
> 需用其他方法提供初值，称为**起步计算**，要求其他格式至多比该格式低一阶。

## 局部截断误差与全局误差、稳定性与收敛性

- **局部截断误差**：$R_i = y(x_{i+1}) - y_{i+1}$（前一步准确时的单步误差）
- **整体（全局）截断误差低一阶**：方法阶数为 $P$，局部截断误差 $O(h^{P+1})$，整体截断误差 $O(h^{P})$
- **阶数**：局部截断误差为 $O(h^{P+1})$ 则称方法阶数为 $P$；步长 $h<1$ 越小、$P$ 越高精度越高

各方法阶数汇总：

| 方法                      | 局部截断误差 | 阶数$P$ |
| ------------------------- | ------------ | --------- |
| 欧拉法（矩形）            | $O(h^2)$   | 1         |
| 改进欧拉 / 梯形 / 二阶 RK | $O(h^3)$   | 2         |
| 三阶 RK                   | $O(h^4)$   | 3         |
| 四阶 RK                   | $O(h^5)$   | 4         |

### 稳定性

差分导致计算误差在传播中积累。$x_i$ 在 $y_i$ 上引入扰动 $\delta$，若对 $j>i$ 的 $y_j$ 偏差不大于 $\delta$，则稳定。对模型方程 $y'=\lambda y$（$\lambda<0$）分析（一般方程局部线性化可化为该形式）。

> 若模型方程稳定，其他方法不一定稳定；但若模型方程不稳定，其他方法很难稳定。

- 显式欧拉：$0<h\le -\dfrac1\lambda$（$|1+\lambda h|<1$）
- 隐式欧拉：无条件稳定

### 收敛性

$x_{i+1}\to x_i$ 时 $y_{i+1}\to y(x_i)$ 是否成立。欧拉法收敛，收敛速度 $O(h)$，一阶收敛，总截断误差 $O(h)$。

## 一阶常微分方程组与高阶方程

一阶常微分方程组化为向量，对每个分量计算；

高阶方程转化为一阶常微分方程组。
