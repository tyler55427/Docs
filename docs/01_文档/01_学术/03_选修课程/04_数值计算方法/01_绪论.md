# 绪论

## 误差分析

### 误差分类

截断误差、舍入误差（模型误差、观测误差）。

> 一般舍入/截断误差比模型误差、观测误差**高一个数量级**。

### 误差与误差限

- 误差：`e = x* - x`；绝对误差：`|e| = |x - x*|`。
- 误差限：`δ(x)`，`|e| = |x* - x| ≤ δ(x)`，即 `|e|` 的上界（取最小刻度的半个，四舍五入）。
- 相对误差：`e_r = e/x* = (x* - x)/x*`；实践中 `x*` 未知，可用 `e_r = e/x` 代替。
- 相对误差限：`ε_r = |e / x*|`。

**推导**：`1/x - 1/x*` 令 `x = x* + δ·x*`，

$$
\frac{1}{x}-\frac{1}{x^*}=\frac{1}{x^*}\left(1-\frac{1}{1+\delta}\right) \approx \frac{\delta}{x^*} \quad (\text{泰勒展开})
$$

即分母引入 `δ` 的相对误差，会让结果产生同量级相对误差。

### 有效位数 / 有效数字

**定义**：当 `x` 的误差限不超过最后一位的半个单位时，该位到第一个非零位的位数称为 `x` 的有效位数。

**定义**：`x` 是 `x*` 的一个近似数，`x = ±10^n × 0.a₁a₂a₃…`，若 `k` 为满足 `|x - x*| ≤ ½·10^(n-k)` 的最大非负整数，则称 `x` 近似 `x*` 有 `k` 位有效数字。（`n` 从右往左数到 0 定标）

**性质**：

- 十进制 `x*` 作 `k` 位**截断**（chopping，`k` 位后置 0）→ 近似数 `x` 至少有 `k-1` 位有效数字。
- 十进制 `x*` 作 `k` 位**舍入**（rounding，四舍五入）→ 近似数 `x` 有 `k` 位有效数字。

**定理**：`x` 是 `x*` 的近似数且 `x` 有 `k` 位有效数字，则其相对误差限

$$
\frac{|x-x^*|}{|x|}\le \delta_r(x)=\frac{1}{2a_1}\times 10^{-(k+1)}
$$

反之，若 `|x-x*|/|x| ≤ 1/(2(a₁+1)) × 10^(-(k+1))`，则 `x` 至少有 `k` 位有效数字。

**运算对有效位的影响**（数值陷阱）：

- **相减消去**：相接近的两个数相减会减少有效位数（相对误差放大）。
- 乘以较大的数（除以较小的数）会增加相对误差。
- 若分子分母可以约掉公因子，应先约分再算（理论与工程实现不同）。

### 约束误差

选择**收敛且稳定**的算法，以提高数值计算的精度。

### 数值稳定性

**定义**：算法输入的小幅度变化只导致输出结果的小幅度变化，则称该算法**数值稳定**；只在部分数据上有此性质称为**条件稳定**。

**经典例子**：`Iₙ = ∫₀¹ xⁿ eˣ dx`

- 递推式一：`Iₙ = 1 - n·I_{n-1}`（从 `I₀` 递推，误差被 `n` 放大，不稳定）
- 递推式二：`I_{n+1} = 1/n (1 - Iₙ)`（由 `Iₙ` 解出 `I_{n+1}`，误差缩小，稳定）

同一问题两种计算方式，误差行为截然不同 → 这正是数值分析要解决的问题。

> 类比：DNN 中给输入加噪的**对抗样本**，本质是问题/算法对微小扰动的敏感性问题。

## 矩阵与向量范数

### 向量范数

**定义（$L_p$ 范数 / Hölder 范数）：** $X = (x_1, \cdots, x_n)^T$ 的 $L_p$ 范数

$$
\|X\|_p = \left( \sum_{i=1}^n |x_i|^p \right)^{\frac{1}{p}}, \quad 1 \le p < +\infty
$$

（$0 < p < 1$ 时，不满足三角不等式）

**距离性质：**

$$
\begin{cases}
\|X\| \ge 0, \text{ 当 } X = 0 \text{ 时 } \|X\| = 0 \\
\|\alpha X\| = |\alpha| \|X\| \\
\|X + Y\| \le \|X\| + \|Y\|
\end{cases}
$$

**常见范数：**

- **1 范数：** $\|X\|_1 = \displaystyle\sum_{i=1}^n |x_i|$（绝对值之和）
- **2 范数：** $\|X\|_2 = \sqrt{\displaystyle\sum_{i=1}^n |x_i|^2}$（平方和开根）
- **$\infty$ 范数：** $\|X\|_\infty = \max_{1 \le i \le n} |x_i|$（模值最大值）
- **加权范数：** $A$ 是正定矩阵，对 $x \in \mathbb{R}^n$，定义 $\|X\|_A = \sqrt{X^T A X}$，$\|X\|_A$ 是向量范数（加权距离）

**定理（范数等价性）：** 任意向量范数是等价的。对两个不同定义的范数 $\rho_1(X), \rho_2(X)$，则存在 $0 < m < M < \infty$，有：

$$
m \rho_2(X) \le \rho_1(X) \le M \rho_2(X)
$$

**定义（向量序列极限）：** 设 $\{X^{(k)}, k = 1, 2, \cdots, n\}$ 为 $\mathbf{R}^n$ 上向量序列，若存在向量 $\alpha \in \mathbf{R}^n$ 有 $\lim_{k \to \infty} \|X^{(k)} - \alpha\| = 0$，则称向量列 $\{X^{(k)}\}$ 是收敛的，$\alpha$ 称为该向量序列的极限。

由向量范数的等价性，向量序列是否收敛与选取哪种范数无关。向量的极限是通过它的所有分量的极限定义的。

### 矩阵范数

**矩阵范数定义：** 设 $A \in \mathbf{R}^{n \times n}$，记方阵 $A$ 的范数为 $\|A\|$。矩阵范数满足下列性质：

1. $\|A\| \ge 0$，当且仅当 $A = 0$ 时，$\|A\| = 0$（非负性）
2. $\forall \lambda \in \mathbf{R}$，$\|\lambda A\| = |\lambda| \|A\|$（齐次性）
3. 对于任意两个同阶矩阵 $A, B$ 有 $\|A + B\| \le \|A\| + \|B\|$（三角不等式）
4. 设 $A, B$ 为同阶矩阵，则 $\|AB\| \le \|A\| \|B\|$（相容性）
5. 对 $\forall X \in \mathbf{R}^n$，恒有 $\|AX\| \le \|A\| \cdot \|X\|$（相容性）

单位矩阵范数为 $1$。

**算子范数（诱导/从属范数）：**

$$
\|A\| = \sup_{X \in \mathbb{R}^n, X \neq 0} \frac{\|AX\|}{\|X\|} = \max_{\|X\|=1} \|AX\|
$$

**常用矩阵范数：**

- **列和范数（1 范数）：** $\|A\|_1 = \max\limits_{1 \le j \le n} \left\{ \sum_{i=1}^n |a_{ij}| \right\}$
- **行和范数（$\infty$ 范数）：** $\|A\|_\infty = \max\limits_{1 \le i \le n} \left\{ \sum_{j=1}^n |a_{ij}| \right\}$
- **谱范数（2 范数）：** $\|A\|_2 = \sqrt{\rho(A^T A)} = \sqrt{\lambda_{\max}(A^T A)}$
- **Frobenius 范数：** $\|A\|_F = \left( \sum_{i=1}^n \sum_{j=1}^n |a_{ij}|^2 \right)^{\frac{1}{2}}$

**谱半径：** $A$ 的谱半径 $\rho(A) = \max\limits_i \{|\lambda_i|\}$，$\lambda_i$ 为特征值。

**性质：** $\rho(A) \le \|A\|$（要求相容）

**矩阵范数也有等价性。**

### 矩阵序列与收敛性

**矩阵序列收敛：** $A^{(k)}$ 收敛定义为 $\lim\limits_{k \to \infty} \|A^{(k)} - A\| = 0$，与范数选择无关。

**收敛矩阵：** $\lim\limits_{k \to \infty} A^k = 0$，$A$ 为收敛矩阵。

**定理：** $\lim\limits_{k \to \infty} A^k = 0 \iff \rho(A) < 1$

**推论：** 存在一种范数，$\|A\| < 1 \implies \lim\limits_{k \to \infty} A^k = 0$

### 条件数

**条件数：** $A$ 非奇异，$\text{Cond}_p(A) = \|A\|_p \|A^{-1}\|_p$

$$
\text{Cond}(A) \ge 1
$$

当 $A$ 为正交矩阵，$\text{Cond}(A) = 1$。

**扰动定理：** $A \in R^{n \times n}$，$b \in R^n$，$Ax=b$，$A$ 非奇异，$\delta A \ne 0$，$\delta b$ 为 $A$ 和 $b$ 的扰动，若 $\|A^{-1}\|\|\delta A\| < 1$，则

$$
\frac{\|\delta x\|}{\|x\|} \le \frac{\text{Cond}(A)}{1 - \text{Cond}(A)} \left( \frac{\|\delta A\|}{\|A\|} + \frac{\|\delta b\|}{\|b\|} \right)
$$

$\text{Cond}(A)$ 大为坏矩阵。
