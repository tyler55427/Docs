# 快速乘法

**问题描述**：给定底数 a 和指数 ex，计算 a 的 ex 次幂。

**解法**：使用快速幂算法（分治法），将指数不断折半，减少乘法次数。递归版通过判断指数奇偶进行分治，迭代版通过二进制移位实现。

## 递归

```cpp
long long Pow(long long x,int exop)
{
	if(exop==0) return 1;
	else if(exop==1) return x;
	else if(exop%2==1) return Pow(x*x,exop/2)*x;
	return Pow(x*x,exop/2);
}
```

## 迭代

```cpp
long long Pow_(long long x,int exop)
{
	long long res=1;
	while(exop>0)
	{
		if(exop%2==1)
		{
			res*=x;
		}
		x*=x;
		exop/=2;
	}
	return res;
}
```
