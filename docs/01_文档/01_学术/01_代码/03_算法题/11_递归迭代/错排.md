# 错排

**问题描述**：n 个人各持一张名片，全部写错（每个人都不拿到自己的名片）的方案数。

**解法**：递推 / 全排列剪枝。递推公式 $D(n) = (n-1) \times (D(n-1) + D(n-2))$。

## 递推法

```cpp
typedef long long ll;

ll JC(int x)
{
    long long sum = 1;
    for(int i = x; i >= 1; --i)
    {
        sum *= i;
    }
    return sum;
}

// 递推法求错排数（基于概率递推）
// P(n) = (n-1) × (P(n-1) + P(n-2)) / n  （概率形式）
// D(n) = (n-1) × (D(n-1) + D(n-2))        （计数形式）
// 初值：D(0)=1, D(1)=0, D(2)=1, D(3)=2
//
// 代码思路：将错排概率 P(n) 用 double 递推，最后乘 n! 转回计数
// a = D(i-2) / (i-2)! ，b = D(i-1) / (i-1)! ，res = D(i) / i!
// 递推：P(i) = ((i-1) * P(i-1) + P(i-2)) / i
//      即 res = ((i-1) * b + a) / i
ll p(int n)
{
    double res;
    if(n==0||n==1) return 0;  // 0人或1人无法错排
    else if(n==2) return 1;    // 2人：只能交换位置
    else if(n==3) return 2;    // 3人：两种错排
    else
    {
        double a=1.0/2, b=1.0/3;  // a = D(2)/2! = 1/2, b = D(3)/3! = 2/6
        for(int i=4; i<=n; ++i)
        {
            res = ((i-1)*b + a) / i;  // P(i) = ((i-1)*P(i-1) + P(i-2)) / i
            a = b;
            b = res;
        }
    }
    return res * JC(n);  // 概率乘 n! 转回计数 D(n)
}

int main()
{
    int n;
    cin >> n;
    cout << p(n) << endl;  // 输出错排方案数
}
```

## 深搜

```cpp
bool s[1001];   // 标记第 i 个位置是否已被"人"占据
int r[1001];     // r[x] = i 表示第 x 个"人"拿到了第 i 张名片
int res, n;     // res 为深搜计数结果（未使用）, n 为人数

// 深搜（枚举所有全排列，剪枝得到错排方案数）
// 思路：第 x 个人尝试拿第 i 张名片（i 不能等于 x，且第 i 张未被动过）
// 全排列结果数 = n!
// 其中错排数 = n! - 包含至少一个"人对号入座"的方案数
void search(int x)
{
    if(x > n)  // 所有人都分配完毕，找到一种方案
    {
        res++;
        return;
    }
    for(int i = 1; i <= n; ++i)
    {
        // i != x 排除"人 i 拿名片 i"的对号情况
        // s[i] == false 表示第 i 张名片尚未被分配
        if(i != x && s[i] == 0)
        {
            s[i] = true;   // 第 i 张名片被第 x 个人拿走
            r[x] = i;      // 记录第 x 个人拿的是第 i 张
            search(x + 1); // 递归处理下一个人
            s[i] = false;  // 回溯：撤销选择
        }
    }
}
```
