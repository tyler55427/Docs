# 高精度乘法

## 高精度乘法

**问题描述**：输入两个大整数（可能超过普通整数类型范围），计算它们的乘积

**解法**：竖式乘法模拟。使用数组存储每一位数字，将第二个数的每一位与第一个数相乘，累加到对应位置，最后统一处理进位

```cpp
int arr[10000010];

void add(string a, int times) {
    while (times--) {
        for (int i = a.size() - 1;i >= 0;--i) {
            arr[a.size() - i - 1] += a[i] - '0';
        }
    }
}

int main() {
    string a, b;
    cin >> a >> b;

    for (int i = a.size() - 1;i >= 0;--i) {
        if (a[i] != '0')
        {
            add(b, a[i] - '0');
        }
        b += '0';
    }

    for (int i = 0;i < 10000000;++i) {
        if (arr[i] >= 10) {
            arr[i + 1] += arr[i] / 10;
            arr[i] %= 10;
        }
    }

    bool sign = false;

    for (int i = 10000000;i >= 0;--i) {
        if (sign || arr[i]) {
            sign = true;
            cout << arr[i];
        }
    }

    if (!sign) {
        cout << 0;
    }

    return 0;
}
```
