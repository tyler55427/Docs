## 序列合并

**问题描述**：给定 n 个数组（实际为 n 个数），计算相邻元素两两取较大值后累加的结果。即 ans = sum(max(arr[i-1], arr[i])) for i = 1 to n-1

**解法**：直接遍历计算。遍历数组，对于每对相邻元素，取较大者累加到答案

```cpp
long long arr[1000009],ans;

int main(){
	int n;
	cin>>n;
	for(int i=0;i<n;++i) cin>>arr[i];
	for(int i=1;i<n;++i) ans+=max(arr[i-1],arr[i]);
	cout<<ans;
}
```
