# 移动零

## 移动零

**问题描述**：给定一个数组 nums，编写一个函数将所有 0 移动到数组的末尾，同时保持非零元素的相对顺序。

**解法**：双指针，left 左边为确认非零元素，right 遍历找到非零元素，进行交换

```cpp
void moveZeroes(vector<int>& nums) {
    int left = 0;
    
    for (int right = 0; right < nums.size(); ++right) {
        if (nums[right] != 0) {
            swap(nums[left], nums[right]);
            ++left;
        }
    }
}
```
