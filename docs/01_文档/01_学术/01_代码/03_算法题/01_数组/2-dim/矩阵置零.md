# 矩阵置零

## 矩阵置零（O(m+n)）

**问题描述**：给定一个包含 m x n 个元素的矩阵，将矩阵中所有的 0 所在的行和列都设置为 0。

**解法**：行列标记数组

```cpp
void setZeroes(vector<vector<int>>& matrix) {
    int n = matrix.size();
    int m = matrix[0].size();
    vector<bool> row(n, false), col(m, false);

    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < m; ++j) {
            if (matrix[i][j] == 0) {
                row[i] = true;
                col[j] = true;
            }
        }
    }

    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < m; ++j) {
            if (row[i] || col[j]) {
                matrix[i][j] = 0;
            }
        }
    }
}
```

## 矩阵置零（O(1)）

**解法**：使用第一行和第一列作为标记数组，需要对第一个元素进行特殊处理

```cpp
void setZeroes(vector<vector<int>>& matrix) {
    int m = matrix.size();
    int n = matrix[0].size();
    int sign_m = 1, sign_n = 1;

    for (int i = 0;i < m;++i) {
        for (int j = 0;j < n;++j) {
            if (matrix[i][j] == 0) {
                if (i && j) {
                    // 用第一行/列作为标记数组
                    matrix[0][j] = 0;
                    matrix[i][0] = 0;
                }
                else {
                    // 用于分别标记第一行/列
                    if (i == 0) sign_n = 0;
                    if (j == 0) sign_m = 0;
                }
            }
        }
    }
    // 从第二行/列开始删除行/列
    for (int i = 1;i < m;++i) {
        if (matrix[i][0] == 0) {
            for (int j = 0;j < n;++j) matrix[i][j] = 0;
        }
    }
    for (int j = 1;j < n;++j) {
        if (matrix[0][j] == 0) {
            for (int i = 0;i < m;++i) matrix[i][j] = 0;
        }
    }
    // 删除第一行/列
    if (sign_m == 0) {
        for (int i = 0;i < m;++i) matrix[i][0] = 0;
    }

    if (sign_n == 0) {
        for (int j = 0;j < n;++j) matrix[0][j] = 0;
    }
}
```

## 矩阵置零（官方题解）

**解法**：状态机的信息高效使用

```cpp
void setZeroes(vector<vector<int>>& matrix) {
    int m = matrix.size();
    int n = matrix[0].size();
    int flag_col0 = false;
    for (int i = 0; i < m; i++) {
        if (!matrix[i][0]) {
            flag_col0 = true;
        }
        for (int j = 1; j < n; j++) {
            if (!matrix[i][j]) {
                matrix[i][0] = matrix[0][j] = 0;
            }
        }
    }
    for (int i = m - 1; i >= 0; i--) {
        for (int j = 1; j < n; j++) {
            if (!matrix[i][0] || !matrix[0][j]) {
                matrix[i][j] = 0;
            }
        }
        if (flag_col0) {
            matrix[i][0] = 0;
        }
    }
}
```
