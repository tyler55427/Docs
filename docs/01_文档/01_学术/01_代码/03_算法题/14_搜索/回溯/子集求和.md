## 子集求和

**问题描述**：给定 n 个数组，每个数组有 m 个元素。目标是选择一个子集（每个数组可选或不选），使得选中的元素之和等于目标数组 goal 中对应位置的值。统计满足条件的方案数

**解法**：DFS 回溯搜索。枚举每个数组选或不选，递归搜索。剪枝：如果当前累计值超过目标值或最终完全匹配目标则记录结果

```cpp
int n,m,res;
int arr[29][109];
int goal[109];
int tt[109];

void dfs(int index,int sign){
	if(index<=n){
		bool exce=true;
		if(sign){
			int i=1;
			bool panduan=true;
			for(;i<=m;++i){
				tt[i]+=arr[index][i];
				panduan=panduan&&(tt[i]==goal[i]);
				if(tt[i]>goal[i]) exce=false;
			}

			if(panduan) res++;
		}
	
		if(index<n && exce){
			dfs(index+1,0);
			dfs(index+1,1);
		}
	
		if(sign){
			for(int i=1;i<=m;++i){
				tt[i]-=arr[index][i];
			}
		}
	
	}
}

int main(){
	cin>>n>>m;
	ios::sync_with_stdio(false),cin.tie(0),cout.tie(0);
	for(int i=1;i<=m;++i) cin>>goal[i];
	for(int i=1;i<=n;++i)
		for(int j=1;j<=m;++j)
			cin>>arr[i][j];
	dfs(0,0);
	cout<<res;
	return 0;
}
```

**备注**：数组下标从 1 开始；剪枝条件包括超出目标值和完全匹配目标值
