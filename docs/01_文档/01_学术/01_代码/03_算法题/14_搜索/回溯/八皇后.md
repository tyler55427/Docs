# 八皇后

## 八皇后问题（Eight Queens）

**题目描述**：在 8×8 棋盘上放置 8 个皇后，使其互不攻击（任意两个皇后不在同一行、列、对角线）

**解法**：位运算 + DFS（"跳舞的线"思想）

**核心思想**：用一个二进制位表示一列（或对角线）的占用情况，每次通过位运算确定可放置位置，O(1) 完成冲突检测

**时间复杂度**：O(N!)，实际非常快（N=15 时仍能在 1s 内完成）

## 跳舞的线核心（位运算版本）

**说明**：三个整数分别表示：
- `cols` — 已占用的列
- `diag1` — 已占用的 `\` 对角线（行+列 相同的在同一对角线）
- `diag2` — 已占用的 `/` 对角线（行-列+N 相同的在同一对角线）

**关键性质**：
- 列冲突：列号 c，标记为 `cols |= (1 << c)`
- `\` 对角线：行号 i，列号 c，对角线编号 = i + c
- `/` 对角线：行号 i，列号 c，对角线编号 = i - c + (N-1)

**DFS 时把上一行的三个状态传给下一行**：
- 下一行可用位置 = `~(cols | diag1 | diag2) & ((1<<N) - 1)`

**位运算推导**：
- cols  左移 1 位（不在同一列）
- diag1 左移 1 位（`\` 对角线"斜向下"）
- diag2 右移 1 位（`/` 对角线"斜向下"）

```cpp
void danceLineDFS(int row, int cols, int diag1, int diag2, int N) {
    // 所有行都放完了，找到一个解
    if(row == N) {
        solutions++;
        return;
    }

    // 计算当前行所有可放置的位置（位为 1 表示该列可用）
    // 可用位置 = 全集 减去 (列冲突 | \ 对角线冲突 | / 对角线冲突)
    int available = (~(cols | diag1 | diag2)) & ((1 << N) - 1);

    // 逐个尝试当前行的可放置位置
    while(available) {
        // 取出最低位的 1（当前要放置的列）
        int pos = available & (-available);
        // 从 available 中清除该位
        available -= pos;

        // 递归到下一行
        // cols  左移 1：下一行的列冲突
        // diag1 左移 1：\ 对角线随行号增加而"左移"
        // diag2 右移 1：/ 对角线随行号增加而"右移"
        danceLineDFS(row + 1,
                     cols | pos,         // 列冲突
                     (diag1 | pos) << 1, // \ 对角线冲突
                     (diag2 | pos) >> 1, // / 对角线冲突
                     N);
    }
}
```

## 传统 DFS 版本（对比学习）

**说明**：检查 (row, col) 位置是否与之前的皇后冲突

```cpp
bool isValid(int row, int col) {
    for(int i = 0; i < row; ++i) {
        // 同列冲突
        if(board[i] == col) return false;
        // 对角线冲突：|行差| == |列差|
        if(abs(board[i] - col) == abs(i - row)) return false;
    }
    return true;
}
```

**说明**：传统 DFS 按行枚举

```cpp
void traditionalDFS(int row, int N) {
    if(row == N) {
        totalSolutions++;
        return;
    }
    for(int col = 0; col < N; ++col) {
        if(isValid(row, col)) {
            board[row] = col;
            traditionalDFS(row + 1, N);
        }
    }
}
```

## 主函数

```cpp
int main() {
    int N;
    cin >> N;

    // 方法 1：跳舞的线（位运算）
    solutions = 0;
    danceLineDFS(0, 0, 0, 0, N);
    cout << "跳舞的线解法: " << solutions << " 种" << endl;

    // 方法 2：传统 DFS
    totalSolutions = 0;
    traditionalDFS(0, N);
    cout << "传统 DFS 解法: " << totalSolutions << " 种" << endl;

    return 0;
}
```
