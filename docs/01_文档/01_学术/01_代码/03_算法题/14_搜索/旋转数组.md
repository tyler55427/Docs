# 旋转数组

**问题描述**：假设按照升序排序的数组在预先未知的某个点上进行了旋转（例如，数组 [0,1,2,4,5,6,7] 可能变为 [4,5,6,7,0,1,2]），在旋转数组中查找目标元素 target 的位置。没有重复元素。

**解法**：改进的二分搜索。数组中存在一个旋转点，旋转点将数组分成两部分，两个部分单独是有序的。判断当前位于哪个有序部分，不断缩小搜索范围。

**备注**：没有重复元素。

```cpp
int search(vector<int>& nums, int target)
{
    int left = 0, right = nums.size() - 1;

    while (left <= right)
    {
        int mid = left + (right - left) / 2;

        if (nums[mid] == target)
        {
            return mid;
        }

        // 左边有序
        if (nums[left] <= nums[mid])
        {
            if (nums[left] <= target && target < nums[mid])
            {
                right = mid - 1;
            }
            else
            {
                left = mid + 1;
            }
        }
        else
        {
            if (nums[mid] < target && target <= nums[right])
            {
                left = mid + 1;
            }
            else
            {
                right = mid - 1;
            }
        }
    }

    return -1;
}
```
