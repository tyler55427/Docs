# 题目名称

## 验证栈

**问题描述**：给定两个长度相同的序列 a 和 b，判断是否可以通过一个栈的操作将序列 a 转换为序列 b。思路是依次将 a 的元素入栈，每次入栈后检查栈顶元素是否与 b 的当前元素相同，若相同则弹出栈顶并移动 b 的指针。最后若栈为空，则说明可以转换。

**解法**：模拟栈操作。遍历序列 a，将每个元素入栈，然后不断检查并弹出栈顶元素直到与序列 b 的当前元素匹配。最后检查栈是否为空。

```cpp
stack<int> s1;
int a[100009],b[100009];

int main()
{
	int n;
	cin>>n;
	while(n--)
	{
		int t;
		cin>>t;
		for(int i=0;i<t;++i)
		{
			cin>>a[i];
		}
		for(int i=0;i<t;++i)
		{
			cin>>b[i];
		}
		int count=0;
		for(int i=0;i<t;++i)
		{
			s1.push(a[i]);
			while(!s1.empty()&&s1.top()==b[count])
			{
				s1.pop();
				count++;
			}
		}
		if(s1.empty())
		{
			cout<<"Yes"<<endl;
		}
		else
		{
			cout<<"No"<<endl;
			while(!s1.empty())
			{
				s1.pop();
			}
		}
	}
}
```

**备注**：

- 这是一个经典的栈模拟问题，用于验证出栈序列是否合法
- 每次入栈后立即检查是否可以弹出，减少不必要的操作
- 注意每轮测试后清空栈，避免影响下一轮
