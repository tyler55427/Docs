# 删除k个数字使得最小

## 删除 k 个数字使得剩下的数字最小

**题目描述**：给定一个数字字符串 s 和整数 k，删除 s 中的 k 个字符，使得剩余数字按原顺序组成的新数最小。

**解法**：贪心（单调栈）

**核心思想**：每次找到第一个出现降序的位置（即高位大于次高位），删除高位。因为删除一个高位数字对数值的影响远大于删除低位数字。

```cpp
while(k--)
{
    int i = 0;
    // 找到第一个降序位置
    // 注意：如果字符串单调递增（非降），则一直走到末尾
    while(i < (int)s.size() - 1 && s[i] <= s[i+1])
    {
        i++;
    }
    s.erase(i, 1);
}

// 去除前导零：保留最后一个字符避免全部删光
while(s[0] == '0' && s.size() > 1)
{
    s.erase(0, 1);
}
```
