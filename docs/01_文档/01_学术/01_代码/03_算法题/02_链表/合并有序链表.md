# 合并有序链表

## 合并两个有序链表

**问题描述**：将两个升序链表合并为一个新的升序链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。

**解法**：使用一个虚拟头节点简化合并过程

```cpp
ListNode* mergeTwoLists(ListNode* l1, ListNode* l2) {
    // 使用一个虚拟头节点简化合并过程
    ListNode* dummy = new ListNode(0);
    ListNode* curr = dummy;

    while (l1 && l2) {
        if (l1->val <= l2->val) {
            curr->next = l1;
            l1 = l1->next;
        }
        else {
            curr->next = l2;
            l2 = l2->next;
        }
        curr = curr->next;
    }

    curr->next = l1 ? l1 : l2;

    return dummy->next;
}
```

## 合并k个有序链表

```cpp
ListNode* mergeKLists(vector<ListNode*>& lists) {
    ListNode* dummy = new ListNode(0);
    ListNode* now = dummy;
    priority_queue<pair<int, int>> q;
    int cnt = 0;
    for (auto list : lists) {
        if (list) {
            q.push({ -(list->val),cnt });
        }
        cnt++;
    }
    int index;
    while (!q.empty()) {
        index = q.top().second;
        q.pop();
        now->next = lists[index];
        now = now->next;
        lists[index] = lists[index]->next;
        if (lists[index]) q.push({ -(lists[index]->val),index });
    }
    return dummy->next;
}
```
