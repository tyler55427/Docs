# 质数

## 试除法

**问题描述**：判断单个数 n 是否为质数。

**解法**：只需检查 2 到 sqrt(n) 的所有整数。时间复杂度 O(sqrt(n))。

```cpp
bool isPrime_trialDivision(int n)
{
    if (n < 2) return false;          // 0 和 1 不是质数
    if (n == 2) return true;           // 2 是唯一的偶质数
    if (n % 2 == 0) return false;      // 偶数都不是质数
    for (int i = 3; i <= sqrt(n); i += 2)
    {
        if (n % i == 0) return false;
    }
    return true;
}
```

## 埃拉托斯特尼筛法

**问题描述**：找出 2 到 maxN 之间的所有质数。

**解法**：从 2 开始，将每个质数的倍数标记为非质数。时间复杂度 O(n log log n)，空间 O(n)。

内层循环从 i*i 开始（因为 i*(i-1) 已被更小的因子筛过）。

```cpp
vector<int> sieveOfEratosthenes(int maxN)
{
    vector<bool> isPrime(maxN + 1, true);
    isPrime[0] = isPrime[1] = false;

    for (int i = 2; i * i <= maxN; ++i)
    {
        if (isPrime[i])
        {
            // 将 i 的倍数标记为非质数
            for (int j = i * i; j <= maxN; j += i)
            {
                isPrime[j] = false;
            }
        }
    }

    vector<int> primes;
    for (int i = 2; i <= maxN; ++i)
    {
        if (isPrime[i]) primes.push_back(i);
    }
    return primes;
}
```

## 欧拉筛（线性筛）

**问题描述**：高效找出 2 到 maxN 之间的所有质数。

**解法**：每个合数只被它的最小质因子筛掉一次。时间复杂度 O(n)，空间 O(n)。

关键优化：如果 i 能被当前质数 p 整除，说明 p 是 i 的最小质因子，此时 p * i 的最小质因子就是 p，不需要继续用更大的质数筛。

```cpp
vector<int> eulerSieve(int maxN)
{
    vector<bool> isPrime(maxN + 1, true);
    isPrime[0] = isPrime[1] = false;
    vector<int> primes;
    vector<int> minPrime(maxN + 1, 0);

    for (int i = 2; i <= maxN; ++i)
    {
        if (isPrime[i])
        {
            primes.push_back(i);
            minPrime[i] = i;
        }

        for (int p : primes)
        {
            if (p * i > maxN) break;

            isPrime[p * i] = false;
            minPrime[p * i] = p;

            if (i % p == 0) break;
        }
    }
    return primes;
}
```

## 获取最小质因子

**问题描述**：获取 1~n 每个数的最小质因子。

```cpp
vector<int> getMinPrimeFactors(int n)
{
    vector<int> minPrime(n + 1, 0);
    vector<int> primes;
    vector<bool> isPrime(n + 1, true);
    isPrime[0] = isPrime[1] = false;

    for (int i = 2; i <= n; ++i)
    {
        if (isPrime[i])
        {
            primes.push_back(i);
            minPrime[i] = i;
        }
        for (int p : primes)
        {
            if (p * i > n) break;
            isPrime[p * i] = false;
            minPrime[p * i] = p;
            if (i % p == 0) break;
        }
    }
    return minPrime;
}
```

## 质因数分解

**问题描述**：给定数 n，求其质因数及其指数。

**解法**：基于最小质因子数组，依次除尽。时间 O(log n)。

```cpp
vector<pair<int, int>> primeFactorization(int n, const vector<int>& minPrime)
{
    vector<pair<int, int>> factors;
    while (n > 1)
    {
        int p = minPrime[n];
        int cnt = 0;
        while (n % p == 0)
        {
            n /= p;
            ++cnt;
        }
        factors.push_back({p, cnt});
    }
    return factors;
}
```
