# 统计矩形

**问题描述**：给定 n 行 m 列的网格，统计：
1. 所有正方形的总数
2. 所有非正方形矩形的总数

**解法**：组合数学。枚举正方形边长 i（从 1 到 min(rows, cols)），边长为 i 的正方形个数 = (rows - i + 1) * (cols - i + 1)。枚举矩形高 h 和宽 w（均从 1 开始），若 h != w 则计入非正方形矩形。时间复杂度 O(n * m)，空间 O(1)。

**备注**：所有矩形数量 = C(n+1,2) * C(m+1,2)，可作为验证。

```cpp
long long rows, cols;          // 网格行数、列数
long long squareCount;         // 正方形数量
long long rectangleCount;      // 非正方形矩形数量

int main()
{
    cin >> rows >> cols;

    // 枚举正方形：边长从 1 到 min(rows, cols)
    for (int len = 1; len <= rows && len <= cols; ++len)
    {
        // 边长为 len 的正方形个数 = (rows - len + 1) * (cols - len + 1)
        squareCount += (rows - len + 1) * (cols - len + 1);
    }

    // 枚举所有矩形（高 i, 宽 j），减去正方形部分得到非正方形矩形
    for (int h = 1; h <= rows; ++h)
    {
        for (int w = 1; w <= cols; ++w)
        {
            long long count = (rows - h + 1) * (cols - w + 1);
            if (h == w)
                squareCount += 0;  // 已在正方形中统计
            else
                rectangleCount += count;
        }
    }

    cout << squareCount << " " << rectangleCount << endl;
    return 0;
}
```
