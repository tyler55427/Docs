# 整数拆分

**问题描述**：包含四种整数拆分问题：
1. 将 n 拆分成 k 个正整数（有序）
2. 将 n 拆分成任意个正整数（无序，二维 DP）
3. 将 n 拆分成任意个正整数（无序，一维 DP）
4. 将 n 分成从小到大的最多 k 个数的和

**解法**：
- 有序拆分：枚举第一个数 x，将 i-x 分成 k-1 个数，dp[i][j] = Σ dp[i - x][j - 1]
- 无序拆分（二维）：dp[n][k] = 将 n 分成不超过 k 的正整数之和的方案数，递推 dp[n][k] = Σ dp[n - t*k][k-1]
- 无序拆分（一维)：完全背包变体，dp[j] += dp[j - i]

```cpp
long long dp_k_ways[105][105];    // dp[n][k] = 将 n 分成 k 个正整数的方案数（有序）
long long dp_undordered[4005][4005];  // dp_undordered[n][k] = 将 n 分成不超过 k 的正整数之和的方案数（无序）
int dp_one_dim[105];               // 一维版：无序拆分
```

## 有序拆分

将 n 分成 k 个正整数（有序拆分）。枚举第一个数 x (1 ≤ x < i)，将 i-x 分成 k-1 个数，dp[i][j] = Σ dp[i - x][j - 1], x = 1..i-1。

```cpp
// 问题1：将 n 分成 k 个正整数（有序拆分）
// 思路：枚举第一个数 x (1 ≤ x < i)，将 i-x 分成 k-1 个数
// dp[i][j] = Σ dp[i - x][j - 1], x = 1..i-1
int countOrdered(int n, int k)
{
    for (int i = 1; i <= n; ++i) dp_k_ways[i][1] = 1;  // 只有一种：全为1
    for (int i = 2; i <= n; ++i)
    {
        for (int j = 2; j <= k; ++j)
        {
            for (int x = 1; x < i; ++x)
            {
                dp_k_ways[i][j] += dp_k_ways[i - x][j - 1];
            }
        }
    }
    return dp_k_ways[n][k];
}
```

## 无序拆分（二维）

将 n 拆分成任意个正整数（无序拆分）。dp[n][k] = 将 n 分成不超过 k 的正整数之和的方案数（顺序无关）。递推：dp[n][k] = Σ dp[n - t*k][k-1], t = 0, 1, 2, ... 直到 n-t*k >= 0。

```cpp
// 问题2：将 n 拆分成任意个正整数（无序拆分）
// dp[n][k] = 将 n 分成不超过 k 的正整数之和的方案数（顺序无关）
// 递推：dp[n][k] = Σ dp[n - t*k][k-1], t = 0, 1, 2, ... 直到 n-t*k >= 0
long long countUnordered(int n)
{
    dp_undordered[0][0] = 1;   // 边界：0 拆成 0 个数的方案数为 1

    // 初始化第一行和第一列
    for (int i = 1; i <= n; ++i) dp_undordered[i][1] = 1;   // 只能全用1
    for (int i = 0; i <= n; ++i) dp_undordered[0][i] = 1;   // 0 拆成任意数只有空集

    for (int i = 1; i <= n; ++i)
    {
        for (int j = 2; j <= n; ++j)
        {
            // 枚举使用了几个 j：t = 0, 1, 2, ...
            // x = i - t*j，表示剩余要拆分的数
            for (int x = i; x >= 0; x -= j)
            {
                dp_undordered[i][j] = (dp_undordered[i][j] + dp_undordered[x][j - 1]) % 2147483648;
            }
        }
    }
    // dp[n][n] 包含"全部由 n 自身组成"的情况（即 n = n + 0 个其他数）
    // 减去 dp[n][n-1] 才能得到正确的无序拆分数
    return dp_undordered[n][n] - dp_undordered[n][n - 1];
}
```

## 无序拆分（一维）

将 n 拆分成任意个正整数（无序拆分），一维 DP。思路：完全背包变体。dp[j] = 方案数。遍历每个物品 i（代表数值 i），对于每个 j 从 i 到 n，dp[j] += dp[j - i]，表示在已有方案基础上再加一个 i。

```cpp
// 问题3：将 n 拆分成任意个正整数（无序拆分），一维 DP
// 思路：完全背包变体
// dp[j] = 方案数。遍历每个物品 i（代表数值 i），对于每个 j 从 i 到 n
// dp[j] += dp[j - i]，表示在已有方案基础上再加一个 i
int countUnordered1D(int n)
{
    dp_one_dim[0] = 1;  // 边界：0 只有空集一种方案
    for (int i = 1; i <= n; ++i)        // 遍历每个可以被拆分的数 i
    {
        for (int j = i; j <= n; ++j)    // 完全背包：每个数可以无限使用（顺序无关）
        {
            dp_one_dim[j] += dp_one_dim[j - i];
        }
    }
    return dp_one_dim[n];
}
```

## 最多 k 个数（DFS）

将 n 分成从小到大的最多 k 个数的和。

```cpp
int n, k, arr[103];

void dfs(int i, int now, int rest)
{
    if (rest == 0)
    {
        for (int j = 0; j < i; ++j) cout << arr[j] << " ";
        cout << endl;
    }
    if (i < k)
    {
        for (int j = now; j <= rest; ++j)
        {
            arr[i] = j;
            dfs(i + 1, j, rest - j);
        }
    }
}
```
