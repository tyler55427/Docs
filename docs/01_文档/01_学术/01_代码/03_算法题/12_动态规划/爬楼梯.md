# 爬楼梯

## 爬楼梯问题

**问题描述**：假设你正在爬楼梯。需要 n 阶你才能到达楼顶。每次你可以爬 1 或 2 个台阶。你有多少种不同的方法可以爬到楼顶呢？

**解法**：动态规划，空间优化

```cpp
int climbStairs(int n) {
    if (n <= 2) {
        return n;
    }
    
    int prev = 1, curr = 2;
    for (int i = 3; i <= n; ++i) {
        int temp = curr;
        curr = prev + curr;
        prev = temp;
    }
    
    return curr;
}
```
