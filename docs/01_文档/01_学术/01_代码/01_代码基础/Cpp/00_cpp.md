# 二、面向对象

## 基础

### 权限

- struct默认为public，class默认为private
- 权限分类：
  - public：类内可以访问，类外可以访问
  - protected：类内可以访问，类外不可以访问
  - private：类内可以访问，类外不可以访问

### 成员

- 对象成员
- 静态成员
  - 静态成员变量
    - 所有对象共享
    - 类内定义`static`，类外初始化 `int Person::age = 10`，而不是实例化后定义
  - 静态成员函数
    - 所有对象共享
    - 只能访问静态成员变量

### this指针

- 变量重名的时候，用于区分
- 函数返回自身对象本身
- 空指针也能访问成员函数

### const修饰符

- 常成员变量
  - 只能在初始化列表中构造
- 常函数
  - 不能修改成员变量（除了mutable声明）
- 常对象
  - 只能调用常函数

### 友元

在类中定义，定义的类/方法能够访问本类中的内容。

- 类作友元
- 全局函数作友元
- 成员函数作友元

### 隐式转换

传入对象不符合类型，但是存在相应的构造函数

explicit禁用隐式转换

## 对象

### 构造函数与析构函数

默认提供无参构造和析构函数

- 无参构造可以是有参构造提供所有默认参数
- 如果有有参构造，不提供默认无参构造
- 如果有拷贝构造，不提供任何默认构造
  - 无引用函数传参
  - 无引用函数返回

### 深拷贝

解决浅拷贝问题：复制值（如指针地址），没有复制指针指向的内容

- 拷贝构造
- 析构函数

### 赋值运算符重载

自定义运算符的规则

- 运算符重载
- 函数重载

定义方式

- 类内定义，类外实现，需要作用域
- 类内友元，类外全局函数实现，不需要作用域

## 虚操作

假的操作，需要到派生类中找实现并调用

### 虚继承

菱形继承同时使用两份基类的问题

忽略基类的初始化操作，由最底层的派生类进行初始化

### 虚析构

使用基类指针创建派生类对象的时候，正确销毁基类和派生类

### 虚函数

基类指针，调用派生类对象

一旦为虚，永远为虚

服务于多态

### 纯虚函数

`virtual void eat() = 0;`

派生类必须重写

不能实例化，抽象类

## 多态

一个标识符指代不同类型的数据

基类指针，调用派生类对象。

同一方法的不同实现

# 三、模板

不用类型复用

- 函数模板
- 类模板

分类

- 模板：实例化时候指定
- 全特化：定义时显示指定为不同类型，当其中一种参数类型的模板需要额外的操作的时候
- 偏特化：定义时显示指定为同一类型

数组

- 定义
  - (&arr)[N]
  - (\*arr)[N]
- 传参
  - int arr[10]
  - int arr[]
  - int\* arr
