# 排序

## 选择排序

每趟选择最小元素放到已排序序列末尾。

```cpp
// 4
constexpr int MAXN = 1010;
constexpr int MAXW = 100010;
int cnt[MAXW], b[MAXN];

// 数组的大小为n+1，数组的下标从1开始

// 1. 选择排序
void selection_sort(int* a, int n) {
  for (int i = 1; i < n; ++i) {
  	// 初始化最小值为i，解决如果i本身就是最小值的情况
    int ith = i;
    for (int j = i + 1; j <= n; ++j) {
      if (a[j] < a[ith]) {
        ith = j;
      }
    }
    std::swap(a[i], a[ith]);
  }
}
```

## 冒泡排序

相邻元素比较交换，逐步将最大元素冒泡到末尾。

```cpp
// 2. 冒泡排序
void bubble_sort(int *a, int n) {
  bool flag = true;
  while (flag) {
  	// 设置标记以便提前退出
    flag = false;
    // 直接全部遍历也影响不大？
    for (int i = 1; i < n; ++i) {
      if (a[i] > a[i + 1]) {
        flag = true;
        int t = a[i];
        a[i] = a[i + 1];
        a[i + 1] = t;
      }
    }
  }
}
```

## 插入排序

将元素插入到已排序序列的正确位置。

```cpp
// 3. 插入排序
void insertion_sort(int arr[], int len) {
  for (int i = 1; i < len; ++i) {
    int key = arr[i];
    int j = i - 1;
    while (j >= 0 && arr[j] > key) {
      arr[j + 1] = arr[j];
      j--;
    }
    arr[j + 1] = key;
  }
}
```

## 计数排序

统计每个数值出现的次数，按顺序输出。

```cpp
// 4. 计数排序
int* counting_sort(int* a, int n, int w) {
  memset(cnt, 0, sizeof(cnt));
  for (int i = 1; i <= n; ++i) ++cnt[a[i]];
  for (int i = 1; i <= w; ++i) cnt[i] += cnt[i - 1];
  for (int i = n; i >= 1; --i) b[cnt[a[i]]--] = a[i];
  return b;
}
```
