# 柱状图中最大矩形

## 柱状图中最大的矩形

**问题描述**：给定一个整数数组 heights，表示柱状图中每个柱子的高度，返回柱状图中最大的矩形面积。

**解法**：单调栈，存储索引

**备注**：

- 栈单调递增
- 栈的上一个元素是前面第一个比他矮的高度
- 栈顶下一个元素是后面比他高的最矮的高度

```cpp
int largestRectangleArea(vector<int>& heights) {
    int n = heights.size();
    stack<int> st;
    int max_area = 0;

    for (int j = 0; j <= n; ++j) {
        int h = (j < n) ? heights[j] : 0;   // 末尾哨兵，强制清栈

        while (!st.empty() && heights[st.top()] > h) {
            int height = heights[st.top()];
            st.pop();
            int width = st.empty() ? j : j - st.top() - 1;
            max_area = max(max_area, height * width);
        }
        st.push(j);
    }

    return max_area;
}
```
