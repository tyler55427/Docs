# 对称二叉树

## 对称二叉树（递归）

**题目描述**：给定一个二叉树，检查它是否是轴对称的。

**解法**：递归，自上而下地判断。注意，不能自下而上，两个子树都是对称的并不意味着它们的父节点也是对称的。

```cpp
bool same(TreeNode* l, TreeNode* r) {
    if (!l && !r) return true;
    if (!l || !r) return false;
    return (l->val == r->val) && same(l->left, r->right) && same(l->right, r->left);
}

bool isSymmetric(TreeNode* root) {
    return same(root->left, root->right);
}
```

## 对称二叉树（迭代）

**解法**：迭代

```cpp
bool check(TreeNode* u, TreeNode* v) {
    queue <TreeNode*> q;
    q.push(u); q.push(v);
    while (!q.empty()) {
        u = q.front(); q.pop();
        v = q.front(); q.pop();
        if (!u && !v) continue;
        if ((!u || !v) || (u->val != v->val)) return false;

        q.push(u->left);
        q.push(v->right);

        q.push(u->right);
        q.push(v->left);
    }
    return true;
}

bool isSymmetric(TreeNode* root) {
    return check(root, root);
}
```
