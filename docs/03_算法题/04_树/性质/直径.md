# 直径（树的直径）

## 树的直径（Tree Diameter）

**题目描述**：给定一棵 n 个节点的树，求最长路径（直径）的长度

**解法**：将每个节点作为路径的中间节点

```cpp
int ans = -1;

int dfs(TreeNode* now) {
    if (!now) return 0;
    int left = dfs(now->left);
    int right = dfs(now->right);
    ans = max(ans, left + right);
    return max(left, right) + 1;
}

int diameterOfBinaryTree(TreeNode* root) {
    dfs(root);
    return ans;
}
```
