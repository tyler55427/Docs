# 二叉树右视图

## 二叉树的右视图（层序遍历）

**题目描述**：给定一个二叉树的根节点 root，想象自己站在它的右侧，返回从右侧所能看到的节点值。

**解法**：层序遍历，取每一层的最后一个节点

```cpp
void bfs(TreeNode* root) {
    if (!root) return;
    queue<TreeNode*> q;
    q.push(root);
    int current_size;
    while (!q.empty()) {
        current_size = q.size();
        vector<int> tmp;
        v.push_back(tmp);
        TreeNode* now;
        for (int i = 0;i < current_size;++i) {
            now = q.front();
            q.pop();
            v.back().push_back(now->val);
            if (now->left) q.push(now->left);
            if (now->right) q.push(now->right);
        }
    }
}

vector<int> rightSideView(TreeNode* root) {
    bfs(root);
    for (int i = 0;i < v.size();++i) {
        ans.push_back(v[i].back());
    }
    return ans;
}
```

## 二叉树的右视图（深度优先搜索）

**解法**：深度优先搜索，优先遍历右子树

```cpp
void dfs(TreeNode* root, int depth) {
    if (!root) return;
    if (depth == ans.size()) {
        ans.push_back(root->val);
    }
    dfs(root->right, depth + 1);
    dfs(root->left, depth + 1);
}

vector<int> rightSideView(TreeNode* root) {
    dfs(root, 0);
    return ans;
}
```
