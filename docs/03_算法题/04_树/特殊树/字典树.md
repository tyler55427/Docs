# 字典树（前缀树）

## 字典树（ Trie）

**说明**：字典树，又叫前缀树

## Trie 结构

```cpp
struct Tree {
    Tree* child[26];
    bool is_end = false;
};

class Trie {
public:
    Tree* tree;
    Trie() {
        tree = new Tree();
    }
```

## traverse 操作

```cpp
    Tree* traverse(string word, bool create=false) {
        Tree* now = tree;
        int index;
        for (auto c : word) {
            index=c-'a';
            if (!now->child[index]){
                if(create) now->child[index]=new Tree();
                else return nullptr;
            }
            now = now->child[index];
        }
        return now;
    }
```

## insert 插入

```cpp
    void insert(string word) {
        Tree* now = traverse(word,true);
        now->is_end = true;
    }
```

## search 搜索

```cpp
    bool search(string word) {
        Tree* now = traverse(word);
        return now?now->is_end:false;
    }
```

## startsWith 前缀匹配

```cpp
    bool startsWith(string prefix) {
        Tree* now = traverse(prefix);
        return now?true:false;
    }
};
```
