# 翻转二叉树

## 翻转二叉树

**题目描述**：给定一个二叉树，翻转它并返回其根节点。

**解法**：递归

```cpp
TreeNode* invertTree(TreeNode* root) {
    if (root == nullptr) {
        return nullptr;
    }
    TreeNode* left = invertTree(root->left);
    TreeNode* right = invertTree(root->right);
    root->left = right;
    root->right = left;
    return root;
}
```
