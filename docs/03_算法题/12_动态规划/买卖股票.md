# 买卖股票

## 买卖股票问题

**问题描述**：给定一个数组 prices，其中 prices[i] 是一支给定股票第 i 天的价格。你只能选择某一天买入这只股票，并选择在未来的某一个不同的日子卖出该股票。设计一个算法来计算你所能获取的最大利润。返回你可以从这笔交易中获取的最大利润。如果你不能获取任何利润，返回 0 。

**解法**：一次遍历，记录历史最低价和最大利润

**备注**：统计历史最小值，但不能统计历史最大值，而是在每次遍历时计算当前价格与历史最低价的差值，并更新最大利润

```cpp
int maxProfit(vector<int>& prices) {
    int min_price = INT_MAX;
    int max_profit = 0;
    
    for (int price : prices) {
        min_price = min(min_price, price);
        max_profit = max(max_profit, price - min_price);
    }
    
    return max_profit;
}
```

## 买卖股票问题 II

**问题描述**：给定一个数组 prices，其中 prices[i] 是一支给定股票第 i 天的价格。在每一天，你可能会决定购买和/或出售股票。你在任何时候最多只能持有一股股票。你也可以购买它，然后在同一天出售。设计一个算法来计算你所能获取的最大利润。

**解法**：贪心算法，统计所有上升的差值

```cpp
int maxProfit(std::vector<int>& prices) {
    int profit = 0;
    for (int i = 1; i < prices.size(); ++i) {
        if (prices[i] > prices[i-1]) {
            profit += prices[i] - prices[i-1];
        }
    }
    return profit;
}
```
