# 背包

约定：W = 背包容量，w[i] = 第 i 个物品的重量，v[i] = 第 i 个物品的价值，c[i] = 第 i 个物品的数量（仅多重/混合背包使用）。

- c[i] = 0 → 物品无限（完全背包）
- c[i] = 1 → 0-1 背包
- c[i] > 1 → 多重背包，最多选 c[i] 次

## 0-1 背包

**问题描述**：每个物品只能选一次。

**解法**：倒序遍历保证每个物品只被考虑一次。

- dp[j]: 容量为 j 时能获得的最大价值
- 如果是二维 dp，可以正序遍历

```cpp
int knapsack_01(int W, vector<int>& w, vector<int>& v)
{
    int n = w.size();
    vector<int> dp(W + 1, 0);

    for (int i = 0; i < n; i++)
    {
        // 倒序遍历，保证每个物品只被考虑一次
        // 如果是二维dp，可以正序遍历
        for (int j = W; j >= w[i]; j--)
        {
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
        }
    }

    return dp[W];
}
```

## 完全背包

**问题描述**：每个物品可以选无限次。

**解法**：容量正序遍历。正序意味着 dp[j - w[i]] 可能已经选过物品 i，从而允许重复选择同一个物品。

```cpp
int knapsack_complete(int W, vector<int>& w, vector<int>& v)
{
    int n = w.size();
    vector<int> dp(W + 1, 0);

    for (int i = 0; i < n; i++)
    {
        for (int j = w[i]; j <= W; j++)   // 正序！和 0-1 唯一的区别
        {
            dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
        }
    }
    return dp[W];
}
```

## 多重背包（暴力版）

**问题描述**：每个物品最多选 c[i] 次。

**解法**：暴力做法：把每个物品的 k 次选择，看作 k 个独立的 0-1 背包。时间复杂度 O(W * Σc[i])，数量大时很慢。

```cpp
int knapsack_multiple_brute(int W, vector<int>& w, vector<int>& v, vector<int>& c)
{
    int n = w.size();
    vector<int> dp(W + 1, 0);

    for (int i = 0; i < n; i++)
    {
        for (int j = W; j >= w[i]; j--)        // 0-1 背包的倒序
        {
            for (int k = 1; k <= c[i] && k * w[i] <= j; k++)
            {
                dp[j] = max(dp[j], dp[j - k * w[i]] + k * v[i]);
            }
        }
    }
    return dp[W];
}
```

## 多重背包（二进制优化版）

**问题描述**：每个物品最多选 c[i] 次。

**解法**：把 c[i] 拆分成 1, 2, 4, 8, ..., 余数，转化为多个 0-1 物品。例如 c[i] = 13 → 拆成 1, 2, 4, 6（因为 1+2+4+6=13）。这样任意 1~13 的数量都能由这几个物品组合出来。时间复杂度 O(W * Σlog(c[i]))。

```cpp
int knapsack_multiple_binary(int W, vector<int>& w, vector<int>& v, vector<int>& c)
{
    vector<int> new_w, new_v;

    for (int i = 0; i < (int)w.size(); i++)
    {
        int amount = c[i];
        for (int k = 1; k <= amount; k *= 2)
        {
            new_w.push_back(w[i] * k);
            new_v.push_back(v[i] * k);
            amount -= k;
        }
        if (amount > 0)
        {
            new_w.push_back(w[i] * amount);
            new_v.push_back(v[i] * amount);
        }
    }

    vector<int> dp(W + 1, 0);
    for (int i = 0; i < (int)new_w.size(); i++)
    {
        for (int j = W; j >= new_w[i]; j--)
        {
            dp[j] = max(dp[j], dp[j - new_w[i]] + new_v[i]);
        }
    }
    return dp[W];
}
```

## 混合背包

**问题描述**：物品类型混合，包含 0-1 背包、完全背包、多重背包。

**解法**：根据 c[i] 的值判断使用哪种策略：
- c[i] = 0 → 完全背包（正序）
- c[i] = 1 → 0-1 背包（倒序）
- c[i] > 1 → 多重背包（二进制拆分后倒序）

统一写法：对于 0-1 或多重，都转为 0-1 物品处理。

```cpp
int knapsack_mixed(int W, vector<int>& w, vector<int>& v, vector<int>& c)
{
    vector<int> dp(W + 1, 0);

    for (int i = 0; i < (int)w.size(); i++)
    {
        if (c[i] == 0)
        {
            for (int j = w[i]; j <= W; j++)
            {
                dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
            }
        }
        else
        {
            vector<pair<int, int>> items;
            int amount = c[i];

            for (int k = 1; k <= amount; k *= 2)
            {
                items.push_back({ w[i] * k, v[i] * k });
                amount -= k;
            }
            if (amount > 0)
            {
                items.push_back({ w[i] * amount, v[i] * amount });
            }

            for (auto& [weight, value] : items)
            {
                for (int j = W; j >= weight; j--)
                {
                    dp[j] = max(dp[j], dp[j - weight] + value);
                }
            }
        }
    }
    return dp[W];
}
```
