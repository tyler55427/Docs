# 背包变体

## 题目名称

**问题描述**：显存清理问题。有 n 个张量，每个张量占用空间 s[i]，清理成本为 min(swap_cost[i], recalc_cost[i])。目标：释放至少 m 单位空间，求最小总成本。

**解法**：转化为 0-1 背包。将空间 s[i] 看作"价值"（我们希望累积达到 m），成本 cost[i] 看作"重量"（我们希望最小化）。dp[j] = 释放恰好 j 空间的最小成本，最后在 [m, limit] 中找最小成本。

```cpp
/*
 * 显存清理问题 → 转化为 0-1 背包
 *
 * 问题描述：
 *   有 n 个张量，每个张量占用空间 s[i]。
 *   清理第 i 个张量的成本为 min(swap_cost[i], recalc_cost[i])。
 *   目标：释放至少 m 单位空间，求最小总成本。
 *
 * 转化：
 *   - 每个张量 → 一个物品
 *   - 空间 s[i] → 物品的"价值"（我们希望累积达到 m）
 *   - 成本 cost[i] → 物品的"重量"（我们希望最小化）
 *   - 目标：总价值 ≥ m 时的最小总重量
 *
 * DP 定义：
 *   dp[j] = 释放恰好 j 空间的最小成本
 *   初始化：dp[0] = 0, 其余 = INF
 *   转移：dp[j] = min(dp[j], dp[j - s[i]] + cost[i])   （倒序）
 *   答案：min{ dp[j] }  for j ∈ [m, limit]
 *
 * 上限优化：
 *   不需要开到 total_space，只需开到 m + max_s。
 *   因为超过 m + max_s 的解一定可以去掉某个张量，空间仍 ≥ m，成本不增。
 */

const int INF = 1e9;

int min_cost_to_free_space(int m, vector<int>& space, vector<int>& swap_cost, vector<int>& recalc_cost) {
    int n = space.size();

    // 1. 每个张量的最小清理成本
    vector<int> cost(n);
    int max_s = 0;
    for (int i = 0; i < n; i++) {
        cost[i] = min(swap_cost[i], recalc_cost[i]);
        max_s = max(max_s, space[i]);
    }

    // 2. DP 容量上限：m + max_s
    int limit = m + max_s;
    vector<int> dp(limit + 1, INF);
    dp[0] = 0;

    // 3. 0-1 背包：倒序遍历
    for (int i = 0; i < n; i++) {
        int s = space[i];
        int c = cost[i];
        for (int j = limit; j >= s; j--) {
            if (dp[j - s] != INF) {
                dp[j] = min(dp[j], dp[j - s] + c);
            }
        }
    }

    // 4. 在 [m, limit] 中找最小成本
    int ans = INF;
    for (int j = m; j <= limit; j++) {
        ans = min(ans, dp[j]);
    }

    return ans;
}


// ==================== 测试 ====================
int main() {
    int m = 10;  // 需要释放至少 10 单位空间
    vector<int> space = { 6, 6, 3 };   // 每个张量占用的空间
    vector<int> swap_cost = { 3, 3, 5 };    // 交换成本
    vector<int> recalc_cost = { 4, 5, 1 };    // 重算成本

    int ans = min_cost_to_free_space(m, space, swap_cost, recalc_cost);

    if (ans >= INF) {
        cout << "error" << endl;
    }
    else {
        cout << "最小成本: " << ans << endl;  // 预期输出: 1 (选第3个张量，重算成本1，释放20空间)
    }

    return 0;
}
```
