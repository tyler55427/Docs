# 完全平方数

## 完全平方数问题

**问题描述**：给定一个正整数 n，返回和为 n 的完全平方数的最少数量。

**解法**：动态规划，维护一个 dp 数组，其中 dp[i] 表示和为 i 的完全平方数的最少数量

**备注**：对于每一个数，都要遍历之前的状态，找到最优解

```cpp
int numSquares(int n) {
    vector<int> dp(n + 1, INT_MAX);
    dp[0] = 0;
    
    for (int i = 1; i <= n; ++i) {
        for (int j = 1; j * j <= i; ++j) {
            dp[i] = min(dp[i], dp[i - j * j] + 1);
        }
    }
    
    return dp[n];
}
```
