# 打家劫舍

## 打家劫舍问题

**问题描述**：这个地方所有的房屋都形成一排。同时，相邻的房屋装有相互连接的防盗系统，如果两间相邻的房屋在同一夜晚被小偷闯入，系统会自动报警。

**解法**：动态规划，维护两个状态：不偷当前房屋和偷当前房屋

**备注**：

- 状态转移方程：`dp[i] = max(dp[i - 1], dp[i - 2] + nums[i])`
- 相邻约束，直接在状态转移方程中体现

```cpp
int rob(vector<int>& nums) {
    if (nums.empty()) {
        return 0;
    }
    if (nums.size() == 1) {
        return nums[0];
    }
  
    int prev2 = nums[0];
    int prev1 = max(nums[0], nums[1]);
  
    for (int i = 2; i < nums.size(); ++i) {
        int current = max(prev1, prev2 + nums[i]);
        prev2 = prev1;
        prev1 = current;
    }
  
    return prev1;
}
```

## 打家劫舍 II 问题

**问题描述**：这个地方所有的房屋都围成一圈，这意味着第一个房屋和最后一个房屋是紧挨着的。同时，相邻的房屋装有相互连接的防盗系统，如果两间相邻的房屋在同一夜晚被小偷闯入，系统会自动报警。

**解法**：计算两次打家劫舍问题，分别考虑偷第一个房屋和不偷第一个房屋的情况

```cpp
int rob(std::vector<int>& nums) {
    if (nums.size() == 1) return nums[0];
  
    auto robRange = [&](int start, int end) {
        int prev2 = 0, prev1 = 0;
        for (int i = start; i < end; ++i) {
            int current = std::max(prev1, prev2 + nums[i]);
            prev2 = prev1;
            prev1 = current;
        }
        return prev1;
    };
  
    return std::max(robRange(0, nums.size() - 1), robRange(1, nums.size()));
}
```
