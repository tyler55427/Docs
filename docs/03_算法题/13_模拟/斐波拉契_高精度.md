# 斐波拉契_高精度

## 斐波拉契_高精度

**问题描述**：计算斐波那契数列第 n 项的值，其中 m 和 n 给出，需要输出第 n-m+1 项（高精度计算）

**解法**：动态规划 + 高精度加法。使用二维数组 dp[i][j] 存储斐波那契数列第 i 项的第 j 位数字，从低位到高位存储，每次进行加法运算时处理进位

```cpp

int dp[1009][1009];
int cnt[1009];

int main()
{
	int m,n;
	cin>>m>>n;
	dp[1][1]=dp[2][1]=1;
	cnt[1]=cnt[2]=1;
	for(int i=3;i<=n;++i)
	{
		cnt[i]=cnt[i-1];
		for(int j=1;j<=cnt[i];++j)
		{
			dp[i][j]+=dp[i-1][j]+dp[i-2][j];
			if(dp[i][j]>9)
			{
				dp[i][j]%=10;
				dp[i][j+1]++;
			}
			if(dp[i][cnt[i]+1])
			{
				cnt[i]++;
				break;
			}
		}
	}
	for(int i=cnt[n-m+1];i>=1;--i)
	{
		cout<<dp[n-m+1][i];
	}
}
```
