# 高精度加法

## 高精度加法

**问题描述**：输入两个大整数（可能超过普通整数类型范围），计算它们的和

**解法**：竖式加法模拟。从低位到高位逐位相加，记录进位，处理不同长度的数

```cpp
int count;
int s[509];
// 高精度加法 
int main()
{
	string s1,s2;
	cin>>s1>>s2;
	int m=s1.length()-1;
	int n=s2.length()-1;
	int ci=0;
	while(m>=0&&n>=0)
	{
		s[count++]=(s1[m]-'0'+s2[n]-'0'+ci)%10;
		ci=(s1[m]-'0'+s2[n]-'0'+ci)/10;
		m--;
		n--;
	}
	while(m>=0)
	{
		s[count++]=(s1[m]-'0'+ci)%10;
		ci=(s1[m]-'0'+ci)/10;
		m--;
	}
	while(n>=0)
	{
		s[count++]=(s2[n]-'0'+ci)%10;
		ci=(s2[n]-'0'+ci)/10;
		n--;
	}
	if(ci) s[count++]=ci;
	for(int i=count-1;i>=0;--i)
	{
		cout<<s[i];
	}
	return 0;
}
```
