# 二分求根

**问题描述**：求一个三次多项式 f(x) = a[3]x³ + a[2]x² + a[1]x + a[0] 在区间 [-100,100] 内的所有实数根，精度要求 0.00001。

**解法**：二分法求根。对每个区间 [i, i+1]，如果 f(i) * f(i+1) <= 0，说明该区间内有根。使用二分法不断缩小区间，直到 |f(m)| < 0.00001。

```cpp
double a[4];

double f(double x)
{
    double r = 0;
    for (int i = 0; i < 4; ++i)
    {
        r = r * x + a[i];
    }
    return r;
}

double FF(double a, double b)
{
    double m = (a + b) / 2;
    while (f(m) > 0.00001 || f(m) < -0.00001)
    {
        if (f(a) * f(m) < 0)
        {
            b = m;
        }
        else
        {
            a = m;
        }
        m = (a + b) / 2;
    }
    return m;
}

int main()
{
    for (int i = 0; i < 4; ++i)
    {
        cin >> a[i];
    }
    for (double i = -100.4; i < 100.4; i++)
    {
        if (f(i) * f(i + 1) <= 0)
        {
            cout << fixed << setprecision(2) << FF(i, i + 1) << " ";
        }
    }
}
```
