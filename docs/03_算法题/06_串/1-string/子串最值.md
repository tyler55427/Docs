# 子串最值

## 连续子数组最大和（Kadane 算法）

**解法**：动态规划，sum 表示以当前元素结尾的最大子数组和，sum = max(单独一个元素, 前面累加和 + 当前元素)，即若前面累加和为负，则不如从当前重新开始

```cpp
int maxSubarraySum(vector<int>& v)
{
    int sum = 0;
    int res = 0;
    for(int i : v)
    {
        sum = max(sum + i, i);  // 以 i 结尾的最大和
        res = max(sum, res);     // 更新全局最大和
    }
    return res;
}
```

## 连续子数组最小和

**解法**：动态规划，sum 表示以当前元素结尾的最小子数组和，sum = min(单独一个元素, 前面累加和 + 当前元素)

```cpp
int minSubarraySum(vector<int>& v)
{
    int sum = 0;
    int res = INT_MAX;  // 全局最小和，初始化为极大值
    for(int i : v)
    {
        sum = min(i, sum + i);   // 以 i 结尾的最小和
        res = min(sum, res);     // 更新全局最小和
    }
    return res;
}
```

## 连续子数组最大乘积

**解法**：动态规划，需要同时维护最大乘积和最小乘积，因为两个负数相乘可能变成最大正数

```cpp
int maxSubarrayProduct(vector<int>& v)
{
    int maxProd = v[0];
    int minProd = v[0];
    int res = v[0];

    for(int i = 1; i < v.size(); ++i)
    {
        int mx = maxProd, mn = minProd;
        maxProd = max({mx * v[i], mn * v[i], v[i]});
        minProd = min({mx * v[i], mn * v[i], v[i]});
        res = max(res, maxProd);
    }
    return res;
}
```
