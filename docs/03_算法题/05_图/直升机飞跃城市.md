# 直升机飞跃城市

**问题描述**：给定一个 n×m 的网格，每个格子有一个高度。直升机从 (0,0) 出发，目的地是 (n-1,m-1)。飞行代价包括上升代价、下降代价和平地代价，求最小总代价。

**解法**：Dijkstra 最短路。状态为 (x, y, h)，h 表示到达该位置时的最大高度。每一步根据目标高度与当前高度决定上升或平地，下降只在终点结算。

## 结构体

```cpp
struct State
{
    int x, y, h;
    int cost;
    bool operator<(const State& other) const
    {
        return cost > other.cost;
    }
};
```

## 主函数

```cpp
int main()
{
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n, m;
    cin >> n >> m;

    int cost_up, cost_down, cost_flat;
    cin >> cost_up >> cost_down >> cost_flat;

    vector<vector<int>> grid(n, vector<int>(m));
    int max_h = 0;
    for (int i = 0; i < n; i++)
    {
        for (int j = 0; j < m; j++)
        {
            cin >> grid[i][j];
            max_h = max(max_h, grid[i][j]);
        }
    }

    vector<vector<bool>> dist(n, vector<bool>(m, false));

    int start_h = grid[0][0];

    priority_queue<State> pq;
    pq.push({ 0, 0, start_h, 0 });

    while (!pq.empty())
    {
        State cur = pq.top();
        pq.pop();

        int x = cur.x, y = cur.y, h = cur.h;
        int cost = cur.cost;

        if (dist[x][y]) continue;
        dist[x][y] = true;

        if (x == n - 1 && y == m - 1)
        {
            cout << cost + (grid[n - 1][m - 1] - h) * cost_down << endl;
            return 0;
        }

        for (int d = 0; d < 4; d++)
        {
            int nx = x + dx[d];
            int ny = y + dy[d];

            if (nx < 0 || nx >= n || ny < 0 || ny >= m) continue;

            int target_h = grid[nx][ny];

            int new_h = max(h, target_h);
            int new_cost = cost + relu(target_h - h) * cost_up + cost_flat;
            pq.push({ nx, ny, new_h, new_cost });
        }
    }

    cout << "-1" << endl;
    return 0;
}
```

**备注**：
- 状态表示到达 (x,y) 时路径上的最大高度 h
- 只有最后到达终点时才结算下降代价
- 使用优先队列实现 Dijkstra，保证代价最小
