# 课程表

**问题描述**：你这个学期必须选修 numCourses 门课程，记为 0 到 numCourses-1。给你一个数组 prerequisites，其中 prerequisites[i] = [ai, bi]，表示如果要学习课程 ai 则必须先学习课程 bi。请你判断是否可能完成所有课程的学习？

**解法**：统计入度和边，更新入度，最终统计个数或者统计是否所有节点的入度都为0

```cpp
bool canFinish(int numCourses, vector<vector<int>>& prerequisites) {
    // 存边
    vector<vector<int>> graph(numCourses);
    // 存入度
    vector<int> indegree(numCourses, 0);
  
    for (auto& edge : prerequisites) {
        graph[edge[1]].push_back(edge[0]);
        ++indegree[edge[0]];
    }
  
    queue<int> q;
    for (int i = 0; i < numCourses; ++i) {
        if (indegree[i] == 0) {
            q.push(i);
        }
    }
  
    int count = 0;
    while (!q.empty()) {
        int node = q.front();
        q.pop();
        ++count;
        for (int neighbor : graph[node]) {
            --indegree[neighbor];
            if (indegree[neighbor] == 0) {
                q.push(neighbor);
            }
        }
    }
  
    return count == numCourses;
}
```
