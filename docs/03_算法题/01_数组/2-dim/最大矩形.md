# 最大矩形

**问题描述**：给定一个仅包含 0 和 1 的二维二进制矩阵，找到只包含 1 的最大矩形，并返回其面积。

**解法**：将每一行看作一个直方图，统计柱形图，然后使用[柱状图中最大矩形](./../../03_堆栈队列/柱状图中最大矩形.md)求解。

```cpp
int maximalRectangle(vector<vector<char>>& matrix)
{
    // 如果矩阵为空，直接返回 0
    if (matrix.empty()) return 0;

    // m 为行数，n 为列数
    int m = matrix.size(), n = matrix[0].size();

    // heights[j] 表示当前行第 j 列向上连续 '1' 的高度
    vector<int> heights(n, 0);

    // 记录全局最大矩形面积
    int max_area = 0;

    // 逐行遍历，把每一行当作底边
    for (int i = 0; i < m; ++i)
    {
        // 更新高度数组：
        // 如果当前格子是 '1'，高度累加 1；
        // 否则高度清零
        for (int j = 0; j < n; ++j)
        {
            heights[j] = matrix[i][j] == '1' ? heights[j] + 1 : 0;
        }

      	// 调用已有算法
        max_area = max(max_area, largestRectangleArea(heights));
    }

    // 返回最大矩形面积
    return max_area;
}
```
