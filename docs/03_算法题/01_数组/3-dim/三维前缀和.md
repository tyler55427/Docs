# 三维前缀和

## 题目名称

**问题描述**：计算三维数组的前缀和

**解法**：对每一个维度单独求前缀和降维。先对第三维（k）做前缀和，再对第二维（j）做前缀和，最后对第一维（i）做前缀和。

```cpp
int a[100][100][100];

// 三维前缀和，对每一个维度单独求前缀和降维
int main(){
	int n,m,l;
	cin>>n>>m>>l;

	for(int i=0;i<n;++i){
		for(int j=0;j<m;++j){
			for(int k=0;k<l;++k){
				cin>>a[i][j][k];
			}
		}
	}

	for(int i=0;i<n;++i){
		for(int j=0;j<m;++j){
			for(int k=1;k<l;++k){
				a[i][j][k]=a[i][j][k-1]+a[i][j][k];
			}
		}
	}

	for(int i=0;i<n;++i){
		for(int j=1;j<m;++j){
			for(int k=0;k<l;++k){
				a[i][j][k]=a[i][j-1][k]+a[i][j][k];
			}
		}
	}

	for(int i=1;i<n;++i){
		for(int j=0;j<m;++j){
			for(int k=0;k<l;++k){
				a[i][j][k]=a[i-1][j][k]+a[i][j][k];
			}
		}
	}

	for(int i=0;i<n;++i){
		for(int j=0;j<m;++j){
			for(int k=0;k<l;++k){
				cout<<a[i][j][k]<<" ";
			}
			cout<<endl;
		}
		cout<<"\n\n";
	}

	return 0;
}
```
