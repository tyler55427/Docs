# 前缀和哈希

## 题目名称

**问题描述**：给定两个字符串 stra 和 strb，求最长的公共前缀和后缀长度。找出 stra 的前缀与 strb 的后缀最长相同的长度，以及 stra 的后缀与 strb 的前缀最长相同的长度。

**解法**：使用前缀哈希（base = 131，unsigned long long 自动溢出）。预处理两个字符串的前缀哈希值和幂次数组。枚举长度 i，分别比较 `stra[1..i]` 与 `strb[lenb-i+1..lenb]` 以及 `stra[lena-i+1..lena]` 与 `strb[1..i]`，取最大值。

```cpp
using namespace std;
const int N=110,base=131;
typedef unsigned long long ULL;
ULL p[N],hl[N],hr[N];
char stra[N],strb[N];
int lena,lenb,lmax;

ULL get(ULL h[],int l,int r)
{
	return h[r]-h[l-1]*p[r-l+1];
}//求l~r的区间哈希值
int main()
{
	int i,j,res=INT_MIN;
	scanf("%s%s",stra+1,strb+1);
	lena=strlen(stra+1);
	lenb=strlen(strb+1);
	lmax=max(lena,lenb);//求最长字符串的长度
	p[0]=1;

	for(i=1;i<=lena;i++) hl[i]=hl[i-1]*base+(stra[i]-96);
	for(i=1;i<=lenb;i++) hr[i]=hr[i-1]*base+(strb[i]-96);
	for(i=1;i<=lmax;i++) p[i]=p[i-1]*base;
	//求前缀哈希值
  
	for(i=1;i<=lmax;i++)
	{
		int al,bl;
		if(lena<i||lenb<i) break;//判断边界
		al=get(hl,1,i)!=get(hr,lenb-i+1,lenb)?INT_MIN:i;
        //判断第一个字符串的前缀的区间哈希值和第二个字符串的后缀的区间哈希值是否相等
		bl=get(hl,lena-i+1,lena)!=get(hr,1,i)?INT_MIN:i;
		//判断第一个字符串的后缀的区间哈希值和第二个字符串的前缀的区间哈希值是否相等
		res=max(res,max(al,bl));//求最大值
	}
	printf("%d\n",res);
	return 0;//华丽的结尾~~~
}
```

**备注**：

- 使用 unsigned long long 自然溢出，比取模更快且无碰撞
- stra[i]-96 将字符转为数字（'a'=1, 'b'=2, ...）
