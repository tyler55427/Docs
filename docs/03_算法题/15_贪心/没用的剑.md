## 没用的剑

**问题描述**：给定 n 把剑，每把剑有两个属性 (p[i], q[i])。按 p 从大到小排序后，统计有多少把剑的 q 值严格大于当前已见到的最大 q 值（即从左到右统计有多少个 "新的最大值"）

**解法**：排序 + 线性扫描。先按 p 降序排序，遍历数组维护最大 q 值，统计严格大于最大 q 值的数量

```cpp
int n, ans, maxn;
pair<int, int> p[100001];
int main() {
    cin >> n;
    for (int i = 1; i <= n; ++i) {
      cin >> p[i].first >> p[i].second;
    }
    sort(p + 1, p + 1 + n);
    for (int i = n; i; --i) {
    	if (p[i].second > maxn) {
    		ans++;
    		maxn = p[i].second;
    	}
    }
    cout << ans;
    return 0;
}
```
