# 摩尔投票

## 摩尔投票算法

**说明**：只适合有一半以上的情况

```cpp
int boyerVote(int arr[]){
    int candidate = -1, vote = 0;
    for(int i=0;arr[i];i++){
        if(vote == 0){
            candidate = arr[i];
        }
        if( candidate == arr[i] ){
            vote++;
        }else{
            vote--;
        }
    }
    return candidate;
}
```

## 寻找多数元素

**解法**：摩尔投票算法分两阶段

```cpp
int findMajorityElement(const std::vector<int>& nums) {
    int count = 0;
    int candidate = 0;

    // Phase 1: Find a candidate for majority element
    for (int num : nums) {
        if (count == 0) {
            candidate = num;
        }
        // 归零后，重新计数，一定满足条件，+1
        count += (num == candidate) ? 1 : -1;
    }

    // Phase 2: Verify if the candidate is indeed the majority element
    count = 0;
    for (int num : nums) {
        if (num == candidate) {
            count++;
        }
    }

    // If the candidate appears more than half of the time, return it
    if (count > nums.size() / 2) {
        return candidate;
    }

    // If there is no majority element, return -1
    return -1;
}
```
