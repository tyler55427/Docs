# 接雨水

## 接最多雨水

**问题描述**：给定 n 个非负整数表示柱子的高度，选择两条线段，使得它们与 x 轴形成的容器可以容纳最多的水。

**解法**：左右指针 + 贪心，每次移动较短的指针，统计更新面积

**备注**：能够移动较短的指针达到贪心，是因为面积由较短的边界决定

```cpp
int maxArea(vector<int>& height) {
    int left = 0, right = height.size() - 1;
    int width = right - left;
    int max_area = 0;

    while (left < right) {
        int h = min(height[left], height[right]);
        max_area = max(max_area, h * width);

        if (height[left] < height[right]) {
            ++left;
        }
        else {
            --right;
        }
        width--;
    }

    return max_area;
}
```

## 总共接雨水

**问题描述**：给定 n 个非负整数表示柱子的高度，每个柱子宽度为 1，计算下雨后能接多少雨水。

**解法**：统计每一个节点，维护当前节点两端的最大高度，计算当前节点能接的水量。如果当前节点作为边界，无法接水，并更新边界高度。

**备注**：一边只知道自己这边能看到的最大值，看到不另一边，所以需要保证右边至少有和左边一样高的边界

```cpp
int trap(vector<int>& height) {
    if (height.empty()) return 0;

    int left = 0, right = height.size() - 1;
    int left_max = 0, right_max = 0;
    int water = 0;

    while (left < right) {
        // 能看到左边的最大值，但看不到右边的最大值，但是知道右边至少有和左边一样高的边界，所以以左边为边界计算水量
        if (height[left] < height[right]) {
            if (height[left] >= left_max) {
                left_max = height[left];
            }
            else {
                // 以短板为边界，计算当前节点能接的水量
                water += left_max - height[left];
            }
            ++left;
        }
        else {
            if (height[right] >= right_max) {
                right_max = height[right];
            }
            else {
                water += right_max - height[right];
            }
            --right;
        }
    }

    return water;
}
```
