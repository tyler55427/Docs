# 删除倒数节点

**问题描述**：给定一个链表，删除链表的倒数第 n 个节点，并返回链表的头节点。

**解法**：使用双指针技巧。first 先移动 n + 1 步，然后同时移动 first 和 second，直到 first 到达链表末尾。此时 second 的下一个节点就是要删除的节点。

## 双指针

```cpp
ListNode* removeNthFromEnd(ListNode* head, int n)
{
    ListNode* dummy = new ListNode(0);
    dummy->next = head;

    ListNode* first = dummy;
    ListNode* second = dummy;

    // first 先移动 n + 1 步
    for (int i = 0; i <= n; ++i)
    {
        first = first->next;
    }

    // 同时移动 first 和 second
    while (first)
    {
        first = first->next;
        second = second->next;
    }

    // 删除倒数第 n 个节点
    second->next = second->next->next;

    return dummy->next;
}
```

**备注**：

- 使用虚拟头节点 dummy 统一处理边界情况（删除第一个节点时无需特殊判断）
- 只遍历一次链表即可完成删除，时间复杂度 O(n)，空间复杂度 O(1)
