# 大数加法

## 大数加法

**问题描述**：

- 给定两个非空链表，表示两个非负整数。
- 它们的位数是按照逆序的方式存储的，并且每个节点只能存储一位数字。
- 请将两个数相加，并以相同形式返回一个表示和的链表。

**解法**：模拟，处理单链，最后处理进位。比数组好处理

```cpp
ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) {
    ListNode* head = new ListNode(0);
    ListNode* now = head;
    while (l1 && l2) {
        ListNode* tmp = new ListNode(l1->val + l2->val + (now->val) / 10);
        now->val %= 10;
        now->next = tmp;
        now = tmp;
        l1 = l1->next;
        l2 = l2->next;
    }
    while (l1) {
        ListNode* tmp = new ListNode(l1->val + (now->val) / 10);
        now->val %= 10;
        now->next = tmp;
        now = tmp;
        l1 = l1->next;
    }
    while (l2) {
        ListNode* tmp = new ListNode(l2->val + (now->val) / 10);
        now->val %= 10;
        now->next = tmp;
        now = tmp;
        l2 = l2->next;
    }
    if (now->val > 9) {
        ListNode* tmp = new ListNode(1);
        now->next = tmp;
        now->val %= 10;
    }
    return head->next;
}
```
