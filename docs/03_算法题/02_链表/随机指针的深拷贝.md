# 随机指针的深拷贝

**问题描述**：给定一个链表，每个节点包含一个额外增加的随机指针，该指针可以指向链表中的任何节点或空节点（NULL）。要求返回这个链表的深拷贝，即创建一个新的链表，新链表中的每个节点都是原链表节点的拷贝，且随机指针指向也正确拷贝。

**解法**：提供两种解法。

- （1）哈希表法：第一次遍历创建所有新节点并存入哈希表，第二次遍历设置新节点的 next 和 random 指针。
- （2）迭代法（奥观海法）：在原链表每个节点后插入新节点，设置新节点的 random 指针，最后分离两个链表。

## 哈希表法

时间复杂度 O(n)，空间复杂度 O(n)。

```cpp
class Node
{
public:
    int val;
    Node* next;
    Node* random;

    Node(int _val)
    {
        val = _val;
        next = NULL;
        random = NULL;
    }
};

Node* copyRandomList(Node* head)
{
    if (!head) return nullptr;
    unordered_map<Node*, Node*> mp;
    Node* now = head;
    while (now)
    {
        mp[now] = new Node(now->val);
        now = now->next;
    }
    now = head;
    while (now)
    {
        mp[now]->next = mp[now->next];
        mp[now]->random = mp[now->random];
        now = now->next;
    }
    return mp[head];
}
```

## 迭代法

时间复杂度 O(n)，空间复杂度 O(1)，最优解法。核心思想是将新节点插入到原节点的后面，这样可以通过 `node->next` 访问到新节点对应的原节点，从而正确设置 random 指针。

```cpp
Node* copyRandomList(Node* head)
{
    if (head == nullptr)
    {
        return nullptr;
    }
    // 创建中间新节点
    for (Node* node = head; node != nullptr; node = node->next->next)
    {
        Node* nodeNew = new Node(node->val);
        nodeNew->next = node->next;
        node->next = nodeNew;
    }
    // 设置新节点的 random 指针
    for (Node* node = head; node != nullptr; node = node->next->next)
    {
        Node* nodeNew = node->next;
        nodeNew->random = (node->random != nullptr) ? node->random->next : nullptr;
    }
    // 提取新链表并恢复原链表
    Node* headNew = head->next;
    for (Node* node = head; node != nullptr; node = node->next)
    {
        Node* nodeNew = node->next;
        node->next = node->next->next;
        nodeNew->next = (nodeNew->next != nullptr) ? nodeNew->next->next : nullptr;
    }
    return headNew;
}
```

**备注**：

- 哈希表法：时间复杂度 O(n)，空间复杂度 O(n)
- 迭代法：时间复杂度 O(n)，空间复杂度 O(1)，最优解法
- 迭代法的核心思想是将新节点插入到原节点的后面，这样可以通过 `node->next` 访问到新节点对应的原节点，从而正确设置 random 指针
