# 环形链表

## 环形链表问题

**问题描述**：给定一个链表，判断链表中是否有环

**解法**：使用快慢指针，快指针每次移动两步，慢指针每次移动一步，如果链表中有环，快指针最终会追上慢指针

```cpp
bool hasCycle(ListNode* head) {
    if (!head || !head->next) {
        return false;
    }
    
    ListNode* slow = head;
    ListNode* fast = head->next;
    
    while (slow != fast) {
        // 当fast无法移动的时候
        if (!fast || !fast->next) {
            return false;
        }
        slow = slow->next;
        fast = fast->next->next;
    }
    
    return true;
}
```

## 找到环的入口节点

**解法**：当快慢指针相遇时，将慢指针重新指向链表头部，快指针保持在相遇点，然后两个指针每次移动一步，最终会在环的入口节点相遇

```cpp
ListNode *detectCycle(ListNode *head) {
    if (!head || !head->next) return nullptr;
    // 这里需要初始化为两个head，先走一步
    ListNode* slow = head->next;
    ListNode *fast = head->next->next;
    while(slow!=fast){
        if(!fast||!fast->next) return nullptr;
        slow=slow->next;
        fast=fast->next->next;
    }
    // 当快慢指针相遇时，将慢指针重新指向链表头部，快指针保持在相遇点，然后两个指针每次移动一步，最终会在环的入口节点相遇
    slow = head;
    while(slow!=fast){
        slow=slow->next;
        fast=fast->next;
    }
    return slow;
}
```
