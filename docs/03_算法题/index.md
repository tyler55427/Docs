# 03 算法题

按考点分类的刷题笔记，每个 .md 文件对应一道题。

下列分类目录内直接是题目文件，无总目录，故不做链接。

## 按数据结构

- `01_数组/` — 一维、二维、三维
- `02_链表/` — 反转、合并、回文、环形、相交、LRU、dance_links 等
- `03_堆栈队列/` — 单调栈、最小栈、滑动窗口最大值、柱状图最大矩形等
- `04_树/` — 翻转、对称、右视图、完全二叉树，另有 `性质/`、`特殊树/` 子目录
- `05_图/` — 岛屿数量、课程表、图着色、前向星、单词接龙等
- `06_串/` — AC 自动机，另有 `1-string/`、`2-string/` 子目录

## 按考点

- `11_递归迭代/` — 记忆化递归、快速乘法、错排
- `12_动态规划/` — 背包、序列问题、约束状态，另有股票、打家劫舍、数位 DP 等
- `13_模拟/` — 数独、表达式、高精度加法/乘法、约瑟夫问题等
- `14_搜索/` — `二分/`、`回溯/` 两个子目录，另有马走日、旋转数组等
- `15_贪心/` — 合并区间、跳跃游戏、接雨水、摩尔投票等
- `16_哈希/` — 前缀和哈希、DNA
- `17_位运算/` — 只出现一次的数字、精确覆盖
- `18_数学/` — Catalan、质数、统计矩形、gcd

## 其他

- `00_笔记/` — 算法笔记与配图
