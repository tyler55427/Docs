# 直线划分平面

## 一条直线划分平面

**问题描述**：给定一条直线，求这条直线将平面划分为多少个区域。
**解法**：
- 一条直线将平面划分为2个区域。
- 新增一条直线时，若与已有的直线相交，则被(n-1)条直线划分的区域数增加n，若不相交，则增加1。
- 由此可以得到递推公式：f(n) = f(n-1) + n，f(1) = 2。

推导得到：
$$
f(n) = \frac{n(n + 1)}{2} + 1
$$

## 折线划分平面

**问题描述**：给定一条折线，求这条折线将平面划分为多少个区域。
**解法**：
- 折线可以看作是由多条直线组成的，因此可以使用类似的思路来解决。
- 新增一条折线时，看成两条直线与之前的直线相交，增加 2\*2\*(n-1) 个区域。
- 但是由于折线有端点，因此需要考虑端点的影响，最终得到递推公式：f(n) = f(n-1) + 4\*(n-1) + 1，f(1) = 2。

推导得到：
$$
f(n) = 2n^2 - n + 1
$$
