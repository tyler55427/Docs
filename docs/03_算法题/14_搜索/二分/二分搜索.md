# 二分搜索

## 二分搜索

**问题描述**：在一个有序数组中搜索一个特定的值，可以重复

**解法**：经典二分搜索，找到目标值的任意一个位置

```cpp
int findNum(vector<int>& nums, int target) {
    int left = 0, right = nums.size() - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] == target) {
            return mid;
        }
        else if (nums[mid] < target) {
            left = mid + 1;
        }
        else {
            right = mid - 1;
        }
    }
    return -1;
}
```

## 找到目标值的第一个位置

**解法**：左闭右开

```cpp
int findFirst(vector<int>& nums, int target) {
    // 左闭右开
    int left = 0, right = nums.size();
    // 不取等号
    while (left < right) {
        int mid = left + (right - left) / 2;
        // 保证严格小于
        if (nums[mid] < target) {
            left = mid + 1;
        }
        else {
            right = mid;
        }
    }

    if (left < nums.size() && nums[left] == target) {
        return left;
    }
    else {
        return -1;
    }
}
```

## 找到目标值的最后一个位置

```cpp
int findLast(vector<int>& nums, int target) {
    // 左闭右开
    int left = 0, right = nums.size();
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] <= target) {
            left = mid + 1;
        }
        else {
            right = mid;
        }
    }

    if (left > 0 && nums[left - 1] == target) {
        return left - 1;
    }
    else {
        return -1;
    }
}
```
