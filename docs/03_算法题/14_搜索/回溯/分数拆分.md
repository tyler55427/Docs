# 分数拆分

**问题描述**：将分数 a/b 分解为若干个互不相同的单位分数之和（单位分数即 1/x 形式的分数，如 1/2 + 1/3 + 1/6 = 1）。古埃及数学中只用单位分数表示分数。

**解法**：DFS + 贪心剪枝（回溯搜索）。从最小的合法分母开始枚举，通过剪枝减少搜索空间。剪枝策略包括：分母下界约束（e >= b/a 向上取整）、上界约束（d * b >= a * e1）。

**备注**：输入格式为多组 a b 数据；按深度递增尝试，直到找到解。

## 全局变量

```cpp
constexpr int MAX_DENOM = 1e7;  // 分母上限

int a, b;  // 待分解的分数 a/b
vector<int> best;      // 当前最优解（最后一项分母最小）
vector<int> current;   // 搜索过程中的当前解
```

## 辅助函数

判断当前解是否优于已记录的最优解：最后一项的分母越小，整体"精度"越高。

```cpp
bool isBetter()
{
    return best.empty() || current.back() < best.back();
}
```

求最大公约数（用于分数化简）。

```cpp
long long gcd(long long x, long long y)
{
    return y ? gcd(y, x % y) : x;
}
```

## DFS 搜索

将分数 a/b 分解为 d 个单位分数。a/b: 待分解的分数（化简后的真分数），d: 剩余需要的单位分数个数，e: 最小允许的分母（避免重复分解）。

递归终止：已分解完 d 个分数。

化简分数：约去分子分母的公因子。

计算分母下界 e1。约束条件：a/b - 1/e >= 0（单位分数不能为负），即 e >= b/a（向上取整）。

剪枝：如果 b/a 超过最大分母限制，则无解。

上界剪枝：检查是否还能在 d 个分数内完成分解。条件：d * (1/e1) >= a/b 即 d/e1 >= a/b 即 d*b >= a*e1。若 d*b < a*e1，说明即使填满 d 个最大的分数也不够，无解。

```cpp
bool dfs(int d, long long a, long long b, int e)
{
    if (d == 0)
    {
        if (a == 0 && isBetter())
            best = current;
        return a == 0;
    }

    // 化简分数：约去分子分母的公因子
    long long g = gcd(a, b);
    a /= g;
    b /= g;

    bool solved = false;

    // 计算分母下界 e1
    // 约束条件：a/b - 1/e >= 0 （单位分数不能为负）
    // 即 e >= b/a（向上取整）
    int e1 = max(e + 1, (int)((b + a - 1) / a));

    // 剪枝：如果 b/a 超过最大分母限制，则无解
    if (b > a * MAX_DENOM)
        return false;

    for (;; ++e1)
    {
        // 上界剪枝：检查是否还能在 d 个分数内完成分解
        // 条件：d * (1/e1) >= a/b 即 d/e1 >= a/b 即 d*b >= a*e1
        // 若 d*b < a*e1，说明即使填满 d 个最大的分数也不够，无解
        if (d * b < a * e1)
            return solved;

        // 选择分母 e1，计算剩余分数
        // a/b - 1/e1 = (a*e1 - b) / (b*e1)
        current.push_back(e1);
        solved |= dfs(d - 1, a * e1 - b, b * e1, e1 + 1);
        current.pop_back();
    }
    return solved;
}
```

## 主求解函数

从深度 1 开始尝试，直到找到解或达到深度上限。分母从 2 开始（1/x 中的 x）。

```cpp
int solve()
{
    best.clear();
    current.clear();
    for (int maxDepth = 1; maxDepth <= 100; ++maxDepth)
    {
        if (dfs(maxDepth, a, b, 2))
            return maxDepth;
    }
    return -1;
}
```
