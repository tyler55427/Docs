# 括号生成

## 括号生成问题

**问题描述**：给定一个整数 n，生成所有由 n 对括号组成的有效括号组合

**解法**：回溯，维护当前生成的括号字符串以及左右括号的数量，确保生成的字符串始终有效

```cpp
void backtrack(vector<string>& result, string path, int left, int right, int n) {
    if (path.length() == 2 * n) {
        result.push_back(path);
        return;
    }

    // 只有当左括号数量小于 n 时，才可以添加左括号
    if (left < n) {
        backtrack(result, path + '(', left + 1, right, n);
    }
    // 只有当右括号数量小于左括号数量时，才可以添加右括号
    if (right < left) {
        backtrack(result, path + ')', left, right + 1, n);
    }
}

vector<string> generateParenthesis(int n) {
    vector<string> result;

    backtrack(result, "", 0, 0, n);
    return result;
}
```
