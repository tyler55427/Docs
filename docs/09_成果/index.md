# 09 成果

自己产出的成品：应用、脚本与可复用的 Claude Code skills。分类说明见 [00_base.md](./00_base.md)。

- `apps/` — AutoHotkey 应用：`BossKey.ahk`（老板键，快速显示/隐藏应用）、`Direct.ahk`（快捷键替代方向键）
- `scripts/` — 脚本（暂无内容）
- `skills/` — Claude Code 技能：
  - `docs-reader/` — 读取/提取/修改 Office 文档
  - `session-manager/` — WSL/Windows 下 Claude 的右下角消息通知
    - 仓库：<https://github.com/tyler55427/session-manager>
