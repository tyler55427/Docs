# 完全二叉树

## 完全二叉树相关操作

**定义**：根节点深度为 1；深度为 d 的完全二叉树最多有 2^d-1 个节点

## 求节点索引 x 所在的层数

```cpp
int getLevel(int x)
{
    int level = 1;
    while(x > pow(2, level) - 1) ++level;
    return level;
}
```

## 求完全二叉树的叶子数

**规律**：叶子数 = ceil(n/2) = (n+1)/2

```cpp
int countLeaves(int n)
{
    if(n == 1) return 1;  // 只有一个节点时，它是叶子

    int depth = getLevel(n);
    int lastLevelNodes = n - (pow(2, depth-1) - 1);
    return lastLevelNodes
         + (pow(2, depth-2) - ceil(lastLevelNodes / 2.0));
    // return (n + 1) / 2;  // 简化公式
}
```

## 求左子树节点数

**核心思想**：完全二叉树中，左子树至少是"倒数第二层满"的大小

```cpp
int countLeftSubtreeNodes(int n)
{
    if(n == 1) return 0;  // 只有一个节点时，左子树为空

    int depth = getLevel(n);
    int lastLevelNodes = n - (pow(2, depth-1) - 1);

    if(lastLevelNodes <= pow(2, depth-2))
        return n - lastLevelNodes / 2;
    else
        return (pow(2, depth-1) - 1) / 2 + pow(2, depth-2);
}
```

## 构造完全二叉搜索树（默认递增序列）

```cpp
void buildCBT_default(int s, int e, int baseIndex, int treeIdx)
{
    if(s > e) return;
    if(s == e) {
        arr[treeIdx] = s;
        return;
    }

    int leftCount = countLeftSubtreeNodes(e - s + 1);
    arr[treeIdx] = baseIndex + leftCount;

    buildCBT_default(s, baseIndex + leftCount - 1, s, treeIdx * 2);
    buildCBT_default(baseIndex + leftCount + 1, e, baseIndex + leftCount + 1, treeIdx * 2 + 1);
}
```

## 构造完全二叉搜索树（自定义数组）

```cpp
void buildCBT_custom(int s, int e, int baseIndex, int treeIdx, int input[])
{
    if(s > e) return;
    if(s == e) {
        arr[treeIdx] = input[s];
        return;
    }

    int leftCount = countLeftSubtreeNodes(e - s + 1);
    arr[treeIdx] = input[baseIndex + leftCount];

    buildCBT_custom(s, baseIndex + leftCount - 1, s, treeIdx * 2, input);
    buildCBT_custom(baseIndex + leftCount + 1, e, baseIndex + leftCount + 1, treeIdx * 2 + 1, input);
}
```
