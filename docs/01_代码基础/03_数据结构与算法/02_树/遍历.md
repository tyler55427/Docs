# 遍历

## 结构体定义

```cpp
struct Node
{
    int data;
    Node* l;
    Node* r;
};

typedef Node* BinTree;  // 用指针类型定义二叉树
```

## 创建节点

```cpp
// 创建一个值为 d 的节点
BinTree createNode(int d)
{
    BinTree t = new Node;
    t->data = d;
    t->l = nullptr;
    t->r = nullptr;
    return t;
}
```

## 先序遍历（递归）

根-左-右

```cpp
void preorderRecursive(BinTree t)
{
    if (t)
    {
        cout << t->data << " ";
        preorderRecursive(t->l);
        preorderRecursive(t->r);
    }
}
```

## 中序遍历（递归）

左-根-右

```cpp
void inorderRecursive(BinTree t)
{
    if (t)
    {
        inorderRecursive(t->l);
        cout << t->data << " ";
        inorderRecursive(t->r);
    }
}
```

## 后序遍历（递归）

左-右-根

```cpp
void postorderRecursive(BinTree t)
{
    if (t)
    {
        postorderRecursive(t->l);
        postorderRecursive(t->r);
```

## 层次遍历

利用队列按层访问

```cpp
void levelTraversal(BinTree t)
{
    if (!t) return;
    queue<BinTree> q;
    q.push(t);
    while (!q.empty())
    {
        BinTree node = q.front();
        q.pop();
        cout << node->data << " ";
        if (node->l) q.push(node->l);
        if (node->r) q.push(node->r);
    }
}
```

## 层序遍历（带层次）

返回每层的节点值

```cpp
struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode() : val(0), left(nullptr), right(nullptr) {}
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
    TreeNode(int x, TreeNode* left, TreeNode* right) : val(x), left(left), right(right) {}
};

vector<vector<int>> levelOrder(TreeNode* root)
{
    vector<vector<int>> ret;
    if (!root) return ret;

    queue<TreeNode*> q;
    q.push(root);
    while (!q.empty())
    {
        int currentLevelSize = q.size();
        ret.push_back(vector<int>());
        for (int i = 1; i <= currentLevelSize; ++i)
        {
            auto node = q.front(); q.pop();
            ret.back().push_back(node->val);
            if (node->left)  q.push(node->left);
            if (node->right) q.push(node->right);
        }
    }
    return ret;
}
```

## 先序遍历（非递归）

沿左子树一路向下访问，遇到节点就输出并压栈，然后回溯处理右子树。右子节点先入栈，确保左子节点先被处理。

```cpp
void preorderIterative(BinTree t)
{
    if (!t) return;
    stack<BinTree> s;
    s.push(t);
    while (!s.empty())
    {
        BinTree node = s.top();
        s.pop();
        cout << node->data << " ";
        if (node->r) s.push(node->r);
        if (node->l) s.push(node->l);
    }
}
```

## 中序遍历（非递归）

左子树一路压栈到底，然后弹出访问，再处理右子树。

```cpp
void inorderIterative(BinTree t)
{
    if (!t) return;
    stack<BinTree> s;
    while (t || !s.empty())
    {
        while (t)
        {
            s.push(t);
            t = t->l;
        }
        if (!s.empty())
        {
            t = s.top();
            s.pop();
            cout << t->data << " ";
            t = t->r;
        }
    }
}
```

## 后序遍历（非递归）

利用两个栈，第一个栈用于遍历，第二个栈用于逆序输出实现左-右-根顺序。

```cpp
void postorderIterative(BinTree t)
{
    if (!t) return;
    stack<BinTree> s1, s2;
    s1.push(t);
    while (!s1.empty())
    {
        BinTree node = s1.top();
        s1.pop();
        s2.push(node);
        if (node->l) s1.push(node->l);
        if (node->r) s1.push(node->r);
    }
    while (!s2.empty())
    {
        cout << s2.top()->data << " ";
        s2.pop();
    }
}
```

## 销毁树

后序遍历释放内存

```cpp
void destroyTree(BinTree t)
{
    if (t)
    {
        destroyTree(t->l);
        destroyTree(t->r);
        delete t;
    }
}
```
