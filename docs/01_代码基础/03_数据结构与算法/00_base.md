# 时间复杂度

**说明：** 衡量算法执行时间随数据规模增长的变化趋势（渐进时间复杂度）。

## 常用时间复杂度（从快到慢）

| 复杂度     | 名称       | 示例                               |
| ---------- | ---------- | ---------------------------------- |
| O(1)       | 常数阶     | 数组随机访问、哈希表查找           |
| O(log n)   | 对数阶     | 二分查找、平衡二叉树查找           |
| O(n)       | 线性阶     | 数组遍历、链表遍历                 |
| O(n log n) | 线性对数阶 | 归并排序、堆排序、快速排序（平均） |
| O(n²)     | 平方阶     | 冒泡排序、插入排序、选择排序       |
| O(2ⁿ)     | 指数阶     | 斐波那契数列递归、子集枚举         |
| O(n!)      | 阶乘阶     | 全排列问题、旅行商问题（暴力）     |

## 计算技巧

- **忽略常数项**：O(2n) → O(n)，O(n/2) → O(n)
- **忽略低次项**：O(n² + n) → O(n²)
- **乘法法则**：嵌套循环的时间复杂度相乘
- **加法法则**：顺序执行的时间复杂度取最大值
- **递归复杂度**：主定理（Master Theorem）分析递归关系

# 常用数据结构

## 数组（Array）

- **特点：** 连续内存空间，随机访问 O(1)，插入/删除 O(n)
- **场景：** 数据缓存、矩阵运算、动态规划表格

## 链表（Linked List）

- **特点：** 非连续存储，插入/删除 O(1)，随机访问 O(n)
- **场景：** LRU 缓存、操作系统进程队列、图的邻接表

## 栈（Stack）

- **特点：** 后进先出（LIFO）
- **场景：** 函数调用栈、表达式求值、括号匹配、Undo 操作

## 队列（Queue）

- **特点：** 先进先出（FIFO）
- **场景：** 任务调度、BFS 广度优先搜索、消息队列、缓冲区

## 哈希表（Hash Table / HashMap）

- **特点：** 键值对存储，查找/插入/删除平均 O(1)
- **场景：** 数据库索引、缓存系统、去重统计、字典实现

## 树（Tree）

- **二叉树（Binary Tree）：** 表达式树、哈夫曼编码
- **二叉搜索树（BST）：** 有序数据的动态查找
- **平衡树（AVL / 红黑树）：** C++ STL map/set、数据库索引
- **堆（Heap）：** 优先队列、Top K 问题、Dijkstra 算法
- **Trie（前缀树）：** 自动补全、拼写检查、词频统计

## 图（Graph）

- **特点：** 顶点和边的集合，表示多对多关系
- **DFS/BFS：** 路径搜索、连通性判断
- **最短路径：** Dijkstra、Floyd（导航、网络路由）
- **最小生成树：** Prim、（通信网络铺设）
- **拓扑排序：** 任务调度、依赖解析

## 并查集（Union-Find / Disjoint Set）

- **特点：** 高效的集合合并与查询
- **场景：** 连通分量判定、Kruskal 算法、社交网络好友关系

## 跳表（Skip List）

- **特点：** 多层索引链表，查找 O(log n)，实现简单
- **场景：** Redis 有序集合（ZSet）、内存数据库索引

## 布隆过滤器（Bloom Filter）

- **特点：** 概率性数据结构，判断元素"一定不存在"或"可能存在"
- **场景：** 缓存穿透防护、垃圾邮件过滤、爬虫 URL 去重
