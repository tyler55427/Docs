# 推理树的结构

## 已知中序和先序，输出后序

通过中序序列和先序序列重建二叉树，输出后序遍历结果。

```cpp
void find_root_l(string sm,string sp)
{
	if(sp.size()==0) return;
	char c=sp[0];
	int i=sm.find(c);
	sp.erase(sp.begin());
	// substr考虑了越界的情况
	find_root_l(sm.substr(0,i),sp.substr(0,i));
	find_root_l(sm.substr(i+1),sp.substr(i));
	cout<<c;
}
void test1()
{
	string sm,sp;
	cin>>sm>>sp;
	find_root_l(sm,sp);
}
```

## 已知中序和后序，输出先序

通过中序序列和后序序列重建二叉树，输出先序遍历结果。

```cpp
void find_root_p(string sm,string sl)
{
	if(sl.size()==0) return;
	char c=sl.back();
	int i=sm.find(c);
	sl.pop_back();
	cout<<c;
	find_root_p(sm.substr(0,i),sl.substr(0,i));
	find_root_p(sm.substr(i+1),sl.substr(i));
}
```
