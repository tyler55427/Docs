# 数组转最小堆

## 算法思路

将输入数组排序后，通过深度优先遍历将元素按最小堆顺序存储到结果数组中。

```cpp
int mt[1001];
int res[1001];
int n,len;

void dfs(int i){
	if(i>n) return;
	dfs(2*i);
	res[i]=mt[++len];
	dfs(2*i+1);
}
```

## 主函数

读取数组，排序后转换为最小堆形式输出。

```cpp
int main(){
	cin>>n;
	for(int i=1;i<=n;++i) cin>>mt[i];
	sort(mt+1,mt+n+1);
	dfs(1);
	for(int i=1;i<=n;++i)
		cout<<res[i]<<" ";
}
```
