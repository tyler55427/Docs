# 06 网络编程

要点：
- 端口：常规服务 < 1024，自建服务建议 ≥ 1024
- TCP：有连接、可靠、双向通道、数据量无上限
- UDP：无连接、不可靠、单个数据报 ≤ 64 KB
- `InetAddress.getAllByName(host)` 解析域名所有 IP
- TCP 服务端：`ServerSocket(port, queue)`，`Socket()` 用于客户端连接
- UDP：`DatagramSocket` + `DatagramPacket`

> 说明：`homework/ChatClient.java` 与 `homework/ChatServer.java` 是基于 TCP 的聊天程序，保留在 `homework/` 子目录。本节示例为 `src/Running/internet.java`，演示 `InetAddress` 基础用法。

## 示例：InetAddress 解析域名

```java
// 原 src/Running/internet.java（已去除 package 声明）
import java.net.InetAddress;

public class internet {
    public static void test()
    {
        String hostname = "www.bilibili.com";
        try{
            InetAddress[] addresses = InetAddress.getAllByName(hostname);
            for(InetAddress address : addresses){
                System.out.println(address);
            }
        }catch (Exception e){
            e.printStackTrace();
        }
    }

    public static void main(String[] args)
    {
        test();
    }
}
```
