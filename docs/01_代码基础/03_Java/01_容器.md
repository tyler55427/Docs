### Optional

Optional 的概念
Optional<T>是一个泛型类，T 表示包含的对象的类型。Optional 可以包含一个非空值，也可以是空值。主要的方法有：

isPresent()：如果值存在，返回 true，否则返回 false。
get()：如果值存在，返回该值，否则抛出 NoSuchElementException。
orElse(T other)：如果值存在，返回该值，否则返回 other。
ifPresent(Consumer<? super T> consumer)：如果值存在，执行给定的代码块。

## 容器

### List

两种构造方式

1. 动态
   List<Student> students = new ArrayList<>();
    1. 可变性：ArrayList 是可变的，意味着你可以随时向其中添加、移除或修改元素。
    2. 初始化：ArrayList 可以通过无参构造函数创建一个空列表，然后动态添加元素，也可以通过其他构造函数来指定初始容量或从另一个集合创建。
    3. 操作方法：ArrayList 提供了一系列操作方法，如 add、remove、set、clear 等，允许灵活操作列表中的元素。
    4. 性能：ArrayList 在频繁的添加和删除操作中表现良好，因为它的底层实现是一个动态数组。
2. 静态
   List<Student> students = List.of();
    1. 不可变性：List.of() 方法创建一个不可变列表，这意味着你不能向其中添加、移除或修改元素。尝试进行修改操作会抛出 UnsupportedOperationException 异常。
    2. 初始化：List.of() 可以方便地创建一个包含多个元素的列表。例如，List.of("A", "B", "C") 会创建一个包含这三个元素的不可变列表。
    3. 操作方法：由于列表是不可变的，因此只提供了查询操作（如 get、contains 等），而没有修改操作。
    4. 性能：不可变列表通常会有更好的性能，因为它们不需要处理并发修改问题，并且可以进行一些底层优化。
