# 六、多态与虚函数

## 虚函数

用 `virtual` 声明的成员函数，派生类可重写（override）。通过**基类指针/引用**调用时，会根据对象的真实类型动态分派：

```cpp
class Shape {
public:
    Shape(int id = 0) : id(id) {}

    // 虚析构：通过基类指针删除派生类对象时，先调用派生类析构
    virtual ~Shape() {}

    // 虚函数：派生类可重写
    virtual void draw() const {}

    // 纯虚函数：只有声明没有实现，Shape 成为抽象类
    virtual void area() const = 0;

protected:
    int id;
};
```

> 一旦函数变为虚函数，派生类中无论是否加 `virtual` 关键字，它都是虚函数。

---

## 多态调用

```cpp
int main() {
    // 基类指针指向派生类对象
    Shape* p = new Circle(1, "red", 0, 0, 5);

    // 动态分派：调用 Circle 的 draw()
    p->draw();

    // 纯虚函数调用：Circle 必须实现 area()
    p->area();

    delete p;  // 虚析构保证先调 Circle 析构，再调 Shape 析构
}
```

---

## 纯虚函数与抽象类

```cpp
virtual void area() const = 0;
```

- 只有声明，没有实现
- 包含纯虚函数的类是**抽象类**，不能被实例化
- 派生类必须重写所有纯虚函数，否则自身也成为抽象类

---

## 虚析构

通过基类指针删除派生类对象时，必须先调用派生类的析构函数：

```cpp
class Shape {
public:
    virtual ~Shape() {}  // 虚析构
};
```

> 虚析构是实现多态清理的关键。普通析构函数在通过基类指针删除派生类对象时只会调用基类析构函数，造成派生类资源泄漏。

---

## 虚函数的三条规则

1. **一旦为虚，永远为虚**：在基类声明为 `virtual` 的函数，在所有派生类中都是虚函数
2. **返回值协变**：覆盖时返回类型可以改为基类指针/引用的派生类版本（仅限指针或引用）
3. **参数必须一致**：覆盖时函数签名（参数列表）必须完全相同

```cpp
class Base {
    virtual Base& build(int n);  // 返回引用
};

class Derived : public Base {
    virtual Derived& build(int n);  // 协变返回：Derived& 替代 Base&
};
```

---

## final 关键字

阻止继续派生或重写：

```cpp
class Base {
public:
    virtual void temp() const final {}  // 禁止派生类重写
};

class Derived : public Base {
    // void temp() const {}  // 错误：temp() 已声明为 final
};

class Temp final {};  // 禁止继承 Temp
```
