# 九、类型转换与特殊语法

## 隐式转换与 explicit

构造函数隐式转换：传入对象不符合参数类型时，如果有相应构造函数，编译器会自动转换：

```cpp
class Person {
public:
    Person(int age) { /* ... */ }
};

void print(const Person& p) { /* ... */ }

print(18);  // 隐式：Person(18)
```

`explicit` 关键字可以禁用隐式转换：

```cpp
class Person {
public:
    explicit Person(int age) { /* ... */ }
};

// print(18);  // 错误：不能隐式转换
print(Person(18));  // 显式构造
```

## 转换函数

将类对象转换为其他类型。特点：类方法、无返回类型、无参数：

```cpp
class Fraction {
    double value;
public:
    Fraction(double v) : value(v) {}

    // 转换为 int：四舍五入
    operator int() const {
        return int(value + 0.5);
    }
};

Fraction f(3.7);
int n = f;  // n = 4
```

## 四种类型转换运算符

| 转换 | 用途 | 特点 |
|------|------|------|
| `static_cast<>` | 编译时类型检查 | 相关类型间转换，`char→int` 改变字节 |
| `dynamic_cast<>` | 运行时安全检查 | 必须有虚函数，失败返回 `nullptr` |
| `const_cast<>` | 去除/添加 `const` | 只能用于指针和引用 |
| `reinterpret_cast<>` | 重新解释位模式 | 不改变内存值，如 `uint16_t` |

```cpp
Base* b = new Derived();

// 安全检查：失败返回 nullptr
Derived* d = dynamic_cast<Derived*>(b);

// 去除 const
const int* pc = &x;
int* p = const_cast<int*>(pc);

// 重新解释
uint16_t a = 0x1234;
uint8_t b = reinterpret_cast<uint8_t*>(&a);
```

## 异常处理

```cpp
try {
    throw runtime_error("error message");
} catch (const exception& e) {
    cout << e.what() << endl;  // 通过 what() 获取信息
} catch (...) {                 // 捕获所有异常
    throw;                      // 重新抛出
}
```

> `catch` 不支持隐式类型转换，按顺序匹配。使用**引用**避免切片问题。

## new / delete

| 表达式 | 含义 |
|--------|------|
| `new int(3)` | 分配一个 `int`，值为 3 |
| `new int[3]` | 分配 3 个 `int` 的数组 |
| `new char[n]` | 分配 n 字节 |

```cpp
int* p = new int(3);    // 单个 int
int* arr = new int[n];   // 动态数组
delete p;
delete[] arr;
```

## 特殊关键字与技巧

### 防止继承：`final`

```cpp
class Base final {};  // 禁止继承 Base
```

### 防止重写：`final`

```cpp
class Base {
    virtual void foo() const final {}
};
```

### nullptr vs NULL

```cpp
int* p1 = NULL;   // NULL 是 (void*)0，兼容 C
int* p2 = nullptr; // nullptr 是 std::nullptr_t，只能赋给指针
```
