# 一、类基础

## 构造函数与析构函数

### 构造函数的分类

```cpp
class Person {
public:
    // 1. 无参构造
    Person() {}

    // 2. 有参构造（带默认参数）
    Person(int a, string n = "") : age(a), name(n) {}

    // 3. 拷贝构造
    Person(const Person& p) : age(p.age), name(p.name) {}

    // 析构函数
    ~Person() {}

private:
    int age;
    string name;
};
```

**实例化方式：**

```cpp
Person p1;              // 无参构造（注意：不能写 Person p1()，会被当成函数声明）
Person p2(18);          // 有参构造
Person p3 = Person(22); // 有参构造（显式）
Person p4 = { 20 };     // 花括号初始化
Person(10);             // 匿名对象，构造完立即销毁
Person p5 = p4;         // 拷贝构造
Person p6(p4);           // 拷贝构造（直接初始化）
```

> 默认提供的构造函数规则：
>
> - 如果写了有参构造，编译器不再提供无参构造
> - 如果写了拷贝构造，编译器不提供任何默认构造

## 初始化列表

构造函数参数列表后以冒号引出，用于初始化成员：

```cpp
class Person {
    int age;
    string name;
public:
    Person(int a, string n) : age(a), name(n) {}  // 初始化列表
};
```

**初始化顺序**：按成员**声明顺序**执行，而非初始化列表中的书写顺序。

## this 指针

指针，指向当前对象。用于解决成员变量重名问题和返回对象本身：

```cpp
class Person {
    int age;
public:
    Person& setAge(int age) {
        this->age = age;  // 区分成员变量和参数
        return *this;     // 返回对象本身
    }
};
```

## const 修饰符

| 形式                    | 含义                                           |
| ----------------------- | ---------------------------------------------- |
| `int age;`            | 普通成员变量                                   |
| `const int age;`      | 常成员变量，只能在初始化列表中构造             |
| `void foo() const {}` | 常函数，不能修改成员变量（除`mutable` 声明） |
| `const Person p;`     | 常对象，只能调用常函数                         |

```cpp
class Person {
    mutable int accessCount;  // mutable 成员，可在常函数中被修改
    int age;
public:
    void print() const {
        accessCount++;  // OK
        // age = 20;    // 错误：不能修改成员变量
    }
};
```

## 静态成员

`static` 成员为所有对象共享：

```cpp
class Person {
public:
    static int total;  // 类内声明
private:
    int age;
};

// 类外初始化（注意：不是实例化后定义）
int Person::total = 0;
```

- **静态成员变量**：所有对象共享，类内声明、类外初始化
- **静态成员函数**：所有对象共享，只能访问静态成员变量

## 权限控制

| 关键字        | 类内访问 | 类外访问 | 派生类访问 |
| ------------- | -------- | -------- | ---------- |
| `public`    | ✅       | ✅       | ✅         |
| `protected` | ✅       | ❌       | ✅         |
| `private`   | ✅       | ❌       | ❌         |

> `struct` 默认为 `public`，`class` 默认为 `private`

---

## 权限与继承的关系

基类成员的访问控制 × 继承方式 → 派生类中的访问控制：

| 基类成员      | public 继承   | protected 继承 | private 继承 |
| ------------- | ------------- | -------------- | ------------ |
| `public`    | `public`    | `protected`  | `private`  |
| `protected` | `protected` | `protected`  | `private`  |
| `private`   | 不可访问      | 不可访问       | 不可访问     |

> 常用 `public` 继承；` protected` 提供过渡；`private` 派生类外部完全不可见
