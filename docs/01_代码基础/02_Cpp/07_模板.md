# 七、模板

## 模板分类

### 函数模板

用 `template<typename T>` 声明，编译器在调用时自动实例化：

```cpp
template <typename T>
T maxOf(T a, T b) {
    return (a > b) ? a : b;
}

cout << maxOf(3, 7) << endl;      // 实例化 maxOf<int>
cout << maxOf(2.5, 3.7) << endl;  // 实例化 maxOf<double>
```

### 类模板

与函数模板类似，但实例化时**必须显式指定模板参数**：

```cpp
template <typename T1, typename T2>
class Pair {
public:
    T1 first;
    T2 second;

    Pair(T1 f, T2 s) : first(f), second(s) {}

    void print() const {
        cout << "Pair<" << typeid(T1).name() << ", "
             << typeid(T2).name() << ">: ("
             << first << ", " << second << ")\n";
    }
};

// 实例化：必须显式指定
Pair<int, double> p1(42, 3.14);
p1.print();
```

## 类模板特化

### 全特化

所有模板参数都指定为具体类型，有独立的实现：

```cpp
// 对 const char* 进行特化：用 strcmp 比较
template <>
class Pair<const char*, const char*> {
    const char* first;
    const char* second;

public:
    Pair(const char* f, const char* s) : first(f), second(s) {}

    bool operator==(const Pair& rhs) const {
        return strcmp(first, rhs.first) == 0
            && strcmp(second, rhs.second) == 0;
    }

    void print() const {
        cout << "Pair<const char*, const char*>: \""
             << first << "\", \"" << second << "\"\n";
    }
};
```

---

### 偏（部分）特化

只指定部分模板参数，或指定两个相同类型：

```cpp
// 当两个模板参数类型相同时的偏特化
template <typename T>
class Pair<T, T> {
    T first, second;

public:
    Pair(T f, T s) : first(f), second(s) {}

    void swap() {
        std::swap(first, second);
    }

    void print() const {
        cout << "PairSame<" << typeid(T).name() << ">: ("
             << first << ", " << second << ")\n";
    }
};

// 实例化偏特化版本
Pair<int, int> p4(10, 20);
p4.print();  // PairSame
p4.swap();
p4.print();  // 交换后
```

### 非类型模板形参

模板参数可以是编译时常量：

```cpp
// 数组版本的 print
template <typename T, int N>
void print(T (&arr)[N]) {
    for (int i = 0; i < N; ++i)
        cout << arr[i] << endl;
}

int arr[] = {1, 2, 3, 4, 5};
print(arr);  // 自动推导 N = 5
```

### 模板的友元

```cpp
template <class T>
class Person {};

// 1. 非模板友元：所有实例化版本共享同一个友元函数
template <class T>
class Node {
    friend void reset(Node&);
};

// 2. 约束模板友元：友元函数本身也是模板
template <class T>
class Tree {
    // 类内声明模板友元
    template <class U>
    friend void treePrint(Tree<U>&);
};

// 3. 非约束模板友元：每个实例化版本有自己的友元实例
template <class T>
class Wrapper {
    friend ostream& operator<<<>(ostream&, const Wrapper<T>&);
};
```
