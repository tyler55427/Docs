# 二、深拷贝

## 浅拷贝问题

默认拷贝构造只复制指针**地址**，而非指针指向的内容。多个对象指向同一块堆内存，析构时会重复 `delete[]` 导致崩溃：

```cpp
// 有问题的浅拷贝
class String {
    char* data_;
    size_t len_;
public:
    String(const char* s = "") {
        len_ = strlen(s);
        data_ = new char[len_ + 1];  // 分配堆内存
        strcpy(data_, s);
    }
    // 拷贝构造：默认实现——只复制指针值（浅拷贝）
    // String(const String& other) : data_(other.data_), len_(other.len_) {}
    ~String() {
        delete[] data_;  // 同一地址会被多次删除
    }
};
```

## 深拷贝实现

手动分配新内存并复制数据：

```cpp
class String {
private:
    char* data_;
    size_t len_;

public:
    String(const char* s = "") {
        len_ = strlen(s);
        data_ = new char[len_ + 1];
        strcpy(data_, s);
    }

    // 深拷贝：拷贝构造
    String(const String& other) {
        len_ = other.len_;
        data_ = new char[len_ + 1];
        memcpy(data_, other.data_, len_);
        data_[len_] = '\0';
    }

    // 深拷贝：析构函数
    ~String() {
        delete[] data_;
    }

    // 深拷贝：赋值运算符重载
    String& operator=(const String& other) {
        // 1. 自赋值检查
        if (this == &other)
            return *this;

        // 2. 释放原有资源
        delete[] data_;

        // 3. 分配新内存并拷贝
        len_ = other.len_;
        data_ = new char[len_ + 1];
        memcpy(data_, other.data_, len_);
        data_[len_] = '\0';

        return *this;
    }
};
```

赋值运算符的**三步曲**：自赋值检查 → 释放旧资源 → 分配复制新资源。
