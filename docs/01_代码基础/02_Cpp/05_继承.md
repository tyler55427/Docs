# 五、继承

## 继承基础

```cpp
class Base {
public:
    Base(int a) : a(a) { cout << "Base构造" << endl; }
    ~Base() { cout << "Base析构" << endl; }
    int a = 0;
};

// 公有继承
class S2 : public Base {
public:
    S2(int a) : Base(a) { cout << "S2构造" << endl; }
    ~S2() { cout << "S2析构" << endl; }
    int a = 1;  // 与基类同名变量
};
```

**同名变量**：通过作用域解析符访问基类成员：

```cpp
S2 s2(5);
cout << s2.a << endl;        // 派生类的 a = 1
cout << s2.Base::a << endl;  // 基类的 a = 5
```

## 构造与析构顺序

继承时的构造/析构顺序（与组合相反）：

```
构造：基类 → 成员对象 → 派生类
析构：派生类 → 成员对象 → 基类
```

```cpp
class Base { public: Base(int a) : a(a) {} int a; };

class S1 {
    Base base;  // 成员对象
public:
    // 基类成员只能在初始化列表中初始化，不能在构造函数体中赋值
    S1() : base(0) { cout << "S1构造" << endl; }
    ~S1() { cout << "S1析构" << endl; }
};

void test1() { S1 s1; }
/*
构造顺序：Base构造 → S1构造
析构顺序：S1析构 → Base析构
*/
```

## 继承中的三对概念

| | 重载 (Overload) | 隐藏 (Overwrite) | 覆盖 (Override) |
|--|--|--|--|
| **作用域** | 相同 | 不同 | 不同 |
| **虚函数** | — | 否 | 是 |
| **函数名** | 相同 | 相同 | 相同 |
| **参数** | 不同 | 不同/相同 | 相同 |

**重载 (Overload)**：同一作用域，函数名相同，参数不同。

**隐藏 (Overwrite/Hide)**：
- 派生类函数与基类函数同名，但参数不同 → 基类函数被隐藏
- 派生类函数与基类函数同名，参数相同，但基类函数**不是虚函数** → 基类函数被隐藏

**覆盖 (Override)**：派生类重写基类的虚函数，参数必须完全一致，通过基类指针调用时动态分派到派生类版本。

## 菱形继承与虚继承

菱形继承导致最顶层基类被继承两次，产生二义性和冗余数据：

```cpp
class Shape { /* ... */ };

class Color : public Shape { /* 第一次继承 Shape */ };
class TwoD : public Shape { /* 第二次继承 Shape */ };
class Circle : public Color, public TwoD { /* 两次构造 Shape */ };
```

### 虚继承

在最底层派生类继承中间类时使用 `virtual`，保证最顶层基类只有**一份**实例：

```cpp
class Color : virtual public Shape { /* 虚继承 */ };
class TwoD : virtual public Shape { /* 虚继承 */ };
class Circle : public Color, public TwoD { /* 只有一份 Shape */ };
```

**虚继承的构造**：由最派生类直接调用基类构造函数，中间类的构造函数**不再初始化**虚基类：

```cpp
// 虚继承中，Color 的构造函数不直接初始化 Shape
Color(const string& c) : Shape(), color(c) {}

// 最派生类 Circle 负责初始化 Shape
Circle(int id, const string& c, int x, int y, double r)
    : Color(c), TwoD(x, y), Shape(id), radius(r) {}
```
