# 三、友元

友元在类中声明，赋予其他类或函数访问本类 `private`成员的权限。

## 全局函数作友元

```cpp
class Room {
public:
    Room(int sqm) : area(sqm) {}
    // 声明友元：全局函数可以访问 private
    friend void inspect(Room& r);
private:
    int area;
};

void inspect(Room& r) {
    // 可直接访问 r.area
}
```

## 成员函数作友元

```cpp
class Room2;  // 前向声明

class Door {
public:
    void open(Room2& r);  // 声明 Door 的成员函数
};

class Room2 {
public:
    Room2(int sqm) : area(sqm) {}
    friend void Door::open(Room2& r);  // 授权 Door::open
private:
    int area;
};
```

## 类作友元

友元类可以访问本类的所有 private 成员：

```cpp
class Room3 {
public:
    Room3(int sqm) : area(sqm) {}
    friend class Manager;  // Manager 类是友元
private:
    int area;
};

class Manager {
public:
    void manage(Room3& r) {
        cout << r.area << " 平米" << endl;  // 可访问 private
    }
};
```
