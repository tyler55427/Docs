# 四、运算符重载

运算符重载让自定义类型支持内置运算符的语法。有两种定义方式：

- **类内定义**：成员函数，左侧操作数必须是本类对象
- **类外定义**：友元函数，可以处理任意类型的操作数

## 以 Vec3 为例——多种运算符

```cpp
class Vec3 {
    double x, y, z;

public:
    Vec3(double x = 0, double y = 0, double z = 0) : x(x), y(y), z(z) {}

    // ── 类内定义 ──────────────────────────────

    // 二元运算符：Vec3 + Vec3
    Vec3 operator+(const Vec3& b) const {
        return Vec3(x + b.x, y + b.y, z + b.z);
    }

    // 二元运算符：Vec3 * Vec3 → double（点积）
    double operator*(const Vec3& b) const {
        return x * b.x + y * b.y + z * b.z;
    }

    // 二元运算符：Vec3 * int → Vec3（数乘）
    Vec3 operator*(int n) const {
        return Vec3(x * n, y * n, z * n);
    }

    // ── 类外定义（友元）──────────────────────

    friend Vec3 operator-(const Vec3& a, const Vec3& b);

    // 类外定义（需类内声明 + 类外实现）
    Vec3 operator+(int n) const;
};

// 类外实现： Vec3 + int
Vec3 Vec3::operator+(int n) const {
    return Vec3(x + n, y + n, z + n);
}

// 类外实现： Vec3 - Vec3（全局函数，友元）
Vec3 operator-(const Vec3& a, const Vec3& b) {
    return Vec3(a.x - b.x, a.y - b.y, a.z - b.z);
}
```

### 调用等价形式

```cpp
c = a + b;    // c = a.operator+(b);
c = a - b;    // c = operator-(a, b);  （友元）
d = a * b;    // d = a.operator*(b);  （点积）
v = a * 3;    // v = a.operator*(3);  （数乘）
```

## 以 Complex 为例——完整实现

复数类，展示所有运算符的**类外定义**写法：

```cpp
class Complex {
private:
    double real, image;  // 实部与虚部

public:
    Complex(double r = 0, double i = 0);
    Complex(const Complex& other);  // 拷贝构造
    void print();

    // 声明所有重载（类外实现）
    Complex operator+(const Complex& other);
    Complex operator-(const Complex& other);
    Complex operator-();              // 一元：求负
    Complex operator=(const Complex& other);
    Complex& operator++();            // 前置++
    Complex operator++(int);           // 后置++
    Complex& operator--();            // 前置--
    Complex operator--(int);          // 后置--
};
```

**实现：**

```cpp
// 构造 & 拷贝
Complex::Complex(double r, double i) : real(r), image(i) {}
Complex::Complex(const Complex& other) : real(other.real), image(other.image) {}

void Complex::print() {
    cout << real;
    if (image > 0) cout << "+" << image << "i" << endl;
    else cout << image << "i" << endl;
}

// 二元 +
Complex Complex::operator+(const Complex& other) {
    return Complex(real + other.real, image + other.image);
}

// 二元 -
Complex Complex::operator-(const Complex& other) {
    return Complex(real - other.real, image - other.image);
}

// 一元：求负
Complex Complex::operator-() {
    return Complex(-real, -image);
}

// 赋值
Complex Complex::operator=(const Complex& other) {
    this->real = other.real;
    this->image = other.image;
    return *this;
}

// 前置++
Complex& Complex::operator++() {
    real++; image++;
    return *this;
}

// 后置++（int 参数区分）
Complex Complex::operator++(int) {
    Complex temp(real++, image++);
    return temp;
}

// 前置--
Complex& Complex::operator--() {
    real--; image--;
    return *this;
}

// 后置--
Complex Complex::operator--(int) {
    Complex temp(real--, image--);
    return temp;
}
```

## 规则速查

| 分类 | 可重载 | 不可重载 |
|------|--------|----------|
| 二元运算符 | `+`, `-`, `*`, `/`, `%`, ... | `::`, `.`, `.*`, `?:`, `sizeof` |
| 一元运算符 | `+`, `-`, `++`, `--`, `!`, `~`, ... | — |
| 特殊运算符 | `[]`, `()`, `->`, `=`, `new`, `delete`, `<<`, `>>` | — |

> `c = a + b` 一定可以写成 `c = a.operator+(b)`；但 `operator+` 不一定等于 `+`，取决于左侧操作数类型。
