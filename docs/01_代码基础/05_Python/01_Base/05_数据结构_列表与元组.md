# 数据结构：列表与元组

## 列表（List）

列表名加 `s`，用方括号 `[]`：

```python
spam = ['cat', 'dog', 'elephant', 'rat']
print(spam[0])      # 索引访问
print(spam[-1])     # 最后一个
print(spam[0:1])    # 切片：[start, end)，不含 end
print(spam[:1])     # 从头开始
print(spam[:])      # 复制整个列表
print(len(spam))
```

### 二维列表

```python
spam = [['cat', 'dog'], [0, 1]]
print(spam[1][0])   # 1
```

### 连接与删除

```python
s1 = [1, 2, 3]
s2 = ['a', 'b', 'c']
s3 = s1 + s2        # [1, 2, 3, 'a', 'b', 'c']
del s3[0]
print(s3)
```

### 遍历

```python
for i in [2, 4, 76]:
    print(i)
print('a' in s2, 'd' not in s2)
```

### 多重赋值（长度严格相等）

```python
a, b, c = s1
print(a, b, c)
```

### 同时取索引与值

```python
for index, item in enumerate(s1):
    print(index + 1, item)
```

### 常用方法

```python
import random
s2 = ['a', 'b', 'c']
print(random.choice(s2))     # 随机选一个
random.shuffle(s2)           # 原地随机打乱

print(s2.index('b'))         # 第一次出现的下标
s2.append('d')               # 末尾追加
s2.insert(4, 'e')            # 指定位置插入
s2.remove('e')               # 删除首次出现的值
s2.sort(reverse=True)        # 排序（reverse=True 降序）
s2.reverse()                 # 原地反转
```

### 列表推导式（List Comprehension）

```python
x = [[i + k for i in range(2)] for k in range(10)]
print(x)        # 10 行 × 2 列
```

矩阵转置：

```python
matrix = [[1, 5, 9], [2, 6, 10], [3, 7, 11], [4, 8, 12]]
mt = [list(i) for i in zip(*matrix)]
print(mt)
```

## 元组（Tuple）

用圆括号 `()`，**不可变**：

```python
eggs = ('qwe', 'asd')
print(eggs)

# 单元素元组必须带逗号
print(type(('hello')))       # <class 'str'>
print(type(('hello',)))      # <class 'tuple'>
```

### 列表 ↔ 元组

```python
list(('apple'))              # 注意单元素字符串会被拆字符
tuple(['apple'])
```

## 引用与拷贝

```python
# 整数赋值会复制；列表赋值共享引用
spam = 41
cheese = spam
spam = 100
print(spam, cheese)          # 100 41

print(id(42))                # 查看内存地址
```

**函数传入列表会修改外部**（引用传递），需要显式拷贝：

```python
import copy
spam = ['cat', 'dog', 'rat']

# 浅拷贝：只复制一层
the = copy.copy(spam)

# 深拷贝：递归复制嵌套结构
the = copy.deepcopy(spam)
```

## 字符串：可以当作"只读列表"

```python
s = 'apple'
print(s[2])       # 'p'
# s[2] = '4'      # 报错，str 不可变
```
