# 基础类型与输入输出

## 数据类型与字面量

```python
# 整型、浮点、字符串、布尔
a = 10              # int
a = '100'           # str
a = 3.14            # float
```

```python
# 字符串复制
print('Python' * 5) # PythonPythonPythonPythonPython
```

```python
# 字符串拼接
print('hello world' + ' python')
```

## 类型转换

```python
# input()返回的总是字符串
myname = '10'
print(len(myname))
print(int(myname) * 5)
```

```python
# 强制转换
print('I am ' + str(29) + ' years old')
print(int('23'))
print(float('3.4'))
```

```python
# int 取整：向 0 靠拢；只有数字字符串可以转换
print(int(-1.5))    # -1
print(int(1.5))     # 1
# print(int('3.3')) 报错；浮点字符串不能直接转 int
```

```python
# 文本与数字相等判断
print(42 == '42')           # False
print(42 == 42.0)           # True
print(42 == 00042.000)      # True
```

## 输入

```python
# myname = input()           # 从控制台读取一行，返回 str
myname = '10'

```

## 输出的几种方式

```python
a = 10
print('I am', a, 'years old')                       # 多参数：自动空格分隔
print('I am ' + str(a) + ' years old')              # 字符串拼接
print('I am %d years old' % a)                      # % 格式化（常用）
print('I am {} years old'.format(a))                # format
print(f'I am {a} years old')                        # f-string（常用）
```
