# 函数

## 定义与基本调用

```python
def test(a):
    print(a, end=' ')               # 不换行
    print(a, a, a)                   # 多参数：自动空格分隔
    print(a, a, sep=',', end='')     # 自定义分隔符和结束符
    print(';')
    global tttt                      # 声明全局变量
    return a                         # 没有 return 时默认返回 None

test('hello')
```

> Python 中函数内部**先读再赋值**同一变量会报错（与 C++ 不同）。

```python
a = 10
def aa():
    print(a)
    a = 5          # 报错：局部变量 a 在赋值前被引用
```

## 参数传递方式

```python
# 位置参数 与 关键字参数
def test(a, b):
    print(a, b)

test(1, 2)            # 位置参数
test(b=2, a=1)        # 关键字参数
# test(a=1, 2)        # 报错：位置参数必须在关键字参数之前
```

## 参数分隔符 `/` 与 `*`

```python
def test(a, b, /, c, d, e, *, f):
    print(a, b, c, d, e, f)

test(1, 2, 3, 4, 5, f=6)              # a/b 只能位置，f 只能关键字
test(1, 2, c=3, d=4, e=5, f=6)
# test(1, 2, c=3, d=4, e=5, 6)       # 报错：6 不能位置
```

## 默认参数

```python
def test(a, b, c=3):
    print(a, b, c)
```

> ⚠️ 默认参数不要用可变对象（`list`、`dict`、`set`），否则多次调用会**共享同一个对象**：

```python
def f(x, l=[]):
    l.append(x)
    return l

print(f(1))   # [1]
print(f(2))   # [1, 2]  ← 同一列表累积
print(f(3))   # [1, 2, 3]
```

## 文档字符串与 help

```python
def test(a, b, c=3):
    """This is a test function
    a, b, c are all int
    """
    print(a, b, c)

print(test.__doc__)
help(test)
```

## 作用域

```python
b = 10
def test():
    b = 5                    # 局部变量，不会改变全局变量（与 C++ 的区别）
    print(b)

test()
print(b)                     # 10
```

## 不同返回类型

```python
def aa(temp):
    if temp == 1:
        return 'temp=1'
    else:
        return 1
```

## 函数注解（PEP 3107）

```python
def f(a: int, b: int, c: str) -> str:
    return a + b

print(f(2, 3, 'sd') == 5)     # True（注解不强制，仅提示）
```

## match-case（Python 3.10+）

```python
x = 90
match x:
    case 1:
        print('1')
    case 2:
        print('2')
    case _:
        print('other')
```
