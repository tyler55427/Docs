# 文件与路径

## 路径相关

- Windows 路径分隔符：`\`
- macOS / Linux：`/`
- 文件名大小写：Windows/macOS **不区分**，Linux **区分**

```python
from pathlib import Path

print(Path('spam') / 'bacon' / 'eggs')    # 支持除法运算
print(Path.cwd())                          # 当前工作目录
print(Path.home())                         # 用户家目录
# . 是当前目录，.. 是上一级目录
```

## 路径拆解

```python
p = Path(Path.cwd())
print(p.anchor)        # 根锚点
print(p.parent)        # 父目录（Path 对象，不是 str）
print(p.name)          # 文件名
print(p.stem)          # 主名（不含后缀）
print(p.suffix)        # 后缀
print(p.drive)         # 盘符（Windows）
```

## 文件大小与目录内容

```python
import os

os.path.getsize(p)     # 文件大小（字节）
os.listdir(p)          # 目录下所有条目列表
```

## 遍历目录树

```python
import os

# 每次迭代返回 (当前文件夹名, 子文件夹列表, 文件列表)
for folderName, subfolders, filenames in os.walk(Path.cwd()):
    print(folderName, subfolders, filenames)
```
