# 调试与异常

## 异常基础

```python
def spam(divideBy):
    try:
        return 42 / divideBy
    except ZeroDivisionError:
        print('Error: Invalid argument!')
```

> `KeyboardInterrupt` 是用户按 Ctrl+C 触发的内置异常。

## 抛出与捕获

```python
import traceback

try:
    raise Exception('This is an error message.')
except Exception as err:                # 与 import 同款别名方式
    print(traceback.format_exc())       # 完整回溯，可写入日志
    print('Error happened: ' + str(err))
```

- **回溯（traceback）**：出错时生成的错误信息
- **调用栈**：错误信息 + 代码行号 + 函数调用顺序

## 自定义异常

```python
from pathlib import Path
import json

class MyError(Exception):
    def __init__(self):
        super().__init__()
    def out(self):
        return "错误：超出[0,100]有效范围"

class MyError1(Exception):
    def __init__(self):
        super().__init__()
    def out(self):
        return "错误：输入错误超过两次"

cnt = 0
l = []
try:
    while len(l) < 5:
        x = int(input())
        if x < 0 or x > 100:
            cnt += 1
            if cnt > 2:
                raise MyError1
        else:
            l.append(x)
except ValueError as e:
    print('错误：输入非数字')
except MyError1 as e:
    print(e.out())
except Exception as e:
    print('错误：其他错误')
finally:
    p = Path('./scores.json')
    p.touch()
    p.write_text(json.dumps(l))
```

## 日志（logging）

级别（从低到高）：`debug`、`info`、`warning`、`error`、`critical`。

```python
import logging

logging.debug('调试信息')
logging.info('普通信息')
logging.warning('警告')
logging.error('错误')
logging.critical('严重')

# 关闭日志
logging.disable(logging.CRITICAL)
```
