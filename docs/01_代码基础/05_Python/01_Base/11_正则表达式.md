# 正则表达式

> 测试素材在同目录 `regex-material/`（含 `regular_express.txt`、`hello.c`、各种 `test*_*.txt` 等），可作为练习样本。

## 模块与基础

```python
import re

# compile 后 search 返回 Match 对象，没找到返回 None
phone = re.compile(r'\d\d\d-\d\d\d-\d\d\d\d')
mo = phone.search('My number is 415-555-4242.')
print('Phone number found: ' + mo.group())
```

## 分组

```python
phone = re.compile(r'(\d\d\d)-(\d\d\d-\d\d\d\d)')
mo = phone.search('My number is 415-555-4242.')
print(mo.group(1))           # 第一组
print(mo.group(2))           # 第二组
print(mo.group(0))           # 整段匹配（默认）
print(mo.groups())           # 元组形式返回所有组
```

匹配括号字符本身需转义：`\(\)`。

## 元字符

| 字符 | 含义 |
| --- | --- |
| `.` | 除换行外的任意字符 |
| `^` | 行首 |
| `$` | 行尾 |
| `?` | 0 或 1 次 |
| `*` | 0 或多次 |
| `+` | 1 或多次 |
| `{}` | 指定次数 |
| `[]` | 字符集 |
| `\|` | 多个模式任选其一 |
| `()` | 分组 |

## 1. 管道 `|`

```python
heroRegex = re.compile(r'Batman|Tina Fey')
print(heroRegex.search('Batman and Tina Fey.').group())
print(heroRegex.search('Tina Fey and Batman.').group())
```

## 2. 问号 `?`（可选）

```python
batRegex = re.compile(r'Bat(wo)?man')
print(batRegex.search('The Adventures of Batman').group())
print(batRegex.search('The Adventures of Batwoman').group())
```

## 3. 星号 `*`（0+）

```python
batRegex = re.compile(r'Bat(wo)*man')
print(batRegex.search('The Adventures of Batman').group())
print(batRegex.search('The Adventures of Batwowowowoman').group())
```

## 4. 加号 `+`（1+）

```python
batRegex = re.compile(r'Bat(wo)+man')
print(batRegex.search('The Adventures of Batman') is None)   # True
print(batRegex.search('The Adventures of Batwowowowoman').group())
```

## 5. 花括号 `{n}` / `{n,m}` / `{n,}` / `{,m}`

```python
# 特定次数
# 范围：{n,m} 匹配 n~m 次
# {n,} 至少 n 次；{,m} 至多 m 次
```

## 6. 贪心与非贪心

```python
greedyHa = re.compile(r'(Ha){3,5}')
print(greedyHa.search('HaHaHaHaHa').group())          # 5 个 Ha

nongreedyHa = re.compile(r'(Ha){3,5}?')                # 加 ? 改为非贪心
print(nongreedyHa.search('HaHaHaHaHa').group())        # 3 个 Ha
```

## 7. findall() 与 search() 的区别

```python
phone = re.compile(r'\d\d\d-\d\d\d-\d\d\d\d')
print(phone.findall('Cell: 415-555-9999 Work: 212-555-0000'))
# search 返回首个 Match 对象
# findall：无分组 → 字符串列表；有分组 → 元组列表
```

## 8. 字符分类

| 简写 | 含义 |
| --- | --- |
| `\d` / `\D` | 数字 / 非数字 |
| `\w` / `\W` | 字母数字下划线 / 非 |
| `\s` / `\S` | 空白 / 非空白 |
| `[0-5]`、`[a-zA-Z]` | 自定义范围 |

## 9. 自定义字符类

```python
vowelRegex = re.compile(r'[aeiouAEIOU]')
print(vowelRegex.findall('RoboCop eats baby food. BABY FOOD.'))
# 类内普通字符不需要转义；如 [0-5.] 表示 0~5 或句点
```

## 10. 取反字符类

```python
vowelRegex = re.compile(r'[^aeiouAEIOU]')
print(vowelRegex.findall('RoboCop eats baby food. BABY FOOD.'))
```

## 11. `^` 与 `$`（行首/行尾）

```python
re.compile(r'^Hello').search('Hello world!')          # 匹配
re.compile(r'^Hello').search('He said hello.')         # None
re.compile(r'\d$').search('Your number is 42')          # 匹配
re.compile(r'\d$').search('Your number is forty two.') # None
```

## 12. 通配符 `.` 与 `.*`

```python
re.compile(r'.at').findall('The cat in the hat sat on the flat mat.')
# ['cat', 'hat', 'sat', 'flat', 'mat']
```

## 13. `.*` 跨行（DOTALL）

```python
re.compile('.*', re.DOTALL).search('a\nb').group()     # 'a\nb'
```

## 14. 大小写（IGNORECASE）

```python
re.compile(r'robocop', re.I).search('ROBOCOP protects the innocent.').group()
```

## 15. 替换 sub()

```python
namesRegex = re.compile(r'Agent \w+')
print(namesRegex.sub('CENSORED', 'Agent Alice gave the secret documents to Agent Bob.'))
```

## 16. VERBOSE：写复杂正则

```python
phoneRegex = re.compile(r'''(
    (\d{3}|\(\d{3}\))?      # area code
    (\s|-|\.)?              # separator
    \d{3}                   # first 3 digits
    (\s|-|\.)               # separator
    \d{4}                   # last 4 digits
    (\s*(ext|x|ext.)\s*\d{2,5})?  # extension
)''', re.VERBOSE)
print(phoneRegex.search('My number is 415-555-4242.').group())
```

## 17. 组合多个 flag

`re.compile()` 第二个参数只能有一个，可用 `|` 组合：

```python
someRegex = re.compile('foo', re.IGNORECASE | re.DOTALL | re.VERBOSE)
```
