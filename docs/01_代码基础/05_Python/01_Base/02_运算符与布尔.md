# 运算符与布尔

## 布尔值

布尔值首字母**必须大写**：`True` / `False`。

```python
Pan_Duan = True
print(Pan_Duan)
```

## 布尔运算符

```python
print(True and True)
print(False or False)
print(not False)
```

优先级：`not` > `and` > `or`。

## 视为 False 的值

- `0`、`0.0`
- `''`（注意：不包括 `' '`，单个空格是 True）
- `[]`、`()`、`set()`、`{}`

```python
if ' ':
    print('dfgsdfg')      # 会执行

# 连续比较
if 1 < 2 < 3:
    print('yes')
```

## 算术运算符（Python 特有）

```python
print(2 ** 3)    # 8，幂
print(25 // 4)   # 6，整除
```
