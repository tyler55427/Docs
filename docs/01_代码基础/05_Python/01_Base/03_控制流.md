# 控制流

## 代码块

Python 用**冒号 + 缩进**表示代码块（与 C++/Java 的 `{}` 不同）。

```python
temp = '1'
if temp == '3':
    print(1)
    print(2)
elif temp == '2':
    print(3)
else:
    print(4)
```

## while 循环

```python
temp = 5
while temp > 0:
    temp -= 1
    if temp == 1:
        break              # 直接跳出循环
    print(temp)
    if temp == 3:
        continue           # 跳过本轮剩余，进入下一轮
    print('hello')
```

## for 循环

```python
# 从 0 到 5，左闭右开
for i in range(5):
    print(i)

# 指定头尾
for i in range(12, 16):
    print(i)

# 指定步长
for i in range(10, 100, 20):
    print(i)

# 倒序
for i in range(3, -3, -1):
    print(i)
```
