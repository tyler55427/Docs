# 数据结构：字典（Dict / Map）

字典是**键值对**集合，排序不重要。

```python
import pprint

mycat = {'size': 'fat', 'color': 'gray', 'disposition': 'loud'}
print(mycat['size'])
```

## 遍历

```python
for k in mycat.keys():
    print(k, end=' ')
print()

for v in mycat.values():
    print(v, end=' ')
print()

# items() 返回元组 (key, value)
for kv in mycat.items():
    print(kv, end=' ')
print()
```

## 常用方法

```python
print('fat' in mycat.values())     # True

# get(key[, default])：不存在时返回 None 或自定义值
print(mycat.get('color'))
print(mycat.get('color', 0))

# setdefault(key, default)：key 不存在时插入默认值
mycat.setdefault('age', '15')
print(mycat)
```

## 美观输出

```python
pprint.pprint(mycat)
```

## 字典推导式

```python
print({i: i ** i for i in range(10)})
```

## 集合（Set）

字符串去重：

```python
x = 'aaabbbbdd'
print(set(x))        # {'a', 'b', 'd'}
```
