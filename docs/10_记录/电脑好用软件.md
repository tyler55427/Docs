# 电脑好用软件

## PowerToys：

window官方工具箱

- 高级粘贴

  - `Win + Shift + V`：打开粘贴面板，支持选择粘贴历史
  - `Ctrl + Shift + V`：粘贴为纯文本
- 前端显示

  - `Ctrl + Alt + T`
- 速览

  - `Ctrl + Space`
  - 需要手动设置，默认为 `Space`

## Everything：

文件搜索

## Notepad++：

记事本

- 功能

  - 垂直同步/水平同步滚动
  - 结构图：左侧菜单，右侧总览
- 快捷键：

  - `Ctrl + T`：交换上下两行

## ZoomIt：

放大镜

[download](https://download.sysinternals.com/files/ZoomIt.zip)

- 快捷键：
  - `Ctrl + 1`：静止页面缩放
  - `Ctrl + 4`：动态页面缩放
  - `Ctrl + 8`：滚动截屏

## QuickLook:

快速查看

[download](https://github.com/QL-Win/QuickLook/releases)

## DeskPin：

窗口永远置顶

- 快捷键：
  - `Ctrl + F12`：切换窗口状态

## Snipaste：

截图、贴图

- 快捷键：
  - 自定义为键盘的截图

## Ditto：

剪切板

[download](https://sabrogden.github.io/Ditto/)

- 快捷键：
  - `Ctrl + Win + ~`：打开（默认没有win，但是和vscode的终端重复）
- PowerToys也有，但是比较麻烦

## 远程：

- CrossDesk
- tailscale组网
- 樱花穿透

## Vscode：

- 快捷键：

  - `Ctrl + E`：搜索路径中的文本
  - `Ctrl + R`：打开最近窗口
  - `Ctrl + Shift + F`：搜索文件中的文本
- 插件：

  - markdown：
    - Office Viewer

## SpaceSniffer：

磁盘存储占用可视化

## Zotero：

论文管理

- 序列式存储，通过标签进行管理
