# 汇报

## 一、基本要求

- 字体统一
  - 中文：雅黑、幼圆
  - 英文：Calibri、Times New Roman
- 文字段落
  - 标题字号：32-36
  - 正文字号：18-24
  - 行间距：1.2-1.5
- 每一页的字不要太多
- AI生成图片汇报
- 换位思考

## 二、汇报内容

### 论文汇报

- 真正有价值的论文
- 相关的论文工作

### 会议交流

**暴露问题、澄清思路、获得反馈、推进工作**

#### 团队项目

维护文档：

- 项目的目标结果
- 技术贡献
- 时间规划
- 成员和分工
- 过程记录
  - 主要进展
  - 实验结果
  - 存在的问题

#### 个人汇报

- 回顾整体的方向没有偏移
- 回顾总结上次的结论和要做的事情
- 总结这段时间的进展
- 列出想要讨论的问题、有意思的实验现象、观察等
- 分享几篇最近读的论文，和对应的一句话内容总结
- 后续的待办和时间安排
