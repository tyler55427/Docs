# 论文

### 论文结构

- 标题：一级主要内容
- 摘要：二级主要内容
- 引入：现有方法的问题
- 相关工作：需要的大分类的基础
- 主要内容：
  - 论文提出的创新点
  - 创新点像解决的问题
- 实验
  - 如何验证创新点的有效
- 结论
- 引用

## 一、找论文

- 公众号：

  - 新智元、机器之心、 量子位
- 论文收集平台

  - [huggingface的DailyPapers](https://huggingface.co/papers/date/2025-09-04)
- 社交媒体

  - 小红书的推荐算法
  - 推特
- github仓库

  - 命名以`awesome-`开头的仓库
- 重要会议和期刊

  - 机器学习：ICML、NeurIPS、ICLR
  - 自然语言处理：ACL、EMNLP、COLM
  - 计算机视觉：CVPR、ICCV、ECCV
  - 人工智能：AAAI、IJCAI
- 论文分享

  - 重要
    - 高质量综述
    - 代表性论文
    - benchmark
  - 具体
    - 老师/同学推荐
    - 跟研究方向十分相近
      - 关注课题组/作者
  - 通过论文扩展
    - 引用与被引用
    - 相关工作
    - 论文中的对比方法
    - AI搜索推荐
- 生态

  - 数据集或 Benchmark的官方网站；
  - Leaderboard 上的方法及对应论文；
  - Hugging Face 的 Models、Datasets 和 Papers 页面；
  - 代码仓库的 Issues、Pull Requests 和后续实现；
  - 新论文实验表格中使用的Compared Methods
- 平台推荐

  - arxiv
  - 订阅Hugging Face的Daily Paper；
  - 从Google Scholar订阅你关注的研究者
  - 关注相关的公众号、小红书论文分享up主；
  - 各大基于AI的论文分享平台
    - 例如AMiner，Bohrium，ChatPaper等

## 二、读论文

### 步骤

- **宏观把握**
  - 摘要
  - 发表单位和发表地点
  - 大致工作
- **锁定核心问题**
  - 作者想解决的问题
- **梳理已有工作**
  - 提出问题的原因
  - 现有的解决方法的不足
- **理解创新点**
  - 作者解决问题的思路
- **理解实验设计**
  - 选择的实验数据集
  - 选择的对比方法和模型
  - 实验结论
  - 查看开源代码并复现
- **查看指标结果**
  - 对比的指标
  - 提升的效果
- **查看引用和被引用**
- **重新思考完整过程**
  - 列出作者的每一个步骤
    - 分析合理性和缺陷
    - 自己的改进思路

### 统一标注

- 黄色：有趣的地方
- 红色：问题
- 绿色：实验设置/定义的名词
- 蓝色：其他论文的有趣的地方
- 紫色：个人见解，包括疑问和思考

### 论文总结模板

```
# 总结
# 问题
# 创新
# 思考
```
