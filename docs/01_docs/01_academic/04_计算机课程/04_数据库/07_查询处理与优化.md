# 七、查询处理与优化
## 7.1 查询处理步骤

1. **解析与生成**：将 SQL 转化为关系代数
2. **求解**：统计查询时长，制定更优方案

## 7.2 代价估计

- **主要**：磁盘与内存之间读取 page 的总数量
- **包括**：寻道成本、CPU 时间、写入磁盘成本

### 选择操作代价

| 算法 | 代价 |
|:---:|:---|
| 文件扫描(堆文件) | br/2（平均） |
| 有序文件扫描 | log₂ br |
| 主索引(主键等值) | HTᵣ + 1 |
| 主索引(非主键等值) | HTᵣ + 占用页数 |
| 辅助索引 | HTᵣ + 记录数 |

## 7.3 外部排序

### 两阶段多路归并排序
1. 每次取 M 页到内存排序
2. 进行 M-1 路归并

**代价**：O(br · (2⌈log_{M-1} N⌉ + 1))

## 7.4 连接算法

| 算法 | 说明 |
|:---:|:---|
| Block Nested Loop Join | 块嵌套循环 |
| Indexed Nested Loop Join | 索引嵌套循环 |
| Merge-Sort Join | 排序合并 |
| Hash Join | 哈希连接 |

### Hash Join
适用等值/自然连接：
1. 将 r, s 的元组分为 n 个桶
2. 对每个桶建立哈希表
3. 连接相同索引的桶

**代价**：3(hᵣ + hₛ)

## 7.5 查询优化

### 优化策略
- **等价查询选最优**：不同表达式最优
- **过滤条件下沉**：先下沉后看行数

### 代价估计因素
- 每个运算的成本
- 依赖关系表的统计信息
- 中间结果的成本

### 选择性估计
- 等值：SC(A,R) = nᵣ / V(A,R)
- 比较：nᵣ · (v-min)/(max-min+1)
- 连接：取决于连接类型

### 启发式优化
1. 消除不满足的记录（减少元组）
2. 消除无用属性（投影减少属性）
3. 利用现有索引
