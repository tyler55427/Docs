# 一、数据库系统概述
## 1.1 数据库基本概念

## 数据库(DB)
**定义：** 一个数据的集合，描述多个相关组织的信息。

- **模式(Schema)**：数据库中数据表的结构、关系和约束，及存储方式（表头）
- **实例(Instance)**：指定一个特定的数据库实例（行）

## 数据库管理系统(DBMS)
增删改查

## 数据库系统(DBS)
```
DBS = DB + DBMS + 应用程序 + 数据库管理员
```

## DBMS 结构
- Query Optimization and Execution（查询优化，查询执行）
- Relational Operators（关系运算符）
- Files and Access Methods（文件和访问方法）
- Buffer Management（缓存管理）
- Disk Space Management（磁盘空间管理）

## 数据抽象层次
| 层次 | 说明 |
|:---:|:---|
| 物理层 | 存储方式/索引 |
| 概念/逻辑层 | 完整展示数据的 schema |
| 视图层 | 根据需求的展示，不建表，可连接多个关系，一般不更新 |

## 数据独立性
- **物理数据独立性**：存储结构不影响数据表结构
- **逻辑数据独立性**：概念组织不影响视图

## 1.2 文件系统的缺点

- **冗余和不一致性**
- **访问数据**：存储及高效访问的权限
- **数据库完整性**：数据的正确性和一致性（约束数据合法）
- **原子性**：事务的所有操作要么全部成功/失败回滚
- **并发处理**：并发访问导致数据错误
- **安全性**：访问权限的开发成本
