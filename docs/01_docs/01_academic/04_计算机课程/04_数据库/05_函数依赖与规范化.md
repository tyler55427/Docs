# 五、函数依赖与规范化
## 5.1 函数依赖(FD)

### 定义
α, β ⊆ R，对于 r ∈ R，记录 t₁, t₂ 在 α 的属性值相同，则在 β 的属性值相同 ⟺ α → β

### 类型
| 类型 | 说明 |
|:---:|:---|
| 平凡 FD | AB → A |
| 非平凡 FD | AB → C |

### 与 key 的关系
- α → R：α 是超键
- α → R，且没有 γ ⊂ α 使得 γ → R：α 是候选键

## 5.2 Armstrong 公理

| 公理 | 说明 |
|:---:|:---|
| 自反律 | B ⊆ A ⟹ A → B |
| 增补律 | A → B ⟹ AC → BC |
| 传递律 | A → B, B → C ⟹ A → C |
| 伪传递律 | A → B, BC → D ⟹ AC → D |
| 合并律 | A → B, A → C ⟹ A → BC |
| 分解律 | A → BC ⟹ A → B, A → C |

## 5.3 属性闭包
将属性的所有函数依赖结果输出。

## 5.4 最小函数依赖集

F 的最小函数依赖集 F_c 满足：
1. F 与 F_c 等价（闭包一样）
2. F_c 没有冗余
3. 每个 FD 的左侧属性是唯一的

## 5.5 范式

### 1NF
属性中没有多值属性

### 2NF
对有 FD: X → {A} in F⁺：
- A ∈ X（平凡的）or
- X 是某个候选键的真子集 or
- A 是一个属性（该属性在某个候选键中）

**防止非主属性完全依赖于候选键的真子集**

### 3NF
对于每个 FD: X → {A} in F⁺：
- A ∈ X（平凡的）or
- X 是个超键 or
- A 是一个主属性

**防止非键决定非主属性**

### BCNF
对于每个 FD: X → {A} in F⁺：
- A ⊂ X（平凡的）or
- X 是一个超码

## 5.6 分解原则

### ① 无损分解（必须）
R₁ ∩ R₂ → R₁/R₂ 至少一个在 F⁺ 中

### ② 保持 FD（可选）
所有子表 FD 并集的闭包与原表 FD 闭包一致

### ③ 好的格式（可选）
冗余信息少
