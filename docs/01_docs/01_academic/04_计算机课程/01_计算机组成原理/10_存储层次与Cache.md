# 十、存储层次与 Cache

## 存储

### 存储层次结构

| 层次    | 设备         | 说明                              |
| ------- | ------------ | --------------------------------- |
| $L_0$ | 寄存器       | CPU 寄存器，保存从 cache 取出的字 |
| $L_1$ | L1 Cache     | SRAM，私有                        |
| $L_2$ | L2 Cache     | SRAM                              |
| $L_3$ | L3 Cache     | SRAM，多核共用                    |
| $L_4$ | 主存         | DRAM                              |
| $L_5$ | 本地二级存储 | 固态硬盘、磁盘                    |
| $L_6$ | 远程二级存储 | 分布式文件系统、Web服务器         |

向上：速度更快、容量更小、价格更高；向下：速度更慢、容量更大、价格更低。

### 局部性原理

| 类型                 | 说明                                                               |
| -------------------- | ------------------------------------------------------------------ |
| **时间局部性** | 被引用的存储器位置在近期再被多次引用（如循环变量）                 |
| **空间局部性** | 被引用的存储器位置在近期再被引用附近位置（如顺序执行的指令、数组） |

### 存储技术

| 类型            | 访问时间  | 单位成本 |
| --------------- | --------- | -------- |
| **SRAM**  | 0.5~2.5ns | 高       |
| **DRAM**  | 50~70ns   | 中       |
| **Flash** | 5~50ns    | 低       |
| **磁盘**  | 5~20ms    | 最低     |

#### SRAM

- 每比特采用 6/8 个晶体管，断电消失（锁存器作为记忆单元）
- 有读写端口，读写操作访问时间不同，但不同位置的数据访问时间固定
- 存储扩展

  - **位扩展**：单元数不变，单元位数增加（数据线并联）
  - **字扩展**：单元位数不变，单元数增加（译码器选片）
  - **字位扩展**：先位扩展，再字扩展

#### DRAM

- 1 晶体管+电容，需刷新，双地址访问（RAS 行选、CAS 列选）
- **刷新周期**：上一次刷新结束到下一次全部刷新一遍的时间间隔（一般 2ms）
- **刷新方式**：集中式刷新、分散式刷新、异步式刷新

#### Flash

- 基于 EEPROM，非易失，寿命有限
- 优点：可靠、速度快、功耗少；缺点：贵、寿命短

#### 磁盘

- **结构**：盘片、磁道、扇区、柱面
- **访问时间** = 寻道时间 + 旋转延迟 + 传输时间
- **平均旋转时间** $\approx \frac{0.5}{RPM}$
- **编址方式**：LBA（逻辑扇区地址）

$$
LBA = C \times \text{磁头总数} \times \text{每道扇区数} + H \times \text{每道扇区数} + (S - 1)
$$

## Cache

### Cache 基础

- **块/行**：层与层之间交换的最小单位（通常 64B）
- **命中率** $h = \frac{N_c}{N_c + N_m}$
- **平均访问时间** $t_a = h \cdot t_c + (1-h) \cdot t_m$
- **命中时间**：访问本层的时间
- **未命中时间**：数据块从下层复制到本层的时间

### Cache 结构

| 有效位         | 标记                 | 脏位                           | 数据     |
| -------------- | -------------------- | ------------------------------ | -------- |
| 标识块是否有效 | 区分同一位置的不同块 | 标识块是否被修改（写回时需要） | 存储数据 |

### Cache 地址结构

$$
\text{请求地址} = \underbrace{\text{Tag}}_{\text{标记}} | \underbrace{\text{Index}}_{\text{组索引}} | \underbrace{\text{Offset}}_{\text{偏移}}
$$

- **Tag**：区分同一位置的不同块
- **Index**：定位 Cache 组
- **Offset**：块内偏移

### Cache 读写

- **读**
  - 命中：从 Cache 读出到 CPU
  - 未命中：将主存块复制到 Cache，再送到 CPU
- **写**
  - 命中：写直达（同时写 Cache 和主存）或 写回（只写 Cache，替换时写回主存）
  - 未命中：写分配（加载主存块到 Cache）或 非写分配（只写入主存，不调入 Cache）
  - 配合：写直达 ⟂ 非写分配；写回 ⟂ 写分配

### Cache 映射方式

- **直接映射**（一组一块，1路组相联）
  - 主存块映射到 Cache 中固定位置（模运算）
  - 优点：映射关系简单，实现容易；
  - 缺点：命中率低，机制不灵活
- **全相联映射**
  - 主存块可放在任意 Cache 位置
  - 优点：机制灵活，命中率高；
  - 缺点：电路难设计，只适用于小的 cache
- **n 路组相联映射**
  - 主存块映射到某组，组内有 n 块，组内逐个比较
  - 优点：映射关系灵活，命中率提高；使用替换算法修改一行而非一组

### 替换算法

| 算法               | 说明                       |
| ------------------ | -------------------------- |
| **随机替换** | 随机选择替换               |
| **FIFO**     | 先进先出                   |
| **LRU**      | 最近最少使用（计数器实现） |

### 命中率影响因素

- 块大小：增加先升后降（空间局部性 ↑ 后块数 ↓）
- Cache 容量：容量越大，命中率越高
- 相联度：越高，命中率越高

### 检验码

- **码距（汉明距离）**：两个码字对应位值不同的个数 $d$
  - $d \geq 2$：具有检错能力（奇偶校验）
  - $d \geq 3$：具有纠错能力
  - $e = \lfloor \frac{d-1}{2} \rfloor$（e 为检错/纠错数）
- **奇偶校验码**：偶校验（1的个数为偶数）或 奇校验（1的个数为奇数），只能检一位错
- **CRC（循环冗余码）**：基于多项式除法，可检测多位突发错误
- **海明码（纠错码）**：$d \geq 3$ 可纠 1 位错，需满足 $2^r \geq m + r + 1$（r 为检验位，m 为数据位）
