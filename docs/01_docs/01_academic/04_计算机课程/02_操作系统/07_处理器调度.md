# 七、处理器调度

## 7.1 调度层次

|   层次   | 说明                                                  |
| :------: | :---------------------------------------------------- |
| 长程调度 | 决定何时成为进程、创建队列的哪个（I/O 密集/CPU 密集） |
| 中程调度 | 交换内存内外的进程                                    |
| 短程调度 | 下一个使用 CPU 的进程                                 |

## 7.2 短程调度

### 时机

- 进程正常/异常终止
- 时钟中断或 I/O 中断
- 系统调用（软中断）
- 信号量操作

### 方式

- **非抢占式**：直至结束/阻塞；易实现；但专用系统
- **抢占式**：运行中暂停，防止 CPU 霸占；但系统开销增大

### 过程

1. 保存现场
2. 根据某种调度算法选择下一个运行的进程
3. 恢复现场

### 目标

- 公平：合理 CPU 分配
- 效率：CPU 及其他系统资源利用率
- 响应时间：交互响应快
- 周转时间 $T_r$：提交到结束（停留时间）短
- 吞吐量
- 实时性：指定进程最后期限

## 7.3 进程调度算法

|      算法      | 缩写 |   选择函数   |   决策模式   | 吞吐量 | 响应时间 |  开销  | 饥饿 |
| :------------: | :---: | :----------: | :----------: | :----: | :------: | :----: | :--: |
|   先来先服务   | FCFS |    max(w)    |    非抢占    | 不强调 |  可能大  |  最小  |  无  |
|      轮转      |  RR  |     常数     | 抢占(时间片) | 低时低 |    短    |  最小  |  无  |
|  最短进程优先  |  SPN  |    min(s)    |    非抢占    |   高   | 短进程小 | 可能高 | 可能 |
|  最短剩余优先  |  SRT  |   min(s-e)   | 抢占(到达时) |   高   |    小    | 可能高 | 可能 |
| 最高响应比优先 | HRRN | max((w+s)/s) |    非抢占    |   高   |    小    | 可能高 |  无  |
|    多级反馈    | MF/FB |  e, 优先级  | 抢占(时间片) | 不强调 |  不强调  | 可能高 | 可能 |

- **FCFS**
  - 短进程等待时间长
  - I/O 密集进程必须等 CPU 密集进程结束，使 I/O 设备未充分利用

- **时间片轮转(RR)**
  - 将 CPU 划分为若干时间片，顺序分配，执行完排在新加入的后面
  - 长度选择：短（切换开销大，一般比交互时间略长）、长（响应时间长）
  - 利于 CPU 密集，不利于 I/O 密集
  - 虚拟轮转(VRR)：I/O 阻塞解除的进程进入辅助队列，辅助队列比就绪队列优先获得 CPU

- **最短进程优先(SPN)**
  - 不可剥夺式，平均等待时间少
  - "短"进程可自饥饿
  - 估计运行时间：$S_{n+1} = a T_n + (1-a) S_n$（指数平滑，$a < 1$）

- **最短剩余优先(SRT)**
  - 剥夺式的 SPN
  - 新进程加入引发重新调度，选剩余时间最短进程执行
  - 需要估计进程剩余执行时间

- **最高响应比优先(HRRN)**
  - 非剥夺式
  $$RR = \frac{w}{s}$$
  - w：等待 CPU 的时间；s：估计执行时间
  - 利短进程，也防止长进程饥饿

- **多级反馈队列(MF/FB)**
  - 多优先级就绪队列，多个队列的时间片不同
  - 优先级越高时间片越小
  - 新进程进入最高优先级队列
  - 进程由于时间片用完后，下降一个优先级队列
  - 进程等待事件，进入等待队列，结束后放回原来队列

## 7.4 性能比较

**归一化周转时间：**

$$
= \frac{T_r}{T_s} = \frac{T_s + T_w}{T_s}
$$

- $T_r$：周转时间
- $T_s$：服务时间
- $T_w$：等待时间

**维护参数：**

- $w$：进程在系统中停留的时间（当前 $-$ 到达）
- $e$：目前花费的执行时间
- $s$：进程所需的总的服务时间

## 7.5 公平共享调度(FSS)

不同用户组，每组多个用户，不同用户组公平共享处理器时间。
