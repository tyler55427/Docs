# 一、操作系统概述

## 1.1 操作系统的概念

操作系统（OS）是机器与应用程序之间的**接口程序**，是**一组程序的集合**。

**目标：**

- 方便（方便用户使用）
- 有效（提高资源利用率）
- 扩展能力（易于添加新功能、纠正错误）

**功能：**

- 程序开发/运行
- I/O 设备访问
- 文件访问控制
- 系统访问
- 错误检测和响应
- 记账

### 三种重要接口：

| 接口 |        全称        | 说明                                      |
| :--: | :----------------: | :---------------------------------------- |
| ISA |    指令体系结构    | 定义机器指令系统，分为用户 ISA 和系统 ISA |
| ABI | 应用程序二进制接口 | 二进制可移植交叉程序标准                  |
| API |    应用编程接口    | HLL 库调用硬件资源和用户 ISA 提供的服务   |

## 1.2 操作系统的发展

### 处理方式发展

- **串行处理**

  - 调度：运行时间与占用时间不同
  - 提高效率：缓冲库、链接装配器、加载器、调试器、I/O 驱动器
- **简单批处理（监控程序）**

  - 监控程序自动加载执行作业，I/O 时通过中断处理，完成后加载下一作业
  - 所需硬件功能：内存保护、定时器、特权指令、中断
- **多道批处理**

  - I/O 等待期间切换运行其他程序（单处理器）
  - 需要支持：硬件（I/O 中断、DMA）、软件（存储管理、作业调度）

### 系统类型

- **分时系统**

  - 多用户同时访问，分时间片分享处理器时间，减小响应时间
- **实时系统**

  - 即时响应、高可靠性，规定时间内完成数据处理

## 1.3 操作系统的主要理论

|        理论        | 说明                             |
| :----------------: | :------------------------------- |
|     进程/线程     | 调度和管理的基本单位             |
|      存储管理      | 内存分配和虚拟存储               |
|   信息保护与安全   | 可靠性、保密性、数据完整性、认证 |
| 进程调度和资源管理 | 公平、有差别的响应性、效率       |

**进程定义：** 一个正在执行的程序

- 可执行的程序
- 相关数据
- 执行的上下文环境/进程状态

**调度软件出错：**

- 不正确的同步（不正确的信号竞争）
- 失败的互斥（竞争）
- 不确定的程序操作（共享内存的读写，调度顺序影响结果）
- 死锁（两个进程都等待对方的资源）

## 1.5 现代操作系统特征

- 微内核体系结构
- 多线程
- 对称多处理（SMP）
- 分布式
- 面向对象设计

### 内核类型

|        类型        | 说明                                                            |
| :----------------: | :-------------------------------------------------------------- |
| 单体内核（宏内核） | OS 基本功能，一个进程实现，共享同一地址空间，效率高但难修改扩充 |
|       微内核       | 更基本的功能，功能分为多个进程，独立地址空间，非特权方式        |
|      混合内核      | 微内核结构，单体内核实现                                        |

### 进程与线程

- **进程**：分配系统资源（CPU 除外）的最小单位
- **线程**：分配 CPU 的最小工作单位
