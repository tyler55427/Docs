# 九、文件管理

## 9.1 文件概念

**文件：** 带标识（文件名）的在逻辑上有完整意义的一组信息项序列

- 文件结构
  - **字段/域 (field)**：基本数据单元
  - **记录 (record)**：一组相关的域
  - **文件 (file)**：相似记录的集合
  - **数据库 (database)**：相关数据的集合

- 文件分类
  - **按性质和用途：**
    - 系统文件
    - 库文件
    - 用户文件

  - **按信息保存期限：**
    - 临时文件
    - 永久文件
    - 档案文件

  - **按保护方式：**
    - 只读文件
    - 读写文件
    - 可执行文件

  - **按逻辑结构：**
    - 流式（无结构）文件
    - 记录式（结构化）文件

  - **按物理结构：**
    - 顺序（连续）文件
    - 链接文件
    - 索引文件

## 9.2 文件组织与访问

### 逻辑结构

|     结构     | 说明                                             | 特点                         |
| :----------: | :----------------------------------------------- | :--------------------------- |
|   字节序列   | 无结构，字节为基本单元                           | 管理简单灵活，但不利于检索   |
|      堆      | 数据按顺序收集，不同记录有不同的域，有特定分隔符 | 穷举访问                     |
|   顺序文件   | 记录格式固定，按关键字段顺序存储                 | 批处理应用，但随机访问性能差 |
| 索引顺序文件 | 增加索引提高查找速度                             | 支持随机访问和溢出文件处理   |
|   索引文件   | 建立多个索引                                     | 速度快                       |
|   散列文件   | 关键字的散列直接找记录                           | 快速直接访问                 |

### 存取方式

- **顺序存取**：开始处顺序读取文件中的全部字节/记录
- **随机/直接存取**：任意位置读取

## 9.3 文件目录

**FCB（文件控制块）：** OS 管理文件的数据结构，存放管理文件所需的信息，是文件存在的标志

**文件目录：** 所有 FCB 组成的有序集合，一个 FCB 称为一个目录项

### 目录结构

| 结构 | 说明                                | 优缺点                                           |
| :--: | :---------------------------------- | :----------------------------------------------- |
| 一级 | 单用户操作系统                      | 结构简单；但索引时间长、有命名冲突               |
| 二级 | 根目录 MFD 下，每个用户一个目录 UFD | 索引时间短；但不利于用户进行文件管理             |
| 多级 | 树型目录                            | 层次方便管理、解决命名冲突；但级别多时索引时间长 |

### 目录操作

- 查找文件项（打开）
- 创建新文件
- 删除文件
- 列出目录中的文件
- 修改目录中的文件

### FCB 分解

将目录项（FCB）中的文件说明信息分成：

- **符号目录项**：文件名、文件内部标识号
- **基本目录项(BFCB)**：其余文件说明信息

## 9.4 文件共享

- **硬链接**：基于索引节点
- **软链接**：基于符号链接

### 访问权限

|       权限       | 说明                   |
| :--------------: | :--------------------- |
|    无 (none)     | 不知道文件的存在       |
| 知道 (knowledge) | 知道文件的存在及属主   |
| 执行 (execution) | 可加载并执行但不能复制 |
|    读 (read)     | 查看/复制内容          |
|  追加 (append)   | 在文件尾添加数据       |
|  更新 (update)   | 修改/删除/添加数据     |
| 删除 (deletion)  | 从文件系统中去掉       |

### 访问控制列表(ACL)

用户、用户组、全部

## 9.5 记录组块

|         方法         | 说明                                                 |
| :------------------: | :--------------------------------------------------- |
|       固定组块       | 记录长度固定，每个块中有效的记录数目固定（内部碎片） |
|  可变长度跨越式组块  | 一个记录允许在不同的块（高效，难实现）               |
| 可变长度非跨越式组块 | 记录长度可变，一个记录只能在一个块（浪费多）         |

## 9.6 空间分配

### 分配方式

|   方式   | 说明                       | 优点                                         | 缺点                       |
| :------: | :------------------------- | :------------------------------------------- | :------------------------- |
| 连续分配 | 文件存放在若干连续物理块中 | 简单；支持顺序和随机存取；顺序存取速度快     | 不能动态增长；存在外部碎片 |
| 链接分配 | 各块之间通过指针连接       | 空间利用率高；有利于动态扩充                 | 不适于随机存取；存取速度慢 |
| 索引分配 | 为每个文件建立索引表       | 既能顺序存取，又能随机存取；充分利用外存空间 | 索引表带来开销             |

### 空闲空间管理

- **位图**：每个位对应一个物理块
- **链式空闲区**：每个空闲分区记录指向下一分区的指针和长度
- **索引**：把空闲空间看作一个文件
- **空闲块列表**：每个块关联一个顺序号

## 9.7 文件系统安全

**访问矩阵的基本元素：**

- **主体 (subject)**：可访问对象的实体（进程）
- **对象 (object)**：可被访问和控制的实体（文件、局部数据等）
- **访问权限 (access right)**：主体访问对象的方式

## 9.8 文件系统性能

**减少磁盘访问次数的方式：**

- 高速缓存
- 磁盘调度
- 合理分配磁盘空间，顺序存放
- 优化信息的分布
