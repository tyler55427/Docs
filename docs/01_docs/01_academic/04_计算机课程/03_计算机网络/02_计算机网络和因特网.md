# 一、计算机网络和因特网

## 1.1 什么是计算机网络与因特网

**计算机网络** = 通信技术 + 计算机技术（通信网络）

**定义**：互联的、自治的计算机集合，通过交换网络（路由器/交换机）互连，但不作为信源、信宿。网络核心：互联网。

| 概念               | 说明                                           |
| :----------------- | :--------------------------------------------- |
| 互联网（Internet） | 能够彼此通信的设备组成的网络，$\approx$ 计算机网络 |
| 因特网（Internet） | 一种互联网络（全球最大）                       |
| 万维网（WWW）      | 一种互联网应用                                 |

### 因特网构成

- **互联的计算设备**：主机 = 端系统、网络应用程序
- **分组交换机** = 路由器 + 交换机
- **通信链路**
- **网络**：设备、路由器、链路的集合，由组织管理

---

## 1.2 什么是协议

**协议**：通信实体间交换的报文的格式和顺序，及报文收发和采取的动作

**三要素**：

- **语法**：信息的结构/格式
- **语义**：控制信息、动作及响应
- **时序**：事件顺序

> Internet 标准通过 **RFC** 文档定义

---

## 1.3 网络边缘

### 组成

- 主机 = 端系统（用户 / 服务器）
- 客户 - 服务器（传统模式）
- P2P（客户对客户）

### 网络应用的两大体系结构

- **$\textcircled{1}$ 客户 - 服务器体系结构（C-S）**

  - 服务器：一直运行、固定 IP、位于数据中心
  - 客户：与服务器通信、间歇连接、动态 IP、客户间不能通信
  - 例：HTTP、IMAP、FTP
- **$\textcircled{2}$ 对等体系结构（P2P，peer-peer）**

  - 没有一直运行的主机
  - 端系统之间直接通信
  - 从对等方请求服务，也给对等方提供服务
  - 可扩展性：新的对等方带来新的服务容量 / 需求
  - 间歇连接，可变 IP，管理复杂

### 接入网、物理媒体

将终端系统物理连接至其边缘路由器的网络（路径上的第一跳路由器）

- 住宅区接入网
- 移动接入网（4G/5G）
- 有线 / 无线通信链路

### 分组传输

- **链路传输速率**：链路容量 / 带宽
- **分组传输时延**：把 L 比特的分组传入链路的时间
- **传输时延**：完成传输的时间
- **传播时延**：在一链路传播数据所需时间

---

## 1.4 网络核心

由互联的路由器和链路所构成的网状结构。

**关键功能**：

- **转发（交换）**：将分组移动到合适的输出链路（局部动作）
- **路由选择**：确定从源到目的地的路径（全局动作）

### 分组交换

- 主机将应用报文划分成组（分组）
- **存储转发**：在分组到达下一条链路前，整个分组必须先到达当前路由器
- **排队**：分组队列；到达速率 > 链路输出速率，排队
- **分组丢失**：路由器的缓存用完，分组丢失

### 电路交换

- 端到端的资源被预留给源到目的地的呼叫，独占资源，保证性能
- **频分复用（FDM）**：划分频率给多用户，连续信号带宽
- **时分复用（TDM）**：划分时间给多用户，所有带宽但不连续

### 对比

- 电路交换：专线速率 1Gb/s，用户 100Mb/s，占空时间 10%
- 分组交换：35 个用户有 10% 同时跳跃概率，0.0004（按需服务 / 突发数据）

## 1.5 Internet 结构

网络的网络：

```
第一层 ISP
    $\updownarrow$
全球 ISP / 多个商业全球 ISP（层次结构）
    $\updownarrow$
因特网交换点 IXP（路由器的对等链路）
    $\updownarrow$
区域 ISP
    $\updownarrow$
接入 ISP（因特网服务提供商）
    $\updownarrow$
内容提供商网络（为主机提供内容）
```

> 一个 ISP 一个 AS，或划分为多个 AS（公司、大学、住宅区等）

## 1.6 网络性能

### 时延类型

- **处理时延**：检查分组的头部
- **排队时延**：在输出链路上的等待时间
- **传输时延**：将分组所有比特推向链路所需时间
- **传播时延**：比特在链路上传播的时间

> 接近链路容量时，时延增大（非排队模型）

### 丢包

队列容量有限，当队列满时，新到达的分组被丢弃

- 丢包 / 重传降低有效吞吐量
- 不必要的重传降低有效吞吐量（超时）
- 上游链路容量 / 缓存浪费在下游丢弃的分组上

### 吞吐量

- **瞬间吞吐量**：某时刻的速率
- **平均吞吐量**：长时间的平均速率

## 1.7 协议层次与服务模型

### 分层结构描述网络

- **概念化**：结构清晰，描述关系，分层的参考模型
- **结构化**：便于维护升级，一层的改变不影响其他层

### 分层的 Internet 协议栈

|  层次  | 说明                           | 协议示例              |
| :----: | :----------------------------- | :-------------------- |
| 应用层 | 网络应用                       | HTTP, IMAP, SMTP, DNS |
| 运输层 | 应用进程端点之间的数据传输     | TCP, UDP              |
| 网络层 | 为数据报选择路由，主机之间通信 | IP, 路由选择协议      |
| 链路层 | 相邻网络节点之间的数据传输     | Ethernet, WiFi        |
| 物理层 | 线路上传输比特位               |                       |

### ISO/OSI 参考模型

在应用层与运输层之间增加：

- **表示层**：数据的解释交换（加密）
- **会话层**：数据交换的同步、检查点、恢复点

> 这两层可放到应用层实现

### 服务分层与封装

某层执行某些操作或使用直接下层的服务来向上一层提供服务（服务模型）。

|  层次  | 服务                                                   |
| :----: | :----------------------------------------------------- |
| 应用层 | 利用运输层、交换报文，为报文添加校验                   |
| 运输层 | 利用网络层，将进程传到进程，封装首部信息 $H_2$ |
| 网络层 | 将报文段从主机传到主机，封装首部信息 $H_n$，构成数据报 |
| 链路层 | 将数据报从节点传到节点，封装首部信息 $H_1$，构成链路层帧 |
| 物理层 | 电信号传输                                             |

每层分组的结构：

```
首部字段
有效载荷字段（来自上一层的分组）
```

### 分层的优点

- **概念化**：结构清晰，便于标示网络系统中的组件，以及描述其相关关系（分层的参考模型）
- **结构化**：模块化的分层更易于系统的维护和升级更新；任何一层服务实现的改变对于系统其他层都是透明的
- 把网络复杂性隐藏到边缘

## 1.8 安全

### 攻击

- **分组嗅探**：广播媒体、杂乱的网络接口读取
- **虚假身份**
  - IP 哄骗：将有虚假源地址的分组送入 Internet
- **拒绝服务（DoS 攻击）**：虚假用户占用大量资源，使资源不能被合法用户使用

### 保护

- **身份认证**（硬件识别工具）
- **机密性**：加密技术
- **完整性检查**：数字签名，防止检测篡改
- **访问限制**：受密码保护的虚拟专用网络（VPN）
- **防火墙**：对分组过滤，检测 DoS 攻击
