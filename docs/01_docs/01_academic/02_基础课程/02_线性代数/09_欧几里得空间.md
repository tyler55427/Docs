# 欧几里得空间

## 内积与欧氏空间

### 定义

设 $V$ 是实数域 $\mathbb{R}$ 上的线性空间，若定义映射 $(\cdot,\cdot): V \times V \to \mathbb{R}$ 满足：

1. **对称性**：$(\alpha, \beta) = (\beta, \alpha)$
2. **线性性**：$(k_1\alpha_1 + k_2\alpha_2, \beta) = k_1(\alpha_1, \beta) + k_2(\alpha_2, \beta)$
3. **正定性**：$(\alpha, \alpha) \ge 0$，且 $(\alpha, \alpha) = 0 \Leftrightarrow \alpha = 0$

则称 $(\cdot,\cdot)$ 为**内积**，$V$ 称为**欧几里得空间**（内积空间）。

### 标准内积

$\mathbb{R}^n$ 中常用**标准内积**（点积）：

$$(\alpha, \beta) = \alpha^T \beta = a_1 b_1 + a_2 b_2 + \cdots + a_n b_n$$

$C[a,b]$ 上可定义 $(f, g) = \int_a^b f(x)g(x)\,dx$。

## 长度、距离与夹角

### 长度（范数）

$$|\alpha| = \sqrt{(\alpha, \alpha)}$$

- $|\alpha| \ge 0$，$|\alpha| = 0 \Leftrightarrow \alpha = 0$
- $|k\alpha| = |k|\,|\alpha|$
- **单位向量**：$|\alpha| = 1$；任一非零向量可单位化 $\alpha/|\alpha|$

### 距离

$$d(\alpha, \beta) = |\alpha - \beta|$$

### 柯西—施瓦茨不等式

$$|(\alpha, \beta)| \le |\alpha|\,|\beta|$$

等号成立 $\Leftrightarrow \alpha, \beta$ 线性相关。

**常用形式**：
- $\mathbb{R}^n$：$\left(\sum a_i b_i\right)^2 \le \left(\sum a_i^2\right)\left(\sum b_i^2\right)$
- $C[a,b]$：$\left(\int_a^b fg\right)^2 \le \left(\int_a^b f^2\right)\left(\int_a^b g^2\right)$

### 夹角

两非零向量 $\alpha, \beta$ 的夹角 $\theta$：

$$\cos\theta = \frac{(\alpha, \beta)}{|\alpha|\,|\beta|}$$

**正交**：$(\alpha, \beta) = 0 \Leftrightarrow \alpha \perp \beta$（$\theta = \pi/2$）。

零向量与任何向量正交。

## 正交性

### 正交向量组

由两两正交的非零向量组成的向量组。**性质**：正交向量组必线性无关。

**标准正交向量组**：$\alpha_1, \cdots, \alpha_s$ 两两正交且都是单位向量，即 $(\alpha_i, \alpha_j) = \delta_{ij}$。

### 基的标准正交化（施密特正交化）

设 $\alpha_1, \cdots, \alpha_s$ 线性无关，构造正交向量组 $\beta_1, \cdots, \beta_s$：

$$\beta_1 = \alpha_1$$
$$\beta_k = \alpha_k - \sum_{i=1}^{k-1} \frac{(\alpha_k, \beta_i)}{(\beta_i, \beta_i)} \beta_i, \quad k = 2, \cdots, s$$

再单位化：$\eta_k = \beta_k / |\beta_k|$，得标准正交向量组 $\eta_1, \cdots, \eta_s$。

**几何意义**：每步从 $\alpha_k$ 中减去其在已有正交方向上的投影分量。

### 标准正交基

若 $\varepsilon_1, \cdots, \varepsilon_n$ 是一组基且两两正交、均为单位向量，称其为**标准正交基**。

- 任意欧氏空间都存在标准正交基（对任一基施密特正交化即得）
- $\alpha = \sum (\alpha, \varepsilon_i)\, \varepsilon_i$：坐标即内积 $(\alpha, \varepsilon_i)$
- $(\alpha, \beta) = \sum x_i y_i$（坐标的标准点积）

## 正交矩阵

### 定义

$n$ 阶实方阵 $Q$，若 $Q^T Q = I$（即 $Q^{-1} = Q^T$），称 $Q$ 为**正交矩阵**。

### 等价条件

- $Q$ 的列（行）向量组构成 $\mathbb{R}^n$ 的标准正交基
- $Q^T Q = I \Leftrightarrow Q Q^T = I \Leftrightarrow Q^{-1} = Q^T$

### 性质

- $|Q| = \pm 1$
- $Q_1, Q_2$ 正交 $\Rightarrow$ $Q_1 Q_2$ 正交
- $Q$ 正交 $\Rightarrow$ $Q^{-1} = Q^T$ 正交
- 正交变换保持长度、内积、夹角不变

## 正交变换

### 定义

欧氏空间 $V$ 上的线性变换 $\mathcal{A}$，若保持内积：

$$(\mathcal{A}\alpha, \mathcal{A}\beta) = (\alpha, \beta), \quad \forall \alpha, \beta \in V$$

称 $\mathcal{A}$ 为**正交变换**。

### 等价刻画

以下对正交变换 $\mathcal{A}$ 等价：
1. 保持内积：$(\mathcal{A}\alpha, \mathcal{A}\beta) = (\alpha, \beta)$
2. 保持长度：$|\mathcal{A}\alpha| = |\alpha|$
3. 把标准正交基映为标准正交基
4. 在标准正交基下的矩阵为正交矩阵

正交变换的几何意义：刚体运动（旋转、反射或其复合），不改变长度与角度。

## 对称变换与实对称阵

### 实对称阵的性质

- 特征值全为实数
- 不同特征值对应的特征向量正交
- 可正交对角化：存在正交阵 $Q$ 使 $Q^T A Q = \Lambda$ 对角

### 对称变换

欧氏空间 $V$ 上线性变换 $\mathcal{A}$ 称为**对称变换**，若

$$(\mathcal{A}\alpha, \beta) = (\alpha, \mathcal{A}\beta), \quad \forall \alpha, \beta \in V$$

- 对称变换在标准正交基下的矩阵是实对称矩阵
- 对称变换的特征值全为实，不同特征值特征向量正交，可正交对角化

### 正交对角化步骤（实对称阵 $A$）

1. 求 $A$ 全部特征值 $\lambda_1, \cdots, \lambda_n$（实数）
2. 对每个 $\lambda_i$，解 $(A - \lambda_i I)x = 0$ 求特征子空间一组基
3. 对重根对应的多向量作施密特正交化（不同特征值的向量已正交，无需再正交化）
4. 单位化得 $\eta_1, \cdots, \eta_n$
5. 令 $Q = (\eta_1, \cdots, \eta_n)$，则 $Q^T A Q = \mathrm{diag}(\lambda_1, \cdots, \lambda_n)$

## 最小二乘法

### 不相容方程的最小二乘解

对不相容（无解）方程组 $Ax = b$，求 $\hat{x}$ 使误差 $\|Ax - b\|$ 最小，称 $\hat{x}$ 为**最小二乘解**。

**正规方程**：

$$A^T A x = A^T b$$

最小二乘解 $\hat{x}$ 满足正规方程。当 $A$ 列满秩时解唯一：$\hat{x} = (A^T A)^{-1} A^T b$。

**几何意义**：$A\hat{x}$ 是 $b$ 在 $A$ 的列空间上的正交投影，残差 $b - A\hat{x}$ 与列空间正交。

## 几种变换对比

| 变换 | 定义核心 | 在标准正交基下矩阵 | 保持 |
|------|----------|-------------------|------|
| 正交变换 | $(\mathcal{A}\alpha, \mathcal{A}\beta) = (\alpha,\beta)$ | 正交阵 $Q$（$Q^TQ=I$） | 长度、内积、夹角 |
| 对称变换 | $(\mathcal{A}\alpha,\beta) = (\alpha,\mathcal{A}\beta)$ | 实对称阵 $A$（$A^T=A$） | — |
| 正定变换 | $(\mathcal{A}\alpha,\alpha) > 0\ (\alpha \neq 0)$ | 正定对称阵 | — |
