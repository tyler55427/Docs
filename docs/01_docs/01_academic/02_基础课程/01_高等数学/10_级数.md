# 级数

## 数项级数

### 基本概念

**部分和**：$S_n = a_1 + a_2 + \cdots + a_n$

**收敛**：$\lim S_n = S$ 存在，$S$ 称为级数的和。

**发散**：部分和序列无极限。

**柯西收敛原理**（序列）：$\{a_n\}$ 有极限 $\Leftrightarrow$ $\forall \varepsilon > 0,\ \exists N$，使 $|a_n - a_m| < \varepsilon$，只要 $n \geq N,\ m \geq N$。

**柯西收敛原理**（函数极限 $x \to a$）：$\lim_{x \to a} f(x)$ 存在 $\Leftrightarrow$ $\forall \varepsilon > 0,\ \exists \delta > 0$，只要 $0 < |x_1 - a| < \delta,\ 0 < |x_2 - a| < \delta$，便有 $|f(x_1) - f(x_2)| < \varepsilon$。

**柯西收敛原理**（级数）：$\sum a_k$ 收敛 $\Leftrightarrow$ $\forall \varepsilon > 0,\ \exists N$，使

$$\left|\sum_{k=n+1}^{n+p} a_k\right| < \varepsilon, \quad \text{只要 } n \geq N,\ p \geq 1$$

**必要条件**：$\lim a_n = 0$（不满足则必发散）。

**序列有极限 $\Rightarrow$ 序列收敛**（称为柯西序列）。

### 收敛级数的性质

- 极限可加减、可乘非零常数
- 收敛 + 发散 = 发散
- 收敛 + 收敛 = 收敛
- 收敛 - 发散 = 发散
- 有限项修改不影响敛散性（$\exists N$，当 $k \geq N$ 时 $a_k = b_k$，则同时收敛/发散）
- 收敛级数加括号仍收敛到原级数的和（结合律）

## 正项级数

### 比较判别法

若 $0 \leq a_n \leq b_n$：
- $\sum b_n$ 收敛 $\Rightarrow$ $\sum a_n$ 收敛
- $\sum a_n$ 发散 $\Rightarrow$ $\sum b_n$ 发散

**极限形式**：若 $\lim \dfrac{a_n}{b_n} = L$（$0 < L < \infty$），则 $\sum a_n$ 与 $\sum b_n$ 同敛散。

**命题 1**（部分和有界性）：正项级数 $\sum u_n$ 收敛 $\Leftrightarrow$ 部分和 $\{S_n\}$ 有上界。

### 比值判别法（达朗贝尔）

设 $\displaystyle\lim_{n \to \infty} \frac{a_{n+1}}{a_n} = l$：
- $l < 1$：收敛
- $l > 1$：发散
- $l = 1$：**不定**

### 根值判别法（柯西）

设 $\displaystyle\lim_{n \to \infty} \sqrt[n]{a_n} = l$：
- $l < 1$：收敛
- $l > 1$：发散
- $l = 1$：**不定**

### 拉阿伯（Raabe）判别法

设 $\displaystyle\lim_{n \to \infty} n\left(\frac{u_n}{u_{n+1}} - 1\right) = R$（$R$ 可为 $\infty$）：
- $R > 1$：收敛
- $R < 1$：发散
- $R = 1$：**不定**

### 积分判别法

若 $f(x) > 0$ 单调递减，$a_n = f(n)$，则 $\sum a_n$ 与 $\int_1^\infty f(x)\,dx$ 同敛散。

### 参考级数

- **几何级数** $\sum r^n$：$|r| < 1$ 收敛，$|r| \geq 1$ 发散
- **调和级数** $\sum \dfrac{1}{n}$：**发散**
- **$p$ 级数** $\sum \dfrac{1}{n^p}$：$p > 1$ 收敛，$p \leq 1$ 发散

## 任意项级数

### 交错级数（莱布尼茨判别法）

$a_n \geq 0$，$a_n$ 单调递减趋于 $0$ $\Rightarrow$ $\sum_{n=1}^\infty (-1)^{n-1} a_n$ 收敛。

### 绝对收敛与条件收敛

- **绝对收敛**：$\sum |a_n|$ 收敛 $\Rightarrow$ $\sum a_n$ 必收敛
- **条件收敛**：$\sum a_n$ 收敛但 $\sum |a_n|$ 发散

**重要性质**：
- 绝对收敛级数的和 = 所有正项的和 + 所有负项的和
- 收敛的正项级数经过重排仍收敛，和不变
- **绝对收敛级数经任意重排仍绝对收敛，和不变**
- 两个绝对收敛级数项乘积（任意排布）的级数也绝对收敛到两级数和的乘积

### 阿贝尔引理与狄利克雷/阿贝尔判别法

**阿贝尔变换**：令 $\beta_i = \sum_{n=1}^i \beta_n$，则

$$\sum_{k=1}^m a_k \beta_k = \sum_{k=1}^{m-1} (a_k - a_{k+1}) B_k + a_m B_m$$

**阿贝尔引理**：$\{a_k\}$ 单调，$\{B_n\}$ 有界（$|B_n| \leq M$），则

$$\left|\sum_{k=1}^m a_k \beta_k\right| \leq M(|a_1| + 2|a_m|)$$

**狄利克雷判别法**：$\{a_k\}$ 单调且 $a_k \to 0$，$\sum b_k$ 部分和有界 $\Rightarrow$ $\sum a_k b_k$ 收敛。

**阿贝尔判别法**：$\{a_k\}$ 单调有界，$\sum b_k$ 收敛 $\Rightarrow$ $\sum a_k b_k$ 收敛。

## 函数项级数

### 收敛域

设 $\sum u_n(x)$ 在 $D$ 上定义。若 $x_0$ 使级数收敛，则 $x_0$ 为收敛点；收敛点的全体称为**收敛域**。

设部分和 $S_n(x) = \sum_{k=1}^n u_k(x)$，$f(x) = \lim S_n(x)$ 为**极限函数**。

### 一致收敛

$\forall \varepsilon > 0,\ \exists N$（与 $x$ 无关），使当 $n > N$ 时对一切 $x \in X$ 有

$$|S_n(x) - f(x)| < \varepsilon$$

记作 $S_n(x) \rightrightarrows f(x)$。

### 一致收敛判别法

**命题 1**：若 $|S_n(x) - f(x)| \leq a_n$（$a_n \to 0$），则 $\{S_n\}$ 在 $X$ 上一致收敛。

**命题 2**：若 $\exists l > 0$ 及点列 $x_n$ 使 $|S_n(x_n) - f(x_n)| \geq l$，则不一致收敛。

**命题 3**（极限形式）：若 $[S_n(x_n) - f(x_n)] \to k \neq 0$，则不一致收敛。

**必要条件**：级数一致收敛 $\Rightarrow$ $u_n(x) \rightrightarrows 0$。

**柯西准则**：$\forall \varepsilon > 0,\ \exists N$，使 $\left|\sum_{k=n+1}^{n+p} u_k(x)\right| < \varepsilon$，$\forall x \in X,\ \forall p \geq 1$。

**强级数判别法（$M$ 判别法）**：$|u_n(x)| \leq a_n$ 且 $\sum a_n$ 收敛 $\Rightarrow$ 一致收敛。

**狄利克雷判别法**：$u_n(x) = a_n(x) b_n(x)$，$\{a_n(x)\}$ 对 $n$ 单调且一致趋于 $0$，$\sum b_n(x)$ 部分和一致有界 $\Rightarrow$ 一致收敛。

**阿贝尔判别法**：$u_n(x) = a_n(x) b_n(x)$，$\{a_n(x)\}$ 单调且一致有界，$\sum b_n(x)$ 一致收敛 $\Rightarrow$ 一致收敛。

### 一致收敛级数的性质

**定理 6（和函数连续性）**：$\sum u_n(x)$ 在 $[a,b]$ 上一致收敛，每一项 $u_n$ 连续 $\Rightarrow$ 和函数 $S(x)$ 连续。

**定理 7（逐项积分）**：$\sum u_n(x)$ 在 $[a,b]$ 上一致收敛，每一项连续 $\Rightarrow$ 可逐项积分：

$$\int_a^b S(x)\,dx = \sum_{n=1}^\infty \int_a^b u_n(x)\,dx$$

**定理 8（逐项求导）**：$\sum u_n(x)$ 点点收敛，$u_n'(x)$ 连续且 $\sum u_n'(x)$ 一致收敛 $\Rightarrow$ 可逐项求导：

$$S'(x) = \sum_{n=1}^\infty u_n'(x)$$

且 $S'(x)$ 连续。

## 幂级数

### 形式与收敛半径

$$\sum_{n=0}^\infty a_n (x-x_0)^n$$

$$R = \lim_{n \to \infty} \left|\frac{a_n}{a_{n+1}}\right| \quad \text{或} \quad R = \frac{1}{\lim_{n \to \infty} \sqrt[n]{|a_n|}$$

### 阿贝尔定理

幂级数在 $|x-x_0| < R$ 内绝对收敛，在 $|x-x_0| > R$ 内发散，在端点处需单独判断。

### 和函数性质

**定理 4**（一致收敛）：$R > 0$ 时
- 在 $[-b, b]$（$0 < b < R$）上一致收敛
- 若在 $x = R$ 收敛，则在 $[0, R]$ 上一致收敛
- 若在 $x = -R$ 收敛，则在 $[-R, 0]$ 上一致收敛

**定理 5**（连续性）：和函数 $S(x)$ 在 $(-R, R)$ 内连续；端点收敛时单侧连续。

**定理 6**（逐项积分）：
$$\int_0^x S(t)\,dt = \sum_{n=0}^\infty \frac{a_n}{n+1} x^{n+1}$$

**定理 7**（逐项求导）：
$$S'(x) = \sum_{n=1}^\infty n a_n x^{n-1}$$

**推论 1-2**：积分/求导所得新级数的收敛半径 $R_1 = R_2 = R$。

**推论 3**：$S(x)$ 在 $(-R, R)$ 内有任意阶导数。

## 泰勒级数

若 $f(x)$ 在 $x_0$ 邻域无限阶可导，则

$$f(x) \sim \sum_{n=0}^\infty \frac{f^{(n)}(x_0)}{n!}(x-x_0)^n$$

**定理 1**（唯一性）：若级数在 $(x_0-R, x_0+R)$ 内收敛于 $f(x)$，则 $a_n = \dfrac{1}{n!} f^{(n)}(x_0)$。

**定理 2**：$f$ 能展开为泰勒级数的充要条件是 $R_n(x) \to 0$，其中

$$R_n(x) = \frac{1}{(n+1)!} f^{(n+1)}(x_0 + \theta(x-x_0))(x-x_0)^{n+1}, \quad \theta \in (0,1)$$

为拉格朗日余项。

### 常用展开（麦克劳林级数）

$$e^x = \sum_{n=0}^\infty \frac{x^n}{n!}, \quad x \in \mathbb{R}$$

$$\sin x = \sum_{n=0}^\infty (-1)^n \frac{x^{2n+1}}{(2n+1)!}, \quad x \in \mathbb{R}$$

$$\cos x = \sum_{n=0}^\infty (-1)^n \frac{x^{2n}}{(2n)!}, \quad x \in \mathbb{R}$$

$$\arctan x = \sum_{n=0}^\infty (-1)^n \frac{x^{2n+1}}{2n+1}, \quad |x| < 1$$

$$\ln(1+x) = \sum_{n=1}^\infty (-1)^{n-1} \frac{x^n}{n}, \quad x \in (-1,1]$$

$$\frac{1}{1-x} = \sum_{n=0}^\infty x^n, \quad x \in (-1,1)$$

$$(1+x)^\alpha = \sum_{n=0}^\infty \binom{\alpha}{n} x^n = \sum_{n=0}^\infty \frac{\alpha(\alpha-1)\cdots(\alpha-n+1)}{n!} x^n, \quad |x| < 1$$

## 广义积分

### 无穷积分

设 $f(x)$ 在 $[a, +\infty)$ 上有定义，对任意 $A > a$，$f$ 在 $[a, A]$ 上可积。若 $\lim_{A \to +\infty} \int_a^A f(x)\,dx$ 存在，则称无穷积分

$$\int_a^{+\infty} f(x)\,dx = \lim_{A \to +\infty} \int_a^A f(x)\,dx$$

收敛。否则发散。

**柯西收敛原理**：$\int_a^{+\infty} f\,dx$ 收敛 $\Leftrightarrow$ $\forall \varepsilon > 0,\ \exists A_0 > a$，只要 $A, A' > A_0$，便有 $\left|\int_A^{A'} f\,dx\right| < \varepsilon$。

**绝对收敛 / 条件收敛**：$\int |f|\,dx$ 收敛则称 $\int f\,dx$ **绝对收敛**；$\int f\,dx$ 收敛但 $\int |f|\,dx$ 发散则称**条件收敛**。

**引理**：若 $f \geq 0$ 可积，则 $\int_a^{+\infty} f\,dx$ 收敛 $\Leftrightarrow$ $\int_a^A f\,dx$ 对一切 $A \geq a$ 有界。

### 比较判别法

设 $0 \leq f(x) \leq g(x)$（$x \geq a$），$f, g$ 在 $[a, b]$ 上可积：
- $\int_a^{+\infty} g\,dx$ 收敛 $\Rightarrow$ $\int_a^{+\infty} f\,dx$ 收敛
- $\int_a^{+\infty} f\,dx$ 发散 $\Rightarrow$ $\int_a^{+\infty} g\,dx$ 发散

**极限形式**：设 $f \geq 0,\ g > 0$，$\lim_{x \to \infty} \dfrac{f(x)}{g(x)} = k$：
- $0 \leq k < +\infty$ 时，$\int g$ 收敛 $\Rightarrow$ $\int f$ 收敛
- $0 < k \leq +\infty$ 时，$\int g$ 发散 $\Rightarrow$ $\int f$ 发散

### 瑕积分

若 $f$ 在 $x = a$ 处无界（以 $a$ 为瑕点），则

$$\int_a^b f(x)\,dx = \lim_{\varepsilon \to 0^+} \int_{a+\varepsilon}^b f(x)\,dx$$

类似有以 $b$ 为瑕点的情形，比较判别法同样适用。

### 常用广义积分

$$\int_0^{+\infty} e^{-x^2}\,dx = \frac{\sqrt{\pi}}{2} \quad \text{（正态分布）}$$
$$\int_0^{+\infty} \frac{\sin x}{x}\,dx = \frac{\pi}{2}$$
$$\int_{-\infty}^{+\infty} e^{-x^2}\,dx = \sqrt{\pi} \quad \text{（高斯积分）}$$

## Γ 函数与 B 函数

### Γ 函数（Gamma 函数）

对 $\alpha > 0$，无穷瑕积分

$$\int_0^{+\infty} x^{\alpha-1} e^{-x}\,dx$$

收敛，定义为 **Γ 函数**：

$$\Gamma(\alpha) = \int_0^{+\infty} x^{\alpha-1} e^{-x}\,dx, \quad \alpha > 0$$

**性质**：

$$
\Gamma(\alpha+1) = \alpha\,\Gamma(\alpha) \quad\Rightarrow\quad \Gamma(n+1) = n!
$$
$$
\Gamma(1) = 1, \qquad \Gamma\left(\tfrac{1}{2}\right) = \sqrt{\pi}
$$

### B 函数（Beta 函数）

对 $p, q > 0$，瑕积分

$$B(p, q) = \int_0^1 x^{p-1}(1-x)^{q-1}\,dx, \quad p > 0,\ q > 0$$

**性质**：

$$
B(p,q) = B(q,p) \qquad \text{（对称性）}
$$
$$
B(p,q) = \frac{\Gamma(p)\,\Gamma(q)}{\Gamma(p+q)}
$$

特例：$m, n$ 为自然数时 $B(m,n) = \dfrac{(m-1)!\,(n-1)!}{(m+n-1)!}$，$B(1/2, 1/2) = \pi$。

## 组合数性质

$$
\binom{n+1}{m+1} = \binom{n}{m} + \binom{n}{m+1} \qquad \text{（Pascal 递推）}
$$

$$
\sum_{k=0}^{n}\binom{n}{k} = 2^n
$$

$$
\sum_{k=0}^{n}\binom{n}{k}(-1)^k = 0
$$

$$
\sum_{k=0}^{m}\binom{n}{k}\binom{m}{k} = \binom{n+m}{m} \qquad \text{（Vandermonde 恒等式）}
$$

## 含参变量积分

### 含参变量正常积分

$$g(y) = \int_a^b f(x,y)\,dx$$

**定理 1**（连续性）：$f(x,y)$ 在 $[a,b] \times [c,d]$ 连续 $\Rightarrow$ $g(y)$ 在 $[c,d]$ 连续。

**定理 2**（可交换积分次序）：
$$\int_c^d dy \int_a^b f(x,y)\,dx = \int_a^b dx \int_c^d f(x,y)\,dy$$

**定理 3**（可微性 / 莱布尼茨公式）：$f, f_y$ 在 $[a,b] \times [c,d]$ 连续 $\Rightarrow$ $g(y)$ 在 $[c,d]$ 可微，且

$$g'(y) = \int_a^b f_y(x,y)\,dx$$

### 含参变量无穷积分

$$g(y) = \int_a^{+\infty} f(x,y)\,dx$$

**一致收敛定义**：$\forall \varepsilon > 0,\ \exists N > a$（与 $y$ 无关），使 $A > N$ 时

$$\left|\int_A^{+\infty} f(x,y)\,dx\right| < \varepsilon, \quad \forall y \in Y$$

**柯西准则**：$\forall \varepsilon > 0,\ \exists N$，使 $A, A' > N$ 时 $\left|\int_A^{A'} f(x,y)\,dx\right| < \varepsilon$。

**$M$ 判别法**：$|f(x,y)| \leq \varphi(x)$ 且 $\int_a^{+\infty} \varphi(x)\,dx$ 收敛 $\Rightarrow$ 一致收敛。

**一致收敛推论**：
- $g(y)$ 在 $Y$ 上连续
- 可在积分号下交换积分次序
- 满足莱布尼茨公式

### 含参变量瑕积分

设 $f(x,y)$ 在 $(a,b] \times Y$ 上连续，$x = a$ 为瑕点。设 $|f(x,y)| \leq g(x)$，且 $\int_a^b g(x)\,dx$ 收敛 $\Rightarrow$ 一致收敛（$M$ 判别法）。

一致收敛时 $g(y)$ 在 $Y$ 上连续、可微、积分号下可交换。

## 傅氏级数

### 三角函数系的正交性

基本三角函数系：$1, \cos x, \sin x, \cos 2x, \sin 2x, \ldots$ 在 $[-\pi, \pi]$ 上两两正交：

$$
\int_{-\pi}^{\pi} \sin nx \cos mx\, dx = 0
$$
$$
\int_{-\pi}^{\pi} \cos nx \cos mx\, dx = \int_{-\pi}^{\pi} \sin nx \sin mx\, dx = \begin{cases} 0, & n \neq m \\ \pi, & n = m \neq 0 \\ 2\pi, & n = m = 0 \end{cases}
$$

**内积**（$L^2[-\pi,\pi]$ 上的双线性型）：

$$(f, g) = \frac{1}{\pi} \int_{-\pi}^{\pi} f(x)\,g(x)\,dx$$

**范数**：$\|f\| = \sqrt{(f, f)} = \sqrt{\dfrac{1}{\pi}\int_{-\pi}^{\pi} f^2(x)\,dx}$

**距离**：$\|f - g\| = \sqrt{\dfrac{1}{\pi}\int_{-\pi}^{\pi} (f(x) - g(x))^2\,dx}$

### 傅氏系数

设 $f(x)$ 以 $2\pi$ 为周期，且在 $[-\pi, \pi]$ 上有界可积。称

$$
a_n = \frac{1}{\pi}\int_{-\pi}^{\pi} f(x) \cos nx\, dx, \quad n = 0, 1, 2, \ldots
$$
$$
b_n = \frac{1}{\pi}\int_{-\pi}^{\pi} f(x) \sin nx\, dx, \quad n = 1, 2, \ldots
$$

为 $f(x)$ 的**傅氏系数**。以傅氏系数为系数所作的三角级数

$$f(x) \sim \frac{a_0}{2} + \sum_{n=1}^\infty (a_n \cos nx + b_n \sin nx)$$

称为 $f(x)$ 的**傅氏级数**。仅当级数收敛时 "$\sim$" 才能写为 "$=$"。

### 分段光滑与狄利克雷收敛定理

**分段连续**：除去有限个第一类间断点外连续。

**分段单调**：有限个单调区间。

**分段可微**：分段连续且导数存在。

**定理 1（狄利克雷）**：设 $f(x)$ 以 $2\pi$ 为周期，在 $[-\pi, \pi]$ 上满足狄利克雷条件（分段连续且分段单调），则傅氏级数在每一点 $x$ 处收敛，且其和为

$$S(x) = \begin{cases} f(x), & x \text{ 为连续点} \\ \dfrac{f(x+0) + f(x-0)}{2}, & x \text{ 为间断点} \end{cases}$$

**定理 2（分段可微）**：设 $f$ 以 $2\pi$ 为周期，在 $[-\pi, \pi]$ 上分段可微，则

$$S(x) = \frac{1}{2}[f(x+0) + f(x-0)], \quad -\infty < x < +\infty$$

### 奇偶函数的展开

**偶函数**：$a_n = \dfrac{2}{\pi} \int_0^\pi f(x)\cos nx\,dx$，$b_n = 0$，只有余弦项（**余弦级数**）。

**奇函数**：$a_n = 0$，$b_n = \dfrac{2}{\pi} \int_0^\pi f(x)\sin nx\,dx$，只有正弦项（**正弦级数**）。

### 周期 $2l$ 的函数的傅氏级数

$$
a_n = \frac{1}{l}\int_{-l}^{l} f(x) \cos \frac{n\pi x}{l}\,dx, \quad n = 0, 1, 2, \ldots
$$
$$
b_n = \frac{1}{l}\int_{-l}^{l} f(x) \sin \frac{n\pi x}{l}\,dx, \quad n = 1, 2, \ldots
$$

傅氏级数：

$$f(x) \sim \frac{a_0}{2} + \sum_{n=1}^\infty \left(a_n \cos \frac{n\pi x}{l} + b_n \sin \frac{n\pi x}{l}\right)$$

### 周期延拓

将定义在 $[-\pi, \pi]$ 上的 $f$ 作**周期延拓**得到 $F(x)$，则 $f$ 与 $F$ 在 $[-\pi, \pi]$ 上傅氏系数相同。

**有界区间 $[0, l]$**：

- 作偶延拓 $\Rightarrow$ 余弦级数
- 作奇延拓 $\Rightarrow$ 正弦级数

### 贝塞尔不等式与帕塞瓦尔等式

设 $f(x)$ 在 $[-\pi, \pi]$ 上可积，$S_n(x) = \dfrac{a_0}{2} + \sum_{k=1}^n (a_k \cos kx + b_k \sin kx)$ 为部分和。

**贝塞尔（Bessel）不等式**：

$$\frac{a_0^2}{2} + \sum_{k=1}^\infty (a_k^2 + b_k^2) \leq \frac{1}{\pi} \int_{-\pi}^{\pi} f^2(x)\,dx$$

**推论**：$a_n \to 0,\ b_n \to 0$（$n \to \infty$）。

**帕塞瓦尔（Parseval）等式**：

$$\frac{a_0^2}{2} + \sum_{k=1}^\infty (a_k^2 + b_k^2) = \frac{1}{\pi} \int_{-\pi}^{\pi} f^2(x)\,dx$$

即 $\lim_{n \to \infty} \sigma_n^2 = 0$，其中

$$\sigma_n^2 = \frac{1}{2\pi} \int_{-\pi}^{\pi} [f(x) - S_n(x)]^2\,dx$$

**$n$ 次谐波**：$a_n \cos nx + b_n \sin nx$，振幅 $A_n = \sqrt{a_n^2 + b_n^2}$。

## 附录：三角恒等式

### 基本恒等式

$$\sin^2 x + \cos^2 x = 1$$
$$\tan x = \frac{\sin x}{\cos x}, \quad \sec^2 x - \tan^2 x = 1$$

### 和差化积

$$\sin A + \sin B = 2\sin\frac{A+B}{2}\cos\frac{A-B}{2}$$
$$\sin A - \sin B = 2\cos\frac{A+B}{2}\sin\frac{A-B}{2}$$
$$\cos A + \cos B = 2\cos\frac{A+B}{2}\cos\frac{A-B}{2}$$
$$\cos A - \cos B = -2\sin\frac{A+B}{2}\sin\frac{A-B}{2}$$

### 积化和差

$$\sin A \cos B = \frac{1}{2}[\sin(A+B) + \sin(A-B)]$$
$$\cos A \cos B = \frac{1}{2}[\cos(A+B) + \cos(A-B)]$$
$$\sin A \sin B = \frac{1}{2}[\cos(A-B) - \cos(A+B)]$$

### 倍角公式

$$\sin 2x = 2\sin x \cos x, \quad \cos 2x = \cos^2 x - \sin^2 x = 2\cos^2 x - 1$$

### 一元二次方程

$ax^2 + bx + c = 0$（$a \neq 0$）：
$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

**韦达定理**：$x_1 + x_2 = -\dfrac{b}{a}$，$x_1 \cdot x_2 = \dfrac{c}{a}$

### 行列式

**二阶**：$\begin{vmatrix} a & b \\ c & d \end{vmatrix} = ad - bc$

### 平面解析几何

**两点距离**：$d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}$

**直线**：点斜式 $y - y_0 = k(x-x_0)$，一般式 $Ax + By + C = 0$

**点到直线距离**：$d = \dfrac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}$

**圆**：$(x-a)^2 + (y-b)^2 = R^2$

**椭圆**：$\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$（$a > b$ 焦点在 $x$ 轴）
