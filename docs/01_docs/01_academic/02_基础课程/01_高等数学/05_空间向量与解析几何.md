# 空间向量与解析几何

## 向量代数

### 向量的基本概念

**向量（有向线段）**：有大小和方向的量，记 $\vec{AB}$ 或 $\vec{a}$

**向量的模**：$|\vec{a}|$

**单位向量**：$\vec{a}^0 = \dfrac{\vec{a}}{|\vec{a}|}$

**零向量**：模为 0，方向任意

### 向量的运算

**加法**：平行四边形法则或三角形法则
$$\vec{a} + \vec{b} = \vec{c}$$

**数乘**：$\lambda \vec{a}$
- $\lambda > 0$：方向相同，模扩大 $|\lambda|$ 倍
- $\lambda < 0$：方向相反，模扩大 $|\lambda|$ 倍

**减法**：$\vec{a} - \vec{b} = \vec{a} + (-\vec{b})$

### 数量积（点积）

$$\vec{a} \cdot \vec{b} = |\vec{a}||\vec{b}|\cos\theta$$

其中 $\theta$ 为两向量夹角，$0 \leq \theta \leq \pi$。

**坐标表示**：若 $\vec{a} = (a_x, a_y, a_z)$，$\vec{b} = (b_x, b_y, b_z)$，则
$$\vec{a} \cdot \vec{b} = a_x b_x + a_y b_y + a_z b_z$$

**运算规律**：交换律、分配律、数乘结合律，**不满足**结合律。

**几何应用**：
- $\vec{a} \cdot \vec{b} = 0 \Leftrightarrow \vec{a} \perp \vec{b}$（垂直）
- $\vec{a} \cdot \vec{a} = |\vec{a}|^2$

### 向量积（叉积）

$$\vec{c} = \vec{a} \times \vec{b}$$

**模**：$|\vec{a} \times \vec{b}| = |\vec{a}||\vec{b}|\sin\theta$

**方向**：按右手系，四指从 $\vec{a}$ 转向 $\vec{b}$，拇指所指方向。

**坐标表示**：
$$\vec{a} \times \vec{b} = \begin{vmatrix} \vec{i} & \vec{j} & \vec{k} \\ a_x & a_y & a_z \\ b_x & b_y & b_z \end{vmatrix}$$

右手坐标系：$\vec{i} \times \vec{j} = \vec{k}$，$\vec{j} \times \vec{k} = \vec{i}$，$\vec{k} \times \vec{i} = \vec{j}$

**几何应用**：
- $|\vec{a} \times \vec{b}|$ 是以 $\vec{a}, \vec{b}$ 为邻边的平行四边形面积
- $\vec{a} \times \vec{b} = \vec{0} \Leftrightarrow \vec{a} \parallel \vec{b}$（平行）

### 混合积

$$[\vec{a}\vec{b}\vec{c}] = (\vec{a} \times \vec{b}) \cdot \vec{c}$$

**坐标表示**：
$$[\vec{a}\vec{b}\vec{c}] = \begin{vmatrix} a_x & a_y & a_z \\ b_x & b_y & b_z \\ c_x & c_y & c_z \end{vmatrix}$$

**几何意义**：以 $\vec{a}, \vec{b}, \vec{c}$ 为棱的平行六面体体积。

**性质**：轮换对称：$[\vec{a}\vec{b}\vec{c}] = [\vec{b}\vec{c}\vec{a}] = [\vec{c}\vec{a}\vec{b}]$

### 向量关系的判别

$$
\begin{cases}
\vec{a} \perp \vec{b} \;\Longleftrightarrow\; \vec{a} \cdot \vec{b} = 0 \\
\vec{a} \parallel \vec{b} \;\Longleftrightarrow\; \vec{a} \times \vec{b} = \vec{0} \\
\vec{a}, \vec{b}, \vec{c} \text{ 共面} \;\Longleftrightarrow\; \vec{a} \cdot (\vec{b} \times \vec{c}) = 0
\end{cases}
$$

## 向量的空间坐标

### 空间直角坐标系

右手系：$x$ 轴指向右，$y$ 轴指向前，$z$ 轴指向上。

### 向量的坐标表示

$\vec{a} = (a_x, a_y, a_z)$，其中 $a_x, a_y, a_z$ 为 $\vec{a}$ 在各坐标轴上的投影。

$$|\vec{a}| = \sqrt{a_x^2 + a_y^2 + a_z^2}$$

### 方向余弦

设 $\vec{a}$ 与各坐标轴夹角为 $\alpha, \beta, \gamma$，则
$$\cos\alpha = \frac{a_x}{|\vec{a}|}, \quad \cos\beta = \frac{a_y}{|\vec{a}|}, \quad \cos\gamma = \frac{a_z}{|\vec{a}|}$$

且
$$\cos^2\alpha + \cos^2\beta + \cos^2\gamma = 1$$

## 空间平面与直线

### 平面方程

**点法式**：已知一点 $M_0(x_0,y_0,z_0)$ 和法向量 $\vec{n} = (A,B,C)$
$$A(x-x_0) + B(y-y_0) + C(z-z_0) = 0$$

**一般式**：$Ax + By + Cz + D = 0$

**截距式**：$\dfrac{x}{a} + \dfrac{y}{b} + \dfrac{z}{c} = 1$（$a,b,c \neq 0$），与三坐标轴交于 $(a,0,0),(0,b,0),(0,0,c)$。

**三点式**：过 $P_1, P_2, P_3$ 三点的平面方程
$$\begin{vmatrix} x - x_1 & y - y_1 & z - z_1 \\ x_2 - x_1 & y_2 - y_1 & z_2 - z_1 \\ x_3 - x_1 & y_3 - y_1 & z_3 - z_1 \end{vmatrix} = 0$$

### 直线方程

**对称式（标准方程）**：已知一点 $M_0(x_0,y_0,z_0)$ 和方向向量 $\vec{s} = (a,b,c)$
$$\frac{x-x_0}{a} = \frac{y-y_0}{b} = \frac{z-z_0}{c}$$

**参数方程**：
$$x = x_0 + at,\quad y = y_0 + bt,\quad z = z_0 + ct$$

**两面式（一般方程）**：
$$\begin{cases} A_1 x + B_1 y + C_1 z + D_1 = 0 \\ A_2 x + B_2 y + C_2 z + D_2 = 0 \end{cases}$$

方向向量 $\vec{s} = \vec{n}_1 \times \vec{n}_2$

### 位置关系

**两平面**：
- 平行：$\vec{n}_1 \parallel \vec{n}_2 \Leftrightarrow \dfrac{A_1}{A_2} = \dfrac{B_1}{B_2} = \dfrac{C_1}{C_2}$
- 垂直：$\vec{n}_1 \perp \vec{n}_2 \Leftrightarrow A_1 A_2 + B_1 B_2 + C_1 C_2 = 0$

**两直线**：
- 平行：$\vec{s}_1 \parallel \vec{s}_2$
- 垂直：$\vec{s}_1 \perp \vec{s}_2 \Leftrightarrow m_1 m_2 + n_1 n_2 + p_1 p_2 = 0$

**直线与平面**：
- 垂直：$\vec{s} \parallel \vec{n} \Leftrightarrow mA + nB + pC = 0$
- 平行：$\vec{s} \perp \vec{n} \Leftrightarrow \dfrac{m}{A} = \dfrac{n}{B} = \dfrac{p}{C}$

### 距离公式

**点到平面距离**：
$$d = \frac{|Ax_0 + By_0 + Cz_0 + D|}{\sqrt{A^2 + B^2 + C^2}}$$

**点到直线距离**：
$$d = \frac{|\vec{s} \times \overrightarrow{M_0 M_1}|}{|\vec{s}|}$$

其中 $M_0$ 为直线上一点，$M_1$ 为空间点。

**两平行平面距离**：
$$d = \frac{|D_2 - D_1|}{\sqrt{A^2 + B^2 + C^2}}$$

## 二次曲面

一般形式：$Ax^2 + By^2 + Cz^2 + Dxy + Eyz + Fzx + Gx + Hy + Iz + J = 0$

经适当坐标变换消去交叉项，可化为标准型。

| 曲面 | 标准方程 |
|------|---------|
| 椭圆锥面 | $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = \dfrac{z^2}{c^2}$ |
| 椭球面 | $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} + \dfrac{z^2}{c^2} = 1$ |
| 单叶双曲面 | $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} - \dfrac{z^2}{c^2} = 1$ |
| 双叶双曲面 | $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} - \dfrac{z^2}{c^2} = -1$ |
| 椭圆柱面 | $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$ |
| 双曲柱面 | $\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 1$ |
| 椭圆抛物面 | $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} - z = 0$ |
| 双曲抛物面（马鞍面）| $\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} - z = 0$ |

| 曲面名称 | 标准方程 | 特征 |
|---------|---------|------|
| 球面 | $(x-x_0)^2 + (y-y_0)^2 + (z-z_0)^2 = R^2$ | 中心 $(x_0,y_0,z_0)$，半径 $R$ |
| 椭球面 | $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} + \dfrac{z^2}{c^2} = 1$ | 三个半轴 $a,b,c$ |
| 单叶双曲面 | $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} - \dfrac{z^2}{c^2} = 1$ | 有腰部环 |
| 双叶双曲面 | $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} - \dfrac{z^2}{c^2} = -1$ | 两叶分立 |
| 椭圆抛物面 | $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = z$ | 向上开口 |
| 双曲抛物面（马鞍面）| $\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = z$ | 形如马鞍 |
| 锥面 | $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = \dfrac{z^2}{c^2}$ | 过原点，用平面 $z = k$ 截得椭圆 |
| 圆柱面 | $x^2 + y^2 = R^2$ | 母线平行于 $z$ 轴 |
| 椭圆柱面 | $\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$ | 母线平行于 $z$ 轴 |
| 双曲柱面 | $\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 1$ | 母线平行于 $z$ 轴 |
| 抛物柱面 | $x^2 = 2py$ | 母线平行于 $z$ 轴 |

### 旋转曲面

由平面曲线绕坐标轴旋转而成。
- 绕 $z$ 轴：$r(z) = f(\sqrt{x^2+y^2})$
- 绕其他轴类似。

## 空间曲线的切线与弧长

### 空间曲线的参数方程

$$x = x(t),\ y = y(t),\ z = z(t),\ t \in [\alpha, \beta]$$

### 切线与法平面

**切向量**：$\vec{T} = (x'(t_0), y'(t_0), z'(t_0))$

**切线方程**：
$$\frac{x-x_0}{x'(t_0)} = \frac{y-y_0}{y'(t_0)} = \frac{z-z_0}{z'(t_0)}$$

**法平面**（过切点垂直于切线的平面）：
$$x'(t_0)(x-x_0) + y'(t_0)(y-y_0) + z'(t_0)(z-z_0) = 0$$

### 弧长公式

$$s = \int_{t_0}^{t_1} \sqrt{x'^2(t) + y'^2(t) + z'^2(t)}\ dt$$

**空间曲线向量式**：

$$
\vec r(t) = x(t)\vec i + y(t)\vec j + z(t)\vec k
$$

$$
s = \int_\alpha^\beta \sqrt{[x'(t)]^2 + [y'(t)]^2 + [z'(t)]^2}\,dt
$$

**切方向**：$\vec T = x'(t)\vec i + y'(t)\vec j$（平面情形）

## 曲面法向量

$$
\begin{cases}
F(x,y,z) = 0 \;\Rightarrow\; \vec n = (F_x,\ F_y,\ F_z) \\[4pt]
z = f(x,y) \;\Rightarrow\; \vec n = (-f_x,\ -f_y,\ 1)
\end{cases}
$$

- 两向量叉乘得法向：$(0,1,f_y)\times(1,0,f_x)$
- 两曲线公法向：$\vec r' \times \vec r''$
