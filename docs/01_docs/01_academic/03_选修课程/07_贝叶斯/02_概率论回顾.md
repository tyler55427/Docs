# 二、概率论回顾
## 基本概念

- **概率**：发生的可能性，通过概率衡量不确定性
- **概率分布**：结果及其概率的集合

| 类型 | 说明 |
|------|------|
| **离散** | 概率质量 |
| **连续** | 概率密度 $= \frac{\text{质量}}{\text{区间长度}}$ |

## 基本分布

- **伯努利分布**：$P(y|\theta) = \theta^y (1-\theta)^{1-y}$
- **正态（高斯）分布**：$P(x) = \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$

## 集中趋势

| 量 | 定义 |
|----|------|
| **均值 (mean)** | $\mu = E[X]$ |
| **众数 (mode)** | $\arg\max_M P(x=M)$（离散）；概率密度峰值（连续） |
| **中位数 (median)** | $P(x < M) = P(x > M) = \frac{1}{2}$ |

- 对称单峰分布：集中趋势相同
- 对称分布：中位数 = 均值

## 最高密度区间 (HDI)

包含 95% 概率质量的区间，区间内概率密度大于其他点的概率密度。

区间长度越短，分布越集中。

## 两因素分布

- **联合概率**：$P(x, y)$
- **边缘概率**：$P(x) = \sum_y P(x, y)$
- **条件概率**：$P(x|y) = \frac{P(x, y)}{P(y)}$
- **乘法公式（链式法则）**：$P(x, y) = P(x|y) P(y)$

## 独立性与条件独立性

- **独立性**：$P(x|y) = P(x)$ 或 $P(x, y) = P(x) P(y)$
- **条件独立**：给定 $z$，$P(x, y|z) = P(x|z)$，记为 $x \perp y \mid z$，等价于 $P(x, y|z) = P(x|z) P(y|z)$

## 概率图模型

- **共同原因**：$x_0 \leftarrow z \rightarrow x_1$，给定 $z$，$X, Y$ 条件独立
- **共同结果**：给定 $z$，$X, Y$ 条件独立

## 贝叶斯法则

$$P(x|y) = \frac{P(y|x) P(x)}{P(y)}$$

其中 $P(y) = \int P(y|x) P(x) dx$（证据/边缘似然）

**后验公式**：

$$P(\theta|D) = \frac{p(D|\theta) p(\theta)}{p(D)}$$

- 似然：$p(D|\theta)$
- 先验：$p(\theta)$
- 证据（边缘似然）：$p(D) = \int p(D|\theta) p(\theta) d\theta$
