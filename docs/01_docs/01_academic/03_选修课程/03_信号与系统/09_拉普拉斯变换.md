# 拉普拉斯变换

## 拉普拉斯变换的定义

### 双边拉氏变换

$$X(s) = \mathcal{L}\{x(t)\} = \int_{-\infty}^{+\infty} x(t)\,e^{-st}\,dt, \quad s = \sigma + j\omega$$

令 $s = j\omega$（即 $\sigma=0$）退化为傅里叶变换，故拉氏变换是 CTFT 的推广（引入 $\sigma$ 实部以保证收敛）。

### 单边拉氏变换

$$X(s) = \int_{0^-}^{+\infty} x(t)\,e^{-st}\,dt$$

用于因果信号与初始条件不为零的微分方程求解。

## 收敛域（ROC）

### 定义

使 $X(s)$ 收敛的所有 $s$ 值集合，称为**收敛域**。一般形如：

- 右边信号：$\mathrm{Re}(s) > \sigma_0$（右半平面）
- 左边信号：$\mathrm{Re}(s) < \sigma_0$（左半平面）
- 双边信号：$\sigma_1 < \mathrm{Re}(s) < \sigma_2$（带状）

**关键**：拉氏变换由 $X(s)$ 与 ROC 共同确定信号，不同信号可有相同 $X(s)$ 但不同 ROC。

### 有限时长信号

时限信号 ROC 为全 $s$ 平面。

### 极点与 ROC 关系

- 右边信号的 ROC 在最右极点右侧
- 左边信号的 ROC 在最左极点左侧
- 双边信号 ROC 为相邻极点之间的带状区域

## 拉氏变换的性质

设 $x(t) \leftrightarrow X(s)$，ROC $R$：

| 性质 | 时域 | 复频域 | ROC |
|------|------|--------|-----|
| 线性 | $a x_1 + b x_2$ | $a X_1 + b X_2$ | $\supseteq R_1 \cap R_2$ |
| 时移 | $x(t-t_0)$ | $e^{-st_0}X(s)$ | $R$ |
| 频移（$s$ 域平移） | $e^{s_0 t}x(t)$ | $X(s-s_0)$ | $R+\mathrm{Re}(s_0)$ |
| 时域微分 | $\dfrac{dx}{dt}$ | $sX(s)$ | $\supseteq R$ |
| 时域积分 | $\int_{-\infty}^t x$ | $\dfrac{X(s)}{s}$ | $\supseteq R\cap\mathrm{Re}(s)>0$ |
| $s$ 域微分 | $-t\,x(t)$ | $\dfrac{dX}{ds}$ | $R$ |
| 时域卷积 | $x_1*x_2$ | $X_1 X_2$ | $\supseteq R_1\cap R_2$ |
| 时域相乘 | $x_1 x_2$ | $\dfrac{1}{2\pi j}X_1*X_2$ | $\supseteq R_1\cap R_2$ |
| 初值定理 | $x(0^+)$ | $\lim_{s\to\infty}sX(s)$ | — |
| 终值定理 | $x(\infty)$ | $\lim_{s\to 0}sX(s)$ | $s=0$ 在 ROC 内 |

### 初值定理与终值定理

$$x(0^+) = \lim_{s\to\infty} sX(s), \quad x(\infty) = \lim_{s\to 0} sX(s)$$

终值定理要求 $sX(s)$ 的所有极点在左半平面（系统稳定）。

### 常用拉氏变换对

| 时域 $x(t)$ | 复频域 $X(s)$ | ROC |
|-------------|---------------|-----|
| $\delta(t)$ | $1$ | 全平面 |
| $u(t)$ | $\dfrac{1}{s}$ | $\mathrm{Re}(s)>0$ |
| $-u(-t)$ | $\dfrac{1}{s}$ | $\mathrm{Re}(s)<0$ |
| $e^{-at}u(t)$ | $\dfrac{1}{s+a}$ | $\mathrm{Re}(s)>-a$ |
| $t^n e^{-at}u(t)$ | $\dfrac{n!}{(s+a)^{n+1}}$ | $\mathrm{Re}(s)>-a$ |
| $\cos\omega_0 t\,u(t)$ | $\dfrac{s}{s^2+\omega_0^2}$ | $\mathrm{Re}(s)>0$ |
| $\sin\omega_0 t\,u(t)$ | $\dfrac{\omega_0}{s^2+\omega_0^2}$ | $\mathrm{Re}(s)>0$ |
| $e^{-at}\cos\omega_0 t\,u(t)$ | $\dfrac{s+a}{(s+a)^2+\omega_0^2}$ | $\mathrm{Re}(s)>-a$ |

### 系统函数与稳定性

#### 系统函数 $H(s)$

$$H(s) = \frac{Y(s)}{X(s)}$$

由系统微分方程 $\sum a_k y^{(k)} = \sum b_k x^{(k)}$ 得：

$$H(s) = \frac{\sum b_k s^k}{\sum a_k s^k}$$

是 $s$ 的有理函数，由**零点**（分子根）与**极点**（分母根）决定系统特性。

#### 稳定性判据

LTI 系统稳定 $\Leftrightarrow$ $H(s)$ 的 ROC 包含 $j\omega$ 轴。

**因果系统**（$h(t)$ 因果）：
- BIBO 稳定 $\Leftrightarrow$ 所有极点在左半平面（$\mathrm{Re}(s)<0$）
- 不稳定：有右半平面极点
- 临界稳定：极点在 $j\omega$ 轴上且为单极点

#### 由极点分布看系统响应

- 左半平面极点 → 衰减项（稳定）
- $j\omega$ 轴共轭极点 → 等幅振荡
- 右半平面极点 → 增长项（不稳定）
- 实轴极点 → 指数；共轭复极点 → 振荡

### 用拉氏变换解常微分方程

#### 步骤

1. 对方程两边取单边拉氏变换（自动纳入初始条件）
2. 解代数方程得 $Y(s)$
3. 部分分式分解 $Y(s)$
4. 反变换得 $y(t)$

#### 部分分式分解

将 $Y(s) = \dfrac{N(s)}{D(s)}$ 拆成简单项之和：
- 单实极点 $p$：$\dfrac{A}{s-p}$
- 共轭复极点 $-a\pm j\omega$：$\dfrac{Bs+C}{(s+a)^2+\omega^2}$
- 重极点：$\dfrac{A_1}{s-p} + \dfrac{A_2}{(s-p)^2} + \cdots$

逐项查变换对表即得时域解。
