# 周期信号的傅里叶级数

## 基本概念

### 信号的正交分解

若函数集 $\{\phi_k(t)\}$ 在区间 $[a,b]$ 上满足正交：

$$\int_a^b \phi_k(t)\,\phi_l^*(t)\,dt = \begin{cases} E_k, & k=l \\ 0, & k\ne l \end{cases}$$

则 $x(t) = \sum_k c_k\,\phi_k(t)$ 中系数由投影给出：$c_k = \dfrac{1}{E_k}\int_a^b x(t)\,\phi_k^*(t)\,dt$。

### 连续时间傅里叶级数

周期 $T$、基频 $\omega_0 = 2\pi/T$ 的周期信号 $x(t)$，用复指数 $\{e^{jk\omega_0 t}\}$ 展开：

$$x(t) = \sum_{k=-\infty}^{+\infty} a_k\,e^{jk\omega_0 t}$$

**复傅里叶系数**：

$$a_k = \frac{1}{T}\int_T x(t)\,e^{-jk\omega_0 t}\,dt$$

**三角形式**：

$$x(t) = a_0 + \sum_{k=1}^{\infty}\big[A_k\cos(k\omega_0 t) + B_k\sin(k\omega_0 t)\big]$$

其中 $a_0$ 为直流分量，$A_k, B_k$ 为实系数，与 $a_k$ 关系：

$$a_0 = \frac{A_0}{1},\quad a_k = \frac{A_k - jB_k}{2},\quad a_{-k} = \frac{A_k + jB_k}{2}$$

### 收敛条件（狄利克雷条件）

$x(t)$ 在一个周期内分段光滑（有限个间断点与极值点）→ 傅里叶级数收敛，在连续点收敛于 $x(t)$，间断点收敛于左右极限均值 $\dfrac{x(t_0^+)+x(t_0^-)}{2}$。

### 离散时间傅里叶级数（DFS）

周期为 $N$ 的离散周期信号 $x[n]$，基频 $\omega_0 = 2\pi/N$：

$$x[n] = \sum_{k=0}^{N-1} a_k\,e^{jk\frac{2\pi}{N}n}$$

$$a_k = \frac{1}{N}\sum_{n=0}^{N-1} x[n]\,e^{-jk\frac{2\pi}{N}n}$$

求和仅 $N$ 项（因 $e^{jk(2\pi/N)n}$ 对 $k$ 周期 $N$）。

## 性质

设 $x(t) \leftrightarrow a_k$（周期 $T$），$x[n] \leftrightarrow a_k$（周期 $N$）：

| 性质 | 时域 | 频域（系数） |
|------|------|--------------|
| 线性 | $A x_1(t) + B x_2(t)$ | $A a_k + B b_k$ |
| 时移 | $x(t-t_0)$ | $a_k\,e^{-jk\omega_0 t_0}$ |
| 频移 | $e^{jM\omega_0 t}x(t)$ | $a_{k-M}$ |
| 共轭对称 | $x^*(t)$ | $a_{-k}^*$ |
| 实信号 | $x(t)\in\mathbb{R}$ | $a_{-k}=a_k^*$（$a_0$ 实，$a_k,a_{-k}$ 共轭） |
| 时域反转 | $x(-t)$ | $a_{-k}$ |
| 时域微分 | $\dfrac{dx}{dt}$ | $jk\omega_0\,a_k$ |
| 时域积分 | $\int_{-\infty}^t x$ | $(jk\omega_0)^{-1}a_k$（$a_0=0$） |
| 卷积（周期） | $x_1 * x_2$（周期卷积） | $N\,a_k b_k$（离散）/ $T\,a_k b_k$（连续） |
| 相乘 | $x_1(t)\,x_2(t)$ | $\sum a_l b_{k-l}$（系数卷积） |
| 帕塞瓦尔 | $\dfrac{1}{T}\int_T \|x\|^2 dt$ | $\sum_k \|a_k\|^2$（功率谱） |

### 帕塞瓦尔定理

周期信号平均功率 = 各谐波功率之和：

$$P = \frac{1}{T}\int_T |x(t)|^2\,dt = \sum_{k=-\infty}^{+\infty} |a_k|^2$$

说明 $|a_k|^2$ 是第 $k$ 次谐波的功率，即周期信号的**离散功率谱**。

## 基本变换对

### 周期方波

占空比 $\tau/T$，幅值 $A$：

$$a_k = \frac{A\tau}{T}\,\mathrm{sinc}\!\left(\frac{k\omega_0 \tau}{2}\right) = \frac{A\tau}{T}\,\frac{\sin(k\pi\tau/T)}{k\pi\tau/T}$$

（$\mathrm{sinc}$ 函数的零点位置反映占空比信息）

### 周期冲激串

$$x(t) = \sum_{k=-\infty}^{+\infty}\delta(t-kT) \quad \Longleftrightarrow \quad a_k = \frac{1}{T}$$

（所有谐波等幅，是采样的理论基础）

### 周期正弦

$$x(t) = \cos(\omega_0 t) \Leftrightarrow a_{\pm1}=\tfrac{1}{2},\ a_{k\ne\pm1}=0$$

$$x(t) = \sin(\omega_0 t) \Leftrightarrow a_{\pm1}=\mp\tfrac{j}{2},\ a_{k\ne\pm1}=0$$
