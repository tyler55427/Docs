# 双向链表

## 结构定义

使用数组模拟双向链表，每个节点包含标记位和左右指针。头节点 m[0] 作为哨兵，简化边界处理。

```cpp
struct T
{
	bool sign;
	int left,right;
}m[100009];
```

## 插入操作

在节点 k 的左侧或右侧插入新节点 i，p=1 表示右侧，p=0 表示左侧。

```cpp
void add(int k,int i,int p)
{
	if(p)
	{
		m[i].left=k;
		m[i].right=m[k].right;
		m[k].right=i;
		m[m[i].right].left=i;
	}
	else
	{
		m[i].left=m[k].left;
		m[i].right=k;
		m[k].left=i;
		m[m[i].left].right=i;
	}
}
```

## 主函数

构建双向链表，标记部分节点后输出未标记的节点。

```cpp
int main()
{
	int n;
	cin>>n;
	m[0].left=m[0].right=0;
	add(0,1,1);
	for(int i=2;i<=n;++i)
	{
		int k,p;
		cin>>k>>p;
		add(k,i,p);
	}
	int mm;
	cin>>mm;
	while(mm--)
	{
		int x;
		cin>>x;
		m[x].sign=true;
	}
	for(int i=m[0].right;i;i=m[i].right)
	{
		if(!m[i].sign)
		{
			cout<<i<<" ";
		}
	}
}
```
