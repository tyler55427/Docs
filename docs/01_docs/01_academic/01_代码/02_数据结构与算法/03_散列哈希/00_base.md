- $ASL_s$(Average Search Length)：

  - 定义：平均查找成功程度，即在散列表中查找一个元素所需的平均比较次数。
  - 计算（以线性探测为例）：
    - $ASL_s = \frac{1}{n} \sum_{i=1}^{n} (1 + c_i)$
    - 其中，$n$为已插入的**元素个数**，$c_i$为第$i$个元素在散列表中查找时的冲突次数。
    - $1+c_i$为比较次数。
- $ASL_u$(Average Search Length)：

  - 定义：平均查找失败程度，即在散列表中查找一个不存在的元素所需的平均比较次数。
  - 计算（以线性探测为例）：
    - $ASL_u = \frac{1}{m} \sum_{i=1}^{m} (1 + d_i)$
    - 其中，$m$为散列表的**key数**，$d_i$为第$i$个槽位在查找失败时的到右边第一空位的距离。
    - $1+d_i$为比较次数。
