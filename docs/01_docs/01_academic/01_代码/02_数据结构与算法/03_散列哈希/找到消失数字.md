# 找到消失数字

**问题描述**：给定一个范围在 1 ≤ a[i] ≤ n 的数组，数组中的元素一些出现了两次，另一些只出现一次。找出所有在 [1, n] 范围之间没有出现在数组中的数字。

**解法**：原地不使用额外 hash，遍历数组，将出现过的数字对应的索引位置的数变为负数，最后再遍历一次数组，找到正数的位置即为缺失的数字。

```cpp
vector<int> findDisappearedNumbers(vector<int>& nums)
{
    for (int num : nums)
    {
        int index = abs(num) - 1;
        if (nums[index] > 0)
        {
            nums[index] = -nums[index];
        }
    }

    vector<int> result;
    for (int i = 0; i < nums.size(); ++i)
    {
        if (nums[i] > 0)
        {
            result.push_back(i + 1);
        }
    }

    return result;
}
```
