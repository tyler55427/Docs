# 前向星

## 前向星（Forward Star）

**问题描述**：用前向星结构存储图，支持添加边和遍历图中所有边。

**解法**：前向星是一种基于链表（或数组模拟链表）的图的存储结构，通过 head 数组记录每个节点的第一条边的位置，用 to、w、nxt 数组存储边的终点、权重和下一条边的位置。时间复杂度 O(m)。

```cpp
const int MAXN = 100005;
const int MAXM = 200005;

int head[MAXN], to[MAXM], w[MAXM], nxt[MAXM], cnt;

void addEdge(int u, int v, int weight) {
    to[++cnt] = v;
    w[cnt] = weight;
    nxt[cnt] = head[u];
    head[u] = cnt;
}

int main() {
    int n, m;
    cin >> n >> m;

    for(int i = 0; i < m; ++i) {
        int u, v, weight;
        cin >> u >> v >> weight;
        addEdge(u, v, weight);
        // 无向图：addEdge(v, u, weight);
    }

    // 遍历所有边
    for(int u = 1; u <= n; ++u) {
        for(int i = head[u]; i; i = nxt[i]) {
            cout << u << " -> " << to[i] << " : " << w[i] << endl;
        }
    }

    return 0;
}
```

**备注**：

- 前向星适合稀疏图，存储效率高
- 边的添加顺序影响遍历顺序（后添加的边先遍历）
- 可轻松改为有向图或无向图
