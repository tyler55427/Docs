# 相交链表

## 相交链表问题

**问题描述**：给定两个链表，找到它们的交点。

**解法**：使用双指针，到结尾的时候，切换到另一个链表的头部，最终会在交点相遇

**备注**：移动步数相同

```cpp
ListNode* getIntersectionNode(ListNode* headA, ListNode* headB) {
    if (!headA || !headB) {
        return nullptr;
    }

    ListNode* pA = headA;
    ListNode* pB = headB;

    // 判断当前节点，而不是next，如果不进入nullptr，会导致五相交的时候无法退出
    while (pA != pB) {
        pA = pA ? pA->next : headB;
        pB = pB ? pB->next : headA;
    }

    return pA;
}
```
