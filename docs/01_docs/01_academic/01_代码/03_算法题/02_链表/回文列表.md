# 回文链表

**问题描述**：判断一个链表是否为回文链表。

## 栈

使用栈进行两次遍历，第一次将所有节点入栈，第二次与原链表比对。

```cpp
bool isPalindrome(ListNode* head)
{
    stack<int> s;
    ListNode* cur = head;
    while (cur)
    {
        s.push(cur->val);
        cur = cur->next;
    }
    cur = head;
    while (cur)
    {
        if (cur->val != s.top())
        {
            return false;
        }
        s.pop();
        cur = cur->next;
    }
    return true;
}
```

## 快慢指针 + 反转

使用快慢指针和链表反转。先找链表中点，反转后半部分，再比较前半与后半是否一致。空间复杂度 O(1)。

```cpp
bool isPalindrome(ListNode* head)
{
    if (head == nullptr)
    {
        return true;
    }

    ListNode* firstHalfEnd = endOfFirstHalf(head);
    ListNode* secondHalfStart = reverseList(firstHalfEnd->next);

    ListNode* p1 = head;
    ListNode* p2 = secondHalfStart;
    bool result = true;
    while (result && p2 != nullptr)
    {
        if (p1->val != p2->val)
        {
            result = false;
        }
        p1 = p1->next;
        p2 = p2->next;
    }

    firstHalfEnd->next = reverseList(secondHalfStart);
    return result;
}
```

- `endOfFirstHalf`：双数为前一半的最后一个，单数为中间节点。
- `reverseList`：反转链表。

```cpp
ListNode* endOfFirstHalf(ListNode* head)
{
    ListNode* fast = head;
    ListNode* slow = head;
    while (fast->next != nullptr && fast->next->next != nullptr)
    {
        fast = fast->next->next;
        slow = slow->next;
    }
    return slow;
}

ListNode* reverseList(ListNode* head)
{
    ListNode* prev = nullptr;
    ListNode* curr = head;
    while (curr != nullptr)
    {
        ListNode* nextTemp = curr->next;
        curr->next = prev;
        prev = curr;
        curr = nextTemp;
    }
    return prev;
}
```
