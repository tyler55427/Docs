# 反转链表

## 反转链表

**说明**：迭代法反转链表，使用三个指针 prev、curr、next_temp

```cpp
ListNode* reverseList(ListNode* head) {
    ListNode* prev = nullptr;
    ListNode* curr = head;
    
    while (curr) {
        ListNode* next_temp = curr->next;
        curr->next = prev;
        prev = curr;
        curr = next_temp;
    }
    
    return prev;
}
```
