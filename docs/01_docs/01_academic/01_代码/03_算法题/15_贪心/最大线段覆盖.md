# 最大线段覆盖

## 最大线段覆盖

**问题描述**：给定 n 个线段 [a, b]，选择尽可能多的线段，使得选中的线段互不重叠（端点相同算不重叠）。求最多能选择多少个线段

**解法**：贪心算法。按线段右端点排序，依次选择右端点最早的线段，只要当前线段左端点大于等于已选线段右端点即可选择

```cpp
vector<pair<int,int>> v;

int main()
{
	int n;
	cin>>n;
	for(int i=1;i<=n;++i)
	{
		int a,b;
		cin>>a>>b;
		v.push_back({a,b});
	}
	sort(v.begin(),v.end(),[](pair<int,int> aa,pair<int,int> bb)
	{
		return aa.second<bb.second;
	});
	int res=1;
	int i=0,p=v[0].second;
	while(i<n)
	{
		i++;
		if(v[i].first>=p)
		{
			res++;
			p=v[i].second;
		}
	}
	cout<<res;
}
```

**备注**：标准贪心解法，按结束时间排序
