# 二维前缀和

## 二维前缀和计算

**说明**：使用差分数组计算矩形区域和

```cpp
int main() {
    ios::sync_with_stdio(0), cin.tie(0), cout.tie(0);
    int n, m;
    cin >> n >> m;
    int x, y;
    int a, b;
    for (int i = 0;i < m;++i) {
        cin >> x >> y >> a >> b;
        arr[x][y]++;
        arr[a + 1][b + 1]++;
        arr[a + 1][y]--;
        arr[x][b + 1]--;
    }
    res[0][0] = arr[0][0];
    for (int i = 1;i <= n;++i)
        for (int j = 1;j <= n;++j)
            res[i][j] = res[i - 1][j] + res[i][j - 1] - res[i - 1][j - 1] + arr[i][j];
    for (int i = 1;i <= n;++i) {
        for (int j = 1;j <= n;++j)
            cout << res[i][j] << " ";
        cout << endl;
    }
    return 0;
}
```
