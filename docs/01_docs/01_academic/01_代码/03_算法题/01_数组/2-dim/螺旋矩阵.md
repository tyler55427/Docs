# 螺旋矩阵

## 螺旋矩阵

**问题描述**：给定一个包含 m x n 个元素的矩阵，按照顺时针螺旋顺序返回矩阵中的所有元素。

**解法**：维护上下边界和左右边界，四个循环进行遍历

```cpp
vector<int> spiralOrder(vector<vector<int>>& matrix) {
    if (matrix.empty()) return {};

    vector<int> result;
    int top = 0, bottom = matrix.size() - 1;
    int left = 0, right = matrix[0].size() - 1;

    while (top <= bottom && left <= right) {
        for (int j = left; j <= right; ++j) {
            result.push_back(matrix[top][j]);
        }
        ++top;

        for (int i = top; i <= bottom; ++i) {
            result.push_back(matrix[i][right]);
        }
        --right;

        if (top <= bottom) {
            for (int j = right; j >= left; --j) {
                result.push_back(matrix[bottom][j]);
            }
            --bottom;
        }

        if (left <= right) {
            for (int i = bottom; i >= top; --i) {
                result.push_back(matrix[i][left]);
            }
            ++left;
        }
    }

    return result;
}
```

## 螺旋矩阵（对称比较法）

**解法**：比较对称，虽然有点重复

```cpp
vector<int> spiralOrder(vector<vector<int>>& matrix) {
    vector<int> result;

    int n = matrix.size();
    int m = matrix[0].size();

    int ns = 0, ne = n - 1, ms = 0, me = m - 1;
    int cnt = n * m;

    while (cnt) {
        for (int i = ms; cnt && i <= me; ++i) {
            result.push_back(matrix[ns][i]);
            cnt--;
        }
        for (int i = ns + 1; cnt && i < ne; ++i) {
            result.push_back(matrix[i][me]);
            cnt--;
        }
        for (int i = me; cnt && i >= ms; --i) {
            result.push_back(matrix[ne][i]);
            cnt--;
        }
        for (int i = ne - 1; cnt && i > ns; --i) {
            result.push_back(matrix[i][ms]);
            cnt--;
        }
        ns++;
        ne--;
        ms++;
        me--;
    }
    return result;
}
```
