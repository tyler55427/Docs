# 图像旋转

## 图像旋转

**问题描述**：给定一个 n x n 的二维矩阵 matrix 表示一个图像。请你将图像顺时针旋转 90 度。

**解法**：先转置矩阵，再列对称

```cpp
void rotate(vector<vector<int>>& matrix) {
    int n = matrix.size();
    
    for (int i = 0; i < n; ++i) {
        for (int j = i; j < n; ++j) {
            swap(matrix[i][j], matrix[j][i]);
        }
    }
    
    for (int i = 0; i < n; ++i) {
        reverse(matrix[i].begin(), matrix[i].end());
    }
}
```

## 直接交换四个元素

**解法**：直接交换四个元素的位置，分别是 (i, j), (j, n - 1 - i), (n - 1 - i, n - 1 - j), (n - 1 - j, i)

```cpp
void rotate(vector<vector<int>>& matrix) {
    int n = matrix.size();
    
    for (int i = 0; i < n / 2; ++i) {
        for (int j = 0; j < (n + 1) / 2; ++j) {
            int temp = matrix[i][j];
            matrix[i][j] = matrix[n - 1 - j][i];
            matrix[n - 1 - j][i] = matrix[n - 1 - i][n - 1 - j];
            matrix[n - 1 - i][n - 1 - j] = matrix[j][n - 1 - i];
            matrix[j][n - 1 - i] = temp;
        }
    }
}
```
