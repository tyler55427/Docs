# 逆序对

## 逆序对计数

**题目描述**：统计一个数组中满足 i<j 且 arr[i] > arr[j] 的 (i,j) 对数

**解法**：归并排序期间统计（分治）

**核心思想**：在归并过程中，当左侧元素 > 右侧元素时，左侧从 i 到 m 的所有元素都与右侧当前元素构成逆序对

## 合并计数

**说明**：合并两个有序子数组 [l..m] 和 [m+1..r]，返回逆序对数量

```cpp
ll mergeCount(int l, int m, int r)
{
    int i = l;      // 左侧子数组的指针
    int j = m + 1;  // 右侧子数组的指针
    int k = l;      // 临时数组的指针
    ll count = 0;   // 逆序对计数

    // 合并两个有序数组
    while(i <= m && j <= r)
    {
        // arr[i] <= arr[j]: 左侧元素更小或相等，不构成逆序对
        // arr[i] > arr[j]: 左侧从 i 到 m 的所有元素都与 arr[j] 构成逆序对
        if(arr[i] <= arr[j])
        {
            temp[k++] = arr[i++];
        }
        else
        {
            temp[k++] = arr[j++];
            count += m - i + 1;  // 左侧 i..m 共 (m-i+1) 个元素都与右侧当前元素构成逆序对
        }
    }

    while(i <= m) temp[k++] = arr[i++];
    while(j <= r) temp[k++] = arr[j++];

    for(int ii = l; ii <= r; ++ii)
        arr[ii] = temp[ii];

    return count;
}
```

## 归并排序主递归函数

**说明**：递归统计左右两部分的逆序对，合并两个有序子数组，统计跨越左右两部分之间的逆序对

```cpp
ll mergeSortCount(int l, int r)
{
    if(l >= r) return 0;  // 递归终止条件：子数组只有一个元素或为空

    int m = (l + r) / 2;  // 取中点，分割数组

    ll leftCount = mergeSortCount(l, m);      // 左侧子数组内的逆序对
    ll rightCount = mergeSortCount(m + 1, r); // 右侧子数组内的逆序对
    ll crossCount = mergeCount(l, m, r);

    return leftCount + rightCount + crossCount;
}
```
