# 区间修改

## 题目名称

**问题描述**：对数组 a 的区间 [l, r] 进行 +k 操作，最后输出修改后的数组

**解法**：差分数组。核心思想是将区间修改 O(n) 转化为差分数组两端更新 O(1)，最后通过前缀和还原为修改后的数组。适用于大量区间修改、少量查询的场景。

```cpp
int a[100];  // 原数组
int b[100];  // 差分数组

int main() {
    int n, l, r, k;
    cin >> n >> l >> r >> k;

    // 第一步：构建差分数组
    // 差分定义：b[i] = a[i] - a[i-1]（a[-1] 视为 0）
    for(int i = 0; i < n; ++i) {
        cin >> a[i];
        if(i == 0) b[i] = a[i];       // b[0] = a[0] - 0 = a[0]
        else b[i] = a[i] - a[i-1];   // b[i] = a[i] - a[i-1]
    }

    // 第二步：对区间 [l, r] 进行 +k 操作
    // 差分性质：对 a[l..r] 加 k，等价于 b[l] += k, b[r+1] -= k
    b[l] += k;
    if(r + 1 < n) b[r + 1] -= k;  // 防止越界

    // 第三步：还原并输出原数组（未修改版本）
    for(int i = 0; i < n; ++i)
        cout << a[i] << " ";
    cout << endl;

    // 第四步：通过前缀和还原修改后的数组
    for(int i = 0; i < n; ++i) {
        int sum = 0;
        for(int j = 0; j <= i; ++j) sum += b[j];  // 前缀和
        cout << sum << " ";
    }
    cout << endl;

    return 0;
}
```
