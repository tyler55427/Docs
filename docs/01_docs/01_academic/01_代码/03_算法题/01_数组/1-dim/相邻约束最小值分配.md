# 相邻约束最小值分配

**问题描述**：给定整数序列 x_i，求解整数序列的函数 f_i 满足：

- f_i >= 1；
- 如果 x_i > x_{i-1}，则 f_i > f_{i-1}；
- 如果 x_i > x_{i+1}，则 f_i > f_{i+1}。

这里增强对整数序列进行分段处理，分段符为小于等于0的整数。

对于每个分段，按照上述条件计算函数f_i的值，并求出所有f_i的总和最小值。

**解法**：分左右两次遍历，满足相邻约束。

```cpp
int distribute[200010];

int main()
{
    string line;
    getline(cin, line);

    vector<int> ratings;
    stringstream ss(line);
    string token;

    while (getline(ss, token, ','))
    {
        ratings.push_back(stoi(token));
    }
    int len = ratings.size();

    distribute[0] = ratings[0] > 0 ? 1 : 0;

    // 从左到右遍历
    for (int i = 1; i < len; ++i)
    {
        if (ratings[i] > 0)
        {
            if (ratings[i] > ratings[i - 1]) distribute[i] = distribute[i - 1] + 1;
            else distribute[i] = 1;
        }
    }

    // 从右到左遍历
    for (int i = len - 2; i >= 0; --i)
    {
        if (ratings[i] > 0)
        {
            if (ratings[i] > ratings[i + 1]) distribute[i] = max(distribute[i], distribute[i + 1] + 1);
        }
    }

    long long ans = 0;
    for (int i = 0; i < len; ++i) ans += distribute[i];

    cout << ans << endl;

    return 0;
}
```
