# 荷兰国旗问题

## 荷兰国旗问题

**问题描述**：给定一个包含红色、白色和蓝色的数组，原地对它们进行排序，使得相同颜色的元素相邻，并按照红色、白色、蓝色顺序排列

**解法**：使用三个指针，维护左右指针两侧的确定性。

- `left`：红色边界左侧，已排好序
- `curr`：当前遍历指针
- `right`：蓝色边界右侧，已排好序

```cpp
void sortColors(vector<int>& nums)
{
    int left = 0, curr = 0;
    int right = nums.size() - 1;

    while (curr <= right)
    {
        if (nums[curr] == 0)        // 红色，与 left 交换，left 和 curr 右移
        {
            swap(nums[left], nums[curr]);
            ++left;
            ++curr;
        }
        else if (nums[curr] == 1)   // 白色，只右移 curr
        {
            ++curr;
        }
        else                         // 蓝色，与 right 交换，right 左移，curr 不变
        {
            swap(nums[curr], nums[right]);
            --right;
        }
    }
}
```
