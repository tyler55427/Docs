## 砍树

**问题描述**：有 n 棵树，每棵树高度为 len[i]。现在需要砍树得到至少 m 米木材。伐木机可以设定一个切割高度 H，高于 H 的树会被砍到 H 高度，低于 H 的树不会被砍。求最大的切割高度 H，使得获得的木材至少为 m 米

**解法**：二分搜索答案。在 [0, max_height] 范围内二分搜索切割高度 H，计算该高度能获得的木材量，根据结果调整搜索范围

```cpp
long long len[1000009];

int main()
{
	long long n,m;
	cin>>n>>m;
	long long l=0,r=0;
	for(long long i=0;i<n;++i)
	{
		cin>>len[i];
		r=max(len[i],r);
	}
	long long temp;
	while(l<=r)
	{
		long long mid=(l+r)/2;
		temp=0;
		for(long long i=0;i<n;++i)
		{
			if(len[i]>mid)
			{
				temp+=len[i]-mid;
			}
		}
		if(temp<m)
		{
			r=mid-1;
		}
		else
		{
			l=mid+1;
		}
	}
	cout<<r;
	return 0;
}
```
