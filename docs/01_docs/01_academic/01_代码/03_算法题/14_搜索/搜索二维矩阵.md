# 搜索二维矩阵

**问题描述**：编写一个高效的算法来判断 m × n 矩阵中是否存在一个目标值。该矩阵具有以下特性：每行中的整数从左到右按升序排列；每行的第一个整数大于前一行的最后一个整数。

**解法**：从右上角开始搜索：
1. 如果目标值等于当前元素，返回 true
2. 如果目标值小于当前元素，向左移动（j--）
3. 如果目标值大于当前元素，向下移动（i++）

找到一个单调的方向。

```cpp
bool searchMatrix(std::vector<std::vector<int>>& matrix, int target)
{
    if (matrix.empty()) return false;

    int m = matrix.size(), n = matrix[0].size();
    int i = 0, j = n - 1;

    while (i < m && j >= 0)
    {
        if (target == matrix[i][j])
        {
            return true;
        }
        else if (target < matrix[i][j])
        {
            --j;
        }
        else
        {
            ++i;
        }
    }

    return false;
}
```
