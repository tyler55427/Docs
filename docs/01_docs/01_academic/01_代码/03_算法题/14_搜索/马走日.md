# 马走日

## 马走日

**问题描述**：在国际象棋棋盘（m x n）上，给定马的起始位置 (x, y)，计算马到达棋盘上每个位置所需的最小步数。马走"日"字，有 8 个可能的移动方向

**解法**：BFS 广度优先搜索。从起始位置开始，将所有可达位置加入队列，记录步数，直到队列为空。最后标记无法到达的位置为 -1

```cpp
queue<pair<int,int>> q;
// 直接用递归的方法就变成了DFS 
int a[500][500];
int p[8][2]={{-1,-2},{-2,-1},{-2,1},{-1,2},{1,2},{2,1},{2,-1},{1,-2}};
int m,n,x,y;

void print(){
	for(int i=0;i<m;++i){
		for(int j=0;j<n;++j){
			cout<<a[i][j]<<" ";
		}
		cout<<endl;
	}
}

int main()
{
	cin>>m>>n>>x>>y;
	x-=1,y-=1;
	q.push({x,y});
	while(!q.empty()){
		int xx,yy;
		xx=q.front().first;
		yy=q.front().second;
		q.pop();
		for(int i=0;i<8;++i){
			if(xx+p[i][0]>=0 && xx+p[i][0]<m && yy+p[i][1]>=0 && yy+p[i][1]<n 
			&& a[xx+p[i][0]][yy+p[i][1]]==0 
			&& !(xx+p[i][0]==x && yy+p[i][1]==y)){
				q.push({xx+p[i][0],yy+p[i][1]});
				a[xx+p[i][0]][yy+p[i][1]]=a[xx][yy]+1;
			}
		}
	}
	for(int i=0;i<m;++i){
		for(int j=0;j<n;++j){
			if(a[i][j]==0 && !(i==x && j==y)) a[i][j]=-1;
		}
	}
	print();
}
```

**备注**：起始位置需转换为 0-indexed；无法到达的位置标记为 -1
