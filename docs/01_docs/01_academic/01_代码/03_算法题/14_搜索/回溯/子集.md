# 子集

## 子集（无重复元素）

**问题描述**：给定一个整数数组 nums，返回该数组所有可能的子集（幂集）。解集不能包含重复的子集

**解法**：使用回溯算法，维护一个路径和一个起始索引来避免重复的子集

```cpp
void backtrack1(vector<vector<int>>& result, vector<int>& path, vector<int>& nums, int start) {
    // 不考虑当前元素的情况
    result.push_back(path);

    for (int i = start; i < nums.size(); ++i) {
        path.push_back(nums[i]);
        backtrack1(result, path, nums, i + 1);
        path.pop_back();
    }
}

// 没有重复元素的情况
vector<vector<int>> subsets(vector<int>& nums) {
    vector<vector<int>> result;
    vector<int> path;

    backtrack1(result, path, nums, 0);
    return result;
}
```

## 子集（有重复元素）

**解法**：先排序，保证相同元素相邻，方便去重

```cpp
void backtrack2(vector<vector<int>>& result, vector<int>& path, vector<int>& nums, int start) {
    result.push_back(path);

    for (int i = start; i < nums.size(); ++i) {
        if (i > start && nums[i] == nums[i - 1]) {
            continue;
        }
        path.push_back(nums[i]);
        backtrack2(result, path, nums, i + 1);
        path.pop_back();
    }
}

// 有重复元素的情况
vector<vector<int>> subsetsWithDup(vector<int>& nums) {
    vector<vector<int>> result;
    vector<int> path;
    // 先排序，保证相同元素相邻，方便去重
    sort(nums.begin(), nums.end());

    backtrack2(result, path, nums, 0);
    return result;
}
```
