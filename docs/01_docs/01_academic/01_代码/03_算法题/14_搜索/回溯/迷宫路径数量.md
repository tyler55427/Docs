# 迷宫路径数量

**问题描述**：给定 m × n 的迷宫，其中 -1 表示障碍物。从起点 (sx, sy) 走到终点 (fx, fy)，只能上下左右移动，且不能重复经过同一格子。统计可行的路径总数。

**解法**：DFS 回溯搜索。深度优先遍历四个方向，标记已访问的格子，回溯时撤销标记。到达终点时路径数加 1。

## 全局变量

- maze：迷宫地图（-1 表示障碍物）
- visited：标记格子是否已访问
- directions：下右上左四个方向

```cpp
int maze[10][10];       // 迷宫地图（-1 表示障碍物）
bool visited[10][10];  // 标记格子是否已访问
int directions[4][2] = {{1, 0}, {0, 1}, {-1, 0}, {0, -1}};  // 下右上左

int startX, startY;    // 起点坐标
int endX, endY;        // 终点坐标
int pathCount;         // 路径总数

int rows, cols;        // 迷宫行数、列数
int obstacleCount;     // 障碍物数量
```

## 判断坐标

判断坐标是否在迷宫范围内。

```cpp
bool isInBounds(int x, int y)
{
    if (x <= 0 || y <= 0 || x > rows || y > cols) return false;
    return true;
}
```

## DFS 回溯

从 (x, y) 走到终点。枚举四个方向，剪枝：必须在范围内、未访问、不是障碍物。标记当前格子为已访问，递归搜索下一格，回溯撤销标记。

```cpp
void dfs(int x, int y)
{
    // 到达终点，路径数加 1
    if (x == endX && y == endY)
    {
        pathCount++;
        return;
    }

    // 枚举四个方向
    for (int i = 0; i < 4; ++i)
    {
        int nx = x + directions[i][0];
        int ny = y + directions[i][1];

        // 剪枝：必须在范围内、未访问、不是障碍物
        if (isInBounds(nx, ny) && !visited[nx][ny] && maze[nx][ny] != -1)
        {
            visited[x][y] = true;
            dfs(nx, ny);
            visited[x][y] = false;
        }
    }
}
```

## 主函数

```cpp
int main()
{
    cin >> rows >> cols >> obstacleCount;
    cin >> startX >> startY >> endX >> endY;

    // 标记障碍物
    for (int i = 0; i < obstacleCount; ++i)
    {
        int bx, by;
        cin >> bx >> by;
        maze[bx][by] = -1;
    }

    dfs(startX, startY);
    cout << pathCount << endl;
    return 0;
}
```
