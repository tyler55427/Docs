# 启发搜索

**问题描述**：给定 n 个物品（每个有时间/重量 a 和价值 b）和总时间限制 total_time，求在时间限制内能获得的最大价值。

**解法**：分支限界 + 贪心启发式剪枝（DFS + 最优性剪枝 + 可行性剪枝）。按价值/时间比排序，DFS 枚举选择，用贪心估计上界进行剪枝。时间复杂度：最坏 O(2^n)，实际通过剪枝大幅减少搜索空间。

## 全局变量

```cpp
constexpr int MAX_N = 105;

int n;            // 物品数量
int totalTime;    // 总时间限制（相当于背包容量）
int bestValue;    // 全局最优解

struct Item
{
    int time;      // 时间（重量）
    int value;     // 价值
    double ratio; // 价值/时间比（效率）
} items[MAX_N];
```

## 贪心上界

按效率比排序（从大到小）。

```cpp
bool operator<(Item a, Item b)
{
    return a.ratio > b.ratio;
}
```

**问题描述**：估计从第 idx 个物品开始，在剩余时间 restTime 内能获得的最大价值上界。

**解法**：优先选择效率高的物品，尽量填满剩余时间。优先装入效率高的物品，时间不够时按比例计算部分价值。

```cpp
// 贪心启发式函数：估计从第 idx 个物品开始，在剩余时间 restTime 内能获得的最大价值
// 思路：优先选择效率高的物品，尽量填满剩余时间
// 返回值是理论上界的估计值（可能高估，但必须乐观才能保证不剪掉最优解）
int heuristicUpperBound(int idx, int restTime)
{
    int totalValue = 0;
    for (int i = idx; i <= n; ++i)
    {
        if (items[i].time <= restTime)
        {
            // 当前物品能装入，加上其价值，减少剩余时间
            restTime -= items[i].time;
            totalValue += items[i].value;
        }
        else
        {
            // 时间不够完整装入，贪心按比例计算部分价值
            // items[i].ratio = items[i].value / items[i].time
            // 可装入的比例 = restTime / items[i].time
            return (int)(totalValue + restTime * items[i].ratio);
        }
    }
    return totalValue;
}
```

## DFS 搜索

**问题描述**：分支限界搜索 0/1 背包问题。

**解法**：DFS + 最优性剪枝 + 可行性剪枝。idx: 当前处理的物品编号，rest: 剩余可用时间，curVal: 当前已获得的价值。

```cpp
void search(int idx, int rest, int curVal)
{
    // 更新最优解
    bestValue = max(bestValue, curVal);

    // 边界：所有物品处理完毕
    if (idx > n) return;

    // 最优性剪枝：即使把剩余物品全部装入也超不过当前最优解
    // heuristicUpperBound(idx, rest) 估计从 idx 开始的最大可能价值
    // 若 curVal + 上界 <= bestValue，说明后续搜索不可能找到更优解，剪枝
    if (curVal + heuristicUpperBound(idx, rest) <= bestValue)
        return;

    // 分支1：不选当前物品，直接跳到下一个
    search(idx + 1, rest, curVal);

    // 分支2（可行性剪枝）：如果当前物品能装入，则选择它
    if (items[idx].time <= rest)
        search(idx + 1, rest - items[idx].time, curVal + items[idx].value);
}
```

## 主函数

```cpp
int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> totalTime >> n;
    for (int i = 1; i <= n; ++i)
    {
        cin >> items[i].time >> items[i].value;
        items[i].ratio = 1.0 * items[i].value / items[i].time;
    }

    // 按价值/时间比从大到小排序（优先选效率高的）
    sort(items + 1, items + n + 1);

    // 从第1个物品开始搜索（初始无选择，rest=totalTime, curVal=0）
    search(1, totalTime, 0);

    cout << bestValue << endl;
    return 0;
}
```
