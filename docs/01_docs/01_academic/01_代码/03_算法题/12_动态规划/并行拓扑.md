# 并行拓扑

## 题目名称

**问题描述**：给定 n 个任务，每个任务有一个完成时间 l 和依赖任务列表，求完成所有任务的最短时间。

**解法**：拓扑排序 + 动态规划。对于每个任务，dp[i] 表示完成该任务的最短时间，dp[i] = max(dp[t]) + l[i]，其中 t 为该任务的依赖任务。

```cpp
int n,l,t,ans[10005],maxans;
int main()
{
    scanf("%d",&n);
    for(int i=1;i<=n;++i){
        scanf("%d",&i);
        scanf("%d",&l);
        int tmp=0;
        while(scanf("%d",&t)&&t)
            tmp=max(ans[t],tmp);
        ans[i]=tmp+l;
        maxans=max(ans[i],maxans);
    } 
    printf("%d\n",maxans);
    return 0;
 }
```
