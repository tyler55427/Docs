# 单词拆分

## 题目名称

**问题描述**：给定一个非空字符串 s 和一个包含非空单词的列表 wordDict，判断 s 是否可以被空格拆分成一个或多个在 wordDict 中出现的单词，可以重复使用。

**解法**：动态规划，维护一个 dp 数组，其中 dp[i] 表示 s 的前 i 个字符是否可以被拆分成 wordDict 中的单词。

**备注**：对于每一个位置，都要遍历之前的状态，找是否能够拆分。

```cpp
bool wordBreak(string s, vector<string>& wordDict) {
    unordered_set<string> word_set(wordDict.begin(), wordDict.end());
    int n = s.length();
    vector<bool> dp(n + 1, false);
    dp[0] = true;
  
    for (int i = 1; i <= n; ++i) {
        for (int j = 0; j < i; ++j) {
            if (dp[j] && word_set.find(s.substr(j, i - j)) != word_set.end()) {
                dp[i] = true;
                break;
            }
        }
    }
  
    return dp[n];
}
```
