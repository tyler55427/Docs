# 只出现一次的数字

## 变体 I

**问题描述**：非空整数数组，除了一个元素只出现一次，其余每个元素均出现两次，找出那个只出现一次的元素。

**解法**：异或运算。任何数与自己异或为 0，0 与 x 异或为 x。时间 O(n)，空间 O(1)。

```cpp
int singleNumber(vector<int>& nums)
{
    int result = 0;
    for (int num : nums)
    {
        result ^= num;
    }
    return result;
}
```

## 变体 II

**问题描述**：非空整数数组，除了一个元素只出现一次，其余每个元素均出现三次，找出那个只出现一次的元素。

**解法**：统计每一位上 1 的个数，若不是 3 的倍数，则只出现一次的元素在该位为 1。时间 O(32n)，空间 O(1)。

```cpp
int singleNumber(vector<int>& nums)
{
    int result = 0;
    for (int i = 0; i < 32; ++i)
    {
        int count = 0;
        for (int num : nums)
        {
            count += (num >> i) & 1;
        }
        result |= (count % 3) << i;
    }
    return result;
}
```

## 变体 III

**问题描述**：整数数组，恰好有两个元素只出现一次，其他元素都出现两次，找出这两个只出现一次的元素。

**解法**：所有元素异或得到两目标数的异或，找最低位 1（diff_bit = xor & -xor），据此将数组分成两组分别异或。diff_bit = xor & (-xor) 保留最低位的 1。

```cpp
vector<int> singleNumber(vector<int>& nums)
{
    int xor_all = 0;
    for (int num : nums)
    {
        xor_all ^= num;
    }

    int diff_bit = xor_all & (-xor_all);

    vector<int> result(2, 0);
    for (int num : nums)
    {
        if (num & diff_bit)
        {
            result[0] ^= num;
        }
        else
        {
            result[1] ^= num;
        }
    }

    return result;
}
```
