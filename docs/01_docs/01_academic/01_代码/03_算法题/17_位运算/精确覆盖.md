# 精确覆盖

## 精确覆盖问题（Exact Cover）

**题目描述**：给定 n 行 m 列的 0/1 矩阵，找出哪些行的组合能够"精确覆盖"所有 m 列（即每列恰好被选中的行覆盖一次）

**解法**：暴力枚举 + 位运算加速

**核心思想**：将每行编码为 m 位二进制数，枚举所有 2^n 种选法，用位运算 O(1) 判断两行是否冲突、是否覆盖所有列

**时间复杂度**：O(n × 2^n)，比朴素 O(n² × 2^n) 快得多

## 主函数

**说明**：读取矩阵并枚举所有选法

```cpp
int main() {
    int found = 0;  // 是否找到解
    cin >> n >> m;

    // 读取矩阵
    for(int i = 1; i <= n; ++i)
        for(int j = 1; j <= m; ++j)
            cin >> matrix[i][j];

    // 将每行转换为 m 位二进制数
    // 二进制位 j（从右往左）对应第 j 列
    // 例如: row[5] = [1,0,1] → rowMask[5] = 0b101 = 5
    for(int i = 1; i <= n; ++i) {
        rowMask[i] = 0;
        for(int j = m; j >= 1; --j) {  // 从高位开始，保证列顺序
            rowMask[i] = (rowMask[i] << 1) | matrix[i][j];
        }
    }

    // 枚举所有 2^n 种选法（每行选或不选）
    for(int state = 0; state < (1 << n); ++state) {
        int covered = 0;  // 已覆盖的列（用二进制表示）

        // 检查当前选法是否有效
        for(int i = 1; i <= n; ++i) {
            // 检查第 i 行是否被选中
            if(state & (1 << (i - 1))) {
                // 若当前行与已覆盖列有重叠（冲突），该选法无效
                if(covered & rowMask[i])
                    break;
                // 否则将该行覆盖的列加入 covered
                covered |= rowMask[i];
            }
        }

        // 检查是否恰好覆盖所有 m 列
        // (1<<m)-1 = 0b111...1（共 m 个 1）
        if(covered == (1 << m) - 1) {
            found = 1;
            for(int i = 1; i <= n; ++i)
                if(state & (1 << (i - 1)))
                    printf("%d ", i);
            puts("");
        }
    }

    if(!found)
        puts("No solution.");
    return 0;
}
```
