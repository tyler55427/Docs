# 记忆化递归

## 题目名称

**问题描述**：计算三维函数 w(a, b, c)，当 a ≤ 0、b ≤ 0 或 c ≤ 0 时返回 1；当 a > 20、b > 20 或 c > 20 时返回 w(20, 20, 20)。当 a < b < c 时，w(a,b,c) = w(a,b,c-1) + w(a,b-1,c-1) - w(a,b-1,c)；否则 w(a,b,c) = w(a-1,b,c) + w(a-1,b-1,c) + w(a-1,b,c-1) - w(a-1,b-1,c-1)。

**解法**：使用记忆化递归，通过三维数组 arr 记录已计算的结果，避免重复计算。

```cpp
#define ll long long 
ll arr[30][30][30];

// 记忆化的递推 

ll w(ll a,ll b,ll c)
{
	if(a<=0 || b<=0 || c<=0) return 1;
	else if(a>20 || b>20 || c>20) return w(20,20,20);
	else if(a<b && b<c) 
	{
		if(arr[a][b][c-1] && arr[a][b-1][c-1] && arr[a][b-1][c]) return arr[a][b][c-1]+arr[a][b-1][c-1]-arr[a][b-1][c];
		if(a>0 && a<=20 && b>0 && b<=20 && c>0 && c<=20 && !arr[a][b][c]) arr[a][b][c]=w(a,b,c-1)+w(a,b-1,c-1)-w(a,b-1,c);
	}
	else
	{
		if(arr[a-1][b][c] && arr[a-1][b-1][c] && arr[a-1][b][c-1] && arr[a-1][b-1][c-1]) return arr[a-1][b][c]+arr[a-1][b-1][c]+arr[a-1][b][c-1]-arr[a-1][b-1][c-1];	
		if(a>0 && a<=20 && b>0 && b<=20 && c>0 && c<=20 && !arr[a][b][c]) arr[a][b][c]=w(a-1,b,c)+w(a-1,b-1,c)+w(a-1,b,c-1)-w(a-1,b-1,c-1);
	}
	// 又是一个判题必须加的东西 
	return arr[a][b][c];
}

int main()
{
	ll a,b,c;
	while(true)
	{
		cin>>a>>b>>c;
		if(a==-1 && b==-1 && c==-1 ) break;
		cout<<"w("<<a<<", "<<b<<", "<<c<<") = "<<w(a,b,c)<<endl;
	}
	return 0;
}
```
