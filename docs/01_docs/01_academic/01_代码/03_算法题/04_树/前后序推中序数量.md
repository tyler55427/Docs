# 前后序推中序数量

## 前后序推中序数量

**问题描述**：已知二叉树的前序遍历和后序遍历，求中序遍历的可能数量。

**解法**：组合数学 + 区间划分。核心思想：在前序/后序中寻找"相邻对"（pre[i], post[i+1]），每一对都代表一个可以左右子树互换的位置，贡献 2 种可能。时间复杂度 O(n²)。

```cpp
int main() {
    string preorder, postorder;
    cin >> preorder >> postorder;

    // 关键观察：对于非叶子节点，其左子树在前序中以某个值 X 开始，
    //          X 在后序中作为某子树的根节点出现一次
    // 找到形如 pre[i] == X, post[j] == X 的配对，
    // 每个这样的配对代表"左右子树可互换"，贡献 2 种中序
    int swapCount = 0;
    for(int i = 0; i < (int)preorder.length(); ++i) {
        for(int j = 1; j < (int)postorder.length(); ++j) {
            // 前序中第 i 个字符等于后序中第 j 个字符，且
            // 前序中第 i+1 个字符等于后序中第 j-1 个字符
            // 这表示 (pre[i+1]) 是 (pre[i]) 的某个子树根
            // 因此 (pre[i]) 的左/右子树可以互换
            if(preorder[i] == postorder[j] && preorder[i + 1] == postorder[j - 1])
                swapCount++;
        }
    }

    // 每个可互换的位置贡献 2 种可能
    int answer = 1 << swapCount;
    cout << answer << endl;
    return 0;
}
```

**备注**：

- 每个可互换位置贡献 2 种可能，最终答案为 2^swapCount
- 适用于只知道前序和后序遍历序列的情况
