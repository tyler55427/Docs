# 树的重心

## 树的重心（Tree Centroid）

**问题描述**：给定一棵 n 个节点的树，找到一个节点作为根，使得删去该节点后，各连通分量的大小都不超过 n/2（即使最大子树最小的节点）。

**解法**：树形 DP（两次 DFS）。

- 第一次 DFS 求每个节点的子树大小 size[u]；
- 第二次 DFS 计算每个节点作为"重心"时的最大子树大小。
- 时间复杂度 O(n)。

```cpp
const int MAXN = 100009;

int n;                          // 节点数
vector<int> tree[MAXN];         // 邻接表
int subtreeSize[MAXN];          // subtreeSize[u] = 以 u 为根的子树大小
int bestCentroid;               // 找到的重心
int minMaxPart = MAXN;          // 最小的"最大子树大小"

// 第一次 DFS：计算每个节点的子树大小
// u:   当前节点
// fa:  父节点
void dfsSize(int u, int fa) {
    subtreeSize[u] = 1;  // 节点 u 本身
    for(int v : tree[u]) {
        if(v == fa) continue;  // 跳过父节点
        dfsSize(v, u);
        subtreeSize[u] += subtreeSize[v];
    }
}

// 第二次 DFS：找重心
// 删去 u 后，最大的连通分量大小 =
//   max(父方向大小 = n - subtreeSize[u],
//       子节点子树大小 = subtreeSize[v])
void findCentroid(int u, int fa) {
    // 当前节点作为"割点"时，最大连通分量大小
    int maxPart = n - subtreeSize[u];  // 父方向的大小

    for(int v : tree[u]) {
        if(v == fa) continue;
        maxPart = max(maxPart, subtreeSize[v]);
        findCentroid(v, u);
    }

    // 更新重心
    if(maxPart < minMaxPart) {
        minMaxPart = maxPart;
        bestCentroid = u;
    }
}
```

## 主函数

```cpp
int main() {
    cin >> n;
    for(int i = 0; i < n - 1; ++i) {
        int u, v;
        cin >> u >> v;
        tree[u].push_back(v);
        tree[v].push_back(u);
    }

    dfsSize(1, 0);
    findCentroid(1, 0);

    cout << "重心: " << bestCentroid
         << " (最大子树大小: " << minMaxPart << ")" << endl;
    return 0;
}
```

**备注**：

- 树的重心广泛应用于负载均衡、树的划分等问题
- 删除重心后，所有连通分量的大小都不超过 n/2
