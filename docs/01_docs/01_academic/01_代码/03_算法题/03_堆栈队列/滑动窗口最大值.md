# 滑动窗口最大值

## 滑动窗口最大值（单调队列）

**题目描述**：给定一个数组 nums 和滑动窗口的大小 k，请你输出所有滑动窗口里的最大值。

**解法**：单调队列，从头到尾单调递减，利用索引判断超时，从尾部删除较小值，则头为当前最大

```cpp
vector<int> maxSlidingWindow(vector<int>& nums, int k) {
    vector<int> ans;
    // 双端队列，存储索引
    deque<int> dq;

    for (int i = 0; i < nums.size(); ++i) {
        // 1. 移除滑出窗口的索引
        if (!dq.empty() && dq.front() <= i - k) {
            dq.pop_front();
        }

        // 2. 移除队列中所有小于当前元素的值（保持单调递减）
        while (!dq.empty() && nums[dq.back()] <= nums[i]) {
            dq.pop_back();
        }

        // 3. 加入当前元素索引
        dq.push_back(i);

        // 4. 当窗口形成后，记录最大值
        if (i >= k - 1) {
            ans.push_back(nums[dq.front()]);
        }
    }

    return ans;
}
```

## 滑动窗口最大值（线段树）

**解法**：线段树（单点修改 + 区间查询最大值）

```cpp
// 向上更新：父节点 = 左右子节点的最大值
void pushup(int i)
{
    c[i] = max(c[2 * i], c[2 * i + 1]);
}

// 建树：后序遍历，从叶节点向上赋值
void build(int i, int l, int r)
{
    if (l == r)
    {
        c[i] = a[l];
        return;
    }
    int mid = (l + r) / 2;
    build(2 * i, l, mid);
    build(2 * i + 1, mid + 1, r);
    pushup(i);
}

// 单点更新：将 a[pos] 修改为 val
void update(int i, int l, int r, int pos, int val)
{
    if (l == r)
    {
        c[i] = val;
        return;
    }
    int mid = (l + r) / 2;
    if (pos <= mid) update(2 * i, l, mid, pos, val);
    else update(2 * i + 1, mid + 1, r, pos, val);
    pushup(i);
}

// 区间查询最大值
int query(int i, int l, int r, int q, int p)
{
    if (q <= l && p >= r) return c[i];
    int mid = (l + r) / 2;
    int ans = INT_MIN;
    if (q <= mid) ans = max(ans, query(2 * i, l, mid, q, p));
    if (p > mid) ans = max(ans, query(2 * i + 1, mid + 1, r, q, p));
    return ans;
}
```

**时间复杂度**：O(n log n)，不如单调队列的 O(n)，但展示了线段树的典型用法
