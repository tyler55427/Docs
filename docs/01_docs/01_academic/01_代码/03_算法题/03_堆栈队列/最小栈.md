# 最小栈

## 最小栈

**问题描述**：设计一个支持 push、pop、top 操作，并能在常数时间内检索到最小元素的栈。

**解法**：两个栈，一个存储，一个维护最小值

```cpp
class MinStack {
private:
    std::stack<int> stack;
    // 从顶到底，单调递增
    std::stack<int> min_stack;

public:
    MinStack() {}
    
    void push(int val) {
        stack.push(val);
        if (min_stack.empty() || val <= min_stack.top()) {
            min_stack.push(val);
        }
    }
    
    void pop() {
        if (stack.top() == min_stack.top()) {
            min_stack.pop();
        }
        stack.pop();
    }
    
    int top() {
        return stack.top();
    }
    
    int getMin() {
        return min_stack.top();
    }
};
```
