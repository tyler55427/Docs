# 约瑟夫问题

## 约瑟夫问题（队列模拟）

**题目描述**：n 个人围成一圈，从 1 开始报数，数到 k 的人出列，重复直到所有人出列，输出出列顺序

**解法**：队列模拟

**核心思想**：用队列维护当前圈，前 k-1 个不断移到队尾，第 k 个出列

**时间复杂度**：O(n*k)

```cpp
vector<int> josephus(int n, int k) {
    queue<int> q;

    // 初始化队列：1, 2, ..., n
    for(int i = 1; i <= n; ++i)
        q.push(i);

    vector<int> order;  // 出列顺序

    while(!q.empty()) {
        // 报数：前 k-1 个人移到队尾
        for(int i = 0; i < k - 1; ++i) {
            q.push(q.front());
            q.pop();
        }
        // 第 k 个人出列
        order.push_back(q.front());
        q.pop();
    }
    return order;
}
```
