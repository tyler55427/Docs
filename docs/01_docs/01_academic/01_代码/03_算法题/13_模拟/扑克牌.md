# 扑克牌

## 扑克牌

**问题描述**：模拟某种扑克牌洗牌和发牌过程。给定 n 张牌，牌号分别为 1 到 n，将牌放入队列中，不断将队首元素移到队尾，然后依次弹出队首元素，最后将队列中的牌依次弹出放入栈中，再从栈顶依次输出

**解法**：队列 + 栈模拟。用队列模拟洗牌过程，栈逆序输出

```cpp
queue<int> q;
stack<int> s;

int main()
{
	int n;
	cin>>n;
	for(int i=n;i>=1;--i)
	{
		q.push(i);
		q.push(q.front());
		q.pop();
	}
	while(!q.empty())
	{
		s.push(q.front());
		q.pop();
	}
	while(!s.empty())
	{
		cout<<s.top()<<" ";
		s.pop();
	}
}
```
