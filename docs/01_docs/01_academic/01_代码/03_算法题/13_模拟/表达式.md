# 表达式

**问题描述**：输入一个中缀表达式（包含 +、-、*、/ 和括号），输出其后缀表达式形式，并计算表达式的值。

**解法**：中缀转后缀（栈）+ 后缀表达式求值（栈）。使用两个栈：一个用于将中缀表达式转换为后缀表达式，另一个用于计算后缀表达式的值。

## 判断运算符

```cpp
bool isOperator(char c)
{
    return c == '+' || c == '-' || c == '*' || c == '/';
}
```

## 优先级

```cpp
int priority(char c)
{
    if (c == '+' || c == '-')
    {
        return 1;
    }
    else if (c == '*' || c == '/')
    {
        return 2;
    }
    return 0;
}
```

## 中缀转后缀

将字符串转换为整数，处理多位数。

```cpp
int to_int(string &s, int &i)
{
    int res = 0;
    for (; i < s.length() && '0' <= s[i] && s[i] <= '9'; ++i)
    {
        res = 10 * res + s[i] - '0';
    }
    return res;
}
```

遍历中缀表达式：操作数直接入队，左括号入栈，右括号弹出直到左括号，运算符弹出优先级不低于自身的运算符后入栈。

```cpp
queue<string> convert_(string s)
{
    queue<string> r;
    stack<char> t;
    t.push('.');

    for (int i = 0; i < s.length(); ++i)
    {
        if (s[i] >= '0' && s[i] <= '9')
            r.push(to_string(to_int(s, i)));
        if (s[i] == '(')
        {
            t.push(s[i]);
        }
        else if (s[i] == ')')
        {
            while (t.top() != '(')
            {
                string tt = "";
                tt += t.top();
                r.push(tt);
                t.pop();
            }
            t.pop();
        }
        else if (isOperator(s[i]))
        {
            while (t.size() > 1 && priority(t.top()) >= priority(s[i]))
            {
                string tt = "";
                tt += t.top();
                r.push(tt);
                t.pop();
            }
            t.push(s[i]);
        }
    }

    while (t.size() > 1)
    {
        string tt = "";
        tt += t.top();
        r.push(tt);
        t.pop();
    }
    return r;
}
```

## 后缀表达式求值

遍历后缀表达式：操作数入栈，运算符弹出两个操作数运算后结果入栈。

```cpp
int cal_(queue<string> s)
{
    stack<int> temp;
    while (!s.empty())
    {
        if (isOperator(s.front()[s.front().length() - 1]))
        {
            int a, b;
            b = temp.top();
            temp.pop();
            a = temp.top();
            temp.pop();
            if (s.front()[0] == '+')
                temp.push(a + b);
            else if (s.front()[0] == '-')
                temp.push(a - b);
            else if (s.front()[0] == '*')
                temp.push(a * b);
            else if (s.front()[0] == '/')
                temp.push(a / b);
            s.pop();
        }
        else
        {
            int i = 0;
            temp.push(to_int(s.front(), i));
            s.pop();
        }
    }
    return temp.top();
}
```

## 打印

```cpp
void print(queue<string> q)
{
    while (!q.empty())
    {
        cout << q.front() << " ";
        q.pop();
    }
    cout << endl;
}
```
