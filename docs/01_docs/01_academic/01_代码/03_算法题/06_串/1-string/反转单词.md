# 反转单词

## 反转单词

**问题描述**：给定一个字符串 s，反转字符串中单词的顺序。单词是由非空格字符组成的字符串。输入字符串可以在前面或者后面包含多余的空格，但是反转后的字符不能包括。你需要减少反转后单词之间的空格到仅有一个空格。

**解法**：使用 istringstream 读取单词，存储在 vector 中，然后反转 vector，最后拼接成结果字符串。

```cpp
string reverseWords(string s) {
    istringstream iss(s);
    vector<string> words;
    string word;
    
    while (iss >> word) {
        words.push_back(word);
    }
    
    reverse(words.begin(), words.end());
    
    string result;
    for (int i = 0; i < words.size(); ++i) {
        if (i > 0) result += " ";
        result += words[i];
    }
    
    return result;
}
```
