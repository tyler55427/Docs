# 子序列

**问题描述**：给定两个字符串 a 和 b，求最长公共子序列长度；给定 n 个整数，求最长不降子序列长度。

**解法**：最长公共子序列使用二维 DP，状态转移时比较当前字符是否相等；最长不降子序列使用一维 DP，枚举之前所有元素进行状态转移。

字符集：里面的字符之间定义了比较关系。子串：在字符集中选取的连续字符。子序列：在字符集中选取的非连续字符，保持相对位置不变。

## 最长公共子序列

二维 DP，`dp[i][j]` 表示 a[0..i-1] 和 b[0..j-1] 的最长公共子序列长度。

```cpp
int dp[1005][1005];

int lcs(string& a, string& b)
{
    int n = a.size(), m = b.size();
    for (int i = 1; i <= n; ++i)
    {
        for (int j = 1; j <= m; ++j)
        {
            if (a[i - 1] == b[j - 1])
            {
                dp[i][j] = dp[i - 1][j - 1] + 1;
            }
            else
            {
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
    }
    cout << dp[n][m] << endl;
}
```

## 最长不降子序列

一维 DP，`dp2[i]` 表示以 arr[i] 结尾的最长不降子序列长度。初始化每个元素的最长不降子序列长度为 1。

```cpp
int arr[1005];
int dp2[1005];

int lds(int n)
{
    for (int i = 0; i < n; ++i)
    {
        dp2[i] = 1;
        for (int j = 0; j < i; ++j)
        {
            if (arr[j] <= arr[i])
            {
                dp2[i] = max(dp2[i], dp2[j] + 1);
            }
        }
    }
    return dp2[n - 1];
}
```
