# 有效括号

## 有效括号

**问题描述**：给定一个只包括 '('，')'，'{'，'}'，'['，']' 的字符串，判断字符串是否有效

**解法**：
- 使用栈来检查括号的匹配情况
- 遇到左括号入栈
- 遇到右括号时检查栈顶元素是否为对应的左括号
- 如果不匹配或者栈为空，则字符串无效

```cpp
bool isValid(string s) {
    stack<char> stack;
    unordered_map<char, char> mapping = {
        {')', '('},
        {'}', '{'},
        {']', '['}
    };
    
    for (char c : s) {
        // 如果是右括号
        if (mapping.find(c) != mapping.end()) {
            if (stack.empty() || stack.top() != mapping[c]) {
                return false;
            }
            stack.pop();
        } else {
            stack.push(c);
        }
    }
    
    return stack.empty();
}
```
