# 最长公共子串

## 字符集说明

**说明**：
- 子串：在字符集中选取的连续字符
- 子序列：在字符集中选取的非连续字符，保持相对位置不变

## 最长公共子串（空间优化）

**版本1**：纯求长度，空间优化到 O(min(n,m))

```cpp
int lcsubstring_length(string s1, string s2) {
    int n = s1.length(), m = s2.length();
    vector<int> prev(m + 1, 0), cur(m + 1, 0);
    int max_len = 0;
    
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            if (s1[i-1] == s2[j-1]) {
                cur[j] = prev[j-1] + 1;
                max_len = max(max_len, cur[j]);
            } else {
                cur[j] = 0;
            }
        }
        swap(prev, cur);
    }
    return max_len;
}
```

## 最长公共子串（输出子串）

**版本2**：输出子串，空间优化版

```cpp
string lcsubstring_string(string s1, string s2) {
    int n = s1.length(), m = s2.length();
    vector<int> prev(m + 1, 0), cur(m + 1, 0);
    int max_len = 0, end_pos = 0;
    
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            if (s1[i-1] == s2[j-1]) {
                cur[j] = prev[j-1] + 1;
                if (cur[j] > max_len) {
                    max_len = cur[j];
                    end_pos = i;
                }
            } else {
                cur[j] = 0;
            }
        }
        swap(prev, cur);
    }
    return s1.substr(end_pos - max_len, max_len);
}
```
