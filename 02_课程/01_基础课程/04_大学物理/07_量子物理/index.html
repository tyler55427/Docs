    七、量子物理¶

    第26章 波粒二象性¶

    26.1 黑体辐射¶

    基本概念¶

    • 热辐射：物体在任何温度下都向外发射各种频率的电磁波，能量按频率的分布随温度而改变
    • 光谱辐射出射度 \(M_\nu\)：单位时间内从物体单位表面积发出的频率在 \(\nu\) 附近单位频率区间的电磁波的能量，单位 \(\text{W}/(\text{m}^2 \cdot \text{Hz})\)
    • 黑体：能完全吸收照射到它上面的各种频率的光的物体，即 \(a(\nu)=1\)

    普朗克量子化假设¶

    谐振子能量只能取离散值：

    \[E = nh\nu,\quad n = 0, 1, 2, \dots\]

    普朗克常量：

    \[h = 6.626\,075\,5 \times 10^{-34}\,\text{J}\cdot\text{s}\]

    核心公式¶

    维恩公式（高频近似）：

    \[M_\nu = \alpha \nu^3 \mathrm{e}^{-\beta\nu/T}\]

    瑞利-金斯公式（低频近似）：

    \[M_\nu = \frac{2\pi\nu^2}{c^2} kT\]

    普朗克公式（全频域精确）：

    \[M_\nu = \frac{2\pi h}{c^2} \frac{\nu^3}{e^{h\nu/kT} - 1}\]

    实验定律¶

    斯特藩-玻尔兹曼定律：黑体的总辐射出射度

    \[M = \int_0^\infty M_\nu \mathrm{d}\nu = \sigma T^4\]

    其中 \(\sigma = 5.670\,51 \times 10^{-8}\,\text{W}/(\text{m}^2\cdot\text{K}^4)\)

    维恩位移律：光谱辐射出射度最大的光的频率

    \[\nu_{\text{m}} = C_V T\]

    其中 \(C_V = 5.880 \times 10^{10}\,\text{Hz/K}\)，温度升高时 \(\nu_{\text{m}}\) 向高频方向移动。

    26.2 光电效应¶

    实验规律¶

    • 饱和光电流与光强成正比
    • 光电子最大初动能与截止电压关系：
    \[\frac{1}{2} m v_{\text{m}}^2 = e U_c\]
    • 截止电压与频率线性相关：\(U_c = K\nu - U_0\)
    • 红限频率 \(\nu_0\)：低于此频率不产生光电效应

    光电效应方程¶

    \[\frac{1}{2}mv^2 = h\nu - A\]

    其中 \(A\) 为逸出功，红限频率：

    \[\nu_0 = \frac{A}{h}\]

    26.3 光的二象性 光子¶

    光子的基本性质¶

    光子能量：

    \[E = h\nu\]

    光子质量（静质量为零）：

    \[m = \frac{h\nu}{c^2} = \frac{h}{c\lambda}\]

    光子动量：

    \[p = \frac{h\nu}{c} = \frac{h}{\lambda}\]

    光的波动性（波长 \(\lambda\)、频率 \(\nu\)）和粒子性（能量 \(E\)、动量 \(p\)）通过普朗克常量联系在一起，这就是波粒二象性。

    26.4 康普顿散射¶

    康普顿散射公式¶

    X 射线光子与静止自由电子弹性碰撞后波长改变：

    \[\Delta\lambda = \lambda - \lambda_0 = \frac{h}{m_0c}(1 - \cos\varphi)\]

    其中 \(\varphi\) 为散射角。波长偏移 \(\Delta\lambda\) 与散射物质及入射波长无关，只与散射角有关。

    电子的康普顿波长：

    \[\lambda_C = \frac{h}{m_0c} = 2.43 \times 10^{-3} \text{ nm}\]

    康普顿散射有力地证明了光具有二象性，并且证明光子与微观粒子的相互作用过程严格遵守动量守恒和能量守恒定律。

    26.5 粒子的波动性¶

    德布罗意假设¶

    实物粒子也具有波动性，粒子的能量 \(E\)、动量 \(p\) 与相联系波的频率 \(\nu\)、波长 \(\lambda\) 的关系：

    \[\nu = \frac{E}{h} = \frac{mc^2}{h}\]
    \[\lambda = \frac{h}{p} = \frac{h}{mv}\]

    与粒子相联系的波称为物质波或德布罗意波。

    实验验证¶

    • 戴维孙-革末实验（1927）：电子在镍晶体表面衍射，观察到与 X 射线衍射类似的图样
    • 汤姆孙实验：电子穿过多晶薄膜衍射，得到与 X 射线相似的衍射环
    • 约恩孙实验（1961）：电子单缝、双缝、三缝衍射实验

    一切微观粒子都具有波粒二象性，德布罗意公式是描述微观粒子波粒二象性的基本公式。

    26.6 概率波与概率幅¶

    玻恩概率波解释¶

    德布罗意波是概率波，波函数 \(\Psi\) 称为概率幅，\(|\Psi|^2 = \Psi\Psi^*\) 是粒子的概率密度。

    概率幅叠加原理¶

    双缝实验中，两缝同开时不是概率相加，而是概率幅叠加：

    \[\Psi_{12} = \Psi_1 + \Psi_2\]
    \[P_{12} = |\Psi_{12}|^2 = |\Psi_1 + \Psi_2|^2\]

    交叉项给出两缝之间的干涉效果。这一叠加规律被费曼称为"量子力学的第一原理"。

    26.7 不确定关系¶

    位置-动量不确定关系¶

    \[\Delta x \Delta p_x \geqslant \frac{\hbar}{2}\]
    \[\Delta y \Delta p_y \geqslant \frac{\hbar}{2}\]
    \[\Delta z \Delta p_z \geqslant \frac{\hbar}{2}\]

    其中约化普朗克常量：

    \[\hbar = \frac{h}{2\pi} = 1.054\,588\,7 \times 10^{-34} \text{ J}\cdot\text{s}\]

    能量-时间不确定关系¶

    \[\Delta E \Delta t \geqslant \frac{\hbar}{2}\]

    不确定关系是波粒二象性的反映，它告诉我们粒子的位置和动量的测量精度存在一个终极的不可逾越的限制。对于宏观物体（如子弹），不确定量极小，不影响经典运动；对于原子中的电子，不确定量与运动速度同数量级，必须用量子力学描述。

    第27章 薛定谔方程¶

    27.1 薛定谔得出的波动方程¶

    含时薛定谔方程（一维）¶

    \[-\frac{\hbar^2}{2m} \frac{\partial^2 \Psi}{\partial x^2} + U(x,t)\Psi = i\hbar\frac{\partial\Psi}{\partial t}\]

    其中 \(\Psi = \Psi(x, t)\) 是粒子（质量为 \(m\)）在势场 \(U = U(x, t)\) 中运动的波函数。

    定态薛定谔方程¶

    在恒定势场 \(U = U(x)\) 中运动时，波函数可分离变量：

    \[\Psi(x, t) = \psi(x) \mathrm{e}^{\mathrm{i}Et/\hbar}\]

    空间部分 \(\psi(x)\) 满足定态薛定谔方程：

    \[-\frac{\hbar^2}{2m} \frac{\partial^2 \psi}{\partial x^2} + U\psi = E\psi\]

    三维直角坐标形式：

    \[-\frac{\hbar^2}{2m} \left( \frac{\partial^2 \psi}{\partial x^2} + \frac{\partial^2 \psi}{\partial y^2} + \frac{\partial^2 \psi}{\partial z^2} \right) + U\psi = E\psi\]

    波函数的标准条件¶

    作为有物理意义的波函数，解必须满足：

    • 单值性：在空间每一点波函数只有唯一值
    • 有限性：波函数在全空间必须有限
    • 连续性：波函数及其一阶导数在势能有限处必须连续

    根据这些标准条件，由薛定谔方程可自然地得出能量量子化结果。

    27.2 无限深方势阱中的粒子¶

    势能函数¶

    \[U(x) = \begin{cases} 0, & 0 < x < a \\ \infty, & x \leqslant 0 \text{ 或 } x \geqslant a \end{cases}\]

    能量量子化¶

    \[E_n = \frac{\pi^2 \hbar^2}{2ma^2} n^2, \quad n = 1, 2, 3, \cdots\]

    定态波函数¶

    \[\psi_n = \sqrt{\frac{2}{a}} \sin\frac{n\pi x}{a}, \quad n = 1, 2, 3, \cdots\]

    能量的德布罗意波解释¶

    \[\lambda_n = \frac{2a}{n} = \frac{2\pi}{k}\]

    此式类似于经典的两端固定的弦驻波条件。

    27.3 势垒穿透¶

    隧道效应¶

    微观粒子可以进入其势能（有限的）大于其总能量的区域，这是由不确定关系决定的。在势垒有限的情况下，粒子可以穿过势垒到达另一侧，这种现象又称隧道效应。

    应用实例¶

    • \(\alpha\) 衰变：\(\alpha\) 粒子通过隧道效应穿透库仑势垒逃出原子核
    • 扫描隧道显微镜（STM）：利用电子隧穿电流对距离的极端敏感性观测固体表面原子排列
    • 热核反应：两个带正电的核通过隧道效应克服库仑斥力而聚合

    27.4 谐振子¶

    势能函数¶

    \[U = \frac{1}{2}kx^2 = \frac{1}{2}m\omega^2 x^2\]

    其中 \(\omega = \sqrt{k/m}\) 是振子的固有角频率。

    能量量子化¶

    \[E_n = \left(n + \frac{1}{2}\right)\hbar\omega = \left(n + \frac{1}{2}\right)h\nu, \quad n = 0, 1, 2, \cdots\]

    谐振子的能量是量子化的，能级是等间距的。

    零点能¶

    \[E_0 = \frac{1}{2}h\nu\]

    微观粒子不可能完全静止，这是波粒二象性的表现，满足不确定关系的要求。

    提要¶

    1. 薛定谔方程（一维）：
    \[-\frac{\hbar^2}{2m} \frac{\partial^2 \Psi}{\partial x^2} + U\Psi = i\hbar \frac{\partial \Psi}{\partial t}\]
    1. 定态薛定谔方程：
    \[-\frac{\hbar^2}{2m} \frac{\partial^2 \psi}{\partial x^2} + U\psi = E\psi\]
    1. 一维无限深方势阱能量量子化：
    \[E_n = \frac{\pi^2 \hbar^2}{2ma^2} n^2, \quad n = 1, 2, 3, \cdots\]
    1. 谐振子能量量子化：
    \[E_n = \left(n + \frac{1}{2}\right)h\nu, \quad n = 0, 1, 2, \cdots\]
    1. 零点能：\(E_0 = \frac{1}{2}h\nu\)

    第28章 原子中的电子¶

    28.1 氢原子¶

    氢原子能级¶

    \[E_n = -\frac{m_{\text{e}} e^4}{2(4\pi\varepsilon_0)^2 \hbar^2} \frac{1}{n^2} = -13.6 \times \frac{1}{n^2} \text{ eV}\]

    三个量子数¶

    • 主量子数：\(n = 1, 2, 3, 4, \cdots\)
    • 轨道量子数：\(l = 0, 1, 2, \cdots, n-1\)
    • 轨道磁量子数：\(m_l = -l, -(l-1), \cdots, 0, 1, \cdots, l\)

    轨道角动量¶

    \[L = \sqrt{l(l+1)} \hbar\]

    轨道角动量沿某方向的分量¶

    \[L_z = m_l \hbar\]

    玻尔频率条件¶

    \[h\nu = E_{\text{h}} - E_{\text{l}}\]

    电子云¶

    原子内电子的运动不能用轨道描述，只能用波函数给出的概率密度描述，形象化地用电子云图来描绘。

    28.2 电子的自旋与自旋轨道耦合¶

    电子自旋角动量¶

    \[S = \sqrt{s(s+1)} \hbar = \sqrt{\frac{3}{4}} \hbar\]

    其中 \(s\) 为电子自旋量子数，只有 \(1/2\) 一个值。

    自旋磁量子数¶

    \[S_z = m_s \hbar\]

    \(m_s\) 只有 \(+1/2\)（向上）和 \(-1/2\)（向下）两个值。

    总角动量¶

    轨道角动量和自旋角动量合成的角动量 \(\boldsymbol{J}\)：

    \[J = |\boldsymbol{L} + \boldsymbol{S}| = \sqrt{j(j+1)} \hbar\]

    总角动量量子数 \(j\) 可取值为 \(j = l + \frac{1}{2}\) 和 \(j = l - \frac{1}{2}\)。

    玻尔磁子¶

    \[\mu_{\text{B}} = \frac{e\hbar}{2m_{\text{e}}} = 9.27 \times 10^{-24} \text{ J/T}\]

    施特恩-格拉赫实验¶

    实验中银原子束在不均匀磁场中分为两束，证明电子自旋角动量的空间量子化，沿磁场方向的分量只有两个值。

    28.3 微观粒子的不可分辨性和泡利不相容原理¶

    不可分辨性¶

    量子物理中同种微观粒子不能区分，即不可分辨性。

    泡利不相容原理¶

    一个量子态上最多只能存在一个费米子。这意味着不可能有两个电子同时具有完全相同的四个量子数 \((n, l, m_l, m_s)\)。

    28.4 各种原子核外电子的组态¶

    四个量子数确定电子状态¶

    • \(n\) 相同的状态组成一壳层，可容纳 \(2n^2\) 个电子
    • \(l\) 相同的状态组成一次壳层，可容纳 \(2(2l+1)\) 个电子

    电子组态¶

    • 氢 (\(Z=1\))：\(1s^1\)
    • 氦 (\(Z=2\))：\(1s^2\)（K壳层填满，惰性气体）
    • 锂 (\(Z=3\))：\(1s^2 2s^1\)
    • 氖 (\(Z=10\))：\(1s^2 2s^2 2p^6\)（闭壳层，惰性气体）
    • 钠 (\(Z=11\))：\(1s^2 2s^2 2p^6 3s^1\)（化学活性强）
    • 氯 (\(Z=17\))：\(1s^2 2s^2 2p^6 3s^2 3p^5\)（易夺取电子）
    • 铁 (\(Z=26\))：\(1s^2 2s^2 2p^6 3s^2 3p^6 3d^6 4s^2\)

    电子排布规律¶

    1. 能量最低原理：电子总是处于可能最低的能级
    2. 泡利不相容原理：同一状态不可能有多于一个电子存在

    28.5 X射线¶

    连续谱¶

    入射高能电子与靶原子发生非弹性碰撞时产生的韧致辐射。截止波长由入射电子的能量 \(E_{\text{k}}\) 决定：

    \[\lambda_{\text{out}} = hc / E_{\text{k}}\]

    线状谱（特征谱线）¶

    靶原子中的电子在内壳层间跃迁时发出的光子形成的特征谱线。\(\text{K}_{\alpha}\) 谱线的频率：

    \[\sqrt{\nu} = 4.96 \times 10^7 (Z - 1)\]

    28.6 激光¶

    受激辐射¶

    激光由原子的受激辐射产生，需要在发光材料中造成粒子数布居反转状态。

    激光特点¶

    • 完全相干，光强和原子数的平方成正比
    • 极高的单色性
    • 高度的指向性

    提要¶

    1. 氢原子能级：\(E_n = -13.6 / n^2\) eV
    2. 电子自旋：\(s = 1/2\)，\(m_s = \pm 1/2\)
    3. 泡利不相容原理：一个量子态上最多只能有一个费米子
    4. 电子组态：由四个量子数 \(n, l, m_l, m_s\) 确定
    5. X射线：连续谱（韧致辐射）和线状谱（特征谱线）
    6. 激光：受激辐射产生，需粒子数布居反转

    第29章 固体中的电子¶

    29.1 自由电子按能量的分布¶

    自由电子气模型¶

    金属中的自由电子处于一个三维的无限深势阱中。沿三个棱的方向分别取作 \(x, y, z\) 轴，势阱边长为 \(a\)。

    驻波条件¶

    \[\lambda_x = \frac{2a}{n_x}, \quad \lambda_y = \frac{2a}{n_y}, \quad \lambda_z = \frac{2a}{n_z}\]

    其中 \(n_x, n_y, n_z\) 可独立地取 \(1, 2, 3, \cdots\) 整数值。

    电子能量¶

    \[E = \frac{p^2}{2m_{\text{e}}} = \frac{\pi^2 \hbar^2}{2m_{\text{e}} a^2} (n_x^2 + n_y^2 + n_z^2)\]

    态密度¶

    单位体积内能量小于 \(E\) 的可能状态总数：

    \[n_s = \frac{1}{3} (2m_{\text{e}})^{3/2} \frac{E^{3/2}}{\pi^2 \hbar^3}\]

    单位体积内能量在 \(E\) 附近的态密度：

    \[g(E) = \frac{(2m_{\text{e}})^{3/2}}{2\pi^2 \hbar^3} E^{1/2}\]

    费米能量¶

    \(T = 0\text{ K}\) 时电子可能占据的最高能级：

    \[E_{\text{F}} = (3\pi^2)^{2/3} \frac{\hbar^2}{2m_{\text{e}}} n^{2/3}\]

    其中 \(n\) 为自由电子数密度。

    费米温度¶

    \[T_{\text{F}} = E_{\text{F}} / k\]

    自由电子分布特点¶

    • \(0\text{ K}\) 时，电子占满 \(E_{\text{F}}\) 以下的所有量子态
    • 常温下，自由电子分布和 \(0\text{ K}\) 时基本相同
    • 泡利不相容原理使自由电子对金属比热贡献甚微

    29.2 金属导电的量子论解释¶

    费米球¶

    在没有电场时，自由电子可能向各方向以任意小于 \(v_{\text{F}}\) 的速度运动，所有电子的速度可以用球心在原点、半径为 \(v_{\text{F}}\) 的球体（费米球）内的点表示。

    导电机制¶

    加上电场后，所有电子都同时沿电场方向加速，费米球沿电场方向平移。倒碰撞（速度反转）使费米球只逆电场方向平移一定速度，此速度即电子的漂移速度。

    量子论电导率公式¶

    \[\sigma = \frac{ne^2\bar{\lambda}}{m_{\text{e}} v_{\text{F}}}\]

    29.3 量子统计¶

    费米-狄拉克分布（FD 分布）¶

    由费米子组成的系统，一个能量为 \(E\) 的量子态上存在的粒子数平均为：

    \[n_{\text{FD},1}(E) = \frac{1}{\mathrm{e}^{(E-E_{\text{F}})/kT} + 1}\]

    玻色-爱因斯坦分布（BE 分布）¶

    由玻色子组成的系统，一个能量为 \(E\) 的量子态上存在的粒子数平均为：

    \[n_{\text{BE},1}(E) = \frac{1}{\mathrm{e}^{(E-\mu)/kT} - 1}\]

    麦克斯韦-玻尔兹曼分布（MB 分布）¶

    经典粒子的能量分布：

    \[n_{\text{MB}}(E) = C \mathrm{e}^{-E/kT}\]

    量子统计适用条件¶

    当粒子的德布罗意波长 \(\lambda\) 和系统中粒子的平均间距 \(d\) 可比或更大时，各粒子的波函数将相互重叠，量子效应突出。近似条件为：

    \[n\lambda^3 \ll 1\]

    29.4 能带 导体和绝缘体¶

    能带的形成¶

    \(N\) 个原子集聚形成晶体时，孤立原子的每一个能级将分裂为 \(N\) 个能级，形成一个能量连续的能带。

    能带结构¶

    • 价带：晶体最上面且有电子存在的能带
    • 导带：价带上方的空带
    • 禁带：能带之间没有可能量子态的能量区域

    导体、绝缘体和半导体的区别¶

    • 导体：价带未填满，在外电场作用下电子可被加速形成电流
    • 绝缘体：价带已填满，导带完全空着，禁带宽度很大（如金刚石约 \(6\text{ eV}\)）
    • 半导体：价带填满，导带空着，但禁带宽度较小（如硅 \(1.14\text{ eV}\)，锗 \(0.67\text{ eV}\)）

    29.5 半导体¶

    本征半导体¶

    纯硅和纯锗这种具有相同数量自由电子和空穴的半导体。

    杂质半导体¶

    • N 型半导体（电子型）：掺入 5 价元素（如磷），电子为多子，空穴为少子
    • P 型半导体（空穴型）：掺入 3 价元素（如铝），空穴为多子，电子为少子

    空穴导电¶

    半导体中除导带电子导电外，价带中电子的逐个依次填补空穴的移位等效于带正电的载流子沿反方向移动。

    29.6 PN 结¶

    PN 结的形成¶

    P 型半导体和 N 型半导体相接处，电子和空穴向对方扩散而形成一个阻挡层（约 \(1\ \mu\text{m}\)），层内存在由 N 指向 P 的电场。

    单向导电性¶

    • 正向偏置：P 区接正极，N 区接负极，阻挡层变薄，电流畅通
    • 反向偏置：P 区接负极，N 区接正极，阻挡层变厚，电流被阻断

    29.7 半导体器件¶

    发光二极管（LED）¶

    正向电流通过 PN 结时，电子和空穴湮灭放出能量，在某些半导体中转化为光子。

    光电池¶

    光照射到 PN 结上产生电子-空穴对，在结内电场作用下形成电流。

    半导体三极管¶

    由一薄层杂质半导体夹在相反类型的杂质半导体间构成，可用于电流放大。

    集成电路¶

    将大量半导体器件和电阻、电容等元件精巧地制备在一小片半导体基底上。

    提要¶

    1. 费米能量：\(E_{\text{F}} = (3\pi^2)^{2/3} \frac{\hbar^2}{2m_{\text{e}}} n^{2/3}\)
    2. 费米-狄拉克分布：\(n_{\text{FD},1}(E) = \frac{1}{\mathrm{e}^{(E-E_{\text{F}})/kT} + 1}\)
    3. 能带：\(N\) 个原子的能级分裂形成能带
    4. 导体：价带未填满；绝缘体：价带填满，禁带宽；半导体：价带填满，禁带窄
    5. PN 结：具有单向导电性

    第30章 核物理¶

    30.1 核的一般性质¶

    核的基本组成¶

    核由中子和质子组成。中子数 \(N\)、质子数 \(Z\) 和质量数 \(A\) 的关系为 \(A = Z + N\)。

    核的半径¶

    \[R = r_0 A^{1/3}\]

    其中 \(r_0 = 1.2 \text{ fm}\)。

    核的自旋¶

    自旋量子数 \(I\)，核自旋角动量在 \(z\) 方向的投影：

    \[I_z = m_I \hbar, \quad m_I = \pm I, \pm(I-1), \cdots, \pm\frac{1}{2} \text{ 或 } 0\]

    核的磁矩¶

    核磁矩在 \(z\) 方向的投影为：

    \[\mu_z = g \mu_{\text{N}} m_I\]

    其中核磁子：

    \[\mu_{\text{N}} = \frac{e\hbar}{2m_{\text{p}}} = 5.06 \times 10^{-27} \text{ J/T}\]

    核磁共振（NMR）¶

    核在外磁场中的能级分裂后，可吸收特定频率的电磁波。对氢核（质子），在 \(B = 1\text{ T}\) 时共振频率为 \(\nu = 42.69\text{ MHz}\)。

    30.2 核力¶

    核力的基本性质¶

    • 力强：在核的线度内，核力比库仑力大得多（例如中心相距 \(2\text{ fm}\) 时，核力约 \(2\times 10^8\text{ N}\)，库仑力仅约 \(60\text{ N}\)）
    • 力程短：两核子中心相距大于核子本身线度时，核力几乎完全消失
    • 与电荷无关：质子-质子、质子-中子、中子-中子之间的作用力相同
    • 与自旋取向有关：两核子自旋平行时的相互作用力大于自旋反平行时
    • 多体力：不遵守叠加原理

    核力的微观本质¶

    核子由夸克组成，核力是夸克之间的色相互作用的残余力。

    30.3 核的结合能¶

    结合能公式¶

    \[E_{\text{b}} = (Z m_{\text{p}} + N m_{\text{n}} - m_{\text{N}})c^2 = \Delta m c^2\]

    其中 \(\Delta m = Z m_{\text{p}} + N m_{\text{n}} - m_{\text{N}}\) 为质量亏损。

    用原子质量表示：

    \[E_{\text{b}} = (Z m_{\text{H}} + N m_{\text{n}} - m_{\text{a}})c^2\]

    平均结合能¶

    \[\bar{E}_{\text{b}} = \frac{E_{\text{b}}}{A}\]

    大多数核的平均结合能约为 \(8\text{ MeV}\)。在 \(A > 20\) 时 \(\bar{E}_{\text{b}}\) 差不多与 \(A\) 无关，说明核力的饱和性。

    裂变和聚变¶

    • 裂变：重核分裂为轻核时放出能量
    • 聚变：两个轻核聚合形成新核时放出能量

    30.4 核的液滴模型¶

    韦塞克半经验公式¶

    \[E_{\text{b}} = a_1 A - a_2 A^{2/3} - a_3 \frac{Z^2}{A^{1/3}} - a_4 \frac{(A - 2Z)^2}{A} + a_5 A^{1/2}\]

    各项意义：

    • 体积项 \(a_1 A\)：核力近程性决定，与总核子数成正比
    • 表面项 \(-a_2 A^{2/3}\)：表面核子的紧邻核子数较少的修正
    • 电项 \(-a_3 Z^2/A^{1/3}\)：质子间库仑斥力减小结合能
    • 不对称项 \(-a_4 (A-2Z)^2/A\)：量子力学修正
    • 对项 \(a_5 A^{1/2}\)：实验结果引入

    常数值：

    \[\begin{aligned} a_1 &= 15.753 \text{ MeV} \\ a_2 &= 17.804 \text{ MeV} \\ a_3 &= 0.710\,3 \text{ MeV} \\ a_4 &= 23.69 \text{ MeV} \\ a_5 &= \pm 11.18 \text{ MeV 或 } 0 \end{aligned}\]

    裂变能¶

    \(^{236}\text{U}\) 裂变为两个相等的裂片释放的能量约为 \(180\text{ MeV}\)。

    30.5 放射性和衰变定律¶

    放射性衰变¶

    放射性是不稳定核自发地发射出一些射线而本身变为新核的现象。三种射线：

    • \(\alpha\) 射线：\(\alpha\) 粒子（氦核 \(^4\text{He}\)）流
    • \(\beta\) 射线：电子流
    • \(\gamma\) 射线：光子流

    衰变定律¶

    \[-\mathrm{d}N = \lambda N \mathrm{d}t\]

    积分得：

    \[N(t) = N_0 \mathrm{e}^{-\lambda t}\]

    其中 \(\lambda\) 为衰变常量。

    平均寿命¶

    \[\tau = \frac{1}{\lambda}\]

    半衰期¶

    \[t_{1/2} = (\ln 2)\tau \approx 0.693\tau = \frac{0.693}{\lambda}\]

    活度¶

    \[A(t) = -\frac{\mathrm{d}N}{\mathrm{d}t} = \lambda N = A_0 \mathrm{e}^{-\lambda t}\]

    活度单位：\(1\text{ Bq} = 1\text{ s}^{-1}\)，\(1\text{ Ci} = 3.70 \times 10^{10}\text{ Bq}\)

    30.6 \(\alpha\) 衰变¶

    势垒穿透¶

    \(\alpha\) 衰变是 \(\alpha\) 粒子通过势垒穿透过程从核内逃逸的现象。

    \(\alpha\) 粒子势能（核外）¶

    \[U(r) = \frac{2Ze^2}{4\pi\varepsilon_0 r}\]

    \(\alpha\) 半衰期与能量的关系¶

    \[\ln t_{1/2} = A E_{\alpha}^{-1/2} + B\]

    30.7 穆斯堡尔效应¶

    原子共振吸收¶

    原子发出光子时获得反冲动量，反冲能量 \(E_{\text{rec}} = (h\nu)^2/(2mc^2)\)。由于 \(\Delta E_{\text{N}} \gg 2E_{\text{rec}}\)，光学共振吸收容易实现。

    \(\gamma\) 射线的困难¶

    对 \(\gamma\) 光子，\(\Delta E_{\text{N}} \ll 2E_{\text{rec}}\)，共振吸收不可能。

    穆斯堡尔的解决方案¶

    使 \(\gamma\) 源和吸收体都嵌在晶体中，接受反冲的是整个晶体（质量增大 \(10^{22}\) 倍），\(E_{\text{rec}}\) 可忽略。这种无反冲的共振吸收就是穆斯堡尔效应。

    相对线宽¶

    对 \(^{57}\text{Fe}\)：\(\Delta E_{\text{N}}/E_{\gamma} \approx 1.6 \times 10^{-13}\)

    30.8 \(\beta\) 衰变¶

    三种 \(\beta\) 衰变¶

    \[\begin{aligned} \text{n} &\longrightarrow \text{p} + \beta^- + \bar{\nu}_e \\ \text{p} &\longrightarrow \text{n} + \beta^+ + \nu_e \\ \text{p} + \beta^- &\longrightarrow \text{n} + \nu_e \quad (\text{电子捕获}) \end{aligned}\]

    \(\beta\) 衰变是核内质子和中子相互变换的结果。

    30.9 核反应¶

    反应截面¶

    \[\sigma = \frac{R}{NI}\]

    其中 \(R\) 是反应速率，\(N\) 是靶核数，\(I\) 是入射粒子流强。单位：\(1\text{ b} = 10^{-28}\text{ m}^2\)。

    \(Q\) 值¶

    \[Q = (m_{\text{X}} + m_x - m_y - m_{\text{Y}})c^2\]

    \(Q > 0\) 为放能反应，\(Q < 0\) 为吸能反应。

    阈能¶

    引发吸能反应所需的入射粒子最小能量：

    \[E_{\text{th}} = \frac{m_x + m_{\text{X}}}{m_x} |Q|\]

    提要¶

    1. 核的性质：\(R = r_0 A^{1/3}\)，\(r_0 = 1.2\text{ fm}\)
    2. 核力：大而短程，与电荷无关，是一种多体力，实质是残余色力
    3. 结合能：\(E_{\text{b}} = \Delta m c^2\)，平均结合能约 \(8\text{ MeV}\)
    4. 液滴模型：韦塞克半经验公式
    5. 放射性衰变：\(N(t) = N_0 \mathrm{e}^{-\lambda t}\)，\(t_{1/2} = 0.693/\lambda\)
    6. \(\alpha\) 衰变：势垒穿透过程
    7. 穆斯堡尔效应：无反冲 \(\gamma\) 射线共振吸收
    8. \(\beta\) 衰变：核内质子和中子相互变换
    9. 核反应：反应截面 \(\sigma = R/NI\)，\(Q\) 值，阈能 \(E_{\text{th}}\)
