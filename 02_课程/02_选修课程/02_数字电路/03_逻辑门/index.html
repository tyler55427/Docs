    3.3 或门¶

    ◇ 或门可以具有多于两个的输入。

    或门（OR gate）具有两个或者更多的输入及一个输出，如图 3.18 所示的标准逻辑符号给出了具有两个输入的或门。或门可以具有多于一个的任意输入。虽然同时给出了特殊形状符号和矩形轮廓符号，但是本书使用的是特殊形状符号。

    3.3.1 或门运算¶

    ◇ 有一个或者一个以上的输入是高电平时，或门的输出就是高电平。

    当任意一个输入为高电平时，或门的输出就为高电平。当且仅当所有的输入是低电平时，输出才会是低电平。所以，或门用来判断它的输入是否有一个或者多个高电平，有高电平输入时，输出一个高电平以表明条件满足。图 3.18 中的 2 输入或门的输入被标记为 \(A\) 和 \(B\)，输出被标记为 \(X\)。或门运算可以表述为：

    数字电子技术（第十一版）¶

    下面定义逻辑电路的几个工作特性，它们是按照传输延迟时间测量得到的开关速度、功率损耗、扇出或驱动能力、速度-功率乘积、直流供电电压和输入/输出逻辑电平。

    传输延迟时间 此参数是在逻辑电路能够工作的最大开关速度或频率下得到的。对于逻辑电路，低速和高速是相对于传输延迟时间而言的。传输延迟时间越短，电路的开关速度就越快，工作频率也越高。

    传输延迟时间 \(t_p\)，即逻辑门的 \(t_p\) 是输入脉冲的出现到此脉冲在输出出现的时间间隔。有两种测量与一个逻辑门有关的传输延迟时间的方法，它们适用于所有其他种类的基本门电路。

    • \(t_{PHL}\)：输入脉冲的特定参考点和对应传输得到的输出脉冲参考点之间的时间，如输出从高电平变化到低电平(HL)的点。
    • \(t_{PLH}\)：输入脉冲的特定参考点和对应传输得到的输出脉冲参考点之间的时间，如输出从低电平变化到高电平(LH)的点。

    例 3.22 给出反相器的传输延迟时间。¶

    解： 图 3.57 给出了传输延迟时间 \(t_{PHL}\) 和 \(t_{PLH}\)。在这种情况下，延迟时间的测量是从输入脉冲边沿幅度的 50% 处的点到输出脉冲对应的点之间的时间间隔。\(t_{PHL}\) 和 \(t_{PLH}\) 的值不一定要相等，但是在多数情况下它们是相等的。

    (图 3.57 展示了输入信号与输出信号的波形对比图。输入波形从低电平 L 跃升至高电平 H，在 50% 幅度处标记为参考点；输出波形相应地从高电平 H 下降至低电平 L，在其 50% 幅度处标记为参考点，两者之间的时间差定义为 \(t_{PHL}\)；同理，输入从 H 降至 L，输出从 L 升至 H 的 50% 对应时间差定义为 \(t_{PLH}\)。)

    相关问题： 有一种逻辑门具有 10 纳秒(ns)的最大传输延迟时间 \(t_{PHL}\) 和 \(t_{PLH}\)。另一种门的最大传输延迟时间 \(t_{PHL}\) 和 \(t_{PLH}\) 是 4 ns。哪一种门的工作频率最高？

    直流供电电压 (\(V_{CC}\)) CMOS 逻辑电路按类型来划分，典型的直流供电电压是 \(5\text{ V}\)、\(3.3\text{ V}\)、\(2.5\text{ V}\) 或 \(1.8\text{ V}\)。高级 CMOS 和双极型逻辑电路相比较，其供电电压的范围很宽。标定的供电电压为 \(5\text{ V}\) 的 CMOS 电路可以允许 \(2 \sim 6\text{ V}\) 的供电电压，尽管电压的大小对传输延迟时间和功率损耗的影响很大，但是在此电压范围内仍然可以正常工作。标定的供电电压为 \(3.3\text{ V}\) 的 CMOS 电路可以工作在 \(2 \sim 3.6\text{ V}\) 的供电电压下。对于典型的双极型逻辑电路，典型的直流供电电压是 \(5\text{ V}\)，可以工作在 \(4.5 \sim 5.5\text{ V}\) 的供电电压下。

    \(\diamond\) 更低的功率损耗意味着从直流供电电压中获取更小的电流。

    功率损耗 一个逻辑门的功率损耗 \(P_D\)，是直流供电电压和平均工作电流的乘积。通常情况下，门电路的输出为低电平时的工作电流比输出是高电平时的工作电流要低。生产商的数据表通常给出的是输出为低电平时的工作电流，即 \(I_{CCL}\)，如为高电平，那么为 \(I_{CCH}\)。平均工作电流基于占空比 50% 来确定（输出低电平和高电平的时间各占一半），所以逻辑门的平均功率损耗为：

    \[P_D = V_{CC} \times I_{C(avg)}\]

    (其中 \(I_{C(avg)}\) 为平均工作电流，通常由 \(I_{CCL}\) 和 \(I_{CCH}\) 的平均值决定。)

    第 102 页¶

    第 3 章 逻辑门 (第 102 页 / 共 87 页标记，此处为教材第 102 页)

    \[P_{\text{D}} = V_{\text{CC}} \left( \frac{I_{\text{CCH}} + I_{\text{CCL}}}{2} \right) \quad (3.2)\]

    CMOS 电路与双极型电路相比，它的功率损耗更小。然而，CMOS 电路的功率损耗和它的工作频率有关。频率为零时，典型的静态功率损耗在微瓦 (\(\mu\text{W}\))/门的范围，而在最大工作频率下，它的功率损耗可以接近毫瓦 (\(\text{mW}\))/门的范围。因此，功率损耗通常是在给出的特定频率下的值。例如对于 HC 系列，静态功率损耗为 \(2.75\ \mu\text{W}\)/门，而在 \(1\text{ MHz}\) 的工作频率下的功率损耗为 \(600\ \mu\text{W}\)/门。

    双极型门电路的功率损耗和频率无关。例如，ALS 系列的功率损耗和频率无关，其功率损耗为 \(1.4\ \text{mW}\)/门，F 系列的功率损耗为 \(6\ \text{mW}\)/门。

    输入/输出逻辑电平：\(V_{\text{IL}}\) 为一个逻辑门的输入电压的低电平值，\(V_{\text{IH}}\) 为输入电压的高电平值。供电电压为 \(5\text{ V}\) 的 CMOS 可以接受的最大 \(V_{\text{IL}}\) 值是 \(1.5\text{ V}\)，最小 \(V_{\text{IH}}\) 值是 \(3.5\text{ V}\)。双极型逻辑门可以接受的最大 \(V_{\text{IL}}\) 值是 \(0.8\text{ V}\)，最小 \(V_{\text{IH}}\) 值是 \(2\text{ V}\)。

    \(V_{\text{OL}}\) 为一个逻辑门的输出电压的低电平值，\(V_{\text{OH}}\) 为输出电压的高电平值。供电电压为 \(5\text{ V}\) 的 CMOS 可以接受的最大 \(V_{\text{OL}}\) 值是 \(0.33\text{ V}\)，最小 \(V_{\text{OH}}\) 值是 \(4.4\text{ V}\)。双极型逻辑门可以接受的最大 \(V_{\text{OL}}\) 值是 \(0.4\text{ V}\)，最小 \(V_{\text{OH}}\) 值是 \(2.4\text{ V}\)。

    速度-功率乘积 (SPP)：在考虑延迟时间和功率损耗的情况下，这个参数可以用来测量逻辑电路的运行状况。它在比较 CMOS 和双极型之间各种逻辑门 (或称 CMOS 门和 TTL 门) 系列的性能时特别有用。

    逻辑电路的 SPP 是延迟时间和功率损耗的乘积，计算的值的单位是焦耳 (\(\text{J}\))，这是一个能量的单位。公式如下：

    \[\text{SPP} = t_{\text{p}} P_{\text{D}} \quad (3.3)\]

    例 3.23 某个门电路有 \(5\text{ ns}\) 的延迟时间，在直流电源电压为 \(5\text{ V}\) 时，它的 \(I_{\text{CCH}} = 1\text{ mA}\)，\(I_{\text{CCL}} = 2.5\text{ mA}\)。求速度-功率乘积。

    解： $\(P_{\text{D}} = V_{\text{CC}} \left( \frac{I_{\text{CCH}} + I_{\text{CCL}}}{2} \right) = 5\text{ V} \left( \frac{1\text{ mA} + 2.5\text{ mA}}{2} \right) = 5\text{ V} (1.75\text{ mA}) = 8.75\text{ mW}\)$ $\(\text{SPP} = (5\text{ ns})(8.75\text{ mW}) = 43.75\text{ pJ}\)$

    相关问题：如果电路的延迟时间为 \(15\text{ ns}\)，SPP 为 \(150\text{ pJ}\)，那么它的平均功率损耗是多少？
