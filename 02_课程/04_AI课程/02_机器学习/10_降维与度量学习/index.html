    十、降维与度量学习¶

    1. k近邻学习 (KNN)¶

    KNN是监督学习，工作机制：给定测试样本，基于某种距离，找到训练集中最近的k个训练样本，基于k个"邻居"预测。

    \[\begin{cases} \text{分类：投票法} \\ \text{回归：平均法/加权平均} \end{cases}\]

    KNN是"懒惰学习"，没有训练过程；相对地，进行训练的叫"急切学习"

    关键在于确定k和合适的距离度量

    给定测试样本 \(x\)、最近邻样本 \(z\)，则最近邻分类器出错概率是对 \(x\) 类别不同的概率

    即 \(P(err) = 1 - \sum_{c \in \mathcal{Y}} P(c|x)P(c|z)\)

    假设样本独立同分布，对 \(x\) 和 \(z\)，\(x\) 的 \(\delta\) 距离能找到训练样本 \(z\)。\(c^* = \arg\max_{c \in \mathcal{Y}} P(c|x)\) 为贝叶斯最优分类

    \[P(err) \simeq 1 - \sum_{c \in \mathcal{Y}} P^2(c|x) \le 1 - P^2(c^*|x) = (1 + P(c^*|x))(1 - P(c^*|x)) \le 2(1 - P(c^*|x))\]

    近邻错误率不超过贝叶斯最优分类器错误率的两倍

    2. 低维嵌入¶

    泛化误差基于 \(x\) 的 \(\delta\) 范围能找到样本，即训练样本的采样密度够大（密采样）

    高维密采样和距离计算困难，称"维数灾难"

    缓解：

    \[\begin{cases} \text{特征提取} \\ \text{降维（维数约简）：数学变换将高维属性空间映射为低维"子空间"} \end{cases}\]

    子空间的样本密度提高，距离计算容易

    能降维是因为学习任务可能只与某个低维分布相关

    2.1 多维缩放 (MDS)¶

    要求原始空间中样本的距离在低维保持，即"多维缩放"(MDS)

    令 \(m\) 个样本的距离矩阵 \(D \in \mathbb{R}^{m \times m}\)，其元素 \(\text{dist}_{ij}\) 为 \(x_i\) 到 \(x_j\) 的距离。

    假定获得 \(d'\) 维空间表示 \(Z \in \mathbb{R}^{d' \times m}\)，\(d' < d\)（原始 \(\mathbb{R}^{d \times m}\)），则 \(d'\) 维空间距离与原始相同：

    \[\|z_i - z_j\| = \text{dist}_{ij}\]

    令 \(B = Z^T Z \in \mathbb{R}^{m \times m}\)，\(b_{ij} = z_i^T z_j\)，有 \(\text{dist}_{ij}^2 = \|z_i\|^2 + \|z_j\|^2 - 2 z_i^T z_j = b_{ii} + b_{jj} - 2 b_{ij}\)

    假设 \(Z\) 被中心化，即 \(\sum_{i=1}^m z_i = 0\)，从而 \(\sum_{i=1}^m \sum_{j=1}^m b_{ij} = \sum_{j=1}^m b_{ij} = 0\)

    有：

    \[\begin{cases} \sum_{i=1}^m \text{dist}_{ij}^2 = \text{tr}(B) + m b_{jj} \\ \sum_{j=1}^m \text{dist}_{ij}^2 = \text{tr}(B) + m b_{ii} \\ \sum_{i=1}^m \sum_{j=1}^m \text{dist}_{ij}^2 = 2m \cdot \text{tr}(B) \end{cases} \quad \text{tr}(B) = \sum_{i=1}^m \|z_i\|^2\]

    令：

    \[\begin{cases} \text{dist}_{i\cdot}^2 = \frac{1}{m} \sum_{j=1}^m \text{dist}_{ij}^2 \\ \text{dist}_{\cdot j}^2 = \frac{1}{m} \sum_{i=1}^m \text{dist}_{ij}^2 \\ \text{dist}_{\cdot\cdot}^2 = \frac{1}{m^2} \sum_{i=1}^m \sum_{j=1}^m \text{dist}_{ij}^2 \end{cases}\]

    则 \(b_{ij} = -\frac{1}{2} \left( \text{dist}_{ij}^2 - \text{dist}_{i\cdot}^2 - \text{dist}_{\cdot j}^2 + \text{dist}_{\cdot\cdot}^2 \right)\)（通过 \(D\) 求 \(B\)）

    对 \(B\) 进行特征值分解，\(B = V \Lambda V^T\)，\(\Lambda = \text{diag}(\lambda_1, \cdots, \lambda_d)\) 的对角阵，\(\lambda_1, \lambda_2, \cdots, \lambda_d\) 为特征值，\(V\) 为特征向量矩阵。

    设 \(\lambda_i\) 中有 \(d^*\) 个非零特征值，构成 \(\Lambda_{d^*} = \text{diag}(\lambda_1, \cdots, \lambda_{d^*})\)，\(V_{d^*}\) 为相应特征向量矩阵。

    则 \(Z\) 可表达为 \(Z = \Lambda_{d^*}^{1/2} V_{d^*}^T \in \mathbb{R}^{d^* \times m}\)

    实际中无需距离精确逼近，取 \(d' \ll d\)，\(\tilde{\Lambda} = \text{diag}(\lambda_1, \cdots, \lambda_{d'})\)，\(\tilde{V}\) 为相应的特征向量矩阵。

    则 \(Z\) 可表达为 \(Z = \tilde{\Lambda}^{1/2} \tilde{V}^T \in \mathbb{R}^{d' \times m}\)

    MDS 算法

    输入：距离矩阵 \(D \in \mathbb{R}^{m \times m}\)，其元素 \(\text{dist}_{ij}\) 为样本 \(x_i\) 到 \(x_j\) 的距离；低维空间维数 \(d'\)。

    过程：

    1. 计算 \(\text{dist}_{i\cdot}^2, \text{dist}_{\cdot j}^2, \text{dist}_{\cdot\cdot}^2\)；
    2. 计算矩阵 \(B\)；
    3. 对矩阵 \(B\) 做特征值分解；
    4. 取 \(\tilde{\Lambda}\) 为 \(d'\) 个最大特征值所构成的对角矩阵，\(\tilde{V}\) 为相应的特征向量矩阵。

    输出：矩阵 \(\tilde{V} \tilde{\Lambda}^{1/2} \in \mathbb{R}^{m \times d'}\)，每行是一个样本的低维坐标。

    3. 主成分分析 (PCA)¶

    最简单对高维空间进行线性变换，\(z = W^T X\)，\(X \in R^{dm}\)，\(w \in R^{d \times d'}\) 为 \(d' \times d\) 维基向量。

    \(z_i\) 是 \(x_i\) 在新坐标系 \(\{w_1, \cdots, w_{d'}\}\) 中的坐标向量，若 \(w_i\) 与 \(w_j\) 正交，则 \(W\) 为正交变换。

    线性降维方法都等价上述基本形式，对 \(z\) 空间性质的不同要求，对 \(W\) 有不同的约束。

    性能判断标准：比较前后学习器的性能。若降至 \(1\) 三维，可视化技术判断。

    正交属性空间中的样本，用一个超平面进行恰当的表达，如何理解超平面。

    超平面的性质：

    • 最近重构性：样本到超平面的距离足够近
    • 最大可分性：样本在超平面的投影尽可能分开

    基于上述性质，能得到主成分分析的两种推导：

    3.1 重构性推导¶

    假定 \(p < l\)，\(z_i x_i = 0\)，投影变换后的新坐标系 \(\{w_1, \cdots, w_d\}\)，\(w_i\) 为标准正交基向量：

    \[\begin{cases} \|w_i\|_0 = 1 \\ w_i^T w_j = 0 \ (i \neq j) \end{cases}\]

    若丢弃部分坐标，降维至 \(d' < d\)，\(x_i\) 在低维的投影为 \(z_i = (z_{i1}, \cdots, z_{id'})\)，\(z_{ij} = w_j^T x_i\)。

    用 \(z_i\) 重构 \(x_i\)，得 \(\hat{x}_i = \sum_{j=1}^{d'} z_{ij} w_j = \sum_{j=1}^{d'} w_j^T x_i w_j\)。

    考虑 \(x_i\) 与 \(\hat{x}_i\) 的距离：

    \[\begin{aligned} \sum_{i=1}^m \left\| \sum_{j=1}^{d'} z_{ij} w_j - x_i \right\|_2^2 &= \sum_{i=1}^m z_i^T z_i - 2 \sum_{i=1}^m z_i^T W^T x_i + \text{const} \\ &\propto -\text{tr}\left( W^T \left( \sum_{i=1}^m x_i x_i^T \right) W \right) \end{aligned}\]

    最小化距离：

    \[\min_W \ -\text{tr}(W^T x x^T W), \quad \text{s.t.} \ W^T W = I\]

    即主成分分析的优化目标。

    3.2 可分性推导¶

    \(x_i\) 在新空间中超平面上的投影 \(W^T x_i\)，为使投影分开，应使方差最大化。

    方差：\(\sum_{i=1}^m W^T x_i x_i^T W\)

    优化目标：

    \[\max_W \ \text{tr}(W^T x x^T W), \quad \text{s.t.} \ W^T W = I\]

    使用拉格朗日乘子法：\(x x^T W = \lambda W\)

    对 \(x x^T\) 特征分解，得特征值排序 \(\lambda_1, \lambda_2, \cdots \ge \lambda_d\)，取前 \(d'\) 个特征向量构成 \(W = (w_1, \cdots, w_{d'})\)。

    （实际中用奇异值分解代替特征值分解）（PCA 可视作逐一向最大方向）

    PCA 算法

    输入：样本集 \(D = \{x_1, x_2, ..., x_m\}\)；低维空间维数 \(d'\)。

    过程：

    1: 对所有样本进行中心化：\(x_i \leftarrow x_i - \frac{1}{m} \sum_{i=1}^{m} x_i\)； 2: 计算样本的协方差矩阵 \(\boldsymbol{X}\boldsymbol{X}^\mathrm{T}\)； 3: 对协方差矩阵 \(\boldsymbol{X}\boldsymbol{X}^\mathrm{T}\) 做特征值分解； 4: 取最大的 \(d'\) 个特征值所对应的特征向量 \(w_1, w_2, ..., w_{d'}\)。

    输出：投影矩阵 \(\boldsymbol{W} = (w_1, w_2, ..., w_{d'})\)。

    \(d'\) 可以指定，也可用 \(d'\) 不同的 \(k\) 近邻分类器进行交叉验证选择 \(d'\)。

    PCA 可以设置一个重构阈值，\(t = 90\%\)，取最小的 \(d'\) 使 \(\frac{\sum_{i=1}^{d'} \lambda_i}{\sum_{i=1}^{d} \lambda_i} \ge t\)。

    PCA 只保留 \(\boldsymbol{W}\) 特征向量（中心化），降维舍弃部分信息：

    • 增大采样密度
    • 减少噪声的影响

    4. 核化线性降维 (KPCA)¶

    通常，非线性降维才能找到合适的低维嵌入。

    区分原本稀疏的"低维空间"与降维后的低维空间，前者称"真"低维空间。

    非线性降维常基于核化技术，核主成分分析（KPCA）。

    将高维特征数据 \(\phi(x)\) 投影到由 \(\boldsymbol{W}\) 确定的超平面，\((\sum_{i} z_i z_i^\mathrm{T}) \boldsymbol{W} = \lambda \boldsymbol{W}\)，

    \(z_i\) 是 \(x_i\) 在高维特征空间中的像，\(\boldsymbol{W} = \frac{1}{\lambda} (\sum_{i} z_i z_i^\mathrm{T}) \boldsymbol{W} = \frac{\sum_{i} z_i z_i^\mathrm{T} \boldsymbol{W}}{\lambda} = \sum_{i} z_i \alpha_i\)。

    令 \(z_i\) 是 \(x_i\) 通过映射产生，\(z_i = \phi(x_i)\)，则 \(\boldsymbol{W} = \sum_{i}^{m} \phi(x_i) \alpha_i\)。

    由一般知道，引入核函数 \(k(x_i, x_j) = \phi(x_i)^\mathrm{T} \cdot \phi(x_j)\)。

    简：\(KA = \lambda A\), \((K)_{ij} = k(x_i, x_j)\), \(A = (\alpha_1, \cdots, \alpha_n)\)

    变成特征值求解问题，取 \(K\) 最大的 \(d'\) 个特征值对应的特征向量

    新样本 \(x\)，其投影后的第 \(j\) 维坐标：

    \[z_j = w_j^T \phi(x) = \sum_{i=1}^n \alpha_i^j k(x_i, x)\]

    \(\alpha_i\) 已经过规范化，\(\alpha_i^j\) 是 \(\alpha_i\) 的第 \(j\) 个分量。

    为获得投影后的坐标，KPCA 需对所有样本求和，计算量大

    5. 流形学习¶

    借鉴拓扑流形的降维方法，"流形"是局部同胚于欧氏空间的空间，局部有欧氏空间性质。给降维算法启发，低维流形嵌入到高维空间，高维空间的分布复杂，但局部仍有欧氏空间的性质，因此，容易局部建立降维映射关系，再推广到全局。

    5.1 等度量映射 (Isomap)¶

    低维流形嵌入到高维空间后，高维空间的直线距离有误导性，在低维嵌入流形上不可达，应该是"测地线"距离。

    利用局部同胚，对每个点基于欧式距离找近邻点，建立近邻连接图，计算最短路径近似。

    得到任意两点的距离后，可用 MDS 获得样本点在低维的嵌入。

    Isomap 算法

    输入：样本集 \(D = \{x_1, x_2, \dots, x_m\}\)；近邻参数 \(k\)；低维空间维数 \(d'\)。

    过程：

    1. for \(i = 1, 2, \dots, m\) do
    2. 确定 \(x_i\) 的 \(k\) 近邻；
    3. \(x_i\) 与 \(k\) 近邻点之间的距离设置为欧氏距离，与其他点的距离设置为无穷大；
    4. end for
    5. 调用最短路径算法计算任意两样本点之间的距离 \(\text{dist}(x_i, x_j)\)；
    6. 将 \(\text{dist}(x_i, x_j)\) 作为 MDS 算法的输入；
    7. return MDS 算法的输出

    输出：样本集 \(D\) 在低维空间的投影 \(Z = \{z_1, z_2, \dots, z_m\}\)。

    Isomap 仅得到训练样本的低维嵌入，对于新样本，常用训练样本的高维低维表示，训练一个回归学习器，对新样本预测。

    近邻图的构建：

    • \(k\) 近邻图：指定近邻点的个数 \(k\)
    • \(\varepsilon\) 近邻图：指定近邻点的距离 \(\varepsilon\)

    指定范围：

    • 大：远点误认为近邻，"短路"
    • 小：近点没有近邻，"断路"

    5.2 局部线性嵌入（LLE）¶

    Isomap 保持近邻样本的距离不同，LLE 保持邻域内样本之间的线性关系。

    假设 \(x\) 能通过邻域样本 \(x_j, x_k, x_l\) 线性组合重构，\(x = w_{ij} x_j + w_{ik} x_k + w_{il} x_l\)。

    LLE 希望该关系在低维空间保持。

    为 \(x_i\) 找近邻集合 \(Q_i\)，基于 \(Q_i\) 计算重构 \(x_i\) 的系数 \(w_i\)：

    \[\min_{w_i, \dots, w_m} \sum_{i=1}^m \| x_i - \sum_{j \in Q_i} w_{ij} x_j \|_2^2, \quad \text{s.t.} \sum w_{ij} = 1\]

    \(x_i, x_j\) 均已知，令 \(C_{jk} = (x_i - x_j)^T (x_i - x_k)\)，\(w_{ij}\) 求解可得：

    \[w_{ij} = \frac{\sum_{k} C_{jk}^{-1}}{\sum_{l, s} C_{ls}^{-1}}\]

    LLE 保持 \(w\) 不变，则低维对应 \(z\) 可求解获得：

    \[\min_{z_1, \dots, z_m} \sum_{i=1}^m \| z_i - \sum_{j \in Q_i} w_{ij} z_j \|_2^2\]

    令 \(Z = (z_1, \dots, z_m)\)，\((W)_{ij} = w_{ij}\)，\(M = (I - W)^T(I - W)\)

    上式重写为：

    \[\min_{Z} \text{tr}(Z M Z^T), \quad \text{s.t.} \ Z Z^T = I\]

    对 \(M\) 最小的 \(d'\) 个特征值对应的特征向量矩阵即为 \(Z^T\)。

    LLE 算法

    输入：样本集 \(D = \{x_1, x_2, \cdots, x_m\}\)；近邻参数 \(k\)；低维空间维数 \(d'\)。

    过程：

    1. for \(i = 1, 2, \cdots, m\) do
    2. \(\quad\) 确定 \(x_i\) 的 \(k\) 近邻；
    3. \(\quad\) 从式(10.27)求得 \(w_{ij}, j \in Q_i\)；
    4. \(\quad\) 对于 \(j \notin Q_i\), 令 \(w_{ij} = 0\);
    5. end for
    6. 从式(10.30)得到 \(M\);
    7. 对 \(M\) 进行特征值分解；
    8. return \(M\) 的最小 \(d'\) 个特征值对应的特征向量

    输出：样本集 \(D\) 在低维空间的投影 \(Z = \{z_1, z_2, \cdots, z_m\}\)。

    6. 度量学习 / 距离度量学习¶

    每个空间对应一个距离度量，降维是指找到合适的距离度量使性能更好。

    基本动机： 学习一个合适的距离度量。

    推广距离度量，使有可学习的参数：

    对 \(x_i, x_j\)，定义 \(\text{dist}_b^2(x_i, x_j) = \|x_i - x_j\|_2^2 = \text{dist}_{i,1}^2 + \cdots + \text{dist}_{i,d}^2\)，\(\text{dist}_{ij,k}\) 为第 \(k\) 维的距离。

    当不同属性重要性不同：

    \[\text{dist}_{wd}^2(x_i, x_j) = \sum_{k=1}^d w_k \text{dist}_{ij,k}^2 = (x_i - x_j)^T W (x_i - x_j) \quad , w_{ij} \ge 0, W = \text{diag}(w), (W)_{ii} = w_i\]

    进一步，\(W = \text{diag}(w)\) 意味着属性之间无关；实际上相关，\(W\) 替换为半正定对称矩阵 \(M\)。

    得到 Mahalanobis 距离：

    \[\text{dist}_{mah}^2(x_i, x_j) = (x_i - x_j)^T M (x_i - x_j) = \|x_i - x_j\|_M^2\]

    \(M\) 称为"度量矩阵"，可学习。

    为了保持距离非负且对称，\(M\) 必须是半正定对称矩阵，则有正交基 \(P\) 使 \(M = P P^T\)。

    目标： 使用 \(M\) 能提高近邻分类器的性能，优化对应评价指标求得 \(M\)。

    例： 近邻成分分析 (NCA)，\(x_j\) 投票中的 \(x_i\) 投票，替换为概率，\(p_{ij} = \frac{e^{-\|x_i - x_j\|_M}}{\sum_{l \neq i} e^{-\|x_i - x_l\|_M}}\)。

    以留一法正确率的最大化为目标，\(x_i\) 的留一法正确率，即被自身外样本正确分类的概率：

    \[p_i = \sum_{j \in \text{same class as } i} p_{ij} \quad , \text{"$\sum$" 表示与 } x_i \text{ 相同类别的集合}\]

    则整个样本集留一法的正确率：

    \[\sum_{i=1}^m p_i = \sum_{i=1}^m \sum_{j \in \text{same class as } i} p_{ij}\]

    有 \(M = PP^T\)，NCA 的优化目标为：

    \[\min_{P} \ 1 - \sum_{i} \sum_{j \in \mathcal{J}_i} \frac{e^{-\|P^T x_i - P^T x_j\|^2}}{\sum_{l} e^{-\|P^T x_i - P^T x_l\|^2}}\]

    也可以引入领域知识作为优化目标，例如：样本相似的"必连"约束集合 \(M\)，不相似的"勿连"约束集合 \(C\)。

    相似距离小，不相似距离大：

    \[\min_{M} \sum_{M} \|x_i - x_j\|_M^2 \ , \quad \text{s.t.} \ \sum_{C} \|x_i - x_k\|_M^2 \ge 1, \ M \succeq 0 \ (\text{正定})\]

    若 \(M\) 是一个低秩半正定矩阵，可对 \(M\) 进行特征分解，找到正交基，数目为 \(\text{rank}(M)\)，可得 \(\text{PER}^{\text{dim} \ \text{rank}(M)}\) 用于降维。
