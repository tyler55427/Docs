# Docs

个人学习仓库，用于记录代码、笔记、项目和生活。

> 部分**课程**笔记由多模态模型识别平板记录笔记整理为md，然后人工粗略进行检查。

## 目录说明

| 目录               | 说明                                                                                               |
| ------------------ | -------------------------------------------------------------------------------------------------- |
| `01_代码基础/`   | 各编程语言（C/C++/Java/Python）与数据结构的基础学习笔记                                            |
| `02_课程/`       | 学校课程笔记，含基础课程、选修课、计算机专业课，以及 AI 相关（Agent、Diffusion、LLM、Transformer） |
| `03_算法题/`     | 算法题刷题笔记，按数据结构（数组、链表、树、图等）与算法类型（DP、贪心、搜索等）分类               |
| `04_AI算法/`     | AI 算法的代码实现（Attention、K-Means、KNN、决策树等）                                             |
| `05_实践/`       | 实践过程中遇到的问题与解决方案（API 调用、命令、CUDA、代理、Python、软件等）                       |
| `06_计算机工具/` | 常用计算机工具的安装与使用笔记（Git、Docker、Conda、LaTeX、Markdown、NPM、Claude 等）              |
| `07_生活/`       | 生活相关记录（日常事务、工作、银行卡等）                                                           |
| `08_实施准则/`   | 项目实施规范与准则（项目流程、TODO、大学、科研等）                                                 |
| `09_成果/`       | 阶段性产出，按类型分为 apps / scripts / skills                                                     |
| `10_记录/`       | 日常记录、日志与规范标准                                                                           |
| `11_前沿方向/`   | AI 前沿方向专题笔记                                                                                |
